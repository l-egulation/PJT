# 스탯·특수 효과 후보 분류

[분야 개요](README.md)

기존 성장 모델에서 나온 스탯 후보를 검토하는 문서다. 아래의 빈 도면·슬롯 강화와 정비소 서비스는 당시 제안이다. 현재 장비와 상점의 기준은 [스케치 무기](../equipment/sketch-weapons.md)와 [보상·상점](../run/rewards.md)을 따른다.

## 기존 모델의 역할과 분류 기준

- **기본 스탯**은 상승하더라도 플레이 스타일에 미치는 영향이 적은 스탯이다. 빈 도면 강화는 기본 스탯을 높여 공격 성능을 강화하는 요소다.
- **색상 잉크**는 기본 스탯 대신 추가 스탯과 특수 효과를 부여해 플레이 스타일을 결정한다.
- 정비소에서는 골드로 특정 캐릭터 스탯의 레벨을 올리거나, 팔레트 슬롯을 강화하거나, 랜덤 색상 잉크를 뽑는다. 캐릭터 강화 대상 스탯과 슬롯 강화의 구체 효과는 미정이며, 후보 분류만으로 성장 경로를 확정하지 않는다. 상세 기준은 [성장·재고·경제](../run/progression-and-economy.md)를 따른다.
- 아래의 세부 항목·분류·추천은 **검토 후보**다. 전체를 게임에 도입하거나 특정 색에 배정한 것은 아니며, 현행 구현 여부를 나타내지 않는다.

분류할 때는 같은 무기로 강화 전후를 비교한다. '같은 행동을 더 높은 성능으로 수행하는가'와 '유리한 행동·거리·타이밍·위험 감수가 달라지는가'를 살핀다. 기본 공격이라는 이름이 붙어 있어도 공격 속도·사거리처럼 운용을 바꾸는 수치는 기본 스탯으로 자동 분류하지 않는다.

스탯의 영향은 증가 폭과 다른 효과의 조합에 따라 달라진다. 아래 평가는 통상적인 증가 범위에서의 상대적인 영향이며, 기본 스탯도 처치에 필요한 타수나 생존 가능한 피격 횟수를 바꿀 수 있다.

## 1. 기본 스탯 후보

| 후보 | 플레이 스타일 영향 | 검토 방향 |
|---|---|---|
| 공통 공격력·공격 피해 배율 | 비교적 낮음. 기본·특수공격의 운용 비중을 유지하면서 공격 성능 상승 | 도면 강화의 우선 후보. 공격력과 피해 배율을 별도 성장 항목으로 둘 필요가 있는지는 검토 |
| 기본 공격 피해 | 단독으로 높이면 기본 공격 중심 운용을 유도할 수 있음 | 특수 피해와 함께 성장시키는 기초 피해 항목으로 검토 |
| 특수공격 피해 | 단독으로 높이면 특수공격 중심 운용을 유도할 수 있음 | 기본 피해와 함께 성장시키는 기초 피해 항목으로 검토. 공통 공격력과의 중복 관리 여부 확인 |
| 최대 체력 | 비교적 낮지만 피격을 감수하는 선택에 영향 | 기본 스탯 후보이되 도면의 공격 강화에 자동 포함하지 않음 |
| 방어력·받는 피해 감소 | 비교적 낮지만 근접 유지·피격 감수에 영향 | 생존 기본 스탯 후보. 도입 여부와 성장 경로 미정 |
| 상태이상 저항·받는 상태이상 지속시간 감소 | 행동 제한을 줄이지만 특정 적·위험을 무시하는 운용을 만들 수 있음 | 기본·추가 스탯 경계 후보. 공격 강화 대상과 분리해서 검토 |

초기 검토에서는 도면이 기본·특수공격의 상대적인 역할을 유지하며 피해를 올리는 구성이 가장 단순하다. 생존 스탯을 사용한다면 캐릭터 성장·장비·잉크 중 어디서 얻는지는 별도 결정한다. 기본 스탯으로 분류했다는 이유로 모든 무기에 체력·방어력 옵션을 추가하지 않는다.

## 2. 추가 스탯 후보 — 공격 동작과 사용 주기

| 후보 | 달라지는 운용 |
|---|---|
| 기본 공격 속도 | 공격 횟수·연속 공격·적중 시 효과의 활용 빈도 |
| 공격 준비 시간 | 적의 빈틈에 공격을 넣는 타이밍 |
| 공격 후 회수 시간 | 공격 후 회피·이동·다음 행동으로 전환하는 시점 |
| 연계 입력 허용 시간·연계 유지 시간 | 콤보를 이어 가는 여유와 중간 이탈 가능성 |
| 차지 속도·최대 차지 시간 | 차지 공격을 선택할 기회와 위험 부담 |
| 특수공격 재사용 시간 | 기본·특수공격의 사용 비중과 반복 주기 |
| 특수공격 최대 충전 횟수 | 연속 사용·비축·순간 집중 사용 |
| 특수공격 충전 회복 속도 | 충전 자원의 장기적인 회전 |
| 행동 자원 최대량·소모량·회복 속도 | 해당 자원을 사용하는 공격·회피의 유지와 배분 |
| 공격 중 이동 속도·방향 전환 성능 | 공격하며 추격하거나 거리를 조절하는 방식 |

전체 공격 속도와 준비·회수 시간은 서로 겹칠 수 있다. 후보를 모두 독립 옵션으로 만들기보다 필요한 조절 범위를 선택한다. 충전·행동 자원이 없는 무기에 해당 체계를 자동 추가하지 않는다.

## 3. 추가 스탯 후보 — 거리·범위·투사체

| 후보 | 달라지는 운용 |
|---|---|
| 근접 사거리 | 적과 유지하는 거리·안전하게 공격할 수 있는 위치 |
| 공격 폭·각도·판정 크기 | 적을 모으는 방식과 다수 상대 능력 |
| 폭발·장판·충격파 범위 | 적 밀집 지점·설치 위치의 가치 |
| 투사체 속도 | 조준 예측·원거리 명중·접근 저지 |
| 투사체 사거리·생존시간 | 먼 거리 견제·화면 또는 공간 점유 |
| 투사체 수·산탄 수 | 단일 대상 집중·다수 대상 분산 적중 |
| 발사 간격·연속 발사 수 | 공격 노출 시간·순간 화력·적중 횟수 |
| 확산각·집탄도 | 근접 집중 사격과 넓은 견제의 선택 |
| 관통 수 | 일렬로 배치된 적을 상대하는 가치 |
| 도탄·연쇄 횟수, 다음 대상 탐색 거리 | 여러 적 사이에 공격을 퍼뜨리는 방식 |
| 유도 강도·선회 속도 | 정밀 조준과 이동 중 공격의 비중 |
| 귀환 속도·왕복 거리 | 귀환형 공격을 반복하고 회수 경로를 활용하는 방식 |
| 투사체 크기·곡사 높이·중력 영향 | 적중 여유와 지형·공중 대상을 공략하는 방식 |

관통·연쇄·귀환·유도 등은 먼저 해당 기능이 있어야 그 수치를 조절할 수 있다. 기능을 새로 부여하는 잉크와 기존 기능의 수치를 높이는 잉크는 구분한다. 무기의 기본 형태·특수공격 자체를 바꾸는 범위는 무기·스킬 스탬프와 역할 중복을 검토한다.

## 4. 추가 스탯 후보 — 이동·회피·방어 행동

| 후보 | 달라지는 운용 |
|---|---|
| 이동 속도·가속·감속 | 추격·거리 유지·이탈 |
| 공중 이동 제어 | 공중에서의 위치 조정과 공격 경로 |
| 점프 높이·추가 점프 횟수 | 공중 전투·접근 경로. 맵 이동 경계와 충돌 가능성도 검토 |
| 대시 거리·속도 | 적을 통과하거나 공격 범위를 벗어나는 방식 |
| 대시 최대 횟수·재충전 속도 | 연속 회피·공격적 진입 후 이탈 |
| 회피 무적 시간·정확한 회피 판정 시간 | 회피 타이밍과 위험 감수 |
| 패링 판정 시간·성공 보상 배율 | 방어 행동을 기다리는 운용 |
| 방어 중 피해 감소·방어 자원 소모 | 공격을 받아내며 유지하는 시간 |
| 피격 경직·밀림 저항 | 공격을 계속하거나 위치를 유지하는 선택 |

추가 점프·패링·방어 등의 존재와 공통 사용 가능 여부는 이 목록으로 확정하지 않는다. 조작 반응성과 공정성에 영향을 주는 무적·판정 시간은 일반 수치 옵션과 별도 검토가 필요하다.

## 5. 추가 스탯 후보 — 피해 특화·확률·조건

| 후보 | 달라지는 운용 |
|---|---|
| 치명타 확률·치명타 피해 | 단독으로는 평균 피해 상승에 그칠 수 있음. 치명타 발동 효과·비축 등과 결합할 때 운용 변화 |
| 방어 관통·방어 무시 비율 | 적의 방어 구조에 따라 대상·무기 선택이 달라질 수 있음 |
| 기본 공격·특수공격 중 한쪽만 강화 | 기본 공격 집중 또는 특수공격 중심 순환 |
| 차지·연계 마무리·공중 공격 피해 | 특정 공격 시점·연계를 선택하는 동기 |
| 근거리·원거리·후방 적중 피해 | 유지 거리·위치 선정 |
| 체력이 낮을 때의 피해 증가 | 낮은 체력을 유지하는 위험 감수 |
| 체력이 가득 찼을 때·피격 없이 유지한 피해 증가 | 피격 방지와 안정적인 운용 |
| 상태이상 대상·표식 대상 피해 증가 | 선행 효과를 적용한 뒤 공격하는 순서 |
| 단일 대상·밀집 대상 특화 피해 | 집중 공격과 적 모으기의 선택 |
| 이동·정지·무기 교체 후 피해 증가 | 이동·정지·교체를 공격에 연결하는 방식 |

수치가 있다는 이유만으로 스타일을 만드는 추가 스탯이 되지는 않는다. 치명타·관통처럼 실제로는 평균 피해만 올리는 후보는 채택 시 행동 변화나 조합 목적이 있는지 확인한다. 조건 없는 단순 공격력 증가는 도면 성장과 중복되므로 색상 잉크 후보로 재검토한다.

## 6. 추가 스탯 후보 — 효과 발동·유지·제어

| 후보 | 달라지는 운용 |
|---|---|
| 잉크 효과 발동 확률·발동 주기 | 효과를 유도하기 위한 공격 빈도·발동 시점 |
| 효과 내부 대기시간 | 추가 효과 중심의 반복 주기 |
| 지속 피해량·피해 간격·지속시간 | 적중 후 이탈·재적용·지속 피해 유지 |
| 상태이상 축적량·발동 임계치 | 빠른 다단 공격과 강한 단발 공격의 활용 |
| 효과 중첩 상한·중첩 유지 시간 | 한 적을 계속 공격하거나 대상을 전환하는 선택 |
| 상태이상·장판·표식 지속시간 | 공간 점유와 후속 공격의 여유 |
| 감속 강도·속박·기절 시간 | 접근 저지와 공격 기회 확보 |
| 밀기·끌기 거리·힘 | 적 위치 조정과 지형 활용 |
| 흡혈률·적중 회복량·처치 회복량 | 공격을 통해 체력을 유지하는 운용 |
| 자동 회복량·회복 시작 지연 | 교전 사이에 이탈해 회복하는 운용 |
| 보호막 양·지속시간·재생 주기 | 보호막을 확보한 시점의 진입·피격 감수 |
| 회복 효과 증폭 | 회복 수단을 중심으로 한 조합의 가치 |

추가 피해·회복·제어의 수치는 해당 효과를 보유한 경우에만 의미가 있다. '모든 효과 위력 증가'처럼 여러 기능을 한꺼번에 강화하는 공통 옵션이 필요한지는 별도 검토한다. 같은 파츠의 독립 발동과 지속 효과의 중첩 계산은 개편 설계의 미정 사항을 유지한다.

| 지속 피해 부여 | 화상·독·출혈 | 피해·지속시간·중첩·갱신 |

| 적 행동 제어 | 감속·속박·기절·끌어모으기 | 강도·시간·범위·보스 적용 |

| 대가와 보상 | 최대 체력 감소 대신 공격 효과 강화·체력 소모 공격 | 대가·보상·해제 처리 |
| 공간 생성 | 장판·잔상·궤적·지연 폭발 | 크기·유지 시간·동시 존재 수 |
| 반응·반격 | 피격 반격·피해 반사·공격 차단 시 효과 | 발동 조건·반격 피해·주기 |

특수 효과는 '어떤 일이 일어나는가', 추가 스탯은 '그 일이 얼마나 자주·넓게·오래·강하게 일어나는가'로 구분할 수 있다. 예를 들어 충격파 생성은 효과이고 충격파 범위·발동 주기는 그 효과의 스탯이다. 같은 잉크가 효과와 그 수치를 함께 가질 수 있다.

## 8. 전투 외 스탯 후보

| 후보 | 분리해서 검토할 이유 |
|---|---|
| 재화 획득량·드롭 확률·보상 품질 | 전투 스타일보다 획득 경제를 변화시킴 |
| 상점 할인·제작·정비 비용 감소 | 비용 정책과 연결되는 성장·경제 요소 |
| 아이템 획득 반경·탐지 범위 | 수집 편의·탐험 정보에 영향 |
| 가방 용량·보관 한도 | 현행 15칸 재고 규칙 등과 별도 조정 필요 |

전투 영향이 적다는 이유로 이 후보들을 도면의 기본 스탯에 포함하지 않는다. 도입 여부와 획득 경로 모두 미정이다.

## 다음 분류에서 결정할 항목

- 공통 공격력 하나로 도면의 공격 성장을 표현할지, 기본·특수공격 피해를 함께 성장시킬지.
- 도면의 공격 성능 강화와 캐릭터 스탯 강화의 관계, 캐릭터가 골드로 레벨을 올릴 수 있는 스탯의 목록.
- 팔레트 슬롯 강화가 장착 효과의 어떤 수치에 영향을 주는지와 단계·상한·유지·이전 범위.
- 최대 체력·방어력 같은 생존 기본 스탯을 사용할지와 별도 성장 경로.
- 후보별 실제 행동 변화와 무기 호환성, 공통 옵션으로 만들 범위.
- 잉크 효과의 자체 수치와 도면 공격 수치 사이의 참조 관계.
- 색상별 배정, 중복 파츠의 합산·독립 발동·상한·발동 연쇄 규칙.

이 문서는 후보 분류이며 콘텐츠 확정·데이터 반영·코드 구현·플레이 검증 완료를 의미하지 않는다.
