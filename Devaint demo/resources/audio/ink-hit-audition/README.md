# 잉크 피격음 비교

`preview/index.html`을 브라우저에서 열면 서버 없이 재생할 수 있다. 10개 후보는 구매한 Gamemaster Audio의 물 튀김·젖은 충돌 원음을 가공한 미확정 제작물이며 게임에 적용하지 않았다. 의성어는 목표 질감의 설명이다.

각 무기의 기본공격 개별 타격·전체 콤보와 확정 스킬을 선택해 후보를 겹쳐 듣는다. 공격음은 생성 시점의 Deviant-main 로컬 Unity 연결에서 읽으며, 스킬은 SelectedSkillAudio의 배치 바이트와 리소스 원본이 같은지 확인한다. 대검 모아내려찍기 6·7번은 각각 고를 수 있다. 원본 캐릭터 모션 프레임도 함께 표시한다. 적중·비행·설치·폭발·복귀 타이밍은 청취용 시나리오이며 게임 시뮬레이션이나 실제 충돌 판정이 아니다. 비공격 스킬에는 자동 피격음을 넣지 않는다. 기존 개별 무기 피격음은 겹치지 않고 새 공통 후보로 대체해 비교한다.

공격음 기본값은 게임의 무기 기본 음량 0.8이다. 에디터의 기기별 PlayerPrefs는 읽지 않는다. 마스터 기본값은 75%이며 겹침 과부하를 줄이기 위한 출력 컴프레서가 있다. 후보 단독/공격 혼합/A-B/10개 순차/무기 전체 재생과 독립 음량·피격 시점·투사체 충돌 지연, 별표 및 선택 JSON 저장·불러오기를 지원한다. 선택은 이 비교 화면 전용 브라우저 저장소를 사용한다.

`source/recipes.json`은 재료·해시·가공과 비교 음원 출처, `source/originals/`는 해당 구매팩 원음의 바이트 사본, `runtime/`은 48 kHz mono PCM16 후보다. `source/template.html`과 `source/app.js`가 화면 편집 원본이다. 다시 만들려면 메인 루트에서 `python resources/tools/build_ink_hit_audition.py`를 실행한다. 이 도구는 Unity 음원·게임 코드를 변경하지 않는다.

여러 마리 청취는 1~10마리와 0~150 ms의 몬스터별 피격 간격을 지원한다. 피격음만 추가되며 공격·폭발·설치음은 복제하지 않는다. 완전 동시·35 ms 빠르게 쓸기·80 ms 차례로 프리셋이 있고, 선택적으로 현재 게임처럼 같은 피격음을 60 ms 이내에서 억제할 수 있다. 몬스터별 적중 표시는 억제 여부와 무관하게 유지하며 설정을 선택 JSON에 저장한다. 피격음만 듣기도 같은 몬스터 수·간격을 사용한다.

현재 적용음 비교는 `WeaponHitSounds.For`의 무기/레이저/폭발 분기를 따라 `SelectedAudioClips.asset`의 GUID로 연결된 로컬 WAV 바이트를 사용한다. 별도 피격음이 없는 폭탄·유탄·모아쏘기·폭발 수리검 등은 무음을 명시하고 혼합 비교에서 기존 폭발음만 유지한다. 현재 피격음은 게임 기본 gain 0.8을 적용하며 기기별 음량 설정은 읽지 않는다. 현재 적용음 혼합·피격음만·현재→후보 A/B를 지원하고, 양쪽 모두 같은 몬스터 수·간격·중복 억제 설정을 사용한다. 60 ms 억제를 끈 다중 재생은 원음 중첩 비교이며 현재 게임 재생 횟수의 재현이 아니다.
