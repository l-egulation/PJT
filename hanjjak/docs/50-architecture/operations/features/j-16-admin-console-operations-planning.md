# J-16 어드민 콘솔 운영 기능 기획

이 문서는 기능을 찾기 위한 경로 문서다. 정책, 수치, 상태, 완료 여부를 정의하지 않는다.

- 운영 정본: [배포·운영 SSOT](../../operations.md)
- 데이터·지표 정본: [데이터·이벤트 SSOT](../../../40-systems/event-system/ssot.md)
- 제안·요구사항: [어드민 콘솔 운영 기획](../../../70-plans/admin-console/README.md)
- 실행 상태·완료 기준·증거: [J-16 작업 문서](../../../wiki/06-delivery/tasks/J-delivery-operations/j-16-admin-console-operations-planning.md)

기능 요구가 바뀌면 먼저 정본 문서의 책임 범위를 확인하고, 필요한 결정은 [결정 로그](../../../80-decisions/README.md)에 남긴다.
