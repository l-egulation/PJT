# MVP Risks

출시 계획에서 추적할 위험은 [Decision Log](../../80-decisions/README.md)의 unresolved·working 항목, 관련 도메인 SSOT, A–K 실행 작업으로 연결한다.

- MVP 범위와 챕터 범위의 충돌
- 장비·스킬·거래 가능 자원의 미확정
- 보석 옵션·보스·보상 수치와 입장 제한 정책의 미확정
- 전투 스탯과 공식의 충돌
- 서버 스테이지 진행 권한과 로컬 성장·실행 체크포인트의 재시도·복구 경계
- 이벤트 전달과 운영 배포의 검증 증거

위 항목의 현재 상태를 이 문서에서 재판정하지 않는다.
