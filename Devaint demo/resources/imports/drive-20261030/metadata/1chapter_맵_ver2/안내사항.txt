1챕터 숲 맵 편집기 안내

■ 실행
저장소에서 tools/chapter1-map-editor/맵 편집기.html 파일을 다운로드한 뒤
Chrome 또는 Edge로 여세요. GitLab 웹의 HTML 미리보기 대신 파일을 내려받아 엽니다.
이미지와 실행 코드가 HTML 안에 포함되어 서버·설치·Drive 동기화가 필요 없습니다.

■ 바닥 타일 수정
상단 '지형 편집' 또는 숫자 2를 누르세요.
붓: 왼쪽 드래그로 바닥을 추가합니다.
지우개: 왼쪽 드래그로 바닥을 지웁니다. 오른쪽 드래그로도 지울 수 있습니다.
사각형 채우기/지우기: 시작 칸에서 끝 칸까지 드래그합니다.
잔디·흙 지형 / 부분 스케치 재질과 1·3·5·9칸 붓 크기를 선택할 수 있습니다.
정밀한 편집은 아래 실제 크기 화면에서 하세요. 필요하면 32px 격자를 켭니다.
노출된 윗면은 잔디+흙, 옆면·밑면은 흙으로 자동 연결됩니다.
돌·뿌리는 가장자리에만 남고, 안쪽은 무늬 없는 어두운 색으로 채워집니다.
모서리와 좁은 천장 끝은 자동으로 둥글게 이어집니다.
둥근 윤곽은 그림 표현이며 편집·저장 기준은 32px 사각 격자입니다.
부분 스케치는 새 타일의 상단 잎에 적용되며 내부 흙은 유지됩니다.

■ 발판·보스·상점 등의 배치
'배치 편집' 또는 숫자 1을 누르세요.
영역을 선택해 드래그하면 이동하며 오른쪽 아래 손잡이로 크기를 조절합니다.
오른쪽 속성에서 이름·종류·좌표·크기·메모를 수정할 수 있습니다.
'영역 추가'로 추가하고 '선택한 영역 삭제' 또는 Delete로 삭제합니다.
바닥 지형과 배치한 발판은 별개입니다.
전투·보조 발판은 두꺼운 흙 발판, 통과 바닥은 나무살·뿌리 발판으로 보입니다.
길이를 바꾸면 양끝과 중간 조각이 이어집니다. 한 칸 너비도 지원합니다.
발판의 표시 높이 1칸은 배치 기준이며 그림의 뿌리는 그 아래로 더 내려옵니다.
바닥을 지워도 발판이 남으면 배치 편집에서 해당 발판을 삭제하세요.
'배치·발판 표시'를 끄면 지형만 살펴볼 수 있습니다.

■ 화면 이동·되돌리기
'둘러보기' 또는 숫자 3: 아래 화면을 드래그해 이동합니다.
편집 중에도 Space+드래그 또는 휠 버튼 드래그로 이동할 수 있습니다.
전체 지도 클릭·공간 이름·가로/세로 슬라이더로도 위치를 바꿀 수 있습니다.
Ctrl+Z: 되돌리기 / Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행.
B: 붓 / E: 지우개 / Esc: 진행 중인 드래그 취소.

■ 저장과 팀 전달 — 중요
'전체 맵 JSON 저장' 또는 Ctrl+S로 지형과 배치를 함께 저장하세요.
자동 저장은 현재 브라우저에만 남습니다. HTML 파일 자체가 바뀌지는 않습니다.
팀원에게 '맵 편집기.html'과 저장한 JSON을 함께 전달하세요.
팀원은 HTML을 열고 'JSON 불러오기'로 해당 수정본을 불러오면 됩니다.
JSON은 같은 기준 맵을 포함한 이 편집기에서 여세요.
동시에 편집한 파일은 자동 병합되지 않습니다. 서로 다른 이름으로 저장해 전달하세요.
'지도 PNG'는 확인용 이미지이며 편집 데이터를 담지 않습니다.
예전 배치 전용 JSON을 불러오면 지형은 유지하고 배치만 바뀝니다.

■ 초기화
'지형만 복원': 바닥만 최초 상태로 복원하고 배치는 유지합니다.
'기본 지형과 배치로 복원': 확인 후 지형과 배치를 모두 최초 상태로 돌립니다.
복원하기 전 수정본 JSON을 저장하세요. 복원도 되돌리기로 취소할 수 있습니다.

■ 현재 범위
높은 흙둔덕·절벽·분지를 포함한 24개 연결 공간의 1챕터 지형을 수정하는 설계 도구입니다.
캐릭터는 크기 비교용입니다. 실제 점프·벽차기·트램펄린·전투는 실행하지 않습니다.
보스·상점·황금방·몬스터 표시도 배치 후보입니다. 보상·잠금 규칙을 확정하지 않습니다.
기존 캐릭터 PNG와 모션 타이밍을 사용하며 실제 Unity 씬에 자동 적용하지 않습니다.
기준 지형 ID가 바뀌어 이전 지형의 자동 저장과 별도로 보관합니다.
이전 편집본 내려받기 버튼으로 JSON을 저장한 뒤 이전 지형용 편집기에서 여세요.
새 지형과 이전 지형의 수정 좌표를 자동으로 섞지 않습니다.
실제 점프 도달 여부와 고체·통과 판정은 Unity 적용 단계에서 검증해야 합니다.
