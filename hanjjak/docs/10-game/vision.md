## 한 문장

한짝은 웹 브라우저에서 열어 두고, 사용자가 다른 일을 하는 동안 이동·전투·성장·보상 처리가 자동으로 이어지는 저피로 방치형 웹 펫 게임이다.

## 문서 연결

세계관과 주인공의 출발점은 [Story](story.md), 세부 경험은 [Target Experience](target-experience.md), 상위 원칙은 [Game Pillars](pillars.md), 플레이 순서는 [Core Loop](../20-design/core-loop.md)에서 관리한다. 출시 범위는 [MVP Plan](../70-plans/mvp-release/requirements.md), 게임 규칙은 [Game Rules](../20-design/game-rules.md)를 따른다.
