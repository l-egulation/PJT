# 시계탑 집행자: 고정형 보스 모션 제작 명세

[분야 개요](README.md)

이 문서는 아티스트와 Unity 작업자가 함께 사용하는 현재 제작 기준이다. 보스는 방 중앙의 천장에 사슬로 매달린 시계탑이며, 양쪽 사슬 끝에 돌주먹이 달린다. 일반 이동·걷기·잉크 잠행·기본 공격은 만들지 않는다. 양손 내려찍기는 보류 상태다. 현재 Unity 테스트방은 HTML 시안(`resources/authoring/workbench/source/MonsterReference/local-assets/hanging-clock-boss-battle-v1`)의 분리 부품·거대 팔·낙하침·믹서기 몸통과 바늘·이펙트·붕괴 조각을 런타임에 조립해 시안과 같은 시간·좌표로 그린다(`ClockExecutionerBoss.Preview.cs`). 이것은 시안 부품이며 승인된 보스 모션 클립이 아니다. 이 문서의 스프라이트시트 제작과 전체 플레이 검증은 완료하지 않았다.

## 디자인과 분리 원본

- 디자인 기준: `unity/Assets/ForestCombatV2/Resources/ClockExecutioner/Stationary.png`. 같은 이미지의 현재 런타임 입력은 `StationaryBytes.bytes`다. PNG는 저장소의 별도 아트 배포 정책에 따라 복원해야 하며, `.bytes`는 테스트용 이미지 입력이다.
- 천장 고정부 / 중앙 몸통 / 왼쪽 주먹 / 오른쪽 주먹 / 사슬 / 시계판 / 시침 / 분침 / 잉크와 파편 효과를 분리한 편집 원본을 전달한다.
- 몸통의 하부는 지상 기본 공격으로 닿아야 한다. 몸통·주먹은 통과 가능하며 접촉 피해가 없다. 사슬과 천장 고정부는 피격 부위가 아니다.
- 몸통과 주먹은 체력을 공유한다. 한 공격이 여러 부위에 겹쳐도 보스 피해는 한 번만 적용한다. 주먹은 준비·뻗기·유지·회수 중 타격 가능하다.
- 기존 256×256 / PPU 32 / 6색은 이전 이동형 제작 규격이다. 새 고정형의 전체 캔버스와 거대 팔 캔버스는 별도 확정이 필요하다. 30유닛 팔을 기존 정사각 셀에 억지로 축소하지 않는다.
- 기존 6색 참고값: `#171716 #41413D #575451 #817D77 #9C968D #D6D0C7`. 최종 원본은 투명 배경과 픽셀 경계를 유지한다. 현재 생성 시안의 색 수가 최종 6색 정리까지 완료됐다는 뜻은 아니다.

## 새로 만들어야 하는 모션과 전달 묶음

아래 8개는 제작·전달용 묶음 제안이다. 실제 PNG 시트 개수는 프레임 수와 최대 텍스처 크기를 확인한 뒤 결정한다. 한 동작의 준비·타격·회수를 서로 다른 클립으로 지정할 수 있어야 한다.

| 묶음 | 필요한 클립·이미지 | 동작과 제작 포인트 |
| --- | --- | --- |
| 01 몸통 대기 | `body_idle`, 사슬·잉크 보조 루프 | 중앙 고정, 미세 흔들림과 잉크 흐름. 흔들림은 몸통을 기준으로 주먹·잉크·시계판·시침·사슬이 조금씩 늦게 따라간다. 캐릭터의 걷기처럼 수평 이동하지 않음 |
| 02 등장·상승·복귀 | `body_intro`, `body_rise`, `body_return` | 입장 공개용 모션, 믹서기 전 위로 빠지는 모션, 원래 위치로 내려오는 모션. 도착 기준점 일치 |
| 03 시계침 소환 | `needle_cast_prepare`, `needle_cast_loop`, `needle_cast_recover` | 몸통 시계가 힘을 모으고 시계침을 소환하는 자세. 구체적인 포즈는 제작 시안 검토가 필요함 |
| 04 사슬 주먹 전조 | `fist_side_exit`, `fist_home_return` | 3연속 시작 때 양쪽 주먹과 사슬이 각자 화면 밖으로 빠르게 빠짐. 원위치 복귀와 대기 연결. 좌우 반전 재사용 가능 여부 검토 |
| 05 거대 팔·주먹 | `giant_fist_extend`, `giant_fist_hold`, `giant_fist_retract` | 왼쪽·오른쪽·위·아래 어느 끝에서든 거대한 팔과 주먹이 나타나 반대쪽으로 뻗음. 가로는 화면 끝에서 끝까지 길이 30유닛·바닥부터 높이 4유닛, 세로는 폭 4유닛 기둥. 사슬 추 휘두르기 모션으로 대체하지 않음 |
| 06 낙하 시계침 | `needle_fall`, `needle_impact`, `needle_fade` | 폭 3유닛의 길쭉한 시계침. 낙하 중 피해, 착지 후부터 무해하게 소멸. 낙하 이동은 Unity 위치 제어와 분리 가능 |
| 07 믹서기 | `mixer_appear`, `mixer_loop`, `mixer_disappear`, 분리된 시침·분침 | 중앙 몸통 전체가 아닌 확대된 시계. 원형 영역의 크기를 읽을 수 있게 제작. 바늘은 코드 회전 또는 루프 시트 중 선택 가능 |
| 08 종료·공통 효과 | `body_death`, `fist_death`, 타격 파편 | 사망 시 몸통·주먹·사슬·믹서기·예고의 종료를 함께 설계. 구체적인 사망 연출 길이는 미정 |
| 09 사슬 긋기 | `chain_line_ink`, `chain_whip`, `chain_impact` | 화면 끝에서 끝까지 잉크 선이 그어지는 획과 그 선을 따라 끝에서 끝까지 내리치는 사슬, 반대편 끝의 충돌 파편. 현재 테스트방은 잉크 선을 코드 직선, 사슬을 시안 사슬 고리 그림으로 그린다 |

별도 자세 전환형 피격 모션은 필요 없다. 보스는 흰 점멸 없이 타격 이펙트·파편·타격음으로만 표현한다(사용자 결정). 제한시간 UI는 코드로 제작할 수 있으므로 반드시 애니메이션 시트로 납품할 필요는 없다. 보스 체력 바는 보스 발밑이 아니라 화면 아래쪽 가운데에 화면 폭 60% 길이의 막대로 그린다(`CombatDiagnostics`, 색은 `TestEnemy.bossBarColor`). 1페이즈는 빨강, 2페이즈는 보라, HP 360 이하 최종 광폭은 먹색(검정)이다. 현재 시험 체력은 1,800이다. 체력·광폭화 기준·최종 단계 배율은 `data/combat/clock_executioner_timing.json`을 편집하고 `python tools/combat/export_clock_boss_timing.py`로 적용한다.

공격 예고는 도형이 아닌 잉크 FX 프레임(최대 3색·알파 0/255·PPU 32·20 FPS)으로 공격이 나오는 곳만 표시한다. 쓸고 지나가는 범위를 바닥에 따로 칠하지 않는다. 범위는 플레이하며 익힌다(사용자 결정).

| 예고 | 프레임 | 표시 |
| --- | --- | --- |
| 시계침 `needleInk` | 20장, 128×472 | 낙하 열 96px 위 화면 위끝에서 잉크가 스며 굵은 방울 세 줄로 늘어진다. 방울은 바닥선에 떨어지고, 마지막 0.2초에 가운데 줄이 늘어난 뒤 침이 떨어진다. 피벗은 바닥선이다. |
| 긴 주먹 `wallInk` | 14장, 80×208 | 주먹이 나올 자리(양옆 화면 끝·화면 위끝·바닥)에서 잉크가 스며 부글거리며 갈라지고 1초 뒤 거대 주먹이 나온다. 모든 발이 전조 1초 내내 보인다. 4유닛 주먹 폭에 맞춰 2/3배로 그리고 세로 주먹은 90° 돌린다. 뻗기가 끝날 때까지 6~13장을 반복한다. |
| 믹서기 `clockRing` | 20장, 416×416 | 반지름 6유닛 피해 원을 잉크 시계판으로 그린다. 출현 위치에서 0~9장으로 그리고, 이동 중에는 시계를 따라 10~19장을 반복한다. |

원본은 `resources/authoring/workbench/source/MonsterReference/local-assets/hanging-clock-boss-battle-v1`의 HTML 시안과 `build-ink-telegraph.py`다. `python resources/tools/export_clock_boss_telegraphs.py --destination outputs/art-review/export_clock_boss_telegraphs`가 `Assets/Deviant/Stage1Monsters/Resources/ClockExecutionerTelegraph`로 복사하고, `python resources/tools/export_clock_boss_preview.py --destination outputs/art-review/export_clock_boss_preview`가 시안의 부품·공격 그림·이펙트(먼지·타격·침 착지·소멸·붕괴 연기)·사슬 고리·미리 자른 붕괴 조각을 `Assets/Deviant/Stage1Monsters/Resources/ClockExecutionerPreview`로 복사한다. `Tools > deviant > Stage 1 Monsters > Import Clock Boss Preview Art`가 두 폴더의 Point·무압축·Full Rect·피벗을 설정하며 해시·색·알파를 검사한다. 프레임이 없으면 보스는 기존 시험용 도형으로 대체한다. 시안 부품은 그림 한 장에서 잘라 만든 것이라, Unity처럼 부위마다 시간차를 두고 흔들면 잘린 자리가 벌어진다. 그래서 내보낼 때 `resources/tools/mend_clock_boss_parts.py`가 복사본만 메운다. 시안 원본은 그대로 둔다. 메우는 곳은 양쪽 사슬 고리 아래(남은 조각을 지우고 진짜 고리 한 마디를 주먹 뒤까지), 가운데 사슬 끝(첨탑 뒤로 한 마디 연장), 첨탑 꼭대기(박혀 있던 사슬 조각 제거·윤곽 닫기), 주먹 테두리 윗선, 시계판 구멍 둘레의 밝은 호, 몸통 잉크와 아래 잉크의 맞닿는 선(서로 12px씩 검정으로 이어 붙임), 흩어진 점이다. 채운 화소는 모두 원래 팔레트 색이다.

Unity 조립 기준: 시안 960×540px(바닥 y464)이 화면 한 장 크기의 30유닛 보스방과 PPU 32로 1:1 대응한다. 보스 그림은 플레이어(그리기 순서 10) 뒤인 3~9에 둔다. 확대 믹서기 몸통은 바닥선에서 그림을 잘라 그린다(마을 지형 셰이더가 스텐실을 써서 SpriteMask는 쓰지 않는다). 믹서기 중심은 명세대로 바닥+6이라 시안(바닥+3.9)보다 2.1유닛 높게 보인다. 작은 주먹 피격 박스는 시안 주먹 위치·크기(86×114px)를 따른다.

## 패턴 시간표: 일반 상태

아래 표는 기본 속도, 곧 2페이즈의 시간이다. 1페이즈는 사슬의 고정 1초 유지를 제외한 시간을 0.85로 나눈 값이다(예: 긴 주먹 전조 1초 → 약 1.18초).

사슬 유지 시간의 편집 원본은 [`data/combat/clock_executioner_timing.json`](../../../../data/combat/clock_executioner_timing.json)의 `chainHoldSeconds`다. `python tools/combat/export_clock_boss_timing.py`로 `Resources/ClockExecutioner/Timing.json`을 재생성하며 `--check`로 일치를 확인한다. 보스가 시작할 때 해당 값을 읽어 스키마와 유한 양수를 검증한다. 다른 보스 시험 수치는 아래 표와 현재 구현 범위를 따른다.

| 사슬 긋기 | 사슬 날아옴 / 유지 / 감김 | 0.15초 / 1초 / 0.2초 | 날아오는 동안은 무해하며, 반대편 끝에 꽂히는 순간 완전히 펼쳐진 사슬 전체 경로(판정 반지름 0.6유닛)에 대해 기준 피해 20을 공통 피해 변동 규칙에 따라 한 번만 판정한다. 그 순간 빗나가거나 대시·무적으로 피해가 거부되어도 해당 사슬은 다시 판정하지 않는다. 각 사슬은 도착 후 전투 시간 기준 1초 동안 완전히 펼쳐진 채 유지한다. 유지 시간은 페이즈 속도 배율을 적용하지 않으며 일시정지 중에는 진행하지 않는다. 유지·감김 중에는 닿아도 무해하다. 긴 프레임으로 도착 시각을 건너뛰면 다음 전투 틱에서 한 번 처리한다. 반대편 끝에 닿는 순간 흙먼지·파편이 피고 화면이 0.2초 흔들린다. 잉크 선은 7px, 사슬 고리는 시안 고리의 2.5배로 그린다. 사슬이 출발하기 전(경고 구간) 잉크 선은 14px 그리고 8px 비우는 점선이며 초당 8번 1↔0.55 불투명도로 깜빡인다. 진짜 사슬·배경 펜선과 같은 먹색이라 모양으로 가르고, 점마다 11px 종이색(#F4ECDE) 테두리를 깔아 어두운 석조 보스방에서도 보이게 한다(아트 리뷰 H-1, 2026-10-30). 사슬이 출발한 뒤에는 실선이다 |
| 사슬 긋기 | 회복 / 다음 패턴 대기 | 2초 / 2초 | 마지막 선 사슬 종료 후. 기본 속도에서 7줄이면 다음 패턴까지 약 7.95초 |

일반·광폭화 공통: 패턴 종료에는 회복까지 포함한다. 그 후 2초 대기한다. HP 360 이하 최종 광폭에서는 회복과 다음 패턴 대기가 모두 0초다. 긴 주먹·시계침·믹서기·사슬 긋기 네 패턴 중 직전 패턴을 제외하고 무작위로 고른다. 난수 시작값은 전투마다 새로 정해 매 판 순서·방향·조준이 달라진다. 긴 주먹의 발마다 출발 끝도 무작위이며, 같은 끝이 다시 나올 수 있다.

## 방과 판정에 맞추는 기준

- 보스방은 모두(시계탑 테스트방과 플레이 빌드 보스방) 고정 카메라 화면 한 장, 즉 폭 30유닛 공간이다(사용자 결정). 양옆과 천장은 화면 바로 바깥의 벽(지형)으로 막혀 있고 보스가 매달린 들보만 보인다. 플레이어가 방 안에 들어오면 입구가 벽으로 닫히고 카메라는 방 중앙(바닥+6)에 고정된다. 전투 전·전투 중·보스 처치 후에도 방 안에 있는 동안 고정을 유지한다. 방을 벗어나면(체크포인트 복귀) 입구가 열리고 카메라가 다시 따라간다(`Chapter1BossRoomEnclosure`). 카메라는 고정 위치로 순간이동하지 않고 0.65초 동안 SmoothStep으로 시작과 끝을 완만하게 옮겨 간다. 체크포인트 복귀·명시적 즉시 배치는 기존 snap 경로를 유지한다. 손맛 카메라의 고정 확대(12%)는 보스방 안에서 끈다(`CombatFeelCamera.HoldBaseFraming`). 켜 두면 화면이 약 26.8유닛만 보여 화면 끝·위끝의 공격 예고 잉크가 잘린다. 들어올 때는 입구에서 1유닛 안쪽부터 방 안으로 보고, 일단 들어오면 닫힌 입구에 붙어 서도 방 안으로 유지한다. 보스방에는 지도 표지 이름표(「최종보스」)를 띄우지 않는다. 시계탑 테스트방은 방 밖 통로에서 시작해 플레이어가 걸어 들어가야 입장 연출이 시작된다.
- 가로 긴 주먹은 화면 끝에서 끝까지 길이 30유닛이라 옆으로 피할 안전 공간이 없다(사용자 결정). 높이는 4유닛이라 한 번 점프(3유닛)로는 못 넘고 이단 점프(6유닛)로 넘는다. 세로 긴 주먹은 폭 4유닛으로 화면 위끝에서 바닥까지 내리찍거나 바닥에서 위끝까지 솟구치며 옆으로 피한다. 전조는 나오는 자리의 잉크로만 알리고 위험 영역 자체는 칠하지 않는다. 거대 주먹 그림(176px)은 4유닛에 맞춰 0.73배로 그린다.
- 믹서기는 시계 전체가 방 안에 등장한다. 왼쪽 출현 중심은 왼쪽 끝+6유닛, 오른쪽 출현 중심은 오른쪽 끝−6유닛이다. 최대 17유닛까지 다가와 도착 쪽 끝과 원형 피해 영역 사이에 1유닛을 남긴다. 시계침 낙하 열은 3유닛 칸 10개다.
- 믹서기 영역 진입 시 즉시 7 또는 8 피해, 안에 머무르면 0.25초마다 피해. 대시 무적은 적용하지만 일반 피격 무적은 반복 피해를 막지 않는다. 밀려남·경직은 없다.
- 대시 중(0.2초 전체, 일반 대시 무적 0.15초보다 길다)에는 보스의 어떤 공격에도 피해를 받지 않는다. 지속 판정 패턴은 대시가 끝났을 때 아직 판정 안에 있으면 피해를 받을 수 있다. 사슬 긋기는 도착 순간에만 판정하므로 그 순간 대시로 피했다면 유지 중에는 다시 맞지 않는다(`ClockExecutionerBoss.DashSafe`). 제한시간 즉사는 예외다.
- 플레이어가 죽어도 죽는 것은 플레이어뿐이다. 보스는 진행 중인 공격·예고·낙하물을 거두고 그 자리에 매달린 채 보이며, 재시작·F5·체크포인트 복귀 때만 초기화된다(사용자 결정, `ClockExecutionerBoss.StandDown`).
- 2페이즈: 누적 HP 손실이 500 이상(HP 3,000 이하)이 되면 즉시 진행 중 공격·예고·낙하물을 거두고 전투를 멈춘 채 검은 띠 0.6초 → 포효 1.4초(입장 포효와 같은 부위별 흔들림, 착지 반동 없음) → 띠 퇴장 0.6초를 보여 준다. 그 뒤 1초 후 다음 패턴을 시작한다. 1페이즈는 기본 패턴을 조금 쉽게 한 것으로 사슬의 고정 1초 유지 구간을 제외한 모든 패턴(전조·공격·이동·회복·대기·믹서기 피해 간격)이 0.85배 속도로 진행되고, 2페이즈는 아래 시간표 그대로인 기본 속도(1배)다. 체력 바는 보라색이 된다(사용자 결정).
- 처치: 검은 띠가 들어오고 입력을 막은 채 붕괴 연출을 2.4초 보여 준 뒤 띠가 빠지면 다시 움직일 수 있다. 스케치 무기 런은 띠가 빠진 뒤 보스 무기 선택이 열리고, 그때까지 입력은 계속 막힌다(QA 2026-11-13). 붕괴가 이어지도록 전투 시간은 멈추지 않는다. 보스가 쓰러지면 방 입구 벽이 열려 걸어 나갈 수 있고, 방 안에 있는 동안 카메라 고정은 유지된다(사용자 결정).
- 현재 구현은 믹서기 기절 면역·다른 패턴 기절 시 취소이며 이미 예고된 시계침은 계속 진행한다. 목표는 [보스 기절 규칙](../../../design/combat/rules.md#보스의-기절-상태와-패턴)에 따라 기절 시간을 부여하되 패턴을 멈추거나 취소하지 않는 것이다. 새 규칙의 런타임 이행·검증은 미완료다.
- 최종 피격박스는 몸통·주먹만 포함하며 실제 새 이미지에 맞춰 검토해야 한다. 현재 몸통 피격박스는 그려진 시계 몸통을 덮도록 폭 5.7·높이 10유닛, 중심 바닥+5.3(바닥+0.3~10.3)이다. 지상 공격과 발밑 범위 잉크가 모두 닿는다. 믹서기 중에는 같은 상자가 믹서기 중심을 따라가는 폭 8.5유닛 임시 상자(바닥~원형 꼭대기인 바닥+12)로 바뀌어 지상 공격과 발밑 범위 잉크가 닿고, 끝나면 몸통 크기로 돌아온다. 작은 주먹 상자는 그림 주먹을 따라간다. 피해 영역은 원형과 구분한다.

## 시간 제한 없음과 UI

보스전에는 제한시간 시계·시간에 따른 광폭화·시간 초과 즉사가 없다. 화면에 남은 시간도 표시하지 않는다. 광폭화는 체력 기준으로만 전환한다.

- 최종 광폭: HP 360 이하에서 2페이즈와 같은 포효(전투를 멈춘 채 검은 띠 0.6초 → 포효 1.4초 → 띠 퇴장 0.6초, F로 건너뛰기)를 전조로 보여 주고 체력 바를 먹색으로 바꾼다(플레이 테스트 2026-11-04). 진행 중 패턴은 거두지 않고 포효 동안 멈춰 있다가, 포효 뒤 광폭화 속도의 1.2배(기본 대비 1.2배)로 전조·공격·이동·믹서기 피해 간격을 가속한다. 진행 중 패턴은 현재 진행 위치를 유지한 채 빨라진다. 공격 후 회복 2초와 다음 패턴 대기 2초를 모두 없애고 다음 무작위 패턴을 같은 전투 틱에 시작한다. 주먹 회수·믹서기 복귀·사슬 감김은 공격 동작에 포함하므로 유지한다. 꽂힌 사슬의 유지 시간은 기존대로 실제 전투 시간 1초다. HP가 한 번에 두 기준을 모두 넘으면 포효는 한 번만 재생하고 최종 속도·먹색 바로 이어진다. 재시작하면 HP 1,800과 일반 단계로 초기화한다.
- 이 체력 규칙은 1챕터 본 게임과 보스 시험방에 적용한다. 2챕터에서 재사용 중인 임시 보스의 별도 HP·기존 1/3 전환 규칙은 유지한다.

플레이어에게 보스 상태를 알린다(사용자 결정 2026-10-29).
- 플레이 GUI의 보스 체력 바는 위 페이즈 색(1페이즈 빨강, 2페이즈 보라, 최종 광폭 먹색)을 따른다. 랜덤 스테이지 보스방(치트 모드 보스방 이동 포함)과 보스 시험 상태(`clockBossTestOnly`) 모두 같은 막대를 쓴다. 보스방에서는 오른쪽 위 골드·가방·미니맵을 숨긴다.
- 입장(걸어 들어가기와 등장 포효)과 2페이즈 포효는 상호작용 키 F로 건너뛴다. 연출 중 오른쪽 아래에 「F 건너뛰기」를 표시한다. 건너뛰면 각 연출의 끝 상태로 간다. 입장은 바로 전투 시작이고, 2페이즈는 전투 재개다. 포효의 흔들림은 다시 재생하지 않는다.
- 처치 연출은 건너뛰지 않는다. 보스에게 지면 지금처럼 새 런으로 시작한다(리뷰 Q7).

길목에서는 카메라 오른쪽 끝을 보스방 입구 경계에 제한해 방 안이 미리 보이지 않게 한다. 입장 흐름은 방에 들어서면 카메라 고정(미끄러지듯 이동)과 함께 플레이어가 방 중앙까지 자동으로 달려가 멈춤(키보드 입력 무시, 이동은 시험 입력 축으로 주입, 보스 HUD 숨김) → 검은 띠 0.6초 → 보스가 위에서 떨어져 착지·먼지·화면 흔들림 0.5초 → 포효 1.3초(몸통·주먹·잉크·시계판·시침·사슬이 부위마다 조금씩 늦게 엇갈려 흔들리고 화면이 잘게 떨린다. 잉크 웅덩이 분출 효과는 쓰지 않는다) → 띠 퇴장 0.6초 → 전투 시작, 띠부터 합계 3초다. 띠는 카메라 화면 위아래에 붙은 월드 그림으로 그린다(IMGUI 사각형은 에디터 화면 배율에 따라 어긋났다). 전투 중과 처치 후에도 카메라를 고정한다. 최종 등장 클립 길이는 확정하지 않았다.

## 납품과 Unity 연결

1. 투명 PNG 시트와 개별 프레임, 부위가 분리된 편집 원본을 함께 전달한다.
2. 각 시트의 셀 크기·행열·프레임 번호·클립 시작/끝·루프 여부·pivot·PPU를 JSON 또는 같은 폴더 안내에 기록한다. FPS와 프레임 수는 아직 미정이며, 기존 이동형의 36프레임을 새 동작에 자동 적용하지 않는다.
3. 준비 완료 / 피해 시작 / 피해 종료 / 회수 완료 / 복귀 완료 / 사망 종료의 기준 프레임을 표시한다. 실제 피해 시점은 위 시간표에 맞춰 Unity가 제어한다.
4. 거대 팔은 좌우 시작점과 최대 길이, 믹서기는 중심 pivot을 고정한다. 잘라낸 프레임마다 정렬점이 바뀌지 않게 한다.
5. 일반(0.85배)·광폭화(1배)·최종 광폭(1.2배, 회복·대기 없음) 속도에서 실루엣·예고·피해 시점이 읽히는지 확인한다.
6. `Tools > Deviant > Chapter1 > Play Boss Test`는 시험방을 열고 바로 Play한다. 시험방의 `HP 1543 · 광폭화`, `HP 360 · 최종 광폭` 버튼은 해당 체력까지 피해를 주며, 현재 HP가 더 낮으면 회복시키지 않는다. `보스전 재시작`으로 처음부터 반복한다. 테스트방 `Assets/MeadowDuskV3/MapVer2/Scenes/ClockExecutionerTest.unity` 또는 `Tools > Deviant > Chapter1 > Open Boss Test`에서 연결한다. 검증 메뉴는 `Verify Boss Combat`이다. 일반 랜덤 스테이지 보스방도 같은 고정형 보스를 쓴다(`ClockExecutionerEncounter`, `Chapter1BossEncounter`는 출구·클리어만 담당). 시험방과 달리 체력·보정 수치·재시작 버튼은 숨긴다. 에디터 또는 치트 모드를 포함한 빌드에서 본 게임(랜덤 스테이지)을 플레이하는 중에는 치트 모드의 보스방 이동으로 현재 런의 보스방 안 왼쪽 바닥에 즉시 이동한다. 씬을 다시 불러오거나 보스 시험 상태로 바꾸지 않으며 시드·장비·체력·적 상태를 유지한다. 기존 입장 연출은 방 진입에 따라 이어진다. 일반 배포 빌드의 메뉴 포함 여부는 별도 빌드 옵션으로 선택한다(`DebugGameMenu`, `Chapter1DebugTravel`). 보스 기본 그림 `Resources/ClockExecutioner/Base.png`는 승인본 `resources/authoring/workbench/source/MonsterReference/approved/05_clock-executioner/base/base.png`의 사본이다.

## 허수아비 전투 시험장

`Tools > Deviant > Chapter1 > Open Dummy Training`은 메인 랜덤 테스트 씬을 직접 열고 Play 모드에서 보스방에 훈련 배치만 추가한다. 별도 씬 사본을 저장하지 않으므로 메인 씬의 오브젝트·설정과 공통 전투 데이터 변경을 다음 실행부터 함께 사용한다. 기존 보스전·`Verify Boss Combat`과 구분한다. 양쪽 발판 상면은 바닥 +4unit, 폭 5unit이며 각 중앙에 허수아비 1마리, 바닥 왼쪽 x=4에 1마리·오른쪽 x=16/17/18에 3마리를 배치한다. 단일 표적과 3마리 그룹의 첫 표적 사이 간격은 12unit이며 그룹 내부는 중심 간 1unit 간격이다. 폭과 간격은 이 시험장의 배치값이다. 허수아비는 HP 1,000, 고정 위치, 공격·몸 충돌 없음이며 실제 공통 전투의 피격 영역을 사용한다.

각 표적은 공통 accepted-hit 기록의 실제 HP 손실을 독립적으로 집계한다. 과잉 피해와 보호막 흡수는 누적하지 않는다. 첫 양수 피해부터 마지막 양수 피해 +2초까지를 분모로 DPS를 계산하고 결과를 고정한다. 그 뒤 새 피해가 오면 새 구간을 시작한다. 전투 정지 중 측정 시각도 정지한다. HP 0에서 자동 회복하지 않는다. F5는 발 위치의 2D 거리가 가장 가까운 허수아비 하나만 HP·상태·측정을 초기화하며, 다른 적·진행·무기 쿨타임·전투 시각은 리셋하지 않는다. 이미 생성된 공격 효과는 유지된다.

F1은 전투·입력을 정지하고 두 무기의 공통 카탈로그 형태·특수 변환과 능력치 잉크 5칸을 편집한다. 실제 변경은 기존 장비 재설정 경로를 사용한다. 색상 파츠 60종 중 **59종**을 실제 공통 장비의 무기별 독립 시험 팔레트에 연결한다. **강철 주입은 보류**하며 장착을 거부한다. 자유 6칸·중복·수치는 실험 설정이고 제품 팔레트 획득·제작·가방 아이템 구현이 아니다. F1의 실제 장비 탭에서 별도 시험 차징 스탬프를 켜거나 끌 수 있다. 기존 특수 선택을 누르면 시험 스탬프를 끄고 기존 기술로 돌아간다. 완충 유지·해제 발동·조기 해제/대시 취소·무기별 저장 게이지는 같은 공통 전투를 사용하며 상태 UI에 실제 게이지를 표시한다. 원본 `data/combat/ink_parts_proposal.json`에서 `python tools/combat/export_training_parts.py`로 표시 메타데이터와 공통 전투 DTO를 함께 생성한다. `--check`로 원본 일치를 검사한다.

메인 씬의 현재 마을 스케치 지형·배경과 카메라 출력을 사용한다. 훈련 중에는 보스·일반 몬스터·진행 보상·포탈/전용 벽 이동 연출을 추가하지 않는다. 공통 이동·점프·벽점프와 무기 실행 규칙은 그대로 사용한다. 표적 UI는 운영체제 동적 한글 폰트와 작은 글씨를 사용하며 원시 시스템 TTF를 프로젝트에 새로 가져오지 않는다. Open Random Stage 또는 Open Boss Test를 선택하면 훈련 선택이 해제된다.

상태의 최소 월드 표시는 공통 `CombatArena`의 `InkStatusVisuals`가 관측한다. 플레이어의 실제 보호막에는 반투명 민트색 캡슐, 빙결에는 옅은 파랑 얼음 외곽, 표식에는 머리 위 보라 룬(개수만큼, 최대 6), 냉기 축적에는 작은 눈꽃(최대 4)을 표시한다. 둔화는 발밑 파란 링, 속박은 링과 사슬, 화상은 작은 주황 불꽃, 다음 피격 감소는 머리 위 금색 문양으로 구분한다. 기존 캐릭터·적 Sprite의 색이나 충돌을 변경하지 않는다. 표식이나 냉기 축적이 있는 허수아비의 카드는 위로 옮겨 아이콘과 겹치지 않게 한다.

표시는 공통 전투 상태의 읽기 전용 스냅샷을 사용하며 일반 적과 허수아비가 같은 경로를 따른다. 애니메이션 위상은 전투 시각을 사용하므로 F1 정지 중에도 흐르지 않는다. 실제 소모·만료·사망·F5 생명 초기화에 따라 숨기고, 아레나 비활성/종료 시 표시 오브젝트·생성 Sprite·텍스처·재질을 정리한다. `ShowInkStatusVisuals`는 표시 비교용이며 전투 계산을 변경하지 않는다. 현재 표시는 외부 이미지 파일이 필요 없는 최소 기술용 형태이며 최종 파츠 아트와 구분한다.

회귀 검사는 `ForestCombatV2.Tests.DummyTrainingTests`다. 실제 씬·발판 높이·표적 6개·공통 피해 관측·측정 종료·가장 가까운 하나만 회복·장비의 독립 적용과 잘못된 선택의 복구를 검사한다. 실행 여부와 결과는 실제 Unity 테스트 출력으로 판단한다.

제작 순서 제안: 분리 대기 원본 → 사슬 주먹 퇴장·거대 팔 → 믹서기 → 시계침 소환·낙하 → 등장·복귀 → 사망 효과. 구체적인 사망 방식, 신규 시트 셀 크기·프레임 수, 예고 효과 아트는 별도 확정 대상이다. 현재 보스 체력은 1,800이다.

훈련장의 F2는 공통 히트박스 렌더러를 켜고 끈다. 하단에는 기존 공통 상태 UI로 현재 무기·두 무기의 특수 기술명·남은 쿨타임/충전 및 플레이어 HP를 표시한다. 위쪽 시험장 안내와 하단 상태 UI가 겹치지 않도록 메시지 영역을 분리한다.
