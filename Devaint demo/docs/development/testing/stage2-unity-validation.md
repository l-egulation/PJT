# 2스테이지 일반5종 Unity 적용·검증

[분야 개요](README.md)

## 적용 위치와 재생 시간

Unity 6000.6.5f1의 Chapter2 본 게임 전투에 연결한다. 실행은 현재 저장소가 지정한 리소스 커밋과 배치 계약을 따른다.

| 몬스터 | 본체 공격 흐름 | 회복 뒤 대기 |
|---|---|---|
| 등짐분사수 | 전조650ms → 분사650ms → 회복700ms | 1200ms |
| 쐐기보행기 | 전조600ms → 돌진 최대500ms → 정지·끌기 해제 → 찍기 전조450ms → 판정150ms → 회복900ms | 1800ms |
| 먹침필경사 | 기존 3연타1590ms, 판정570–640/720–790/870–940ms | 900ms |
| 신호 투척수 | 발사까지650ms → 본체 회복700ms | 1400ms |
| 늘어진 수의 | 발사까지1600ms → 본체 회복900ms | 1800ms |

기존 PNG와 FX를 그대로 참조한다. 프레임 표시 시간만 재배분하고 M3의 제외하기로 한 4타 프레임을 카탈로그에서 제외한다. 이미지 생성·재디자인·새 시트 출력은 없다. 픽셀32당1u,512×384 및 기존 피벗을 유지한다.

`tools/combat/export_chapter2_approved_normals.py`가 `data/combat/stage2_*.json`을 읽어 `Chapter2ApprovedNormals.json`, 재생 카탈로그, 원본 해시가 있는 `chapter2_approved_motion_bindings.json`을 만든다. 기존 `export_chapter2_normal_attacks.py` 진입점도 이 확정 수출기로 연결했다. 각 명령의 `--check`로 재생성 일치를 검사한다.

## 전투 연결

- `Chapter2NormalEnemy`: 체력·이동·진입 대기·거리/높이/화면 조건·프레임 시간과 판정·재공격 대기. 확정 피격박스는 좌우 반전하며 별도 이동 충돌체는 기존 크기를 유지한다.
- `Chapter2NormalOrdnance`: 방 단위 투사체·장판 소유권. 본체 회복과 분리하고 목표 바닥만 충돌하며 벽·천장·다른 바닥을 통과한다. H3 사망 시 정리하고 R 발사탄은 사망 후에도 유지한다.
- 신호투척수·늘어진 수의는 `minimumFlightSeconds=0.9`를 조준 궤도 계산에 전달한다. 탄심 목표 도달 시간을 늘리면서 정점 높이와 목표 위치를 유지하고, 근거리는 가로 속도를 줄인다. 원거리 최대 가로 속도는 6u/s다.
- K4/M3의 매타0.15u/0.08초 밀림과 전용 이동 경직은 공통 피격 접수 이후 적용한다. B3 찍기의 공통 박스 밖 밀림은 확정 찍기 박스로 계산한다.
- 공통 `CombatActor`는 기본값이 유지되는 취소 opt-in을 제공한다. H3만 비치명 피격 중 공격 시계를 유지한다. 챕터1 적의 기본 취소 정책은 유지한다.
- 방 경계 전환·리셋은 독립 효과까지 정리한다. 단순 화면 이탈은 이미 발사한 탄을 정리하지 않는다.

## 재현

`pwsh -NoProfile -File tools/combat/verify_chapter2_projectile_arc.ps1`은 실제 `C2Arc`를 지정 Unity 버전의 Vector2/Mathf에 연결해 근·원거리, 목표 높이, 정점, 수직 투척, 잘못된 최소 시간과 기존 호출 호환성을 수치 검사한다. 씬·피격·지면 충돌 검사는 아니다.

Unity Test Runner EditMode의 `Deviant.Chapter2.Tests.Chapter2ApprovedNormalTests`를 실행한다. 실제 Chapter2 씬에서 5종 actor를 사용하며, 정량 비교 구간은 같은 씬 안에 임시 평지를 만들어 지형 변수와 분리한다. 프로덕션 씬·지형 에셋은 변경하지 않는다. 실제 지형·피격 자세 회귀는 기존 Chapter2 테스트와 함께 검사한다.

테스트 결과·캡처는 저장소 루트의 `outputs/approved-normal-tests.xml`, `outputs/approved-normal-tests/`에 남긴다. 실행 결과와 캡처는 커밋 대상에 포함하지 않는다.

## 구현의 경계

남은 기획은 `stage2-monster-pending.md`를 따른다. 연결된 같은 높이 바닥 구간을 이동 영역으로 사용하며 동적 바닥 추종을 새 규칙으로 확정하지 않는다. 장판은 현재 `[생성, 생성+4초)`에서만 틱을 허용한다. 최소거리 미확정 항목·스폰 조합·엘리트와 보스는 이번 일반5종 확정으로 확대하지 않는다.

## 벽 이동 검사

분할 지형의 개별 사각형 경계는 다른 사각형 안에 묻혀 있을 수 있다. `Chapter2Tests`는 본체와 오르기·첫 점프 높이를 포함한 통로가 실제로 비어 있는 벽면을 선택한다. 모든 레이아웃에서 선택 조건을 검사하고, 실제 씬의 양쪽 벽에서 시작·점프 뒤 비관통과 실제 이탈을 확인한다.

Chapter1의 연속 입력·버퍼 검사는 임시 연속 벽 지형에서 수행한다. 문·착지대가 있는 실제 통로의 오르기·내려오기와 입구 이동은 별도 실제 맵 검사에서 유지한다. 프로필 저장소를 대체하는 테스트는 씬 종료와 OnDestroy 저장이 끝난 뒤 기본 저장소로 복원한다.
