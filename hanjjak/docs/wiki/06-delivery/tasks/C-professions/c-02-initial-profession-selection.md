# C-02 최초 주력 재료 선택 규칙·화면 정의

> 작업 상태와 완료 증거의 SSOT. 도메인 규칙은 [주력 재료](../../../../30-domain/character/ssot.md)를 따른다.

## 완료 기준

최초 로그인 직후 선택, 선택 전 게임 진행 차단, 세 선택지·80:10:10 비율·변경 불가 안내가 확정된다.

## 선행 작업

C-01

## 비고

confirmed 요구사항에 따라 선택 시점·진입 차단·세 선택지·비율·변경 불가 안내가 확정됐다. 웹에서는 주방 배경과 종이 카드 기반 선택 화면, 서버 응답 비율 표시, 선택 전 확인 단계, 처리 중 중복 클릭 차단, 오류 안내를 구현했다. 2026-09-07 실제 game-api 브라우저 흐름에서 신규 계정이 선택 화면을 먼저 보고, 재료를 다시 고른 뒤 확정할 수 있으며, 성공 후 메인 화면으로 이동하고 새로고침 시 선택 화면을 건너뛰는 것을 확인했다.

- 2026-09-08 시각 자산 적용: 투명 한지 보드·재료 카드·확인 패널·주/보조 버튼·선택 인장을 `apps/web/src/features/material-preference/assets/*-v2.png`로 추가하고 기존 감자·고구마·옥수수 바구니와 조합했다. 서버 응답 비율과 선택·재선택·확정 동작은 유지했다.
- 2026-09-08 검증: 데스크톱과 390×844 축소 배치에서 세 카드가 보드 안에 표시되고, 카드 선택 시 인장·확인 버튼이 나타나며 `다시 선택`으로 초기화되는 것을 확인했다. 브라우저 콘솔 오류가 없었고 `typecheck`, `test`(8개 파일·22개), `build`가 통과했다.
- 2026-09-08 사용자 시각 검토 보정: 메인 제목과 카드 제목을 프레임 안쪽으로 내리고, 카드 폭을 넓혔다. 재료 이미지는 카드 안에서 소폭 축소했으며 비율 문구의 좌우 여백을 늘리고 하단 확인 패널을 위로 올려 가장자리 밀집과 하단 쏠림을 보정했다.
- 2026-09-08 선택 상태 추가 보정: 양 끝 카드를 보드 안쪽으로 이동하고 메인·카드 제목을 더 내렸다. 보조 비율 행과 확인 패널은 위로 올렸으며, 선택 인장을 확대하고 선택되지 않은 카드는 명도를 낮춰 현재 선택을 색상 외 인장과 밝기 차이로 함께 구분한다.
- 2026-09-08 최종 간격 보정: 사용자 재검토에 따라 감자·옥수수 카드를 중앙으로 두 단계 더 이동하고 메인 제목을 추가로 내렸다. 카드와 부제목 간격은 유지했으며, 카드 하단을 가리지 않도록 카드 묶음을 소폭 위로 이동하면서 확인 패널의 높이와 하단 여백을 함께 조절해 패널 중심을 위로 올렸다.
- 2026-09-08 국가 선택 표현 적용: 서버의 감자·고구마·옥수수 선택값, 영구 저장과 80:10:10 규칙은 변경하지 않고 첫 진입 UI만 `감자의 나라`·`고구마의 나라`·`옥수수의 나라` 중 시작 국가를 고르는 표현으로 바꿨다. 각 카드에는 국가의 대표 재료와 서버 응답 획득 비율을 함께 표시한다.
- 2026-09-08 국가 선택 UI 검증: 브라우저에서 로그인 → 세 국가 카드 표시 → 고구마의 나라 선택 → 인장·비선택 카드 어둡게 표시 → 확인 문구 → 다시 선택을 확인했다. `typecheck`, `test`(9개 파일·25개), `build`가 통과했다.
- 2026-09-08 국가 풍경 자산 적용: 기존 감자·고구마·옥수수 바구니 그림을 각 재료의 경작지와 건축물로 구성한 투명 배경 국가 풍경(`potato-country-v1.png`, `sweet-potato-country-v1.png`, `corn-country-v1.png`)으로 교체했다. 브라우저에서 세 풍경이 카드 안에 잘림 없이 표시되고, 고구마의 나라 선택 시 선택 인장·비선택 카드 어둡게 처리·확정 후 메인 진입이 유지되는 것을 확인했다. `typecheck`, `test`(9개 파일·25개), `build`가 통과했다.
- 2026-09-08 국가 선택 구성 분리: 국가 이름을 `감자 나라`·`고구마 나라`·`옥수수 나라`로 다듬고, 큰 세로 카드 프레임 안에 묶였던 이름·풍경·재료 정보를 각각 이름 명패, 프레임 없는 국가 풍경, 별도 정보 명패로 분리했다. 선택 영역과 인장·비선택 명도 효과는 세 요소 전체에 유지했다. 브라우저에서 감자 나라 선택 상태를 확인했고 `typecheck`, `test`(9개 파일·25개), `build`가 통과했다.
- 2026-09-08 분리 구성 간격 보정: 국가 이름 명패와 풍경 사이에 독립된 여백을 만들고, 대표 재료·획득 비율 정보 명패의 세로 높이와 두 행 사이 간격을 확대했다. 옥수수 나라 선택 상태에서 인장, 명패, 풍경과 하단 확인 영역이 겹치지 않는 것을 브라우저로 확인했다.
- 2026-09-08 픽셀 재료 아이콘 적용: 국가 선택 묶음을 아래로 이동하고 이름 명패와 하단 확인 패널의 세로 높이를 확대했다. 정보 명패의 대표 재료 텍스트값은 192×192 투명 픽셀 스프라이트 감자·고구마·옥수수 이미지로 교체했으며, 좌측 항목 글자 크기를 키웠다. 브라우저에서 옥수수 나라 선택 배치를 확인했고 `typecheck`, `test`(9개 파일·25개), `build`가 통과했다.
- 2026-09-08 정보 명패 가독성 보정: 세로형 재료 아이콘이 행 배치를 밀지 않도록 명패 오른쪽에 고정하고, 정보 명패를 확대해 아래로 이동했다. 좌측 항목 글자는 추가 확대하고 국가 풍경은 소폭 축소해 이름·풍경·정보 사이 여백을 확보했다.
- 2026-09-08 명패 위치 미세 보정: 획득 비율 문구를 소폭 확대해 아래로 정렬하고, 정보 명패와 국가 이름 명패를 각각 아래로 이동했다. 브라우저에서 세 국가의 명패·풍경·확인 패널 사이 간격을 확인했다.
- 2026-09-08 전체 수직 배치 보정: 메인 제목과 세 국가 선택 묶음을 아래로 이동하고, 정보 명패는 풍경에서 추가로 내렸다. 하단 확인 패널도 함께 내려 선택 묶음과의 간격을 유지했다.
- 2026-09-08 확인 패널 가독성 보정: 정보 명패와 하단 확인 패널 사이 간격을 줄이고 확인 질문·변경 불가 안내의 글자 크기를 확대했다. `다시 선택`과 `확정하기` 버튼의 폭·높이·글자 크기도 함께 키웠다.
- 2026-09-08 확인 패널 최종 보정: 확인 패널을 소폭 위로 이동하고 왼쪽 문구를 패널 내부 위쪽에 맞췄다. 두 동작 버튼은 폭·높이·글자 크기를 추가 확대하고 브라우저에서 장식 영역 내부 표시를 확인했다.
- 2026-09-08 제목·선택 묶음 간격 보정: 세 국가 선택 묶음을 소폭 위로 이동하고, 메인 제목 밑줄과 설명 문구 사이의 위쪽 여백을 늘렸다.
- 2026-09-08 재료 마을 풍경 v2 적용: 작은 카드에서도 국가 정체성이 남도록 원경의 일반 성·경작지 풍경을 근접 구도의 재료 건축 마을로 교체했다. 감자는 감자 껍질 지붕과 싹 굴뚝, 고구마는 고구마 형태의 보라색 집과 덩굴 다리, 옥수수는 알갱이 탑과 알갱이 길로 표현했다. 브라우저에서 감자·옥수수 선택 상태의 색상과 실루엣을 확인했다.
- 2026-09-08 빈티지 주방 UI 재구성: 기존 국가 풍경 v2와 서버 선택 로직은 유지하고 금장 보드·국가별 이름 및 정보 명패를 제거했다. 전용 타일 벽·나무 조리대 배경 위에 세 국가를 직접 배치하고, 재료와 획득 비율은 하나의 공용 정보 띠로 합쳤다. 선택 상태는 평면 붉은 도장과 비선택 명도 차이로 표시하며 하단 확인 영역은 한 장의 얇은 종이로 축소했다. 1088×731 브라우저에서 감자 나라 선택, 재선택·확정 버튼 표시와 요소 간 비겹침을 확인했고 `typecheck`, `test`(9개 파일·25개), `build`가 통과했다.
- 2026-09-08 정보·확인 영역 통합 보정: 국가 풍경이 정보 문구를 덮지 않도록 공용 정보 띠를 불투명한 최상위 레이어로 고정했다. 선택 후 확인 영역도 같은 종이 색·상하선·폭을 사용하고 정보 띠 바로 아래로 붙여 두 영역이 하나의 하단 제어부로 보이게 조정했다.
- 2026-09-08 제목 도장 자산 교체: 국가 선택 제목 왼쪽의 CSS 임시 선 아이콘을 인증 화면과 같은 실제 그릇 도장 PNG로 교체하고 제목 여백과 도장 크기를 조정했다. 미선택 검토 계정으로 화면에 재진입해 배치와 표시를 확인했다.
- 2026-09-08 획득 비율 표시·최종 확인 보정: 세 국가 아래의 불투명 정보 상자와 칸 구분선을 제거하고 배경을 완전히 투명하게 바꿨다. `대표 재료`·`획득 비율` 라벨 대신 픽셀 재료 아이콘과 확대된 80:10:10 퍼센트만 국가별 중앙에 표시한다. 제목 아래 중복 안내는 제거하고 선택 후 안내 문구를 확대했다. 하단 `확정하기`는 서버 요청을 즉시 보내지 않으며 중앙 확인 모달의 `이 나라로 확정`을 눌러야 선택 API를 호출한다. 브라우저에서 고구마 선택, 모달 열기와 취소를 확인했고 최종 확정 요청은 검토 계정에 보내지 않았다.
- 2026-09-08 비율 강조 보정: 세 국가의 재료 아이콘과 퍼센트를 추가 확대하고, 각 나라의 주력 80% 항목은 보조 10%보다 아이콘과 숫자를 한 단계 크게 표시했다. 브라우저에서 세 비율 묶음이 각 국가 아래 중앙에 유지되고 서로 겹치지 않는 것을 확인했다.
- 2026-09-08 비율 순서 보정: 모든 국가에서 재료를 감자·고구마·옥수수 순으로 표시하고, 국가별 주력 재료의 수치만 80%로 바뀌도록 정리했다. 크기 강조는 실제 주력 재료 항목을 따라간다.
