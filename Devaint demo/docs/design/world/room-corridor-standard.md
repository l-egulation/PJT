# 방·통로 공통 규격

[분야 개요](README.md)

1·2챕터의 방과 통로가 따르는 연결 규격이다. 방 원형 데이터는 `data/map/block_rooms.json`, 구현·검증 방법은 [블록 맵 개발 문서](../../development/gameplay/world/block-map.md)를 따른다. 수치는 [이동 수치](../../../data/combat/locomotion/player.json)(1단 점프 3u, 2단 점프 6u, 몸 0.9375×2u, 벽 오르기 7.5u/면)에 근거한다.

## 격자와 소유

- 1칸 = 1u = 32px. 고체와 일방향 발판 윗면은 모두 정수 칸이다. 일방향 발판 충돌 두께는 1챕터 0.125u, 2챕터 0.5u다.
- 방과 통로는 16×12u **블록** 위에 놓는다. 방은 2×1·2×2·3×2·2×3 블록이고 통로 블록은 1×1이다. 예외: 보스방 앞 긴 통로는 3×1 블록이다.
- 방은 테두리(벽·천장·바닥)를 스스로 가진다. 천장·바닥은 2칸, 좌우 벽은 3칸이다(사용자 요청 2026-11-06, 좌우 직결 문 길이 4→6칸). 예외: 보스방은 좌우 1칸이며 안쪽 폭이 카메라 한 화면인 30u다. 1챕터 정비소는 좌우 5칸이다(안쪽 38칸).
- 스테이지는 하나의 셀 격자와 일방향 발판 목록으로 조립한다. 충돌·타일·지도가 같은 셀에서 나온다. 각 셀은 방 하나 또는 통로 블록 하나만 소유하며, 방과 통로 블록 밖은 고체다.
- 모든 고체는 두께 2칸 이상이다. 같은 칸에 일방향 발판을 겹쳐 두지 않는다. 겹치는 일방향 발판의 세로 간격은 3칸 이상이다.

## 출입구

| 슬롯 | 위치 | 열림 | 닫힘 |
|---|---|---|---|
| 좌우 `L0..`, `R0..` | 블록 행 n의 바닥선. 문턱 = 12n+2(방 기준), 높이 6 | 테두리를 판다. 안쪽 4×6 접근 영역은 비운다. 위층 문은 벽에 붙은 4×2 선반을 둔다 | 테두리 실벽 |
| 아래 `B0..` | 블록 열 가운데 6칸 | 바닥 높이에 폭 6 일방향 문 바닥 발판, 그 2칸 아래(바닥 테두리 아래끝) 문턱 디딤 | 바닥 실벽 |
| 위 `T0..` | 블록 열 가운데 6칸 | 천장 3칸 아래 폭 6 접근 발판 | 천장 실벽. 이 출입구 전용 발판도 뺀다 |

- 모든 일반방은 상·하·좌·우 방향마다 슬롯을 하나 이상 가진다. 선언한 슬롯의 모든 활성 조합과 좌우반전에서 활성 출입구 사이를 왕복할 수 있어야 한다.
- 좌우반전은 원형 폭 기준으로 지형·적·슬롯을 함께 뒤집는다(L↔R, 열 c ↔ 블록 수−1−c). 슬롯이 블록 가운데·바닥선에 있으므로 반전해도 격자 위에 남는다.

## 연결

| 연결 | 형태 | 이동 |
|---|---|---|
| 수평 직결 | 두 방이 맞닿고 같은 블록 행 슬롯 | 문 사이 6u 터널(좌우 벽 3+3), 바닥 평탄. 보스방 쪽은 4u, 1챕터 정비소 쪽은 8u |
| 수직 직결 | 위아래로 맞닿고 같은 블록 열 슬롯 | 아래 방 접근 발판 → 위 방 문턱 디딤(위 방 바닥 테두리 아래끝) 5u는 2단 점프 → 문 바닥 2u는 1단 점프 |
| 보스 앞 긴 통로 | 1·2챕터 주 경로 마지막 방 → 보스방, 항상 | 가로 3블록(48u) 평탄 통로, 좌우만 열림, 적 없음. 앞 방 벽 3 + 48 + 보스방 벽 1 = 52u가 한 화면(약 30u)을 넘어 이어진다(사용자 요청 2026-11-11). 1챕터는 승인 시계탑 길목 배경, 2챕터는 임시 시안 배경(재설계 예정, [2챕터 런타임](../../development/gameplay/world/chapter2-runtime.md#지하수로-미술)) |
| 통로 블록 | 방 사이에 블록 하나 | 수평 16u, 굴곡·T자(세로는 바닥 2 → 디딤 4 → 디딤 8 → 위 방 문턱 디딤 12 → 위 방 바닥 14로 2·4·4·2u. 첫 디딤 위로 몸 2u와 여유 2u가 있어 디딤에서 옆으로 대시해도 벽 모서리에 걸리지 않는다, 사용자 요청 2026-11-06) |
| 벽타기 통로 | 위·아래만 열린 블록 하나 | 문 바닥에서 착지 발판까지 8u를 벽 한 면으로 오른다(점프 3 + 벽 오르기 7.5, 여유 2.5). 착지 발판에서 위 방 바닥까지 4u는 2단 점프. 벽차기 반복은 요구하지 않는다 |

- 짧은 직결을 우선한다. 통로 블록은 연결 하나에 하나까지이며 이어 붙이지 않는다. 보스 앞 긴 통로만 예외다. 연결할 수 없는 배치는 통로를 늘리지 않고 방 위치·원형·반전을 바꾼다.
- 벽타기 통로는 1챕터 갈래에 0~1개, 2챕터에 1~3개(주 경로 1개 이상)다(사용자 결정 2026-11-05).
- 1단 점프 최고 높이는 정확히 3.0u, 2단은 6.0u다(locomotion: 초속 20, 상승 중력 66.7). 그래서 3u·6u 계단은 될 듯 말 듯 닿지 않으므로 두지 않는다. 점프로 오르는 계단은 1단이면 2u 이하, 2단이면 4~5u다(사용자 요청 2026-11-06). 판정기(tools/map/movecheck.js의 strictRise)가 이 계단만으로 길이 이어지는지 검사한다.
- 방 안 디딤면 상승은 4u 권장·5u 상한, 같은 높이 간격은 4u 권장·6u 상한이다. 대시가 필요한 간격은 필수 경로에 두지 않는다.

## 적 배치

- 적은 고체 또는 방 고유 일방향 발판 위에 서고, 출입구 발판(문 바닥·접근 발판·디딤) 위에는 두지 않는다.
- 연속 바닥 폭: 가시뿌리 4, 먹빗자루 5, 포수 4, 포격수 3, 돌진꾼 10(2챕터 8), 엘리트 8.
- 좌우 출입구 안쪽 면에서 8u·문턱 ±4u 안, 상하 출입구 발판 ±4u 안에는 두지 않는다. 원거리 적이 문턱과 같은 높이면 12u 이상 떨어뜨린다. 이 금지 구역은 활성 여부와 관계없이 선언한 모든 슬롯에 적용한다.
- 2챕터 일반 적의 이동 영역은 열린 좌우 출입구의 접근 구역(방의 좌우 벽 + 접근 4)을 스폰 반대쪽으로 잘라 낸다.

## 스테이지 구성

- 1챕터: 왼쪽 시작방에서 오른쪽 끝 보스방으로 가는 가로 진행. 구조는 [런 구조](../run/run-structure.md)를 따른다.
- 2챕터: 맨 위 시작방에서 아래로 120~144u 내려갔다가 옆으로 한 방을 지나 다시 올라와 위쪽 보스방에 닿는 세로 진행. 주 경로 9방 + 순환 갈래 2방(전투방·잠긴 상자방) + 막다른 정비소·봉인 도전방 + 엘리트 갈래. 어떤 방도 시작방보다 높지 않다. 주 경로 문→문 이동의 세로/가로 비는 2 이상이다. 상세는 [2챕터 방과 연결](chapters/chapter2-layout.md)을 따른다.

## 미정·확인 대상

- 2챕터 일반방 적 수 6~10은 시험값이며 플레이 후 조정한다.
- 1챕터 일반 적의 대기 배회는 스폰 위치 기준이며 방 경계로 가두지 않는다. 금지 구역(8u)이 배회 반경보다 넓어 출입구에 머무르지 않는 것은 플레이로 확인한다.
- 큰 방의 세로 스크롤, 진입 시점 화면의 적 가독성, 접합부 타일 표현은 Unity 화면으로 확인한다.
