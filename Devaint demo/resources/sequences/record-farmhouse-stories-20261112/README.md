# 기록 농가 이야기 컷씬

사용자가 제공하고 선택한 이야기 1·2·3 컷씬과 HTML 검토 화면.

- 원본 ZIP은 source/에 바이트 그대로 보존한다.
- 이야기 1은 원본 07을 제외한 8장, 이야기 2는 8장이다.
- runtime/ PNG는 원본 frames(960×540) 또는 첫 artwork(960×420)의 바이트를 그대로 사용한다.
- 본문·해금·읽음·순서의 게임 기준은 소비자 data/story/record_stories.json이다.
- Unity에서는 별도 등장/흡수 효과 없이 페이지 페이드만 사용한다.
- preview/index.html은 사용자 검토용이며 Unity의 저장 진행과 연결하지 않는다.

이야기 3은 사용자 제공 긴팔 로브·붉은 잉크 v3의 원본 01·03·04·05·06·07·10을 사용한다. 02·08·09는 중복 흐름을 줄이기 위해 재생에서 제외하고 source/story3-v3의 10장과 원본 ZIP에는 보존한다. 본문은 소비자 데이터에서 수정할 검토 초안이다.
