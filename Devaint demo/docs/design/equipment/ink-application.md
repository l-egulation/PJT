# 런 도감과 무기별 잉크 적용

[장비 기획](rules.md) · [무기 획득 후 사용하기까지](sketch-weapons.md#무기-획득-후-사용하기까지)

## 도감에서 무기에 적용

**잉크에는 레벨이 없다.** 일반 처치 보상에서 잉크를 고르거나 상점에서 구매하면 런 도감에 등록한다. 획득마다 같은 종류의 부여 횟수가 기본 10회씩 늘어나며 이후에도 다시 획득할 수 있다. 같은 잉크라도 무색 슬롯이나 다른 색의 강화 슬롯에서는 기본 수치, 같은 색의 강화 슬롯에서는 강화 수치를 사용한다. 예를 들어 빨강 잉크 하나를 검의 무색 칸과 망치의 빨강 강화 칸에 부여하면, 검에서는 기본 수치가, 망치에서는 강화 수치가 적용된다. 도감에는 빨강 잉크 한 종류로 남는다. [기본·강화 수치와 런 도감](inks/rules.md)

일반·상점·이벤트·튜토리얼 등 실제 잉크 지급 경로는 획득당 10회를 더한다. 기존 잔여 횟수를 일괄 배증하지 않는다. 보상 후보 자격은 [보상 규칙](../run/rewards.md)을 따르며 상점은 보유 여부와 관계없이 해금한 종류를 제공한다.

최초 무기 구성 확정에는 골드 비용이 없다. 감소 항목이 있는 경우에만 잉크 설명과 장착 시 보이는 무기 효과창에 해당 스탯을 음수로 표시한다. 이를 위한 별도 경고창이나 추가 확인은 없다.

**잉크 배치를 확정해야 무기가 활성화되며, 확정 시 빈 슬롯을 포함한 전체 구성이 고정된다.** 슬롯을 전부 채울 필요는 없지만 확정 후에는 빈 슬롯 추가·기존 잉크 교체·해제·이동을 할 수 없다. 전투 중 인벤토리를 열어도 확정한 무기를 수정할 수 없다. 구성은 무기가 파괴될 때까지 유지한다. 가방 보관·재장착으로 편집 권한을 되돌리지 않는다. 최초 확정 전 임시 배치는 [스케치 무기](sketch-weapons.md#무기-획득-후-사용하기까지)를 따른다.

잉크의 **내구도는 남은 부여 횟수**를 뜻한다. 전투 중 효과 발동이나 무기 교대마다 줄어드는 값이 아니다. 같은 무기의 여러 칸과 다른 무기에 중복 부여할 수 있지만 **채운 슬롯 하나마다 1회**가 필요하다.

- 확정 전 임시 배치는 각 슬롯이 1회를 **예약**한다. 모든 미확정 무기의 예약을 합산해, 남은 횟수를 넘는 배치는 거부한다. 같은 칸에 같은 잉크를 다시 선택해도 추가 예약하지 않는다.
- 임시 잉크 제거·교체·미확정 무기 버리기는 기존 예약을 해제한다. 가방을 닫아도 임시 구성과 예약은 유지한다.
- 무기 구성을 확정하면 그 무기의 예약분을 실제 소비하고 전체 슬롯을 고정한다. 다른 미확정 무기의 예약은 유지한다. 확정 후 무기 보관·재장착·버리기·파괴로 횟수를 돌려주지 않는다.
- 잔여 0회인 잉크는 부여 목록에서 숨긴다. 마지막 횟수로 이미 부여한 잉크는 계속 작동하며 무기 파괴 시 기존 효과 수명 규칙을 따른다. 재획득하면 기본 10회를 더하고 목록에 다시 표시한다.

예를 들어 잔여 10회에 A 무기의 두 칸과 B 무기의 한 칸을 임시 배치하면 예약 3회·추가 부여 가능 7회다. A를 확정하면 잔여 8회·예약 1회·추가 부여 가능 7회가 된다. 같은 종류를 다시 얻으면 잔여는 18회로 늘어난다. 중복 장착본 효과는 개별 잉크 효과 명세를 따른다.

## 무기 적용 전 조건 안내

현재 빨강·파랑 잉크는 공격 대상의 상태 조건으로 발동하며 자원 소모나 플레이어 페널티가 없다. 적용 조건은 [색별 효과](inks/effects.md#빨강파랑의-공통-상태-조건)를 따른다.

## 장착본별 발동과 새 무기 상태

동일 잉크 중복본의 쿨타임은 장착본별로 독립 관리하며 준비된 장착본 모두 발동할 수 있다. 각 장착본은 공격 실행당 최대 1회 발동한다. 빨강·파랑의 증가율과 쿨감은 장착본별로 합산하고, 상태이상과 자원 상한은 [효과 규칙](inks/effects.md)을 따른다.

새 무기의 최초 구성을 확정할 때 장착 잉크의 내부 쿨타임은 준비 상태로 시작한다. 기존 무기의 교대·재장착으로 쿨타임을 초기화하지 않는다. 장착한 두 무기 사이에서는 비활성 무기의 잉크 쿨타임도 계속 진행한다. 가방에 보관한 무기의 잉크 내부 쿨타임은 남은 시간을 정지하고, 재장착하면 남은 시간부터 진행한다. 가방 보관 중 **스킬** 쿨타임 정지는 [장착 규칙](weapons/rules.md)을 따른다.
