# 젖은 타격 3번 발전안 — 전체 반려

기존 ink-hit-audition의 3번 WAV 바이트를 기준으로 음량을 낮추고 음높이·저음·고역을 조절한 후보 5개다. 새 타격 레이어나 금속·나무 소리를 추가하지 않는다. 원본과 후보의 상대 음량을 유지하며 미확정, 게임 미적용 상태다.

preview/index.html에서 원본 3번과 A/B, 무기 기본공격·스킬 모션 혼합, 여러 마리 타격, 별표 및 선택 파일 저장을 지원한다. 기준 버튼은 무기와 무관하게 원본 3번으로 고정한다. 별도 브라우저 저장소를 사용해 기존 10개 비교 화면 선택과 섞이지 않는다.

source/recipes.json에 입력 해시와 모든 가공 수치를 기록한다. 메인 루트에서 `python resources/tools/build_wet_hit_revision.py`로 재생성한다. runtime/은 48 kHz 모노 PCM16 WAV다.

현재 2차 후보는 시작 부분의 1 kHz 이하 성분을 최대 78% 줄이고 약 0.12~0.14초까지 부드럽게 해제한다. 고역의 액체감과 해제 이후 샘플은 보존하며, 줄인 뒤 전체 음량을 다시 키우지 않는다. source/baseline-v1은 이전 5개 렌더를 재현한 기준 WAV다.

사용자가 이 계열 전체를 반려했다. 재채택된 것으로 취급하거나 게임에 적용하지 않는다.
