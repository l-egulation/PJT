# 다음 공격 강화 이펙트 시험판

「다음 공격 한 방을 강하게 하는」 잉크 파츠 셋의 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다.

| 파츠 | 언제 | 효과 | 쓰는 시트 |
|---|---|---|---|
| 승전의 칼끝(빨강) | 처치 시 | 다음 공격 피해 +25% | `charge-rise` → `charge-release` → `emp-hit` |
| 인계된 칼날(빨강) | 무기 전환 시 | 바꾼 무기 다음 공격 피해 +30% | `emp-hit` |
| 인계된 사거리(파랑) | 무기 전환 시 | 바꾼 무기 다음 공격 사거리 +40% | 없음 |

무기를 바꾸면 바꾼 무기가 곧바로 자동 공격하므로(전투 규칙) 인계 두 파츠는 기다리는 구간이 거의 없다. 그래서 승전의 칼끝만 기다림 반복이 있다. 인계된 칼날은 머리 위 칼날 표식을 만들었다가 뺐다: 표식이 뜨자마자(약 0.16초) 공격이 나가 겹쳐 보이지 않는다. 강해진 한 방(`emp-hit`)만 쓴다. 인계된 사거리는 숫자만 바뀌는 버프라 이펙트를 두지 않는다(더 멀리 있는 몬스터가 맞는 것이 표시다. 쿨타임 감소·파열의 여백과 같은 판단).

- `charge-rise.js`: 기다림(0.8초 반복). 몸 폭 전체에서 붉은 기운이 아래에서 위로 쭉 피어올라 머리 위에서 흩어진다. 양옆 가장자리에 몰리지 않는다. 옵션 `width`(20)·`top`(96).
- `charge-release.js`: 공격 시작(0.28초). 몸 둘레 기운이 가는 줄기로 손에 빨려 들고 손에서 번쩍인다. 옵션 `hand`(손 자리, [6, -17]).
- `emp-hit.js`: 강해진 한 방이 맞는 순간(0.24초). 날카로운 네 갈래 빛 별. 일반 흰 피격 위에 겹친다. 옵션 `size`(22).
- `glow-dot.js`: 빛 방울(흰 속 → 색 → 번짐). `charge-release`·`emp-hit`가 쓴다.
- `export.mjs`: Git 제외 `outputs/pixelfx/empower/`에 빨강 셋(`charge-rise`, `charge-release`, `emp-hit`)을 뽑는다.

```sh
node 전투테스트/다음공격강화/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- 25fps, PPU32 게임 화소 1:1. `emp-hit`만 피벗이 맞은 자리(몬스터 몸 가운데)이고 나머지는 플레이어 발 가운데다.
- 오른쪽을 보는 판만 뽑았다. 왼쪽을 보면 시트를 좌우 반전한다(`emp-hit`은 대칭이라 그대로).
- `hand`·`head`는 1스테이지 캡처의 서 있는 자세 기준이다. 공격 동작 중 손 위치는 게임이 맞춰야 한다.
- 팔레트는 임시값이다.

## 확인한 범위

1스테이지 캡처 위에서 「처치 → 기다림 → 공격」과 「무기 바꿈 → 바로 공격」 두 장면을 이어 붙여 렌더링으로만 봤다. 기다림 시안(손 불씨·머리 위 칼날·솟는 줄기·양옆 기운)에서 몸 전체로 오르는 기운으로 바꿨고, 인계는 허리 빛 고리 → 머리 위 칼날 표식을 거쳐 표식 없이 강해진 한 방만 쓰기로 했다. Unity·공격 동작 중 위치는 확인하지 않았다.
