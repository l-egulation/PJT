# 몬스터 상태이상 표시 (2026-11-06 확정)

플레이어의 잉크 파츠가 몬스터에게 거는 상태(표식·속박·기절·중독)를 보여 주는 이펙트다. pixelfx(MIT)로 1배(32px = 1u)로 그렸고, 2스테이지 보스 VFX의 다크 판타지 칠하기를 색조를 유지하도록 고친 게임 화풍으로 다시 칠했다. 게임은 `runtime/`만 쓴다.

## 확정 내용

| 상태 | 표시 | 시트 |
|---|---|---|
| 표식 | 머리 위에 잉크 방울이 쌓인 순번 색(빨·주·노·초·파·남·보)으로 한 줄, 새 표식이 오른쪽. 외곽선 없음 | `mark-drop` |
| 표식 터짐 | 표식 하나가 터질 때(0.08초 간격) 머리 위 그 방울이 작게 튀어 사라지고, 몸통 가운데에서 그 색 잉크가 넓게 튄다(몬스터 **뒤** 레이어). 같은 순간 몬스터 몸이 그 표식 색으로 물들었다가 0.2초에 걸쳐 빠진다(Unity 코드). 외곽선 없음 | `mark-pop`, `mark-burst` |
| 속박 | 몸통을 감은 꼰 잉크 밧줄 세 줄(바짝 조여 앞쪽이 살짝 처짐, 줄마다 기울기 다름). 앞쪽 반은 몬스터 앞, 뒤쪽 반은 몬스터 뒤. 몸 폭 2u 미만은 `small`, 이상은 `large` 행 | `bind-front`, `bind-back` |
| 기절 | 머리 위 금빛 별 셋이 기울어진 고리를 돈다. 표식 줄이 있으면 그 위 | `stun-stars` |
| 중독 | 보라 독 해골 거품이 몬스터 몸 전체 범위 안 무작위 자리에서 맺혀 떠오르다 터진다. 중첩당 초당 2.5개, 크기 둘(`small`·`big`)을 섞는다. 중독 동안 몸을 보라로 물들인다(Unity 코드) | `poison-skull` |

- 밑줄 긋기는 "특수 스킬을 쓰면 캐릭터 기본 공격이 25% 오르는" 버프 스킬로 바뀔 예정이라(사용자 결정) 상태 표시를 만들지 않는다.
- 냉기·빙결·화상·둔화는 지금 54종 잉크에 없어서 새로 그리지 않았다.
- 외곽선: 표식 방울·방울 터짐·몸통 터짐만 외곽선과 그림자 테두리가 없다(사용자 요청). 나머지는 잉크 외곽선과 1·2px 그림자 테두리가 있다.

## 폴더

| 경로 | 내용 |
|---|---|
| `runtime/*.png` | 게임용 시트 7장. 열 = 프레임, 행 = 변형(표식 색·크기), 셀은 왼쪽 위부터. |
| `runtime/sheets.json` | 시트마다 셀 크기·프레임 수·변형 이름·피벗(셀 왼쪽 위 기준 px)·프레임 시간(ms)·반복 여부·용도. 메인 Unity 바인딩이 이 값을 그대로 쓴다. |
| `source/pixelfx/*.js` | pixelfx 효과 코드(`inkstatus` 범주). pixelfx의 `src/core`와 `src/fx/status/_lib.js`를 쓴다. |
| `source/tools/export_runtime.mjs` | 효과를 1배로 그려 게임 화풍으로 칠하고 `runtime/`을 쓴다. |
| `source/tools/gamestyle.mjs` | 게임 화풍 다시 칠하기(색조 유지, 밝기 5계단, 옅은 빛 줄임, 그림자 테두리). |
| `preview/ink_status_preview.html` | 확정안을 실제 몬스터 4종의 대기 동작 위에 겹친 미리보기(그림 내장). 표식 쌓기·터트리기, 중독 중첩, 실전 지속시간 재생, 게임 기본 검 피격 이펙트와 겹쳐 보기("타격")가 있다. |

## 다시 만들기

1. pixelfx 저장소(https://github.com/patch-gg/pixelfx)의 `src/fx/inkstatus/`에 `source/pixelfx/*.js`를 둔다.
2. 이 폴더에서 `node source/tools/export_runtime.mjs <pixelfx 저장소 경로>`를 실행한다.

같은 코드로 다시 내면 `runtime/` 시트가 바이트 그대로 나온다(결정적 난수).
