# 파열 가시 이펙트 시험판

빨강 잉크 `ink2_red_07` 파열 가시(표식을 터트릴 시, 격발 대상에게 발동 무기 기본 공격 기준 피해 60%인 추가타 1회)가 들어갈 때 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다.

[덧베기](../덧베기/README.md)와 같은 빛 선 방식의 [pixelfx](https://github.com/patch-gg/pixelfx)(MIT) 이펙트다. 몬스터 발밑에서 큰 가시 하나가 비스듬히 솟아 몸통을 꿰뚫고, 작은 가시 둘이 곁에 솟는다. 가시는 화소마다 선까지의 거리를 재서 흰 심 → 빨강 → 반투명 번짐으로 칠하고, 끝으로 갈수록 바늘처럼 가늘어진다. 넘침·떨림 없이 0.05초 만에 뻗어 멈췄다가, 0.14초부터 가늘어지며 0.3초에 사라진다.

- `burst-thorn.js`: 이펙트. 옵션 `palette`, `dir`(1이면 오른쪽으로 맞음: 큰 가시가 왼쪽 발밑에서 오른쪽 위로 솟는다).
- `glow-path.js`: 빛나는 꺾은선 공용 함수([속박](../속박/README.md)과 같은 파일).
- `export.mjs`: 빨강 한 판을 뽑는다. 결과는 Git 제외 `outputs/pixelfx/burst-thorn/burst-thorn_red.png/json`.

```sh
node 전투테스트/파열가시/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- 한 장 160×140, 25fps, 10장(0.36초, 끝의 장들은 비어 간다). 피벗 (80, 80) = 맞은 몬스터의 몸통 가운데. 바닥은 피벗 아래 28px(`meta.pixelfx.floor`, 표식 격발과 같다). PPU32 게임 화소 1:1.
- 0장이 추가타 접촉 장이다. 큰 가시가 이미 약 80% 솟아 있다.
- 격발과 같은 순간에 틀면 빨간 격발 덩어리에 묻혀 안 보인다. 미리보기는 격발 접촉 장에서 피격 멈춤(0.075초) + 0.3초 뒤, 격발이 흩어진 다음 두 번째 타격으로 틀었다(`meta.pixelfx.afterBurstContact` 0.375초). 실제 추가타 시점은 데이터에 없다(미정).
- 오른쪽으로 맞는 판만 뽑는다. 왼쪽으로 맞으면 시트를 좌우 반전한다.
- 바닥에서 솟는 모양이라 보라 [속박](../속박/README.md)의 빛 말뚝과 닮은 면이 있다. 색(빨강·보라)과 개수·크기(큰 가시 하나 대 여러 말뚝)로 구분한다.

## 확인한 범위

1스테이지 실제 게임 캡처(가시뿌리를 때리기 전·맞는 순간·맞은 뒤) 위에서 빨강 격발(표식 5개, 테두리 없음) 뒤에 가시 추가타를 이어 붙이고, 다른 시안 셋(사방으로 뻗음·바깥에서 찔러 듦·뒤로 꿰뚫고 나감)과 나란히 렌더링으로만 봤다. 사용자가 이 시안을 골랐다. Unity 실행·다른 몬스터·보스 크기는 확인하지 않았다. pixelfx 검사에서 한 장 4.4ms가 걸려 시트로 쓰는 것을 전제로 한다.
