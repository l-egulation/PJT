# 색상 잉크 파츠 개편안 53종

[카탈로그 개요](README.md)

> 적용 범위: 현재 코드·생성기·시험 도구의 구현 자료이며 제품 성장 기획이 아니다. 새 기준은 [무기 도면·런 잉크 도감](../../../design/equipment/rules.md)이다. 아래 고정 파츠·등급·팔레트 수치를 새 잉크 레벨·보상에 승계하지 않는다.

색상마다 고유한 방식으로 피해에 기여하도록 다시 짠 색상 잉크 파츠다. 색상 역할과 아래 `사용자 결정` 규칙은 확정 방향이다. 파츠별 등급·+0~+5 수치·쿨타임은 승인된 재설계 기준이다. 실전 밸런스 체감은 플레이 검증 대상이다.

편집 원본: [`ink_color_parts_proposal.json`](../../../../data/combat/ink_color_parts_proposal.json). 이 문서는 `node tools/ink-combination-lab/generate-color-parts.cjs`로 생성하고 `--check`로 일치를 검사한다. 현재 제품 기준은 [잉크 구성 규칙](../../../design/equipment/inks/rules.md#효과-부여와-공격-부여)이다.

**구현 범위**: Unity 런의 색상 잉크는 이 53종을 사용한다. 파츠별 고정 내부 등급·슬롯 강화 대상은 [`ink_color_parts_tuning.json`](../../../../data/combat/ink_color_parts_tuning.json)의 확정 테이블이고, 가방과 정비소는 파츠별 문양과 등급 문장을 사용한다. 전투 이펙트는 기존 그림을 임시로 쓰고, 전기장만 반경에 맞춘 전용 번개 장판 반복 시트를 쓴다. 브라우저 시뮬레이터는 [이전 50종](ink-simulator-part-catalog.md)으로 남아 있다.

## 색상 역할

| 색 | 역할 | 피해에 기여하는 방식 |
|---|---|---|
| 빨강 | 직접 피해 | 추가타·다음 공격 강화처럼 피해를 직접 더한다. |
| 노랑 | 이동으로 피해 | 걷기·대시·전기장과 공속·이속 증가를 피해로 연결한다. |
| 초록 | 체력으로 피해 | 보호막·체력 상태와 피격 반격을 피해로 연결한다. 회복은 전투 누적으로만 얻는다. |
| 파랑 | 공격하기 쉽게 | 공격 범위·사거리와 남은 특수 쿨타임 감소로 공격 기회를 늘린다. |
| 보라 | CC로 피해 | 속박·기절·독을 걸고 그 상태를 피해로 연결한다. |

## 트리거

| 트리거 | 기준 |
|---|---|
| 상시 | 트리거 없이 적용한다. 마지막으로 실제 공격을 시작한 무기의 팔레트 효과만 적용한다. |
| 몬스터 적중 시 | 원타격과 추가타의 적중. 지속 피해·장판 피해는 적중으로 세지 않는다. |
| 몬스터 처치 시 | 몬스터 한 생명당 한 번. |
| 스위칭 시 | 이 잉크를 낀 무기에서 다른 무기로 바꿀 때. 바꾸기 전 무기의 잉크 효과를 먼저 모두 처리한 뒤 다른 무기로 바꾸고, 바꿔 든 무기가 자동 공격한다. |
| 표식 터트릴 시 | 표식을 쌓은 무기가 아닌 무기로 맞혀 쌓인 표식을 모두 터트릴 때. 역순으로 터지는 연쇄의 마지막 빨강 표식이 터질 때 한 번 발동한다. |
| 색 표식이 터질 때 | 표식 연쇄에서 그 순번 색의 표식이 터질 때. 그 색까지 표식이 쌓여 있어야 한다. |
| 이동 시 | 걷기·대시의 실제 가로 이동 거리. 넉백·순간이동·위치 보정은 제외한다. |
| 대시 시 | 대시 중 몬스터와 겹쳤을 때. 대시 한 번에 몬스터마다 한 번. |
| 피격 시 | 몬스터 공격으로 실제 체력 피해를 받았을 때. 보호막에 모두 막힌 피해·낙사·자해는 제외한다. |
| 속박이 풀릴 때 | 몬스터에게 걸린 속박이 시간이 다 되어 풀릴 때. 처치로 사라진 속박은 제외한다. |

## 공통 규칙

`사용자 결정`은 확정 방향, `초안`은 사용자 결정을 구현하려고 제안한 시험 규칙, `기존`은 개편 설계의 기존 규칙이다.

- `사용자 결정` 회복은 처치·적중 누적과 표식 터트리기로만 얻는다. 시간 경과·스위칭·상시 회복 파츠는 두지 않는다. 몬스터를 처치하거나 때리지 않으면 회복이 오르지 않는다. 표식으로 회복하는 파츠는 자체 쿨타임 15초를 둔다.
- `초안` 보호막을 만드는 파츠는 자체 쿨타임 15초 이상을 둔다. 스위칭 보호막 15초는 사용자 결정이고, 다른 보호막 파츠로 넓힌 하한은 초안이다.
- `사용자 결정` 지속 피해(독·기절 지속 피해)와 장판 피해(전기장)를 허용한다.
- `사용자 결정` 전기장은 노랑 파츠가 함께 쓰는 하나의 효과다. 이동 중 남기는 작은 전기장과 표식을 터트린 자리의 전기장은 크기·유지시간만 다르고 피해 방식은 같다.
- `초안` 같은 몬스터는 겹친 전기장 수와 관계없이 0.5초에 한 번만 전기장 피해를 받는다.
- `초안` 지속 피해·전기장 피해는 적중 트리거를 발동하지 않고 표식을 쌓지 않는다. 이 피해로 처치하면 처치 트리거는 발동한다.
- `사용자 결정` 반경으로 대상을 찾는 잉크 효과(전기장·폭발·전류·느려짐 장판·표식 옮겨 묻히기 등)는 몬스터 몸 중심이 아니라 켜져 있는 피격 영역의 가장 가까운 점까지 거리를 잰다. 피격 영역이 없거나 꺼져 있으면 몸 중심을 쓰고, 같은 반경 안 대상 순서도 이 거리로 정한다. 옮겨 쓰기·파도·대시처럼 상자로 쓸고 지나가는 효과는 그 상자가 피격 영역과 겹치는지로 판정한다. 모든 몬스터에 같은 규칙을 쓰며 반경 값은 바꾸지 않는다. 시계 보스는 몸통(믹서기 중에는 믹서기)·주먹 피격 영역 중 켜진 것만 대상으로 하고, 모두 꺼져 있으면(전투 전·믹서기 출입·사망) 범위 잉크도 닿지 않는다.
- `사용자 결정` 전기장은 깔린 동안 반경에 맞춘 번개 장판이 바닥에서 계속 지직거리는 전용 표현으로 보이고 전기장이 끝나면 사라진다. 이동 시 속도 증가 표현은 쓰지 않는다.
- `사용자 결정` 독은 다시 걸면 지속시간만 갱신한다. 팔레트 슬롯 강화 단계에 따라 최대 중첩 수가 늘어난다.
- `초안` 독은 대상마다 하나이며 최대 5중첩이다. 적용 파츠의 상한까지 1중첩을 더하고 기존의 높은 중첩을 줄이지 않는다. 독이 지속되는 동안 더 높은 틱 피해와 그 출처를 유지하며 만료·독폭탄으로 제거되면 초기화한다.
- `사용자 결정` 처치 폭발(ink3_red_05)은 반경 6 안의 적에게 기본 공격 피해 100%를 준다. 반경 2·40%에서 범위를 3배로 넓히고 피해를 올렸으며, 강화표는 기존 오름 비율을 유지해 100→110→130→160→200→250%다(사용자 결정 2026-11-10).
- `사용자 결정` 독폭탄은 독이 계속 쌓이도록 자체 쿨타임을 두고, 쿨타임마다 독에 걸린 몬스터를 맞히면 걸린 독을 지우며 남은 독 피해를 한 번에 준다.
- `사용자 결정` 보스에게는 CC 지속시간에 기존 배율 25%를 적용하고, CC에 붙은 피해는 100% 적용한다.
- `사용자 결정` 쿨타임 감소는 진행 중인 남은 쿨타임에서 뺀다. 0 아래로 내리지 않고 다음 사용으로 저장하지 않는다.
- `사용자 결정` 표식은 기본으로 쌓이지 않는다. "표식 터트릴 시" 파츠나 색 번짐을 장착하면 원타격에 표식을 묻히는 기능이 함께 생긴다. 표식을 묻히는 기능이 이미 있으면 다른 파츠가 추가로 발동시키지 않으므로 원타격당 표식은 1개다.
- `초안` "색 표식이 터질 때" 파츠도 "표식 터트릴 시" 파츠처럼 표식을 묻히는 기능을 켠다. 붉은 낙관은 표식 피해만 늘리고 표식 기능을 켜지 않는다.
- `초안` 두 무기 중 한쪽에만 표식 기능을 켜는 파츠가 있어도 두 무기의 원타격이 모두 표식을 묻힌다. 표식은 무기를 바꿔 때려야 터지므로 한쪽만 묻히면 혼자 터트릴 수 없기 때문이다.
- `사용자 결정` 표식은 최대 7개이고 쌓인 순서대로 빨·주·노·초·파·남·보 색이 붙는다. 몬스터 체력바 옆 숫자가 쌓인 수만큼 하나씩 올라가고, 가장 최근에 쌓인 색으로 표시한다. 7개가 찬 뒤 맞히면 유지시간만 갱신한다. 표식이 쌓일 때마다 그 몬스터의 표식 전체 유지시간을 8초로 갱신한다.
- `사용자 결정` 표식을 쌓은 무기가 아닌 무기의 원타격이 표식이 있는 몬스터에 적중하면 그 몬스터의 남은 표식을 모두 터트린다. 터트린 타격은 터트린 뒤 자기 무기의 표식 1개를 새로 남긴다.
- `사용자 결정` 표식은 쌓인 역순(보→남→파→초→노→주→빨)으로 0.08초마다 하나씩 터지며, 하나마다 이펙트와 기준 피해 15%를 준다. 연쇄 전체를 추가타 1회로 보고, "표식 터트릴 시" 파츠는 마지막 빨강이 터질 때 한 번 발동한다. 연쇄 중 몬스터가 죽으면 연쇄가 멈춘다.
- `초안` 연쇄의 첫 표식 피해만 추가타로서 적중 트리거를 발동하고, 나머지 표식 피해는 적중 트리거를 발동하지 않는다. 표식 피해로 처치하면 처치 트리거는 발동한다. 연쇄가 몬스터의 죽음으로 멈추면 남은 색 표식 파츠와 "표식 터트릴 시" 파츠는 발동하지 않는다.
- `초안` 표식 연쇄에서 발동하는 파츠는 표식을 터트린 무기의 팔레트를 본다. 표식이 터지는 도중에 무기를 바꿔도 터트린 순간의 팔레트를 유지한다.
- `기존` 기준 피해는 장착 무기 기본 콤보 각 타격 피해의 산술평균이다.
- `초안` 2026-11-05 추가 11종(농묵·밑줄 긋기·내달린 획·옮겨 쓰기·되갚는 잉크·갑옷 깁기·겹쳐 쓰기·정리 정돈·앞당긴 획·넘어뜨리기·약점 찌르기)은 사용자가 고른 시험 초안이다. 겹쳐 쓰기는 충전이 무기 자원이므로 마지막으로 공격한 무기와 관계없이 이 잉크를 낀 무기에 적용한다.
- `사용자 결정` 슬롯 강화 비용은 각 슬롯의 현재 단계에 따라 50/100/180/350/600G이며 +5까지 누적 1,280G다. 파츠 교체·정비소 이동은 단계와 다음 비용을 바꾸지 않는다.
- `사용자 결정` 덧칠은 자기 자신이 만든 추가타에 재발동하지 않는다. 단독 +5는 원타격의 50%를 한 번 추가한다. 다른 잉크가 만든 추가타에 반응하는 기존 규칙은 유지한다.

## 용어

- **표식 터트리기**: 표식을 쌓은 무기가 아닌 무기로 맞혀, 쌓인 표식을 역순으로 하나씩 모두 터트리는 것
- **기준 피해**: 장착 무기 기본 콤보 각 타격 피해의 산술평균
- **속박**: 이동만 막고 공격은 허용
- **기절**: 시전 중이던 공격을 취소하고 이동·새 공격을 막음

## 몬스터 상태 표시

- `사용자 결정` 2026-11-06 확정. 그림 원본은 resources `effects/ink-status`, 게임 연결은 `InkStatusVisuals`다.
- 표식: 머리 위에 잉크 방울을 쌓인 순번 색으로 한 줄 띄운다(새 표식이 오른쪽, 외곽선 없음). 하나가 터질 때마다 그 방울이 머리 위에서 작게 튀어 사라지고, 몸통 가운데에서 그 색 잉크가 몬스터 뒤로 넓게 튀며, 몬스터 몸이 그 색으로 물들었다가 0.2초에 걸쳐 빠진다.
- 속박: 몸통을 꼰 잉크 밧줄 세 줄이 감는다. 앞쪽 반은 몬스터 앞, 뒤쪽 반은 몬스터 뒤에 그린다.
- 기절: 머리 위(표식 줄이 있으면 그 위)에 금빛 별 고리가 돈다.
- 중독: 몬스터 몸 범위 안 무작위 자리에서 보라 독 해골 거품이 중첩당 초당 2.5개 맺혀 떠오르다 터지고, 중독 동안 몸을 보라로 물들인다.
- 밑줄 긋기는 버프 스킬로 바꿀 예정이라 상태 표시를 두지 않는다.

## 고정 등급과 슬롯 강화 수치

아래 수치는 +0 → +1 → +2 → +3 → +4 → +5 순서다. 범위 증폭은 여의봉을 통합했으며, 기존 여의봉 ID는 범위 증폭으로 읽는다.

| 파츠 | 등급 | 강화 수치 |
|---|---|---|
| 추가타 | 1 | 추가타: 20% → 22% → 26% → 32% → 40% → 50% |
| 집중 공격 | 3 | 한 번 쌓일 때마다 피해 증가: 2% → 2.3% → 3.08% → 4.76% → 8% → 14% |
| 교체 강타 | 2 | 다음 공격 피해 증가: 35% → 38% → 42.2% → 47.9% → 55.4% → 65% |
| 표식 폭발 | 4 | 표식 폭발 추가타: 30% → 33.75% → 43.5% → 64.5% → 105% → 180% |
| 처치 폭발 | 1 | 처치 폭발 피해: 100% → 110% → 130% → 160% → 200% → 250% |
| 처치 공격력 | 3 | 처치당 공격력 증가: 0.3% → 0.33% → 0.408% → 0.576% → 0.9% → 1.5%<br>공격력 증가 상한: 15% → 16.125% → 19.05% → 25.35% → 37.5% → 60% |
