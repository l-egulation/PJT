# Deviant — 시작 마을

[분야 개요](README.md)

무기·성장의 제품 기준은 [무기·잉크](../../equipment/rules.md)다. 새 런은 맨손으로 시작한다. 현재 마을은 이정표에서 맨손으로 출발하며 출발·외형·맨손 기본 공격을 연결한다. 맨손 기본 공격은 기존 전투 시전·피격 처리에 [전용 2타 모션과 승인 초기 규격](../../equipment/weapons/rules.md#맨손-기본-공격)을 연결한다. 최종 밸런스 검토와 새 장비 성장 구현은 후속 작업이다. 통합 공방은 [개편 영구 성장](../../progression/roguelite-progression.md)의 묶음 해금·공용 리롤·생존·경제 지원을 제공한다. 팔레트 칸 수·무색 칸 해금은 제거한다. 마을 채색용 잉크는 런 장비용 잉크 도감과 구분한다.

## 목표와 동선

게임 실행 → 타이틀 → 시작 마을 → 해금·이야기 확인 → 이정표에서 맨손으로 출발 → 1챕터 → 결과 → 마을로 이어진다. [마을 팔레트 조각](../../progression/village-palette-pieces.md) 5개를 모은 뒤에는 1챕터 → 2챕터 → 결과 → 마을이다. 마을은 공격·피격·적이 없는 안전한 로비이며, 기존 마을과 같은 지형·건물·캐릭터 화풍을 사용한다.

첫 진입은 [초반 스토리](../../story/opening/opening.md)를 [플레이형 오프닝](../../story/opening/opening-playable.md)으로 마을 안에서 보여 준다. 지워짐에 휩쓸린 쓰러짐·조력자의 희생·첫 각성은 같은 우물 앞이다. 주인공은 그 자리에서 잉크 몸으로 깨어난 뒤 조작 가능해진다.

귀환 시 월드 시간의 되감기·대가에 관한 서사 규칙은 미정이다. 결과 화면에서 마을로 복귀하는 제품 동선과 세계 시간 확정을 구분한다. 기록 농가에서 이후의 여정 동기를 확인하고 1챕터로 출발한다. 이미 본 대화는 다시 읽을 수 있고, 반복 출발에 같은 안내를 강제하지 않는다.

## 시설과 역할

| 상호작용 지점 | 역할 | 사용 조건 |
|---|---|---|
| 기록 농가의 기록 책상(표시 이름 「기록」) | 프롤로그와 귀환 이야기, 발견한 수첩 재열람 | 처음부터, 이야기 발견 상태 반영 |
| 우물 | 귀환 위치, 획득한 마을 잉크 붓기와 색 복원 | 첫 붉은 잉크는 장인과 자동 진행, 이후 미사용 잉크를 F로 사용. 붓을 잉크가 없으면 상호작용 없음 |
| 장인의 공방 | 능력치·공용 리롤·잉크 및 증강 묶음·생존·경제 지원을 한 책 화면에서 선택·구매 | 공방은 처음부터 확인 가능. 작업대 열림 연출은 팔레트 잉크 1개, 회수 잉크 2개. 공방 항목은 첫 런 정산 뒤 선행 해금 트리로 열리며 마을 잉크 개수를 요구하지 않음(부활만 1챕터 클리어 추가). 가격 조건 유지 |
| 출발 이정표 | F로 오른쪽으로 걸어 나가 1챕터 시작 | 필수 안내 완료. 도면 선택 없이 맨손으로 출발 |

마을에는 위 네 곳만 시설 상호작용 대상으로 둔다. 별도 보급소·회수공방 건물과 출발 준비대는 배치하지 않는다. 장인의 공방은 기존 염색공방 건물·작업대 그림을 재사용한다. 화면 왼쪽은 줄기 탭과 [해금 트리](../../progression/roguelite-progression.md#해금-트리)를 표시하고, 오른쪽에서 선택한 노드의 효과·가격·조건을 확인해 구매한다. 잠긴 기능도 볼 수 있지만 기존 `ProgressionService.StatusOf`와 `TryPurchase`를 통과해야 구매된다. 화면은 보급·팔레트·회수의 안정 ID, 저장 데이터, 비용을 바꾸지 않으며 선행 조건은 해금 트리를 따른다.

장인은 처음 정산한 런 뒤 같은 공방에서 마법안료와 보급 기능을 소개한다. 첫 붉은 잉크 뒤에는 그 공방에 팔레트 작업이 추가되었음을 알린다. 첫 런에 바로 클리어한 경우 두 설명을 한 번의 공방 방문으로 잇는다. 두 번째 잉크 뒤 회수 기능도 같은 작업대에서 소개하며 별도 문 수리·망치 소리 따라가기 동선은 없다. 다섯 번째에는 마을 공방에 머문다. 장인이 없어도 해금 조건을 만족한 기능을 쓸 수 있다.

## 마을 채색과 해금

마을과 튜토리얼의 구름은 타이틀과 같은 여섯 실루엣을 2×2 도트로 그린다. 큰 구름과 작은 구름이 함께 흐르며, 몸통은 고정하고 가장자리 한 도트와 바람 아래쪽의 작은 구름 조각만 12초 주기로 서서히 변한다. 진한 외곽선 없이 밝은 몸색과 옅은 내부 음영을 사용한다. 스케치에 닿으면 그 순간의 모양과 이동이 멈추고, 색이 돌아오면 이어서 움직인다.

밝은 상태의 마을과 오프닝 튜토리얼 길은 같은 낮 하늘을 사용한다. 위쪽은 밝은 하늘색, 중간은 옅은 청록빛, 수평선은 따뜻한 아이보리로 이어지며 타이틀 시안의 승인된 낮 색감과 맞춘다. 스케치 하늘, 색 복원 조건, 지워지는 전환과 하늘길의 황혼·밤 연출은 기존 규칙을 따른다.

사용자 결정(2026-10-31, 2026-11-02 갱신). 마을은 [초반 스토리](../../story/opening/opening.md)처럼 지워진 상태로 시작한다. 처음 방문하면 건물·작업대·소품·땅·하늘·원경이 모두 스케치다. 1챕터를 깰 때마다 얻는 [마을 팔레트 조각](../../progression/village-palette-pieces.md)으로 색이 우물에서부터 군데군데 → 점점 → 다섯 번째에 전부 돌아온다. 사용자 결정(2026-11-04, 플레이 테스트): 마을의 색은 **이 조각으로만** 돌아온다. 해금 구매·1챕터 보스 첫 클리어·출발은 어떤 건물도 칠하지 않으며, 그 전까지 마을은 무조건 스케치다.

- 해금 구매는 작업대의 자물쇠 연출과 해금 효과만 남기고 건물 색은 바꾸지 않는다. 예전의 해금 건물 채색과 건물 채색 효과(8장 번짐)는 쓰지 않는다(그림·코드는 Editor K 미리보기용으로 남는다). 기록 초기화는 조각 색도 함께 지운다.

## 화면·입력·장비 경계

- 모든 필수 시설은 하나의 연결된 평지에서 접근한다. 시설을 쓰기 위한 벽타기·정밀 점프·숨은 입구를 두지 않는다.
- 기존 1챕터 GUI의 Galmuri·도트 프레임·선택/비활성 표현을 재사용한다. 배경·건물은 [마을 미술 기준](../../../assets/world/village/stage1-village-art-direction.md)의 컬러/스케치 짝을 따른다.
- 마을 작업대는 영구 해금과 기록 확인용이다. 런에서는 [상점](../../run/rewards.md)에서 골드로 무기·잉크를 사고 인벤토리에서 무기를 확정하거나 잉크를 부여한다.
- 네 상호작용 지점 위에는 이름표와 가까이 있을 때 F 키캡을 표시한다. 공방 전체를 잠그지 않고, 화면 안의 각 항목에 기존 잠김 조건을 표시한다.
- 상호작용 범위 안의 가장 가까운 작업대·우물·이정표에만 흰색 2픽셀 외곽선을 표시한다. 범위 밖, 화면 열림, 이야기, 출발 이동 중에는 숨기며 F 키캡과 같은 대상을 따른다. 컬러/스케치 원본은 바꾸지 않는다.
- F 상호작용, Esc 현재 화면 닫기, 키보드/패드 포커스 복귀는 기존 화면 라우터와 제어 scope를 사용한다. 뷰에서 `Time.timeScale`·실제 지갑·전투 상태를 직접 수정하지 않는다.
- 이정표에서 F를 누르면 도면 선택창 없이 맨손으로 새 런을 한 번 생성한다. 시작 방의 기존 도면 제안과 도면 두 개를 요구하는 출구 잠금도 이 출발에는 나타나지 않는다. 영구 해금의 출발 골드·체력·공격력·이동속도 등은 같은 런 계획에 적용한다. 런에서도 A로 맨손 전용 2타 기본 공격을 사용하며 별도 특수 공격은 없다. 세부 규격은 [맨손 기본 공격](../../equipment/weapons/rules.md#맨손-기본-공격)을 따른다.
- 대시 추가를 해금하면 마을에서도 최대 2회와 공통 쿨타임을 사용한다. 구매 저장 직후와 재진입·프로필 재로드에 반영하고, 다른 프로필 갱신이 사용 횟수나 쿨타임을 채우지는 않는다. 챕터 전투에는 출발 스냅샷을 사용한다.
- 1챕터에서는 장비·입력·지도·엘리트·보스·정비소가 현재 확정 규칙을 사용한다. 거점 아트 작업으로 팀 맵 지형·몬스터·카메라 배치를 임의 변경하지 않는다.

## 아트 제작 단위

시작 마을의 승인 배치는 `data/assets/starting_hub.json`의 `layoutProposal`이 기준이다. 시설이 모인 지상 생활 구간은 44유닛이며 32PPU·구조물 밑면 중앙 피벗을 쓴다. 기존 기록 농가 1채와 승인 염색공방 1채, 통합 작업대·우물·이정표·담장·짐수레를 사용하고 출발길의 작은 집과 출발 문은 두지 않는다. 기록 책상 x 10.75, 우물 14.5, 통합 작업대 28.5, 이정표 36에 배치한다. 하늘길은 별도 84유닛 폭을 유지하며, 그 바깥쪽에서 지상으로 떨어지면 생활 구간 안으로 돌아온다. 카메라 좌우 범위는 마을 땅과 그 위의 일반 점프(2단 점프 포함 약 6유닛) 동안 생활 구간 44유닛 안에 머물러, 이정표 근처에서 점프해도 화면이 옆으로 밀리지 않는다. 84유닛 범위는 하늘길 판이 진행 중이거나 완주 후 마을 땅에 다시 서기 전, 또는 하늘길의 가장 낮은 돌(출발 돌, 높이 17) 1유닛 아래보다 높이 있을 때만 쓴다(`StartingVillageWorld.CameraRightUnits`). 시설 간격과 작은 접지 Y 보정은 이 데이터에 보존한다.

출발 이정표에서 F를 누르면 선택창 없이 맨손 런을 한 번 준비하고 카메라를 고정한 채 오른쪽으로 자동 이동한다. 캐릭터가 화면 밖으로 나가면 기존 페이드로 1챕터에 입장한다.

배경은 1스테이지 전투와 같은 2×2 도트 픽셀 띠(산·먼 마을·가까운 마을)와 하늘·구름·새다. 색 있는 판은 사용자 컬러 디자인을 다시 그린 것이고(리소스 `environments/stage1-background-color-20261112`), 색 빠진 판은 그 그림을 같은 밝기의 크림 회색으로 바꾼 것이라 오프닝에서 색이 지워질 때 두 판이 점까지 겹친다. 전투 스테이지는 색 빠진 판을 쓴다. 가로 이동 비율은 구름 0.05, 산 0.08, 먼 마을 0.18, 가까운 마을 0.45이며 각 띠는 한 칸씩 좌우 반전해 이어진다. 띠의 양 끝에는 대칭 건물의 반쪽만 두어 반전 구간과 맞닿으면 한 채가 되고, 그 구역에는 반전으로 짝지어 보일 다른 것을 두지 않는다. 띠의 맨 아래는 덤불 줄로 끝난다. 구름은 색 있는 동안만 초당 5픽셀 흐르고, 새 두 마리는 위·중간·아래·중간 날갯짓으로 저마다 제 시계로 날다가 스케치가 된 자리에서 그 자세로 멈춘다(색 빠진 상태에서는 구름과 새가 움직이지 않는다). 바닥과 튜토리얼 길의 벽·발판은 전투와 같은 32px 잔디 타일과 나무 발판이다: 색 빠진 판은 전투 타일 그대로, 색 있는 판은 2챕터처럼 속을 비운 판(드러난 면을 따라 흙 테두리, 안쪽은 짙은 흙빛)이다. 보스 제단과 출구는 승인된 석조 상태별 그림을 사용하며 보상 규칙과 다음 챕터의 실제 구현 범위는 기존 런 명세를 따른다.

| 분류 | 신규 출력 | 기존 재사용 |
|---|---|---|
| 건물 | 추가 제작 없음 | 통합 공방에 기존 염색공방 컬러/스케치 짝, 기록 농가에 기존 마을 집 |
| 작업대 | 추가 제작 없음 | 통합 공방에 기존 팔레트 작업대, 기록 농가에 기록 작업대, 공통 종이·스탬프 표현 |
| 거점 소품 | 우물·공방 작업대·이정표의 컬러/스케치 짝 | 기존 담장·식생·길·발판·원경 |
| UI | 영구 해금 목록·마법안료·시설/상태 문양 | Galmuri, 도트 공통 프레임·버튼·슬롯·코인 |
| 효과 | 구매 완료·재화 획득의 재사용 가능한 짧은 키프레임 | 기존 이동·귀환/포탈·명중 효과와 음원 중 맞는 것 |
| 캐릭터·이야기 | 필요 누락분은 실제 출처를 확인한 뒤 제작 | 기존 주인공·확정 등장인물·StoryReference/StoryPreview 장면 자료 |

원본·게임용 출력·미리보기·색인과 검토 상태는 `resources/`에서 관리한다. 현재 재사용 자료와 새 파일의 출처·규격·투명 배경·피벗·해시를 함께 기록한다. 새 출력의 `runtime` 경로는 게임용 내보내기라는 뜻이며 최종 미술 승인이나 Unity 통합을 뜻하지 않는다.

보스 처치 후의 다음 챕터 출구는 수로를 예고하는 단순한 돌 아치·물길·철창 5개로 표현한다. 게임용 크기는 112×144px이며 닫힘·열림·12개 상승 프레임을 모두 32PPU·밑면 중앙 피벗으로 맞춘다. 보스가 죽으면 닫힌 철창이 나타나고, 플레이어가 F로 사용하면 철창이 상승한 뒤 0.15초 후 기존 1챕터 클리어 결과 처리로 이어진다. 문을 여는 도중에는 입력과 시뮬레이션을 막고 중복 사용을 거부한다. 실제 2챕터 맵 진입이 구현되었다는 의미는 아니다.

## 현재 구현과 목표

시작 마을은 1챕터와 같은 카메라·픽셀 뷰포트와 평지 지형을 사용하며, `TemporaryGuiWorldOutput`이 월드를 GUI 아래 출력한다. 기록 농가·우물·장인의 공방·이정표 네 곳을 F로 사용한다. 화면이 열리면 마을 전용 제어 scope가 정지와 입력 차단을 소유하고 닫을 때 자기 것만 반환한다. 사용자 결정(2026-11-13): 일시정지 메뉴·화면·동작 카드가 마을을 멈춘 동안에는 우물 잉크 붓기와 그 효과음·저장, 색 번짐, 장인의 퇴장·사라짐, 자동으로 닫히는 말풍선과 추격 암전의 시간도 함께 멈추고, 풀리면 멈춘 자리에서 이어진다(`StartingVillageWorld.SceneTime`). 첫 방문은 [플레이형 오프닝](../../story/opening/opening-playable.md), 잉크 귀환은 [첫 붉은 마을 잉크](../../story/village/first-red-village-ink.md)를 따른다. 마을 채색은 잉크 사용 상태에만 따른다.

완료 판정은 명세 작성, 에셋 출력, Unity 배치, 기능 연결, 실제 시작 마을→1챕터 플레이·빌드 검증으로 나눠 기록한다. 준비된 에셋 파일이나 문서만으로 플레이 완성을 주장하지 않는다.

### 기록 농가의 스토리 목록

사용자 결정(2026-11-13): 플레이어에게 보이는 이름은 마을 이름표와 화면 제목 모두 「기록」이다. 기록 농가·기록 책상은 문서와 코드의 시설 이름으로만 쓴다. 기록 화면의 막 뒤로 마을 그림이 비치는 것은 의도이지만, 시설 이름표(「기록」, 「장인의 공방」 등)는 화면이 열린 동안 숨긴다.

기록 농가는 보상 선택 화면과 같은 85% 검은 막으로 월드를 어둡게 하고, 960×540 기준 왼쪽 스토리 목록과 오른쪽 미리보기를 표시한다. 선택은 ↑↓, 재생은 상호작용 키(기본 F), 닫기는 Esc다. 목록 항목 안에는 키 배지를 넣지 않고 재생 버튼에만 키를 표시한다. 선택 테두리는 한 겹이며 별도 굵은 노란 줄이나 포커스 테두리를 겹치지 않는다. 재생 버튼만 얇은 외곽 틀을 두고 닫기·목록 복귀·페이지 조작은 키 배지만 있는 인라인 표시로 둔다. 키 배지는 글자 폭에 맞춰 늘어나며 고정된 긴 칸으로 만들지 않는다. 기록 화면은 HTML과 같은 Galmuri11을 독립된 동적 래스터 글꼴로 26/17/13/11/10px 등 요청 크기에 표시한다. 글리프 텍스처는 Point 샘플링을 적용하고, 입력 프로필이 연결된 뒤 하단 키 배지의 폭도 다시 계산한다. 또한, 인벤토리의 12px 정적 글꼴 규칙은 변경하지 않는다. 책·종이·책등·제목 탭은 사용하지 않는다.

잠긴 스토리도 목록에 흐린 글자와 자물쇠로 표시한다. 선택해도 그림·본문을 표시하지 않고 잠금 안내만 보여 주며 재생 버튼과 키 재생을 차단한다. 해금된 스토리는 첫 그림과 페이지 수를 미리 볼 수 있다.

재생 화면은 960×540 원본 컷과 아래 검은 영역의 수첩 기록 문장을 함께 표시한다. 본문은 명사형이 아닌 직접 겪은 관찰·생각의 문장으로 쓴다. Space 또는 F로 다음 페이지, Esc로 목록 복귀한다. 하단에는 현재 / 전체 페이지를 표시한다. 0.28초 페이드아웃 후 컷을 교체하고 0.38초 페이드인한다. 등장·흡수 등 별도 조력자 애니메이션은 없다. 전환 중 중복 입력을 막고 Esc는 즉시 연출을 취소한다. 마지막 페이지를 넘기면 별도 종료 화면 없이 목록으로 돌아간다.

게임 기준 원본은 `data/story/record_stories.json`이다. `build_hub_bindings.py --record-stories-only`는 이미지 배치와 별개로 텍스트 카탈로그 `HubRecordStories.json`을 생성·검사한다. 컷 원본과 검토 HTML은 리소스의 `sequences/record-farmhouse-stories-20261112/`에서 관리하고, Unity 적용은 메인의 명시적 배치 계약을 따른다. 이야기 1은 제공된 원본 07(잉크를 나눠 주는 컷)을 제외한 8장, 이야기 2는 8장이다. 이야기 3(마을색을 되찾을 방법)은 제공된 긴팔 로브·붉은 잉크 v3의 01·03·04·05·06·07·10, 총 7장으로 구성한다. 병 발견 → 마을 귀환 → 한 방울 → 풀잎 변화 → 남은 잉크 붓기 → 주변 복원 → 다음 잉크를 찾기로 결심 순서다. 02·08·09의 중복 내용은 앞뒤 장면에 합치며, 첫 마을 잉크 사용 뒤 기존 해금·완독 상태를 그대로 사용한다. 이야기 3의 수첩 문장은 편집 원본에서 수정한다. 원본 ZIP과 제외 장면은 리소스에 보존한다.
