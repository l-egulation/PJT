# Changelog

## [0.0.2.0] - 2026-09-14

### Changed

- 오프라인 보상은 1분 이상부터 분 단위로 계산하고 최대 480분까지 지급합니다.
- 복귀 시점의 현재 스테이지를 1분 자동전투했을 때 얻는 기대 보상의 50%를 인정된 분 수만큼 지급합니다.

### Fixed

- 1분 미만 재접속은 기존 실행 세션을 이어 사용하며 보상 작업과 팝업을 만들지 않습니다.

### Added

- 59초·60초·119초·8시간 경계, 현재 스테이지 기준, 50% 지급량과 운영 배포 설정을 검증합니다.

## [0.0.1.0] - 2026-09-14

### Changed

- 오프라인 보상을 서버 UTC 기준 10초 단위, 최대 80초로 계산하고 가장 높은 최초 클리어 스테이지의 1분 기대 보상률을 적용합니다.
- 오프라인 보상 화면에서 실제로 자리를 비운 시간과 보상이 적용된 시간을 각각 정확히 표시합니다.

### Fixed

- 같은 탭을 새로고침하거나 실행 세션을 다시 열 때 기존 세션을 이어 사용해 오프라인 보상이 잘못 생성되는 문제를 막았습니다.
- 활성 세션의 보상 작업을 조회·교체 요청으로 반복 수령할 수 없도록 서버 전이를 제한하고, 기존 보상 결과와 롤백 API도 호환되게 처리했습니다.

### Added

- 10초 경계·80초 상한, 최고 클리어 스테이지, 세션 재개 경쟁 조건, 배포 설정 전파를 검증하는 회귀 테스트를 추가했습니다.
