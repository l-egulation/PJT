# 1페이즈 중앙 장치 「잉크 결정」 (2026-11-12)

렉토가 만든 환각 전장의 기계장치(판정 2×3u, 체력 2000)를 「잉크 결정」으로 다시 그렸다. 예전 기계 그림(boss-siblings-lineup-20261103/unity-phase1/machine.png)을 대신한다.

## 사용자 결정

- 여러 시안(환등기·잉크 환각구·최면 원반·세 눈 문양·펼친 페이지·잉크 마법진·잉크 결정) 가운데 잉크 결정을 골랐다.
- 크기는 1차 크기(그림 3×4u)로 한다. 1.3배 키운 판은 캐릭터 옆에서 너무 컸다.
- 결정 둘레를 도는 구슬, 떠오르는 반짝이 조각, 결정 속 얇은 선(잉크 띠·흰 세로줄), 위 끝 십자 반짝임, 속 타원 빛은 모두 뺐다.
- 속은 면 명암만 두고, 강조는 넓은 빛 띠가 면을 한 번 쓸고 가는 「빛 쓸기」로 정했다.
- 손상은 귀퉁이가 들쭉날쭉 떨어지는 판이 싸 보여서 「갈라져 벌어짐」으로 바꿨다. 손상은 쌓인다. 2단계는 1단계의 금과 벌어짐을 같은 자리에 두고 아래 조각에 새 금을 하나 더한다.

## 실행용 시트 (runtime/)

칸은 왼쪽 위부터 행 우선, pivot 은 칸 왼쪽 위에서 잰 화소, 32px = 1u. 형식은 rose-blue-boss-vfx-20261105/runtime/sheets.json 과 같다.

| 시트 | 칸 | 장 | 시간 | 반복 | 쓰임 |
|---|---|---|---|---|---|
| machine-crystal-idle | 96×128 | 12 | 85ms | 반복 | 멀쩡할 때 |
| machine-crystal-damage1 | 96×128 | 12 | 85ms | 반복 | 한 번 갈라짐(두 동강) |
| machine-crystal-damage2 | 96×128 | 12 | 85ms | 반복 | 두 번 갈라짐(세 동강) |
| machine-crystal-hit0·1·2 | 96×128 | 3 | 50ms | 한 번 | 맞을 때. 숫자는 그때의 손상 단계 |
| machine-crystal-break | 256×256 | 14 | 70ms | 한 번 | 부서질 때(7열×2행) |

- 대기·손상·맞기 칸의 pivot (48,76)은 판정 2×3u 칸의 가운데다. 판정 칸은 칸 안 x 16~80, y 28~124 이고, 그 위로 결정 끝과 빛 번짐이 1u 솟는다. 1:1 로 그린다(늘리지 않는다).
- 부서지기 칸은 결정 칸을 (80,64)에 둔 것이라 pivot 이 (128,140)이다. 부풀며 번쩍 3장 → 결정 모양 섬광 → 조각 9개가 튀어 떨어지고 잉크가 퍼졌다 사라진다.
- 손상 단계를 바꾸는 체력 문턱은 그림 쪽 제안(66%·33%)일 뿐 기획 확정이 아니다.

## 다시 뽑기

```
cd source
python export_runtime.py ../runtime
```

`crystal_v3.py`(결정·빛 쓸기), `crystal_damage_options.py`(손상 B안 `opt_B`), `crystal_states.py`(맞기·부서지기)가 그린다. Pillow·NumPy·SciPy 가 필요하다. 지금 runtime 과 바이트까지 같게 다시 나오는 것을 확인했다.
