# 둔화 이펙트 시험판

보라 잉크 무거운 발목(적중 시 2초간 이동 속도 20% 감소)이 몬스터를 느리게 할 때 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다. 지금 게임의 임시 표시(발밑 파란 링)를 대신할 후보다.

두 가지를 함께 쓴다.

1. **몸 물들임(게임에서)**: 몬스터 그림을 보라(#9a5cc8)로 40% 정도 연하게 물들인다. 어두운 몸에도 보라가 보이도록 밝기를 조금 띄운 뒤 섞었다. 이펙트 시트는 몬스터 위에 겹치는 그림이라 몸 자체를 물들일 수 없으므로, 흰 피격 번쩍임처럼 스프라이트 색으로 해야 한다. 시트 JSON의 `meta.pixelfx.bodyTint`에 값을 적어 두었다.
2. **퍼지는 물결(이 시트)**: 몸 가운데에서 보라 물결이 테가 물결치듯 일렁이며 느릿느릿 바깥으로 약 26px 퍼지고 옅어진다. 물결 셋이 엇갈려 3초에 한 번씩 퍼진다. 선 없이 반투명 번짐이고, 물결 안쪽 가장자리만 조금 밝다.

- `slow.js`: 이펙트(3초 반복). 옵션 `cy`(몸 가운데 높이, -28), `waves`(3), `strength`(1.0), `width`(3.2), `reach`(26), `shape`(`wavy` 몸 둘레 / `ground` 발밑 바닥 / `side` 양옆), `period`(비교용 속도).
- `export.mjs`: Git 제외 `outputs/pixelfx/slow/slow_purple.png/json`을 뽑는다.

```sh
node 전투테스트/둔화/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- 160×104, 25fps, 75장 반복(3초). 피벗 (80, 92) = 몬스터 발 가운데. PPU32 게임 화소 1:1.
- 둔화는 2초라 반복 한 바퀴(3초)를 다 돌기 전에 끝난다. 끝날 때 시트와 물들임을 함께 짧게(약 0.15초) 흐리게 빼는 것을 전제로 했다(미구현).
- `cy`는 가시뿌리(몸 가운데가 발 위 약 28px) 기준이다. 키가 다른 몬스터는 바꿔 뽑는다.

## 확인한 범위

1스테이지 실제 게임 캡처의 가시뿌리 위에서 렌더링으로만 봤다(물들임은 캡처 화소를 칠해 흉내 냈다). 시안 A~I 중 「몹이 보라로 덮이고 주위로 퍼지는」 방향을 고르고, 동그란 원 → 일렁이는 물결, 퍼지는 거리 60 → 26px, 1초 → 3초로 다듬었다. Unity·다른 몬스터·속박과 겹칠 때는 확인하지 않았다.
