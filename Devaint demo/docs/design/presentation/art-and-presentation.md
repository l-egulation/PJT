# 아트·모션·연출 기준

[분야 개요](README.md)

## 목적과 시각 방향

책·기록·잉크의 세계를 시각 자료와 게임 표현에 일관되게 연결한다. [초반 이야기](../story/opening/opening.md)의 기록 삭제는 완성된 색·질감이 빠지고 불완전한 선과 빈 종이로 바뀌는 현상이다. 지워진 마을은 전체가 스케치다. 주인공은 지나가던 평범한 사람으로 시작하며 크림색 후드·청록색 스카프를 착용한다. 각성 전후는 별도 제작본 없이 같은 주인공 모션에 색 바램·색 복귀로 구분한다. 깃털펜은 현행 플레이 무기·소개 설정에서 제외한다.

## 제작 원본과 적용 상태

1Stage 마을 제작 브랜치의 환경 미술은 [마을 미술 기준](../../assets/world/village/stage1-village-art-direction.md)을 따른다. 따뜻한 종이색·선과 빗금·가까울수록 많은 묘사·단순한 원경·같은 구조의 컬러 전환이 채택 범위다. 스케치 지형 내부는 종이색과 연한 빗금이며 검은 채움이나 회백색 면을 공통 스케치 규칙으로 사용하지 않는다. 정지 화풍 채택과 게임 에셋·Unity 적용은 구분한다.

## 규격과 게임 판정

전투 공통 단위는 PPU 32·루트 scale 1이다. 투명 캔버스 전체를 몸 크기로 쓰지 않는다. 플레이어 피벗·몸·피격 박스의 기준은 [전투 명세](../combat/rules.md)와 [플레이어 판정 데이터](../../../data/combat/player_hurtbox.json), 몬스터 규격은 [행동 전달 데이터](../../../data/monsters/chapter1_approved.json)를 따른다. 둘의 발 피벗을 같은 값으로 가정하지 않는다.

원본 프레임·재생 시간·자르기·피벗·반전·타격 시각을 함께 전달한다. 그림 속 무기와 이펙트를 몸 콜라이더에 포함하지 않는다. 미지원 형태의 대체 모션은 최종 승인 아트와 구분한다. 모션 교체가 피해·연계·활성 시간 변경을 자동 승인하지 않는다.

## 전투 화면 반응과 사망 슬로우

명중 VFX는 실제 수락된 타격에만 연결한다. 화면 킥·왜곡은 출력 강도를 줄이거나 끌 수 있고, 출력 조정이 피해·판정·공격 시각을 바꾸지 않는다. 큰 강타 강조의 행동 목록은 별도 확정한다.

**슬로모션은 플레이어 본인의 실제 사망 순간에만 발동한다.** 일반·엘리트·보스를 포함한 몬스터 처치에는 발동하지 않는다. 한 생명의 사망 통지를 반복해 지속시간을 연장하지 않으며, 일시정지가 우선하고 개발 리셋·출력 종료는 자기 시간 요청만 해제한다. 배율·강조 시간은 `data/combat/hit_feedback_time.json`의 시험값을 사용한다. [기술 계약](../../development/presentation/visuals/combat-hit-feedback-design.md)과 [현재 연결 범위](../../development/presentation/visuals/combat-hit-feedback-plan.md)를 함께 확인한다.

## 1챕터 플레이어 외곽선

1챕터 플레이어는 스케치 배경의 종이색·검은 선과 같은 색 구성이라 배경에 묻힌다. 이를 막기 위해 플레이어 스프라이트 바깥에 짙은 잉크색(RGB 34·28·24) 1텍셀 외곽선을 상하좌우 이웃 기준으로 두른다. 종이색 여백을 더한 2겹 외곽선은 채택하지 않았다. 외곽선은 플레이어에만 적용하며 몬스터·투사체·이펙트에는 두르지 않는다. 컬러 구간에서 외곽선을 줄이거나 끌지, 그 전환 방식은 미정이다.

## 조명·노말맵·반응형 소품

창문·랜턴·횃불과 석양 연출은 [조명 명세](lighting-and-reactive-props.md)를 따른다. 완만한 픽셀 명암, 캐릭터·몬스터까지 포함하는 초기 투영 그림자, 몸·공격에 반응하되 통행을 막지 않는 랜턴이 확정 방향이다. 노말 표면 명암·투영 그림자·발광·빛줄기를 구분하며 기존 플레이어 외곽선과 필수 공격 예고의 판독성을 유지한다.

접지 그림자: 주인공과 모든 몬스터 발밑의 땅(또는 발판) 윗면에 2px 도트 다섯 줄의 납작한 그림자를 둔다. 그림자 안의 화면 색에 0.8을 곱해 지형 색이 한 단계씩 어두워지고(크림→연회색, 연회색→중간 회색) 잔디·흙 무늬는 비친다. 공중에서는 바로 아래 땅에 남아 높을수록 좁고 옅어지며, 8칸 넘게 뜨거나 아래에 땅이 없으면, 또 죽거나 숨은 동안에는 그리지 않는다. 소품·발판에는 두지 않는다. 구현은 `Deviant.Combat.ContactShadowPresentation`(셰이더 `Deviant/ContactShadowMultiply`)이며 전투·마을·튜토리얼이 같은 아레나로 그린다.

통과 벽 가장자리: 1스테이지 전투에서 통과 발판을 받치는 옅은 흙벽(뒤 배경, 충돌 없음)은 바깥 가장자리 2px(도트 한 줄)를 몸통보다 한 단 진한 `#CCC5B7`로 칠한다. 검은 외곽선은 쓰지 않는다. 받침 벽끼리 겹쳐도 테두리는 다른 벽 안쪽에 비치지 않는다. 구현은 `Stage1CombatArt.ReplaceSoilBackwalls`가 벽마다 테두리 렌더러(셰이더 `Hidden/VirtualWallOutlineSoil`, `_Rim` 1, 정렬 한 칸 아래)와 가장자리만큼 안으로 들인 몸통 렌더러를 둔다.

[기술 설계](../../development/presentation/visuals/lighting-and-reactive-props.md)의 합성 실험장과 [에셋 제작 계약](../../assets/presentation/lighting-props.md)은 실제 아트의 노말 제작·전체 게임 통합·최종 미술 검증 완료를 뜻하지 않는다. 스케치/컬러 상태와 점등/소등은 별도 축이며 자동 연동 규칙은 정하지 않는다.

## 포장과 전달

[제작 규칙](../../workflow/asset-production.md)에 따라 제작 기준본·작업중·확정본·미리보기·공유 사본을 구분한다. 게임 적용 파일에는 대상 콘텐츠 ID, 버전, 프레임 순서·시간, PPU·피벗, 사용 위치, 패키지 해시·복원 방법, 채택 범위를 설명한다. 공통 양식은 [에셋 템플릿](../../workflow/asset-template.md)을 따른다.

이미지와 Unity 패키지·실행 빌드는 별도 ZIP 정책을 따른다. Git의 `.meta`와 원본 이미지를 함께 복원해 GUID를 보존한다. 패키지 다운로드 주소가 없는 경우 담당 제작자가 보관한 ZIP을 전달받아야 하며 존재하지 않는 공유 주소를 작성하지 않는다.

## 검증과 남은 범위

원본 해시·프레임 수 확인 → 잘라내기·피벗 확인 → 좌우·모션 전환·실제 타격 동기화 → 지형·HUD와 합성 화면 확인 순으로 본다. 미리보기 승인, Unity 임포트 성공, 실제 플레이 화면 검증을 구분한다. 최신 검 공격 원본 미확보 항목과 전체 무기 표현 교체, 최종 사운드·제품 연출 범위는 별도 확정·적용이 필요하다.

## 배경 음악

타이틀, 오프닝의 색이 있는 길과 지워짐 추격, 시작 마을, 1챕터 사냥터와 시계탑 집행자 조우, 2챕터 지하 수로와 Rose·Blue 조우, 1·2챕터 정비소에는 지정된 배경 음악을 재생한다. 곡이 바뀔 때 이전 곡은 2초에 걸쳐 페이드아웃하고 새 곡은 조용히 시작해 3초에 걸쳐 커진다(곡마다 조정 가능). 전환 도중 다시 바뀌어도 들리던 소리를 끊지 않고 그 음량에서 줄이며, 씬 로드 정지 뒤에도 음량이 한꺼번에 뛰지 않는다. 곡의 반복 경계는 최대 2초 겹침으로 연결한다. 오프닝 길 음악은 조사 수첩이 닫히고 이동 튜토리얼이 시작되면 끊김 없이 60% 음량으로 낮아져 지워짐 컷신까지 이어진다. 긴장된 지워짐 음악은 색이 빠지기 시작하는 컷신(`erasure-begin`)과 함께 시작한다. 지워짐 추격 음악은 전선이 우물에 닿을 때 페이드아웃하고 각성 후 시작 마을 음악으로 이어진다. 정비소 방에 들어가면 필드곡을 페이드아웃하고 차분한 정비소 곡으로 바꾸며, 나가면 필드곡으로 돌아간다. 현재 정비소 곡은 제작 중인 곡이 오기 전까지 쓰는 임시 대체곡이다. 1챕터 사냥터는 〈Village Patrol〉의 인트로를 한 번 재생하고 본편을 반복한다. 시계탑 조우 중에는 보스 음악을 우선하고, 조우가 끝나면 사냥터 음악으로 돌아간다. 2챕터는 수로에서 〈damp metallic tension〉, Rose·Blue 등장부터 조우 종료까지 〈Duel of Shadows〉를 재생한다. 전투 페이즈가 바뀌어도 곡은 이어지고, 수로에서 보스를 처치하면 필드곡으로 돌아간다. 보스전(1챕터 시계탑 집행자·2챕터 Rose·Blue) 중 사망하면 어두운 종소리(〈game over dark bell chime〉)를 한 번 울리고 음악을 정적까지 페이드아웃하며, 씬이 바뀔 때까지 필드곡으로 돌아가지 않는다. 사망 또는 2챕터 클리어 정산에는 음악을 페이드아웃한다. 음악은 메뉴 정지·타격 정지·슬로모션에 따라 속도가 바뀌지 않는다.
