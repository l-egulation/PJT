# 회복 이펙트 시험판

초록 잉크 회복 파츠 3종(생명 회수·파열의 생기·사냥의 회복)이 플레이어 체력을 회복할 때 함께 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다.

[이동 속도](../이동속도/README.md)와 같은 빛나는 선 방식의 [pixelfx](https://github.com/patch-gg/pixelfx)(MIT) 이펙트다. 발밑에 빛 고리가 생겨 몸을 훑고 가슴 높이까지 올라가며 좁아지고, 고리를 따라 얇은 줄기 넷이 처음부터 끝까지 같은 굵기로 솟아 빠져나간다. 고리 뒤쪽 반은 몸 뒤로 가는 쪽이라 연하게 그린다.

- `heal.js`: 이펙트(0.64초). 줄기는 `../이동속도/speed-trail.js`의 `glowLine`을 고른 굵기(`uniform`)로 쓴다.
- `export.mjs`: Git 제외 `outputs/pixelfx/heal/heal_green.png/json`을 뽑는다.

```sh
node 전투테스트/회복/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- 72×112, 25fps, 17장(마지막은 빈 장). 피벗 (36, 100) = 플레이어 발 가운데. 좌우 대칭이라 반전하지 않아도 된다. PPU32 게임 화소 1:1.
- 초록 팔레트는 임시값이다. 생명 회수는 적중마다 터지므로 작은 판이 필요할 수 있다(미정).

## 확인한 범위

1스테이지 실제 게임 캡처의 플레이어 위에서 렌더링으로만 봤다. 시안 셋(솟는 빛줄기·떠오르는 빛 방울·올라가는 고리)과 무릎 높이 고정 고리를 비교해 사용자가 올라가는 고리를 골랐다. Unity·연속 회복은 확인하지 않았다.
