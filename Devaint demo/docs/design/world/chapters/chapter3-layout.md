# 3챕터 성채 진입 맵 초안

[분야 개요](README.md)

HTML에서 검토하고 수정하는 맵 설계 초안이다. Unity 씬·맵 생성기·런 전환에는 아직 연결하지 않는다. [편집기 실행과 검증](../../../development/tools/stage3-map-editor.md)을 따른다.

## 공간의 역할

2스테이지 지하수로에서 성채 외곽으로 올라와 덮인 정원 회랑과 경비 구역을 지나 안쪽 작업동으로 들어간다. 중반에는 경비 회랑의 위층으로 올라가고, 후반에는 기록 운반용 낮은 통로로 내려간다. 끝의 기록 반입장 관문은 후속 4스테이지 기록·잉크 정제시설의 반입실로 이어지는 자리다. 최종 도서관은 후속 5스테이지의 구상이며 이 맵에 포함하지 않는다.

| 구간 | 공간 | 주 경로의 이동 |
|---|---|---|
| 외곽 정원 | 수로 출구 S, 덮인 정원 회랑 F01, 외곽 경비실 F02 | 넓은 바닥과 낮은 단차로 가로 진행 |
| 경비 구역 | 성벽 계단실 F03, 경비 휴게실 M, 복층 경비 회랑 F04 | 계단실에서 중층으로, 복층 회랑에서 위층으로 이동 |
| 작업동 접근 | 안쪽 운반 계단 F05, 기록 운반 통로 F06, 기록 반입장 관문 B | 낮은 운반 길로 내려와 작업동 관문에 도달 |

## 방과 연결

- 일반 전투방 8개와 시작·정비소·엘리트·보스 각 1개로 총 12방이다. 방 수와 적·보상 배치는 조정 가능한 초안이다.
- 주 경로는 `S → F01 → F02 → F03 → M → F04 → F05 → F06 → B`다. 일반 전투방은 6개다.
- 선택 갈래 `M → F07 위층 경비탑 → F04`와 `F05 → F08 작업동 보관실 → F06`은 앞쪽 주 경로로 다시 합류한다.
- 엘리트방 E는 F07 옆의 막다른 갈래다. 2챕터 전용 엘리트의 챕터 전체 추격을 승계하지 않는다.
- 연결은 양방향이며 일반방 섬멸로 통행을 잠그지 않는다. M에는 일반 적을 두지 않으며, F06의 평평한 바닥에 잉크 충전소 위치 후보를 둔다.
- B의 안쪽 폭은 30u다. 보스·제단·출구는 위치 후보이며 활성 조건과 전투는 HTML에서 실행하지 않는다.

## 편집 원본과 공통 규격

기본 초안 원본은 `tools/map/stage3-editor/map-core.js`의 `seed()`다. 같은 폴더의 `기본맵.json`과 `3챕터_맵편집기.html`은 `node tools/map/stage3-editor/build.cjs`로 생성한다. 편집기에서 바꾼 배치는 별도의 JSON으로 내려받고 다시 불러온다. 브라우저 자동 저장은 소스 파일이나 기본 초안을 덮어쓰지 않는다.

[방·통로 공통 규격](../room-corridor-standard.md)의 1u=32px, 16×12u 조립 블록, 고체 2u 이상, 직결 우선과 통로 최대 1블록을 따른다. 편집 좌표는 왼쪽 위가 원점이며 Y는 아래로 증가한다. 하향 통과 발판의 시험 두께는 0.5u다. 출입구·연결 디딤은 연결 데이터에서 생성한다. 출입구가 어긋난 연결은 경고선으로 표시하고 벽을 열지 않는다.

배경의 아치·깃발·식물·문서 상자는 구간을 구분하는 코드 기반 참고 표현이다. 실제 게임 아트의 제작·승인을 뜻하지 않는다. 적과 보상은 배치 후보이며 종류·수치·개수와 최종 전투 동선은 미정이다. 간이 이동 테스트와 정적 배치 검사는 Unity 전체 경로 완주·카메라·전투 검증과 구분한다.
