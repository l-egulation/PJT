# 게임 테스트 환경

[분야 개요](README.md)

Unity Hub에서 이 저장소의 `unity` 프로젝트를 **Unity 6000.6.5f1**로 연다. `Tools > deviant > Testing > Play Game Sandbox`를 누르면 실제 1챕터에 테스트 설정창이 열린다. Project 창에서 `Assets/Deviant/Playtest/Scenes/GameSandbox.unity`를 열어 Play해도 된다. `Open Game Sandbox`는 씬만 연다.

팀원은 `main`을 pull한 뒤 `Play Game Sandbox`를 실행한다. 메뉴는 현재 배치 계약을 검사하고, 누락되거나 갱신이 필요한 에셋이 있으면 고정된 `resources` 커밋을 받아 Git LFS를 복원한 뒤 Unity에 배치한다. 첫 실행에는 Python 3.9 이상(`python` 명령), Git LFS 및 GitLab 리소스 읽기 권한이 필요하다. 원격 리소스가 필요할 때는 GitLab에 미리 로그인한다. 이미 배치된 파일이 계약과 일치하면 다운로드를 건너뛴다. 씬을 직접 열고 Play하는 경우에는 배치가 끝난 상태여야 한다.

테스트 진입 씬은 새 맵이나 전투 구현을 갖지 않는다. 현행 `Chapter1Procedural`과 `Chapter2Procedural`의 맵·적·보스·정비소·공통 GUI를 사용한다. 에디터/개발 환경 전용이며 일반 게임 빌드의 진입 씬 목록은 바꾸지 않는다. 일반 플레이로 돌아가려면 Play를 종료하고 `Tools > deviant > Game > Play Common Game`을 사용한다.

## 조작

- **F3 / 테스트 설정 열기**: 전투를 멈추고 설정한다. 닫으면 전투를 재개한다. 다른 화면이 정지시켰다면 그 화면의 정지도 닫아야 한다.
- **장비 · 런 잉크**: 무기 1/2 각각 검·둔기·원거리의 형태와 스킬을 자유 선택한다. 형태 변경 시 기본 스킬로 돌아가며 기존 팔레트 구성은 유지한다.
- **잉크**: 본게임과 같은 `RunInks` 카탈로그 39종을 이름/색상으로 찾아 선택한 칸에 바로 장착한다. 이름·설명·효과·수치·장착본별 쿨타임은 본게임의 `SketchEquipment`·`CombatArena.RunInks`를 사용한다. 골드·보유·도감 등록 여부와 관계없이 교체/해제한다.
- **팔레트**: 기본 3칸이며 1~6칸을 선택한다. 선택한 칸의 색을 무색·빨강·노랑·초록·파랑·보라로 변경한다. 잉크와 칸 색이 같으면 색상 강화 효과, 다르면 기본 효과를 사용한다. 테스트 편집에서는 칸별 색을 자유롭게 지정한다. 칸 수를 줄이면 뒤쪽 칸의 잉크가 사라진다. 같은 잉크의 색만 바꿀 때 장착본과 남은 쿨타임은 유지하고, 다른 잉크로 바꾸거나 비우면 해당 칸의 쿨타임을 초기화한다.
- **전투 수치**: 공통 공격 강화는 현재 카탈로그의 최대 단계까지 비용 없이 증감한다. 잉크의 구형 +0~+5 강화는 사용하지 않는다. 피해 배율·공속·쿨타임은 무기별 독립이다. 최대 HP 변경은 체력도 회복한다.
- **방 바로 이동**: 1·2챕터별 시작방·엘리트·정비소·보스방 바로가기와 현재 챕터의 모든 방 목록을 제공한다. 다른 챕터의 일반 방은 그 챕터 시작방으로 간 뒤 목록에서 고른다.
- **F5 / 현재 방 다시 시작**: 현재 방을 새 전투로 재시작한다. 사망/보스전 이후에도 사용할 수 있다.

| 직접 입력값 | 테스트 범위 |
|---|---|
| 기본 / 스킬 피해 배율 | 0~1000, 원본·잉크·강화에 추가 곱셈 |
| 추가 기본 공격속도 배율 | 0.05~20, 무기별 시험 기본 공속에 추가 곱셈 |
| 스킬 쿨타임 | -1은 원본·쿨감 사용, 0~3600초는 지정 간격 |
| 최대 HP | 1~1,000,000 |

이 범위는 테스트 도구의 입력 범위이며 제품 밸런스를 확정하지 않는다. 발사기의 스킬/강화 예외도 원래 전투 규칙을 따른다. 비정상 숫자와 범위 밖 값은 적용하지 않는다.

## 상태와 이동

방 이동은 해당 챕터 씬을 새로 로드해 적·기계·보스 페이즈·투사체·결과 화면·출입문을 초기화한다. 두 무기의 형태·스킬·잉크·팔레트 색상·공통 공격 강화·수치·최대 HP 설정을 복원하고 체력을 회복한다. 챕터별 고정 seed를 사용하므로 이번 실행에서 보던 방 번호를 다시 선택할 수 있다. 처치 수·바닥 보상·가방·골드·잉크 발동 중첩과 쿨타임 등은 새 전투 상태다.

설정은 실행 중 메모리에만 유지한다. Play 종료 후 다시 실행하면 검/망치, 각 3칸 빈 무색 팔레트, 공통 공격 강화 0, 기본 배율, HP 100으로 시작한다. 일반 프로필의 해금·마법안료·진행 상황에 쓰지 않는다. 테스트 창의 편집 명령은 명시적으로 생성한 테스트용 성장 데이터(`IsSandbox`)만 받으며 일반 런에서는 거절한다.

테스트 창은 본게임의 `SketchEquipment`를 장비 소유자로 사용하고 디버그 편집 API를 통해 무기·팔레트를 변경한 뒤 `SyncSketchLoadout`으로 실제 전투 장비를 갱신한다. `SketchRunBinding`의 일반 런 진행·보상 화면은 연결하지 않는다. 구형 `WeaponGrowthMvp`는 공통 공격 배율 시험용 성장 정보로만 남으며 테스트 잉크 목록·슬롯 강화·잉크 효과에는 사용하지 않는다.

## 검증

`Deviant.Playtest.Tests`는 최신 39종의 기본·강화 수치, 장착본/쿨타임 보존, 1~6칸, 구형 ID·잘못된 색상·일반 런 편집 거부를 검사한다. 실제 씬에서는 두 무기 장착, 다음 프레임의 형태/스킬 유지, 설정 종료·챕터 이동·재시작 후 복원과 실제 기본 공격으로 발동하는 기절 잉크의 기본·강화 지속시간을 검사한다. 두 챕터의 모든 방 이동·보스방 이탈 검사도 제공한다. 그래픽 장치가 있는 Unity 6000.6.5f1 검증 사본에서 EditMode 테스트로 실행한다.

## 보스 페이즈 이동

Tools → deviant → Testing → Play Game Sandbox에서 F3 설정 창의 방 이동 탭을 열고 ‘2챕터 보스 페이즈’의 1·2·3페이즈 바로 시작 버튼을 사용한다. 무기·잉크·강화·직접 입력 수치를 유지하며 새 보스 전투의 선택 페이즈로 진입한다. 현재 방 다시 시작과 F5는 선택한 페이즈를 다시 시작한다. 일반 방으로 이동하면 페이즈 지정이 해제된다.
