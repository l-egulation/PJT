# 몬스터 기획과 구현 경계

[분야 개요](README.md)

## 목적과 원본

2스테이지 잉크 도시 아래 지하수로는 [일반·엘리트 공격과 남매 보스 기획](../chapter2/normal/stage2-waterway-monsters.md)을 따른다. 일반 3근거리·2원거리의 확정 수치·판정·공격 시간은 [Unity 본 게임 전투](../../../development/testing/stage2-unity-validation.md)에 연결한다. 엘리트의 핵심 공격과 적용 범위는 별도 명세를 따른다. 남매는 석궁 전방·원거리 잉크술 후방의 교대 방향이며 세부 밸런스는 미정이다. [8명 정지 픽셀 기본본과 모션 제작 기준](../../../development/presentation/visuals/stage2-monster-idle-study.md)을 사용한다. 기본자세·제한 팔레트·에테르 입력을 준비했으며 현재는 대기 아트를 검토한다. 기존 생성 대기 루프는 제작 기준에서 제외한다. 8명의 상체·장비가 함께 들썩이고 발을 고정하는 몸통 호흡 대기 시안이 있으며(수의는 전체 부유), 일반5종의 대기·이동·공격과 검토 효과는 사용자 승인되었다. 승인 패키지는 [승인 목록](../../../../data/presentation/stage2_normal_assets_approved.json)을 따른다. 엘리트·보스 모션과 게임 적용은 별도다.

1챕터 몬스터의 역할·모션·판정·행동을 같은 대상으로 연결한다. 1챕터는 마을 기존 몬스터 4종·신규 일반 몬스터 프로토타입 2종과 시계탑 보스를 사용한다. 픽셀·프레임·시간의 원본은 `resources/authoring/workbench/source/MonsterReference/approved/manifest.json`과 승인 프레임, 전투 수치의 편집 원본은 [stage1_village_monsters.json](../../../../data/combat/stage1_village_monsters.json)이다. 적용 방법은 [1스테이지 몬스터 모션](../../../development/presentation/visuals/stage1-monster-motions.md)을 따른다. 프레임별 수치와 판정 좌표를 이 문서에 복제하지 않는다.

이전 들판 6종(들쥐·두더지·멧돼지·허수아비·짚단·두레박) 기획은 폐기했다. 1챕터 배치·보상·밸런스의 기준으로 사용하지 않는다. 이미 제작된 아트·제작 원본은 [에셋 제작 기준](../../../workflow/asset-production.md)에 따라 별도로 보존한다.

일반 3종과 엘리트의 공격 형태·수치는 플레이테스트용 1차 값이다. 1챕터 랜덤 스테이지 보스방은 사용자 결정에 따라 고정형 시계탑 집행자 전투를 사용한다. 최대 체력은 18000이며 긴 주먹·시계침·믹서기·사슬 긋기 패턴을 사용한다. 누적 피해 1285(남은 HP 16715)에서 2페이즈, HP 1800 이하에서 최종 광폭으로 전환한다(원본 `data/combat/clock_executioner_timing.json`의 `maxHealth`, `enrageDamage`, `finalPhaseHealth`). 시간표와 연출은 [고정형 보스 제작 명세](../../../development/presentation/visuals/clock-executioner-sprites.md)를 따르며, 그림은 HTML 시안 부품이고 승인 모션이 아니다. 승인 모션이 들어오기 전에는 없는 모션을 다른 그림으로 대체해 제작 완료로 처리하지 않는다. 보스·엘리트·일반 몬스터의 처치 보상은 [성장·경제](../../run/progression-and-economy.md)를 따른다.

시계탑 집행자는 하나의 체력을 공유하며, 페이즈 전환 때 회복하지 않는다.

| 페이즈 | 남은 체력 구간 | 해당 구간에서 소모하는 체력 |
|---|---|---:|
| 1페이즈 | 18000 → 16715 | 1285 |
| 2페이즈 | 16715 → 1800 | 14915 |
| 3페이즈 | 1800 → 0 | 1800 |

보스 기절의 목표 규칙은 [공통 전투 명세](../../combat/rules.md#보스의-기절-상태와-패턴)를 따른다. 기절 시간은 부여되지만 패턴은 멈추거나 취소되지 않는다. 아래 연결된 기존 보스 구현·검증 설명과 새 규칙 이행 여부를 구분한다.

| 시계침 | 방향 무관 | 없음 |

## 엘리트 수문장 전투

`Open Random Stage`의 `Chapter1Procedural`에서 우물 도르래 수문장의 체력은 3000이다. 공격 시작 시 대상이 기존 할퀴기 판정 안에 있고 지형에 가리지 않으면 갈고리를 생략하고 승인 공격의 후반 16장(1.23초)을 바로 재생한다. 즉시 피해를 주는 것은 아니며, 할퀴기 시작 후 0.64~0.81초에 기본 피해 40을 한 번 적용한다. 이 근접 공격은 갈고리 포획을 요구하지 않으며 대상이 회피하면 빗나간다.

근접 조건 밖에서는 기존 갈고리 연계를 1.5배속으로 사용한다. 본체·포획·회수·끌어오기·할퀴기·FX가 같은 시간 변환을 사용하며 전체 2.83초는 약 1.887초가 된다. 갈고리를 빗맞히면 후속 할퀴기 모션은 재생하되 피해를 주지 않는다. 기존 3.8초 공격 간격과 승인 이미지·원본 프레임 시간은 유지한다.

잉크 잠행은 기존 구현을 사용한다. 근접 할퀴기를 우선하고, 근접 조건 밖에서 첫 공격 이후 쿨타임·안전 지면 조건을 만족하면 잠행한다. 녹기 0.55초, 1.55초 위치 고정, 0.55초 지면 예고, 2.10~2.28초 단일 분출 피해, 쿨타임 8초는 갈고리 배속에 영향을 받지 않는다. 최종 전투 밸런스와 전체 맵·무기 조합 검증은 별도다.

수문장의 할퀴기·잠행 분출에 맞은 플레이어는 피해만 받고 피격 경직(입력 잠금)과 밀려남이 없다(원본 `noPlayerHitReaction: true`). 갈고리 끌어오기는 별개 동작으로 유지한다. 엘리트는 일반 피격 경직에 면역이다. 피해·흰 점멸·파편·밀려남은 적용되지만 일반 피격으로 이동·갈고리·할퀴기·잠행 준비를 멈추거나 피격 자세로 전환하지 않는다. 별도 기절·속박·명시적 공격 취소와 사망 처리는 유지한다. 일반 3종의 경직 규칙은 바꾸지 않는다. 원본은 엘리트의 `hitStaggerImmune: true`이며 개체 정의로 내보낸다.

## 신규 일반 몬스터 전투 프로토타입

술통 포격수와 맷돌 돌진체는 승인 네이티브 공격 그림과 코드 이동을 사용하는 일반 몬스터다. 전투 원본은 `data/combat/chapter1_new_monsters.json`, 미술 원본은 `resources/monsters/stage-01/normal/{barrel-gunner,millstone-charger}/`다. 술통은 본체 67장·증기 분출·별도 잉크탄·착탄·붉은 폭탄 전조, 맷돌은 굴림 8장·흰 충격파를 사용한다. 별도 피격·죽음 모션은 아직 없다. 기존 개별 기본 PNG도 보존한다.

| 항목 | 술통 포격수 | 맷돌 돌진체 |
|---|---|---|
| 체력 / 기본 피해 | 230 / 15 | 390 / 20 |
| 최초 감지 | 직선거리 24유닛 | 직선거리 12유닛. 벽·발판이 시선을 가리면 발견하지 않는다(2026-11-13 사용자 결정) |
| 일반 이동 | 고정. 피격·넉백·밀치기에도 위치가 바뀌지 않는다 | 초당 1.5유닛 접근. 감지 후 끝까지 추격(아래 [근접 이동형 끝까지 추격](#근접-이동형-끝까지-추격)) |
| 공격 시작 | 감지 조건과 유효 발밑 지면 필요 | 가로 12유닛·발 높이차 2유닛 이내 |
| 준비·전조 | 1.5초 부풀기 후 발사하며 1.3초 폭탄 전조. 발사 때 위치 고정 | 2초. 1.8초 점점 강해지는 작은 떨림 후 0.2초 정지. 시작 시 좌우 방향 고정 |
| 발동 | 수직 상승 0.36초·화면 밖 0.46초·고정 지점 수직 낙하 0.48초 뒤 표면 위 2×2유닛 착탄 피해 | 초당 12유닛으로 최대 가로 12유닛 이동 |
| 종료 후 대기 | 폭발 후 2초 | 돌진 종료 후 3초 |

포탄 비행은 연출이며 지형을 통과한다. 착탄 순간 대상당 한 번만 적중하고 비행 중 접촉 피해·잔류 피해는 없다. 반투명 붉은 폭탄 이미지의 표시 영역은 판정 박스와 같은 2×2유닛(64×64px)이며 캐릭터와 겹쳐도 보인다. 둥근 그림이 사각 피해 판정을 원형으로 바꾸지는 않는다. 첫 준비 전에 개체별 0~1.5초 지연을 사용하며 이후 독립적으로 공격하고 경고 중첩을 허용한다. 포격수가 죽으면 미폭발 경고·포탄을 취소한다.

돌진은 플레이어를 지나쳐 계속되며 같은 실행은 대상당 한 번만 적중한다. 벽에서 정지한다. 절벽은 떨어진 곳에서 원래 발판으로 돌아올 경로가 있을 때만 낙하하며 계속 돌진하고, 없으면 모서리에서 멈춰 돌진을 끝낸다(짧은 돌진). 통로와 이웃 방에서도 거리·지형 조건에 따라 접근과 공격을 계속한다. 감지 상실 시 진행 중 공격은 마친 뒤 새 공격을 멈추고 안전한 교전 지면에서 대기하며 체력을 자동 회복하지 않는다.

전조·공격 중 일반 피격 경직은 면역이며 공격을 계속한다. 맷돌의 돌진에 맞은 플레이어는 돌진 방향으로 초당 13칸, 0.45초 동안 밀려나며 위로 초당 11칸 튀어 날아간다(`data/combat/chapter1_new_monsters.json`의 `playerLaunchSpeed`·`playerLaunchSeconds`·`playerLaunchUp`). 맷돌은 넉백을 받고, 술통은 몬스터 정의의 `immovable`로 언제나 제자리에 고정된다(피격 번쩍임 같은 제자리 연출은 유지). 별도 기절·빙결 등 행동불가는 공격을 취소하고 해제 후 정해진 공격 대기를 적용한다. 몸·피격·돌진 판정은 핵심 몸체에 맞추며 투명 여백과 장식을 제외한다. 플레이어 피격 경직·무적·넉백 크기는 기존 공통 규칙을 사용하고, 폭발은 폭심 바깥쪽·돌진은 진행 방향으로 밀친다. 몬스터가 플레이어에게 주는 피해는 추가 변동 없이 기본값 100%를 사용하고 정수로 표시하며 일반 몬스터 보상을 따른다.

선택 방 원본은 `data/combat/chapter1_selected_rooms.json`이다. 사용자 편집본의 17개 유지 방을 보존하고 전투 후보 12개를 생성한다. 三자 열린 누각·엇갈린 처마길·세 마당 돌문길은 제외하고 두물길 둑다리를 포함한다. 실제 통합 검증 범위는 실행 결과와 구별한다.

현재 일반·엘리트의 기본 피해는 가시뿌리 16, 먹빗자루 20, 배수관 포수 20, 술통 포격수 30, 맷돌 돌진체 40, 우물 도르래 수문장 40이다(2026-11-16 사용자 결정). 수문장의 할퀴기와 잠행 분출은 같은 수치를 사용한다. 최대 체력은 각각 230·220·230·230·390·3000이며 보스 최대 체력은 18000이다(엘리트·보스 체력은 2026-11-16 사용자 결정). 패턴 피해는 기존 값을 유지한다.

맷돌은 체력이 절반을 지나도 진행 중인 전조·돌진을 이어간다.

## 공통 행동과 판정

- 몸은 지형과 충돌하고 캐릭터끼리는 통과한다. 몸 접촉 자체의 피해는 없다.
- 몸과 피격 영역을 분리하고 모션마다 기하를 임의로 바꾸지 않는다. 공격 실행·타격번호·대상으로 중복 적중을 막는다.
- 감지, 추적, 공격 준비·발동·회복, 피격, 사망을 구분한다. 개별 조건·시간·박스는 구조화 데이터를 따른다.
- 감지 시야의 발판 차폐와 일반 근접 공격의 발판 비차폐는 서로 다른 규칙이다.
- 종별 애니메이션 제작 완료는 AI·이동·공격판정 구현 완료가 아니다.

### 근접 이동형 끝까지 추격

일반 몬스터가 플레이어 쪽으로 방향을 정할 때는 발 기준 위치(root)의 X 차이를 사용한다. 좌우 차이가 4도트(32px/u 기준 0.125u) 이내이면 현재 방향을 유지하고, 같은 발판 직접 접근이나 경로 없는 접근에서도 이 폭 안의 미세 이동을 멈춘다. 플레이어가 위아래에 있어도 같은 규칙이다. 발판 경로를 따라 도약 지점으로 이동하거나 복귀할 때는 실제 이동 방향을 바라보며, 공격의 기존 방향 고정·추적 시점은 유지한다. 기준값은 `enemy_pursuit.json`의 `targetFacingDeadzone`이다.

2026-11-11 사용자 결정. 근접 이동형(가시뿌리·먹빗자루·맷돌 돌진체·2챕터 K4·B3·M3)은 한 번 감지하면 시야와 무관하게 대상의 현재 위치를 알고 따라간다. 거리 기준 생성 위치 목줄·마지막 목격 위치 대기와 2챕터의 생성 바닥 영역 제한을 쓰지 않고, 아래 화면 이탈 규칙으로만 추격을 멈춘다. 추격 중 이동속도는 종별 기존 이동속도에 공통 배율(현재 2.4배)을 곱한다. 지형은 발판 윗면 구간 그래프로 보고 점프·일방 발판 하향점프·절벽 낙하로 대상이 있는 발판까지 경로를 찾는다. 점프 최대 높이는 상한이며 실제로는 각 경로에 필요한 만큼만 뛴다. 경로상 점프·하향점프는 도약 지점에서 무작위 시간만큼 멈춰 기다린 뒤 진행한다. 추격하며 걷는 중에는 무작위 간격·무작위 높이로 깡충 뛴다. 공격 사거리 안, 착지 지점이 현재 발판 밖, 천장이 최소 높이보다 낮을 때는 뛰지 않는다. 도달할 수 없으면 도달 가능한 발판 중 대상과 가장 가까운 곳에서 기다린다.

근접 이동형은 개체마다 추격 속도와 점프 준비 시간이 ±10% 안에서 다르다. 감지하면 대상 쪽을 보고 머리 위에 "!"를 띄운 채 개체별 반응 시간만큼 멈췄다가 추격한다. 처음 발견한 몬스터는 반경 안의 다른 몬스터에게 시야와 무관하게 경보를 한 단계만 전한다. 받은 몬스터는 발견자와 가까운 순으로 거리에 비례해 늦게 "!"를 띄우고 같은 반응을 거쳐 움직인다(다시 퍼뜨리지 않는다). 경보는 근접 6종과 원거리 이동형(배수관 포수·R·H3)이 받고 술통 포격수는 받지 않는다. 이 규칙은 공통 감지 원본의 `alertPropagation: false`보다 우선한다. 2챕터 일반 몬스터(K4·B3·M3·R·H3)는 2026-11-13 사용자 결정에 따라 발견을 자기 소유 방 안에서만 한다. 몬스터가 화면 안에 있고, 대상이 같은 방에 있으며, 종별 감지 거리·높이 안에서 벽·발판에 가리지 않을 때만 직접 발견하고, 경보도 대상이 받는 몬스터의 소유 방 안에 있을 때만 받는다. 발견 전의 근접 이동형은 대상 쪽으로 다가가거나 경로를 찾지 않고 제자리에 있는다. 한 번 발견한 뒤의 추격은 위 규칙대로 방과 시야에 관계없이 이어진다. 개체 편차·반응·경보 지연·무작위 점프는 스테이지 생성 시드와 종 ID·생성 위치로 정해 같은 시드에서는 항상 같다. "!"는 승인 아트 전의 임시 코드 그림이다. 공격 판정·대기 시간은 바꾸지 않으며 점프·낙하 경로를 이동하는 중에는 공격을 시작하지 않는다. 가시뿌리와 맷돌의 돌진은 같은 짧은 돌진 규칙을 쓴다. 벽이나 돌아올 경로가 없는 절벽 모서리에서 멈추고, 돌아올 경로가 있는 절벽에서는 떨어지며 계속 돌진한다. 가시뿌리는 이전의 "돌진 거리 전체가 평평한 바닥일 때만 시작" 조건 없이 공간이 짧아도 돌진하며, 멈춘 뒤 남은 공격 시간은 제자리에서 진행한다. B3 돌진은 기존대로 모든 절벽 앞에서 멈춘다. 대상이 은신 중이면 위치를 새로 갱신하지 않는다.

2026-11-12 사용자 결정(화면 이탈 복귀). 추격 중인 근접 이동형의 몸 상자가 게임 화면(카메라 사각형)을 완전히 벗어난 채 1초가 지나면 추격을 멈추고 생성 위치로 돌아간다. 화면 밖에서 감지·경보로 추격을 시작한 개체는 화면에 한 번 들어온 뒤부터 판정하고, 6초 안에 화면에 들어오지 못하면 그때 포기한다. 공격 중·점프·낙하 중에는 포기하지 않는다. 복귀는 같은 경로 규칙으로 평소 이동속도로 걸으며 무작위 점프는 하지 않는다. 복귀가 10초를 넘거나 길이 없어 1초 동안 서 있으면, 자신과 생성 위치가 모두 화면 밖일 때만 생성 위치로 순간이동한다. 체력은 회복하지 않는다. 복귀 중에는 화면 안에서 대상을 다시 감지할 때만 "!" 반응부터 다시 추격하고, 연쇄 경보는 받지 않는다. 도착하면 감지 전 상태로 돌아가 다음 감지 때 "!"를 다시 띄운다. 1·6·10·1초는 조정기 시험값이다.

원거리 이동형(배수관 포수·R·H3)과 고정형(술통 포격수)은 기존 이동 규칙을 유지하고 사정범위만 넓힌다. 조정기에서 정한 값을 종별 원본에 반영했다: 배수관 포수 공격 시작 7→10.5유닛, R 10→20유닛, H3 11→22유닛(2챕터는 감지 거리도 같은 값), 술통 포격수 감지·포격 16→24유닛. 시험 단계 값이며 최종 밸런스는 별도다.

수치 원본은 [enemy_pursuit.json](../../../../data/combat/enemy_pursuit.json)(`tuning-draft`)이며 [추격 조정기](../../../../tools/combat/monster_pursuit_tuner/index.html)에서 같은 규칙으로 시험한다. 구현은 축 정렬 상자 지형(`ArenaSurface` 상자 충돌체)만 경로에 넣고 타일맵·회전 지형은 제외한다. 실제 맵 통합 검증은 별도다.

일반 적 피격 경직의 기존 문서 간 불일치는 [미정·충돌 목록](../../../overview/open-questions.md)에 명시한다. 새 수치를 이 문서에서 결정하지 않는다.

## 배치

전투방 12개 원형에는 각각 18마리(S1-05는 15마리)를 둔다. 랜덤 스테이지의 전투방에는 기존 일반 3종과 신규 일반 몬스터 프로토타입 2종을 편집본에 따라 배치하고, 엘리트방에는 우물 도르래 수문장 한 마리만 둔다. 최종 보스방에는 시계탑 집행자를 둔다. 기존 일반 3종은 감지 전 생성 위치 주변에서 무작위 보행·대기를 반복하고 벽과 절벽으로 나가지 않는다. 포격수는 지정 위치에서 대기하며 돌진체는 감지 후 끝까지 추격한다. 감지 시 종별 추격·공격으로 전환한다. 공간 규칙은 [런 구조](../../run/run-structure.md)를 따른다.

## 전달·확인 항목

종별 ID, 행동 데이터 버전, 원본 이미지 패키지와 해시, 프레임 순서·시간, 발 피벗, 몸·피격·공격 박스, 좌우 반전, 실제 타격 시각, 지형별 이동 가능 범위를 확인한다. 대기·추적·벽 차폐·공격 취소·피격·사망·복귀를 실제 씬에서 확인한 뒤 검증 범위를 기록한다. 전체 명세 준수 여부를 이미지 미리보기만으로 판정하지 않는다.

## 중복 잉크 빌드의 체력 시험값

일반몹은 검 기본 피해 65·영구 성장 및 강화 슬롯 없음으로 비교한다. 작은 일반몹 HP 220·230은 무강화 4타, 맷돌 HP 390은 6타다. 상태 공급 1개 + 대응 빨강 3개(+90%)가 활성화되면 기준 피해 123.5로 각각 2타·4타다. 실제 피해 변동 90~110%와 공격 종류에 따라 타수는 달라질 수 있다. 엘리트 HP 1170는 큰 일반몹의 3배다.

첫 보스 HP는 2026-11-16 사용자 결정으로 9000에서 18000으로 올렸다. 동일 집중 조합의 검 연속 기본 DPS 약 352.9과 공격 가능 비중 60%를 가정하면 약 85초다. 혼합 조합(상태 1·빨강 1·생존 2)의 빨강 공백과 회피를 포함한 1~2분 목표는 플레이로 확인한다. 페이즈 HP 비율은 대체로 유지하고 패턴을 반드시 보여 주기 위한 최소 생존 시간은 추가하지 않는다. 실제 스킬 사용·거리·숙련·패턴 전환 대기 검증 전의 수치다.

현재 종별 보상 기여값을 유지하도록 HP 등급 경계를 45·78로 조정한다. 먹빗자루는 4, 가시뿌리·포수·포격수는 5, 맷돌은 8을 유지하고 엘리트는 보상 하나를 적립한다.
