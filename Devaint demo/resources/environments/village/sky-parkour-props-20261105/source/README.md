# 마을 파쿠르 에셋

마을 스케치 화풍의 투명 PNG 24장이다. png 폴더에 게임용 그림, source 폴더에 내장 imagegen 생성 원본과 프롬프트, parkour-native.png에 1배 비교를 넣었다.

- 뜬 돌: 32·64·96px 폭. 풀·덩굴이 있는 판과 없는 판 각각 3장. 캔버스 높이는 64px이며 발판 아래 투명 여백을 포함한다.
- 무너지는 돌: 64×64. crumbling-00은 갈라진 기본형, 01~05는 흔들림·파손 진행 순서다.
- 움직이는 발판: 밧줄 목판 64×96·96×96. 밧줄의 상단 여백을 포함한다. 발판 이동은 코드에서 처리한다.
- 화살 장치: 24×32, 좌·우 각각 4장. 00은 평소, 01~03은 장전 중 밝아지는 순서다.
- 화살: 35×9, 좌·우 한 장씩. 동일 그림을 반전해 방향을 맞췄다.
- 기본 사용 배율은 32 PPU, Point 필터. 각 PNG는 독립 그림이며 새 큰 크기가 필요하면 새 픽셀 크기에 맞춰 제작한다.
- 미술 시안이며 Unity 맵의 배치·충돌·이동·발사 동작은 포함하지 않는다.
