# 공통 게임과 제작 자료

게임 실행은 [Unity 공통 게임](../docs/getting-started/playtest.md)을 사용한다. 이 폴더에는 별도 이동·공격·HP 구현을 두지 않는다.

- `template.html`: 공통 게임 실행 안내.
- `build.py`: 기존 확정 캐릭터·몬스터의128px 아틀라스 제작과 실행 안내 생성.
- `적용에셋128`, `배경레이어_v2`: 제작·비교용 자료.

별도 ZIP의 기존 `플레이.html`은 복원에서 제외한다. 그림과 제작 원본·원본 ZIP은 보존한다. 전투 회귀 검사는 Unity의 `Deviant.Combat.Tests`에서 수행한다.
