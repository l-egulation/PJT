## 책임

보석 슬롯, 해금, 레벨, 합성, 옵션 풀, 중복 적용, 거래 가능 속성과 일일 보석 보스 던전의 입장권·진행·보상 제한을 소유한다. 아이템 수량 원자성은 [아이템 SSOT](../items/ssot.md), 전투 계산은 [전투 SSOT](../combat/ssot.md), 시장 체결은 [거래소 SSOT](../economy/ssot.md)가 소유한다. 버전별 수치는 [보석 콘텐츠](../../60-content/gems/mvp-v1.md)가 소유한다.

## 해금과 장착

- 메인 스테이지 1-5를 최초 클리어하면 보석 콘텐츠와 6슬롯 프리셋 3개를 동시에 연다.
- 사용자는 프리셋 하나당 5,000쌀을 지불해 순서대로 추가 해금할 수 있으며 계정당 최대 10개를 보유한다.
- 기본 이름은 `프리셋 1`, `프리셋 2`, `프리셋 3`이고 사용자는 각 프리셋의 이름을 12자 안에서 변경할 수 있다.
- 메인 전투, 생존형·폭주형·장갑형 보석 던전과 향후 레이드는 각각 하나의 보석 프리셋에 연결한다. 같은 전투 유형을 여러 프리셋에 중복 연결할 수 없다.
- 옵션 종류와 관계없이 어느 슬롯에도 장착할 수 있다.
- 같은 보석 인스턴스를 여러 프리셋에 등록할 수 있다.
- 메인 스테이지 전투에는 메인 전투에 연결한 프리셋을 적용한다.
- 보석 던전 전투에는 현재 시간 슬롯에 열린 보스 유형에 연결한 프리셋을 적용한다.
- 메인 전투에 연결한 프리셋은 언제든 변경할 수 있다.
- 메인 스테이지 진행 중 메인 전투 연결 프리셋을 변경하면 현재 전투를 종료하고 변경된 프리셋으로 현재 스테이지를 일반 몬스터 0/20부터 다시 시작한다. 재시작 상태는 [스테이지 SSOT](../world/ssot.md)를 따른다.
- 현재 열린 보스 유형에 연결한 프리셋은 보석 던전 도전 시작 전까지 변경할 수 있다.
- 보석 던전 도전을 시작하면 성공·실패·사용자 중단·앱 종료·연결 끊김으로 도전이 끝날 때까지 해당 보스 유형에 연결한 프리셋을 변경할 수 없고, 전투에는 시작 시점 구성을 적용한다.
- 고정 공격력과 고정 최대 HP는 적용 중인 프리셋에 장착한 모든 보석의 값을 합산한다.
- 특수 옵션은 옵션 종류별로 적용 중인 프리셋에 장착한 보석 중 가장 높은 값 하나만 적용한다.
- 서로 다른 특수 옵션은 동시에 적용한다.
- 적용 중인 프리셋에 장착한 보석만 전투 스탯에 반영한다.
- 어느 프리셋에든 등록된 보석은 장착 중으로 취급하며, 모든 프리셋에서 해제하기 전에는 합성 또는 거래 등록에 사용할 수 없다.
- 사용자는 인벤토리에 보관 중인 보석 칸 전체를 잠그거나 잠금 해제할 수 있다. 칸 일부 수량만 잠그는 조작은 제공하지 않는다. 슬롯 식별·지급 중첩·이관 기준은 [아이템 SSOT](../items/ssot.md#인벤토리-슬롯과-수량)를 따른다.
- 잠긴 보석은 프리셋에 등록하거나 등록 상태를 유지할 수 있지만 수동·일괄 합성과 거래 등록에는 사용할 수 없다.
- 잠금 상태 변경은 해당 칸의 모든 보석에 원자적으로 저장하며 프리셋 등록 여부와 독립적이다.
- 보석함 개봉 또는 합성으로 새 보석을 지급할 때 고정 공격력·고정 최대 HP는 미잠금, 공격력%·고정 방어 관통·치명타 확률·공격속도 특수 옵션은 잠금 상태로 생성한다.
- 자동 잠금된 특수 옵션 보석도 사용자가 직접 잠금 해제할 수 있다.

공격속도 보석 두 개는 높은 하나만 적용하고, 공격속도와 치명타 보석을 함께 장착하면 두 옵션을 모두 적용한다.

## 레벨·합성

- 보석 레벨은 1~7이다.
- 같은 레벨 보석 3개를 소비하면 한 단계 높은 보석 1개를 지급한다.
- 사용자는 정확히 3개를 직접 선택하는 수동 합성과 목표 레벨 아래의 안전 대상을 연속 처리하는 일괄 합성을 선택할 수 있다.
- 일괄 합성은 2~7레벨 중 결과 목표 레벨 하나와 허용할 보석 옵션 종류를 지정한다. 선택한 목표 레벨 아래의 허용 보석을 낮은 레벨부터 3개 단위로 합성해 목표 레벨까지 올리고, 각 단계에서 3의 배수가 되지 않는 나머지는 보존한다.
- 사용자는 실행 전에 대상 보석 수와 단계 전체의 예상 합성 횟수를 확인한다.
- 일괄 합성의 안전 대상은 계정이 소유한 미장착·미잠금·미판매 보석으로 제한한다.
- 수동 합성도 장착·잠금·판매 중인 보석을 입력으로 사용할 수 없다.
- 결과 옵션은 결과 레벨의 옵션 풀에서 다시 추첨한다.
- 7레벨 보석은 더 합성하지 않는다.
- 수동·일괄 합성 모두 선택한 입력 전체 소비, 결과별 옵션 추첨과 결과 전체 지급을 하나의 원자적 결과로 처리한다.

| 레벨 | 1레벨 환산 가치 |
|---:|---:|
| 1 | 1 |
| 2 | 3 |
| 3 | 9 |
| 4 | 27 |
| 5 | 81 |
| 6 | 243 |
| 7 | 729 |

## 옵션 풀

| 레벨 | 고정 공격력 | 고정 최대 HP | 공격력% | 고정 방어 관통 | 치명타 확률 | 공격속도 |
|---:|---:|---:|---:|---:|---:|---:|
| 1~5 | 50% | 50% | — | — | — | — |
| 6 | 35% | 35% | 15% | 15% | — | — |
| 7 | 35% | 35% | 7.5% | 7.5% | 7.5% | 7.5% |

- 1~5레벨은 고정 공격력과 고정 최대 HP만 등장한다.
- 6레벨은 고정 옵션 외에 공격력%와 고정 방어 관통이 등장한다.
- 7레벨은 더 높은 공격력%·방어 관통과 치명타 확률·공격속도가 등장한다.
- 옵션별 값, 합산 순서와 상한은 [보석 콘텐츠 v1](../../60-content/gems/mvp-v1.md)을 따른다.
- 옵션 추첨 결과는 콘텐츠 버전과 seed로 재현할 수 있어야 한다.

## 보석함과 거래

- 보석은 거래할 수 있다.
- 판매 등록하려는 보석은 사용자가 모든 프리셋에서 직접 해제하고 잠금도 직접 해제해야 한다.
- 판매 등록은 프리셋 해제나 잠금 해제를 자동으로 수행하지 않는다.
- 보석함은 계정 귀속이며 거래할 수 없다.
- 보석과 보석함의 계정 인벤토리 슬롯 점유와 공간 부족 처리는 [아이템 SSOT](../items/ssot.md)를 따른다.
- 보석함 한 개를 열면 보석 한 개를 지급한다.
- 개봉 수량은 1개, 보유 수량 이내의 지정 수량 또는 전체로 선택할 수 있다.
- 여러 개를 열 때도 보석함마다 결과 레벨과 옵션을 독립적으로 추첨한다.
- 일괄 개봉은 선택한 보석함 전체 소비와 결과 보석 전체 지급을 하나의 원자적 결과로 처리한다.
- 개봉 전에 선택한 보석함 소비 후 결과 보석 전체 지급까지 반영한 필요 슬롯을 검사하며, 부족하면 소비·추첨·지급을 시작하지 않는다.
- 보석함 결과 레벨은 1레벨 85%, 2레벨 10%, 3레벨 5%다.
- 결과 옵션은 지급 레벨의 옵션 풀에서 추첨한다.
- 개봉 결과는 보석별 콘텐츠 버전과 seed로 재현할 수 있어야 한다.
- 거래 화폐·수수료·체결·가격 보호는 [거래소 SSOT](../economy/ssot.md)를 따른다.

## 입장권

- 보석 던전은 메인 스테이지 1-5 최초 클리어와 함께 열린다.
- 최초 해금 시 계정당 한 번 입장권 3장을 지급한다.
- 입장권은 서버 기준 KST 매시 정각마다 한 장 충전하며 앱 종료 중에도 누락된 정각 경계를 소급한다.
- 최대 보유량은 3장이다.
- 최대치에서는 충전 타이머를 표시하지 않는다. 한 장을 소비하면 다음 KST 정각부터 다시 충전한다.
- 클리어 보상 또는 소탕 보상을 받을 때 입장권 한 장을 소비한다.
- 실패, 사용자 중단, 앱 종료와 연결 끊김은 입장권을 소비하지 않으며 보상을 지급하지 않는다. 도전이 종료되면 해당 보스 프리셋 잠금을 해제한다.
- 성공 시 도전 상태 확정, 입장권 차감, 보석함 지급, 보스별 최고 클리어 단계와 단계별 최초 보상 상태 갱신, 보상 수용량 예약 정리와 요청 결과 기록을 서버에서 하나의 원자적 결과로 처리한다. 같은 요청의 재시도는 기록된 결과를 반환하며 중복 결과를 만들지 않는다.
- 도전 시작 전에 보석함 보상 수령에 필요한 계정 인벤토리 수용량을 검사하고, 기존 보석함 스택 슬롯에 대한 지급 권리 또는 빈 슬롯 하나를 도전 종료까지 예약한다.
- 성공 보상은 예약한 스택 슬롯 또는 빈 슬롯에 지급하고, 실패·사용자 중단·앱 종료·연결 끊김은 보상 수용량 예약을 해제한다.
- 위 충전 주기와 최대 보유량은 `gem-dungeon-v2-accelerated-applied` 정식 기준이다. 이전 `gem-dungeon-v1-applied`의 8시간·최대 3장 정책과 승격 전 베타 값은 [MVP 보석·던전 수치](../../60-content/gems/mvp-v1.md)와 [가속 베타 기록](../../60-content/gems/beta-accelerated.md)에 변경 없이 보존한다.

## 시간 슬롯 보석 던전

- 보석 던전은 현재 열린 보스의 신규 단계 도전 또는 최고 클리어 단계 소탕을 선택하는 별도 콘텐츠다.
- 계정당 진행 중인 보석 던전 도전은 하나만 허용한다.
- 신규 도전은 서버가 콘텐츠 버전·캐릭터 상태·장비·스킬·보스 프리셋과 seed를 입력으로 결정론적으로 계산하고, 클라이언트는 서버가 반환한 순서화된 전투 사건을 재생한다. 클라이언트가 제출한 승패나 피해량을 결과 권한으로 사용하지 않는다.
- 보스는 KST 정각마다 변경한다.
- 기본 순환은 `생존형 → 폭주형 → 장갑형`의 고정 3시간 주기다.
- 같은 KST 시간 슬롯에는 모든 계정에 같은 보스를 연다.
- 순환 기준일과 순서는 콘텐츠 버전으로 관리한다.
- 보석 던전 도전 시작 시 KST 시간 슬롯, 보스 유형, 단계, 보스 프리셋, 콘텐츠 버전과 보상표를 도전 스냅샷으로 확정한다.
- 서버는 계산된 전투 종료 시각을 `minimumCompleteAt`으로, 그 시각의 15초 뒤를 `expiresAt`으로 확정한다. `minimumCompleteAt` 전에는 성공 확정을 허용하지 않고, `expiresAt`이 지난 미완료 도전은 자동 중단한다.
- 클라이언트의 완료 요청은 서버가 보관한 도전 스냅샷과 계산 결과만 검증·확정한다. 완료 요청 본문의 승패·피해량·보상 값은 신뢰하지 않는다.
- 도전 중 KST 정각을 지나 다음 시간 슬롯이 열려도 시작한 도전은 스냅샷 기준으로 성공·실패·사용자 중단까지 처리한다. 단, 앱 종료와 연결 끊김은 사용자 중단으로 처리한다.
- 도전이 끝난 뒤 새 요청부터 변경된 KST 시간 슬롯의 보스와 콘텐츠를 적용한다.
- 세 보스는 각각 1~10단계를 순차 해금한다.
- 보스별 최고 클리어 단계와 단계별 최초 클리어 상태는 서로 독립이다.
- 실제 전투로 도전하는 신규 단계는 해당 보스의 최고 클리어 단계 다음 단계다.
- 신규 단계를 클리어하고 입장권이 남아 있으면 같은 시간 슬롯에 바로 다음 신규 단계에 도전할 수 있다.
- 시간 슬롯별 신규 단계 클리어 횟수에는 입장권 외의 별도 제한을 두지 않는다.
- 정식 v2 단계별 목표 메인 진행은 다음 표를 사용한다. 각 단계의 권장 빌드·보스 절대 수치는 [MVP 보석·던전 수치](../../60-content/gems/mvp-v1.md)의 정식 v2 승격 절을 따른다.

| 던전 단계 | 목표 메인 진행 |
| ---: | --- |
| 1 | 1-5 |
| 2 | 1-7 |
| 3 | 1-10 |
| 4 | 2-1 |
| 5 | 2-4 |
| 6 | 2-7 |
| 7 | 2-10 |
| 8 | 3-1 |
| 9 | 3-4 |
| 10 | 3-7 |

- 세 보스의 1단계는 1-5 목표 성장 빌드가 보석 없이 클리어 가능한 난이도로 설계한다.
- 1단계는 확정 클리어가 아니며 장비·스킬 성장이 부족하면 실패할 수 있다.
- 세 보스의 정체성은 유지하되 1단계 클리어 조건은 보석 옵션을 요구하지 않는다.
- 실패, 사용자 중단, 앱 종료와 연결 끊김은 보상과 입장권을 소비하지 않고 해당 보스 프리셋 잠금을 해제한다.
- 위 교체 주기와 단계별 목표 메인 진행은 `gem-dungeon-v2-accelerated-applied` 정식 기준이다. 단계별 절대 수치와 보존된 이전 버전은 [MVP 보석·던전 수치](../../60-content/gems/mvp-v1.md)가 소유한다.
- 교체 주기는 KST 기준으로 정렬된 3,600초 시간 슬롯으로 구현한다. 도전 중 슬롯이 바뀌어도 시작 시점 스냅샷을 끝까지 유지한다.

| 보스 유형 | 핵심 검사 |
|---|---|
| 생존형 | 2초마다 발생하는 회피 불가능한 강타를 견디며 15초 생존하는 최대 HP 검사 |
| 폭주형 | 15초 제한시간 내 공격력·스킬·치명타·공격속도를 합쳐 처치하는 공격 성능 검사 |
| 장갑형 | 높은 방어력을 15초 제한시간 내 뚫고 처치하는 방어 관통·공격 성능 검사 |

- 권장 빌드는 모든 seed에서 성공해야 한다. 최악의 seed에서 HP 1 또는 제한시간 직전 성공까지 허용하며 별도 안전 여유는 보장하지 않는다.
- 권장 빌드 미만은 성공을 보장하지 않는다.

## 최초 클리어와 소탕

- 단계별 100% 보상은 보스별 최초 클리어 한 번만 지급한다.
- 단계 $d$의 최초 클리어 보석함 수는 $R_{\mathrm{first}}(d)=9+d$다.
- 소탕 대상은 현재 열린 보스의 최고 클리어 단계로 고정하며 하위 단계는 소탕할 수 없다.
- 소탕 보상은 최고 클리어 단계 최초 보상의 30%를 내림한 $R_{[200~\mathrm{sweep}}(d)=\lfloor0.3R_{\mathrm{first}}(d)\rfloor$개다.
- 소탕은 1회, 보유 입장권 이내의 지정 횟수 또는 사용 가능한 전체 횟수를 선택할 수 있다.
- 일괄 소탕은 선택 횟수만큼 입장권을 소비하고 최고 클리어 단계의 1회 소탕 보상에 선택 횟수를 곱한 보석함을 지급하며 전투는 실행하지 않는다.
- 일괄 소탕의 입장권 전체 차감과 보석함 전체 지급은 하나의 원자적 결과로 처리한다.
- 단계별 보상표와 기준 스펙은 [보석 콘텐츠 v1](../../60-content/gems/mvp-v1.md)이 소유한다.

## 불변 조건

- 한 계정에 진행 중인 보석 던전 도전이 둘 이상 존재하지 않는다.
- 만료된 도전은 입장권과 보상을 소비하지 않고 프리셋 잠금과 보상 수용량 예약을 해제한다.
- 같은 보스·단계의 최초 클리어 보상을 두 번 지급하지 않는다.
- 실패·사용자 중단·앱 종료·연결 끊김은 입장권과 보상을 소비하지 않는다.
- 정각 경계 충전은 최대 3장을 넘지 않는다.
- 합성은 정확히 입력 3개를 소비하고 결과 1개를 지급한다.
- 같은 특수 옵션은 가장 높은 하나만 적용하고 다른 특수 옵션은 함께 적용한다.
- 옵션·보석함 추첨 결과는 콘텐츠 버전과 seed로 재현할 수 있어야 한다.
- 보석 보너스와 던전 보스 수치는 플레이어 상태에 따라 런타임에서 임의로 바뀌지 않는다.
