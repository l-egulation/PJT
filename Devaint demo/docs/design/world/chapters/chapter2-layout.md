# 2챕터 방과 연결

[분야 개요](README.md)

공통 게임은 타이틀 → 시작 마을 → 1챕터 → 2챕터로 이어진다. 1챕터 보스 출구에서 F로 철창을 열면 열림 연출과 페이드 뒤 현재 장비·체력·가방·골드·고정 팔레트를 유지해 2챕터로 이동한다. 1챕터 결과 화면을 거치거나 런을 종료하지 않으며 첫 보스 해금만 먼저 기록한다. 사망 또는 2챕터 완료에서 런을 한 번 정산하고 마을로 돌아간다. 2챕터 보스(Rose·Blue)를 처치하면 3챕터 대도서관으로 가는 출구 문(서가 두짝문, 6×7유닛, F 키캡, 사용자 결정 2026-11-13)이 레이아웃의 출구 자리(보스 무대 오른쪽 끝 3유닛 앞 바닥)에 나타나고, 그 4유닛 앞 같은 바닥에 1챕터와 같은 색상 잉크 제단이 나온다(플레이 확인 2026-11-06). 2챕터를 처음 깨는 런에는 제단이 나오지 않는다([런 구조](../../run/run-structure.md)의 제단 규칙). 출구에서 F를 누르면 고르지 않은 제단 후보를 파기하고 두 짝 문이 안으로 열리는 연출(8장, 안쪽 서가 복도의 등불빛) 뒤 2챕터를 클리어한다. 그림 원본은 resources `environments/stage2-library-exit-20261113`이며 1챕터 출구 아치는 그대로다. 3챕터가 아직 없어 2챕터 출구는 이미 깬 런에서도 결과 화면을 거쳐 마을로 돌아간다.

2챕터 맵은 [방·통로 공통 규격](../room-corridor-standard.md)의 블록 격자 원형으로 **런타임에 조립**한다(사용자 결정 2026-11-05). 같은 시드는 같은 맵을 만든다. 일반방 원형 16종 중 10종을 중복 없이 골라 시작·정비소·엘리트·보스·봉인 도전방·잠긴 상자방 각 1방을 더한 총 16방이며, 방 id는 S·F01~F10·M·E·B·SEAL·CHEST다. 주 경로 일반 9방은 F01~F09, 순환 갈래의 전투방은 F10이다. 봉인 도전방·잠긴 상자방은 1챕터 원형(`S1-SEAL-A~C`, `S1-CHEST-A~C`)을 그대로 쓰며 규칙은 [스테이지 기믹](../stage-gimmicks.md#2챕터)을 따른다(사용자 결정 2026-11-13).

**세로 이동이 주가 되는 구성**이다. 시작방은 맨 위에 있고 주 경로는 아래로 120~144u 내려갔다가 옆으로 한 방을 지나 다시 위로 올라온다. 내려가기·올라가기 구간의 연결은 90%가 상하 출입구이며 세로로 긴 방(2×3 블록)을 주 경로에 먼저 쓴다. 주 경로 문→문 이동의 세로/가로 비가 2 미만인 배치는 다시 뽑는다. 어떤 방도 시작방보다 높지 않다. 벽타기 통로는 1~3개이며 주 경로에 1개 이상 있다.

순환 갈래 2방(전투방 1개 → 잠긴 상자방)은 내려가는 쪽 주 경로 방(1~5번째)에서 올라오는 쪽 주 경로 방(6~9번째)으로 이어진다. 갈래 없이도 주 경로가 이어진다. 모든 연결은 양방향이다. 봉인 도전방은 정비소 자리 뒤 주 경로 방(3~9번째)에 붙는 막다른 갈래다.

정비소는 비전투 장착·강화 공간이며 2×1 블록(안쪽 26×8u)이다. 주 경로 2~7번째 방 가운데 잠긴 상자방 갈래가 갈라지는 자리 이하의 방에 붙는 연결 하나뿐인 막다른 갈래다. 엘리트방에는 2스테이지 전용 엘리트 A3(HP 1350, 원본 `data/combat/chapter2_elite.json`) 1마리를 두며, 첫 진입 뒤에는 챕터 전체로 추격한다. 주 경로 4~9번째 방에 붙는 막다른 갈래이며 전투 규칙은 [A3 전용 엘리트](../../enemies/chapter2/elite/chapter2-elite-three-patterns.md)를 따른다. 보스방은 Rose·Blue 3페이즈 보스와 사용자 승인 30×18unit 전투장을 사용하며 [Rose·Blue 전투 명세](../../enemies/chapter2/rose-blue/chapter2-rose-blue-boss.md)를 따른다. 보스방은 꼭대기 근처까지 올라온 주 경로 마지막 방의 좌·우 출입구에서 가로 48u [보스 앞 긴 통로](../room-corridor-standard.md)를 지나 들어간다(사용자 요청 2026-11-11). 1챕터의 우물 도르래 수문장과 시계탑 집행자는 2챕터에 배치하지 않는다.

시드 200개 기준 특수방 위치(지도 3×3 구역): 보스는 위쪽 행(왼쪽 47%·오른쪽 35%·가운데 18%), 정비소와 엘리트는 중간·아래 6~9구역에 고르게 놓인다. 세 방의 구역 조합은 91가지다. 이 분포는 봉인 도전방·잠긴 상자방을 넣기 전 측정값이며 다시 재야 한다.

HUD·가방·정비소·색상 잉크 관리·미니맵·전체 지도·일시정지는 현재 공통 게임 GUI를 사용한다. 팔레트는 출발 구성과 귀속을 유지하며 새로 구매·드롭하지 않는다. 골드·마법안료는 기존 규칙대로 즉시 지급하고 색상 잉크·스탬프·부품은 기존 바닥 픽업을 사용한다. 바닥 픽업 위에는 이름 줄을 띄우지 않고, 플레이어가 2.6유닛 안으로 다가가면 가장 가까운 하나의 이름을 공통 말풍선으로 보여 준다(골드는 금액만 뜬다). 사망 결과는 [런 구조](../../run/run-structure.md#1챕터-플레이-빌드-기준)의 공통 사망 연출이 끝난 뒤 표시한다. 일반 적은 플레이어가 다른 방·통로에 있어도 피격·공격·전투 틱을 유지하며 방 경계를 넘는 것만으로는 적 투사체·폭탄을 취소하지 않는다(사용자 결정 2026-11-09). 플레이어가 보스방에 들어가면 일반 적은 공격을 멈추고 진행 중 공격과 적 투사체·폭탄을 취소한다. 섬멸 회복은 소유 방 기준 한 번만 처리한다.

방 원형의 지형·발판·몬스터 편집 원본은 `data/map/block_rooms.json`이다. 실행과 검증은 [2챕터 런타임](../../../development/gameplay/world/chapter2-runtime.md)과 [블록 맵](../../../development/gameplay/world/block-map.md)을 따른다. 전체 경로의 양방향 수동 완주·전투 밸런스·낙하와 카메라 가독성은 플레이 확인 대상이다.

수동 포탈은 평평한 지면에서 C로 포탈1, V로 포탈2를 세우고 포탈 안에서 F로 반대쪽 포탈로 건너간다. 보스방 입장 시 방 밖에 둔 포탈을 정리한다.
