# 임시 표현과 필요한 에셋

[분야 개요](README.md)

현재 게임에서 승인 아트 대신 임시 표현을 쓰는 곳과, 제작·승인·복원이 필요한 에셋 목록이다. 항목이 해결되면 이 목록에서 지운다. 기능 규칙은 각 명세가 기준이며, 이 문서는 아트·표현의 빈자리만 다룬다. 기준 시점: 2026-10-31 main.

추가 제작분 151장 중 105장을 게임에 적용했다([적용안과 적용한 선택](needed-assets-application.md#적용한-선택)). 적용분도 **최종 미술 승인 전**이며, 승인 결과에 따라 교체할 수 있다.

## 1. 승인 대기 중인 적용 에셋

| 대상 | 현재 상태 |
|---|---|
| 시작 마을 55장 | 건물·작업대·소품 컬러/스케치 20, 문양 16, 해금·안료 효과 16프레임, 이야기 배경 3 |
| 추가 제작 적용분 105장 | 제단·출구·F 키캡·출발 도면 그림·건물 채색·가방 파괴·제단 획득/폐기·안료 대비·이야기 인물·검 접촉광 |
| 검 접촉광 | 원래 승인 6장이 아닌 **대체 후보**다. 원본을 찾으면 원본을 우선한다 |
| 이야기 서술·인물 배치 | `data/story/starting_village_opening.json`의 문장과 줄별 인물 위치는 초안이다 |
| 새 효과음 연결 | 기존 WAV 재사용. 실제 장치에서 음량·어울림 확인 전 |

## 2. 아직 게임에 적용하지 않은 것

| 대상 | 이유 |
|---|---|
| 게임패드 문양 20장, F 외 키보드 키캡 20장 | 게임패드 입력 매핑·다른 키 안내가 없다. 매핑이 생기면 `KeycapMarker`에 플랫폼별 조회를 추가한다 |
| 출구 닫힘(`exit-sealed`) | 출구 연출 설계 전. 지금은 보스 처치 전에 출구를 숨긴다 |
| 제단 24px 호환본, 종이 포함 도면 카드 | 48px 본·큰 그림과 택일이라 쓰지 않음 |
| 키캡 표시음 | 선택 사항. 대상이 바뀔 때만 울려야 해 연결 기준을 정한 뒤 적용 |
| 픽셀 가방 그림 7장(`ui/inventory/runtime/Art/ink-*.png`) | 원본은 있으나 Unity의 `PixelInventory/Art` 폴더 전체가 메인에서 추적되지 않아(`.meta` 없음) 배치 계약에 넣을 수 없다. 폴더의 `.meta` 추적부터 정해야 한다 |

## 3. 아직 없는 에셋

| 대상 | 쓰일 곳 | 비고 |
|---|---|---|
| 잉크 몸 주인공의 각성 장면 그림 | 이야기 3장 첫 줄 | 현재 그 줄은 배경만 보인다 |
| 인물 움직임 | 조력자 등장·희생 장면 | 정지 그림과 소실 마스크만 있다. 오프닝은 정지 그림이 솟아오르는 연출로 대신한다 |
| 2챕터 | "2챕터는 준비 중입니다" 안내 | 테마·구성 설계 전 |
| 우물 광장의 채색 조건 | 채색 규칙 확장 시 | 컬러/스케치 짝은 이미 있어 에셋은 불필요 |

## 4. 정리가 필요한 로컬 파일

| 파일 | 상태 |
|---|---|
| `unity/Assets/ForestCombatV2/Resources/ClockExecutioner/Stationary.png.meta` | 짝 PNG가 없다. 게임은 `StationaryBytes`를 읽는다. Unity를 열면 `.meta`가 지워지므로 참조 확인 후 정리한다 |
