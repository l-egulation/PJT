# 발사기 공격과 잉크별 스킬

[분야 개요](README.md)

현재 발사기 설계다. 스킬 수치 원본은 [launcher_skills.json](../../../../../data/combat/launcher_skills.json), 기본 공격 볼 탄환은 [원거리 데이터](../../../../../data/combat/ranged_basic_design.json)의 `launcher`를 따른다.

## 구조

발사기도 다른 형태처럼 **기본 공격(S) 1개와 잉크가 고르는 스킬(D) 1개**를 가진다.

- 기본 공격은 장착 잉크와 관계없이 항상 **볼 탄환**이다.
- 특수 잉크는 D 스킬을 고른다. 미장착 **모아쏘기** / 범위 **레이저** / 이동 **샷건** / 후속타 **유탄·파편**이다.
- 기본 공격은 기본 피해·기본 공속 강화를, 스킬은 특수 피해·쿨감 강화를 적용한다. 스킬은 기본 공속으로 준비·회복이 줄지 않는다.
- 발사기 그림은 장착 잉크를 따른다. 범위 잉크면 평소와 볼 탄환 발사도 레이저포 그림으로 그린다. 스킬은 그 잉크 총의 승인 발사 자세를 쓴다.
- 각 스킬은 사용자 승인 개별 피해·쿨타임을 적용한다.

## 기본 공격 — 볼 탄환

| 공격 | 피해 | 준비 / 회복 / 전체 모션 | 범위·비행 |
|---|---|---|---|
| 볼 탄환 | 65 | 약 0.092308 / 0.215385 / 0.307692초 | 지름0.3·속도20·거리8 |

새 S 입력당1회, 버튼 유지 자동 반복 없음이다. 볼 탄환 공속 ×1.3은 준비·회복 시간을 나눈 원본 값에 반영되어 있다. 강화 없는 단일 대상 이론 DPS는 211.25다.

중력 없는 수평 직선 탄이며 첫 유효 적에게65피해 후 소멸한다. 고체 벽/바닥에 막히고 일방향 발판은 통과한다. 발사 중심은 기존 승인값 **(±0.85625,1)**이다.

## 스킬 (D)

| 장착 잉크 | 스킬 | 피해 | 준비 / 회복 / 전체 모션 | 쿨타임 | 범위·비행 |
|---|---|---|---|---:|---|
| 미장착 | 모아쏘기 | 1단200·2단275·3단350 | 충전 0.20~0.80 / 0.30 | 6초 | 지름0.3·0.45·0.6·속도20·거리8·적 명중 시 2×2 범위 피해 |
| 범위 | 레이저 | 대상당200 | 0.15 / 0.45 / 0.60초 | 8초 | 가로 무한·지형 통과·두께0.25 |
| 이동 | 샷건 | 탄당100, 같은 적 최대500 | 0.15 / 0.65 / 0.80초 | 7초 | 5발·각 거리6·속도20·지름0.2 |
| 후속타 | 유탄·파편 | 본체225 + 파편별60, 최대465 | 0.20 / 0.80 / 1.00초 | 9초 | 본체30도·속력10·중력20·지름0.4 |

- 새 D 입력으로 사용하고 공통 특수 규칙(실제 발동부터 쿨타임, 발동 전 대시 취소 미소비, 교체 예약)을 따른다.
- 방향은 준비 시작 입력, 없으면 바라보는 쪽으로 고정한다. 지상은 모션 중 수평 입력0, 공중은 정상 중력이다.
- 발사된 효과는 공격 취소·교체 후 유지하고 발사 시점의 특수 피해 배율을 파편까지 보존한다. 사망·런 종료·테스트 리셋은 정리한다.
- 사거리는 생성점부터 탄심 이동거리다. 레이저·샷건·유탄은 발 위1에 생성하며 탄 반지름+0.05만큼 몸 앞끝에서 떨어뜨린다. 모아쏘기·레이저·샷건은 몸→발사점과 비행 중 모든 지형을 통과한다. 유탄은 기존 고체 검사를 유지한다. 비행 스윕으로 적을 놓치지 않으며 기존 탄별 사거리·적 충돌 규칙을 유지한다.

### 모아쏘기

D를 누르고 있는 동안 충전한다. 0.20초 전에 떼면 0.20초에 쏘고, 0.80초가 되면 자동으로 쏜다. 충전은 **3단계**다. 뗀 시간이 0.20~0.40초면 1단(피해**200**·탄 지름**0.3**), 0.40~0.60초면 2단(**275**·**0.45**), 0.60~0.80초면 3단(**350**·**0.6**)이며 단계 안에서는 값이 오르지 않는다. 쏜 뒤 회복은 0.30초다. 볼 탄환과 같은 직선 탄이며 첫 유효 적과 충돌하면 그 충돌점을 중심으로 가로2×세로2unit 정사각형 범위 공격을 한 번 발생시키고 소멸한다. 직접 맞은 적을 포함해 범위와 겹친 각 적에게 그 단계의 피해를 한 번씩 주며 직격 추가 피해는 없다. 범위 크기는 충전량과 관계없이 2×2unit이고 고체 벽이 피해를 차단한다. 벽·바닥·발판은 통과하고 사거리 종료 때는 범위 공격 없이 소멸한다. 밀기·관통은 없고 발사 중심은 볼 탄환과 같다.

### 레이저

준비 끝에 발사 높이에서 바라보는 가로 방향으로 사거리 제한 없이 적을 관통하며 모든 유효 적에게 각각200피해1회다. 고체 벽·바닥·일방향 발판을 모두 통과하며 지형 뒤의 적도 같은 피해 판정에 포함한다. 벽이 없는 방향도 피해 사거리 상한은 없으며, 표시만 현재 질의의 콜라이더와 카메라 범위를 덮는 유한 길이로 그린다. 이후 보이는 빔은 추가 피해 없는 표시 효과이며, 그 유지 시간은 추가 피해 간격이나 버튼 유지 자동 반복을 뜻하지 않는다.

### 샷건과 반동

중앙 수평 기준 **-20 / -10 / 0 / +10 / +20도**로 5발을 동시에 발사한다. 각 탄은 모든 적을 관통하고 적마다 한 번씩 피해를 준다. 고체 벽·바닥·일방향 발판을 모두 통과해 각 탄의 기존 거리6까지 이동한다. 각 적이 서로 다른 탄5발에 모두 맞을 수 있어 대상별 최대100이며 거리에 따른 감쇠는 없다. 같은 탄이 같은 적에게 중복 피해를 주지는 않는다.

지상·공중 모두 **발사 반대쪽으로6unit**, **낮은 점프 전체 포물선 시간**에 걸쳐 이동한다. 낮은 점프 높이1unit은 초기 테스트값이다. 기존 상승/하강 중력에서 정상 높이 복귀까지 약 **0.31177초**, 수평속도 약 **19.25unit/s**다. 일반 점프 횟수를 소비하지 않는다. 지상에서 쏘면 땅을 떠난 뒤 다시 닿을 때 반동이 끝난다.

반동 구간은 방향키 수평속도를 합산하지 않고 반동 속도를 사용한다. 자체 무적은 없으며 벽·이른 착지·유효 대시 취소로 실제 이동이 짧아질 수 있다.

### 유탄과 파편

본체는 30도 포물선, 속력10·중력20이다. 첫 적/고체 접촉 시 **피해45·폭발 반경1.2**로 한 번 폭발한다. 일방향 발판은 위로 통과하고 위에서 하강 접촉 시 충돌한다. 비충돌5초 만료는 피해·폭발·파편 없이 제거한다.

본체 폭발 지점에서 월드 +X 기준 **30 / 60 / 120 / 150도** 방향으로 파편4개를 즉시 생성한다. 각 분산 방향으로0.2 떨어진 위치에 생성하며 시작부터 적/고체와 겹치면 그 자리에서 즉시 폭발한다.

| 파편 항목 | 값 |
|---|---|
| 한 파편 폭발 | 피해12·반경0.6 |
| 초기 속력 / 중력 | 6 / 20 |
| 최대 비행시간 | 0.6초 |
| 폭발 조건 | 첫 적/고체/하강 발판 접촉 또는 수명 만료, 파편당1회 |
| 탄체 충돌 지름 | 0.2 — 기능 구현용 임시값 |

본체·파편 폭발은 고체 벽에 차폐되고 자해·직격 추가 피해는 없다. 같은 적이 본체1회+서로 다른 파편4회를 맞을 수 있어 강화 전 합계 최대93이다. 각 폭발은 대상당1회이며 복수 콜라이더 중복을 제거한다.

모든 발사기 스킬은 범위 또는 관통으로 복수 대상 피해가 가능하다. 기본 볼 탄환만 첫 적 한 명에서 소멸한다. 샷건은 각 탄별·대상별 중복을 제거하며 지형 뒤의 적도 맞힌다. 포물선 유탄과 폭발의 고체 차폐는 유지한다.

## 구현·검증 범위

볼 탄환과 네 스킬은 공통 Combat V2 런타임을 사용하는 본 게임과 시험장에 연결한다. 위 연출을 `LauncherSkillFx`로 재생하며 그림이 배치되지 않은 환경은 이전 승인 표현(기본포 A·레이저 B·샷건 A·유탄 B)으로 그린다. 모아쏘기 몸 동작은 새 그림 없이 발사기 `attack_single` 프레임 순서만 바꾼다. 최종 밸런스와 아트 가독성 평가는 별도 확인한다.

수동 확인은 [실행 안내](../../../../development/testing/testing.md)를 따른다. 얇은 벽·근접 생성·레이저 적별1회·샷건 동일 적5발·지상/공중 반동 거리·모아쏘기 단계별 피해/크기·파편 시작 겹침·폭발 차폐·취소/교체 후 스냅샷을 확인한다.
