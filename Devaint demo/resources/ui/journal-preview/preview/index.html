새로 생성한 버튼 탭 카드 슬롯을 독립 PNG로 분리했습니다. 잉크는 40×56px, 글씨는 실제 텍스트입니다. 원본과 추출 좌표는 assets/refined에 보존했습니다.

검토 범위 / 조립 방식

버튼 슬롯 탭 게이지 텍스트를 각각 조립했습니다. 전체 시안을 잘라 쓴 화면은 없습니다. 클릭 결과는 이 HTML 안에서만 유지되며 게임 저장에는 영향을 주지 않습니다.

원본 생성 아틀라스, 분리한 PNG, 재사용 에셋 출처, 화면별 필요 요소는 README.md와 manifest.json에 기록했습니다. 최종 파츠 ID별 문양 연결과 Unity 입력 서비스 연결은 승인 후 작업 범위입니다.
