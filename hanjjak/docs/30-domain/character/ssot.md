## 책임

감자·고구마·옥수수 주력 재료의 최초 선택, 변경 불가와 드롭 계열 비율을 소유한다. 챕터별 세대 풀·드롭 기회·지급 수량과 거래 체결은 각각 [아이템 SSOT](../items/ssot.md), [MVP 주력 재료 드롭표 v1](../../60-content/items/material-drops-mvp-v1.md), [거래소 SSOT](../economy/ssot.md)가 소유한다.

## 현재 규칙

- 플레이어는 최초 로그인 직후 감자·고구마·옥수수 중 하나를 주력 재료로 한 번 선택한다.
- 선택 재료와 두 비선택 재료의 드롭 계열 비율은 모든 세대에서 80:10:10이다.
- 주력 재료를 선택하기 전에는 메인 화면과 게임 진행으로 진입할 수 없다.
- 최초 선택은 이후 변경할 수 없다. 같은 재료 재요청은 현재 선택으로 성공 수렴하고 다른 재료 요청은 거절한다.
- 장비 성장은 감자·고구마·옥수수를 1:1:1로 소비하며 부족한 비선택 재료는 거래소에서 보완한다.
- 표시명은 `감자 전문`, `고구마 전문`, `옥수수 전문`이며 세대별 재료 표시명은 [아이템 표시 콘텐츠 v1](../../60-content/items/mvp-v1.md)이 소유한다.

구형 A/B/C 전문 명칭, 선택 전문 단독 생산과 C-05~C-07의 전문 변경 공식·비용·이력은 폐기된 기능 경로이며 구현 대상이 아니다. F·I·K 작업은 이 SSOT를 링크하고 실행 상태만 소유한다.
