# Unity 전투 공통 명세

[분야 개요](README.md)

현재 적용하는 현행 명세다. [무기·잉크 시스템](../equipment/rules.md), [검·둔기 상세](../equipment/weapons/forms/melee.md), [원거리 상세](../equipment/weapons/forms/ranged.md)와 함께 사용한다. 수치는 초기 테스트 기준이며 출시 밸런스 확정을 뜻하지 않는다.

[런·챕터 구조](../run/run-structure.md)에 따라 한 챕터 내부는 방 없이 자유 이동한다. 챕터끼리는 물리적으로 연결되지 않고 이전 챕터로 돌아갈 수 없다. 테스트 구역의 구조를 독립 방·전멸 잠금 출구 규칙으로 승계하지 않는다. 경제·영구 해금·반복 귀환 서사는 [사용자 확정 사항](../../overview/overview.md)의 확정 범위와 미정 항목을 따른다.

## 피해·적 체력의 기준 단위

검 기본 공격은 타격당 **65**다. 모든 무기의 기본·스킬 피해(차지·연타·지속 피해·파편·미끼 반격 포함)와 일반·엘리트·보스 및 파괴 가능한 보스 패턴 HP는 같은 5배 단위로 맞춘다. 맨손은 40/50이다. 공격 주기·잉크 증가율·적 처치 타수는 유지하고 표시 피해량의 차이를 키운다. 플레이어 HP·적이 플레이어에게 주는 피해·회복·방어막은 기존 단위를 유지한다.

보스 페이즈 전환의 HP/누적 피해 기준, 보스끼리 주는 패턴 피해·회복량, 반사탄의 적 대상 피해도 적 HP 단위에 맞춘다. 원본 적 탄 피해는 반사 시 한 번 5배 환산하며 잉크·스킬 배율과 중복 적용하지 않는다. 실피해를 소비하는 무기 내구도와 보상 HP 등급 경계도 같은 단위를 사용한다. 원본은 `data/combat/weapon_ink_run_design.json`의 `combatBalanceTrial` 및 각 무기·몬스터 데이터다.

## 키보드 조작과 재설정 범위

기본 키는 **A=무기 1 기본공격 / S=무기 2 기본공격 / Q=무기 1 스킬 / W=무기 2 스킬 / Space=점프**다. 좌우 방향키 이동, Shift 대시, **↑ 유지로 벽 기어오르기 / ↑+Space로 벽 차기**, 아래+Space 발판 내려가기를 사용한다. 월드 상호작용(도면 선택·정비소 열기/닫기·보스 출구)은 **F**, 인벤토리 열기/닫기는 **Tab**, 받아 둔 처치 보상 열기는 **G**([런 보상](../run/rewards.md#스테이지에서-얻는-무기와-잉크)), 개발용 포탈 설치/귀환은 **C/V**, 전투 리셋은 **F5**다. A/S·Q/W은 교체 버튼을 먼저 누르지 않고 해당 슬롯의 공격을 요청한다. 스킬 버튼 유지·해제는 해당 슬롯에만 전달한다. 빈 장착 칸의 기본 공격은 맨손으로 실행한다. 빈 칸의 스킬 입력이나 쿨타임 중 입력은 다른 무기의 공격으로 대체하지 않는다. [장착 칸과 맨손](../equipment/weapons/rules.md)을 따른다.

개발용 전투 리셋은 키가 아니라 치트 모드의 「전투 상태 초기화」로 옮겼다. 스킬 명세의 S/D는 과거 기본/특수 구분 표기이며 현재 물리 키 배정을 뜻하지 않는다. 입력 매핑은 전투 행동과 분리한다. 패드는 West/North(X/Y, Square/Triangle)로 기본 1/2, 좌/우 trigger로 스킬 1/2, South로 점프, East로 대시를 같은 행동 요청에 연결한다. 전체 기본값과 입력 수명은 [다중 입력 장치 구조](../../development/presentation/ui/input-devices.md)를 따른다. 사용자가 키를 변경하는 설정 화면·중복 키 검증 UI·저장·기본값 복원은 후속 범위다.

**X**를 한 번 누르면 무기 1·2 순서를 맞바꾼다. A/Q는 바뀐 무기 1, S/W는 바뀐 무기 2를 사용하며 HUD·가방도 같은 순서를 표시한다. 무기 인스턴스·형태·스킬·장착 잉크·팔레트·강화·남은 쿨타임·마지막으로 공격한 무기는 유지한다. 두 무기가 모두 준비되고 공격·차징·대시·기절·포탈 이동 중이 아닐 때만 적용한다. 스케치 무기 런에서는 무기를 한 자루 이상 장착했을 때 A와 B에 든 것(무기와 맨손, 또는 두 무기)을 맞바꾸며 마지막 몬스터 공격 적중 후 5초 동안 장착·해제·교체와 함께 X가 잠긴다([무기 구성](../equipment/weapons/rules.md)). 일시정지·입력 차단 중에는 적용하지 않으며, 거절된 입력을 나중에 자동 실행하지 않는다. 교환 전 예약 공격과 유지 중인 스킬 입력은 새 슬롯으로 넘어가지 않고 새로 눌러야 한다.

## 단위와 플레이어 판정

Unity unit·초 기준, PPU 32, 루트 scale 1이다. 대기 신체 높이 64px를 2unit으로 유지한다. 128×128px 투명 캔버스 전체를 신체 크기로 사용하지 않는다.

| 항목 | 확정값 |
|---|---|
| 발 원점 | 원본 좌상단 기준 픽셀 경계 (64, 121) |
| 스프라이트 피벗 | 정규화 (0.5, 0.0546875), 좌하단 기준 (64, 7)px |
| 신체 기준 픽셀 경계 | left=55, right=85, top=57, bottom=121 |
| 몸·피격 Box size | (0.9375, 2) |
| 오른쪽 offset | (0.1875, 1) |
| 왼쪽 offset | (-0.1875, 1) |
| 오른쪽 몸 경계 | x=[-0.28125, 0.65625], y=[0, 2] |

좌표 변환은 `xUnity=(xPixel-64)/32`, `yUnity=(121-yPixel)/32`다. 원본 스프라이트를 수정하거나 무기·스카프·이펙트를 몸 크기에 포함하지 않는다. 대기·이동·공격·점프에서 고정 크기를 유지하고 방향 전환 시 offset.x만 반전한다. `SpriteRenderer.flipX`와 콜라이더 반전을 별도로 처리한다. 확정 데이터는 [player_hurtbox.json](../../../data/combat/player_hurtbox.json)이다.

지형 충돌 몸과 피해 수신 영역은 같은 기하의 **별도 콜라이더**다. 몸은 지형 충돌, 피격 영역은 trigger 또는 명시적 탐색 대상이다. 벽 밀착 중 반전할 때 새 몸이 벽 안으로 들어가지 않도록 검사·보정한다.

| 역할 | 충돌·탐색 규칙 |
|---|---|
| WorldSolid | 플레이어·적의 몸을 막음 |
| OneWayPlatform | 액터의 발판 규칙 적용. 내려가기 예외는 아래 명세 사용 |
| PlayerBody / EnemyBody | 지형과 충돌. 주인공-적·적-적끼리는 통과 |
| PlayerHurtbox / EnemyHurtbox | 상대 공격의 피해 탐색 대상. 몸을 추가 피해 대상으로 세지 않음 |
| PlayerAttack / EnemyAttack | 상대 피격 영역만 탐색하고 대상 ID로 중복 제거 |

접촉 자체 피해는 없다. 겹쳐 있는 적들도 공격별 다수 적중 대상이 될 수 있다. 역할명은 기존 Unity Layer 번호를 덮어쓰라는 지시가 아니다.

1챕터 카메라는 마지막 착지 높이를 기준으로 일반 점프의 세로 화면을 고정한다. 공중에서 기준 높이보다 위112px·아래48px 범위를 벗어나면 기준을 옮기며, 다른 높이에 착지하거나 계단·턱을 이동하면 세로 추종을 부드럽게 늦춘다(임계 감쇠10, 약0.5초에 정착). 일반 점프가 원래 높이로 돌아오는 하강 중에는 낙하 미리보기 보정을 적용하지 않는다. 낙하 속도가 15~25unit/s로 커지면 기존 감쇠 22까지 단단하게 따라가 긴 낙하에서 플레이어가 화면 아래로 빠지지 않게 하고, 낙하 미리보기 보정은 유지한다. 보스방 고정 시야는 감쇠 22를 쓴다. 수치는 `ForestCombatWorld.cameraVerticalOmega` 시험값이다. 점프 중 쏜 직선 탄은 카메라 이동만큼 화면에서 기울어 보일 수 있다.

카메라가 더 이동할 수 없는 맵 끝에서는 대기·이동 중 **몸과 들고 있는 무기의 실제 시각 범위**가 화면 안에 남도록 별도 이동 경계를 둔다. 공격 이펙트는 화면 밖을 허용한다. 투명 캔버스가 아닌 무기·방향·모션별 실측 범위로 계산한다. 구체적인 여백과 지원 화면 비율별 검증은 후속이며 현재 전투 씬 검증만으로 완료 처리하지 않는다.

## 이동과 점프

- 일반 수평 이동의 최고속도는 지상·공중 **7.5unit/s**다. [영구 이동속도 강화](../progression/roguelite-progression.md#영구-캐릭터-강화)(최대 +20%)와 노랑 잉크의 이동속도 증가는 이 최고속도에 덧셈 배율로 적용한다. 정지에서 최고속도까지 지상 **0.05초**·공중 **0.10초**, 최고속도에서 정지까지 지상 **0.03초**·공중 **0.08초** 동안 일정 가감속한다(1차 시험값). 반대 방향 입력은 감속으로 먼저 멈춘 뒤 같은 스텝의 남은 시간에 가속한다. 대시·벽점프 밀어내기·피격 밀림·공격 자체 이동은 기존 자체 속도를 쓰며, 끝난 뒤에는 그 순간 수평속도(최고속도로 제한)에서 일반 가감속을 이어 간다. 공격이 반환하는 즉시 이동 값은 바꾸지 않는다. 일반 이동·기본 대시·대시 점프 취소·첫/둘째 점프 속도·공통 상승/하강 중력의 편집 원본은 [locomotion/player.json](../../../data/combat/locomotion/player.json)이다. 기술별 이동/반동 거리·높이와 공통 탄도 중력을 구분한다.
- 총 **2단 점프, 각 3unit**이다. 첫 점프·재점프 모두 발동 위치에서 최대 3unit 상승하고 수직속도를 **+20unit/s로 교체**한다. 기존 속도에 가산하지 않는다. 점프 키를 누르는 시간과 관계없이 항상 최대 높이로 뛰며, 상승 중 키를 놓아도 상승속도를 줄이지 않는다. 착지 예약 후 키를 놓아도 같은 최대 높이로 뛴다. 키보드와 패드에 같은 규칙을 적용한다.
- 자유 공간의 점프 목표는 상승 0.30초 / 하강 0.24초다. 상승 가속도 66.6666667, 하강 가속도 104.1666667unit/s²를 사용한다. `v0=2H/Tup`, `gUp=2H/Tup²`, `gDown=2H/Tdown²`의 연속 운동 기준이며 물리 스텝 오차를 실측한다. 프로젝트 중력과 수동 가속도를 중복 적용하지 않는다.
- 유효 접지 이후 사용량 0→1→2로 관리한다. 걸어 떨어져도 0회 사용을 유지해 공중에서 두 점프를 사용할 수 있다. 착지로 회복하며 천장·옆벽·적 접촉·대시로 회복하지 않는다.
- 점프는 새 입력만 받는다. 공중 점프가 남으면 즉시 사용하고, 모두 소모했으면 **0.12초 예약**한다(1차 시험값). 그 안에 착지하면 첫 점프 1회를 실행한다. 착지·새 입력·예약을 중복 실행하지 않는다.
- 천장에 닿으면 상승속도를 0으로 만들고 낙하한다. 지형을 통과해 목표 높이를 보장하지 않는다.
- 공중 기본·특수 공격을 허용한다. 기본 공격의 일반 공중 이동은 7.5unit/s이며 기존 수직 운동·중력을 유지한다. 특수의 체공·이동 제한은 기술별 명세를 따른다.

## 테스트 환경의 벽타기·벽점프

- 연결된 벽면의 높이가 캐릭터 충돌 높이(현재 2unit)를 초과하는 고체 벽만 대상으로 한다. 같은 면에 세로로 연결된 지형은 합산하고, 낮은 벽과 일방향 발판은 제외한다.
- 벽 이동은 **↑를 유지하는 동안의 기어오르기** 하나뿐이다. 별도 잡기 키·정지 매달리기·미끄러짐은 없다. ↑를 누르고 벽에 닿으면 수직 `runSpeed` 7.5unit/s로 오르고, ↑를 놓거나 ↓를 누르면 벽에서 떨어져 일반 중력으로 낙하한다. ↑ 없이 벽에 닿는 것만으로는 붙지 않는다.
- ↑ 없이 일반 점프로 상승하며 벽·턱을 지날 때는 상승 운동을 끊지 않는다. ↑ 없이 벽을 향해 낙하할 때도 벽이 낙하를 늦추지 않는다.
- **벽 차기는 ↑를 유지한 상태에서 Space를 새로 누를 때만** 실행한다. 직접 접촉·근접 판정·예약·코요테 모두 같은 ↑ 조건을 사용한다. ↑ 없는 Space는 일반 점프이며, 지면의 Space와 일방향 발판의 ↓+Space는 기존 일반 점프·내려가기 규칙을 따른다.
- 근접 벽점프는 `wallJump.jumpCheckDistance` 0.15unit 안의 유효 벽을 고른다. 설정이 0이어도 기존 접촉 허용 거리 0.08unit은 사용한다. 양쪽 벽이 모두 후보면 누른 좌우 방향의 뒤쪽 벽, 좌우 입력이 없으면 바라보는 쪽 벽을 먼저 고른다. ↑를 누른 상태에서는 상승 중에도 벽을 찰 수 있고 일반 점프 횟수를 소비하지 않는다.
- 벽 스태미나는 벽마다 `wallSlide.staminaDuration` 1.0초다. 기어오르기가 스태미나를 사용한다. 다른 벽으로 옮기거나 착지하면 다시 채우고, 같은 벽에서는 남은 시간을 이어 쓴다. 소진하면 일반 낙하로 이탈하며 그 벽은 착지하거나 다른 벽을 거치기 전까지 다시 사용할 수 없다. 소진 직후 코요테도 ↑가 필요하다. `staminaDuration`이 0이면 제한이 없다.
- 수치 원본은 `data/combat/locomotion/player.json`이다. `wallSlide.clingDuration`, `wallJump.detachDuration`, `arrivalClingDuration`은 현재 0이며 현재 실행은 이 값으로 정지 매달림이나 붙기 지연을 만들지 않는다. 이전 프로필의 필드는 읽기·해시·왕복 저장용으로 보존한다. `wallSlide` 속도 필드는 보존만 하며 현재 실행에서 사용하지 않는다.
- 벽점프는 수직 초기속도 `firstJumpVelocity` 20unit/s, 벽 반대쪽 수평속도 `awayHorizontalSpeed` 18unit/s의 한 종류다. 제자리 수직 킥은 없다. `releaseCarryDuration` 0.15초 동안 수평 입력을 무시하고 이어서 `controlRecoveryDuration` 0.20초 동안 일반 공중 이동으로 복구한다. 착지·벽 접촉·공격·대시·입력 차단은 복구를 끝낸다. 이전 프로필에서 `releaseCarryDuration`이 0이면 `horizontalSpeed`·`carryDuration` 단일 킥을 사용한다.
- ↑를 유지하며 Space를 반복해 양쪽 벽을 번갈아 찬다. 킥 순간 누르던 벽 방향의 좌우 키는 뗄 때까지 입력 없음으로 보고, 다른 방향·새 공중 점프·착지·리셋에서 이 무시를 끝낸다. 킥은 승인 `wall_kick` 그림을 사용한다.
- 맞은편 벽에 도착하면 ↑가 눌려 있으면 바로 기어오르고, ↑가 없으면 붙지 않고 낙하한다. 0.2초 자동 매달림이나 수직속도 0으로 버티는 상태를 만들지 않는다.
- 벽 꼭대기 보조는 **↑를 누를 때만** 사용한다. 벽 윗면−발 위치가 `wallJump.ledgeHopHeight` 1.6unit 이하이면 올라선다. 별도 좌우 키를 함께 누를 필요는 없다. `ledgeHopHeight`가 0이면 이 보조를 사용하지 않는다.
  - `wallJump.ledgeClimbSeconds`가 0보다 크면(현재 0.48초) **그린 대로 올라선다**: 그 시간 동안 벽에 붙은 채 멈추고(점프·이동 입력 무시) 올라가기 그림이 벽 모서리에 붙어 재생된 뒤, 벽 앞면에서 `ledgeClimbForward`(현재 0.67unit) 들어간 윗면에 선다. 피격·경직·사망 등으로 벽 이동이 끊기면 그 자리에서 떨어진다. 설 자리가 막혀 있으면 아래 뜀으로 대신한다.
  - `ledgeClimbSeconds`가 0이면 윗면보다 0.15unit 높이까지 오르는 상승속도와 벽 방향 이동으로 뛰어 올라선다.
  - 1.6unit 은 올라가기 첫 그림에서 손이 모서리에 걸리는 발 깊이다(벽 오르기 그림에서 끊김 없이 이어진다).
- `wallJump.bufferDuration` 0.10초는 ↑+Space를 미리 눌러 진행 방향의 벽 접촉 순간 차는 예약이다. **접촉 시에도 ↑가 눌려 있어야** 한다. ↑ 해제·예약 만료·입력 차단·공격·대시·피격 이동잠금·사망·리셋은 예약을 제거한다. ↑를 다시 누르는 것만으로 취소한 Space를 되살리지 않는다. 근처에 벽이 없는 ↑+Space는 일반 점프다.
- `jumpAssist.wallCoyoteDuration` 0.10초 동안 벽에서 옆으로 이탈한 뒤에도 ↑+Space로 그 벽을 찰 수 있다. ↑ 없는 Space는 이 유예를 사용하지 않는다. 벽 꼭대기를 넘은 경우·착지·공격·대시·입력 차단·리셋에서는 유예를 적용하지 않는다.
- 벽타기에 무적을 부여하지 않는다. 천장·고체 바닥은 공통 충돌로 막으며, 공격·대시·피격 이동잠금·상태이상·입력 차단 중에는 벽타기가 중단된다. 본 게임에서 벽 능력을 언제 해금하는지는 별도 기획이다.
- 대시와 연계한 강화 벽점프는 후속 설계다. 현재 대시는 벽에 닿으면 끝나며 강화 벽점프를 만들지 않는다.

### 점프 정점 체공 보정

자발적인 첫 점프·공중 재점프는 자연스럽게 상승속도가 0이 되는 정점에서 **최대 0.06초** 동안 하강 시작을 늦춘다. 상승 궤적과 목표 높이 3unit은 유지하며, 0.06초가 끝나면 기존 하강 중력을 적용한다. 고정 스텝 안에서 정점 도달·보정·남은 하강 시간을 나누어 적분하므로 스텝 하나 전체를 추가 체공으로 계산하지 않는다. 이동·공격·대시 입력을 잠그지 않는다.

보정은 각 유효 점프의 자연 정점에서 한 번만 적용한다. 천장 충돌, 걸어 떨어짐, 적·투사체의 탄도, 특수의 강제 수직 이동에 적용하지 않는다. 새 점프·착지·대시·사망·리셋에서는 이전 보정 상태를 정리한다. 상승 0.30초·하강 0.24초의 기존 자유 공간 목표에 정점 보정 최대 0.06초가 추가된다. 최대 높이와 프레임별 시각 결과의 Unity 실측 검증은 별도다.

일반 점프와 2단 점프의 몸은 승인 그림의 원래 배율로 표시한다. `JumpMotionPresentation`의 몸 늘리기·몸 잔상은 기본적으로 끄고, 착지 압축·가로 팽창도 추가하지 않는다. 두 효과는 Editor의 표현 비교에서만 별도로 켜 볼 수 있다. 1·2챕터는 마을과 같이 120Hz 고정 이동 사이의 위치로 몸을 그리고(`ActorRenderInterpolation`, 표시 전용) 카메라도 그 위치를 따른다. 이동·점프 높이·속도·판정·충돌 위치는 바꾸지 않는다. `DoubleJumpPuff`의 2단 점프 발밑 이펙트와 대시·공격 전용 잔상은 각자의 기존 설정을 유지한다. 벽타기·벽점프 중에는 비교용 점프 효과가 켜져 있어도 이를 즉시 정리하고 전용 벽 모션을 원래 배율로 표시한다.

## 기본 대시

| 항목 | 규칙 |
|---|---|
| 방향 | 좌우 입력, 없거나 수평축 0이면 현재 시선 |
| 거리·시간·속도 | 4.5unit / 0.20초 / 22.5unit/s. 일반 이동속도를 더하지 않음 |
| 자원 | 최대 1회, 실제 시작에 소비, 시작+1초 회복. 착지로 초기화하지 않음. [대시 추가](../progression/roguelite-progression.md#대시-추가) 해금 시 최대 2회가 회복 하나를 공유: 가득 찬 상태의 첫 대시 시작+1초에 2회가 한꺼번에 회복 |
| 수직 | 대시 중 수직속도 0·중력 중단. 종료 후 0에서 낙하 |
| 무적 | 시작 경과 [0, 0.15초), 일반 공격·투사체 피해 무시 |
| 벽 | 즉시 대시·무적 종료, 환불 없음. 낙사 면역 없음 |

대시 중 공격 입력은 실행·예약하지 않는다. 유효 점프로 대시를 취소할 수 있다. 일반 점프 사용량을 소모하고 **진행 방향 수평 5를 0.10초 유지**한 뒤 일반 공중 조작으로 돌아간다. 이 구간에 추가 무적은 없다. 점프를 다 썼으면 대시를 계속하며 자원·회복시각을 바꾸지 않는다. 취소 시 남은 대시 이동·무적을 종료한다.

대시 잔상은 기존 생성 간격에 더해 몸이 원본 그림 기준 2px 이상 이동했을 때만 남겨, 감속 끝에서 같은 위치에 겹쳐 쌓이지 않게 한다. 종료 뒤에는 기존 자세 복귀 시간 0.10초 안에 추가로 감쇠하며 완전히 사라진다. 지상에서 시작한 대시도 발판을 벗어나면 공중 대시와 같은 `jump_apex` 자세로 전환하고 이전 웅크린 잔상을 정리한다. 대시 종료 뒤에는 정상 공중·착지 모션으로 돌아가며 이동 보간·거리·속도 곡선·낙하·무적·판정은 변경하지 않는다.

## 지형·발판·생존 낙사 복귀

초기 전투 테스트는 평지·벽·점프로 넘는 높이차·일방향 발판이다. 경사 보행·자동 계단 오르기는 후속 범위다.

- **아래 이동키 + 점프**(기본 ↓+Space)로 현재 서 있는 일방향 발판만 통과한다. 아래 0.08unit 보정·수직속도 -2로 시작하고 고체 관통이 없는지 검사한다. 최소 0.25초가 지난 뒤 몸 전체가 발판 아래로 0.02unit 이탈하거나, 다시 점프해 발이 발판 위로 0.02unit 올라오면 충돌을 복구한다. 바닥과 발판 사이가 몸 높이와 같은 낮은 디딤도 내려간 뒤 다시 올라서고 착지할 수 있어야 한다.
- 내려가기는 점프 사용량을 소모·회복하지 않는다. 일반 고체 바닥과 아래 다른 발판은 통과하지 않는다. 고체 바닥의 아래+점프 동작 선택은 후속 입력 설계다.
- 낙사는 맵에 명시한 영역으로 판정하며 카메라 하단이나 고정 Y값만으로 정하지 않는다. 한 추락에 **현재 최대 HP의 10% 피해 1회**를 적용한다. HP가 0이면 사망하고 생존 복귀하지 않는다.
- 생존 시 낙사 시각 `T-3초` 이하의 가장 최근 **평평하고 몸 전체를 지지하는 안전 접지 표본**으로 복귀한다. T-3에 공중이면 그 이전 표본을 사용하며 더 최근 접지를 고르지 않는다. 연속 접지 중에도 기록하고 3초보다 오래된 마지막 유효 접지를 버리지 않는다.
- 표본의 지형·위험 겹침을 재검사하고 부적합하면 더 이전 표본을 찾는다. 기록이 없으면 테스트 구역의 검증된 시작 위치를 사용한다. 챕터 연결 공간에서 기록 식별 범위·시작 위치를 연결하는 세부 규칙은 후속 맵 설계다. 이전 챕터로 복귀하지 않는다.
- 배치 후 일반 공격·투사체 보호 0.60초, 즉시 이동·공격 가능, 점프 사용량 0이다. 대시 자원·절대 회복시각과 현재 적·진행 상태를 유지한다. 과거 체력·세계 전체를 복원하지 않는다. 낙사 피해는 대시·복귀 보호·보호막·피해 감소를 우회한다.

생존 낙사 복귀와 체력 0 이후 반복 귀환의 서사를 구분한다. 반복 귀환의 방식·세계 시간은 재기획 대상이다.

## 피격·사망·리셋

- 초기 최대/현재 HP는 **100**이다. 피해 계산은 소수로 유지한다.
- 유효 피격은 일반 이동 입력만 **0.12초 잠금**, 추가 피격 무적 **0초**다. `test/combat-feel`의 플레이어 밀림은 `data/combat/player_hit_reaction.json`을 사용한다. 일반 타격은 최소 **0.9unit / 0.18초**, 마을 몬스터 근접 공격은 피격 당시 공격 박스 끝에서 플레이어 피격 영역이 **0.18unit** 더 벗어나는 거리까지 밀리며 최대 **4.5unit**으로 제한한다. 고체 벽에서는 멈추고 투사체 공격의 긴 사거리 박스는 밀림 거리에 사용하지 않는다. 시험 정책이 꺼져 있으면 기존 **0.5unit / 0.10초**를 사용한다. 공격·특수·점프 수직 운동·대시 타임라인 자체는 생존 피격으로 취소하지 않는다.
- 기본 대시·특수의 실제 강제 이동 구간에서는 피해·입력 잠금은 적용하되 밀림을 생략한다. 일반 밀림이 진행 중일 때 새 밀림도 생략하고 기존 방향·종료시각을 유지한다. 생략한 밀림을 나중에 예약하지 않는다.
- 별개 타격마다 피해를 적용하고 입력 잠금을 마지막 피격+0.12초로 갱신한다. 남은 시간에 더하지 않는다. 무적·패링으로 막은 타격은 피해·피격 잠금·밀림을 만들지 않는다.
- HP 0 이하이면 런 종료·사망 연출·결과 화면을 거쳐 사용자 입력으로 새 런을 시작한다. 정산·새 런은 중복 실행하지 않는다. 런 장비·잉크 강화·진행은 초기화하고 영구 해금 방향은 유지한다. 실제 영구 저장 항목·경제·시작 장비·시작 장소는 후속 설계다.
- 짧은 사망 슬로우는 플레이어의 실제 사망 순간에만 허용한다. 몬스터 처치 자격으로 사용하지 않는다. 요청의 합성·일시정지·정리는 [연출 기준](../presentation/art-and-presentation.md#전투-화면-반응과-사망-슬로우)과 [타격감 기술 계약](../../development/presentation/visuals/combat-hit-feedback-design.md)을 따르며 피해·공속 원본은 변경하지 않는다.
- 새 런은 HP 100, 점프 0회 사용, 대시 1회 보유(대시 추가 해금 시 2회), 이전 일시상태·공격·효과·입력 예약 없음으로 시작한다.
- 개발용 전투 리셋은 테스트 공간·설정 장비를 유지하고 체력·적 배치·쿨타임·충전·효과·예약을 초기화한다. 실제 세이브·재화·해금을 변경하지 않고 반복 리셋으로 보상을 생성하지 않는다. 테스트 프로필을 실제 저장과 분리한다.

## 기본 공격·입력 우선순위

- 기본 공격은 타격마다 새 입력이다. 현재 타격 중 후속 입력 **1개 예약**, 종료 후 **0.30초 이내** 다음 타격 연계, 초과 시 새 1타다. 마지막 타격 중 예약은 종료 후 새 1타를 시작한다. 버튼 유지 자동 반복은 없다.
- 근접 기본 공격의 방향은 **모션 중 좌우 입력을 따라 전환**한다. 몸·그림·판정 방향을 함께 맞춘다. 지상에서 이동 가능한 형태는 방향 입력이 있는 동안 **각 타격마다 0.65unit / 0.08초 전진**한다. 전진 시간창은 타격 기준 앞뒤 0.04초이며 공속으로 시간만 축소한다. 망치·대검은 지상 제자리다. 공중은 모든 근접 기본 공격에서 일반 이동 7.5·중력을 유지한다. 손맛 시험 값([`attack_feel_motion.json`](../../../data/combat/attack_feel_motion.json))이 있는 기본 공격은 이 전진 대신 방향 입력과 관계없이 시선 방향으로 지정 거리를 타격 시각까지 감속 곡선으로 전진하고, 앞의 살아 있는 적 몸 0.15unit 앞에서 멈춘다. 현재 검 1·2타 0.5·0.75unit, 망치 0.3125unit이며 테스트 후보다.
- 원거리 기본 공격의 방향·지상 이동·반동은 [원거리](../equipment/weapons/forms/ranged.md)와 [발사기](../equipment/weapons/forms/launcher.md)의 개별 명세를 따른다.
- 유효 점프·대시·아래점프로 기본 공격의 준비·활성·회복 어느 구간에서든 즉시 취소하고 미발생 직접 타격·남은 활성·후속 예약을 제거한다. 아래점프는 통과 가능한 일방향 발판에서 실제 내려가기가 성공할 때만 취소하며, 고체 바닥·내려가기 금지 발판·발판 없음 등으로 실패하면 현재 공격과 예약을 유지한다. 아래점프는 점프 사용량을 바꾸지 않는다. 자원이 없으면 취소하지 않는다. 이미 발사된 독립 효과는 유지한다.
- 기본 공격 중 Q/W(무기 1/2 스킬)을 누르면 대상 슬롯의 사용 조건을 확인한 뒤 준비·활성·회복 어느 구간에서든 기본 공격을 즉시 취소하고 그 슬롯의 특수 준비를 시작한다. 다른 슬롯의 스킬이면 그 슬롯으로 전환하며 기본 연계는 새로 시작하고 [스위칭 준비 단축](rules.md#무기-스위칭-취소)을 따른다. 미발생 직접 타격·남은 활성·기본 후속 예약을 제거한다. 쿨타임·지상·대상 조건을 만족하지 못하면 기본 공격을 유지한다. 특수 자체의 준비 시간과 실제 발동 시 쿨타임 소비 규칙은 유지한다.
- 동시 입력은 사망/낙사 → 강제상태·충돌 → 현재 상태에서 유효한 대시 → 유효 점프(아래점프 포함) → 특수 → 기본 공격 → 일반 이동 순서다. 대시 중 유효 점프 취소는 상태별 예외이며, 아래점프로 대시나 특수를 취소하지 않는다. 현재 동작 종료 시 **교체 예약이 공격 예약보다 우선**하며 공격 예약을 삭제한다.

## 무기 스위칭 취소

현재 선택하지 않은 다른 무기의 Q/W(스킬)은 **예약하지 않고 즉시** 처리하고, A/S(기본 공격)는 진행 중인 동작이 있으면 **후속 1개로 예약**해 그 동작이 끝난 뒤 시작한다. 대상 슬롯의 준비·쿨타임·지상·대상 조건을 먼저 검사하고, 만족하지 못하면 거절하며 현재 동작을 유지한다.

- **기본 공격 중 다른 무기 A/S**: 현재 타격 모션(준비·활성·회복)이 끝난 시각에 다른 무기의 기본 공격(새 1타)을 시작한다. 같은 무기 후속 예약과 한 칸을 함께 쓰며 나중 입력이 앞 예약을 대체한다. 회복 구간을 끊는 것은 [교대 공격 잉크](rules.md#교대-공격-잉크-역할)의 적중 시 후딜 캔슬뿐이다.
- **기본 공격 중 다른 무기 Q/W**: 준비·활성·회복 어느 구간에서든 현재 기본 공격을 즉시 취소하고 그 무기의 스킬을 시작한다. 미발생 직접 타격·남은 활성·기본 후속 예약을 제거한다.
- **특수 중**: 실제 발동(쿨타임 소비) 이후부터 다른 무기 Q/W은 같은 방식으로 즉시 취소·전환하고, 다른 무기 A/S는 1개 예약해 특수가 끝난 뒤 시작한다. 발동 전의 다른 무기 입력은 예약 없이 거절한다. 시작된 쿨타임과 독립 투사체·잔상·장판·표식은 유지하고 직접 다단의 남은 타격은 제거한다. 폭탄 미사일 비행 중 입력 예외는 유지한다.
- **스위칭 준비 단축**: 이전 동작이 첫 타격·효과를 발생시킨 뒤(근접 타격 시각, 원거리 발사, 특수 발동) 다른 무기 공격이 즉시 전환이나 예약 연계로 이어지면 전환한 무기의 첫 공격 **준비 구간(시작~첫 타격·발동)**에 기본 단축률과 이전 무기의 [휘몰아치기](rules.md#교대-공격-잉크-역할) 단축률을 곱으로 적용한다. 기본 단축률은 **0%**이며 수치 원본은 [`weapon_switch.json`](../../../data/combat/weapon_switch.json)의 `afterHitWindupReduction`이다. 명중 여부는 따지지 않는다. 기본 공격·스킬 모두 적용하며 활성·회복·쿨타임은 바꾸지 않는다. 첫 타격 전에 전환하면 단축 없이 시작한다.
- 같은 무기 입력은 기존 규칙을 따른다. 기본 공격 중 같은 무기 기본은 후속 1개 예약, 같은 무기 스킬은 즉시 취소이며 스위칭 단축은 없다. 특수 중 같은 무기 입력은 거절한다.
- 대시 중 공격 입력은 기존대로 거절한다. 유효 점프·대시는 다른 무기 예약도 제거한다. 공중에서도 같은 규칙을 적용한다. 무기별 쿨타임은 독립 진행하고 스위칭으로 바꾸지 않는다. 전환하면 이전 무기의 기본 연계는 초기화한다.
- 동작이 이미 끝난 대기 상태에서의 다른 무기 공격은 스위칭으로 보지 않아 단축하지 않는다. 예약 연계는 이전 동작의 종료 시각에 바로 이어지므로 스위칭으로 본다. 차지형 특수의 모으기 시간은 플레이어가 조절하므로 단축하지 않는다. 시험 잉크 파츠의 준비 단축과는 곱으로 중첩한다.

### 교대 공격 잉크 역할

잉크가 없으면 A/S 교대 입력은 한 타격 모션이 끝나야 다음 무기가 나간다. 교대 공격의 세 병목을 서로 다른 노랑 색상 잉크가 하나씩 줄인다. 하나만 끼면 그 구간만 빨라지고, 함께 끼면 [준비 단축 → 적중 즉시 후딜 캔슬 → 반대 무기 준비 단축]이 맞물려 고속 교대 난타가 된다. 역할 분리는 사용자 결정이고 이름·수치는 시험 초안이다. 원본은 [`ink_color_parts_proposal.json`](../../../data/combat/ink_color_parts_proposal.json)이며 [색상 잉크 파츠](../../development/data/catalogs/ink-color-parts.md#노랑--이동으로-피해)에 생성된다.

| 역할 | 잉크 | 줄이는 구간 | 적용 조건 |
|---|---|---|---|
| A 기본 모션 속도 | `ink3_yellow_02` 뛰어난 발걸음 | 공속 10%로 그 무기 공격의 준비·회복 | 상시. 마지막으로 공격한 무기의 팔레트에 있을 때 |
| B 스위칭 준비 단축 | `ink3_yellow_04` 휘몰아치기 | 바꿔 든 무기 첫 공격의 준비 50%, 바꿔 든 무기 공속·이속 30% 3초 | 이 잉크를 낀 무기의 공격이 첫 타격·효과를 낸 뒤 다른 무기 공격으로 이어질 때. 준비 단축은 쿨타임과 관계없이 매번, 공속·이속은 쿨타임 3초마다 |
| C 적중 시 후딜 캔슬 | `ink3_yellow_07` 끊어 치기 | 현재 기본 공격의 남은 회복 | 이 잉크를 낀 무기의 기본 공격 원타격이 몬스터에게 적중한 그 공격만. 회복 구간에서 다른 무기 A/S를 누르면 바로 끊고 시작한다. 판정 구간에서 누른 입력은 예약했다가 회복이 시작될 때 끊는다 |

- 허공을 때린 공격, 추가타·지속·장판 피해로는 C가 열리지 않는다. 같은 무기 연계와 특수의 회복은 끊지 않는다. C로 끊은 전환도 첫 타격 뒤 전환이므로 B의 준비 단축을 받는다.
- 잉크는 무기 팔레트 단위로 적용한다. B·C는 이 잉크를 낀 무기에서 나가는 전환에만 작동하므로 양방향 교대에는 두 무기에 모두 낀다.
- 공속은 준비·회복만 줄이고 판정 구간은 유지한다. B의 준비 단축, 공속, 시험 잉크 파츠의 준비 단축은 곱으로 중첩한다.

## 판정·피해·공속

모든 타격은 소유자·원본 무기·공격 실행·타격번호·기본/특수 분류·효과 인스턴스·스냅샷을 추적한다. 같은 실행/타격번호는 대상당 1회 피해다. 여러 프레임·복수 콜라이더·재진입으로 같은 타격을 반복하지 않는다. 다단은 타격번호를 나누고 지속 효과는 명시된 적별 간격을 사용한다. 가시·장판의 피해 주기는 별도 콘텐츠 설계다.

고체 벽·바닥은 공격을 차폐한다. 다만 [직선 투사체형 원거리 특수](../equipment/weapons/forms/ranged.md)는 발사 경로와 탄체의 지형 충돌을 무시하고 기존 사거리까지 진행한다. 레이저도 지형 차폐를 무시한다. 폭발·근접·기본 투사체·플레이어 이동의 고체 검사는 각 기존 규칙을 따른다. 일방향 발판은 일반 근접 공격을 차폐하지 않는다. 대형 적의 노출된 피격 부분과 벽 뒤 부분을 구분하고 투사체는 이동 구간 스윕으로 얇은 지형·표적을 건너뛰지 않게 한다. 투사체의 발판 충돌은 개별 명세를 따른다.

전방 근접 기본공격·특수공격은 몸 전체와 **몸 뒤 경계에서 0.25unit(8px)**까지 판정에 포함한다. 오른쪽을 볼 때 박스의 뒤쪽 끝은 발/root 기준 x=-0.53125이고 왼쪽은 대칭이다. 기존 앞쪽 끝·높이·타격 시간·피해는 유지한다. 겹친 적도 같은 타격의 대상으로 판정하며, 잔상은 저장한 위치·방향에서 같은 뒤쪽 범위를 사용한다. 양방향 공격·투사체·설치 효과는 각자의 형상을 유지한다. 대검 기본공격만 예외로 몸 앞끝(root x=±0.65625)부터 기존 전방 끝까지 판정한다. 대검 특수 4종은 기존 범위를 유지하며 기본공격의 전방 제한을 적용하지 않는다. 예외로 방패 밀기(`shield_movement`)는 root 기준 앞뒤 2unit 대칭(폭 4·높이 4.5·바닥 발 높이) 박스를 사용해 몸 뒤 2unit까지 판정한다.

- 피해 = `기준 피해 × (1 + 해당 종류 증가율 합계)`. 기본·특수 증가를 분리하고 초기 적 방어는 0이다. +20% 두 개와 기준 피해 10이면 14다.
- 플레이어가 적에게 주는 전투 피해는 무기·잉크 보정 후 유효 타격마다 독립적으로 균등 추첨한 **90~110%**를 한 번 곱하고 피해 감소·보호막을 처리한다. 기본·특수·투사체·반사·지속 피해 모두 적용한다. 몬스터·보스가 플레이어에게 주는 피해에는 이 변동을 적용하지 않고 기본 피해의 **100%**를 사용한 뒤 피해 감소·보호막을 처리한다. 단, 시계탑 집행자 믹서의 기본 피해 자체를 7 또는 8로 고르는 무작위는 유지한다. 소수 정밀도로 실제 피해를 계산하며, 피해 숫자는 적용된 피해를 반올림(0.5 올림)해 정수로 표시한다. 낙사는 최대 HP의 10%를 유지하고 보스 시간 초과의 강제 사망 같은 명시적 우회 처리는 변동하지 않는다. 배율 원본은 `data/combat/damage_variance.json`이다.
- 기본 피해/특수 피해 잉크는 개당 ×1.2, 기본 공속은 개당 ×1.1(상한 없음), 특수 쿨타임은 개당 남은 쿨타임 ×0.8이며 같은 종류끼리 곱해 중첩한다. 쿨타임 감소량은 최대 80%다. 등급은 초기 단일 등급이다.
- 기본 공속 배율 M은 준비·활성·회복을 M으로 나눈다. 연계 여유 0.30초는 고정한다. 기본 공속을 특수 모션·투사체 탄도에 적용하지 않는다. 물리 갱신보다 짧은 활성창도 시간 구간 교차로 검출한다.
- 독립 효과는 원본 무기의 실제 발동 당시 스탯을 저장한다. 이후 교체·정비로 기존 효과를 재계산하지 않는다. 생성된 투사체·잔상·장판은 취소·교체 후 유지하고 사망·런 종료·리셋으로 제거한다. 직접 다단은 취소 시 남은 판정을 제거한다.

## 특수·정비·상태이상

- 무기 2개, 개별 무기마다 형태 1 / 능력치 5 / 특수 1칸, 미장착 잉크 15개, 추가 무기 보관 0이다. 장착분은 가방 한도에서 제외한다.
- 특수 쿨타임 = `기본값 × (1 - min(감소율 합계, 0.8))`. 실제 효과 발동부터 무기별 독립 진행하고 비활성 무기도 회복한다. 발동 전 취소는 무료, 빗나감·발동 후 벽 소멸은 소비다.
- 일반 특수는 점프 입력을 예약 없이 무시하고 유효 대시로 취소한다. 실제 발동 이후에는 다른 무기 스킬로 [스위칭 취소](rules.md#무기-스위칭-취소)하고 다른 무기 기본 공격은 특수가 끝난 뒤로 예약한다. 대시 취소 시 교체 예약도 삭제한다. 폭탄 미사일 비행은 개별 입력 예외를 따른다.
- 충전형은 순차 회복하고 추가 소모로 타이머를 초기화하지 않는다. 정비는 남은 비율을 유지한다. 충전 수가 달라지는 전환은 [회복 부담 정규화](../equipment/weapons/forms/melee.md#충전정비취소의-예외)를 따른다.
- 잉크 정비는 전투 종료 후 허용한다. 챕터 연결 공간의 전투 종료·안전 정비 조건은 후속 설계다. 실물 재고·교환·비활성 UI·고유 드랍은 [무기·잉크 시스템](../equipment/rules.md)을 따른다. 테스트 장비 직접 공급을 실제 재고 구현으로 취급하지 않는다.
- 일반 적 기본 경직은 0.30초·현재 공격 취소, 재피격은 마지막 타격+0.30초 갱신이다. 플레이어 기본공격 피격에 타격 방향0.25unit/0.10초 밀림을 적용하며 고체 벽에서 멈춘다. 별도 밀기 효과와 합산하지 않는다. 보스·미끼는 기본 밀림에서 제외하며 보스 기본 경직은0이다. 손맛 시험 값이 있는 플레이어 공격은 기본 밀림 대신 그 밀림을 같은 거리·종료 시각 안에서 처음에 빠르고 끝에서 부드럽게 멈추는 3차 감속 곡선으로 적용하고, 기본 공격이 아닌 강베기도 같은 기본 경직·공격 취소를 받는다. 현재 검 1·2타 0.5·0.8125unit/0.12초, 망치 1.75unit/0.16초, 강베기 1.5unit/0.16초이며 테스트 후보다.
일반 피격 밀림은 다음의 사거리 상한을 함께 적용한다.

- 장착하고 사용할 수 있는 근접 무기가 둘이면 각 무기 기본 연계의 가장 짧은 전방 사거리 중 작은 값을 사용한다. 근접+원거리 또는 근접 한 개만 사용 가능하면 해당 근접 무기의 기본 사거리를 사용한다. 원거리 슬롯의 탄 비행거리는 계산에 넣지 않는다.
- 명중 순간의 플레이어 위치·공격 방향·대상 피격박스와 기본 사거리로 허용 밀림 거리를 저장한다. 공격자 쪽 피격박스 끝이 사거리 끝에서 `basicPushOverlap` 0.25unit 안쪽에 남도록 하며, 피격박스 폭이 더 작으면 그 폭을 사용한다. 안쪽은 기존 밀림 거리, 경계 근처는 남은 허용 거리까지만 밀린다.
- 이미 경계 밖인 적은 추가로 밀거나 안쪽으로 당기지 않는다. 경계에서 다시 맞으면 이전에 남은 일반 밀림도 새 거리 안으로 갱신하고, 피해·경직·공격 취소는 정상 적용한다. 플레이어 이동·무기 교체·사용 가능 슬롯 변경으로 이미 시작한 밀림의 경계를 옮기지 않는다.
- 현재 공격에 적용된 사거리·영역 확대는 그 공격의 시작 스냅샷을 사용한다. 대기 중인 다른 근접 무기는 현재 기본공격 정의의 기준 사거리를 사용하며, 다음 공격용 효과를 미리 발동·소비하지 않는다.
- 일반 밀림을 사용하는 강베기에도 같은 상한을 적용한다. 기술 데이터의 전용 밀기·돌진으로 밀어붙이기와 원거리 탄·폭발의 밀림은 각 기술의 설정을 사용한다. 고체 지형 충돌과 보스·미끼의 기존 밀림 자격을 유지한다.

- 속박은 이동 금지·공격 가능, 일반 적과 플레이어의 기절은 현재 공격 취소·이동/새 공격 금지다. 이미 발사한 탄은 유지한다. 재적용은 남은 시간과 새 시간 중 긴 값이다. 보스의 기절은 아래 예외를 따른다. 보스는 밀기·끌기·도발에 면역이다.
- 먹안개는 은신과 별도로 생성0.5초 뒤부터0.5초마다 영역 내 적에게6피해를 준다. 4초 만료 시각까지8틱이며, 매 틱 범위·고체 차폐를 재검사하고 특수 피해 배율은 발동 시 저장한다. 연막 틱 자체는 기습·은신 해제를 일으키지 않는다. 발동 후 취소·교체에도 남고, 같은 시전자 재설치·사망·리셋에는 제거한다.
- 은신은 추적 대상에서 제외하고 실제 공격 시작에 해제한다. 무적은 아니다. 도발은 일반 적에게 적용하고 이미 발사된 공격은 유지한다.
- 기습: 현재 기습 추가 피해는 숨죽이기·연막 모두 0이다(2026-11-10). 값을 다시 주면 플레이어가 은신 중에 직접 타격이 있는 공격을 시작했을 때 그 공격이 처음 받아들여진 적중 대상 한 명에게 추가 피해(동시에 유효하면 큰 값)를 더한다. 추가 피해는 기준 피해에 더해 그 공격의 피해 배율을 함께 받는다. 무기 종류와 기본·특수를 가리지 않으며, 같은 공격의 나머지 대상·타격과 은신이 풀린 뒤 시작한 공격에는 없다. 무적·회피로 막힌 적중은 소비하지 않는다. 투사체·폭발·지속 피해는 기습을 받지 않는다. 수치 원본은 `data/combat/stealth_ambush.json`이다.
- 숨죽이기 해제 가속: 숨죽이기 은신이 풀리면(공격 시작으로 해제되거나 3초가 끝나면) 그때부터 4초 동안 기본 공격 공속이 50% 빨라진다(×1.5). 특수 공격과 연막 은신에는 적용하지 않는다. 수치 원본은 `stealth_ambush.json`의 `stealthExitBasicSpeedBonus`·`stealthExitSeconds`다.
- 방패 패링은 전방 180도·[0,0.20초) 창에서 첫 성공한 공격 하나만 차단하고 창을 닫는다. 실패 쿨타임1.20초·기본 모션0.45초, 성공 시점부터 고정0.60초 재무장·0.10초 회복이다. 이 반응 시간과 성공 재무장 하한은 공격 준비/회복 강화·쿨감·쿨타임 환급으로 줄이지 않는다. 근접은 공격자 한 명에게 고정26×특수 피해 배율, 투사체는 방향·소유자 반전·한 번만 반사하며 추가 근접 반격은 없다. 반격·반사는 기존 스킬/특수 적중 분류를 유지하며 잉크 상태 조건·공격당 발동 제한도 적용한다. 후방·레이저·장판·낙사는 패링하지 않는다. 수호막·방패 밀기·미끼에는 패링을 추가하지 않는다. 시계탑 집행자·Rose·Blue의 패턴별 방향·반격·반사 예외는 각 보스 명세가 소유한다.

## 검증 기준과 남은 범위

수치·상태 전이의 기대 결과와 실제 실행 증거를 구분한다. 좌우 벽 밀착/반전, 고공속 시간창, 적 겹침/중복, 공중 동작, 취소 전후 소비, 독립 효과의 위치/스탯, 낙사 안전 접지, 보스 제어, 장비 유지 리셋을 검사한다. 수동 검증 절차와 자동 테스트 실행법은 [구현 안내](../../development/testing/testing.md)에 있다.

카메라 끝 시각 여백, 챕터 탐험·전투 종료·정비 판정, 실제 획득/드랍/저장, 전용 잉크 콘텐츠, 미정 종류·형태, 전체 밸런스와 구형 코드 이행은 후속 범위다.

## 보스의 기절 상태와 패턴

보스에게 기절·속박·슬로우를 부여하고 남은 시간·아이콘·이펙트와 빨강·파랑 조건 판정을 유지한다. 다만 이 상태로 패턴을 중단·취소하거나 이동을 잠그거나 이동·공격 동작을 감속하지 않는다. 보스 자신의 교대·연출 상태는 각 보스 규칙을 따른다.

### 보스의 기절·속박 내부 쿨타임

보스 전용 재부여 제한은 없다. 기절·속박 내부 쿨타임 데이터는 모두 0초이며 슬로우에도 새 제한을 추가하지 않는다. 원본 무기 보라 잉크의 활성 시간·재사용 시간은 그대로 적용한다. 데이터 원본은 [boss_status_design.json](../../../data/combat/boss_status_design.json), 잉크 중복 및 부여 규칙은 [잉크 효과](../equipment/inks/effects.md)를 따른다.

### 스킬 발동과 근접 범위 대상

모든 스킬은 전방에 적이 없어도 발동할 수 있다. 적이 없으면 공격은 헛스윙하고 보호·은신·설치 등 자기 효과는 기존 조건대로 실행하며 실제 발동 시 쿨타임과 자원을 소비한다. 지상 전용, 쿨타임, 자원, 설치 공간의 조건은 유지한다. 순간이동할 적이 없으면 제자리에서 공격한다.

검·채찍·레이피어·단검과 망치·방패·대검의 근접 기술은 각 타격의 정해진 범위 안 모든 적에게 전체 피해를 준다. 타격 번호별 대상당 한 번이며 기존 다단 타격 수·시간·박스·차폐 조건은 유지한다. 이동 기준 적 하나를 고르는 것은 피해 대상을 한 명으로 제한하지 않는다. 표식형 후속타는 본타에 맞은 모든 적을 각자 기억하고, 그중 살아 있는 대상에만 예약 피해를 준다.

### 보스 연출의 화면 우선순위

보스 입장·페이즈 전환·흡수·퇴장 연출은 캐릭터 기술의 전체화면 효과보다 우선한다. 연출 시작 시 진행 중인 암전·색 반전·스킬 임시 줌을 걷어내며, 연출 중 시작된 전체화면 효과도 건너뛴다. 중단한 효과는 연출 종료 후 기존 시전 시각에서 되살리지 않는다. 연출이 끝난 뒤 새로 시전하는 기술은 원래 화면 효과를 재생한다.

피해·타격 시각·자원·쿨타임과 일반 타격·바닥·투사체 효과, 보스의 전조·기믹·자체 연출은 유지한다. 일반 일시정지는 이 우선순위를 부여하지 않는다.
