# 몬스터 제작 원본

- 이 경로는 외부 리소스 저장소의 공통 제작 원본이다. Git 명령·커밋은 외부 저장소의 합의한 작업 브랜치에서 수행한다. 메인 게임 저장소의 브랜치·게임 수치·씬을 제작 도구에서 변경하지 않는다.
- 현재 확정 프레임과 박자는 `approved/manifest.json`·승인 PNG가 기준이다. 일반 3종은 외곽선 없는 v3, 우물 도르래는 v4 보정본을 유지한다. 이전 편집 JSON을 현재 승인 PNG 위로 다시 내보내지 않는다. 사용자 미채택 후보를 승인으로 바꾸지 않는다.
- 고정 팔레트는 `approved/master-palette.json`의 정확한 6색과 알파 0/255다. `paletteLock: true`를 유지한다. 디더링·새 색·반투명·흐림·AA·임의 리사이즈를 허용하지 않는다. 작은 내부 명암·실루엣·발 원점을 보존한다.
- 일반·엘리트 기본/대기/걷기는 128×128, PPU32, pivot (0.5, 0.0625)다. 가시뿌리의 걷기 방향·잎 보정과 먹빗자루·배수관 좌우반전을 유지한다.
- 엘리트 공격은 C안 34장/2830ms다. 앞 18장/1600ms 갈고리 투척·회수 뒤 16장/1230ms 반대 손 할퀴기로 이어진다. 448×180 캔버스·지면 y165·뒤 발 x332, pivot (286/448, 15/180), 갈고리 최대 도달 150px를 유지한다. 게임의 선택적 가속·근접 후속 판정은 메인 규칙이며 원본 박자를 바꾸지 않는다.
- 엘리트 대기는 20장/2060ms, 배수관·엘리트 걷기는 각각 24장/2400ms의 왼쪽 걷기다. 머리·몸통·갈고리·빈손의 후행과 `idle/parts/` 편집 부위를 보존한다.
- 피격 5종 v4의 머리 보정을 유지하고 실루엣 높이로 정규화하지 않는다. 피격 120ms는 편집 길이이지 게임 경직 수치가 아니다. 엘리트 죽음은 작은 잉크 방울 v4, 34장/1790ms, 본체 128×128을 (32,24)에 둔 192×160 FX 캔버스·ground y144·pivot (0.5,0.1)다. body/fx 동기 레이어와 90ms 피격 정지 뒤 잉크 폭발·붕괴를 유지한다.
- 엘리트는 화면 왼쪽 금속 갈고리와 화면 오른쪽 빈손으로 역할을 구분한다. 얇은 사슬·부위 단면·분리 FX를 외곽선 정리나 빈틈 채움으로 손상하지 않는다. 승인 v4의 재질색·프레임 외곽 1px 보정과 알파·시간을 보존한다.
- 이전 이동형 시계탑 기본·피격은 `approved/05_clock-executioner/`에 보존한다. 새 제작은 메인 `docs/development/clock-executioner-sprites.md`의 천장 사슬 고정형 기준이다. 이전 이동형 구상·시험방 분리 부품을 새 승인 모션으로 취급하지 않는다. 걷기·일반 이동·기본 공격을 추가하지 않는다.
- 공격 FX 기준은 `approved-effects/manifest.json`이다. 최대 3 RGB색·윤곽선 없는 네이티브 도트를 사용한다. 요청된 빗자루 연기 소멸만 크기를 유지한 프레임 전체 균일 알파 페이드를 허용한다. 본체·다른 불투명 FX에 이 예외를 확장하지 않는다. 사용자가 제외한 시안을 다시 붙이지 않는다.
- 픽셀 수정 시 관련 편집 데이터·PNG·시트·해시를 함께 검증한다. 원본 ZIP·다른 세트를 덮어쓰거나 바이트가 다른 파일의 해시만 바꿔 통과시키지 않는다. 미술 승인·원본 생성·Unity 적용·피해/충돌/밸런스 검증을 구분한다.
- `editor/`의 고정 공통 UI와 사용자 저장 픽셀·배치·메타데이터를 유지한다. UI 자체 변경을 요청받은 경우에만 HTML/JS/CSS를 바꾸며 먼저 `editor/AGENTS.md`를 읽는다. 브라우저 저장소의 사용자 작업을 지우지 않는다.
- 제작 출력은 외부 `tools/export_stage1_monster_motions.py`, `export_stage1_monster_effects.py` 등으로 새 빈 검토 디렉터리에 만든다. 메인에 적용할 때는 배치 계약·gitlink·Unity 어댑터를 명시적으로 갱신하며 게임 수치의 원본은 메인 `data/combat/`에 유지한다.
