# J-01 공통 게임·경제 이벤트 스키마

이 문서는 기능을 찾기 위한 경로 문서다. 정책, 수치, 상태, 완료 여부를 정의하지 않는다.

- 규칙·수치·상태의 정본: [데이터·이벤트 SSOT](../ssot.md)
- 실행 상태·완료 기준·증거: [J-01 작업 문서](../../../wiki/06-delivery/tasks/J-delivery-operations/j-01-game-economy-event-schema.md)

기능 요구가 바뀌면 먼저 정본 문서의 책임 범위를 확인하고, 필요한 결정은 [결정 로그](../../../80-decisions/README.md)에 남긴다.
