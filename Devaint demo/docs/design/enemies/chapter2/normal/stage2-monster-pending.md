# 2스테이지 일반 몬스터 남은 결정과 검증

[분야 개요](README.md)

## 확정된 설계

5종 피격박스, 공격별 판정 크기, 체력·일반 이동·돌진 및 탄 수평속도, 공격 시작 수평거리·재공격 대기, 타격당 피해·횟수·이동 경직·밀림, 공격 취소 예외, 돌진 최대거리·정지 방향, 장판 수명·첫 피해·중첩·동시 수·사망 정리, 조준 고정·목표 바닥·직격 처리, 곡선 추가 높이, 전조·공격·회복 시간은 해당 편집 원본에 확정되어 있다.

원본: `data/combat/stage2_monster_geometry.json`, `stage2_monster_stats.json`, `stage2_monster_damage_reaction.json`, `stage2_monster_attack_timing.json`, `stage2_projectile_rules.json`.

## 남은 기획

| 항목 | 남은 결정 |
|---|---|
| 근접 거리·높이 | 보행기·필경사 최소거리의 남은 세부(배치 바닥 구역만 이동·도달불가 발사보류·거의0 수평거리 수직투척은 확정) |
| 돌진 끌기 | 취소·경직·사망 시 안전한 해제 위치(지형 막힘 시 즉시정지·해제→찍기전조는 확정) |
| 투사체 예외 | 목표 바닥 이동의 세부·탐색 구현 범위(목표 바닥 소멸 시 기존비행·수명만료 처리까지 확정) |
| 장판 판정 | 마지막 틱과 수명 종료가 겹치는 경계(장판은 착지 플레이어만 피격으로 확정) |
| AI·조합 | 추적/이탈의 남은 세부·스폰 조합(첫 공격 지연·화면 내 새 공격·동시 공격 무제한은 확정; 기존 방 경계 규칙 유지) |

## Unity 적용

`Chapter2NormalEnemy`가 확정된 수치·박스·공격 시계를, `Chapter2NormalOrdnance`가 본체와 독립된 투사체·장판을 처리한다. 기존 HTML은 편집 및 설계 검토 자료이며 Unity 검증은 별도 테스트 결과를 따른다.

- 5종 기존 프레임 표시 시간을 확정 시간표에 대응했다. M3는 원본 3연타 프레임과 간격을 유지한다.
- 곡선은 고정 수평속도와 발사점 대비 추가 높이로 계산한다. 도달 불가능하면 보류하고 거의0 수평거리에서는 수직 투척한다.
- 근접 3종의 높이2u 조건은 공격 시작에만 사용하며 판정 크기를 늘리지 않는다.
- 배치 바닥의 연결된 같은 높이 구간을 이동 영역으로 사용한다. 동적 바닥 이동의 추종 방식은 미확정이며, 목표 바닥이 이동·소멸하면 원래 궤적과 수명까지만 유지한다.
- 장판 수명 끝과 정확히 겹친 마지막 틱은 현재 구현에서 제외한다. 최종 기획 확정은 위 남은 목록을 따른다.
- 검증 절차·결과: `docs/development/testing/stage2-unity-validation.md`.

일반5종과 별개인 엘리트·보스 제안을 이 목록의 확정 내용으로 확대하지 않는다.
