# 1Stage 마을 미술 기준

[분야 개요](README.md)

스타일 ID는 `STAGE1_WARM_PAPER_HATCH`다. 전체 스케치 화풍은 [approved-sketch.png](../../../../Stage1VillageReference/ArtDirection/approved-sketch.png)를 따르며 현재 제작 방향은 [2차 채택 시안 5장](../../../../Stage1VillageReference/ArtDirection/phase2-selected/selection.json)이다. 지형의 선 굵기·빗금 농도·돌 크기는 사용자가 지정한 `ReferenceGround/platform.png` 발판을 기준으로 통일한다. 밝은 타일도 같은 큰 돌과 외곽에 맞춰 갱신하고 구조물·식생 다양화를 양쪽 상태에 함께 적용한다. 시안 채택과 실제 게임의 미술 승인은 구분한다.

전체 진행은 완전 스케치 → 부분적으로 밝음이 남은 혼합 → 완전 밝음이다. 앞 약2/3은 스케치 영향 구간, 뒤 약1/3은 밝은 구간이며 매 화면에 같은 비율을 강제하지 않는다. 경계는 B 방향의 구조물 덩어리를 따르는 또렷한 영역이다. 넓은 그라데이션·이중 윤곽·들뜬 종이 효과는 사용하지 않는다. 정확한 완전 스케치/혼합 분량과 확산 발동 조건·속도는 미정이다. [현재 제작 순서](../../../development/gameplay/village/stage1-village-production-plan.md)를 따른다.

## 표현 기준

- 밝은 돌 면, 둥근 아랫입술, 작은 깨짐, 짧은 연필선과 성긴 사선 빗금을 유지한다. 별도 후보의 짙은 음영이나 현실적인 돌 질감으로 바꾸지 않는다.
- 따뜻한 종이색을 유지하며 검은 흙·회색 판·갈색 얼룩으로 내부를 채우지 않는다. 빗금의 필압과 길이가 살아 있어야 하며 임의의 옅은 선 패턴이나 수식으로 대체하지 않는다.
- 가까운 구조물은 명확한 윤곽과 필요한 묘사, 먼 배경은 단순한 큰 형태와 연한 선으로 구분한다. 블러로 거리감을 만들지 않는다.
- 작은 풀과 덩굴은 그림의 연결부를 숨기는 수단으로 쓰지 않는다. 발판에 붙은 원화의 덩굴은 전체 윤곽을 보존한다.
- 같은 원화에서 돌·모서리·흙·발판을 준비하고 실제960×540 게임 화면에서 선 굵기와 정보량을 비교한다.
- 발판의 짙은 따뜻한 흑연 윤곽과 힘 있는 사선 획을 지형에 적용한다. 평지 돌은24/32/40px 폭 계열로 배치해 크기 편차를 제한하고, 긴 돌 줄 전체를 축소해 작은 돌 무리를 만들지 않는다. 모서리의 돌 높이도 같은 배율의 발판과 비교한다.
- 발판 기준 그림 자체는 유지한다. 내부 빗금의 획과 간격은 발판을 참고한 원화 재질을 사용하며, 넓은 땅에서도 칸마다 다시 시작하지 않는다. 노출 경계 바로 안쪽은 발판에 맞는 필압을 유지하고, 깊은 내부에서는 같은 획을 종이색 쪽으로 옅게 한다. 경계 거리로 연속 조절하며 윤곽선·충돌에는 적용하지 않는다.
- 바닥 돌의 윗선은 발판처럼 또렷하게 읽혀야 한다. 외곽 후광 정리가 착지선의 반투명 흑연 획까지 지우지 않도록 해당 원화 한 행의 짙은 선만 보존·보강한다. 돌 면·아랫윤곽·빗금 전체를 함께 굵게 하지 않는다.

## 그림의 크기와 배치

32px는 배치와 충돌 격자의 기준이다. 원화 전체를32×32px 또는16px 사분면 안에 억지로 자르는 기준이 아니다. 그림은 충분한 투명 여백이 있는 전체 스프라이트로 보존하고 착지선·연결점으로 배치한다. 계단도 평지와 같은 온전한 돌을 배치하며, 돌 한가운데를 잘라 계단 끝을 만들지 않는다. 별도 모서리 원화의 삼각형 빗금·수직 돌 조각은 지형 위에 중복 배치하지 않는다. 내부 메시의 이웃 칸은 정점을 공유하는 위치까지 채우고, 벽·아랫면 원화는 연결 끝에서1px씩 겹쳐 투명 여백의 틈을 방지한다.

그림의 물리적인 크기는 캐릭터와 실제 착지선에 맞춘다. 전체 스프라이트의 투명 여백과 피벗을 확인하고 풀·덩굴·돌의 작은 돌출은 그림 영역 안에 둔다. 내부 빗금은 지형 전체의 좌표에서 이어 표시하여 칸 경계에서 다시 시작하지 않는다. 그림을 수직으로 비균일하게 늘여 빗금 각도를 바꾸지 않는다.

이미 형태가 완성된 스케치에 기존 컬러 알파를 덮어 윤곽을 자르지 않는다. 충돌 지형은 유지하며 두 상태의 그림을 같은 접촉선에 등록한다. 컬러 부품은 자체 생성 알파를 보존하고 벽은 같은 외곽 그림에 두 상태의 재질을 연결한다. 작은 시각적 돌출과 상태 경계는 실제 화면에서 검토한다. 외곽 정합뿐 아니라 내부 돌 이음선·배경 이중 윤곽도 따로 판단한다.

## 현재 적용 범위

게임용 지형은 `Resources/Village/ReferenceGround/`와 `library.json`, 밝은 짝은 그 아래 `Bright/`를 사용한다. `VillageReferenceGround`가 기존 지형과 발판 위치에 같은 부품을 배치하며 두 상태의 재질을 선택한다. `VillagePresentation`의 옛 컬러 지형·발판 렌더는 이 경로가 켜졌을 때 표시하지 않는다. 원화RGBA는 보관하며 희미한 외곽 후광과 안쪽 합성 가장자리만 표시 단계에서 정리한다. 밝은 짝은 실제 조립 화면을 확인했으며 최종 사용자 미술 승인은 아직이다.

2차 작업본은 지형6PNG와 주거·시장·광장·나무·사이프러스·수풀·풀의 밝음/스케치14PNG다. `phase2-scenery.json`에 자체 알파 등록·바닥 여백·해시를 기록한다. 신규 근경은 원래 획을 사용하고 기존 근경용 추가 흑연 보강에서 제외한다. 현재 팀 맵의 가로 진행에 따라 주거·시장·광장·정원 장식으로 배치하며 지지 지면과 여유 공간을 검사한다. 방 번호를 진행 순서로 취급하지 않는다.

새 근경 스케치의 노란 면 채움은 표시 재질에서 승인 지형의 따뜻한 종이·흑연 팔레트에 맞춘다. 윤곽의 위치·알파·해상도는 유지하고 블러를 사용하지 않는다. 분수·벤치·화분은 자체 원화의 실제 발밑이 같은 선에 닿아야 하며, 배치는 고정4px 여백 대신 등록된 `groundOffsetPixels`를 사용한다. 나뭇잎 끝이나 희미한 알파를 건물 바닥으로 오인하지 않도록 실화면을 확인한다.

근경은 나무·건물·담장·낮은 수풀을 한 지면의 겹치는 묶음으로 배치한다. 나무와 담장은 건물보다 뒤, 낮은 수풀은 건물 앞이면서 캐릭터 뒤에 둔다. 건물끼리 같은 간격으로 분리하기 위한 빈96px 띠는 두지 않는다. 지형 내부와의 겹침·접지 검사는 유지하며 장식끼리의 겹침은 허용한다.

`VillageBackdropWalls`는 실제 지형의 `ReferenceGround/body` 빗금과 `Bright/soil` 흙 타일을 사용해 발판 아래에서 지면으로 이어지는 ㄱ자/반대 ㄱ자 배경벽을 만든다. `backdrop-tiles.json`이 승인된 `wall-left`·`wall-right`·`underside` 전체 원화를 외곽 반복 타일로 지정한다. 32px 사각형 채움의 잘린 끝을 그대로 노출하지 않고 원래 알파와 흑연 윤곽을 표시하며, 둥근 끝과 겹치는 연결 모듈로 모서리를 구성한다. 모듈 내부의 겹친 선은 감추고 바깥 실루엣만 남긴다. 표시 캔버스는 논리 외곽보다8px 넓어 돌출된 픽셀을 자르지 않는다. 같은 월드 좌표·배율·노출 가장자리 깊이로 그려 모서리에서도 빗금과 흙 질감이 이어진다. 밝은 배경벽은 실제 흙 타일의 명도·깊이·결을 유지하면서 채도만45%로 낮춘다. 회베이지 단색을 섞어 면 전체를 뿌옇게 만들지 않는다. 스케치 배경벽은 종이색과 옅은 빗금을 유지하며 블러나 벽돌 담장 재질로 대체하지 않는다. 캐릭터·근경보다 뒤의 렌더 전용 메시이고 충돌·강체·지형 점유를 추가하지 않는다. 방마다 최대4곳, 지면에 닿는 높이 범위에서 배치한다. 보통 가로 몸통은80/96/112px, 세로 몸통은96/128/144px 폭을 섞어 두껍게 구성하고 짧은 발판에서는 폭에 맞춰 줄인다. 비슷한 높이의 중심끼리는128px 간격을 확보하며, 그림의 반복 크기를 늘리지 않고 부품 수와 연결 길이로 덩어리를 키운다. 두께·최대 수·간격·접지 탐색 범위는 `backdrop-tiles.json`으로 조절한다.

현재 배치는 기존 119장과 추가 작업본 20장을 함께 선택한 [공통 리소스 배치 계약](../../manifests/unity-deployment.json)을 사용한다. [테스트 씬 에셋 안내](../approved-traversal-and-village.md)를 따른다. 원화·요청문·보존 패키지는 `resources/environments/village/`와 외부 색인에서 찾으며 이미지 배치로 제작 원본이나 승인 상태를 바꾸지 않는다.

타일과 발판은 2026-10-26 사용자가 실제 적용본을 1차 확정했다. `ReferenceGround`의 그림·크기·윗선·빗금을 유지한다. 확정본 해시와 실행 화면은 Git 제외 `outputs/village/approved-terrain-v1/`로 확인할 수 있다. 이 승인은 근경 구조물·원경·중간 전환의 미술 완료 승인을 포함하지 않는다.

승인 지형 9PNG와 A 슈퍼점프의 컬러·스케치 2PNG는 전체 환경 세트에 포함한다. 밝은 원본 69장·등록 스케치 39장·지형 9장·점프대 2장의 바이트·알파를 유지한다. `.meta`·`library.json`·셰이더는 메인의 것을 함께 사용한다.

현재 스케치 manifest가 참조하는 생성 응답, 지형/A 발판 원화·요청문과 원본 패키지는 외부 저장소에서 보존한다. 제작 원본 전체를 Unity Assets에 풀지 않는다. 근경 흑연 보강·연속 빗금·컬러/스케치 경계는 해당 셰이더·런타임·씬과 함께 검토하며 PNG 배치만으로 미술 완료를 주장하지 않는다.

현재 사용하지 않는 긴 돌 줄·네 모서리 오버레이와 B·C·D 후보도 보존하되 활성 배치에는 포함하지 않는다. 새 제작 세트는 메인의 배치 계약으로 명시적으로 선택하며 자동 추가하지 않는다.

가까운 건물·담장·수풀·수로·지하 앞 기둥은 발판에 비해 옅은 윤곽과 빗금을 보강한다. 해당 스케치 재질에서만 기존 흑연 획의 농도를 높이고 밝은 종이 면, 원래 알파·실루엣·지붕·창·접지 위치를 유지한다. 주변 픽셀을 번지게 하거나 전체 배경을 함께 진하게 하지 않는다. 먼 배경과 지하 후벽에는 적용하지 않는다. 이 근경 보정은 실제 화면 검토 대상이며 아직 사용자 승인을 받지 않았다.

기존24구간 배치·물리·캐릭터·전투·카메라·지도 데이터는 아트 변경 대상이 아니다. 실행·기술 검증을 통과해도 사용자의 최종 미술 승인을 뜻하지 않는다.

기준·게임용 그림·원화 생성 프롬프트는 [현재 manifest](../../manifests/stage1-village-art-direction.json)와 [실행 안내](../../../development/gameplay/village/stage1-village-experiment.md)를 따른다. 미채택 후보와 시험 도구는 `outputs/village/99-rejected-before-reference-reset/`에 보관하며 현재 게임 에셋으로 사용하지 않는다. 추가 지형 후보·옛 비교 화면은 그 아래 `terrain-iterations/`에 분리한다. 정상 원본·현재 근경/배경 생성 원본·확정 지형 재현에 필요한 원화는 보관 대상에서 제외한다.
