# 차기 메인 스테이지 최초 클리어 보상

## 책임과 적용 범위

`progression-rebalance-v1`의 1~4장 최초 클리어 보상 수량과 스테이지 배치를 소유한다. 반복 드롭은 [아이템 SSOT](../../30-domain/items/ssot.md)와 [재료 드롭 콘텐츠](../items/material-drops-mvp-v1.md), 강화 비용은 [장비 SSOT](../../30-domain/items/equipment/ssot.md), 진행은 [스테이지 SSOT](../../30-domain/world/ssot.md), 직접 스킬 해금의 상태 전이는 [스킬 SSOT](../../30-domain/character/skills/ssot.md)가 소유한다. 실행 상태는 [A-05](../../wiki/06-delivery/tasks/A-release-scope/a-05-progression-rebalance.md)를 따른다.

## 공통 지급 규칙

- 계정·스테이지·보상 버전마다 한 번만 지급한다. 반복 클리어·재전송·소급 재실행으로 추가 지급하지 않는다.
- 재료는 무작위 추첨 없이 감자·고구마·옥수수를 각각 지급하고 반복 드롭 재료와 같은 거래 가능한 `itemId`·스택에 합산한다.
- 1~9스테이지의 구간 총량은 순번 1~9의 선형 가중치로 배분한다. 정수 나머지는 최대 잔여 방식으로 계산하고 동률이면 뒤 스테이지부터 1개씩 더한다.
- 쌀은 최초 클리어·다음 스테이지 해금과 함께 지갑에 즉시 지급한다.
- 재료·보석함 묶음은 전량 수용 가능하면 즉시 지급하고, 인벤토리 공간이 부족하면 전용 최초 보상 수령 대기함에 보존한다. 사용자는 공간 확보 후 묶음 전체를 원자 수령하며 부분 수령하지 않는다.
- 기존 계정은 저장된 최초 클리어 기록에 따라 같은 보상 생성 경로로 한 번 소급한다.
- 치장 뽑기권·천장·확률은 이번 리밸런싱 범위가 아니다. 기존 1-5 치장 해금과 지원은 [치장 SSOT](../../30-domain/cosmetics/ssot.md)를 유지하며 이 표에서 추가 지급하지 않는다.

## 보존되는 후속 경계

- 5~10장 최초 보상, 4-10 신규 보상, 전설·신화 강화 지원과 80레벨 이후 보상은 미정이다.
- 레이드 관련 보상은 레이드 설계 후 추가한다.
- 단계별 지급량이 없는 후속 범위를 0 지급이나 출시 승인으로 해석하지 않는다.
