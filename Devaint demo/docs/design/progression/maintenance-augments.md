# 증강

[성장·경제](README.md) · [런 성장](../run/progression-and-economy.md)

## 적용 범위

소모성 도면 무기를 사용하는 런에서 정비소의 공격력 강화를 없애고, 3장 중 1장을 고르는 증강 선택으로 성장한다. 한 제안에는 안정형 1장과 도박형 2장을 제공한다. 개별 무기·잉크를 오래 보유하지 않아도 선택한 증강으로 성장하는 방향이다. 증강은 상점·정비소에서 팔지 않고 **보스 처치**와 **봉인 도전방 보상 상자**에서 무료로 고른다(사용자 결정 2026-11-13). 데이터·코드 이름의 ‘정비소 증강’(`maintenance_augments`)은 처음 연결한 자리에서 온 이름이며 획득처를 뜻하지 않는다.

편집 원본은 [`maintenance_augments_proposal.json`](../../../data/combat/maintenance_augments_proposal.json)이다. 전체 후보는 안정형 12종·도박형 27종이며, 개별 효과·대가·세부 조건과 Unity 적용 수치(`effect`)·시험값(`trialValues`)·공통 규칙(`runtimeRules`)은 이 데이터가 소유한다. [증강 검토 화면](../../../tools/augment-workbench/index.html)에서 전체 목록과 3장 선택을 확인한다.

**구현 범위: 39종 중 30종을 1챕터 보스 처치 보상과 봉인 도전방 보상 상자에 연결했다.** 도면 내구도(누적 실피해)가 아직 구현되지 않아 도면 소모·잔량·소진에 의존하는 9종(S07·S08·W01·W04·W05·W07·W09·X01·X11)은 게임에서 제안하지 않는다. 검토 화면에는 ‘내구도 대기’로 표시한다. 플레이 밸런스 확인은 아직이다.

처음 만든 봉인 도전방의 시험 증강(공격 속도·공격력 등 12종, 같은 카드 3번까지 중첩)은 폐기했다(사용자 결정 2026-11-13). 증강은 이 문서의 체계 하나만 쓴다.

## 획득

- 화면이 열리면 첫 카드가 선택된다. ←/→로 카드를 이동하고 F 한 번으로 현재 카드의 증강을 바로 획득한다. 아래 획득 버튼으로 이동할 필요가 없다. 리롤 후에는 새 제안의 첫 카드가 선택된다. 설명이 넘치면 ↑/↓로 현재 카드만 스크롤하고 맨 위·맨 아래에서는 기존 리롤·선택 행동으로 이동한다. W/S와 휠도 유지한다. 패드는 방향키와 확인 버튼으로 같은 흐름을 사용한다.
- **보스 처치:** 보스 출구가 **다음 챕터로 이어질 때만** [보스 무기 보상](../run/rewards.md#스테이지에서-얻는-무기와-잉크)을 고른 뒤 이어서 증강 3장 중 1장을 고른다(사용자 결정 2026-11-13). 현재는 1챕터 보스가 해당하고, 마지막 챕터인 2챕터 보스는 무기 보상만 준다. 다음 챕터가 생기면 그 챕터의 보스 앞 챕터들이 같은 규칙을 따른다. 무기를 선택·획득한 직후 추가 획득 확인 없이 열린다. 보스 처치 연출 중 사망하면 열리지 않는다.
- **봉인 도전방 보상 상자:** 상자를 여는 즉시 3장 중 1장을 고른다. 세부 흐름은 [스테이지 기믹](../world/stage-gimmicks.md#봉인-도전)을 따른다.
- 정비소 성장 탭의 기존 ‘공격 강화’ 자리에는 보유 증강 목록과 획득처 안내만 보이며 구매 버튼은 없다.
- 제안은 안정형 1장과 서로 다른 계열의 도박형 2장을 같은 확률로 뽑는다. 이미 가진 증강과 내구도 대기 9종은 뽑지 않는다. 같은 증강은 한 런에 한 번만 얻는다. 이 구성을 채울 수 없으면 남은 카드에서 최대 3장을 보여 주고, 남은 카드가 없으면 선택 화면을 열지 않는다.
- 선택 중에는 게임이 멈추고 건너뛸 수 없다. 고른 증강은 런 성장 기록(`WeaponGrowth`)에 저장해 1챕터에서 고른 증강이 2챕터에도 유지되고, 새 런에서 비어 있다. 기존 공격 강화 단계는 증강으로 오르지 않는다.

## 효과 분류와 합산

- **주는 피해**는 플레이어가 주는 모든 피해(잉크 효과·가시 포함)다. **기본 공격**·**스킬**은 무기 행동에서 직접 나온 피해이며 맨손 기본 공격도 기본 공격에 포함한다. **무기 공격**은 기본 공격과 스킬 중 맨손을 뺀 피해다. 잉크 효과·추가 피해·반사 탄환은 기본 공격·스킬·무기 공격이 아니다.
- 같은 능력치의 증강 수치는 **더해서** 한 번에 곱한다. 예를 들어 ‘정석대로 갑시다’(+20%)와 ‘종이갑옷’(+35%)을 함께 가지면 주는 피해는 1.55배다. 기본 공격에 맞은 한 타는 주는 피해·무기 공격·기본 공격·조건부 피해 증감을 모두 더한다. 잉크·기존 공격 강화·봉인 증강 등 다른 시스템의 배율과는 곱한다.
- 합이 지나치게 낮아지지 않도록 하한을 둔다(시험값): 주는 피해·받는 피해·최대 체력 10%, 걷기 속도·기본 공격 속도 20%. 스킬 대기시간 감소는 최대 80%, 치명타 확률은 최대 100%다.
- 이동속도는 걷기(달리기·공중 좌우 이동·공격 중 이동)에만 적용하며 대시·점프·벽 이동은 바꾸지 않는다. 기본 공격 속도는 기본 공격 동작 전체에, 스킬 대기시간은 스킬 충전 시간에 적용한다.
- 회복량 증감은 모든 체력 회복(방 클리어·회복 잉크·흡혈·회복소 등)에 적용한다. 최대 체력 증가로 함께 늘어나는 체력은 회복량 증감을 받지 않는다.

## 최대 체력

- 증강의 최대 체력 증감(‘두꺼운 종이’ +20%, ‘대용량 잉크병’ +100%, ‘잉크가 아니라 피였네’ −30%, ‘행운의 대가’ −20%, ‘성장통’)은 증강을 뺀 기본 최대 체력에 대한 비율을 더한다. 기본 최대 체력에는 마을 강화·봉인 증강의 최대 체력이 포함된다.
- 최대 체력이 늘면 늘어난 만큼 현재 체력도 늘고, 줄면 현재 체력을 새 최대치로 자른다. 2챕터 진입 때 다시 계산하는 최대 체력은 체력을 채우지 않는다.
- 성장통은 도박형이다. 선택 전 최대 체력의 30%에서 시작해 10마리 처치마다 기준 체력의 10%만큼 증가하고, 최종적으로 기준 체력의 150%까지 성장한다. 기준이 100이면 30에서 시작해 70마리 처치 시 100, 120마리 처치 시 150이다. 현재 줄어든 최대 체력에 10%를 곱하는 복리 구조가 아니다. 기준은 선택 시점에 가진 다른 증강의 최대 체력 비율을 포함하며, 이후 얻은 증강의 비율은 그 위에 더한다. 처치 수는 증강을 고른 뒤 플레이어 피해로 쓰러뜨린 적이다.

## 개별 시험 규칙

카드 문구가 정한 수치 외에 아래 값은 Unity 시험값이다. 원본은 데이터의 `trialValues`와 각 카드 `effect`다.

| 증강 | 시험 규칙 |
|---|---|
| 착실한 마침표(S12) | 적마다 서로 다른 공격의 적중 횟수를 센다. 세 번째 공격의 그 적중 직후, 실제로 준 피해의 60%를 추가 피해로 준다. |
| 끝까지 읽기(S13) | 공격이 맞기 직전 적의 체력이 최대 체력의 30% 이하일 때 적용한다. |
| 큰 글씨도 문제없다(S14) | 엘리트·보스(훈련 허수아비 포함)에게 주는 무기 공격에 적용한다. |
| 이번엔 너다(W08) | 무기 공격을 시작할 때 직전 무기 공격과 다른 무기면 그 공격의 모든 적중이 +45%, 같은 무기면 −20%다. 첫 공격은 변화가 없다. |
| 잉크가 아니라 피였네(C02) | 무기 공격으로 적의 체력을 실제로 줄인 양의 10%를 회복한다. 한 번에 최대 3, 회복 후 1초 동안 다시 회복하지 않는다. |
| 마감 직전(C03) | 내 현재 체력이 최대 체력의 30% 이하인지 피해를 줄 때마다 판정한다. |
| 무사고 장인(C04) | 피해를 받지 않은 1초마다 주는 피해가 5%씩, 최대 30%까지 오른다. 피해를 실제로 받으면 0으로 돌아가고 5초 동안 −20%이며, 그 뒤 다시 쌓는다. |
| 딱 한 놈만(C05) | 피해를 줄 때 내 위치에서 6칸 안의 살아 있는 적 수를 센다. 1명이면 +60%, 2명 이상이면 −20%, 0명이면 변화가 없다. |
| 다섯 번째는 진심(C10) | 무기 공격을 시작할 때마다 센다. 다섯 번째 공격의 모든 적중이 +250%, 나머지는 −20%다. |
| 정면 승부(C11) | 맞는 적이 바라보는 쪽(같은 x 포함)에서 때리면 무기 공격 +50%다. 적이 내가 바라보는 반대쪽에서 때리면 받는 피해 +40%다. |
| 행운의 대가(C12) | 치명타 확률을 더하고 치명타는 기존 규칙대로 두 배 피해다. |
| 제자리 인쇄소(M04) | 적중한 무기 공격을 적과 무기에 관계없이 센다. 세 번째 공격의 각 적중 직후 실제로 준 피해의 100%를 추가 피해로 준다. |
| 반송 봉투(X08) | 플레이어의 근접 공격 판정이 아직 반사되지 않은 적 탄환(1챕터 원거리 몬스터 탄환)에 닿으면 탄환을 되돌리고 탄환 피해를 두 배로 한다. 2챕터 엘리트·보스의 전용 탄환·광선·지형 공격은 대상이 아니다. 적 탄환에 맞으면 받는 피해 +30%다. |
| 위험한 책갈피(X09) | 스킬을 시작한 자리에 책갈피를 남기고 3초 뒤 그 자리로 옮긴다. 도착점이 막혀 있으면 가장 가까운 설 수 있는 자리로 옮긴다. |
| 사인해 주세요(F02) | 한 적에게 서로 다른 공격을 세 번 맞히면 세 번째 적중 직후 실제로 준 피해의 150%를 추가 피해로 주고 표시를 처음부터 다시 쌓는다. 그 전에 다른 적을 맞히면 표시가 그 적으로 옮겨 1부터 센다. |

- 추가 피해는 피해 배율·치명타를 다시 받지 않고, 적중 횟수·흡혈·잉크 발동에 넣지 않는다.
- 한 번의 공격은 같은 적에게 여러 번 맞아도 한 번만 센다.

## 내구도 대기 증강

도면 무기의 실제 소모 기준은 [내구도 명세](../equipment/durability.md)의 누적 실피해다. 카드의 도면 소모량 증가·감소는 이 집계에 연결할 배율 후보이며, 공격 횟수 소모로 기존 기준을 바꾸지 않는다. 내구도 집계와 무기 파괴를 구현한 뒤 9종의 소모 배율·잔량·소진 발동과 유령 수·런 사이 보존 등 미정 값을 정해 연결한다.

[무기·잉크 규칙](../equipment/rules.md)의 맨손 등 기본 공격과 스케치 무기 구분도 유지한다. 내구도를 소모하지 않는 기본 공격을 무기 소진 보상에 포함하지 않는다.

## 원본과 검토 화면

```sh
python tools/combat/export_maintenance_augments.py
python tools/augment-workbench/build.py
```

JSON을 편집한 뒤 Unity 카탈로그와 검토 HTML을 다시 생성하고 `--check`로 일치를 검사한다. `template.html`은 화면 구조만 소유하며, 생성된 `index.html`과 `MaintenanceAugments.json`을 직접 편집하지 않는다. 화면은 외부 미디어·네트워크 요청 없이 동작한다. 별도 리소스 원본이나 공유 드라이브 배포물을 만들지 않는다.

## 남은 설계

시험값의 플레이 밸런스, 정식 추첨 확률·가중치, 증강과 능력치 잉크의 합산 상한, 내구도 대기 9종의 연결이 남아 있다.
