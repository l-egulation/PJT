## 책임

메인 스테이지 자동 사냥에서 사용하는 재료 드롭 기회, 지급 수량과 세대별 가중치를 소유한다. 챕터별 누적 세대 풀과 보상 원자성은 [아이템 SSOT](../../30-domain/items/ssot.md), 세대 안의 주력·비주력 계열 비율은 [주력 재료 SSOT](../../30-domain/character/ssot.md)를 따른다.

현재 버전의 2~4장 값은 실제 처치시간, 보스 완주율, 장비 강화 소비량과 거래량 검증 전인 `working` 기준이다. `progression-rebalance-v1`은 1장 확정 공급만 이 문서의 차기 절로 대체하고 2~4장은 아래 현재 값을 참조한다.

## `progression-rebalance-v1` 1장 확정 공급

- 1장 1~9스테이지는 재료 드롭 성공/실패 RNG를 사용하지 않는다.
- 일반 몬스터 처치마다 M1 재료 2개, 보스 처치마다 M1 재료 10개를 확정 지급한다.
- 세대는 M1로 고정하고 계열만 계정 주력 재료 기준 80:10:10으로 선택한다.
- 일반 몬스터 20마리와 보스 1마리 한 사이클은 M1 재료 50개를 확정 공급한다.
- 1-10은 반복 드롭이 없는 돌파 시험을 유지한다.
- 동일 전투 입력·밸런스 버전·seed는 같은 계열 선택과 결과를 만든다.
- 2~4장은 아래 현재 버전의 15% 성공률·성공당 10개·세대 역가치 가중치를 유지한다. 2-5·4-5 승급 목표가 시뮬레이션에서 실패하면 새 콘텐츠 버전에서 조정한다.

## 현재 버전 공통 드롭 판정

### 공통 드롭 판정

| 항목 | working 값 |
| --- | ---: |
| 일반 적 1마리당 재료 추첨 횟수 | 1회 |
| 추첨 1회당 재료 드롭 성공률 | 15% |
| 성공 1회당 지급 수량 | 10개 |
| 보스 1마리당 재료 추첨 횟수 | 5회 |
| 보스 각 추첨의 성공률 | 15% |

- 일반 적과 보스의 각 추첨은 독립적으로 처리한다.
- 실패한 추첨은 재료를 지급하지 않는다.
- 성공하면 현재 챕터의 세대 가중치로 세대 하나를 먼저 선택한다.
- 선택된 세대 안에서 계정 주력 재료 80%, 두 비주력 재료 각각 10%로 계열 하나를 선택한다.
- 최종 지급 아이템은 `계열 + 세대` ID로 결정한다.

## 챕터별 세대 가중치

세대 환산가치 `M1:M2:M3:M4 = 1:5:25:125`를 기준으로, 해금된 각 세대가 같은 기대 환산가치를 공급하도록 역가치 가중치를 사용한다.

| 챕터 | M1 가중치 | M2 가중치 | M3 가중치 | M4 가중치 | 정규화 비중 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 1 | 1 | 0 | 0 | 0 | M1 100% |
| 2 | 5 | 1 | 0 | 0 | M1 83.333%, M2 16.667% |
| 3 | 25 | 5 | 1 | 0 | M1 80.645%, M2 16.129%, M3 3.226% |
| 4 | 125 | 25 | 5 | 1 | M1 80.128%, M2 16.026%, M3 3.205%, M4 0.641% |

런타임은 반올림된 백분율보다 정수 가중치를 우선 사용한다. 정규화 비중은 사람이 검토하기 위한 표시값이다.

## 계열 가중치

세대와 관계없이 계정의 주력 재료 선택을 적용한다.

| 주력 선택 | 감자 | 고구마 | 옥수수 |
| --- | ---: | ---: | ---: |
| 감자 | 80 | 10 | 10 |
| 고구마 | 10 | 80 | 10 |
| 옥수수 | 10 | 10 | 80 |

## 최종 아이템 ID

| 세대 | 감자 | 고구마 | 옥수수 |
| --- | --- | --- | --- |
| M1 | `POTATO_M1` | `SWEET_POTATO_M1` | `CORN_M1` |
| M2 | `POTATO_M2` | `SWEET_POTATO_M2` | `CORN_M2` |
| M3 | `POTATO_M3` | `SWEET_POTATO_M3` | `CORN_M3` |
| M4 | `POTATO_M4` | `SWEET_POTATO_M4` | `CORN_M4` |

## 판정 순서

1. 현재 적에 해당하는 재료 추첨 횟수를 가져온다.
2. 각 추첨에서 15% 성공 여부를 독립 판정한다.
3. 성공한 추첨마다 현재 챕터의 정수 세대 가중치로 세대를 선택한다.
4. 선택 세대 안에서 계정 주력 재료 기준 80:10:10으로 계열을 선택한다.
5. `계열 + 세대` 아이템 ID 10개를 전투 보상 결과에 추가한다.
6. 전투 보상과 인벤토리 증가는 하나의 멱등 처리 단위로 확정한다.

## 검증과 승격 조건

- 각 챕터의 세대 가중치 합계와 정규화 비중 합계가 유효하다.
- 아직 해금되지 않은 상위 세대의 가중치는 0이다.
- 같은 콘텐츠 버전·전투 입력·seed는 같은 재료 결과를 만든다.
- 일반 적 20마리와 보스 1마리의 한 사이클은 총 25회의 재료 추첨 기회를 가진다.
- 주력 재료를 바꾼 테스트 계정 사이에서 세대 분포는 같고 계열 분포만 80:10:10으로 바뀐다.
- 장비 강화 단계별 M1~M4 소비량과 비교해 세대별 과잉·병목을 측정한다.
- 거래소에서 주력 잉여분 판매와 두 비주력 부족분 구매가 실제로 성립하는지 검증한다.
- P10·P50·P90의 챕터 도달 시간과 장비 성장 속도가 목표 범위를 벗어나면 세대 가중치, 총 드롭률 또는 지급 수량을 새 콘텐츠 버전에서 조정한다.
