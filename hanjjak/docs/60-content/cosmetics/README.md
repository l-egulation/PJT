# Cosmetics Content

치장 해금·뽑기·수량·성급·도감·세트 규칙은 [치장 SSOT](../../30-domain/cosmetics/ssot.md)가 소유한다.

- 콘텐츠 바이블 설계: [MVP 핵심 수집·성장 콘텐츠 바이블 설계](../../superpowers/specs/2026-09-02-mvp-content-bible-design.md)
- 승인 설계: [치장 뽑기 시스템 요구사항 설계](../../superpowers/specs/2026-09-01-cosmetic-gacha-design.md)
- 요구사항 명세: [치장 뽑기 시스템 요구사항 명세서](../../70-plans/cosmetic-gacha/requirements.md)
- 콘텐츠 상태: [MVP 치장 뽑기 콘텐츠 v1](./mvp-v1.md)

`mvp-v1.md`는 사용자 승인된 `working` 게임 콘텐츠 설계다. 공통 1회 비용의 절대 정수와 실제 아트 메타데이터는 후속 게임 설계에서 확정한다. 현재 런타임 JSON은 이 결정 이전 콘텐츠를 담고 있으며, 구현·검증 상태는 [K-21 작업](../../wiki/06-delivery/tasks/K-client-ux/k-21-cosmetics-vertical-slice.md)과 [구현 증거](../../70-plans/character-cosmetics-collection/implementation-evidence.md)에서 구분해 확인한다.
