## 책임

스킬 목록, 해금·성장 재료, 장착 슬롯, 자동 사용 우선순위와 전투 적용을 소유한다. 스킬 강화 재료의 아이템·거래 속성은 [아이템 SSOT](../../items/ssot.md), 시장 체결은 [거래소 SSOT](../../economy/ssot.md)를 참조한다.

## 스킬 구성

| 역할 ID | 분류 | 효과 |
| --- | --- | --- |
| `active_heavy` | 공격 액티브 | 한 번에 큰 피해 |
| `active_dot` | 공격 액티브 | 전투 장판을 5초 유지하며 현재 전투 중인 대상에게 1초 간격 5회 피해 |
| `active_haste` | 버프 액티브 | 5초간 기본공격 속도 증가 |
| `active_basic_amp` | 버프 액티브 | 5초간 기본공격 피해 증가 |
| `passive_critical` | 패시브 | 치명타 확률 증가 |
| `passive_all_damage` | 패시브 | 모든 주는 피해 증가 |

스킬·스킬북 표시명과 아이콘·액티브 전투 VFX 확정 시안은 [MVP 스킬 표시 콘텐츠 v1](../../../60-content/abilities/mvp-v1.md)이 소유한다. MVP 액티브 연출은 해당 확정 VFX와 기존 공통 캐릭터 모션, 코드 기반 타격·지속 피해·상태 효과를 조합하고, 패시브는 별도 시전 연출 없이 상시 적용한다. 확정 시안의 런타임 에셋 연결과 검증 상태는 [H-05 액티브·버프·패시브 전투 검증](../../../wiki/06-delivery/tasks/H-skills/h-05-skill-combat-validation.md)이 소유한다. 궁극기는 MVP에 포함하지 않는다.

## 효과 수치

| 스킬 | 노말 1→10 | 희귀 1→10 | 영웅 1→10 | 전설 1→10 |
| --- | ---: | ---: | ---: | ---: |
| 강타 | 공격력 200→290% | 320→455% | 480→660% | 700→925% |
| 지속 피해 | 총 250→385% | 420→600% | 640→865% | 920→1,190% |
| 기본공격 속도 | 20→29% | 32→41% | 45→54% | 60→69% |
| 기본공격 피해 | 20→29% | 32→41% | 45→54% | 60→69% |
| 치명타 확률 | 5→14% | 16→25% | 28→37% | 40→49% |
| 모든 피해 | 5→14% | 16→25% | 28→37% | 40→49% |

- 네 액티브의 재사용시간은 10초다.
- 치명타 피해는 150%이며 기본공격과 강타에 적용하고 지속 피해에는 적용하지 않는다.
- 모든 피해 패시브는 기본공격, 강타와 지속 피해에 적용한다.
- 공속 버프 중 기본공격 간격은 `0.4 / (1 + 공속 증가율)`초다.
- 공속·기본공격 피해 버프는 발동 행동에 기본공격을 함께 수행한다. 강타와 지속 피해는 해당 행동의 기본공격을 대체한다.
- 지속 피해는 시전 후 1초 간격으로 최대 5회 피해를 예약한다. 대상이 죽으면 남은 예약 틱은 원래 논리 시각을 유지한 채 다음 유효 대상에 적용하고, 해당 시각에 대상이 없으면 틱을 소멸한다. 대상 전환 시 5초 지속시간을 재시작하지 않는다.
- `active_dot`은 특정 대상에게 상태를 부착하지 않는 전투 장판이다. 이 스킬을 사용한 행동의 시전·회복 점유 시간은 공통 행동 점유 시간의 3분의 1이며, 재사용시간 10초와 총 피해량은 유지한다.

## 장착과 자동 사용

- 공격·버프 액티브는 같은 4개 슬롯을 사용하며 한 슬롯에는 해금한 액티브 하나만 장착한다.
- 플레이어는 장착한 액티브의 자동 사용 우선순위를 정하고 저장한다.
- 캐릭터가 행동할 수 있는 시점마다 슬롯 1부터 검사하고, 유효 대상과 재사용시간 조건을 만족하는 첫 액티브 하나를 사용한다.
- 선택한 스킬이 강타·지속 피해면 해당 행동의 기본공격을 대체한다. 선택한 스킬이 공속·기본공격 피해 버프면 버프를 적용하고 같은 행동에 기본공격을 한 번 수행한다. 사용할 수 있는 액티브가 없을 때는 기본공격만 수행한다.
- 행동이 끝나면 다음 행동 시점에 슬롯 1부터 다시 평가한다. 네 액티브의 재사용시간은 서로 독립이다.
- 패시브는 액티브 슬롯을 쓰지 않고 해금 즉시 항상 적용한다.
- 일반 몬스터 사이와 보스 진입 시 재사용시간을 유지하고 사이클 완료·사망 시 초기화한다.

## `progression-rebalance-v1` 최초 스킬 해금

1-1~1-6 최초 클리어에서 `active_heavy`, `active_dot`, `active_haste`, `active_basic_amp`, `passive_critical`, `passive_all_damage` 순서로 해당 스킬을 노말 1강에 직접 해금한다. 책 아이템과 쌀을 소비하거나 지급하지 않는다.

- 계정·스테이지·보상 버전별 최초 보상과 같은 중복 방지 경계를 사용한다.
- 이미 해당 스킬이 노말 1강 이상이면 기존 등급·강화·실패 보정을 유지하고 추가 변경하지 않는다.
- 기존 계정 소급은 저장된 최초 클리어 기록을 기준으로 미해금 스킬만 노말 1강으로 확정한다.
- 2강 이상 강화, 상위 등급 승급, 스킬북 드롭·거래, 쌀 비용·성공률·실패 보정은 아래 기존 규칙을 유지한다.
- 1-10 적 재산출의 최소 스킬 기준은 위 여섯 스킬 노말 1강이다.

## 스킬북과 드롭

- 첫 노말 책은 해당 스킬을 해금하고 노말 1강을 적용한다.
- 스킬북은 스킬별·등급별 품목 ID를 가지며 거래할 수 있다.
- 스킬북 드롭은 파밍 스테이지 1~9에서 일반 몬스터 20마리와 보스 1마리 각각에 독립 판정을 1회 수행하며 성공률은 0.5%다. 한 사이클의 판정 기회는 총 21회다.
- 10스테이지 돌파 시험은 스킬북을 드롭하지 않는다.
- 등급이 드롭 풀에 포함되는 챕터에서는 첫 스테이지부터 여섯 스킬의 책을 모두 동일한 확률로 선택한다.

| 구간 | 등급 비중 |
| --- | --- |
| 챕터 1 | 노말 100% |
| 챕터 2~3 | 노말:희귀 = 2:1 |
| 챕터 4~5 | 노말:희귀:영웅 = 4:2:1 |
| 챕터 6 이후 | 노말:희귀:영웅:전설 = 8:4:2:1 |

전설 스킬북은 6-1부터 드롭된다. 현재 챕터 1~4 MVP에서는 전설 책 획득과 전설 승급 경로를 잠근다.

## 강화와 승급

같은 스킬은 노말→희귀→영웅→전설로 승급하며 각 등급은 1~10강이다. 최초 노말 해금은 노말 1강을 적용한다. 상위 등급 승급은 직전 등급 10강에서만 요청할 수 있고 100% 성공하며 해당 등급 1강을 적용한다.

2~10강의 단계별 기본 성공률은 다음과 같다.

| 목표 단계 | 기본 성공률 |
| ---: | ---: |
| 2강 | 70% |
| 3강 | 65% |
| 4강 | 60% |
| 5강 | 50% |
| 6강 | 45% |
| 7강 | 40% |
| 8강 | 30% |
| 9강 | 25% |
| 10강 | 20% |

강화 시도 쌀 비용은 버전별 고정 정수표이며 모든 스킬에 동일하게 적용한다.

```text
gradeIndex = NORMAL 0, RARE 1, EPIC 2, LEGENDARY 3
riceCost = 90 × currentEnhancementLevel × 2^gradeIndex
```

| 등급 | 1→2강 | 9→10강 | 실패 없는 2~10강 누적 |
| --- | ---: | ---: | ---: |
| 노말 | 90 | 810 | 4,050 |
| 희귀 | 180 | 1,620 | 8,100 |
| 영웅 | 360 | 3,240 | 16,200 |
| 전설 | 720 | 6,480 | 32,400 |

강화 시도와 해금·승급에 사용하는 같은 스킬의 책 조합 및 해금·승급 쌀 비용은 다음과 같다.

| 목표 등급 | 시도당 같은 스킬의 책 | 해금·승급 쌀 | 결과 |
| --- | --- | ---: | --- |
| 노말 | 노말 1 | 100 | 최초 해금 시 노말 1강 |
| 희귀 | 노말 2 + 희귀 1 | 4,050 | 노말 10강에서 희귀 1강 |
| 영웅 | 노말 4 + 희귀 2 + 영웅 1 | 8,100 | 희귀 10강에서 영웅 1강 |
| 전설 | 노말 8 + 희귀 4 + 영웅 2 + 전설 1 | 16,200 | 영웅 10강에서 전설 1강 |

- 2~10강 시도는 목표 등급의 책 조합과 해당 등급·단계의 고정 쌀 비용을 소비한다.
- 해금·승급은 목표 등급의 책 조합과 위 해금·승급 쌀 비용을 소비하고 100% 성공한다.
- 상위 등급 승급 조건 또는 현재 MVP 접근 범위를 충족하지 못하면 요청을 거절하고 책과 쌀을 소비하지 않는다.
- 실패하면 요구 책과 쌀을 소비하지만 등급과 단계는 유지한다.
- 실패 보정은 `스킬 ID × 현재 등급 × 목표 단계`별로 독립 저장한다.
- 실패마다 해당 목표의 다음 성공률을 5%p 올리되 최종 성공률은 최대 100%다.
- 성공하면 해당 목표의 실패 보정을 초기화한다.
- 별도 횟수 기반 확정 성공 천장은 없다. 누적 보정으로 최종 성공률이 100%가 된 시도는 확정 성공한다.

## 처리 불변 조건

- 스킬 해금·등급·단계, 목표별 실패 보정과 액티브 장착 순서는 서버가 최종 권한을 가진다.
- 클라이언트와 로컬 전투 엔진의 스킬 상태는 서버 확정 상태의 캐시이며 독립적으로 성장 결과를 확정하지 않는다.

- 해금·승급·강화 요청은 서버가 계정 권한, 현재 단계, 콘텐츠 버전, 책과 쌀 보유량을 다시 검증한다.
- 책·쌀 차감, 성공 판정, 단계 변경과 실패 보정 변경은 하나의 원자적 결과로 처리한다.
- 같은 idempotency key의 재시도는 책·쌀이나 성장 결과를 중복 적용하지 않는다.
- 장착 순서 저장은 해금 여부, 중복 장착과 슬롯 수를 서버가 검증하고 하나의 순서로 확정한다.
