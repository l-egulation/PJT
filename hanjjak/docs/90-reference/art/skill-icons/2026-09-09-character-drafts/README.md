# 캐릭터 기반 스킬 아이콘 초안

이 디렉터리는 2026-09-09에 생성한 스킬 아이콘 시각 초안이다. 현재 정책이나 최종 아트 사양을 정의하지 않는다.

## 공통 생성 기준

- 아이콘 캡처: 픽셀 아트 밀도, 은색 팔각 프레임, 정사각형 구도 참고
- 메인 캐릭터 이미지: 두 줄의 황금빛 몸통, 검은 타원 눈, 가는 팔다리, 등 뒤의 막대 외형 참고
- 캐릭터가 직접 스킬을 사용하는 장면으로 구성
- 텍스트·숫자·워터마크 제외
- 프레임 바깥 체크무늬는 초안용 투명 배경 표현이며 실제 알파 채널이 아니다. 채택안에서 실제 투명 배경과 게임용 크기를 후처리한다.
- 생성 방식: Codex 내장 이미지 생성
