# 스케치 무기와 런 잉크 도감

[분야 개요](README.md)

런은 맨손으로 시작한다. 일반 처치 보상에서 스케치 무기 또는 잉크를 고르고, 상점에서 골드로 추가 구매할 수 있다. 무기는 인벤토리에서 팔레트를 확정하면 사용 가능하다. [스케치 무기와 무기별 팔레트](sketch-weapons.md)

| 찾는 규칙 | 기준 문서 |
|---|---|
| 보상 게이지·받아 둔 보상·6회 혼합 선택·이벤트 방·보스 보상·상점 | [런 보상](../run/rewards.md) |
| 두 장착 칸·가방 교체·맨손 | [무기 구성과 활성 슬롯](weapons/rules.md) |
| 무기에 잉크 부여·예약·횟수 소비 | [잉크 적용](ink-application.md) |
| 색상별 효과·레어도·기본/강화 수치 | [잉크 콘텐츠](inks/rules.md) |
| 실피해 누적·무기 파괴와 남은 효과 | [내구도](durability.md) |

구조화된 기획 원본은 [무기·잉크 런 설계 데이터](../../../data/combat/weapon_ink_run_design.json)다. Unity의 맨손 전투·슬롯 입력·가방 일시정지와 기존 팔레트 구현 범위는 [장비 구현](../../development/gameplay/equipment/inventory-and-loot.md)을 따른다. 일반 런은 새 도감·보상·활성화·내구도 경로를 사용하며 전체 런 밸런스와 플레이 가독성은 검증 대상이다.
