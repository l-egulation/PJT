# 새 피격음 10개 방향

젖은 타격 3번 및 후속 5개는 사용자 반려다. 새 후보는 서로 다른 구매팩 원음 10종을 사용하고 이전 젖은 펀치·물 탄환 혼합을 재사용하지 않는다. 의성어와 이름은 목표 질감이며 게임 적용 전 청취 후보다.

preview/index.html은 75개 기본공격·스킬 항목, 모션, 여러 마리, 단독/혼합/A-B/순차 재생, 별표 및 선택 JSON을 제공한다. 참고 버튼은 기존 망치 피격음으로 고정되며 무기를 바꿔도 같은 참고음을 재생한다. 브라우저 저장소는 이전 후보와 분리한다.

48 kHz 모노 PCM16. 최대 RMS 0.045, peak 0.25로 낮게 제한하며 새 저음 타격층이나 왜곡은 더하지 않는다. source/recipes.json에 구매 ZIP 항목과 해시·구간·가공 수치를 기록한다. 원본은 source/originals에 보존한다. 메인 루트에서 `python resources/tools/build_hit_directions.py`로 재생성한다.
