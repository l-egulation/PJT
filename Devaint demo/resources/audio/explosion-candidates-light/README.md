# 가벼운 폭발음 후보 — 방향 반려

사용자가 이 방향을 반려했다(2026-11-16). 원하는 것은 소리를 끊거나 빠르게 재생하는 것이 아니었다. 실제 폭탄처럼 위협적이고 리얼한 느낌이 덜한 소리였다. 대신 원음 자체를 바꾼 `explosion-candidates-stylized`를 만들었다. 이 폴더는 비교 자료로만 보존한다.

`explosion-candidates`의 1번과 2번(실제 폭발 녹음)을 가볍게 만든 후보다. 사용자 피드백(2026-11-16)은 다음과 같다. "1·2번에서 좀 더 가벼운 소리였으면 좋겠다. 지금 소리는 3D 실사에 가까운 게임에 나올 것 같다. 우리는 2D 픽셀 횡스크롤이다." 사용자가 고를 때까지 게임에는 적용하지 않는다.

## 만드는 방식

원음마다 세 단계를 만들었다. 단계가 올라갈수록 같은 세 가지를 더 강하게 한다.

| 단계 | 재생 속도 | 저음 덜기 (24 dB/oct) | 최대 길이 (기본 폭발 기준) | 끝 페이드 |
|---|---|---|---|---|
| 가볍게 | 1.15배 | 120 Hz 아래 | 0.60초 | 0.15초 |
| 더 가볍게 | 1.30배 | 180 Hz 아래 | 0.45초 | 0.12초 |
| 아주 가볍게 | 1.50배 | 250 Hz 아래 | 0.32초 | 0.10초 |

- 재생 속도를 올리면 폭발이 더 높고 작게 들린다. FFT 대역 제한 리샘플링을 써서 고역 겹침(에일리어싱)이 생기지 않는다.
- 최대 길이는 자리마다 다르다. 큰 폭발은 1.6배, 유탄 한 발은 0.8배다. 녹음이 이보다 먼저 -54 dB까지 줄어들면 그 지점에서 끝낸다.
- 왜곡이나 추가 레이어는 없다.
- 유탄은 가볍게 만든 한 발로 지금과 같은 3연쇄를 만든다. 시각은 0, 0.13, 0.27초이고 배율은 0.7, 0.55, 0.85다.
- 크기는 그 자리의 지금 소리와 같게 맞췄다. 기준은 K-가중 400 ms 최대값이고, 피크는 모두 0.89 이하다.

자리마다 쓴 원음은 다음과 같다.

| 자리 | 1번 원음 | 2번 원음 |
|---|---|---|
| 기본 폭발 | `explosion_small_short_01` | `explosion_small_no_tail_03` |
| 큰 폭발 | `explosion_large_06` | `explosion_large_no_tail_06` |
| 유탄 | `explosion_small_short_02` | `explosion_small_no_tail_01` |

비교 화면 `preview/index.html`은 이전 후보 화면과 같은 기능을 제공한다. 지금 소리와 A/B, 3개 겹침, 실제 공격·스킬 소리 뒤에 붙여 듣기, 음량 조절, 별표, 메모, 선택 파일 저장이다. 자리마다 마지막 두 장은 가볍게 만들기 전 원본이다.

원음 해시와 단계별 수치는 `source/recipes.json`에 있다. 메인 루트에서 `python -X utf8 resources/tools/build_explosion_light.py`로 다시 만든다.
