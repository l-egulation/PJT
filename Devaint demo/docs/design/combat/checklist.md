# Unity 전투 설계 체크리스트

[분야 개요](README.md)

50항목·각2%, 5항목마다10% 보고한다. **현재42/50 = 84%, 다음10% 단위 보고는45/50 = 90%**다. 설계 완료율이며 코드·빌드·수동 플레이 완료율이 아니다. 범위를 바꾸면 분모와 변경 전후 진행률을 설명한다.

완료 조건은 답변 또는 명시적 위임 반영·명세·Unity에서 관찰할 검증 절차와 기대 결과 기록이다. 수치 보류만으로 완료 처리하지 않는다. 현행 기준은 [공통 전투 명세](rules.md), [무기·잉크 시스템](../equipment/rules.md), [런 구조](../run/run-structure.md)다.
