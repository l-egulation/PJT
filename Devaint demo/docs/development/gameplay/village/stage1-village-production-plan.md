## 실행 순서

1. **기준 고정·정리:** 5장과 해시를 제작 기준본에 고정한다. 미채택 후보는 보관 폴더로 옮기고 현행 목록에서 제외한다. 사용 중인1차 에셋·프롬프트·복원 자료·팀 공유 사본은 보존한다.
2. **밝음·스케치 지형:** 승인된 온전한 돌·벽·발판과 접촉선에 맞춰 밝은 짝을 제작한다. 평지·벽·계단·안팎 모서리·천장을 같은 부품 배치로 표현한다.32px는 충돌 격자이며 그림을 자르는 틀이 아니다. 전체 투명 캔버스·FullRect·명시적 앵커를 유지한다.
3. **연속 내부·발판:** 스케치 빗금은 승인 원화 재질을 연속 월드 좌표로 표시한다. 밝은 흙은 상단·옆면·천장 등 모든 노출 경계에서 안쪽으로 자연스럽게 어두워진다. 발판은 좌끝·반복 중앙·우끝으로 길이를 늘리고 돌·덩굴을 자르지 않는다.
4. **대표 근경 화면:** 주거 화면 하나에서 건물·식생·지형의 선과 명암을 맞춘다. 문·처마·수관 겹침으로 형태를 풍부하게 하되 넓은 면은 비운다. 유효 픽셀 바닥과 피벗을 측정해 접지하고 실제 게임 크기로 비교한다.
5. **구역별 확장:** 대표 화면이 맞으면 시장·광장·정원에 필요한 차이만 추가한다. 작은 풀·덩굴은 선택적으로 배치하며 이음새 결함을 가리지 않는다. 캐릭터·착지점 주변은 비워 두고 근경은 월드 고정, 원경은 패럴랙스로 둔다.
6. **세 구간·B 경계:** 팀 맵의 실제 진행 정보를 바탕으로 분포를 적용한다. 혼합 구간은 구조물 덩어리별로 또렷한 상태를 선택한다. 두 그림을 넓게 반투명으로 겹치지 않는다. 같은 장소의 상태가 카메라 이동만으로 변하지 않도록 검토한다. 확산 미리보기와 게임 진행 트리거는 구분한다.
7. **전체 검증·전달:** 대표 화면, 접합부·여러 길이, 전체 구간 순서로 확인한다. 제작 원본·요청문·게임 PNG·앵커·대응 목록과 실제 캡처를 함께 관리한다.

실제 투명 PNG로 제작한다. 불투명 종이를 지우거나 형태가 다른 생성물에 기존 알파를 덮어 잘라 맞추지 않는다. 등록된 그림의 표시 재질 조정과 다른 그림을 강제로 마스킹하는 처리를 구분한다.

## 검증과 진행 규칙

Unity6000.6.5f1 D3D11 그래픽으로 컴파일·플레이·캡처한다. `-nographics` 결과를 렌더 검증으로 사용하지 않는다. 현행 팀 맵 검증기로 맵·발판·적·점프·공격 수치 보존을 확인한다. 실패 기대값을 바꿔 통과시키지 않는다.

같은 카메라의 밝음·스케치·경계 캡처, 여러 발판 길이, 벽·계단·천장, 스크롤·최고점·지하·지도·Windows 실행을 검토한다. 실제로 실행하지 않은 항목은 미실행으로 표시한다. 적용·실행 검증·사용자 최종 승인은 구분한다.

로그·캡처·재개 상태는 ignored `outputs/village/`에 둔다. 관련 현재 문서는 구현과 함께 갱신한다. 독립적인 기능 단위로 검증·로컬 커밋하며 관계없는 변경을 스테이징하지 않는다. 원격 push·MR·merge는 별도 요청 없이 하지 않는다.

이미지 제작은 imagegen 스킬의 `scripts/image_gen.py` CLI를 사용한다. 기존 사용자 환경 `OPENAI_API_KEY`·`OPENAI_BASE_URL`(sub2api)을 그대로 쓰고 값은 출력하지 않는다. 불투명 시안은 `gpt-image-2`, 실제 투명 에셋은 이미 사용자 승인된 `gpt-image-1.5`를 사용한다. 실제 출력 크기·RGBA·유효 픽셀·표시 배율을 검사한다.

승인 기준 안의 선·재질·접지·배치 보정은 자율 진행한다. 별도 재승인 대기를 추가하지 않는다. 같은 원인으로 실패하면 전체 재생성을 반복하지 말고 형태·알파·해상도·연결 구조를 조사한다. 품질을 낮춰 전체를 채우거나 시안을 Unity 결과로 대신하지 않는다.
