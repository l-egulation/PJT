# Equip preview assets

사용자가 제공한 `equip.zip`에서 치장 선택 프리뷰 검증에 필요한 완성 프레임, 부위별 레이어, 기본 젓가락에 한 부위만 착용한 `worn` 이미지를 복사한 임시 에셋이다.

- `turtle-*`: 거북이수호자
- `fishbread-*`: 붕어빵
- `chef-*`: 요리사
- `rainbow-*`: 무지개떡

원본 ZIP은 수정하지 않았다. 이번 프리뷰의 선택 부위는 모자·상의·장갑·신발·망토·무기 6종이며 하의는 노출하지 않는다. `거북이수호자`, `붕어빵`, `요리사`는 `worn/rest_01-*` 이미지를 사용하고, 별도 `worn` 이미지가 없는 `무지개떡`은 완성 프레임을 카드 프리뷰로 사용한다.
