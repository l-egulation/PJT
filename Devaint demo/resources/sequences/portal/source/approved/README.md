# 포탈 확정 에셋 · 2026-10-27

채택: 캐릭터 몸 형태를 유지한 채 검게 변하는 입장·퇴장 + 포탈 소멸 2차 B.

- character_draw/: 최종 사용자 수정 캐릭터의 뒤돌기→그리기→복귀 46장, 128×128.
- portal_draw/: 검은 포탈이 그려지는 효과 20장, 128×128.
- portal_melt_B/: 위에서부터 녹아내려 바닥에서 작게 튀는 채택 B 효과 30장, 128×128, 1760ms.
- full_sequence/: 채택 전체 연결 120장, 256×152. 검토용 이동·가림·검정 전환까지 합성한 투명 PNG와 편집 JSON.
- walk_unarmed/, jump_master/: 연결에 사용한 맨손 걷기와 점프 원본.
- preview/: 전체 GIF와 퇴장 확대 검토 자료.
- manifest.json: 각 트랙의 프레임 순서, 시간(ms), 크기, 파일 SHA-256.
- timeline.json: 전체 11.8초 연출의 구간과 위치 정보.

재생 순서: 그리기 → 입장 위치 이동 → 검정 전환·중앙선 가림 → 캐릭터가 완전히 들어감 → 포탈 B 소멸 → 화면 전환 → 검은 몸으로 나옴 → 원래 색 복원 → 착지.

PNG는 원래 크기로 사용하고 Unity Filter Mode=Point, Compression=None으로 가져옵니다. 확대 미리보기는 최근접 보간을 사용합니다. 캐릭터의 몸 형태·윤곽은 잉크 줄기나 타원으로 변형하지 않습니다. 그리기 중 파란 궤적은 제거된 상태입니다.

이 묶음은 승인된 아트와 연출 검토 자료입니다. Unity의 포탈 기능·카메라 전환·이동 물리에 대한 런타임 연결은 아직 수행하지 않았습니다. full_sequence는 게임용 단일 캐릭터 애니메이션이 아닌 위치 이동을 포함한 합성 검토본입니다. 구성요소를 분리해 사용하세요.
각 editor.json은 기존 공통 픽셀 편집기에서 불러올 수 있습니다.
