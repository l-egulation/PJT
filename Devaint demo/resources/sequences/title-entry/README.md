# 타이틀에서 문으로 진입하는 모션 초안

`preview/index.html` 하나만 브라우저에서 열면 스타일·절개 좌표·모션 스크립트·내장 이미지(Base64 data URI)가 모두 포함되어 있어 외부 서비스나 별도 파일 참조 없이 바로 시작하기 → 기록 3개 → 슬롯 선택 → 찢김 → 문 진입을 확인할 수 있다. 원본 이미지는 `source/`에 첨부 바이트 그대로 보존한다.

## 채택 방향과 초안 범위

사용자가 선택한 A안은 화면 위에서 아래로 종이가 한 번에 ‘파악’ 찢어지고, 문 앞의 여유를 짧게 가져간 뒤 천천히 끌려가다가 마지막에 확 진입하는 방식이다. 찢김은 초반 몇 프레임에 크게 벌어지는 곡선과 짧은 반동을 사용한다. 흡입의 앞 72%는 1→1.45배의 느린 접근, 뒤 28%는 64배까지 급격한 확대와 주변 속도선으로 과장한다. 중앙에서 사방으로 터지는 B안과 선택 카드에서 균열이 번지는 C안은 사용하지 않는다.

첫 첨부는 찢김 전후에 계속 사용하는 마을 종이, 두 번째는 틈 안쪽의 문과 공간, 세 번째는 버튼 색·테두리 참고다. 마을 종이를 다른 그림으로 교체하거나 전체 화면 색을 교차 전환하지 않는다. 같은 마을 원본을 같은 카메라 변환으로 그린 뒤 절개 영역 안에만 두 번째 그림을 표시한다. 따라서 절개 가장자리 밖의 종이색·건물·구름·수풀은 찢김 전후에 그대로 이어진다.

`preview/index.html`에 내장된 `TitleTearContour`는 두 번째 그림의 청록색 내부 공간에 연결된 픽셀 영역에서 얻은 절개 경계와 말려 올라간 종이 단면·바깥 그림자 경계를 담는다. 데이터는 좌표뿐이며 `source/`의 원본 PNG를 재인코딩하지 않는다. 절개 바깥에는 두 번째 그림의 입체적인 종이 말림 단면을 첫 그림의 종이 색조에 맞춰 합성하고, 가장자리 바깥 그림자는 첫 그림의 구름·산·건물 스케치 선이 비치도록 어둡게 드리운다.

틈 안쪽 공간은 정지 배경에 고정돼 있던 날리는 종이 조각 두 장을 분리해 입체 궤적으로 흡입시키고, 사선 빛기둥·수면 윤슬 반사·미세 입자를 함께 움직인다. 또한 종이 전면과 틈 내부 회랑 사이에 깊이 시차를 두고, 고속 확대 구간에서는 안쪽 석조 관문과 발광하는 아치 문을 고해상도 벡터 구조로 보강해 64배 진입 시에도 픽셀 깨짐 없이 선명하게 통과하도록 구성했다. 레이어가 분리된 최종 원화·음향·실제 저장 연동은 포함하지 않는다.

## 기본 시간표

슬롯 클릭을 0초로 한다. 기본값은 2.31초이며 타이밍은 검토 중이다.

| 시간 | 표현 |
|---|---|
| 0.00–0.18초 | 선택 카드 강조, 메뉴 사라짐 |
| 0.18–0.28초 | 짧은 위쪽 균열 |
| 0.28–0.40초 | 파악 찢김, 순간 반동 |
| 0.40–0.48초 | 문이 드러난 직후 0.08초 여유 |
| 0.48–1.668초 | 문을 향해 천천히 끌려감 |
| 1.668–2.13초 | 마지막 0.462초에 급가속, 주변 속도선 |
| 2.13–2.31초 | 따뜻한 빛으로 화면 전환 |

재생·일시정지·반복·시간 슬라이더·0.5/1/1.5배속으로 확인한다. 찢김·문을 보는 여유·흡입의 세 시간을 각각 조절하며, 뒤 구간의 시작과 전체 길이는 함께 갱신한다. 자동 반복은 하지 않는다. 브라우저가 숨겨지면 재생을 멈춘다.

## 실제 게임 연결과 미정

이 자료는 브라우저 모션 초안이다. 슬롯 정보는 예시이며 실제 저장 파일을 읽거나 쓰지 않는다. Unity 타이틀·씬·기존 프로필·원본 배치 계약은 변경하지 않는다. 문 통과 후에는 검토용 도착 화면을 보여 준다. 실제 신규/기존 기록별 진입 위치, 저장 범위·시점, 삭제·손상 처리, 기존 단일 프로필 이관, 연출 건너뛰기, 최종 아트와 사운드는 후속 설계다. 문 안 공간의 서사적 의미를 확정하지 않는다.
