# 1스테이지 전투 구조물 · 2×2 도트 픽셀판

1스테이지 전투 공간의 구조물을 새 지형(stage1-pixel-lawn-wood-32)과 같은 격자로 다시 그린 세트다. 32px = 1유닛(PPU 32), 기본 도트 2×2px, 선은 1점 굵기, 2×2 뭉침 0. 색은 지형 6색(색 빠진 세계)이고 의미 있는 색(제단 보석, 간판 물감, 석상 웨이브 등)만 남긴다. 출구는 2챕터 지하수로 입구라 stage2-sewer 석재색을 쓴다.

## 사용할 PNG

`runtime/structures.json`에 파일별 크기·기준점(bottom/top)·역할이 있다. 밑면은 지형 접촉면(타일 위에서 8px 아래)에 붙이고 잔디 장식이 앞에 오게 그린다.

| 대상 | 파일 | 크기 |
|---|---|---|
| 잉크 충전소(주유기형) | recovery-station | 96×112 (3.5u) |
| 정비소 뒷벽·책상·등불·간판 | maintenance-* | 660×258 · 150×78 · 20×38 · 60×60 |
| 출구(닫힘·열림) | exit-sealed · exit-open | 128×160 |
| 잉크 제단 | altar-before · altar-after | 48×40 |
| 잠긴/보상 상자 | *-chest-closed/open | 60×54 |
| 웨이브 수호자 석상 | seal-dormant · active · wave2 · wave3 · broken | 48×72 |
| 철창 | iron-gate-body · tip | 24×128 · 24×24 |

움직임 8장씩: `runtime/anim/` 출구 열림(철창 올라감), 제단 등장·사용, 획득(금빛 방울이 터짐), 폐기(먹 방울이 녹아 떨어짐).

## 제작과 확인

`source/` 스크립트가 격자 위에 직접 그린다(`px.py`의 lint로 뭉침·꺾임 검사). 정비소 뒷벽은 기존 그림의 계단식 윤곽을 따라 돌을 다시 쌓았다. `preview/unity-*.png`는 격리 Unity 6000.6.5f1에서 실제 1챕터 맵(seed 1, 새 타일·배경)에 지금/새 그림을 같은 자리로 찍은 비교다.
