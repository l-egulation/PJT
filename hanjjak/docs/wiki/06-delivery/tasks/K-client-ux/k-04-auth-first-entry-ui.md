# K-04 회원가입·로그인·첫 진입 UI 구현

> 작업 상태와 완료 증거의 SSOT. 도메인 규칙은 [클라이언트 UX](../../../../30-domain/player/ux/ssot.md)를 따른다.

## 완료 기준

가입, 로그인, 오류 안내, 로딩, 첫 캐릭터 진입 흐름을 키보드와 포인터로 완료할 수 있다.

## 선행 작업

B-01, K-02

## 비고

이번 범위에서 인증 전 로그인·회원가입 화면, 회원가입 닉네임 입력, 세션 확인 로딩, 인증 실패 안내, 인증 성공 후 닉네임 상단 표시와 주력 재료 선택/게임 화면 진입을 구현했다. 기존 주력 재료 선택 화면도 인증 뒤에만 실행된다. 로컬 PostgreSQL과 실제 game-api를 붙여 닉네임 회원가입·세션 유지·로그아웃·재로그인을 브라우저로 확인했다. 2026-09-06에는 승인된 주방·티켓·기본 스킨 캐릭터 자산을 인증 화면에 적용하고 로그인·회원가입 공통 프레임, 닉네임 글자 수, 비밀번호 표시 전환, 키보드 포커스를 구현했다. 최신 인증·국가 선택 화면과 실제 game-api의 재연결, 첫 진입 시각 정합성, 단일 활성 세션, Origin 차단과 요청 제한까지 검증했다.
