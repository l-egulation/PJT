# K-27 점진형 온보딩·캐릭터 대화 가이드 구현

> 작업 상태와 완료 증거의 SSOT. UX 규칙은 [클라이언트 UX SSOT](../../../../30-domain/player/ux/ssot.md), 현재 설계안은 [점진형 온보딩·가이드 설계안](../../../../70-plans/progressive-onboarding/README.md)을 따른다.

## 완료 기준

- 역할 의상별 튜토리얼 장이 함께 사용할 수 있는 캐릭터 대화 오버레이를 제공한다.
- 대화 클릭과 Enter·Space 진행, Escape·건너뛰기 종료를 제공한다.
- 현재 설명 대상 하나를 강조하고, 하단 HUD를 설명할 때 대화창이 대상을 가리지 않는다.
- 계정별 완료·건너뛰기 상태를 저장해 첫 진입 안내가 반복 노출되지 않게 한다.
- 모험가의 장에서 캐릭터 상태, 스테이지 진행, 획득 보상, 화면 한켠(PIP)의 첫 안내 흐름을 제공한다.
- 지원 해상도와 키보드 입력을 검증하고, 후속 장·다시 보기·서버 동기화의 남은 범위를 기록한다.
- 첫 안내를 끝냈거나 건너뛴 계정도 전투 화면에서 게임 방법을 다시 단계별로 볼 수 있다.

## 선행 작업

K-02, K-03, K-06

## 현재 구현 범위

- 사용자가 배경을 제거한 투명 튜토리얼 대화창 PNG를 그대로 연결하고, 이름표 글자 확대·단계 표시·명시적인 `다음`·`완료` 버튼과 대상 spotlight를 구현했다.
- 모험가의 장 5단계를 메인 전투 화면 첫 진입에 연결했다. 마지막 단계에서 실제 `화면 한켠` 버튼을 강조하고 작은 창으로 전투를 이어 보는 기능을 안내한다.
- 현재 진행 상태는 계정 ID로 분리한 브라우저 `localStorage`에 임시 저장한다.
- 모험가 모자·스카프·가방을 착용한 투명 자세 시트를 런타임에 연결하고, 대사 단계별로 인사·설명·지시·완료 포즈를 전환한다.
- 검토용 전투 HUD 미리보기에서는 역할 장 7개와 선택형 마을 안내를 목록에서 전환하고, 역할별 working 대사와 역할 의상 시트를 연속 확인할 수 있다.
- 각 단계는 전투·인벤토리·장비·스킬·던전·보석·치장·장터·랭킹·설정의 실제 화면을 열고, 설명 대상에 맞춰 노란 spotlight를 다시 계산한다. 화면을 가리는 목록은 장 선택 후 접힌다.
- 최신 `origin/main`을 병합하고 인벤토리·장비·스킬·보석 튜토리얼은 메인 전투 뒤에 현재 창 크기·스타일로 표시한다. 장터 튜토리얼도 구형 거래 화면 대신 현재 `MarketPlaza`를 사용한다.
- 미리보기 장터에는 검토용 고정 데이터를 미리 주입하고 폴링을 끄되, 일반 `MarketPlaza`의 3초 폴링 정책은 그대로 유지한다. 모험가 외 장의 실제 게임 트리거는 아직 연결하지 않는다.
- 대장장이의 장은 전투 화면에서 시작해 강조된 장비 메뉴, 무기 슬롯, 강화 버튼을 사용자가 직접 눌러 진행하는 5단계 상호작용 시안으로 확장했다. 목표 외 화면은 오버레이가 차단하고, 목표 위치의 투명 조작 영역이 실제 버튼 클릭을 전달한다.
- 대장장이 미리보기에는 연습용 2,000쌀과 1회 강화에 충분한 재료를 고정 주입한다. 강화 시 무기 단계·능력치·쌀·전투력 표시가 실제로 바뀌지만, 이는 검토용 fixture이며 실제 계정 지급 정책이나 보상 계약을 확정하지 않는다.
- 스타일리스트의 장은 연습용 뽑기권으로 1회 뽑기를 직접 실행하고, 확정 결과인 붕어빵 모자를 옷장에서 직접 착용하는 5단계 상호작용 시안으로 확장했다. 뽑기 결과와 현재 착용 상태는 미리보기 안에서만 이어지며 실제 계정 재화와 컬렉션을 변경하지 않는다.
- 보석 마법사의 장은 연습용 보석을 직접 장착하고 프리셋을 로컬 저장한 뒤, 같은 2레벨 보석 세 개를 차례로 선택해 3레벨 보석으로 합성하고 결과 확인까지 직접 누르는 10단계 상호작용 시안으로 확장했다. 저장·합성은 결정론적 미리보기 fixture만 갱신하며 실제 프리셋·보석 서버 API를 호출하지 않는다.
- 낮은 뷰포트와 좁은 뷰포트에서 대화창 우측·하단이 잘리지 않도록 좌우 폭 계산, 다음 버튼 위치, 목표 자동 스크롤과 장비 보드 전체 캔버스 축소를 보정했다.
- 직접 조작 단계에서는 대사와 중복되던 노란 행동 안내를 제거했다. 화면 하단의 강조 대상을 가리지 않도록 대상 상단 좌표에서 대화창 높이와 18px 안전 간격을 뺀 위치로 즉시 올려 배치한다.
- 일반 대화 단계의 `다음`·`완료` 버튼은 대화창 전체 클릭 영역 안에서 프레임 우하단에 고정하고, 대사와 겹치지 않는 전용 여백을 확보한 큰 버튼으로 표시한다.
- 전투 화면 왼쪽 `전투 기록` 아래에 `튜토리얼 보기` 단추를 두고, 같은 종이 판과 안내자 한짝 자세 그림으로 다시 보기 진입점을 열었다. 안내서는 `AdventurerTutorial` 과 같은 `TutorialDialogue` 를 쓰고 모험가의 장 대사에 스테이지 선택·성장 메뉴·마을 메뉴·전투 기록 4단계를 더한 9단계다.
- 대화 오버레이에 `이전` 단추와 좌우 화살표 이동을 추가했다. 마지막 단계는 기존과 같이 `완료` 로 닫고, 다시 보기는 `닫기`·Escape·배경 누르기로 닫으며 닫은 뒤 포커스가 여는 단추로 돌아온다. 첫 진입 안내는 실수로 닫히지 않도록 배경 누르기를 켜지 않는다.
- 안내가 열려 있는 동안 Tab 포커스를 대화 오버레이 안에 가둔다. 다시 보기는 HUD 축소(zoom)와 채팅 패널 위에 그려지도록 `document.body` 로 포털한다.
- 다시 보기 단추는 1180px·900px·620px 폭에서 스테이지 판·마을 메뉴와 겹치지 않는 자리로 각각 옮긴다. 다시 보기는 계정별 첫 진입 완료 상태를 읽거나 쓰지 않는다.
- 대화창 안에서 건너뛰기와 중복되던 우측 장 이름 표시는 제거했다. 원본 대화창 PNG의 실제 테두리 범위를 모두 표시하고, 의상 자세 시트의 행 경계 픽셀이 다음 자세 영역에 비치지 않도록 캐릭터 프레임을 안전 영역 안에서 잘라 표시한다.
- 모험가 외 여섯 장의 실제 게임 트리거를 연결했다. `tutorialRuntimeCatalog.ts` 에 미리보기와 분리한 런타임 대상 정의를 두고, `tutorialTriggers.ts` 가 실제 계정 응답(`/api/v1/equipment`, `/api/v1/skills`, `/api/v1/gems`, `/api/v1/character/stats`)만으로 시작 조건을 판정한다. `ProgressiveTutorialRuntime.tsx` 가 한 번에 한 장만 여는 우선순위 큐와 계정별 완료 저장을 담당한다.
- 런타임 장은 재화를 소비하는 단추(제작·강화·뽑기·합성)를 대신 누르지 않는다. 설명만 하고 실행은 사용자에게 남긴다. 직접 누르는 단계는 화면을 여는 성장 메뉴 단추뿐이다.
- 다른 안내·보상·확인 창이 떠 있으면 열지 않고 기다린다. 대상이 늦게 그려지면 최대 20초까지 기다렸다가 열고, 사용자가 그 화면을 벗어나면 완료로 적지 않고 닫는다.
- `번외: 마을 안내` 는 자동 실행 대상에서 제외했고, 전투 화면의 `튜토리얼 보기` 다시 보기는 자동 실행 완료 상태를 읽거나 쓰지 않는다.
- 장은 전투 화면에서만 시작하지 않는다. 사용자가 성장 메뉴를 먼저 눌러 장비·스킬·보석 화면에 들어와도, 그 화면을 설명하는 단계부터 이어서 연다. `장비 버튼을 눌러 봐` 같은 이동 단계는 이미 그 화면에 있는 사용자에게 건너뛴다.
- 전투 화면 밖의 여섯 화면에 `<장 이름> 다시 보기` 단추를 왼쪽 아래에 두었다. 그 화면의 단계만 재생하므로 다시 보기가 사용자를 다른 화면으로 옮기지 않으며, 자동 실행 완료 상태를 읽거나 쓰지 않는다. 전투 화면은 기존 `튜토리얼 보기` 단추가 같은 일을 하므로 새 단추를 두지 않는다.
- 장비·스킬·보석 화면은 네이티브 `<dialog>` 를 `showModal()` 로 열어 브라우저 top layer 에 그려진다. 안내 오버레이를 그 바깥에 두면 z-index 와 무관하게 창 아래로 깔려 보이지 않으므로, 이 세 화면에서는 오버레이와 다시 보기 단추를 창 안에 심는다. 창이 아닌 화면에서는 배경 filter 때문에 오버레이가 그 칸 안에 갇히므로 그대로 `document.body` 에 얹는다.
- 안내를 미룰지 판단할 때 `<dialog open>` 을 방해물로 세지만, 지금 설명하려는 화면을 품고 있는 창은 방해물에서 뺀다. 장비·스킬·보석 화면 자체가 그 창이라, 빼지 않으면 그 화면의 장이 영영 열리지 않는다.

## 남은 범위

- 대장장이의 `성장 제안이 필요한 첫 실패` 갈래와 장터 상인의 `부족 재료 바로 가기` 갈래 (현재는 각각 `최초 제작 가능`, `거래소 첫 방문`만 연결)
- 이미 해당 기능을 먼저 사용한 계정의 장 자동 완료 처리 (현재는 조건이 지나간 계정에서 장이 열리지 않을 뿐 완료로 적지 않는다)
- 설정 화면 도움말에서의 다시 보기 진입점(현재는 전투 화면 HUD 단추만 제공)
- 다시 보기 안내서에서 전투 화면 밖 화면(장비·보석·장터 등)으로 이어지는 장 연결
- 계정 단위 가이드 상태의 서버 저장 계약 확정과 다기기 동기화
- 초보자 여정 퀘스트 카드와 기능 개방 안내 대기열
- 실제 계정에 지급할 튜토리얼 전용 쌀·강화 재료·뽑기권·연습 보석의 수량, 1회성·멱등 지급 계약과 중도 이탈 시 회수 여부 확정
