화면 배율은 보기만 확대합니다. 실제 몬스터 크기는 오른쪽의 높이(px)로 조절하세요. 드래그하거나 방향키로 이동할 수 있고, Shift+방향키는 8px씩 이동합니다.

몬스터별 크기

너비는 그림 비율에 맞춰 자동 변경됩니다. 크기를 바꿔도 발끝 위치는 유지됩니다. 표시 체크를 켜면 여러 개체를 함께 배치할 수 있습니다.

저장과 비교 기준

설정은 이 브라우저에 자동 저장됩니다. 브라우저 저장이 제한된 경우에도 JSON 저장·불러오기를 사용할 수 있습니다. JSON에는 실제 픽셀 높이와 위치가 들어갑니다. PNG는 선택틀을 뺀 960×540 합성으로 저장됩니다.

배경 밝기·색과 플레이어 원본은 바꾸지 않습니다. 검정 근경은 원래 가림 순서대로 표시됩니다. 초기 크기는 이전 검토값이며 최종 제작 규격이 아닙니다. 이 화면은 디자인 크기·배치 합성 도구입니다.
