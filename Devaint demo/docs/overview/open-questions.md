# 미정 사항과 명세 충돌

[분야 개요](README.md)

현재 해결해야 할 질문과 기준 간 불일치를 관리한다. 결정 이력을 쌓는 문서가 아니다. 확정되면 해당 분야 원본을 갱신하고 이 목록에서는 제거한다. 새 수치·콘텐츠·제품 정책을 이 목록에서 자동 확정하지 않는다.

## 기존 문서 사이의 충돌

현재 공통 수평 이동은 `locomotion/player.json`의 7.5unit/s, 일반 적 기본 피격은 `enemy_hit_reaction.json`의 경직0.30초·밀림0.25unit/0.10초를 따른다. 공통 게임·독립 시험장·들쥐·챕터 시험의 물리 키 기본값은 좌우 방향키 이동, A/S 무기 1/2 기본, Q/W 무기 1/2 스킬, Space 점프, F 상호작용, C/V 개발용 포탈, F5 개발 리셋이다. 패드 재설정과 실제 콘텐츠 미정 사항은 위 목록을 따른다. 명세 충돌을 발견하면 관련 원본과 현재 구현을 함께 대조한다.

## 실행·전달의 제약

- 코드만 받은 환경에는 이미지·Unity 배경 패키지가 없다. `.meta`·씬 존재를 실행 준비 완료로 해석하지 않는다.
- 일부 배포본은 팀 다운로드 주소가 아직 없다. [에셋 안내](../assets/README.md)의 패키지와 매니페스트를 기준으로 실제 받을 경로를 마련해야 한다.

## 질문을 확정하는 방법

질문을 관련 항목끼리 최대 10개로 묶고 질문별 최소 3개 선택지와 추천 근거를 제시한다. 사용자 선택이나 기존 명시적 위임을 확인한 뒤 원본 명세·데이터를 갱신한다. 결정 이유·검증 결과는 Git 커밋에 남긴다. 문서 충돌을 구현에 맞춰 자동 변경하지 않는다.
