# 2스테이지 지하수로 v25

2026-11-12 사용자 승인. v24 배경을 바꾸고, 땅 속을 어두운 바위로 비우고, 통과 발판을 다시 그린 판이다. 실제 `current` 레이아웃 8구간, 960×540, PPU 32이고 Unity에는 아직 적용하지 않았다.

- `runtime/background/`: RGB. 64×32 마름돌 뒷벽, 기둥(받침·머리돌), 가로 관, 문(아치), 벽등·매단 등, 천장 채광 빛줄기, 배수구 물줄기, 사슬·쇠 받침, 접촉 그늘, 바닥 쪽 젖은 얼룩.
- `runtime/foreground/`: RGBA. 땅(테두리 2~3줄만 v21 벽돌, 벽돌 단위로 끊긴 가장자리, 속은 청보라 바위, 먹 1px 테), 통과 돌판(판 11px, 규격 12px 이하), 이끼, 물방울, 물웅덩이.
- `preview/`: 위 두 층에 먼지와 승인 캐릭터(리샘플링 없음)를 합성한 것. `compare-v24-v25-*.png`, `detail-3x.png`, [review.html](review.html).

## 배치 규칙

- 문은 테 폭 전체가 같은 높이 바닥 위에 있고, 위·옆이 땅에 잘리지 않고, 통과 발판이 지나가지 않을 때만 둔다. 큰 문(반지름 76·높이 200)부터 중간(60·160), 작은 문(46·124) 순으로 맞추고, 기둥 받침에 닿지 않는 범위에서 좌우로 옮겨 본다.
- 등과 물줄기는 문 테에서 24px 넘게 떨어뜨리고, 가로 관과 겹치지 않게 하고, 통과 발판에서 8~16px 띄운다. 캐릭터 머리 뒤에는 등을 두지 않는다.
- 모든 위치는 월드 좌표와 해시로 정해져서 다시 만들어도 같다.

## 재제작

`source/build.py`가 `source/render_modern.py`로 8구간을 그린다. 맵은 `../source/chapter2-layouts.json`, 테두리 벽돌은 `../stage2-unified-stone-v21`에서 읽는다. Python 3, Pillow, NumPy, SciPy가 필요하고, 비교판 글꼴은 Windows 맑은 고딕을 쓴다.
