# 무기 소리 비교

`../preview/index.html`을 브라우저에서 연다. 오디오·본체 프레임을 HTML에 내장하며 서버가 필요 없다. 40개 스킬과 발사기·폭탄 기본공격 재검토 2개 항목에 새 후보와 현재음 11번을 제공한다. 일반 항목은 후보 10개이며, 잔상·매듭은 고정/연결안 1개와 현재음만 표시한다. 맨손을 포함한 11종의 확정 기본공격도 들을 수 있다. 후보는 승인 전이며 게임을 자동으로 바꾸지 않는다.

## 비교와 저장

연막 최종 확정본은 `smoke-release-14/smoke14-07-smoother.wav`이다. 전달된 별표·고정·연동 스킬 전체 40개(대검 모아내려찍기 6·7번 포함 41변주)를 로컬 게임에 적용했다. 대검 6·7번은 번갈아 재생한다. 원본 선택 JSON은 보존하고 `../../gamemaster-skills-selected/source/render.json`의 출처·타이밍 및 메인 `data/audio/skill-selections.json`을 적용 계약으로 사용한다. 연막 WAV는 바이트 그대로 배치했다. 현재 이 HTML은 적용 전 청취 비교 기록이며 11번의 이전 게임음은 새 적용본이 아니다. 다른 음색 재검토 없이 게임 연결만 갱신했다.

사용자가 전달한 선택 원본은 `selections/user-skill-selections-revision12.json`에 바이트 그대로 보존했다. 별표는 모두 확정이며 복수 별표와 원래 확정 리비전도 보존한다. `selection-status.json` 기준 미정 스킬은 없다. 별표가 없는 발사기 기본공격 재검토는 현재 게임음을 유지했다. 기존 브라우저 선택은 우선하고, 기록이 없는 항목만 이 선택 파일에서 복원한다. 이전 연막 재검토 기록은 남기되 최종 확정은 14차를 따른다. 폭탄 B3와 대형 8번의 공통음 지정은 유지한다. 게임에는 아직 적용하지 않았다.

폭탄·먹안개의 현재 합성 후보는 청감 재검토가 필요하다. `../preview/raw-materials-02.html`은 구매팩 WAV 바이트를 그대로 재생하는 별도 음색 비교다. 공압 장치 방출·분무기 분사 10개(S11~S20), 물 분출 마법·마법 버블 10개(B11~B20)이며, 크레이지 아케이드 물풍선 파열을 폭탄 방향으로 삼는다. 과거 합성 재료로 사용된 물 분출 원음 4개는 해당 사실을 표시한다. 이전에 기각한 1차 원음 9개와 중복하지 않는다. 음색 방향 선택은 기존 스킬 별표 확정과 별도이며 게임에 적용하지 않는다.


- 무기·스킬 또는 `기본공격 새 후보`를 선택하고 후보를 누르면 본체 모션과 함께 재생한다. 기본공격 재검토 항목에서도 기존 적용음은 11번이다.
- `기본공격 + 모션`은 현재 Unity 사본과 배치 계약의 SHA256·GUID가 일치하는 확정 기본공격을 재생한다. 망치는 5번, 휘두름 0ms·충격 +210ms가 적용된 WAV다. 기본공격과 선택 스킬을 이어 비교할 수 있다.
- 소리별 위치 ±400ms(5ms 단위), 음량 0~150%를 편집한다. 개별 듣기는 비교용이며 음소거 상태를 선택에 저장하지 않는다. 지속음의 시작·끝은 페이드하고 지정한 시간만 재생한다.
- 사용자 영상은 참고 분석용이며 후보의 오디오 샘플로 사용하지 않는다. 현재 HTML에는 영상 발췌 재생이나 녹음 오디오 내장이 없다. 보관 원본과 후보를 분리한다. 레이저는 별도로 합성한 위상 연속 하강음이며 다른 새 후보는 구매 원음의 편집·조합이다.
- 브라우저에 별표 확정·선택·편집값을 저장한다. 별표가 여러 개면 모두 확정안이다. 후보 리비전이 바뀌어도 이전 확정 기록과 리비전을 보존하고, 수정본이 있다는 상태를 별도로 표시한다. 열한 번째 시안은 폭탄에서 원음의 첫 충격과 버블 팝을 빼고 연속 물 분출 구간만 사용한다. 먹안개는 1초짜리 단일 분출음으로 교체하며 파열음과 지속 루프를 없앤다. 미끼 설치 레이어와 밝게 조정한 레이저는 보존한다. 고정·연결된 동작과 다른 스킬 음원은 유지한다. 매듭은 후보별 고정이 아니라 04 시안 1번 감기 한 가지다. 잔상은 강베기 확정 후보(없으면 현재 청취 후보)와 개별 위치·음량을 공유한다. 잔상에서 편집해도 강베기에 반영된다.
- `전체 선택 파일 저장`으로 `skill-sound-selections.json` schemaVersion 7을 받는다. 고정안·강베기 연결 및 해석된 연결 레시피, 기본공격 재검토 여부, 공통음, 레이어·출처 해시, 충돌/지속 시나리오, 위치·음량과 현재 적용음 비교 정보를 포함한다.

## 공통음과 사건

최신 12차 반영: 대형·이동·설치 폭발은 11차 대형 8번 원음으로 고정했다. 기본공격·3연속·폭발 수리검은 확정 B3 원음으로 고정했다. 대형·설치 투척 레이어 gain은 0.95에서 1.9(+6.02dB)로 올렸으며 시점은 유지한다. 기존 별표와 레이어 위치·음량 편집값을 보존한다. 기본공격 미리듣기의 폭발은 B3 확정안이며 아직 Unity 적용 전이다. 11번 현재음은 실제 게임 사본 그대로다. 이후 아래의 과거 후보 설명보다 이 지정이 우선한다.


| 공통음 | 함께 바뀌는 항목 |
|---|---|
| 순간이동 | 흘려찌르기, 섬광 연침, 수리검 뒤이동·복귀 |
| 큰 수리검 투척 | 큰 관통 수리검, 전진 회전 수리검 |
| 잉크 물풍선 파열 | 폭탄 기본공격 새 후보, 폭발 수리검 |
| 짧은 잉크 폭발 | 3연속 폭탄만 |
| 큰 폭탄 폭발 | 대형 폭탄, 착지 시한폭탄, 미사일 |

후보를 고르면 같은 번호의 공통음도 선택한다. 개별 소리 편집에서 공통음만 따로 고를 수도 있다. 연속 비교에서도 번호에 맞는 공통음을 사용한다. 폭발 수리검 투척은 큰 관통·회전 수리검 공통 투척과 별개다. 현재 폭탄 기본공격 11번은 현재 투척과 `ApprovedCombatAudio`의 실제 기본 폭발 WAV·기본 gain을 쓴다. 새 폭발 후보를 고르기 전에는 게임의 기본 폭발이 바뀌지 않는다.

잔상은 강베기의 소리 구성·gain·개별 편집을 첫 베기 시점으로 옮기고 후속 시점에는 소리를 내지 않는다. 강베기 현재음 11번을 선택한 경우에도 같은 WAV를 시각만 옮겨 쓴다. 매듭은 04 시안 1번의 감기 레이어만 모든 후보 데이터에 고정하며 후속음을 없앤다. 화면에는 각각 연결안·고정안 하나만 표시한다.

3연속 폭탄은 02 시안의 투척 레시피를 원본 컷 해시로 복원한다. 3회 투척과 기존 보조음의 타이밍·gain을 유지하고, 폭발의 강한 앞부분은 짧게 두되 기존의 0.20~0.25초 절단은 사용하지 않는다. 원음 전체 꼬리와 한 번의 연속 감쇠를 사용하며, 마지막은 피크 대비 -65dB 이하가 60ms 이상 이어진 뒤 마무리한다. 다른 폭탄도 잘린 물소리 대신 구매팩 물 튀김 원음의 꼬리를 복원하며, 별도의 뒤늦은 물방울 타격을 제거해 한 번의 파열로 이어지게 한다. 다른 게임 효과음의 녹음이나 샘플을 사용하지 않는다.

연막 첫 펑과 발사기 기본공격·산탄은 짧고 매끈한 압력음을 중심으로 거친 원음의 꼬리를 줄인다. 산탄과 기본 발사는 구매 총·포 원음의 낮은 몸통을 함께 사용한다. 미끼는 무거운 설치 한 번만, 레이저는 낮은 옥타브를 더한 두꺼운 하강음이다. 레이피어·모아쏘기 충전, 미끼 시전, 미사일 비행은 무음이다. 보호막·방패 밀기는 짧은 공명만 사용한다.

수리검 이동은 투척 후 적중을 가정한 시점에 명중음, 30ms 뒤 공통 순간이동음, 적중 5초 뒤 복귀음을 비교한다. 실제 구현은 적중 수락 후 적이 살아 있는 경우에만 이동한다. 30ms는 청취상 분리를 위한 값이며 게임 로직의 지연 수치가 아니다. 적용 시 실제 적중·이동·복귀 사건에 연결한다. 빗나감이나 사망한 적을 맞힌 경우를 성공 예시와 혼동하지 않는다.

## 미리보기 범위

본체 프레임은 현재 AnimationCatalog·HeavyWeaponCatalog와 MotionSourceRegistry 전용 바인딩을 사용하고 CombatTimeFixed 시간 매핑을 따른다. 생성 카탈로그에 없는 폭탄 3연속 차기·관통 수리검·발사기 충전 발사는 Runtime MotionSourceRegistry의 암묵 바인딩을 명시한다. FrameTime 모드가 추가되면 빌더는 중단한다.

투사체 궤적·실제 충돌·적의 생사·히트스톱을 재현하는 Unity 시뮬레이터는 아니다. 본체 프레임과 카탈로그 효과, 현재 재생하는 소리 이름을 보여 준다. 충전·지속·충돌 시점은 비교 시나리오이며 실제 게임 수치를 변경하지 않는다.

- 방패 밀기: 게임 이동 수치 유지. 소리는 시작할 때 0.32~0.45초의 단발이다.
- 보호막: 처음 0.48~0.61초의 단발만. 연막 효과는 기본 유지 3초이며 소리는 1초 분출 한 번이다.
- 전진 회전 수리검: 게임 비행 2초. 02 시안의 회전 WAV를 재사용하며 재생률만 1.12로 조절한다. 03 시안의 빠른 회전 변조는 쓰지 않는다.
- 미사일: 기본 청취 비행 3초, 게임 최대 10초. 비행 구간 무음, 끝에만 폭발.
- 착지 시한폭탄: 설정한 착지 시점 뒤 신관 1.5초.
- 유탄 연쇄 폭발: 청취용 0/130/270ms. 게임 적용 때는 실제 파편 폭발 사건 사용.

## 제작과 검사

제작기는 `build_skill_audio_audition.py`와 `skill_audio_revision2.py`부터 `skill_audio_revision11.py`까지다. 최신 편집은 마지막 단계가 담당하며 numpy를 사용한다. `restoredTripleThrowLayers`는 이전 투척의 레이어와 원음 해시를, `fixedWhipLayer`는 한 가지 감기를, `linkedAction`은 강베기 연결을 명시한다. 출처 그래프가 구매 원음·직접 합성·편집 입력을 구분하며 사용자 영상이나 다른 게임 녹음을 후보에 포함하지 않는다.

단발은 부드러운 주파수 필터와 자연스러운 꼬리 페이드를 사용한다. 폭탄은 구매팩 Water/Magic_Spells의 연속 물소리에서 가장 강한 타격 후 90ms부터 추출한다. 화약 폭발·타격·버블 팝·원음의 시작 충격을 사용하지 않는다. 30ms 어택과 연속 감쇠로 짧은 타격을 억제한다. 낮은 사인 압력음과 물방울이 주음을 맡지 않는다. 인공 리버브·에코를 넣지 않는다. 3연속/일반/대형 WAV 피크는 각각 0.30/0.36/0.44다. 먹안개는 정확히 48,000샘플의 1초 분출음 한 레이어만 사용한다. 35ms 어택·250ms 끝 페이드를 쓰며, 파열음·반복·3초 유지음은 없다. 게임 연막 효과 유지시간과 분출음 길이를 구분한다. 미끼는 시전 시작 0.20초 설치 순간부터 접촉음, 18ms 뒤 잉크 정착음을 겹친다. 설치 전에는 후보 소리가 없다. 게임 적용 시에는 타이머가 아닌 SpawnDecoy 성공 사건에 연결해야 하며 현재 HTML은 성공 시나리오다. 레이저는 기존 WAV의 650Hz 이상을 최대 약 6.85dB 강조한 뒤 전체 에너지를 유지한다. 레이저 길이와 음높이 진행은 바꾸지 않는다. 새 폭발음은 10ms 구간별 실제 피크로 겹침 상한을 계산한다. 조용해진 꼬리를 최대 음량으로 계산해 전체 소리를 과도하게 낮추지 않는다. 미리보기 시간과 재생 종료도 마지막 소리의 꼬리까지 포함한다. 과거 시안 원본은 보존하며 생성 파일과 출처를 구분한다.

```powershell
python resources/tools/build_skill_audio_audition.py --archive '<구매 ZIP>'
node resources/audio/gamemaster-skill-audition/source/test.cjs
python resources/tools/check_skill_audio_revision11.py
python resources/tools/configure_lfs.py
```

`recipes.json`은 내장 미디어를 뺀 레시피와 출처다. DOM/AudioContext 스텁 검사는 시간·공통음·선택·취소를, PCM 검사는 1번 감기 고정·강베기 연결·02 투척 복원·짧은 폭발의 꼬리·고역 잔류·녹음 출처 배제·파일 해시를 확인한다. 이 검사는 실제 브라우저·장치 청취 또는 Unity 실행 검증이 아니다.

## 미정 목록

HTML 상단에 펼쳐진 미정 목록은 해당 브라우저의 별표(`favorites`)와 `choice`를 모두 확정으로 계산한다. 별표가 여러 개면 모두 확정안이며 마지막 재생 후보만으로는 확정하지 않는다. 매듭 조이기는 사용자 지정 1번 감기 고정으로, 잔상은 강베기 확정안과 연동한다. 리비전이 바뀌어도 확정 기록을 미정으로 되돌리지 않고 “확정 이후 수정본 있음”으로 표시한다. 새 버전이 자동으로 승인된 것은 아니다. 이전 로컬 `previousReviews`에 남아 있는 별표는 최초 실행 시 한 번 복원하며 이후 사용자가 해제한 별표는 다시 복원하지 않는다. `confirmedCandidates`에 확정 번호·리비전·확인 가능한 편집 기록을, `reviewStatus`에 상태를 저장한다. 다른 브라우저의 선택이나 아직 전달되지 않은 선택 파일은 이 목록에 포함되지 않는다.
