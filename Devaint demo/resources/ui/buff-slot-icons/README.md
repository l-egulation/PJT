# 버프칸 아이콘 (2026-11-12 확정)

캐릭터 HP 바 아래와 보스 체력바 아래의 버프칸(잉크 효과·내부 쿨타임 표시)에 쓰는 24×24 픽셀 아이콘이다. pixelfx(MIT)의 코어(프레임·페인터·합성·PNG)로 1배(32px = 1u 화풍)로 그렸다. 게임은 `runtime/`만 쓴다.

## 확정 내용

| 파일 | 효과 | 고른 그림 |
|---|---|---|
| `move-speed.png` | 이동속도 증가(노랑) | 겹 화살촉 |
| `shield.png` | 방어막 생성(초록) | 방패 |
| `heal.png` | 체력 회복(초록) | 십자 |
| `stun.png` | 기절 부여(보라) | 고리를 도는 별 세 개 |
| `bind.png` | 속박 부여(보라) | 사슬 |
| `poison.png` | 중독 부여(보라) | 해골 |
| `slow.png` | 슬로우 부여(보라) | 가운데 정렬한 소용돌이 |
| `basic-damage.png` | 기본 공격 피해 증가(빨강) | 검과 위 화살표 |
| `basic-speed.png` | 기본 공격 속도 증가(빨강) | 검과 속도선 |
| `skill-cooldown.png` | 스킬 쿨타임 감소(파랑) | 시계 |
| `skill-damage.png` | 스킬 피해 증가(파랑) | 번개 |
| `trigger-*.png` | 발동 조건 배지: 기본 공격·스킬 공격·스위칭·대쉬·상태이상 부여 | 오른쪽 아래 모서리 삼각형 색띠(투명 바탕 덧그림) |

- 칸 테두리 색은 잉크 색이다. 배지는 효과 아이콘 위에 그대로 겹쳐 그린다.
- 기본 공격 속도 증가는 현재 기본 잉크 43종에 없는 효과로, 표시용 그림만 미리 만들었다.

## 폴더

| 경로 | 내용 |
|---|---|
| `runtime/*.png` | 게임용 24×24 아이콘 11장과 배지 덧그림 5장 |
| `source/tools/make_icons.mjs` | 후보 3안과 확정본 생성 코드(거리 함수로 모양을 잡고 5단 음영·잉크 외곽선을 칠한다) |
| `source/tools/make_final.mjs` | 회복·방패 정리판 생성 코드(재기 규칙으로 다시 그림). `--all`이면 비교용 정리 시안 전체 |

## 회복·방패 정리판

회복·방패만 픽셀아트의 재기(jaggies) 규칙으로 다시 그린 판을 쓴다. 나머지 9종과 배지는 처음 확정본 그대로다(사용자 결정 2026-11-12).

- 직선은 수평·수직·1:1(45°)만 써서 계단 길이를 일정하게 둔다.
- 외톨이 픽셀·한 칸 돌기·한 칸 홈을 남기지 않는다.
- 칸 모서리는 2-1 계단으로 깎는다.

## 사용자 손수정 (2026-11-12)

생성본 위에 사용자가 픽셀 편집기로 직접 고친 판이 `runtime/`의 현재본이다. 고친 파일은 11장이고, 나머지 5장(기본 공격 피해·기본 공격 속도·회복·이동속도·방패)은 생성본 그대로다.

| 파일 | 바뀐 칸 |
|---|---|
| `skill-damage.png` | 22 |
| `skill-cooldown.png` | 15 |
| `slow.png` | 9 |
| `bind.png` | 4 |
| `poison.png` | 3 |
| `stun.png` | 2 |
| `trigger-*.png` 5장 | 각 1 (모서리 한 칸 비움) |

## 다시 만들기

1. `node source/tools/make_icons.mjs <pixelfx 저장소 경로> <후보 출력 폴더> runtime`
2. `node source/tools/make_final.mjs <pixelfx 저장소 경로> runtime`

1이 생성본 전체를 쓰고 2가 회복·방패를 정리판으로 덮어쓴다. 같은 코드로 다시 내면 같은 바이트가 나온다(난수 없음). **위 손수정은 코드에 없으므로 `runtime/`에 그대로 다시 내면 손수정 11장이 지워진다.** 다시 낼 때는 다른 폴더로 내서 비교한다.
