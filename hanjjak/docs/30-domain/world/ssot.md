## 책임

챕터·스테이지 ID, 해금·진행 조건, 일반 전투·보스 구조, 실패 복귀, 안정 파밍 위치를 소유한다. 전투 공식과 드롭 상세는 다른 도메인을 참조한다. 일일 보석 던전의 별도 단계와 회전 규칙은 [보석 SSOT](../gems/ssot.md)가 소유한다.

## 구조

### 차기 리밸런싱 목표: `progression-rebalance-v1`

2026-09-11 사용자 승인. 차기 범위는 [제품 범위](../../70-plans/mvp-release/requirements.md)의 차기 절을 따르며 1~4장 절대 수치만 구현·검증한다. 아래 기존 소벽 표는 현재 버전 기록이다.

- 의도적인 성장벽은 각 챕터 10스테이지에만 배치한다. 1~9에서 반복 정체하도록 설계하지 않는다.
- 초반은 최초 클리어 보상을 장비에 투자하고 거래소로 부족 재료를 보충하면 진행이 이어지는 경험을 목표로 한다. 첫 실패 자체를 강제하지 않는다.
- 1-10·2-10·3-10·4-10의 기준 장비는 각각 노말 25강·희귀 15강·희귀 25강·영웅 15강이다.
- 3-10은 2레벨 보석 3개와 3레벨 보석 3개, 4-10은 4레벨 보석 6개를 기준으로 한다. 보석 옵션은 보스 검사축에 맞추되 실제 플레이어에게 지급·강제·보정하지 않는다.
- 각 10스테이지의 정상 기준 빌드는 검증 seed에서 90% 이상 성공해야 한다. 부족 빌드는 공격력·최대 HP·방어 관통 중 해당 보스 검사축 부족으로 실패해야 한다.
- 승급 자격은 다음 챕터 도달에 열리지만 자동 승급하지 않는다. 정상 공급·거래 표본에서 노말→희귀는 2-5, 희귀→영웅은 4-5 안에 가능해야 한다.
- 다음 챕터 첫 스테이지의 최초 보상을 받기 위해 아직 얻을 수 없는 승급·보상이 필요해지는 순환 조건을 만들지 않는다.
- 성장 경험은 1~2장 기본 파밍·거래소, 3~4장 보석, 5~6장 레이드, 7~8장 신규 콘텐츠, 9~10장 종합 활용으로 연결한다.
- 기존 보스 단독 사이클·수동 반복 범위는 유지한다. 무드롭 돌파 시험의 반복 드롭과 [최초 클리어 전용 보상](../../60-content/stages/first-clear-rebalance.md)은 구분한다.
- 1~4장 적 절대 수치는 위 기준 빌드와 [성장 SSOT](../progression/ssot.md)의 차기 시간 목표로 다시 산출한다. 현재 적 표를 차기 검증 완료 수치로 사용하지 않는다.
- 5~10장 적 수치는 2026-09-14 설계로 확정했다. `apps/balance-lab` 생성기가 기준 레벨 `2i−1`·기준 Q 램프에서 계산하며, 일반 공격은 기준 빌드 최대 HP의 고정 비율(파밍 1.0%, 소벽 0.75%, 관통벽 0.6%)이고 5장부터 일반 HP도 기준 빌드 최대 HP를 따른다. 보스 HP·공격·강타는 기준 빌드가 90% 승리하는 상한을 이진탐색으로 구한다. 플레이어 레벨 상한은 200이다. 4-10 신규 보상은 여전히 후속 범위다.

실행 상태와 검증 범위는 [A-05](../../wiki/06-delivery/tasks/A-release-scope/a-05-progression-rebalance.md)를 따른다.



장기 설계는 챕터당 10개 스테이지로 구성한다. 구현 범위는 챕터 1–10, 총 100스테이지다(2026-09-14 확정). 기존 배포 버전의 동결 콘텐츠 `v1` 은 [MVP 범위](../../70-plans/mvp-release/requirements.md)의 챕터 1–4·40스테이지로 유지한다.

- 글로벌 인덱스는 $I=10(C-1)+s$다.
- 각 스테이지의 일반 몬스터와 보스는 같은 `enemyLevel`과 `enemyDefense`를 사용한다. MVP v1의 `enemyLevel`은 기존 기준 레벨, `enemyDefense`는 기존 보스 방어력에서 가져온다.
- 적 레벨은 콘텐츠 식별·밸런스 기준이며 현재 피해식의 직접 입력이 아니다. 레벨·권장 스펙·성장벽 유형은 스테이지 선택 화면의 입장 조건이나 표시 정보로 사용하지 않는다.
- 각 챕터의 1~9스테이지는 일반 몬스터 20마리와 보스 1마리의 연속 사이클이다.
- 각 챕터의 10스테이지는 일반 몬스터 없이 최종 보스 1마리만 등장하며, 사이클 시작 사건은 곧바로 `BOSS_SPAWNED`다. 챕터 1은 `딸기 시루(strawberry-siru)`, 챕터 2는 `로열 어소트먼트 선물 골렘(royal-assortment-gift-golem)`, 챕터 3은 `후토마끼 왕(futomaki-king)`을 사용한다.
- 4와 7스테이지는 소벽, 10스테이지는 대벽이라는 밸런스 분류를 유지하되 화면에는 노출하지 않는다.
- 보스 처치 시 다음 스테이지를 해금하고 사이클 완료 회복을 적용한다.
- 챕터 1은 `성심당` 테마를 사용한다. 1-1~1-10의 일반·보스 외형과 제빵 공간 배경은 `packages/game-content/versions/v1/stages/stages.json`의 `normalMonsterIds`·`bossMonsterId`·`backgroundId`가 소유하며, 복수 일반 몬스터 ID는 전투 순서대로 교대한다.
- 챕터 2는 `쿠키 선물세트` 테마를 사용한다. 2-1~2-10의 일반·보스 외형과 제작 공간 배경은 같은 스테이지 콘텐츠의 `normalMonsterIds`·`bossMonsterId`·`backgroundId`가 소유하며, 복수 일반 몬스터 ID는 전투 순서대로 교대한다.
- 챕터 3은 `스시집` 테마를 사용한다. 3-1~3-10의 일반·보스 외형과 아침·점심·저녁·새벽 배경은 같은 스테이지 콘텐츠의 `normalMonsterIds`·`bossMonsterId`·`backgroundId`가 소유하며, 복수 일반 몬스터 ID는 전투 순서대로 교대한다.
- 챕터 1 메인 전투는 기본 마스터 외형만 표시하고 치장 장착 상태를 합성하지 않는다. 렌더링 동작은 서버 결정론 전투의 논리 tick 사건을 재생하며 별도 랜덤·장식용 타이머로 판정처럼 보이는 동작을 만들지 않는다.

| --- | --- | --- | --- |
| 1 | 공격력 | 최대 HP | 방어 관통 |

## 실패·복귀

- 방치모드는 `자동 진행`과 `스테이지 반복` 두 가지다. 전투 자체는 두 모드에서 모두 자동이며 챕터 반복 모드는 사용하지 않는다.
- 자동 진행에서는 보스 처치로 사이클을 완료하면 다음 스테이지를 해금하고 즉시 그 스테이지로 이동한다. 4-10처럼 다음 MVP 스테이지가 없으면 현재 스테이지를 반복한다.
- 자동 진행에서 일반 몬스터 사망 또는 보스 실패가 발생하면 1초 뒤 현재 스테이지 사이클을 재시작한다. 1~9스테이지는 일반 몬스터 0/20부터, 10스테이지는 최종 보스전부터 재시작한다.
- 스테이지 반복은 사용자가 해금한 각 챕터의 1~9스테이지만 대상으로 지정할 수 있다. 10스테이지는 무드롭 돌파 시험이므로 수동 반복 대상으로 지정할 수 없다.
- 스테이지 반복에서는 선택한 하나의 1~9스테이지를 사이클 완료 뒤 다시 0/20부터 반복하고, 실패해도 같은 스테이지의 0/20부터 재도전한다.
- 방치모드와 반복 대상 변경 요청은 현재 사이클이 끝난 뒤 적용한다. 요청 시 서버는 스테이지 존재·해금·1~9 여부를 검증하고 반복 대상을 서버 권한 상태로 저장한다. 웹 상태 엔진은 로컬 현재 방치모드를 유지하다가 사이클 경계에서 저장된 반복 대상을 사용해 `스테이지 반복`으로 전환한다.
- 사용자는 해금한 스테이지를 선택할 수 있다. 선택한 스테이지 입장은 현재 전투를 즉시 중단하고 1~9스테이지는 0/20부터, 10스테이지는 최종 보스전부터 시작하며 기존 방치모드는 유지한다.
- 메인 보석 프리셋을 변경하면 현재 전투를 즉시 종료하고 1~9스테이지는 일반 몬스터 0/20부터, 10스테이지는 최종 보스전부터 다시 시작한다. 플레이어를 최대 HP로 회복하고 공격·스킬 상태를 초기화하며, 재시작 전에 받은 보상은 유지한다.
- 처치 확정으로 이미 받은 보상은 실패·수동 전환·프리셋 변경으로 되돌리지 않는다. 미처치 적과 남은 사이클 보상은 지급하지 않는다.
- 앱 종료 중 진행과 재실행 복원은 [계정·저장 SSOT](../player/ssot.md)를 따른다.

## 콘텐츠 입력과 선택 화면 정보

- 스테이지 콘텐츠는 표시 이름, 공통 적 레벨·방어력, 일반 몬스터, 보스 패턴, 주요 보상, 해금 조건, 프레젠테이션 ID와 콘텐츠 버전을 가진다. 공통 적 수치와 보스 패턴의 40개 행은 [MVP 적 수치 v1](../../60-content/enemies/mvp-v1.md)이 소유한다. 챕터 1 프레젠테이션은 `packages/game-content/versions/v1/stages/stages.json`, 표시 이름·해금 조건·주요 보상은 `packages/game-content/versions/v1`의 chapters·stages·drops 콘텐츠가 소유한다. 런타임에서 플레이어 상태에 맞춰 콘텐츠를 동적으로 바꾸지 않는다.
- 스테이지 선택 상세는 주요 보상, 현재 방어 관통으로 해당 스테이지 적에게 주는 기본 피해의 정수 퍼센트와 해당 스테이지의 최근 실패 1건을 제공한다. 권장 레벨·권장 공격력·권장 HP·권장 관통·내 스펙·성장벽 유형은 제공하지 않는다.
- 피해 퍼센트는 [전투 SSOT](../combat/ssot.md)의 관통 배율에 100을 곱해 반올림한 값이다. 입장 조건이 아니며 클라이언트 표시 계층이 별도 공식을 만들지 않는다.
