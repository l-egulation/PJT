# 시계탑 보스방 · 승인 V12

2026-10-30 승인. 기존 마을 집의 따뜻한 크림색, 얇은 연필선과 평평한 명암을 유지한 길목·보스방입니다.

- 길목은 열려 있는 마을에서 낡은 회벽이 늘어나고, 뒷배경이 가려지면서 기둥·도르레·톱니가 나타납니다.
- Unity의 실제 26유닛 연결 구간에 구조물을 배치합니다. 기존 최대 6유닛 통로와 바닥 충돌은 그대로 사용합니다.
- 보스방은 30유닛 너비의 후면 벽, 회전 톱니, 도르레, 천천히 움직이는 잔해로 구성합니다. 모든 레이어는 플레이어·보스·지형 뒤에 있으며 충돌체가 없습니다.
- 색을 회색으로 바꾸던 채도 필터를 제거했습니다. 굴 안쪽에서는 같은 색 계열로 밝기만 낮춥니다.

## 원본 및 사용본

- `assets/`: 승인한 배치용 원본 이미지. 기존 그림은 덮어쓰지 않습니다.
- `originals/`: 생성 원본 2장, 프롬프트와 출처, 최초 분리 스크립트.
- `index.html`: 승인한 연속 동선 HTML. 긴 시안을 실제 Unity 연결 구간에 그대로 늘여 붙이지 않고 구조물 비율을 유지해 재배치했습니다.
- `unity-layout.json`: Unity 배치·애니메이션·텍스처 해시.
- 저장소 `unity/Assets/ForestCombatV2/Resources/ClockBossEnvironment/`: PNG 데이터를 담은 .bytes 사용본과 layout.json. 런타임에서 투명 스프라이트로 읽습니다.
- `Chapter1BossRoomEnclosure`에서 `Chapter1BossBackdrop`을 등록하므로 랜덤 1챕터와 보스 테스트방에서 같은 배경을 사용합니다.

## 다시 내보내기

MonsterReference 로컬 서버(55825)를 켠 상태에서 저장소 루트의 `tools/art/export_clock_boss_environment.cjs`를 Node로 실행합니다. Playwright가 필요합니다. 원본 색은 sRGB로 유지하고, 큰 배경만 실제 화면 크기에 맞춰 축소합니다.

이 폴더는 미채택 이전 시안 경로에 의존하지 않습니다. 기존 몬스터와 보스 전투·모션 원본은 별도로 유지합니다.
