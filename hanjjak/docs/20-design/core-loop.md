# Core Loop

한짝의 기본 플레이 루프는 다음과 같다.

```text
자동 이동
  ↓
조우
  ↓
자동 전투
  ↓
경험치·쌀·아이템 보상
  ↓
레벨·장비·스킬 성장
  ↓
상위 스테이지 도전
```

전투 실패 시의 복귀 규칙은 [World Domain](../30-domain/world/ssot.md), 보상과 성장 규칙은 [Items](../30-domain/items/ssot.md)·[Progression](../30-domain/progression/ssot.md)의 정본을 따른다.

일일 병렬 루프는 [보석 SSOT](../30-domain/gems/ssot.md)의 보스 도전 → 보석 획득 → 합성·장착·거래 흐름을 따른다. 일일 제한과 보석 규칙은 이 문서에서 다시 정의하지 않는다.
