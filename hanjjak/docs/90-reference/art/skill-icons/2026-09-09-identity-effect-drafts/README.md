# 스킬 정체성·효과 기반 아이콘 초안

이 디렉터리는 스킬명, 전투 효과, 현재 런타임 VFX를 함께 고려해 생성한 선택용 시각 초안이다. 정책이나 최종 아트 사양을 정의하지 않는다.

2026-09-09 사용자 선택 `3·3·3·1·1·1`은 [MVP 스킬 표시 콘텐츠 v1](../../../../60-content/abilities/mvp-v1.md)에 전파했다. 이 디렉터리는 비교 후보 전체를 보존하며, 선택된 6개 파일의 정본은 `docs/60-content/abilities/icons/mvp-v1/`이다.

## 공통 원칙

- 캐릭터 등장은 선택 사항이다. 스킬 판독에 도움이 될 때만 손, 막대, 눈 등 일부를 사용한다.
- 내부 도형과 이펙트는 중앙 영역에 제한하고, 은색 팔각 테두리 앞에 균일한 어두운 안전 여백을 둔다.
- 테두리는 모든 방향에서 끊김 없이 노출하며 내부 이미지가 침범하지 않는다.
- `마! 쫄이나`는 진홍·주홍·주황 계열만 사용하고 보라·자주·분홍·파랑 계열을 배제한다.
- 스킬명과 전투 효과는 [MVP 스킬 표시 콘텐츠 v1](../../../../60-content/abilities/mvp-v1.md)과 [스킬 SSOT](../../../../30-domain/character/skills/ssot.md)를 따른다.
- 액티브 스킬의 시각 언어는 `apps/web/public/assets/effects/skills-v1/`의 현재 런타임 VFX를 참고했다.
- 생성 방식: Codex 내장 이미지 생성.
