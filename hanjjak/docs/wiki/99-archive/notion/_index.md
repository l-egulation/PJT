# Notion 원문 보관소

이 디렉터리는 2026-08-28 시점 Notion에서 회수한 내용을 원문 형태로 보존한다. 페이지 원문은 front matter에 Notion page ID와 원본 URL을 두고, 데이터베이스 행 export는 data source와 원문 속성을 둔다.

## 읽는 법

- doc_kind가 archive 또는 reference인 문서는 현재 정책이 아니다.
- 본문 안의 미정·구형·충돌하는 수치는 삭제하지 않았다.
- 서명된 이미지 URL은 만료될 수 있다.
- 첨부 파일 자체를 회수하지 못한 경우는 [첨부 목록](attachments.md)에 이유와 ID를 남겼다.

## 분류

- pages/project: 프로젝트 허브와 팀·자료실·상위 페이지
- pages/materials: 자료실 행과 설계 원문
- pages/ideas: 아이디어 행
- pages/develop: 개인 디벨롭 행
- [05-meetings/records](../../05-meetings/records/_index.md): 회의록 원문과 날짜별 전사
- databases: 데이터베이스 스키마와 행 속성
- [06-delivery/tasks](../../06-delivery/tasks/_index.md): 작업 페이지는 실행 문서에 원문 속성을 함께 보존

원문을 현재 정책으로 승격할 때는 원문 파일을 직접 고치지 않고, 해당 주제의 SSOT와 [결정 로그](../../../80-decisions/README.md)를 갱신한다.
