# 승인된 방·통로 축소안

사용자가 승인한 축소 시안 4종의 도면 원본은 `approved-prototypes.json`입니다. 승인 시안 4종을 보존하는 자료입니다. 현재 게임의 방 원형은 `../../data/map/block_rooms.json`입니다.

| 대상 | 승인 크기 |
|---|---|
| 숲의 이중 공터 | 32×18칸 |
| ㄷ자 회랑 | 32×27칸 |
| ㄹ자 층계 회랑 | 32×27칸 |
| 직선 통로 | 10×12칸 |

일반 방은 순방향 언덕 전투, ㄷ자는 상층 안쪽→하강→하층 출구, ㄹ자는 상층 오른쪽→중층 왼쪽→하층 오른쪽 동선을 유지합니다. 각 전투방은 10마리이며 ㄹ자는 3·4·3마리로 나눕니다. 통로에는 적을 배치하지 않습니다. 기존 전투 면을 재차 통과하는 필수 처치 동선은 두지 않습니다.

방과 방 사이 전체 배치 간격, 상하 분기·합류, 외부 출입구 어댑터, 나머지 방은 이 승인 데이터에 포함하지 않습니다. 이 파일을 동기화 도구에 직접 넣지 않습니다. 편집기/카탈로그/생성기의 크기 가정과 출입구 연결을 함께 변경하고 검증해야 합니다.
