# 1차 배포 체크리스트

Notion의 1차 배포 체크리스트와 A–K 데이터베이스를 옮긴 색인이다. 작업별 상태·완료 기준·증거는 [A–K 작업 색인](../../wiki/06-delivery/tasks/_index.md)과 하위 문서가 소유한다.

## 흐름

A 배포 범위 → B 계정·저장 → C 주력 재료 → D 스테이지 → E 자동전투·스탯 → F 드롭·인벤토리 → G 장비·제작·강화 → H 스킬·자동 사용 → I 거래소·경제 → J 데이터·테스트·배포 → K UI·UX

## 운영 원칙

- 초기 상태는 Notion 원문처럼 미확인이다. 구현·검증 증거 없이는 완료로 바꾸지 않는다.
- A-01이 범위를 소유한다.
- A-04의 인수 시나리오가 배포 판단의 종착점이다.
- 각 작업의 도메인 규칙은 작업 문서에 복제하지 않고 도메인 SSOT로 링크한다.
