	- 아이템 조합식은 일단 DAG 형태로 구성
- 맵 구조
	- 자원을 습득하는 지역 단위. ex) 셀 → 섹터 → 그리드
		- 지역 레벨은 하위 지역을 포함하는 관계<br>(ex. 그리드는 복수개의 섹터로 구성, 섹터는 복수개의 셀로 구성)

		- 동일 지역 레벨에서 경계를 넘어 다른 지역으로 이송하려면 패널티 발생<br>(ex. 셀 → 셀, 셀 → 섹터, 섹터 → 섹터, 섹터 → 그리드)<br>(ex. 이송비, 재료 손실 등)
		- 해당 지역에서 만들 수 있는 최대한 가치있는 아이템까지 만들어낸 다음에 상위 레벨 지역으로 옮기거나, 동일 레벨 지역으로 옮겨서 손실을 완화해야 함.
- 지역 비효율 개선:
	- 각 지역에서 생산하고 조합하는 아이템의 생산 과정은 `레시피`  획득을 통해 줄일 수 있음.<br>파이프라인이 만들어지고 끝이 아니라, 지속적으로 공정을 개선 가능. 무작정 방치하면 찝찝하게 만드는게 목적.
		- ex. 짜장면

			2. 파기름 + 춘장 = 볶은 춘장

		- ex. 짜장면(+레시피, 공정 간소화)
