# 폭발음 후보

2026-11-16 사용자 요청으로 만든 후보 모음이다. 사용자가 고를 때까지 게임에는 적용하지 않는다.

`preview/index.html`을 브라우저로 열면 서버 없이 재생된다. 화면 원본은 `source/template.html`, `source/app.js`다.

## 점검 결과

지금 폭발음 파일은 손상되지 않았다. 클리핑, 지직거림, 순간 튐이 없다. 이상하게 들리는 이유는 실제 폭발 녹음이 아니기 때문이다.

| 자리 | 지금 소리 | 정체 |
|---|---|---|
| 기본 폭발 `explosion_bomb` | B3 | 물 마법과 물 튀김을 섞은 「큰 물풍선」 |
| 큰 폭발 `explosion_large` | r11 | 해일 마법에서 충격을 뺀 물 소리 |
| 유탄 `explosion_grenade` | r3 | 작은 폭발을 990 Hz 아래만 남겨 먹먹하게 만든 3연쇄. 0.5초에서 급히 끝난다. |

## 후보 공통 규칙

- 구매팩의 폭발 계열 녹음만 쓴다. 원래 속도와 음높이를 유지하고, 왜곡이나 저음 보강은 하지 않는다.
- 2차 30 Hz 고역통과로 들리지 않는 울림만 걷어낸다.
- 시작은 녹음이 시작되는 지점이다. 끝은 녹음이 스스로 -54 dB까지 줄어든 지점이다. 녹음이 그 전에 끝나면 끝 80 ms를 페이드한다.
- 크기는 그 자리의 지금 소리와 같게 맞췄다. 기준은 K-가중 400 ms 최대값이다. 유탄은 지금 소리가 다른 자리보다 약 8 dB 작아서, 후보도 그만큼 작다.
- 유탄 후보는 지금과 같은 3연쇄로 만들었다. 시각은 0, 0.13, 0.27초이고 배율은 0.7, 0.55, 0.85다.
- 이름에 「레트로」가 붙은 후보는 8비트 게임 폭발이다. 일부러 거친 디지털 질감이 있어서 깨진 소리처럼 들릴 수 있다.

## 비교 화면

비교 화면에서 할 수 있는 것은 다음과 같다.

- 후보 단독 재생
- 지금 소리와 후보의 A/B 비교
- 0.15초 간격 3개 겹침 재생
- 지금 소리부터 후보 전부를 순서대로 재생
- 실제 공격·스킬 소리 뒤에 폭발 붙여 듣기: 폭탄 평타, 폭탄 3연투, 폭발 수리검, 폭탄 원거리·후속 스킬, 발사기 후속 특수기
- 폭발음·공격음·전체 음량 조절
- 별표, 메모, 선택 파일 저장

공격 뒤 폭발 시각은 비교용 예시이고, 게임 충돌 판정과는 다르다. 원음 해시와 가공 수치는 `source/recipes.json`에 있다. 메인 루트에서 `python resources/tools/build_explosion_candidates.py`로 다시 만든다.
