# 들쥐 행동

[분야 개요](README.md)

들쥐 AI는 공통 전투·HUD를 사용하며 들판 테스트 `Assets/MeadowDuskV3/Scenes/Chapter1MeadowCombat.unity`에서 확인한다. 들쥐1종의 수평 평지 행동이며 다른5종 AI의 구현 완료를 뜻하지 않는다.

행동 전달 데이터는 `data/monsters/chapter1_approved.json`, 들쥐 런타임 정의 생성은 `tools/combat/export_field_mouse.py`다. 플레이어 이동은 `data/combat/locomotion/player.json`, 일반 적 기본 피격 밀림은 `data/combat/enemy_hit_reaction.json`을 편집한다. Unity 생성 JSON만 수정하지 않는다.

## 에셋 복원

들쥐·무기·HUD 이미지는 [리소스 배치 안내](../../../assets/README.md)의 공통 실행기로 준비한다. 별도 입력 패키지 복원은 사용하지 않는다. 이미지 배치는 게임 정의를 재생성하지 않으며, 정의 변경이 있을 때만 `tools/combat/export_field_mouse.py`와 `tools/combat/export_unity_catalog.py`를 실행한다.

조작은 [들판 테스트 안내](../../../../unity/Assets/MeadowDuskV3/README.md)를 따른다.

## 현재 행동

1챕터 들판의 고정 지형은 씬 소유 `StaticArenaSurfaceIndex`에 생성 시 등록한다. 경로·발밑 검사에서는 경로의 경계 상자와 겹치는 후보만 구하고 기존 지면 높이·연속 지지·벽 판정을 그대로 적용한다. 검사 목록은 적마다 재사용한다. 이동·크기 변경·추가 지형은 인덱스 재구성이 필요하며, 현재 들판은 실행 중 지형을 변경하지 않는다. 스트리밍 숲 등 인덱스를 연결하지 않은 씬은 현재 활성 지형을 검색한다. 전투 120Hz·감지 주기·안전 여백·행동 규칙은 이 최적화로 바꾸지 않는다.

추적 지형 그래프는 몸 크기·속도·점프/낙하 정책·중력의 값 키로 공유하며 반복 조회에서 문자열 키를 만들지 않는다. 추적 지형은 단단한 상자를 8유닛 격자와 열별 바닥 높이 순서로 캐시한다. 그래프는 발판을 가로·높이 8유닛 격자와 열별 높이 순서로 캐시한다. 현재 발판·아래 발판·벽·천장 조회는 전체 목록을 훑지 않으며, 결과와 동률일 때 낮은 id를 고르는 규칙은 전체 검사와 같다. 추적 경로 탐색의 작업 목록은 몬스터마다 재사용하고, 같은 발판 위의 대상은 기존 수평 추격으로 처리한다. 같은 그래프의 추격자가 같은 발판에서 같은 대상 발판으로 가면 경로를 공유한다. 공유 경로는 0.5유닛 단위로 맞춘 시작·대상 위치와 종의 기본 추격 속도(개체 편차 제외)로 한 번 계산하고, 재계산 주기 동안 유지한다. 복귀 중인 개체와 최근 실패한 간선이 있는 개체는 자기 위치·속도로 따로 계산한다. 경로가 없다는 결과도 재계산 주기 동안 유지하고, 현재 발판이나 대상 발판이 바뀌면 바로 다시 찾는다. 그래프의 간선은 생성 후 변경하지 않으며 진행 중인 점프는 지형 캐시가 교체되어도 원래 간선·목표를 유지한다. 감지·경로 재계산 주기와 도약·낙하·공격 자격은 유지한다.

발 높이는 `ArenaSupportProbe`가 지형 전용 마스크와 적별 재사용 ray 결과 목록으로 검사한다. 동일한 발 좌표·중심 오프셋·허용 오차·접촉 skin의 결과만 동기 읽기 묶음 안에서 공유한다. 감지/평지 경로 관측, 공격 자격 관측과 안전 속도 계산의 읽기 묶음을 분리하며 이동·방향 변경·공격/취소 콜백 전에 끝낸다. 다음 묶음과 묶음 밖의 공개 검사는 다시 물리를 조회하므로 같은 시뮬레이션 시각의 발판 비활성화·이동도 이전 결과로 대신하지 않는다. 감지·공격·추격 주기와 경로 재탐색 정책은 유지한다.

발판도 감지 시야를 차폐한다. 감지와 실제 공격 차폐는 별도이며 근접 공격의 기존 발판 비차폐는 유지한다. 착지 시 물리 접촉 여유를 다른 높이의 지면으로 오인하지 않는다. 보이지만 도달할 수 없는 대상은 마지막 안전 지점에서 대기 후 복귀한다. 복귀 완료 후에도 기존 재교전 조건을 유지해 같은 도달 불가 대상을 향해 왕복하지 않는다.

몸 겹침의 공격 시작 간격은0이다. 정상 준비·사거리·높이·방향 고정·실제 공격 박스 적중 조건을 유지하며 접촉 피해는 없다. 일반 적 기본 피격은0.30초 경직·공격 취소와0.25칸/0.10초 밀림을 적용한다. 고체 벽에서 멈추고 별도 밀기 효과에 기본 밀림을 더하지 않는다. 보스·미끼는 기본 밀림에서 제외한다.

일반 지상·공중 이동은7.5칸/초이며 대시·점프 높이·기술별 이동은 별도다. 최신 검 v10 공격은 원본 이미지8장 미확보로 보류했다. 실행용 기존 확정 무기 모션을 사용하며 최신 검 교체 완료를 주장하지 않는다.

경사·0.125칸 단차·지면 우회 경로와 실제 접촉 시각을 정렬하는 다중 액터 동시 사건 처리는 현재 들쥐 행동의 구현 범위가 아니다. 검증 결과는 커밋 본문과 Git 제외 `outputs/`의 실행 출력으로 관리한다.
