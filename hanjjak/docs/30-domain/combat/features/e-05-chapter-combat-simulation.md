- 규칙·수치·상태의 정본: [전투 SSOT](../ssot.md)
- 실행 상태·완료 기준·증거: [E-05 작업 문서](../../../wiki/06-delivery/tasks/E-auto-combat/e-05-chapter-combat-simulation.md)

기능 요구가 바뀌면 먼저 정본 문서의 책임 범위를 확인하고, 필요한 결정은 [결정 로그](../../../80-decisions/README.md)에 남긴다.
