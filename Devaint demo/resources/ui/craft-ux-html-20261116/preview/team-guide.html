03 / NAVIGATION방향키는 지금 선택한 영역에서 움직입니다

상단 가방 / 장비↓가방 스케치 / 잉크↓아이템 목록F선택한 항목 실행
  • 탭 위치로 올라간 뒤 ← →로 가방 / 장비를 바꿉니다. 가방의 분류도 같은 방식으로 이동합니다.
  • 가방 첫 줄에서 ↑를 누르면 분류로, 분류에서 다시 ↑를 누르면 상단 탭으로 올라갑니다.
  • 탭을 옮긴 직후에는 탭 또는 분류가 선택된 상태입니다. ↓로 목록에 내려가기 전에는 첫 잉크를 선택한 것처럼 강조하지 않습니다.
  • 탭의 A/D, Q/E 키와 표시를 제거했습니다. 방향키로 이동하며 탭 글씨의 위치는 선택 여부와 관계없이 고정합니다.
  • F는 항상 현재 선택된 대상의 실행입니다. 화면에 보이는 모든 F 안내가 동시에 작동하는 의미가 아닙니다.

노랑 = 현재 선택 / 실행 대상

선택한 버튼과 키 표시, 선택 무기의 이름과 상태 문구를 노란 포인트 색으로 보여 줍니다.

잉크 = 고유 색상 우선

선택한 잉크는 노랑으로 덮지 않고 그 잉크의 색으로 표시합니다. 목록의 다른 잉크는 흑백입니다.

가방의 스케치 목록은 확정 여부를 한 번에 비교해야 하므로 비선택 무기를 흐리게 하지 않는 예외입니다. 장비 목록과 잉크 목록은 현재 선택을 구분하도록 비선택 항목을 낮춰 표시합니다.

04 / BAG가방에는 스케치와 잉크 두 분류만

스케치 목록

  • 미확정 스케치와 제작 확정된 무기를 함께 표시합니다. 확정 무기는 장착 여부와 관계없이 가방에서 확인할 수 있습니다.
  • 미확정: 무기 그림은 흑백, 아래에 예를 들어 4칸 / 미확정 표시. 선택하면 F 제작하기.
  • 확정: 무기 그림은 컬러, 내구도 정보 표시. 선택하면 F 장착하기로 이어집니다.
  • 선택한 이름은 조금 더 크게, 이름 아래 상태도 같은 노란색으로 강조합니다. “미확정 스케치 n개 / 방향키 선택” 같은 반복 안내는 제거했습니다.

06 / CONFIRMATION확인은 한 번, 기본 선택은 제작 확정

↓ 제작하기 선택F →이 구성으로 제작할까요?F →제작 확정
  • 팝업에는 무기 이름, 적용한 칸 수, 빈 칸 수, 각 칸의 잉크와 현재 적용한 잉크 요약이 함께 나옵니다.
  • 버튼은 제작 확정 / 계속 편집 두 개입니다. 위치를 뒤집지 않고 처음 선택을 제작 확정으로 맞췄습니다.
  • ←는 제작 확정, →는 계속 편집을 선택합니다. F는 선택한 버튼을 실행합니다.
  • 선택된 버튼에 F 키 표시를 두고, 계속 편집 버튼에 Esc 표시는 중복해서 붙이지 않습니다. 시안의 Esc 취소 동작은 남아 있습니다.

11 / REVIEW ROUTE팀원이 직접 확인할 순서

시안 열기 후 “샘플 초기화”에서 시작하면 같은 순서로 확인할 수 있습니다. 마우스는 시안을 여는 데만 사용하고, 이후에는 방향키와 F를 중심으로 조작해 보세요.

  1. 가방의 미확정 무기는 흑백, 확정 무기는 컬러인지 확인합니다. 비선택 무기도 확정 여부를 구분할 수 있어야 합니다.
  2. 가방 첫 줄에서 ↑로 분류에 올라갑니다. 잉크로 바꾼 직후에는 첫 잉크가 선택 표시되지 않고, ↓로 내려갔을 때 활성화되는지 확인합니다.
  3. 잉크 목록에서 선택한 항목만 고유 색, 나머지는 흑백인지 확인합니다. 목록은 n/총수, 상세는 남은 횟수 n회 / 총 횟수 n회여야 합니다.
  4. 미확정 스케치에서 F 제작하기. 오른쪽 잉크가 보이더라도 왼쪽 칸에서 F를 누르기 전까지 잉크 선택 상태로 오해되지 않아야 합니다.
  5. 1번 칸 → F → 잉크 이동 → F. 1번 칸에 적용되고 왼쪽으로 돌아오는지 확인합니다. 같은 방식으로 다른 칸도 채웁니다.
  6. 잉크 선택 중 Esc로 나와 적용하지 않는 경우와, 채운 칸에서 R로 지우는 경우를 확인합니다.
  7. ↓로 제작하기에 내려가면 위 편집 영역이 흐려지는지 확인합니다. ←→로 돌아가기를 선택했을 때 F 표시도 따라가야 합니다.
  8. 제작하기 F → 확인창. 적용 잉크와 빈 칸, 소모·변경 불가 안내를 확인합니다. 기본 선택은 제작 확정이며, 계속 편집도 방향키와 F로 선택할 수 있어야 합니다.
  9. 제작 확정 후 새 무기의 내구도·팔레트와 현재 슬롯 두 개를 확인합니다. ←→로 슬롯을 바꾸고 F 교체 후 바로 전투 복귀하는지 확인합니다.
  10. 샘플을 다시 구성해 이번에는 C 보관을 실행합니다. 기존 장착이 유지되고 새 무기는 보관되며, 추가 확인창 없이 전투로 돌아가야 합니다.
  11. 장비 탭에서 무기 2 슬롯부터 F 교체하기 → 보관 무기 선택 → F. 무기 2에 바로 들어가고 슬롯 선택을 한 번 더 묻지 않아야 합니다.
  12. 반대로 보관 무기부터 고르면 F 후 대상 슬롯 선택이 나오는지 확인합니다. 슬롯 우선 흐름과 구분해야 합니다.
  13. 장착 슬롯에서 R 해제하면 맨손이 되는지, X로 두 자리가 교환되는지, N으로 이름을 바꿀 수 있는지 확인합니다.
  14. 상단의 “무기 2 맨손”과 팔레트 4/5/6칸 조건을 바꿔 긴 이름, 많은 칸, 빈 슬롯에서도 배치와 조작 안내가 잘리지 않는지 확인합니다.
