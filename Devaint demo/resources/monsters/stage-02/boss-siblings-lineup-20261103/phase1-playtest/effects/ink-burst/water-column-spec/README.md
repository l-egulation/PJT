# 잉크 분출: 낮은 기둥과 물보라
검토용 코드 VFX. 기존 채택 에셋 및 Unity 적용본은 변경하지 않음.

- 240×150 픽셀 화면을 nearest-neighbor 확대.
- 최신 피드백: 높이 65px, 반폭 8px로 낮춰 꼭대기 방울이 화면 안에 보이게 함.
- 어두운 검보라 3색 #0a0910 #17131f #30263e. 가장자리 전용 색 띠를 제거해 외곽선 없이 내부 명암만 흐르게 함.
- 분출 시 밑동 물보라 24개, 유지 중 꼭대기와 밑동의 추가 방울. 큰 방울은 2px 덩어리로 표시.
- 중력 260, 바닥에서 방울 소멸. 바닥 원형 물결은 없음.
- 예고 .28s / 분출 .16s / 유지 .8s / 붕괴 .42s. 조절 슬라이더, 슬로모, 반복 및 정지 제공.

## 맵 배치 검토
1페이즈 웹 테스트에 코드 기둥 선택지를 연결. 4배 정수 확대, 중앙 발판 표면에 2px 겹쳐 배치. 시각 높이 260px. 사용자 참고 이미지처럼 밑동의 얕은 잉크 웅덩이와 끊어진 솟은 가장자리를 추가. 기존 이미지 선택 가능. 피해 수치·판정은 기존 값 그대로이며 Unity 적용 없음.

맵 크기 보정: 너무 크다는 피드백으로 맵 배치만 3배 정수 확대, 높이 50px로 조정. 화면상 높이 260→150px, 본체 폭 64→48px. 밑동 바닥선 +2px 유지. 단독 조절 시안 값은 유지.

맵에서 기둥 몸통 폭 6~96px, 높이 45~300px를 개별 조절. 기본 폭 24px. 변경 즉시 고정 분출 장면을 갱신하며 재생으로 동작 확인. 3배 정수 확대를 유지하고 시뮬레이션 형상만 변경.

밑동 참고 이미지 반영: 납작한 타원형 잉크 웅덩이에 끊어진 보라빛 물보라 림과 양옆의 짧은 솟음을 추가. 기둥 몸통을 줄여도 밑동은 최소 폭 유지. 외곽 검정 선이나 화면 밖으로 퍼지는 원형 파문은 추가하지 않음.

## 바닥 원형 잔상 (영상 피드백)
최신 지정값: 맵 높이 102px / 몸통 폭 30px. 분출·유지 중 0.28초 간격으로 밑동에서 납작한 타원형 파문을 발산. 각 파문은 .72초간 바깥으로 퍼지며 끊어진 픽셀 잔상을 남김. 기둥 붕괴 후에도 남은 파문은 수명 끝까지 표시. 파문 보조색 #51405f 사용.

## 세밀한 픽셀 보정
맵 배치 렌더링을 3배에서 1배로 변경하고 형상 치수를 직접 화면 픽셀로 입력. 폭 30px·높이 102px 유지, 바닥 파문을 1px 선으로 표시. 파문 확산 범위와 타원 깊이는 별도 배율로 유지.

## 상승 동작 보정
분출 중 높이 비율로 밑동과 무늬를 다시 늘리던 계산 제거. 밑동 확장 형상은 목표 높이에 고정하며, 무늬는 바닥 기준 좌표에서 위로 이류. 0.24초 동안 분출 선두가 단조 상승, easeOutBack 반동 제거. 상승 선두에 짧은 밝기 띠 추가. 맵의 `잉크 분출 처음부터` 버튼으로 시작 구간 재생 가능.
