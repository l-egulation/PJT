# 끌어당김 이펙트 시험판

보라 잉크 교대의 손짓(무기 전환 시 주변 몬스터를 전환 전 자리 쪽으로 최대 1칸)과 쓰러진 중심(처치 시 처치 지점 쪽으로 최대 1칸)이 몬스터를 끌어올 때 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다.

빛 줄 하나가 손에서 몬스터로 날아가 가슴에 착 붙고(잉크 번짐), 붙는 순간만 관성으로 출렁이다가 일자로 팽팽하게 펴진다. 잠깐 멈춘 뒤 일자 그대로 몬스터를 1칸(32px) 끌어오고, 놓으면 일자 그대로 손으로 감겨 들어간다. 줄은 18마디를 이은 물리(버렛 적분 + 길이 제약)로 움직이고, [`../속박/glow-path.js`](../속박/glow-path.js)로 흰 심 → 보라 → 반투명 번짐으로 칠한다.

- `pull-rope.js`: 이펙트(0.8초). 시점 상수 `SHOOT`(0.1, 붙음) · `TAUT`(0.2, 일자로 펴짐) · `PULL0`~`PULL1`(0.26~0.46, 당김) · `RELEASE`(0.52, 놓음). 옵션 `dist`(몬스터까지, 72) · `pull`(끌어오는 거리, 32) · `hand`(손 높이, -30) · `chest`(붙는 높이, -26).
- `export.mjs`: Git 제외 `outputs/pixelfx/pull/pull-rope_purple.png/json`을 뽑는다. 시점·거리를 JSON `meta.pixelfx`에 적는다.

```sh
node 전투테스트/끌어당김/export.mjs --pixelfx <pixelfx>
```

## 게임에 붙일 때

- 몬스터를 실제로 옮기는 건 게임이 한다. `pullStart`~`pullEnd`(0.26~0.46초) 동안 ease-out(1-(1-k)^3)으로 `pullDistance`(32px)만큼 당기는 쪽으로 옮기면 줄과 맞는다.
- 시트는 몬스터가 오른쪽 72px에 있는 경우 하나로만 구워진다. 실제 거리·높이는 매번 달라 시트를 늘이거나 돌리면 줄 굵기가 어색해진다. 거리가 크게 다르면 이 코드를 기준으로 게임 안에서 줄을 직접 그리는 편이 맞다.
- 왼쪽으로 당기면 시트를 좌우 반전한다. 여러 몬스터를 당기면 줄을 몬스터마다 하나씩 쓴다.

## 시트 규격

- 112×72, 25fps, 21장(마지막은 빈 장). 피벗 (12, 60) = 당기는 쪽(플레이어 또는 처치 지점) 발 가운데. PPU32 게임 화소 1:1.
- 보라 팔레트는 임시값이다. 「주변」 범위·보스 적용은 기획에서 미정이다.

## 확인한 범위

마을 배경 위 가시뿌리를 72px 떨어진 자리에서 실제로 32px 끌어오는 렌더링으로만 봤다(당기는 쪽은 막대로 표시). 중심에 빨려 드는 시안 셋(조여드는 물결·소용돌이·쏠리는 줄기) 대신 사용자가 「줄 하나로 물리를 적용해 착 붙고 당기는」 방향을 골랐고, 일자로 펴진 뒤 당기게 다듬었다. Unity·여러 몬스터·다른 거리는 확인하지 않았다.
