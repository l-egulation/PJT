# I-03 매수·매도 IOC와 부분 체결

- 규칙·수치·상태의 정본: [거래소·경제 SSOT](../ssot.md)
- 실행 상태·완료 기준·증거: [I-03 작업 문서](../../../wiki/06-delivery/tasks/I-marketplace-economy/i-03-instant-partial-purchase-settlement.md)
- 장비 강화 부족 재료 구매 계획: [요구사항](../../../70-plans/equipment-shortage-market-purchase/requirements.md)
- 양방향 주문장 전환 계획: [Office Hours 설계](../../../70-plans/market-order-book/design.md)

기능 요구가 바뀌면 먼저 정본 문서의 책임 범위를 확인하고, 필요한 결정은 [결정 로그](../../../80-decisions/README.md)에 남긴다.
