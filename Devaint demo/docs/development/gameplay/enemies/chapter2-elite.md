# 2챕터 A3 엘리트 본 게임 연결

[분야 개요](README.md)

## 실행과 배치

Unity 6000.6.5f1의 기존 `Assets/Chapter2/Scenes/Chapter2Procedural.unity`에서 동작한다. 공통 게임의 1→2챕터 진입도 같은 씬을 사용하므로 별도 시험장으로 전환하지 않는다.

`Chapter2World`가 레이아웃의 기존 `E:elite` 배치에서 `Chapter2EliteEnemy`를 생성한다. 기존 좌표·방 소유권·방 구조·다른 적·임시 보스는 유지한다. 레이아웃의 `04_well-warden`은 기존 배치 식별자다. 실제 A3 외형은 `Chapter2ElitePresentation`이 승인된 24/52/28프레임과 독립 VFX를 재생한다. 기존 씬·레이아웃은 수정하지 않는다.

## 교전·추격·처치

- E방 첫 진입에 교전을 시작하고 첫 패턴 전 2초 기다린다. 그 전에는 다른 방에 있는 플레이어를 원거리 기습하지 않는다.
- 교전 뒤 같은 챕터의 보스 조우 전까지 모든 방·통로에서 엘리트의 시뮬레이션·피격·공격을 유지한다. 시작방·정비소도 포함한다. Rose·Blue 보스 조우 진입 시 A3는 보상 없이 제거되고 추격·효과·파편이 정리된다. 방 이동이 진행 중인 엘리트 패턴이나 파편을 취소하지 않는다.
- 일반 적은 기존 소유 방의 전투 활성 규칙을 계속 사용한다. 엘리트의 장거리 이동 수단은 안전 지면을 검사하는 순간이동이며 별도 평상시 걷기 추격은 추가하지 않는다.
- 처치 장소와 관계없이 소유권은 E방이다. 기존 `Chapter2RoomState`와 중복 정산 방지를 사용해 E방 섬멸·섬멸 회복·엘리트 보상·킬을 한 번만 처리한다. 회복은 플레이어가 살아 있을 때만 적용하고 보상은 처치 위치에 생성한다.
- 플레이어 사망 또는 엘리트 사망 시 공격·파편·날림을 정리하고 추격을 종료한다. 챕터 씬을 떠날 때 해당 인스턴스와 이벤트를 정리하며 다른 챕터로 승계하지 않는다.
- F5 전투 초기화는 엘리트 체력·원래 배치·교전 여부·E방 섬멸 상태를 함께 초기화한다. 정비소·가방·지도·일시정지는 공통 시뮬레이션 정지 정책을 따른다.

## 수치와 시간

설계 기준은 [엘리트 명세](../../../design/enemies/chapter2/elite/chapter2-elite-three-patterns.md)다. 편집 원본은 `data/combat/chapter2_elite.json`, 생성 사본은 `unity/Assets/Chapter2/Resources/Chapter2Elite.json`이다.

```sh
python tools/combat/export_chapter2_elite.py
python tools/combat/export_chapter2_elite.py --check
```

HP 270. 방이 다르거나 근접 범위 밖이면 순간이동을 우선하고, 근처에서는 사용 가능한 패턴 중 동일 확률 랜덤 선택이며 연속 중복을 허용한다. 공중 플레이어에게 순간이동을 시작하지 않는다. 모든 공격 종료 후 휴식은 2초이며 추가 쿨다운은 없다.

| 패턴 | 패턴 시작부터의 시간 | 피해 |
|---|---|---|
| 순간이동 펀치 | 시전 0~0.77초, 도착 후 준비 0.77~1.02초, 활성 1.02~1.12초, 휴식 1.12~3.12초 | 20, 날림 중 벽 충돌 시 추가 10·스턴 1초 |
| 전진 3연타 | 1.3배속 접점 약 0.77/1.15/1.92초, 마지막 활성 종료 2초, 휴식 종료 4초 | 15/15/25 |
| 돌 파편 | 응축·좌우 추적 0~1.45초, 1.45초 방향·돌 위치·조준 고정, 1.5초 발사, 휴식 종료 3.5초 | 각 8, 5개 모두 적중 시 40 |

돌은 응축 중 승인된 주먹 앞 돌 중심을 따라 이동한다. 1.45초 고정 후 플레이어가 반대편으로 이동해도 재조준하지 않는다. 파편은 60° 부채꼴로 균등 배치하고 30u/s로 벽 또는 플레이어에 닿을 때까지 날아간다. 휴식 중에도 발사한 탄은 유지한다.

순간이동 취소는 0.77초 시전 완료 때 판정하고 2초 휴식한다. 날림은 수평 6u/0.15초이며 유효 대시가 날림·벽 충돌보다 우선한다. 벽 추가 피해는 날림당 1회이며 해당 벽 충돌 스턴 동안에는 대시를 시작할 수 없다.

시험장에서 승인한 임시 판정 수치를 본 게임에도 사용한다. 본체 충돌 판정 2.4×3u, 순간이동 펀치 활성 0.1초·3연타 활성 약 0.077초·타격당 1회, 각 0.5u 전진은 접점 직전 약 0.077초, 파편 가시 크기 0.5u·충돌 박스 0.35u다. 파편은 현재 고체 바닥·천장·벽에서도 소멸한다. 전체 전투 장소에서의 수동 밸런스 검증은 별도다.

## 공통 전투와 연결

`CombatActor.ReceivesAutomaticHitReaction`은 기본값이 true인 선택적 정책이다. A3만 일반 피격 경직·기본/타격감 자동 밀림·생존 시 젖힘/들림을 받지 않는다. 명시된 밀기·당기기 스킬과 기존 기절·속박 제어는 유지한다. A3를 보스로 분류해 변위 전체를 막지 않는다.

전용 근접 반응은 `ICustomPlayerHitReactionSource`로 공통 추가 밀림과 중복되지 않게 한다. 수평 날림과 대시 취소는 플레이어의 기존 모터·대시를 사용한다. 다른 챕터·일반 적은 기본 정책을 유지한다.

## 검증 범위

`Deviant.Chapter2.Tests.Chapter2EliteIntegrationTests`는 기존 씬을 저장하지 않고 열어 E 배치·HP·첫 교전·다른 방/통로 추격·일반 적 방 밖 교전 유지·정비소 정지·다른 방으로 순간이동·날림 대시·E방 보상 중복 방지·사망/초기화·승인 모션 접점 수치·일반 경직 면역·명시 밀기·돌 좌우 추적/고정을 검사한다. Unity Test Runner의 EditMode에서 실행한다. 전용 아트 품질·모든 레이아웃 수동 완주·최종 난도 승인을 대신하지 않는다.

## 아트 배치와 재생

원본은 `resources/monsters/stage-02/elite/stone-fist/`에 보존한다. 리소스 커밋과 메인 gitlink를 일치시킨 뒤 고정 실행기로 Unity 사본을 배치한다.

```sh
python tools/assets/register_chapter2_elite_art.py
python tools/combat/export_chapter2_elite_art.py
python tools/combat/export_chapter2_elite_art.py --check
python tools/assets/update_assets.py --check
python tools/assets/update_assets.py
```

`data/combat/presentation/chapter2_elite_art.json`은 선택한 프레임·시간·피벗·효과 배율의 편집 원본이다. 생성된 `Resources/Chapter2EliteArt.json`과 Point/Full Rect/PPU32 가져오기 설정을 사용한다. 본체의 88px 대기 높이에 기준 3u × 외형 배율 1.6를 적용해 시각 높이 4.8u로 맞춘 동일 배율과 발 피벗을 모든 모션에 적용한다. 회수 모션은 전투 휴식 상태에서도 끝까지 재생한다. 본체와 효과는 모두 `arena.Now`를 샘플링하며 별도 실시간 타이머를 사용하지 않는다.

바닥 3연타의 충격파와 장식용 돌 10/12/18개는 피해가 없다. 돌 펀치의 파쇄 40ms 이후에는 실제 비행탄 5개만 표시한다. 속도 30u/s, 중심 조준 기준 -30/-15/0/+15/+30도, 중력·유도 없음이다. 비행탄의 원본 16px 돌 모양은 보존하고 런타임 투명 여백을 더해 흰 1px 테두리가 잘리지 않게 한다. 긴 축을 속도 벡터에 맞추며 패링 반사 후에도 정렬한다. 본체에는 흰 테두리를 적용하지 않는다.

Unity 검증은 원본 패키지와 설정을 `outputs/` 아래 격리 프로젝트에 복사하고 Unity 6000.6.5f1 EditMode에서 수행한다. `Chapter2EliteArtIntegrationTests`는 모션 접점·피벗·크기·일시정지 샘플·장식 돌·실제 5개 탄과 흰 외곽 렌더를 검사한다. 원본 아트 재생과 게임의 실제 탄 충돌·수명은 구분한다.
