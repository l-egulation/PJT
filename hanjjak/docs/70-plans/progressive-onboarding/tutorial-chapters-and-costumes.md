# 역할 의상별 튜토리얼 장 구성

## 결론

튜토리얼을 **7개의 역할 장**과 **선택형 번외 안내**로 나눈다. 한 역할 장 안의 작은 퀘스트들은 같은 의상을 공유하고 대사와 자세만 바꾼다.

이 구조는 사용자가 의상만 보고도 설명 주제를 예상하게 하고, 퀘스트마다 새 의상을 만드는 에셋 폭증을 막는다.

게임의 스테이지 챕터 1~4와 혼동하지 않도록 사용자 화면에는 `튜토리얼 챕터 1` 같은 번호 대신 `모험가의 장`, `보석 마법사의 장`처럼 수첩의 장 이름을 사용한다.

## 큰 구분

| 역할 장 | 한짝 의상 | 담당 콘텐츠 | 시작 계기 | 장의 마지막 경험 |
| --- | --- | --- | --- | --- |
| 모험가의 장 | 스카프·작은 배낭을 착용한 초보 모험가 | 첫 메인 전투, HP와 진행, 획득 패널, 레벨·능력치, 전투 결과 | 첫 메인 화면 진입 | 첫 전투 결과와 전리품 확인 |
| 대장장이의 장 | 앞치마·머리띠·작은 망치를 든 견습 대장장이 | 재료와 인벤토리, 장비 6부위, 최초 제작, 강화, 승급 | 실제 제작 가능 상태 또는 성장 제안이 필요한 첫 실패 | 장비 성장 결과 확인 |
| 비법 수련가의 장 | 수련복·머리띠·스킬북을 든 수련가 | 스킬북, 스킬 해금, 액티브 슬롯과 우선순위, 패시브, 강화·승급 | 첫 스킬북을 실제로 획득 | 장착한 스킬의 첫 자동 발동 확인 |
| 던전 기사의 장 | 가볍고 단순한 갑옷·방패 문양의 기사 | 오늘 열린 던전, 세 입장문, 입장권, 세 보스 유형, 도전·포기, 최초 클리어, 소탕 | 던전 해금 뒤 첫 방문 | 첫 보석함 획득 또는 정상적인 실패 결과 확인 |
| 보석 마법사의 장 | 짧은 로브·마법 모자·보석 브로치를 착용한 마법사 | 보석함 개봉, 보석 옵션, 장착, 전투별 프리셋 연결, 합성, 잠금 | 보석함 또는 장착 가능한 보석을 실제 보유 | 보석 프리셋을 전투에 처음 연결 |
| 스타일리스트의 장 | 베레모·줄자·짧은 케이프를 착용한 재단사 | 치장 뽑기, 재화·확률 확인, 첫 획득, 미리보기·착용, 중복 등록, 도감·세트 | 치장 해금 뒤 첫 방문 | 첫 치장 착용 또는 첫 세트 진행 확인 |
| 장터 상인의 장 | 상인 모자·동전 주머니·장부를 든 상인 | 거래 품목 탐색, 구매·판매, 주문, 물품 수령, 판매 정산·우편 | 부족 재료 바로 가기 또는 사용자의 거래소 첫 방문 | 첫 거래 결과나 미체결 결과를 이해하고 수령·정산 확인 |
| 번외: 마을 안내 | 모험가 의상을 재사용 | 랭킹, 채팅, Picture-in-Picture, 설정, 오프라인 보상, 전투 기록 | 사용자가 해당 기능을 직접 처음 선택 | 별도 장 완료 없이 첫 방문 안내 종료 |

## 권장 순서

```text
모험가
  ├─ 재료가 준비됨 ─────────> 대장장이
  ├─ 스킬북을 얻음 ─────────> 비법 수련가
  └─ 던전·보석·치장이 열림 ─> 원하는 역할 장 선택
                                  ├─ 던전 기사 ─> 보석함 획득 ─> 보석 마법사
                                  └─ 스타일리스트

성장 재료가 부족하거나 거래소를 직접 방문함 ─> 장터 상인
```

역할 장은 완전한 직선 코스가 아니다. 기능이 실제로 열리고 플레이어가 수행 가능한 상태가 되었을 때 추가한다. 던전에서 보석함을 얻은 뒤 보석 마법사로 이어지는 흐름은 자연스럽지만, 이미 보석을 가진 사용자는 던전 장을 기다리지 않고 보석 장부터 시작할 수 있다.

## 역할 장 하나의 공통 리듬

각 장은 다음 세 박자로 통일한다.

1. **등장 대사**
   - 의상을 입은 한짝이 자신이 맡은 역할과 지금 배울 이유를 한 문장으로 말한다.
2. **핵심 행동 2~4개**
   - 한 화면에 대상 하나만 강조하고, 클릭으로 대사를 넘긴다.
   - 완료는 화면 클릭이 아니라 제작·클리어·획득·장착처럼 실제 확정된 결과로 판단한다.
3. **완료 대사와 도장**
   - 배운 내용을 한 문장으로 정리하고 다음 역할 장이 준비되었을 때만 연결한다.

예를 들어 던전 기사의 장은 다음 정도면 충분하다.

```text
등장: 오늘은 내가 던전 안내 기사야!
1. 오늘 열린 세 입장문과 보스를 확인한다.
2. 입장권·다음 단계·보상을 확인한다.
3. 처음 도전하고 성공·실패·포기 결과 중 하나를 확인한다.
숙련 의뢰: 이미 이긴 보스를 처음 소탕한다.
```

소탕, 일괄 합성, 지정가 주문처럼 첫 사용에 필요하지 않은 기능은 같은 의상을 쓰는 `숙련 의뢰`로 나중에 추가한다. 입문 장을 길게 만들지 않는다.

## 의상 디자인 규칙

- 의상은 기능을 상징하는 소품 2~3개만 사용한다. 갑옷과 로브도 화려한 판타지 장식보다 기존 한짝의 단순하고 귀여운 실루엣을 유지한다.
- 얼굴과 젓가락 몸통을 가리지 않는다. 모자·망토·앞치마는 한짝임을 즉시 알아볼 수 있는 크기로 제한한다.
- 세 던전 보스마다 새 갑옷을 만들지 않는다. 기사 의상 하나를 유지하고 대사창의 작은 보스 배지로 생존형·폭주형·장갑형을 구분한다.
- 튜토리얼 의상은 설명을 위한 역할극 표현이며 실제 보유 치장, 착용 상태나 전투 능력치를 바꾸지 않는다.
- 스타일리스트 의상도 획득 가능한 치장처럼 오해되지 않도록 대화창에 `안내 의상` 표식을 공통으로 둔다.
- 좌우 지시 자세를 반전해 재사용하려면 문양과 소품을 좌우 대칭으로 설계한다.

## 에셋 규모

개별 퀘스트마다 의상을 새로 만들지 않고 다음 네 자세를 역할 장마다 재사용한다.

| 공통 자세 | 사용처 |
| --- | --- |
| 인사·기본 설명 | 장 시작과 일반 대사 |
| 지시 | UI 대상 강조, 좌우 반전 가능 |
| 걱정·주의 | 실패, 공간 부족, 소비 전 경고 |
| 격려·완료 | 성공, 장 완료, 다음 행동 연결 |

7개 역할 의상에 네 자세를 모두 제작하면 최대 28개다. 최초 시안은 사용 빈도가 높은 `모험가`, `던전 기사`, `보석 마법사` 세 의상과 네 자세만 제작해 12개로 검증하고, 나머지는 같은 실루엣 규칙으로 확장한다.

가능하면 `기본 몸·표정`, `의상`, `손에 든 소품`을 레이어로 분리한다. 평면 PNG로만 제작하더라도 같은 자세의 몸 비율과 기준점을 고정해 의상 교체가 캐릭터 재설계처럼 보이지 않게 한다.

- [빈 튜토리얼 대화창](./mockups/tutorial-dialogue/tutorial-dialogue-frame-blank-v1.png)
- 왼쪽 25%는 역할 의상 캐릭터가 겹쳐지는 영역으로 비워 두고, 빈 이름표는 그 오른쪽부터 시작한다.
- 이름과 본문은 이미지에 굽지 않고 화면에서 텍스트로 합성한다.
- 배경 제거와 최종 화면 비율에 맞춘 여백 정리는 사용자 후처리 범위다.

## 퀘스트에 넣지 않는 것

- 랭킹·채팅·Picture-in-Picture·설정은 필수 역할 장으로 만들지 않는다.
- 거래소는 시장 물량에 따라 결과가 달라지므로 메인 진행의 필수 관문으로 사용하지 않는다.
- 레이드·아레나처럼 현재 제공 범위가 아닌 콘텐츠의 의상과 튜토리얼은 미리 만들지 않는다.
- 기능 해금 전에 의상을 먼저 등장시켜 아직 할 수 없는 행동을 설명하지 않는다.

## 현재 기준과 미결정 사항

### 현재 기준

- 메인 전투는 자동으로 진행되며 튜토리얼이 공격 버튼을 요구하지 않는다.
- 보석 던전과 보석, 치장은 실제 서버 해금 상태를 기준으로 안내한다.
- 세 던전 보스의 첫 도전 안내는 유형별로 한 번만 제공한다.
- 기능 설명 의상은 실제 치장 보유·착용·전투 효과와 분리한다.

### 추후 결정

- 역할 장 완료에 별도 보상을 지급할지 여부
- 사용자 화면에서 사용할 수첩 이름과 역할 장의 최종 명칭
- 역할 의상도 나중에 실제 치장으로 제공할지 여부
- 모든 역할 의상을 레이어형으로 제작할지 완성형 초상 PNG로 제작할지 여부
