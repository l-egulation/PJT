# 성장·재고·보상·경제

[분야 개요](README.md)

장비 성장의 기준은 [무기 도면·런 잉크 도감](../equipment/rules.md)이다. [런 구조](run-structure.md)와 런 사이 영구 성장을 구분한다.

## 런 안의 성장과 재고

맨손으로 출발해 처치 보상과 상점에서 무기를 얻는다. 무기를 확정하고 두 칸에 장착하는 과정은 [스케치 무기](../equipment/sketch-weapons.md)를 따른다. 획득 무기·잉크·남은 내구도는 해당 런에 귀속한다.

## 처치 보상과 상점

[일반 보상·보스·상점](rewards.md)은 별도로 집계한다. 상점은 무기와 잉크를 골드로 판매한다. 팔레트 구성에는 골드가 들지 않으며 잉크는 슬롯당 1회를 예약·확정 소비한다. 상품 진열·가격은 [상점 시험값](rewards.md#스테이지에서-얻는-무기와-잉크), 칸 수 비례 최대 내구도는 [내구도 시험값](../equipment/durability.md#칸-수-비례-최대-내구도-시험값)을 따른다.

영구 성장 중 새 구조에 맞춘 해금 대상·의존 관계·기존 저장 이전은 [로그라이트 영구 성장](../progression/roguelite-progression.md)을 따른다. 런 도감은 영구 수집 도감이 아니며 새 런마다 새로 구성한다.

## 증강

정비소의 런 내 공격력 강화를 없애고 [안정형 1장·도박형 2장 중 1장 선택](../progression/maintenance-augments.md)으로 성장한다. 증강은 상점에서 팔지 않으며, 다음 챕터로 이어지는 보스를 처치하면 무기 보상 뒤에, 봉인 도전방 보상 상자를 열면 무료로 1장을 고른다(사용자 결정 2026-11-13). 마지막 챕터(현재 2챕터) 보스는 증강을 주지 않는다. 1챕터 보스와 봉인 보상에 30종을 연결했고, 도면 내구도에 의존하는 9종은 내구도 구현 전까지 제안하지 않는다. 플레이 밸런스 확인은 아직이다.

## 별도 처치 재화와 회복

장비 아이템 선택 보상과 별개로 기존 골드·마법안료 규칙은 유지한다. 1스테이지 골드 시험값은 일반 6~10G·엘리트 200~280G·보스 600~720G이며, 2스테이지 일반은 13~16G·엘리트는 450~550G다. 양끝을 포함해 균등 정수 추첨한다. 골드는 처치 즉시 자동 지급한다. 처음 깨는 챕터에서 런이 끝나 마을로 돌아가는 보스는 골드를 지급하지 않으며 마법안료는 지급한다. 재화 연출은 기존 구현을 따른다.

방 섬멸 회복과 잉크 충전소는 [런 구조](run-structure.md)를 따른다. 새 도면·잉크 보상과 별도 누적 런 버프를 같은 시스템으로 해석하지 않는다.

## 현재 구현과 이행

현재 마을은 통합 공방 한 곳에서 기존 보급·팔레트·회수 기능을 제공하며 항목별 해금 조건·가격·선행 조건을 유지한다. 이정표 F로 도면 선택 없이 맨손 출발하며, 런에서도 A로 [맨손 전용 2타 기본 공격](../equipment/weapons/rules.md#맨손-기본-공격)을 사용한다. 승인 초기 규격의 최종 밸런스는 플레이 테스트 대상이다. 개발용 1챕터 씬 직접 진입에는 기존 도면 선택이 남아 있다. 현재 코드와 수치 데이터에는 팔레트·스탬프·아이템 드롭 구현이 남아 있다. 이는 새 기획의 구현 완료가 아니다. 새 획득·보관·활성화·내구도·보상 UI와 저장 경계는 별도 구현해야 한다. 개발 상세와 기존 수치 생성은 [인벤토리·보상 구현](../../development/gameplay/equipment/inventory-and-loot.md), [데이터 파이프라인](../../development/data/data-pipeline.md)을 따른다.
