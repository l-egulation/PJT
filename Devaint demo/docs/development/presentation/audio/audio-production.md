# 확정 효과음과 Unity 에셋 전달

[분야 개요](README.md)

## 게임 효과음의 연속 재생

플레이어 무기의 기본공격·스킬·폭발·적중 효과음과 점프·2단 점프·대시·벽차기 효과음을 `AudioCueFactory.PublishContinuous`로 재생한다. 공격·실제 적중 사건에서 재생을 시작하며 정상 전진 중 `timeSamples`를 반복 지정하지 않는다. FixedUpdate 사이의 같은 시각이나 짧은 히트스톱은 이미 시작한 DSP를 되감거나 재시작하지 않는다. 명시 일시정지·차징 대기는 별도 hold 신호로 제어하고, 재개는 같은 위치에서 이어간다. 게임 전체 시간 배율은 pitch에 반영하지만 기본 공격 공속 버프는 음원의 재생 속도·피치를 변경하지 않는다. 이미 끝난 단발을 다음 poll에서 다시 시작하지 않으며 취소·사망·리셋·소유자 수명은 기존 CuePlayer가 관리한다.

점프·2단 점프·대시·벽차기는 2026-11-16부터 연속 재생으로 바꿨다. 샘플링 재생은 매 갱신마다 재생 위치를 0.02초 단위 시뮬레이션 시각으로 다시 맞춰서, 짧은 단발음이 끊기거나 지직거렸다. 이 네 소리는 고정 음량 80%를 유지하며 무기·스킬 음량 설정을 받지 않는다(`ApprovedCombatAudio.ContinuousTraversal`). 발걸음·회복·플레이어 피격과 몬스터 자체 효과음은 기존 `Publish`의 샘플링 재생과 고정 음량 80%를 유지한다. 단 회복음(`sfx_player_heal`)은 2026-11-16부터 40%다(`ApprovedCombatAudio.FixedVolume`). 너무 크다는 사용자 피드백 때문이다. 아이템 획득음도 같은 이유로 `ForestCombatV2/Resources/PresentationSfx.asset`의 음량을 0.8에서 0.4로 낮췄다. 대상은 제단·증강 획득(`altar-acquire`), 재화 줍기(`gold-pickup`), 안료 줍기(`pigment-pickup`)다. 무기·스킬 음량 설정과 연속 재생 수정은 이 소리들에 적용하지 않는다.

저작 도구의 정확한 위치 스크럽과 수동 시뮬레이션은 기존 `Publish`의 샘플링 방식을 유지한다. 두 경로를 혼동하지 않는다. 확정 WAV·GUID·무기별 피격음 선택과 전투 판정 시간은 이 출력 수정으로 변경하지 않는다.

## 공통 잉크 피격음 검토

`resources/audio/ink-hit-audition/preview/index.html`에서 구매팩 액체·젖은 충돌 기반 피격 후보 10개를 비교한다. 11종 무기의 기본공격 개별 타격·전체 콤보 및 확정 스킬 41개 변주를 포함한 75개 청취 항목을 제공한다. 공격음은 로컬 Unity에 연결된 파일을 기준으로 하고, 기존 무기별 피격음 대신 후보를 겹친다. 비공격 스킬에는 자동 피격음을 넣지 않는다. 실제 모션 프레임을 표시하되 충돌·폭발·복귀는 조절 가능한 청취 시나리오이며 게임 충돌 판정은 아니다.

후보 단독·혼합·A/B·순차 재생, 독립 음량·피격 시점 조절, 별표 및 `ink-hit-audition-selection.json` 저장/불러오기를 제공한다. 여러 마리 비교는 1~10마리, 0~150 ms 간격과 동시/쓸기 프리셋을 제공한다. 피격음만 복제하며 게임의 60 ms 중복음 억제도 선택해서 비교한다. 현재 피격음은 `WeaponHitSounds` 분기와 `SelectedAudioClips`의 GUID 연결에서 가져와 현재음/후보 A/B 및 단독 비교를 제공한다. 별도 피격음이 없는 폭발 계열은 그 상태를 유지한다. 사용자는 기존 게임 피격음을 유지하기로 확정했다. 신규 후보 10개는 적용하지 않고 비교 자료로 보존한다. 확정 선택은 리소스의 `source/decision.json`에 기록한다. 제작 원본과 가공 재현 방법은 해당 리소스의 `README.md`에 둔다.

이후 후보(`resources/audio/ink-hit-directions/`, `ink-hit-wet-revision/`)는 반려됐다. 사용자는 `resources/audio/ink-hit-three-directions/`의 2번 「접촉점 + 잉크 두께」(퍽+척)를 모든 무기의 기본공격·스킬 공통 피격음으로 골랐다(2026-11-16). 게임용 사본 `sfx_hit_common_01_v01.wav`는 2번 후보에 1/0.8을 곱한 판이다. 그래서 기본 음량 0.8에서 비교 화면과 같은 크기가 된다. 원음·가공·의도·한계는 해당 리소스의 `README.md`와 `source/recipes.json`에 둔다.

## 현재 별표 스킬 적용

`data/audio/skill-selections.json`이 구매팩 별표 스킬 40개와 41개 변주의 현재 로컬 적용 계약이다. `resources/audio/gamemaster-skills-selected/`의 WAV 59개를 `unity/Assets/Deviant/Audio/Resources/SelectedSkillAudio/`로 바이트 그대로 배치하고 메인 소유 `Catalog.json`으로 연결한다. 별표의 원래 승인 리비전을 보존하며, 대검 모아내려찍기 6·7번은 호출마다 번갈아 사용한다. 샷건은 별표가 확정한 3차 원음을 사용한다. 연막은 최종 `smoke-release-14/smoke14-07-smoother.wav` 바이트 그대로다.

폭발음(2026-11-16): 세 자리 모두 사용자가 준 참고 영상의 폭발을 5 ms·1/6 옥타브 단위로 측정하고, 그 모양대로 새 잡음을 깎아 만든 소리로 바꿨다. 큰 폭발(`explosion_large`와 폭탄 원거리·후속·이동 스킬의 `__explosion`)은 `explosion_large_resynth_01`을 쓴다. 유탄(`explosion_grenade`, `launcher_followup_special__explosion`)은 같은 소리를 3연쇄로 만든 `explosion_grenade_resynth_01`을 쓴다. 출처는 둘 다 `resources/audio/explosion-reference-resynth/` 1번이다. 기본 폭발(`explosion_bomb`, `bomb_basic_special__explosion`, `shuriken_range_special__explosion`)은 `resources/audio/explosion-small-bomb/` 4번 「더 작은 폭탄」(`explosion_bomb_small_01`)을 쓴다. 이 소리는 꼬리 ×0.45, +1/2 옥타브, -3.5 dB다. 세 소리 모두 -30 dB 아래로는 처음 줄어들던 기울기 그대로 -70 dB 이하까지 줄어든다. 측정 꼬리에 남은 -40 dB 평탄부와 그 뒤의 급한 끝은 없다. 발사기 모아쏘기 충격음(`launcher_charge_impact`)은 기존 승인 폭발을 유지한다. 폭탄 기본공격의 폭발은 전용 스킬 폭발음이 없다. 그래서 반경 규칙(2.8 이상이면 큰 폭발)에 따라 반경 3인 기본공격이 큰 폭발로 재생되고 있었다. 지금은 `CombatArena.IsBombBasicAttack`으로 폭탄 기본공격을 알아보고, 폭탄 3연투의 한 발과 같은 `explosion_bomb`을 재생한다. 공격을 알 수 없는 폭발은 반경 규칙을 그대로 따른다.

끊김 수정판(2026-11-16): 망치 기본 스킬·원거리·연계, 대검 모아내려찍기 6·7번과 이동, 발사기 후속 특수기, 레이피어 스킬 4종과 순간이동 2종, 수리검 순간이동·복귀는 `resources/audio/skill-natural-tails/`의 `*_tail_NN.wav`를 쓴다. `Catalog.json`이 이 파일들을 가리킨다. 위 선택 파일과 원래 렌더는 그대로 보존하며 바뀌지 않는다. 예전 렌더의 조각이 0.18~0.36초 뒤 짧은 페이드로 끝나 울림이 끊겼기 때문이다. 같은 원음·시작점·필터·배율로 원음 감쇠를 이어 붙였고, 그 앞부분은 예전과 같다. 레이피어 바람 소리는 구매 원음 자체가 끝나 있어 원음 끝 80 ms 페이드만 부드럽게 했다. 망치 기본공격 2타는 `sfx_weapon_hammer_basic_1_01_v03.wav`를 `SelectedAudioClips`가 가리킨다. 기존 2타의 휘두름 층은 그대로 두고, 「쿵」 충격 층을 횡강타(`hammer_default`) 소리로 바꿨다. 횡강타 소리는 기존 충격 피크 시각(0.549초)에 맞추고, 재생 배율 보정(1.1525)은 기존과 같다. 전체 크기는 1타와 같은 체감 크기로 맞췄다. 이전에 음량만 낮춘 v02는 보존하지만 쓰지 않는다.

- 대형·이동·설치 폭발은 대형 8번, 기본공격·3연속·폭발 수리검은 B3를 사용한다. 대형·설치 투척 gain은 1.9다. 투척과 미래 폭발을 한 타이머로 예약하지 않는다.
- 연막 생성, 받아치기 성공, 미끼 설치 성공, 실제 순간이동과 복귀에서 해당 소리를 재생한다. 연막 발동 전 취소나 미끼 설치 실패에는 소리가 나지 않는다. 수리검 적중과 이동은 별도 사건이며 복귀는 실제 복귀 위치를 확보했을 때만 재생한다.
- 미사일 변신·비행은 무음이며 폭발만 재생한다. 유탄은 선택한 연속 폭발 클립에 기존 파편 잡음을 중복해서 얹지 않는다.
- 기존 기본공격 및 발사기 기본공격은 유지한다. 무기별 음량은 `WeaponAudioSettings`와 기존 Ctrl+` 메뉴를 따른다. 전투 규칙·피해·이동·쿨다운은 변경하지 않는다.

Unity 6000.6.5f1에서 전체 클립 임포트·로딩 및 실제 연막 발동/취소·미끼 설치 성공/실패·변주 교대 검사 2개를 통과했다. 고정 배치 실행기로 59개 파일을 검증했다. 폐기된 구형 씬 자료가 없는 Game/Lab 회귀 검사 2개는 건너뛰었으며 수동 장치 청감 검증을 수행한 것은 아니다.

이는 Deviant-main 작업본의 로컬 적용이며 Git 커밋·push 또는 원격 main 갱신이 아니다. 기존 청취 HTML의 11번은 적용 전 게임음 비교 기록임을 표시한다. 아래의 이전 제작 도구 설명보다 이 적용 계약과 최종 사용자 지정이 우선한다.


청취 선택한 효과음 **119종**의 WAV 원본은 `resources/audio/approved-combat/runtime/SFX/<category>`에서 Git LFS로 관리하고, [고정 리소스 배치](../../../assets/README.md)로 `unity/Assets/Deviant/Audio/SFX/<category>`에 복원한다. `.meta`·GUID·가져오기 설정은 계속 메인이 추적한다. 원본과 바이트가 같은 48kHz·모노·PCM16 파일이며 총 약 7.4MiB다. 플레이어 12, 무기/전투 55, 몬스터 18, UI 10, 아이템 11, 스토리 7, 환경 6종이다. 음악·대사 TTS는 포함하지 않는다.

이 119종 목록은 **기준 음원 파일과 임포트 설정의 전달**이다. 실제 게임 연결은 아래 런타임 목록을 따른다. 목록에만 있는 나머지 음원이 자동 재생되는 것은 아니다.

검 제작 기준은 **Minifantasy 검 3**이며 [basic-sword-selection.json](../../../../data/audio/basic-sword-selection.json)을 따른다. 제작 작업 공간의 확정 07 단발이 편집 소스다. 현재 게임용 6종 무기 음원은 사용자가 확정한 편집 설정에서 새로 내보낸다. 기준 119종의 이전 기본공격 파일과 런타임 선택을 혼동하지 않는다.

## 실제 전투 재생

- 현재 편집 원본은 [approved-weapon-project.json](../../../../data/audio/approved-weapon-project.json)이다. 검·채찍·레이피어·한손 단검·대검·수리검의 46개 연계/개별/특수 설정을 보존한다. 기본공격은 승인한 전체 연계 믹스를 실제 타별 시작 경계에서 분리하고, 특수는 해당 설정을 사용해 총 40개 실행 음원을 만든다. 개별 타 미리보기 값도 보존하되 기본공격 런타임의 권한은 전체 연계 믹스다.
- 기본공격의 시간표나 특수 종료 시간이 승인 당시 참조와 달라지면 내보내기를 중단한다. 바뀐 공격을 작업실에서 확인·확정한 뒤 참조 설정과 함께 다시 내보낸다.
- `node tools/audio/export_runtime_sfx.cjs`는 HTML과 같은 DSP로 48kHz 스테레오 PCM16을 내보낸다. 출력은 `unity/Assets/Deviant/Audio/Resources/ApprovedCombatAudio`의 WAV와 `Catalog.json`이다. 확정 소스의 SHA256을 확인하며 피치·속도·음량·반복·좌우 이동을 굽는다. 사용자가 올린 음량은 보존하고 믹스 과출력 방지는 편집기와 같은 0.94 피크 감쇠를 사용한다. 이 출력의 스테레오/음량 규격은 기준 119종 모노 납품 규격과 구분한다.
- 생성 전에 `python3 tools/assets/update_assets.py`로 편집 입력 `Source/basic_sword_selected_07_v01.wav`와 기준 이벤트 WAV를 준비한다. 원본·런타임·편집 입력 WAV 170개는 resources에 등록하고 Unity 경로는 로컬 사본으로 사용한다. 재생성으로 바뀐 WAV는 resources의 원본·색인·해시·LFS를 먼저 갱신하고 외부 커밋·push·복원 후 메인의 배치 계약을 맞춘다. `Catalog.json`과 승인 편집 설정은 메인 소유다.
- 공통 Game/Lab `CombatArena`가 명시 카탈로그를 읽는다. `ApprovedCombatAudio`는 기존 `CuePlayer`·`AudioCueFactory`를 사용하며 실제 공격 시작에서 현재 타 음원만 시작한다. 기본 공격 공속은 음원의 재생 배율에 반영하지 않고 차지는 실제 해제 시점을 따른다. 휘두름은 실제 공격 시작, 별도 적중음은 실제 적중 사건에 연결한다. 입력 대기·미입력 후속타를 음원이 예약하지 않는다. 취소·사망·리셋·비활성화는 정리하고, 이미 활성화한 잔상·매듭 조임·낙인 대검·회전 수리검의 독립 음원 꼬리는 해당 효과처럼 유지한다. 전투 시간 정지 때는 같은 시계의 오디오도 멈춘다.
- 기존 폭발 4종은 실제 폭발 사건에서 재생한다. 일반 폭탄/수리검 폭발·대형 폭탄·유탄 본체·파편을 구분하고, 시각 이펙트 대체 경로가 폭발음을 중복 재생하지 않는다. 투척 순간에 미래 폭발음을 예약하지 않는다.
- 일반 렌더 프레임 사이에 FixedUpdate 시각이 같다는 이유로 DSP를 일시정지하지 않는다. 명시 일시정지·수동 시뮬레이션 정지는 같은 오디오 시계로 처리한다. 채찍 첫 타격이 빗나갔거나 표식 대상이 사망하면 미래 조임 음원 꼬리를 재생하지 않는다.
- 몬스터는 소리를 내지 않는다(2026-11-13 사용자 결정). 멧돼지·물양동이를 포함한 모든 몬스터의 공격/피격/죽음 소리를 연결하지 않으며, 맞는 소리는 아래 [무기·스킬별 공격 소리와 맞는 소리](#무기스킬별-공격-소리와-맞는-소리)가 정한다. 카탈로그의 `boar_*`·`bucket_*` 항목은 남아 있지만 호출하지 않는다.
- 카탈로그는 이 40개 공격과 10개 폭발/몬스터 음원, 총 50개 재생 항목이다. 몬스터 음원 6개는 호출하지 않는다. 나머지 이동·UI·스토리, 장치별 최종 믹싱은 별도 범위다. 기존 배포 119종의 원본을 바꾸지 않고 사건용 사본을 해시 검사 후 만든다.

`ApprovedCombatAudioIntegrationTests`는 공통 게임/시험장의 무기 11종 평타 공격 소리, 취소·정지·리셋·중복 방지, 폭발 종류, 공통 숲 멧돼지가 소리를 내지 않는 것, 검·망치로 맞힌 피격의 무기별 맞는 소리, 실제 승인 Sprite/오디오 연결을 검사한다. `ApprovedMonsterAudioTests`는 종별 표현의 멧돼지·물양동이가 공격·피격·죽음에 소리를 내지 않는 것을, `WeaponHitSoundsTests`는 공격 ID·피해 종류별 맞는 소리 선택과 클립 등록을 검사한다. 자동 오디오 상태·화면 검사는 실제 장치 청취 품질 평가를 대신하지 않는다.

## 무기 사운드 작업실

[HTML 빌더와 사용법](../../../../tools/audio/weapon_sfx_studio/README.md)은 확정 단발을 잘라 무기별 승인 본체 모션과 비교하는 오프라인 제작 도구다. 피치·속도·음량, 타격별 배치, 반복·회전음, JSON/작업 HTML 저장과 WAV 내보내기를 지원한다. 내보낸 파일은 검토 후보이며 Unity 카탈로그·전투 규칙·승인 목록을 자동 변경하지 않는다.

## 사용할 파일과 제작 정보

YAML의 `delivery.root: AudioWork`는 제작 도구를 실행하는 위치의 작업 폴더 예시다. Unity 에셋 경로는 JSON의 저장소 상대 경로가 기준이다. 생성 원본·이전 후보·모델 가중치·기기별 절대 경로·개인 인증 정보는 이 전달본에 넣지 않는다. 모델 원본과 후보는 제작 작업 공간에서 따로 보존한다. `version_id`는 원본 제작 기록과 대조하는 식별자이고, Git의 파일 SHA256은 납품 파일 무결성 기준이다.

## 이름·음량·임포트

파일명은 `<event_id>_<variant:02d>_v<revision:02d>.wav`이다. ID는 유지하고 변주는 함께 사용할 다른 연기, revision은 같은 변주의 교체본에 사용한다. 이미 사용 중인 파일과 `.meta`를 덮어쓸 때는 GUID를 유지하고 참조 영향을 확인한다. Unity 폴더를 제작 작업 공간의 단계 폴더로 다시 나누지 않는다.

후처리 피크 상한은 **-16dBFS**다. 일반 소리의 발음 구간 RMS 목표는 -28dBFS, 미사일 비행 루프는 -30dBFS, 환경 공기 레이어는 -36dBFS이며 낮은 제한을 따른다. 브라우저 미리듣기 초기 볼륨 80%는 WAV에 구워진 음량이 아니다. 원본은 최소 2초로 생성하고 포화 샘플 비율이 0.1%를 넘거나 무음·비정상 수치가 있으면 후보 등록을 거부한다.

Unity 임포트는 원본 샘플레이트 유지, PCM, Decompress On Load, Preload Audio Data를 사용한다. 이미 모노인 원본에 Force To Mono를 추가 적용하지 않는다. 이 설정은 Editor 제작용 원본에 적용한다. 제품 빌드는 [미디어 압축](../../delivery/media-compression.md)에 따라 Opus 128kbps를 포함하고 런타임 디코더로 재생한다. 장면별 로딩·믹서·3D 감쇠·루프 소유권은 제품 바인딩 단계에서 결정한다. WAV 원본·해시는 resources에, Unity `.meta`는 메인에 각각 커밋한다.

## 공격과 발 접촉 시간

기본공격은 무기별 최단 한 사이클의 WAV 하나와 `production.regions`의 타별 영역을 사용한다. `production.events`는 초, `event_samples`는 48kHz 파일 내 샘플 위치다. 실제 입력이 늦거나 공격이 취소되면 전체 사이클을 예약하지 않고 실제 타의 모션 시계에서 해당 영역만 사용한다. 공격속도별 WAV나 각 타의 중복 파일은 만들지 않는다. 채찍 기본공격은 외부 소싱 TODO이며 현재 WAV 목록에서 제외한다.

| 기본공격 | 길이 ms | 파일 내 제작 피크 ms |
|---|---:|---|
| 검 | 1000 | 200, 600 |
| 레이피어 | 800 | 100, 320, 560 |
| 한손 단검 | 1000 | 45, 210, 430, 845 |
| 망치 | 1090 | 210, 660 |
| 방패 | 600 | 250 |
| 대검 | 1230 | 210, 460, 930 |
| 발사기 볼 탄환 | 400 | 120 |
| 폭탄 투척 | 900 | 200 |
| 수리검 | 600 | 100, 370 |
| 발사기 레이저 | 600 | 150 |
| 발사기 샷건 | 800 | 150, 동시 한 발사음 |
| 발사기 유탄 | 1000 | 200 |

표는 제작 시 피크 배치 참조이며 실제 적중 순간을 고정하는 규칙이 아니다. 타격·발사 수치의 기준은 전투 데이터와 [기본공격 시간표](basic-attack-audio-timing.md)다. 효과음 때문에 공격속도나 전투 규칙을 바꾸지 않는다.

섬광 연침은 150/270/390/510/630ms의 5회 찌르기에 단발 원본을 재사용한다. 삼연 도약은 3충전이며 새 입력당 80ms에 한 번 공격하므로 자동 3연타 WAV로 만들지 않는다. 먹안개는 150ms에 생성될 때의 짧은 방출음이며 연막 유지 3초를 파일에 굽지 않는다. 유탄 본체·파편·대형 폭탄·시한폭탄의 폭발은 실제 접촉·수명·신관 사건을 따르고 투척음에 미래 폭발을 예약하지 않는다.

풀·흙·돌·나무 발걸음은 120ms 한 발 원본 하나를 각 접촉에 재사용한다. 승인 달리기의 6프레임 `[65,55,65,55,65,55]ms` 중 3/6번 프레임 시작인 **120/305ms**, 매 **360ms**를 제작용 접촉 A/B로 사용한다. 간격은 185/175ms이며 좌우 별도 WAV를 만들지 않는다. JSON의 `foot_peak_offset_samples`만큼 재생 시작을 앞당겨 피크를 접촉에 맞춘다. 이 제작 마커가 현재 게임에 연결됐다는 뜻은 아니다.

향후 발걸음 바인딩은 캐릭터 표현 시계를 공유하고 grounded/run에서만 재생한다. 정지·공중·대시·공격·사망·리셋과 일시정지 시 예약을 정리하고 같은 접촉을 중복 방출하지 않는다. 몬스터 이동 접촉 6종은 제작 대상에서 제외했으며 플레이어 주기를 복사하지 않는다.

저장소 루트에서 표준 Python으로 실행한다. 모델이나 생성 도구 의존성은 필요하지 않다.

```powershell
python tools/audio/check_approved_sfx.py
python tools/check_docs.py
```

첫 검사는 승인 목록과 실제 파일 집합, SHA256, PCM 규격·길이·피크, 공격 피크 위치, 발 접촉 보정값, 제외 ID, Unity GUID와 importer를 검사한다. Unity Editor 검증은 프로젝트 지정 버전 **6000.6.5f1**과 같은 패키지 구성으로 WAV가 AudioClip으로 읽히는지 별도로 확인한다. 파일·임포트 검사는 실제 게임 플레이·수동 청취·믹싱 검증을 대신하지 않는다.

## 선택 음원과 재생 지점

Gamemaster Pro Sound Collection에서 선택한 SFX 46개와 BGM 4곡은 `resources/audio/deviant-selected/`의 색인과 고정 배치 계약으로 복원한다. 선택 WAV와 기존 승인 세트의 변주·리비전을 구분한다. `SelectedAudioClips.asset`이 재생 ID를 Unity AudioClip에 연결한다. 오프닝 지워짐·쓰러짐·각성, 마을 해금·안료·잉크 파괴는 기존 `PresentationSfx` 이벤트에서 새 클립을 재생한다. 선택 SFX는 원본 좌우 평균 모노·48kHz PCM16·-16dBFS 피크로, BGM은 원본 WAV 바이트 그대로 등록한다.

- 달리기 발 접촉은 이동 모션의 두 접촉에서 흙·풀·돌·목재를 고른다. 첫 점프(`sfx_player_jump`, 착지 순간 실행되는 선입력 점프 포함)·공중 두 번째 점프·벽차기·대시·피격은 각 동작이 수락됐을 때 재생한다.
- 체력 회복은 `sfx_player_heal`(`Magic_Spells/vanish_spell_flash_potion_03`, 1.88초)을 플레이어 체력이 실제로 오른 순간 재생한다. 회복 펌프, 방 정리 회복(1·2챕터), 증강의 즉시 회복·최대 체력 증가·처치 흡혈, 열쇠 상자 체력 보상, 봉인 도전 성공, 잉크 회복·적중 흡혈·씨앗 줍기가 모두 `CombatPlayer.Heal`을 거친다. 체력이 가득 차 오르지 않았거나 사망 상태면 재생하지 않는다. 적중 흡혈처럼 연달아 들어오는 회복은 전투 시간 0.5초(`HealSoundInterval`) 안에서 소리 하나를 공유한다.
- 대시는 `foley_cloth_light_fast_movement`의 11번, 첫 점프와 두 번째 점프는 같은 13번 소리를 쓴다. 두 점프는 재생 ID만 따로 두고 같은 클립을 가리킨다. 원본을 그대로 두지 않고 `resources/tools/mix_selected_sfx.py`가 `asset.json`의 `recipe`대로 시작 지점을 자르고, 180Hz 아래를 거르고, 피크 -16dBFS로 맞춰 만든다. 같은 팩의 `whoosh_swish_*` 계열은 저음이 대부분이고 들리는 구간이 20~70ms라 짧은 '드득'으로 들려 이동음에 쓰지 않는다.
- 대검 기본 3타도 아래 무기·스킬별 공격 소리(`sfx_weapon_greatsword_basic_0~2`)로 바뀌었다. `ApprovedCombatAudio`는 `sfx_weapon_<공격 ID>` 선택음이 있으면 승인 렌더 대신 그 클립을 재생하고, 타격 시점·재생 배율·취소는 승인 카탈로그 값을 그대로 쓴다.
- 미사일은 실제 변신과 비행 루프에 연결한다. 비행 루프는 명시 일시정지 때 멈추며 취소·폭발·사망·리셋에서 정리한다. 기본 둔기·방패의 판정음과 볼 탄환·폭탄의 발사음은 쓰지 않고 공격 소리(`sfx_weapon_<공격 ID>`)가 대신한다.
- UI는 확인·취소·실패·대화 넘김·가방 열기·재개·작업대 열기와 기록 농가 수첩 열기를 구분한다. 장착과 스탬프는 거래 성공을 기준으로 한다.

## 무기·스킬별 공격 소리와 맞는 소리

### 구매팩 기본공격 선택과 로컬 적용

현재 구매팩 선택의 기준은 `data/audio/basic-attack-selections.json`이다. 기본공격에만 적용하며 기존 스킬·명중·폭발음 선택과 구분한다. 검 5번, 채찍 9번, 레이피어 10번, 단검 9번, 방패 1번, 대검 4번, 폭탄 1번, 맨손 10번을 사용한다. 수리검은 폭탄 후보 2번 원음이다. 발사기는 현재 실행 음원으로 확정했다. 망치는 후보 5번으로 확정했으며 2타 휘두름 0ms·충격음 +210ms를 반영했다. 선택 파일의 현재 후보와 유일한 즐겨찾기가 모두 5번이며 개별 조절값을 보존한다.

구매 원음과 편집 결과는 `resources/audio/gamemaster-selected/`, 제작기는 `resources/tools/render_basic_attack_audio.py`가 소유한다. 구매팩으로 바꾼 10종의 기본공격 22타를 각 판정/발사 시각에 맞추고, 현재 게임 기본 공속에서 선택 원음의 피치를 유지하도록 기존 실행 배율을 보상해 렌더한다. 선택 WAV의 GUID와 SelectedAudioClips 연결은 유지하며 고정 배치 매니페스트의 소스·해시를 갱신한다. 이 로컬 적용은 리소스 커밋·push·메인 gitlink 갱신을 대신하지 않는다.

`resources/audio/gamemaster-audition/preview/revision-02.html`은 망치 비교·개별 위치 편집용이다. 기존 9번 계열을 6~12dB 키운 10개 시안이며 2타의 첫 바닥 접촉 프레임 `CharacterBasicOutline/hammer-a/15`보다 40ms 앞에 휘두름과 충격음의 에너지 피크를 함께 배치한다. 휘두름의 꼬리를 유지해 두 소리가 겹치며 브라우저 출력 지연을 모션 시계에 반영한다. 재검토 시안은 설계 음량을 유지하며 승인 전에는 게임 음원을 교체하지 않는다.

망치 2타는 휘두름·충격음을 별도 원음으로 비교하며 각각 ±400ms(5ms 단위)로 이동할 수 있다. 1배속 기준 개별 오프셋은 후보별로 보관하며 선택 JSON schemaVersion 3의 `layerOffsetsMs`와 원음 해시로 전달한다. 개별 듣기는 비교용으로만 쓰며 게임 적용은 확정 후보와 두 위치 값을 함께 반영한다.

개발 메뉴 `[Ctrl + Backquote]` → **무기별 음량**에서 11종의 공격·명중음과 개별 설정하지 않은 스킬을 0~100%, 5% 단위로 조절한다. 기본값은 팀 기본 믹스 [`AudioMixDefaults.json`](../../../../unity/Assets/Deviant/Audio/Resources/AudioMixDefaults.json)을 따른다. 이 파일에 없는 무기는 기존 AudioSource 음량과 같은 80%다. 2026-11-16 사용자가 편집기에서 맞춘 값을 기본값으로 정했다. 무기는 망치 80%, 방패 90%, 발사기 80%, 폭탄 20%다. 스킬은 한손 단검 원거리 15%, 방패 연계 25%, 대검 원거리 20%, 발사기 원거리 특수 5%, 이동 특수 60%, 후속 특수 45%다. 값은 `deviant.audio.weapon.<form>` PlayerPrefs로 기기에 저장되어 기본값보다 우선한다. 무기 초기화는 저장값을 지워 팀 기본값으로 되돌린다(`WeaponAudioSettings.DefaultFor`).

같은 메뉴의 **스킬별 음량**에서 무기를 선택해 확정 스킬 40종을 각각 조절한다. `SkillAudioSettings`는 설정하지 않은 스킬에 팀 기본 믹스의 스킬 값을 적용한다. 그 값이 없으면 무기 음량을 상속한다. 또한 수정한 스킬은 `deviant.audio.skill.<actionId>`에 독립적인 절대 음량으로 자동 저장한다. 별도 설정한 스킬은 무기 음량 변경에 영향을 받지 않는다. 한 스킬의 시전·실제 폭발·설치·이동·적중음은 같은 설정을 사용하며, 같은 WAV를 공유해도 다른 스킬이나 기본공격의 음량은 바뀌지 않는다. 받아치기·연막처럼 사건에서만 소리가 나는 스킬도 해당 스킬 설정을 따른다. 개별/전체 스킬 복원은 개별 설정을 지워 팀 기본값(없으면 무기 음량)으로 되돌리고 기존 무기 설정은 보존한다. 변경은 다음 소리 재생부터 반영되며 이미 재생 중인 소리를 다시 시작하지 않는다.

전체 음량·BGM·잉크 파츠의 별도 피격음과 스킬 출처가 없는 공용 효과음은 별도다. HTML의 현재 적용음은 파일과 기본 실행 배율의 비교이며 기기에 저장한 개발 메뉴 음량까지 읽지는 않는다.

아래 갈래별 제작 설명은 유지된 스킬·명중음과 이전 기본공격 원본의 기준이다. 위에서 별도로 선택한 기본공격에는 구매팩 선택 기준이 우선한다.

몬스터가 아니라 **무기와 스킬이 소리를 정한다**(2026-11-13 사용자 결정). 공격 소리와 맞는 소리는 두 겹으로 나눈다. 공격 소리는 맞든 빗나가든 공격이 시작될 때 나고, 맞는 소리는 플레이어 공격이 적에게 수락된 순간에 난다. 소리는 맞고 공격한다는 것만 분명히 알리고 무기마다 세세하게 나누지 않는다. 무기를 **검·방패·총** 세 갈래로 묶어 갈래마다 공격 소리 하나·맞는 소리 하나를 쓰고, 무기는 음높이(재생 배율)만 다르다. 원본은 `resources/audio/weapon-sounds/`(Sonniss GDC 2026 Game Audio Bundle, deviant-selected 일부)이고 라이선스와 만드는 법은 그 `asset.json`에 있다.

| 갈래 | 무기(음높이 배율) | 공격 소리 원판 | 맞는 소리 원판 |
|---|---|---|---|
| 검 | 검 1.0, 대검 0.78, 레이피어 1.18, 한손 단검 1.28, 채찍 1.1, 수리검 1.35 | 쇳소리 없는 바람 「휙」 | 칼 베기 「챙」 + 「퍽」 |
| 방패 | 방패 1.0, 망치 0.8, 맨손 1.2 | 무기 휘두름 | 젖은 「퍽」 |
| 총 | 발사기 1.0, 폭탄 0.85 (레이저 맞는 소리 1.35) | 예전 승인 발사기 렌더 | 탄 「퍽」 |

소리가 과하다는 판단에 따라 검 갈래 공격 소리는 금속 긁힘이 없는 바람 소리로 바꾸고, 방패·총 갈래는 공격·맞는 소리 모두 더 작고 어둡게 다듬었다. 이 「부드럽게」 다듬기는 100Hz 아래·5kHz 위를 덜고 6ms 페이드인을 넣은 뒤 가장 큰 50ms RMS를 공격 소리 -35dBFS·맞는 소리 -30dBFS로 맞추고 부드러운 상한(-24·-20dBFS)으로 누른다. 검 갈래 맞는 소리만 아래 기본 방식으로 다듬은 판을 쓴다. 90Hz 아래와 7kHz 위(약 -4dB)를 덜고, 발음에 3ms 페이드인을 넣고, 가장 큰 50ms 구간 RMS를 맞는 소리 -28dBFS·공격 소리 -31dBFS로 맞춘 뒤 부드러운 상한(맞는 소리 -17dBFS, 공격 소리 -20dBFS)으로 피크를 누른다. 한 번 휘둘러 여러 적을 맞혀도 같은 맞는 소리는 0.06초(`HitSoundSpacing`) 안에 한 번만 난다.

- 공격 소리 `sfx_weapon_<공격 ID>`: 평타 23타와 스킬 40개, 무기 11종 전부. 공격 시작부터 재생하면 가장 큰 지점이 그 공격의 타격 시각에 오도록 정렬했다. 승인 카탈로그에 있는 공격은 그 `nominalImpact`·`nominalDuration`을 쓰고, 망치·방패·발사기·폭탄·맨손처럼 카탈로그에 없던 공격은 [`WeaponSounds/Timing.json`](../../../../unity/Assets/Deviant/Audio/Resources/WeaponSounds/Timing.json)의 시각·길이를 쓴다. 평타는 공격속도에 맞춰 재생 배율을 바꾸고 충전 공격은 실제 해제 시각에 맞춘다.
- 맞는 소리 `sfx_hit_<무기>`: [`WeaponHitSounds`](../../../../unity/Assets/Deviant/Combat/Runtime/Unity/WeaponHitSounds.cs)가 수락된 피격의 공격 ID(없으면 무기 형태)로 고른다. 큐 ID는 무기별로 남아 있지만 `SelectedAudioClips`에서 레이저를 포함한 11개 `sfx_hit_*`가 모두 같은 공통 클립 `sfx_hit_common_01_v01.wav`를 가리킨다. 무기별 ID는 무기·스킬 음량 설정과 0.06초 중복 억제를 유지하기 위해 둔다. 이전 무기별 WAV와 표의 「맞는 소리」 열은 더 이상 재생되지 않으며 파일은 보존한다. 레이저(`launcher_range_special`, 피해 종류 Laser)는 `sfx_hit_launcher_laser`, 받아치기(Parry)는 방패, 잉크 파츠는 `sfx_combat_hit_ink`를 쓴다. 폭탄·유탄·파편·미사일·폭발 수리검처럼 폭발로 맞는 공격은 폭발음이 대신해 맞는 소리를 내지 않는다. 공격 ID도 무기도 알 수 없는 피격은 소리를 내지 않는다.
- `ApprovedCombatAudio`가 전투장의 수락된 피격 기록을 읽어 맞는 소리를 낸다. 몬스터 종류, 1챕터 표현 부품(`Chapter1HitFeedback`)과 무관하게 1·2챕터·보스 모두 같은 규칙이다.
- 압축 배포용 Opus 목록(`CompressionSelection.json`, `CompressedAudio/Catalog.json`)에는 아직 새 74개가 없다. 빌드에서는 원본 WAV를 그대로 싣는다.

## 배경 음악

타이틀, 시작 마을·튜토리얼 도주 전, 도주, 1·2챕터 사냥터, 2챕터 보스, 정비소는 최종 제출 음원을 쓴다. 1챕터 보스는 기존 음원을 사용한다. 새 음악은 전주를 한 번 재생하고, 박과 음색이 맞는 본구간을 DSP 교차 페이드로 반복한다. 곡이 바뀔 때는 기존 곡과 새 곡을 각각 페이드한다. 도주 진입은 시작 타격을 살리기 위해 페이드를 짧게 적용한다. 재생 설정 원본은 `data/audio/background-music.json`이며 `python tools/audio/export_background_music.py`로 Unity JSON을 생성한다.

1·2챕터에서 플레이어가 죽으면 `player-death` 효과음을 한 번 재생하고 BGM을 0.12초 만에 줄여 끈다. 이 음원은 피크 -1dBFS 로 다른 선택 효과음(피크 -16dBFS)보다 약 15dB 커서 `PresentationSfx`의 음량을 0.15로 둔다. 결과 화면에서는 음악을 재개하지 않으며, 다른 장면으로 이동하면 해당 장면의 곡을 시작한다.

튜토리얼 우물 앞에서 두 앞선이 만나 주인공이 스케치로 굳는 것(`ErasureMet`)은 죽음으로 다루지 않는다. `player-death`를 재생하지 않고, 도주 음악(`opening_erase`)을 트랙의 `fadeOutSeconds` 3.8초(손끝부터 스케치가 번지는 시간)에 걸쳐 천천히 줄여 끈다. 조력자 장면은 음악 없이 진행하고, 각성이 끝나면 마을 곡을 시작한다.

`BackgroundMusicPlayer`가 2D AudioSource 풀(기본 2개, 페이드가 겹칠 때 최대 4개)을 DSP 시계로 관리한다. 큐가 바뀌면 이전 곡은 페이드아웃(기본 2초), 새 곡은 느리게 시작하는 smoothstep 곡선으로 페이드인(기본 3초)하며 트랙마다 `fadeOutSeconds`·`fadeInSeconds`로 바꿀 수 있다. 페이드 도중 다른 큐를 요청하면 남는 소리는 끊지 않고 현재 음량에서 페이드아웃한다. 방금 떠난 큐가 아직 들리면 처음부터 다시 틀지 않고 그 소리를 되살린다. 씬 로드 같은 메인 스레드 정지 뒤에는 한 프레임이 페이드를 `fadeStepLimitSeconds`(0.1초)만큼만 진행하고 나머지는 페이드 시간표를 뒤로 미룬다. 같은 파일·재생 구간을 쓰는 두 큐는 한 소리를 공유해 재생 위치를 유지한 채 음량만 이어서 바꾼다. 같은 `group`의 다른 파일로 바꾸면 새 파일을 이전 소리의 재생 위치에서 시작해 교차 페이드한다.

배경 음악은 항상 재생 속도 1로 재생한다. 웹 빌드의 Unity 오디오 채널은 마지막으로 받은 재생 속도를 다음에 시작하는 클립에 다시 적용하므로, 반복 경계나 큐 전환에서 새로 시작한 곡이 빨라진(음이 높아진) 채로 이어질 수 있다. `BackgroundMusicPlayer`는 웹 빌드에서 매 프레임 [`MusicPitchGuard.jslib`](../../../../unity/Assets/Deviant/Audio/Plugins/WebGL/MusicPitchGuard.jslib)로 30초 이상 클립을 재생하는 채널의 재생 속도를 1로 되돌리고, 처음 되돌린 순간 브라우저 콘솔에 경고를 한 번 남긴다. 브라우저 콘솔의 `deviantAudioDump()`는 채널별 저장 재생 속도·실제 재생 속도·클립 길이·샘플레이트를 표로 보여 준다. 에디터와 다른 플랫폼에서는 동작하지 않는다.

새 음원은 원본 바이트를 복원하고, Unity에서 로드 시 디코딩해 반복 시작 샘플을 찾는다. 반복 경계는 0.12초 등전력 교차 페이드다. 시작 마을과 도주 전의 두 튜토리얼 큐는 같은 파일·음량·재생 구간을 공유해 이어서 재생한다. 지워짐 컷신이 시작될 때(`StartErasureChase`, 비트 `erasure-begin`) 도주 음악으로 전환한다.

WebGL은 브라우저 오디오가 시작되기 전에는 타이틀곡을 예약하지 않는다. 브라우저가 사용자 입력을 기다리면 웹 화면에 ‘소리 켜기’ 버튼을 표시한다. 입력 후 Web Audio가 실행 상태가 되면 타이틀곡을 처음부터 예약한다. 타이틀을 떠나면 버튼을 제거한다.

## 구매팩 스킬 시안

`resources/audio/gamemaster-skill-audition/preview/index.html`은 40종 스킬과 발사기·폭탄 기본공격 재검토 2개 항목을 비교한다. 일반 항목은 후보 10개·현재음 11번이며 잔상·매듭은 연결/고정안 하나와 현재음을 표시한다. 확정 기본공격 11종과 이어 듣기, 소리별 위치·음량 조절을 지원한다. 게임 소리는 교체하지 않았으며 선택 JSON을 받아 적용한다. 상세 비교 범위와 미디어·레시피·빌더는 해당 리소스의 `source/README.md`가 소유한다.

현재 매듭은 04 시안 1번 감기만 사용하고 후속음을 없앤다. 잔상은 강베기 선택과 개별 조절값을 공유하여 첫 베기만 재생한다. 3연속 폭탄은 02 시안의 투척 WAV·타이밍·gain을 복원하며, 폭발은 원음의 전체 꼬리를 복원하고 강한 앞부분 이후 연속 감쇠한다. 파일 마지막 샘플만 0으로 만들거나 짧은 구간을 여러 번 감쇠하는 방식으로 대신하지 않는다. 다른 폭탄·폭발 수리검은 구매팩 물소리의 첫 충격 이후 연속 분출 구간으로 만든 음원을 공유한다. 외부 게임 녹음을 복제하거나 사용자 영상 소리를 후보에 섞지 않는다.

연막 첫 펑·발사기 기본공격·산탄은 거친 꼬리를 줄인 짧은 압력음을 중심으로 구성한다. 미끼 설치는 무겁게, 레이저는 낮은 몸통을 더해 재제작한다. 모아쏘기 발사음은 유지하고 충전은 무음이다. 보호막·방패 밀기는 짧은 공명, 미끼는 설치음만, 미사일은 마지막 폭발만 재생한다. 회전 수리검은 02 시안 원음을 12% 빠르게 재생한다.

HTML은 충돌 시뮬레이터가 아니다. 폭발·적중·복귀 등은 청취용 성공 시나리오이며 게임 적용은 실제 사건에 연결한다. 선택 JSON schemaVersion 7은 고정안·강베기 연결 및 해석 결과·공통음·개별 편집을 보존한다. 자동 시간·PCM 검사는 직접 청음과 실제 게임 검증을 대신하지 않는다.

폭탄 후보는 구매팩 물소리의 가장 강한 타격 후 90ms부터 연속 분출 구간을 사용한다. 화약 폭발·단단한 충격·버블 팝·원음 시작 타격을 쓰지 않는다. 먹안개는 터지는 소리와 유지 루프를 없애고, 발동 시점부터 1초짜리 단일 분출음을 재생한다. 인공 잔향·에코와 낮은 사인 압력음을 넣지 않는다. 미끼 후보는 시전 0.20초의 설치 성공 시점부터 접촉음과 18ms 뒤 잉크 정착음을 겹친다. 시전음은 없으며 게임 적용 때 SpawnDecoy 성공 사건에 연결한다. 레이저는 밝게 조정한 기존 WAV를 유지한다. 연막의 게임 효과 시간은 그대로이며 레이저의 길이·음높이 진행은 보존한다. 3연속 투척·폭발 사건 위치는 유지한다. 폭발 꼬리는 10ms 피크 포락선으로 실제 겹침을 계산하며 화면 시간과 재생 종료도 꼬리 끝까지 포함한다. HTML 상단 미정 목록은 별표와 확정 선택을 모두 확정으로 계산하고, 사용자 지정 고정안·강베기 연동 상태를 구분한다. 복수 별표도 모두 확정안이다. 마지막 청취만으로는 확정하지 않는다. 후보가 수정되어도 기존 확정을 미정으로 되돌리지 않으며 “확정 이후 수정본 있음”을 별도 표시한다. 이전 로컬 기록에 남아 있는 별표는 최초 실행 시 한 번 복원한다. `confirmedCandidates`에 원래 확정 리비전과 남아 있는 편집 기록을, `reviewStatus`에 상태를 저장한다. 수정본 자체를 자동 승인하지 않는다.

폭탄·먹안개 후보의 음색은 재검토 중이다. `resources/audio/gamemaster-skill-audition/preview/raw-materials-02.html`에서 구매팩 원음 20개를 가공 없이 비교한다. 공압 장치·분무기 계열 연막 재료 10개와 물 분출 마법·마법 버블 계열 폭탄 재료 10개이며, 이전 1차 원음과 중복하지 않는다. 과거 합성에 사용된 재료는 표시한다. 폭탄은 크레이지 아케이드 물풍선 파열 방향이며, 이 페이지의 선택은 원음 방향 확인이다. 기존 별표·게임 배치와 별도로 보관한다.

폭탄 파열음은 focused-mixes-01의 B3로 사용자 확정했다. `resources/audio/gamemaster-skill-audition/source/focused-selections.json`에 선택 파일과 해시를 보존한다. 현재 청취 화면은 `preview/smoke-release-08.html`이다. ### 기본 공속과 효과음의 분리

선택 음원에는 기본 속도에서 원음의 음색을 보존하기 위한 제작 보정이 이미 들어 있다. `data/audio/basic-attack-selections.json`의 `outputs.playbackRate`를 `python tools/audio/export_basic_playback_rates.py`로 `WeaponSounds/BasicPlaybackRates.json`에 운반한다. `--check`는 원본과의 일치를 검사하며 PCM 바이트를 재인코딩하지 않는다. 런타임은 이 고정 보정을 유지하고 공속 버프와 무관하게 재생한다. AudioSource의 숫자 pitch를 무조건 1로 바꾸는 방식은 보정된 파일의 음색까지 바꾸므로 사용하지 않는다. 공격 취소·사망·리셋·일시정지는 기존 CuePlayer 수명을 유지한다. 원음에 포함된 휘두름/충격의 피크를 새 타격 시각으로 재편집하지 않으며 별도 타격음이 실제 적중 시점을 나타낸다.
