# 1스테이지 · 다양한 하늘과 종잇재 채택본

[실제 게임 화면과 움직이는 효과 보기](preview/index.html). 채택한 타일·배경 팔레트·산과 마을 PNG를 그대로 사용하고 구름/새 변형 및 코드 종잇재를 추가한 미술 채택본이다. 본 게임 프로젝트에는 아직 통합하지 않았다.

## 구름·새

기본 이미지 생성 도구로 구름 6종, 새 무리 6종의 투명 아틀라스를 만들었다. 원본은 source에 보존한다. `source/BuildSkySprites.cs`가 이를 개별 네이티브 PNG로 출력한다. 구름은 192×64px, 새 무리는 32×16px 투명 캔버스이며 PPU32, scale1, Point, 압축 없음, 밉맵 없음이다. 구름 3색은 #DDD8CD / #E6E2D8 / #F0EBE2, 새는 #B7AFA0를 사용한다. 실제 그림은 투명 여백 안에 들어간다. 꽃·타일·캐릭터는 재생성하지 않았다. 제작 요청문은 `source/requests.json`에 있다.

`Stage1Atmosphere.Initialize(camera, cloudSprites, birdSprites, seed)`에 구름 6개와 새 무리 6개의 Sprite 배열을 넘긴다. 검토 seed는 7312026이다. System.Random을 사용하므로 게임의 전역 Unity 랜덤 상태를 바꾸지 않는다. 같은 시드는 같은 변형·위치·좌우 방향을 재현한다. seed를 바꾸면 배치가 바뀐다. 그리드 각 영역 안에서 위치를 흔들어 무작위 겹침을 줄이며, 카메라를 따라 순환하는 넓은 필드를 재사용한다. 구름은 패럴랙스 X .06/Y .025, 새는 X .08/Y .04로 먼 레이어 속도를 유지한다. 새 무리는 천천히 옆으로 이동한다. 산·먼 마을·가까운 마을은 이전 네이티브 그룹의 분리 PNG를 참조한다.

## 코드 종잇재

`source/Stage1Atmosphere.cs`는 Unity 런타임 MonoBehaviour다. Editor API나 물리·전투 변경이 없다. 96개 찢긴 오각형을 한 동적 Mesh로 그리며 텍스처 없이 코드로 생성한다. 옆으로 부는 바람, 완만한 낙하, 서로 다른 회전·접힘 위상을 사용한다. 기본 크기는 2.5~4.5px, 드문 조각 6.5px다. 기존 회갈색 약 70%·검정 #141414 약 10%·흰색 #FFFFFF 약 20%를 섞어 낮은 불투명도로 화면 전역에 배치하고 카메라 초점 근처에서는 더 옅게 만든다. 색상은 조각마다 고정하며 프레임마다 바꾸지 않는다. 색상 선택에 난수를 추가 소비하지 않으므로 기존 조각의 크기·위치·회전·바람은 유지된다. 현재 96개에서는 회갈색 67개, 검정 10개, 흰색 19개다. 조각 꼭짓점은 월드 1/32 단위로 스냅한다. 화면 가장자리 밖에서 순환하므로 재생 중 생성·삭제하지 않는다. Inspector의 `ashCount`, `windPixelsPerSecond`, `ashEnabled`로 수량·바람·표시를 조절한다.

`Stage1PaperAsh.shader`와 `../stage1-pixel-background-native-20261111/source/NativeBackground.shader`가 필요하다. 실제 통합에서는 두 셰이더가 빌드에서 제거되지 않도록 참조 재질을 연결해야 한다. 현재 검토는 Shader.Find를 쓰는 Editor 실행이다. 프레임별 시뮬레이션 대신 같은 시간 입력으로 재현할 수 있어 캡처 시 `manualTime=true`, `RenderAt(seconds)`를 사용한다.

## 게임 화면과 재현

[채택본 보기](preview/index.html)는 Unity 6000.6.5f1의 격리 프로젝트에서 960×540, orthographicSize 8.4375, 1u=32px로 렌더링한다. 실제 캐릭터·적·지형·나무 발판·크림색 통과 벽을 사용한다. S1-04 계단, S1-07 수직 방 위/아래, S1-08 넓은 방의 채택본만 보관한다. HUD와 적의 공격은 미술 검토를 위해 제외한다.

source/Stage1ApprovedReview.cs는 채택한 세 그룹만 참조하는 검토 어댑터다. source/capture-approved.ps1에 격리 Unity 프로젝트 경로를 지정해 실행한다. 이전 미채택 시안의 그림·셰이더·스크립트가 필요하지 않다. 이 실행은 검토 프로젝트에 어댑터 사본을 설치하며 본 게임 프로젝트를 자동 변경하지 않는다.

전체 맵 이동과 실내외 효과 강도 전환, Shader.Find로 찾는 셰이더의 빌드 보존을 위한 참조 재질 연결은 실제 게임 통합 단계에서 검토한다. 미술 승인과 본 게임 통합 완료를 구분한다.
