# 잉크 파츠 브라우저 시뮬레이터

[분야 개요](README.md)

> 장비 성장 이행 범위: 제품 규칙은 [무기 도면·런 잉크 도감](../../design/equipment/rules.md)을 따른다. 아래 팔레트·스탬프·출발 도면 선택·바닥 아이템 드롭은 현재 구현 설명이며 새 제품 기획이 아니다. 런 도감·무기 잉크 적용·내구도·전투방 3지선다의 구현과 실행 검증은 미완료다.

신규 50종(색상별 10종)의 트리거와 효과를 독립 브라우저 모델에서 실행한다. 제품 규칙은 [개편 설계](../../design/equipment/rules.md), 파츠 효과는 [카탈로그](../data/catalogs/ink-simulator-part-catalog.md)를 따른다. Unity 전투에 효과를 통합한 것은 아니다.

## 팔레트·무기 귀속 제한의 현재 범위

제품은 팔레트를 무기에 먼저 장착한 뒤 색상 호환 칸에만 잉크를 넣고, 효과는 기본적으로 그 무기에만 적용한다. B 또는 두 무기 강화는 파츠에 명시한 예외다. 원본의 `equipmentRules`·`effect.weaponScope`·`crossWeaponException`은 이 설계 기준을 기록한다. 현재 브라우저는 자유 6칸이며 팔레트 선장착·색상 호환 검사와 일부 공통 버프의 자기 무기 한정 처리를 아직 구현하지 않았다. 이 필드 추가를 실행 반영으로 해석하지 않는다.

## 실행과 조작

저장소 루트에서 `node tools/ink-combination-lab/generate-simulator.cjs --preview`를 실행하고 `outputs/ink-combination-lab/ink-parts.html`을 브라우저로 연다. 파일을 다시 생성했다면 브라우저를 새로고침한다. 별도 서버나 네트워크 연결은 필요 없다. 같은 폴더의 `encyclopedia.html`은 읽기 전용 도감이다.

- A/B 편집 대상을 고른 뒤 파츠를 장착한다. 각 6칸은 자유 조합 시험용 가정이다. 장착 칸을 누르면 해제한다. 파츠·프리셋·실험 설정을 바꾸면 전투를 초기화한다.
- Q/W는 A/B 기본 공격, E/R은 A/B 스킬, Space는 반대 무기로 교대 후 자동 기본 공격이다. 다른 무기의 공격 버튼도 교대 과정을 거친다. 공격 동작 중이나 스킬 쿨타임 중의 요청은 거절한다.
- 방향키 또는 이동 버튼으로 이동한다. 몬스터를 클릭하면 조준 대상을 선택한다. 자동 조준을 끄면 이동 방향을 바라본다. 근접 보기에서는 카메라가 플레이어를 따르며 전체 보기로 모든 배치를 볼 수 있다.
- 몬스터 이동·공격을 끄면 허수아비 시험이다. 켜면 이동과 조준 공격이 작동한다. `피격 20`으로 회복·보호막을 시험하고 수동 표식 버튼으로 격발을 준비할 수 있다.
- 전투 초기화는 체력·몬스터·강화·예약 공격·쿨타임·계측을 초기화하며 장착 구성을 유지한다. 구성과 설정은 별도 버전의 브라우저 localStorage에 저장한다. 이전 후보 목록의 저장 데이터는 재사용하지 않는다.

## 구현된 처리

스위칭은 **떠나는 무기 A의 모든 관련 효과 발동 및 즉시 파생 효과 처리 → B로 전환 → B 자동 공격** 순서다. 발동 원본과 적용 대상은 구분한다. A의 효과가 B 공격을 강화할 수 있다. 예약 단발 공격은 A에서 예약하고 이후에도 A 귀속과 원래 대상의 생명을 유지한다.

원타격·추가타 모두 적중과 처치 트리거를 실행한다. 죽은 대상에 예약된 추가 피해는 재등장한 다른 생명으로 이전하지 않는다. 다음 공격 강화는 빗나가도 공격 시작 시 소비하고, 다음 스킬 전용 반경은 기본 공격에 소비하지 않는다. 시간 경과 피해는 없다.

빨강은 실제 추가 피해·단발 예약·다음 공격 강화를 계산한다. 노랑은 실제 이동 속도를 바꾸며 추적·후퇴 방향과 누적 한도를 검사한다. 초록은 현재/최대 체력·실제 피해 비례 회복·보호막 흡수와 만료를 계산한다. 파랑은 실제 대상 선택 사거리·반경과 지정 무기의 남은 쿨타임을 바꾼다. 보라는 실제 변위·둔화·속박·기절·공포·침묵·무장해제·실명 상태를 적용한다.

간이 AI에서 속박은 이동, 기절은 이동·공격, 침묵은 스킬, 무장해제는 기본 공격을 제한한다. 실명은 새 조준을 막으며 이미 조준한 공격을 소급 취소하지 않는다. 공포는 부여 시 A의 위치에서 멀어지게 한다. 조준 원은 공격 준비 중 목표 지점이며 이동으로 피할 수 있다.

## 제품 설계와 남은 이행

MVP 설계는 표식 최대 5개·8초 유지·전량 소비·소비 표식 수 비례 기본 격발 피해·각 격발 잉크 효과 1회다. MVP 기본 피해 기준은 격발 무기의 기본 콤보 각 타격 피해 평균이며 소비 표식당 계수는 0.15다. 기본 격발 피해는 추가타 적중·처치 트리거를 발동한다. 제품 표식은 전체 8초 갱신·격발 후 새 무기 표식 1개 부여를 사용한다. 아래 브라우저 기본 실험값의 표식 상한 6개·기본 피해 0은 아직 이 설계에 맞춰 변경하지 않았으며, 제품 규칙을 확정하는 값이 아니다.

## 미정 규칙의 실험값

편집 원본은 `data/combat/ink_simulator_proposal.json`이다. 아래는 제품 확정값이 아니며 화면에서 변경할 수 있다.

| 항목 | 기본 실험값 |
|---|---|
| 표식 부여 | 적중당 1개, 추가타 부여 꺼짐. 수동 모드로 변경 가능 |
| 표식 유지·상한 | 8초·6개 |
| 격발 | 실제 무기 전환 후 다른 무기의 표식이 있는 몬스터 적중 시 해당 표식을 전량 소비하고 격발 무기의 파츠 실행. 이후 새 표식 부여 |
| 격발 자체 피해 | 0. 파츠가 만드는 피해는 별도 |
| 추가타 연쇄 | 깊이 2, 최대 6까지 변경 가능. 별도 실행 예산 512건으로 페이지 정지 방지 |
| 파츠 내부 쿨타임 | 인스턴스별 0.25초. 0으로 바꾸면 같은 시각의 추가타도 재발동 가능 |
| 동일 강화 효과 | 강한 값만 적용. 합산 모드로 변경 가능 |
| 동일 파츠 | 기본 중복 장착 꺼짐. 실험 옵션으로 허용 가능 |
| 보스 CC | 지속시간·변위 0.25배 |
| 강제 제어 회복 구간 | 0초. 설정 시 기절·속박·공포 사이의 공유 간격으로 사용하며 둔화·침묵·실명까지 막지 않음 |

표식 부여용 특정 트리거, 최종 소비·중복·연쇄 제한, CC 저항과 보스 규칙은 여전히 미정이다. 브라우저 설정 변경은 제품 명세를 변경하지 않는다. 간이 무기 4개도 파츠 비교용 시험 프리셋이며 승인된 Unity 무기 형태 전체의 복제본이 아니다.

## 원본과 검증

`data/combat/ink_simulator_parts_proposal.json`의 `effect.params`가 실행 수치다. 이름·설명·수치를 함께 수정한다. 코드는 한국어 설명에서 숫자를 파싱하지 않는다. `tools/ink-combination-lab/simulator.js`는 DOM 없는 결정적 계산 엔진, `simulator-app.js`는 장착·입력·저장·Canvas 표시다. HTML/CSS와 두 JSON은 생성 시 하나의 HTML로 묶는다.

```sh
node --test tools/ink-combination-lab/simulator.test.cjs
node tools/ink-combination-lab/check-simulator-catalog.cjs
node tools/ink-combination-lab/generate-simulator.cjs --preview
node tools/ink-combination-lab/generate-simulator.cjs --check --preview
python tools/combat/export_training_parts.py --check  # 기존 Unity 데이터가 바뀌지 않았는지 별도 검사
```

선택적인 브라우저 상호작용 검사는 [도구 안내](../../../tools/ink-combination-lab/README.md)를 따른다. 기존 Unity 잉크 카탈로그·훈련장·실행 효과는 별도 구현이며 이 브라우저 모델의 50종으로 덮어쓰지 않는다. 원본·생성기·생성 문서를 분리해 기존 Unity 데이터 파이프라인을 유지한다. 지형 물리·실제 모션·투사체 비행·차징 스탬프·드롭·제작·경제는 재현하지 않는다. 이 간이 모델의 피해·제어 결과를 제품 밸런스 또는 Unity 검증 완료로 해석하지 않는다.

## MVP 정비소 모드

`growth.js`는 재고·가격·귀속·거래를, `growth-app.js`는 별도 정비소 화면을 담당한다. 기존 자유 50종 모드는 유지한다. MVP 모드에서는 20종만 획득하며 색상 일치·무색 호환·무기당 중복 제한·팔레트 최초 무기 귀속을 적용한다. 장착·빈칸 채우기는 무료, 교체는 등급별 비용, 점유 칸 색상 변경은 두 팔레트 공용 런당 횟수(`colorChangesPerRun`, 1차 시험값 2회)·회당 `colorChangeGold`이며 새 잉크와 원자적으로 교체한다. 슬롯 최대 +5와 캐릭터 공통 공격 강화를 실제 전투 수치에 적용한다.

잉크 판매가는 현재 뽑기 가격의 20%다. 판매는 뽑기 가격 트랙을 올리지 않고 성공 뽑기만 다음 가격을 올린다. 현재 가격에서 5개 판매하면 1회 뽑기가 가능하다. 장착 잉크 직접 판매와 빈칸 색상 변경은 미정이므로 제공하지 않는다. 새 팔레트로 교체할 때는 추가 비용 없이 기존 팔레트·잉크를 소멸하고 새 팔레트 +0을 적용한다. 이 뽑기·판매가 계산은 브라우저 도구 자체의 동작이다. 게임 정비소는 더 이상 뽑기를 하지 않고 [잉크 판매대](../../design/run/progression-and-economy.md)에서 등급 3~4 잉크를 고정 가격에 팔며, 색상 잉크 판매가는 8G 고정이다.

3칸 기본 단색·4칸 기본 2+2에서 각 칸은 독립적으로 무색이 될 수 있다. 시험 확률은 10%다. 5칸은 기존 색상 가중치로 추첨한다. 브라우저 팔레트 획득 도구는 칸 수와 기본 색을 직접 골라 확인하는 시험 UI이며 실제 상점 재고나 런 진행 UI가 아니다. 보상 시험 도구는 원본 확률로 잉크·골드를 지급한다. 페이지 재로드 시 MVP 재고는 초기화하며 자유 조합 저장과 분리한다.

```sh
node --test tools/ink-combination-lab/growth.test.cjs tools/ink-combination-lab/simulator.test.cjs
node tools/ink-combination-lab/growth-browser.test.cjs
python tools/combat/export_weapon_growth.py --check
```

Unity 본 게임 연결 코드는 `WeaponGrowth`, `CombatArena.MvpInk`, `Chapter1MaintenanceShop.Growth`와 `TemporaryGameGui.Growth`다. 해당 코드의 추가와 Unity 실행 검증 완료는 구분한다. 최신 검증 결과는 커밋 본문 및 작업 응답으로 전달한다.
