# 전체 무기 기본공격 사운드 비교

`../preview/index.html`을 브라우저에서 직접 연다. 11종(검·채찍·레이피어·단검·망치·방패·대검·발사기·폭탄·수리검·맨손), 기본공격 23타와 무기별 구매팩 후보 10개, 현재 적용음 1세트를 포함한다. 이미지·원음은 HTML에 내장하여 서버·인터넷 없이 동작한다. 같은 후보가 여러 무기에 중복될 수 있으며 내장 원음은 중복 제거한다.

## 사용

- 상단에서 무기를 고르고 후보를 눌러 본체 모션과 함께 듣는다. 처음에는 채찍을 보여 주며 이후 마지막 무기를 기억한다.
- 전체 연계 또는 각 타를 선택한다. 기본 배율은 현재 playtest_environment의 채찍 1.4, 대검 0.8, 나머지 1이다.
- 반복·11개 순차 비교·프레임 탐색·속도·좌우 방향·기본 이펙트·후보별 소리 시점·즐겨찾기를 지원한다.
- `이 소리로 선택`으로 무기별 선택을 기록한다. `전체 선택 파일로 저장`은 모든 무기의 선택과 음원 출처를 JSON으로 내보낸다. 브라우저 저장은 localStorage를 사용한다.
- 검 5번 선택은 `selections.json`의 사용자 선택으로 보존하며 현재 게임 적용과 구분한다. 화면에서 이후 다른 후보를 선택하면 그 브라우저의 선택이 우선한다.
- 파일명과 길이로 추린 1차 후보이며 청취 승인이 아니다. 발사기·폭탄·수리검은 발사/투척 소리 대상이다. 실제 접촉 명중음·폭발음·스킬은 이 비교 범위에 포함하지 않는다.

## 시간과 현재 적용음

현재 AnimationCatalog·HeavyWeaponCatalog·MeleeCatalog의 프레임과 Unity PNG 피벗을 읽는다. 본체는 AttackMotionTiming.MapSourceTime과 같은 타격 전/후 구간 매핑으로 재생한다. 프레임 원본의 길이와 게임 공격 길이가 다를 때 원본 시간을 그대로 재생하지 않는다. FrameTime은 지원하지 않으며 빌드 시 거부한다. 기본 이펙트는 고정 카탈로그 그림 참고다. 동적 궤적·투사체 비행·적 명중·히트스톱·이동은 재현하지 않는다.

11번 `현재 적용 중`은 SelectedAudioClips.asset GUID로 실제 연결을 확인한 타별 음원이다. ApprovedCombatAudio/Catalog와 WeaponSounds/Timing의 우선순위를 따르고, 공격 시작부터 nominalDuration / 실제 모션 길이 배율로 재생한다. 후보용 피크 재정렬·시점 조절은 적용하지 않는다. 비교 음량 맞춤을 끄면 게임 클립 gain 0.8을 사용한다. 듣기 음량은 별도이며 게임 마스터 믹스·장치 출력까지 동일하다는 뜻은 아니다.

새 후보는 8ms 에너지 최대점을 각 타의 판정/발사 시각에 맞춘다. 앞부분은 프리롤로 보존하고 속도를 바꾸어도 원음 피치는 유지한다. 비교 음량 맞춤은 활성 구간 RMS와 피크 제한을 재생 gain에 적용한다. WAV 바이트는 변경하지 않는다. 무기/후보 전환·정지·탭 숨김은 예약 음원도 취소한다.

## 빌드와 검증

리소스 작업 브랜치에서 `resources/audio/gamemaster-audition/`을 작업 디렉터리로 사용한다.

```powershell
python source/build.py --archive "C:/Users/SSAFY/Downloads/Gamemaster Audio - Pro Sound Collection.zip"
node --check source/app.js
node source/test.cjs
python ../../tools/configure_lfs.py
```

`weapons.json`이 후보 목록, `selections.json`이 대화에서 확정한 선택의 원본이다. 빌더는 출력·출처·해시·catalog·generated-assets·LFS payload 등록을 갱신한다. `provenance.json`은 스냅샷을 기록한다. 기존 게임 데이터·Unity 음원·GUID는 변경하지 않는다. 현재 클립이 카탈로그의 GUID 또는 resources 원본 바이트와 다르면 빌드를 중단한다.

단위 검사는 실제 앱 스크립트를 DOM·AudioContext 스텁에서 실행해 모든 무기의 타 선택·시간 매핑·현재 재생 배율·음원 예약 취소·순차 비교·무기별 선택 보존을 검사한다. 실제 브라우저 레이아웃·오디오 디코더·장치 청취 검증을 대신하지 않는다.

## 망치 접촉 시점 비교

`../preview/revision-02.html`은 미확정인 망치만 보여 준다. 발사기는 현재 게임 음원(11번)으로 확정했다. 망치 10개는 기존 9번 휘두름을 6/9/12dB 키우고 2타의 휘두름과 충격음의 에너지 피크를 같은 시각에 겹친다. 기준은 첫 바닥 접촉 프레임 `hammer-a/15`보다 40ms 앞이며 현재 기본속도에서 2타 시작 후 250ms다. 휘두름의 꼬리를 접촉 시점에 끊지 않는다. 접촉 시각은 프레임 길이와 현재 모션 매핑에서 계산하며 현재 기본속도에서는 2타 시작 후 290ms다. 자동 음량 맞춤은 끄고 설계 음량을 유지한다. 11번은 기존 게임 음원이다. 후보 revision으로 이전 시점 보정·선택이 새 시안에 섞이지 않게 한다.

화면은 `getOutputTimestamp()`의 실제 출력 시계를 따라간다. 지원하지 않는 브라우저는 `baseLatency + outputLatency`를 보정한다. 단위 검사에서 출력 지연과 0.5/1/1.5/2배속의 바닥 접촉 프레임을 확인한다. 장치 청취 검증을 대신하지 않는다.

### 휘두름·충격음 개별 배치

망치 후보 1~10번의 `2타 소리 위치 · 따로 조절`에서 휘두름과 충격음을 각각 -400~+400ms, 5ms 단위로 옮긴다. 슬라이더나 숫자 입력을 사용한다. 음수는 먼저, 양수는 늦게이며 1배속 기준 오프셋을 배속으로 나누어 재생한다. 1타와 현재 적용음(11번)은 분리 편집 대상이 아니다. `2타 반복하며 조절`로 확인하며 `휘두름만`·`충격음만`은 미리듣기용이고 선택 저장에 음소거를 반영하지 않는다.

각 후보의 `layerOffsets`와 확정 선택의 `layerOffsetsMs`에 `swing`·`impact`를 저장한다. 선택 파일 schemaVersion 3은 두 원음의 SHA256·기준 피크·재생 길이도 내보낸다. 두 원음은 같은 gain으로 렌더하며 각 원음 피크의 합을 제한하여 위치를 바꿔도 클리핑하지 않는다. 브라우저 저장은 해당 장치/파일에 한정될 수 있으므로 전달할 때는 `전체 선택 파일로 저장`을 사용한다. HTML만 조절해서 게임 음원이 바뀌지는 않는다.

`resources/tools/render_basic_attack_audio.py`는 사용자가 준 선택 JSON과 명시한 수정(폭탄 1, 수리검은 폭탄 2)을 반영해 구매팩 선택 원본·기본공격 렌더·2차 시안을 만든다. `--apply-local`은 Unity의 기존 GUID를 유지한 채 WAV 사본과 배치 매니페스트를 갱신한다. 기존 스킬·명중음과 과거 리소스 원본은 보존한다. 실제 적용값은 메인의 `data/audio/basic-attack-selections.json`과 리소스 `audio/gamemaster-selected/source/recipe.json`을 대조한다. 후보의 HTML 선택 저장은 자동으로 Unity를 변경하지 않는다.
