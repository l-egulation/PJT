# 2챕터 출구 · 3챕터 대도서관으로 가는 문 (2026-11-13)

2챕터 보스방 출구를 1·2챕터 공용 돌 아치(environments/stage1-pixel-structures-20261112 의 exit)에서 대도서관 입구 문으로 바꾼다. 사용자가 시안 A~D 가운데 A 「서가 두짝문」을 고르고, 크게·디테일·픽셀 재기 규칙까지 다듬은 2차를 확정했다.

## 규격

- 96×112 도트를 2배로 키운 192×224(6×7u, 32px = 1u). 아래 가운데가 기준점이다(바닥 윗면). 맨 아래 8px 은 돌계단이다.
- 열림 8장 `runtime/opening/01~08`(01 닫힘 → 08 열림), 장당 80ms(Unity SpriteFlipbook 기본). `door-closed` = 01, `door-open` = 08.
- 열리면 안쪽 서가 복도·샹들리에·사다리가 보이고, 채광창이 밝아지며 계단에 빛이 쏟아진다.

## 그림

박공(펼친 책 문장·세로 빛살·꼭대기 깃펜 촉), 처마(이빨 장식·책등 띠), 반원 채광창, 서가 기둥(기둥머리·받침·서랍, 칸마다 기운 책·두루마리), 기둥 바깥 벽등, 두 짝 문(위 칸 서가 새김, 아래 칸 들어간 판에 책 문양, 놋쇠 경첩·리벳·고리·열쇠판), 돌계단 두 단.

픽셀 재기 규칙: 박공 비탈 1:3, 채광창 반원 셋은 마디가 한 방향으로만, 펼친 책 1:2, 기운 책 1:3, 안쪽 바닥선·사다리·계단 빛 가장자리도 정수 기울기. `source/door_a2.py` 의 `check()` 가 박공·반원 마디를 출력한다.

## 다시 뽑기

```
cd source
python door_a2.py      # ../build 에 A2-00~07 과 GIF. runtime 은 그 사본이다(바이트까지 같음을 확인)
```
