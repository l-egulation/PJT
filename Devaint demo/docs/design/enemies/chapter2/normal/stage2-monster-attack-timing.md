# 2스테이지 공격 시간

[분야 개요](README.md)

편집 원본: `data/combat/stage2_monster_attack_timing.json`. 확정 설계. 기존 프레임의 표시 시간을 `tools/combat/export_chapter2_approved_normals.py`로 재배분하여 Unity 본체·독립 효과 카탈로그와 전투 시계에 연결한다. 새 스프라이트는 생성하지 않는다.

등짐분사수: 전조0.65초 → 피해 판정0.65초 → 회복0.70초 → 대기1.2초. 계속 공격 가능하면 시작 간격3.2초다. 대상이 분사에 처음 겹칠 때 첫 피해를 주고, 이후0.30초 간격·공격 전체 최대3회다. 처음부터 겹치면 공격 시작 기준0.65/0.95/1.25초에 피해를 준다. 나갔다 돌아와도 해당 분사의 횟수와 재피격 대기를 초기화하지 않는다.

쐐기보행기: 돌진 전조0.60초 → 실제 이동 최대0.50초 → 정지·끌기해제 → 내려찍기 전조0.45초 → 찍기 판정0.15초 → 회복0.90초 → 대기1.8초. 돌진 판정은 실제 돌진 구간에만 존재하고 대상별 최초접촉1회 피해다. 정지하면 즉시 돌진 판정을 정리한다. 찍기 판정도 대상별1회 피해다.

지형 조기정지가 없으면 돌진0.60~1.10초, 찍기1.55~1.70초, 회복종료2.60초, 다음 전조4.40초다. 조기정지 시 실제 정지 시각에서 내려찍기 전조0.45초를 새로 계산하므로 나머지 일정도 앞당긴다. 전조·회복에는 본체 공격 피해가 없다.

먹침필경사는 A안으로 확정했다. 공격 시작 기준 [0.57,0.64), [0.72,0.79), [0.87,0.94)초에만 각각0.07초 활성이다. 원본프레임7~9,13~15,19~21에 대응한다. 각 찌르기당 대상별1회(5피해), 공격 전체 최대3회(15피해)이며 찌르기 사이·전조·회복에는 판정이 없다. 기존3연타 시작 간격0.15초와 총 모션1.59초를 유지한다. 원거리2종은 발사 후 투사체의 비행·충돌이 본체 회복과 별도로 진행한다.
