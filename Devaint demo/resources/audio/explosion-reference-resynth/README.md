# 참고 영상 재현 폭발음

2026-11-16 사용자가 앞선 폭발음 후보를 모두 탈락시키고, 처음 준 참고 영상과 "완전 흡사하게" 만들어 달라고 했다. 이 폴더는 그 요청에 따른 후보다.

**사용자 결정(같은 날): 큰 폭발과 유탄은 1번을 쓴다.** 그 뒤 1번의 꼬리를 고쳤다. 꼬리가 -40 dB 근처에 머물다가 1.5초쯤 한 번 다시 올라온 뒤 끝나던 것을, -30 dB 아래로는 처음 줄어들던 기울기 그대로 -70 dB 이하까지 줄어들게 했다(`steady_end`). Unity에는 `SelectedSkillAudio/explosion_large_resynth_01.wav`(`runtime/large-1.wav`)와 `explosion_grenade_resynth_01.wav`(`runtime/grenade-1.wav`)로 배치했다. 큰 폭발 파일은 `explosion_large`, 폭탄 원거리·후속·이동 스킬 폭발이 함께 쓴다. 유탄 파일은 `explosion_grenade`, 발사기 후속 특수기 폭발이 함께 쓴다. 기본 폭발은 이보다 작은 폭탄으로 만들기로 했고, 그 후보는 `explosion-small-bomb`에 있다.

## 방식

참고 영상은 다른 2D 픽셀 게임의 화면 녹화다. 그 소리는 이 저장소에 넣지 않는다.

1. 측정: `--analyze`로 참고 음원에서 첫 폭발(0.95~2.65초)을 측정한다.
   - 단위는 5 ms마다, 1/6 옥타브 대역 55개다.
   - 폭발 전(0.3~0.9초)의 배경 잡음을 빼되, 각 칸 전력의 10%는 남긴다.
   - 35 ms 중앙값으로 무관한 짧은 딸깍을 지운다.
   - 피크 200 ms 뒤부터의 꼬리는 75 ms 평균으로 매끄럽게 한다.
   - 결과는 dB 숫자뿐인 모양 정보다(`source/reference-contour.json`). 재생 가능한 소리가 아니다.
2. 합성: 고정 시드 잡음의 STFT에 그 모양대로 대역별 이득을 준다.
   - 이득은 로그 주파수 축에서 매끄럽게 보간한다.
   - 결과는 참고의 시작, 음색, 감쇠를 따르지만 원래 소리의 샘플은 하나도 들어 있지 않다.

## 후보

| 번호 | 이름 | 내용 |
|---|---|---|
| 1 | 참고 영상 그대로 | 측정한 모양 그대로. 앞의 밝은 섬광음까지 포함한다. |
| 2 | 참고 영상 · 딸깍 없이 | 시작 70 ms의 1.5 kHz 이상을 -15 dB 낮추고, 몸통을 20 ms에 걸쳐 연다. 사용자가 이전에 "딸깍 빼"라고 했던 것을 반영했다. |
| 3 | 참고 영상 그대로 · 다른 잡음 | 1번과 같은 모양이고 잡음 시드만 다르다. 결 차이를 비교하는 용도다. |

크기는 그 자리의 지금 소리와 같게 맞췄다(K-가중 400 ms 최대값). 유탄은 지금과 같은 3연쇄다. 비교 화면의 「참고 파일 불러오기」로 영상을 열면 같은 크기로 A/B할 수 있다.

## 참고와의 거리

거리는 레벨 곡선 차이와 대역 분포 차이에 0.6을 곱한 값의 합이다. 낮을수록 가깝다.

| 소리 | 거리 | 대역 분포 차이 |
|---|---|---|
| 1번 | 4.1 | 0.9 dB |
| 2번 | 4.1 | 0.9 dB |
| 3번 | 4.2 | 0.7 dB |
| 이전 후보들 | 9~21 | |
| 지금 게임 소리 | 16.3 | |

## 만들면서 고친 문제

- 1/6 옥타브 저역 대역 일부가 STFT 한 칸보다 좁아 데이터가 없었다. 이 때문에 저음이 과하게 키워졌다. 데이터가 있는 대역만 쓰도록 고쳤다.
- 이득을 dB에서 2로 나누는 단위 실수가 있었다. 그래서 보정이 절반만 적용돼 고역과 꼬리가 너무 컸다. 이 실수를 고쳤다.
- 배경을 1.5배로 빼자 꼬리에 조각난 「섬」이 생겼다. 10%를 남기고 꼬리를 시간축으로 매끄럽게 해서 없앴다.

## 한계

- 측정과 그림으로는 가깝지만, 제작자는 소리를 직접 듣지 못했다.
- 참고 녹화의 압축(AAC)이나 녹화 레벨 때문에 원래 게임 소리와 미세하게 다를 수 있다.
- 다른 게임 효과음의 소리 모양을 그대로 따른 재현이다. 샘플은 쓰지 않았지만, 출시 전에 팀에서 이 방식을 써도 되는지 판단하는 것이 좋다.
