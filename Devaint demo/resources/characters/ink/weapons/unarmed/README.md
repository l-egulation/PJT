# 맨손 기본 공격

사용자가 선택한 19장·2타(0.36초 + 0.32초)의 외곽 정리 v2다. 원본 캔버스 640×360과 PNG 바이트를 유지하며 공간 픽셀화하지 않는다. `source/generated-sheet.png`는 생성 원본, `source/aligned/`는 발 정렬 입력, `runtime/approved-combo/`는 배경 제거·외곽 및 색 보정 결과다. 제작 스크립트는 당시 입력 경로를 포함한 보존 원본이다.

Unity 가져오기 설정은 메인이 소유한다. PPU90·상단 기준 피벗(340,340)은 기본 자세의 높이 2unit과 발 기준을 맞춘다. 전투 피해·판정·이동 및 시간의 기준은 메인의 `data/combat/unarmed_basic.json`이다. 그림에 포함된 공격 호는 별도 이중 효과를 추가하지 않는다.
