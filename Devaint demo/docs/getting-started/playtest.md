# deviant 실행

[분야 개요](README.md)

들판 전투 화면 좌측 상단의 미니맵은 주변 지형과 청록색 현재 위치, 빨간색 적 몬스터 위치를 실시간으로 갱신한다. 적 표시는 미니맵과 전체 지도에 공통 적용하며, 탐색한 방과 공개된 인접 길목의 살아 있는 적만 표시한다. 처치하거나 비활성화된 적과 미탐색 공간의 적은 표시하지 않는다. 캐릭터를 따라 이동하며 전투는 계속된다. M으로 전체 지도를 열면 미니맵 대신 전체 지도를 표시한다.

들판의 기존 맵·ver2에서는 **M**으로 전체 지도를 연다. 현재 위치·구간 번호·지형과 발판 구조·카메라 범위를 표시한다. 휠 또는 +/−로 확대·축소하고 드래그로 이동한다. **C**는 현재 위치, **Home**은 전체 보기, **M/Esc**는 닫기다. 지도 확인 중에는 전투가 정지한다. 이 키는 현재 테스트환경의 조작이며 제품 전체의 최종 키 배정을 확정하지 않는다.

일반 적 무리 배치와 슬롯별 공격력·공격속도·특수 선택은 [테스트 설정창](../development/tools/playtest-workbench.md)을 사용한다. 공통 씬에서 F1로 연다.

## 실행 공간 선택

현재 게임 진입과 빌드는 아래 타이틀·시작 마을·랜덤 스테이지를 연결한다. Unity 메뉴의 `Tools/deviant/Open Sketch Title`은 승인된 새 타이틀 씬을 연다. `Deviant.Game.Editor.SketchTitleEditor.OpenAndPlay`는 같은 씬을 열고 재생하는 Editor 진입점이다.

| 확인하려는 것 | 씬 |
|---|---|
| 타이틀 → 새 런 → 결과 | `Assets/ForestCombatV2/Scenes/Chapter1Title.unity` |
| 작업대·첫 방문 이야기·출발 준비 | `Assets/Deviant/Hub/Scenes/StartingVillage.unity` |
| 최신 팀 스케치 지형·발판의 1챕터 랜덤 스테이지 | `Assets/MeadowDuskV3/MapVer2/Scenes/Chapter1Procedural.unity` |

구씬은 실행·빌드·맵 선택 대상이 아니다. 2챕터 단독 검토는 Tools → deviant → Chapter2를 사용하며 공통 게임과 같은 HUD·가방·정비소·지도를 쓴다. [실행·데이터·검증](../development/gameplay/world/chapter2-runtime.md)을 따른다.

기존 회귀 테스트용 원문은 Unity 에셋 밖 `unity/Tests/Fixtures/LegacyScenes/`에만 둔다.

## 통합 게임 실행

Unity **6000.6.5f1**에서 `unity`를 연다. `Tools > deviant > Game > Play Common Game`은 현재 체크아웃에 고정된 에셋을 준비한 뒤 타이틀에서 시작한다. 처음 받아야 하는 파일이 있으면 Python, Git LFS, GitLab 리소스 읽기 권한이 필요하다. 타이틀 씬을 직접 열거나 `Open Common Game`으로 열어 Play할 때는 먼저 [에셋을 복원](../assets/README.md)한다.

통합 씬은 숲 지형·카메라, Combat V2 전투, 실제 HP와 무기 이름을 표시하는 HUD를 사용한다. 전투 입력은 아래 Combat V2 표와 같다. ESC로 일시정지하고, Editor·Development Build에서는 F1로 전투 시험 장비 패널을 연다. 공용 GUI의 가방·정비소 성장·보상은 1·2챕터에 연결되며, 런 중간 저장은 지원하지 않는다. 영구 프로필 저장은 아래 플레이 흐름을 따른다. 기존 숲·무기 실험과 확정 배경 공급 경로의 범위는 [코드 구조](../development/architecture/architecture.md)를 따른다.

`Tools > deviant > Game > Build Windows` 또는 `Tools > Team Playtest > Build Windows`는 공통 게임을 빌드한다. 기본 결과는 Unity 프로젝트 기준 `Builds/Windows/deviant/deviant.exe`이며 `TEAM_PLAYTEST_OUTPUT`으로 출력 폴더를 지정할 수 있다. 출력 디렉터리 전체를 동반 파일과 함께 배포한다. 모듈·리소스 준비, batch 명령과 산출물/검증 범위는 [게임 빌드·배포 준비](../development/delivery/build-and-distribution.md)를 따른다. 이전 `BuildForestWindows` 자동화 호출도 같은 게임을 빌드한다.

## Web 빌드

`Tools > deviant > Game > Build Web` 또는 batch 빌드와 브라우저 실행은 [Web 빌드 안내](../development/delivery/web-build.md)를 따른다. Unity 6000.6.5f1 Web Build Support와 고정 리소스 복원이 필요하다.

## 1챕터 플레이 빌드 흐름

`Assets/ForestCombatV2/Scenes/Chapter1Title.unity`를 열어 Play하면 타이틀에서 **시작하기**·**설정**·**종료**를 고른다. 시작하기는 밝은 인간/스케치 잉크의 반반 구도를 유지하며 1.2초 동안 암전해 검은 화면을 한 프레임 표시한 뒤 시작 마을(`Assets/Deviant/Hub/Scenes/StartingVillage.unity`)로 가며, 설정에서는 인게임과 동일한 화면·소리·조작 탭을 사용한다. 마을에서는 ←/→로 걷고 Space로 뛰며 작업대 앞에서 **F**로 화면을 연다. **Esc → 단축키**에서 이동·공격·가방 등 키보드 배치를 바꿀 수 있다. 기록 농가·우물·장인의 공방·이정표 네 곳을 이용한다. 공방의 보급·팔레트·회수 기능은 한 화면에서 고르며 기존 해금 조건을 유지한다. 도면 선택 없이 이정표에서 **F**를 누르면 오른쪽 자동 이동·화면 이탈·페이드 후 새 시드의 1챕터 랜덤 스테이지에 맨손으로 출발한다. 런에서도 A로 [맨손 전용 2타 기본 공격](../design/equipment/weapons/rules.md#맨손-기본-공격)을 사용하며 별도 특수 공격은 없다. 사망 또는 2챕터 클리어 결과의 **마을로**는 마을로 돌아온다. 마법안료·보스 첫 클리어·해금은 영구 프로필(빌드 `persistentDataPath/profile`, Editor는 `profile/editor`)에 저장된다. 체력이 0이 되면 카메라 충격과 기존 죽는 모션 뒤 화면이 서서히 검어지고, 완전 암전 후 전투가 멈추며 사망 결과(플레이 시간·처치 수)가 나온다. 세부 시간·일시정지 동작은 [공통 사망 전환](../development/presentation/ui/hud.md#사망-전환)을 따른다. 결과의 **마을로**로 마을에 돌아가 다시 출발한다. 주 경로 끝 보스방의 시계탑 집행자를 쓰러뜨리면 방 오른쪽 끝 출구가 열린다. 출구 앞 **F**로 철창 열림 연출이 끝나면 결과 화면 없이 현재 런과 장비를 이어 페이드로 2챕터 수로에 진입한다. 처음 깬 런도 같다(첫 붉은 잉크는 보스방에서 챙기고 조각으로 기록한다). 2챕터를 깨거나 사망하면 결과 뒤 마을로 돌아간다. 2챕터 결과는 1챕터와 같은 항목(런 전체 플레이 시간·처치 수, 탐험 구역, 사망이면 보스 남은 체력, 마법안료, 마을 잉크)을 보여 준다. Esc 일시정지의 **마을로**는 1·2챕터 모두 결과·정산 없이 런을 끝내고 마을로 간다. 런 중간 저장은 하지 않는다. 기준은 [런 구조의 1챕터 기준](../design/run/run-structure.md#1챕터-플레이-빌드-기준)이다.

빌드 씬 순서는 타이틀 → 시작 마을 → 1챕터 랜덤 스테이지 → 2챕터다. `Tools > deviant > Chapter1 > Create Title Scene And Build Order`가 타이틀 씬과 이 네 씬의 빌드 설정을 다시 만든다. 치트 모드 HUD·F1 패널·판정 표시는 Editor 또는 `DEVIANT_DEBUG_MENU`를 포함한 플레이어 빌드에서 표시한다. F1~F12 개발 도구, 치트 모드의 **전투 상태 초기화**는 같은 조건(`DevFeatures.Enabled`)에서만 동작한다. 포탈은 일반 배포 빌드에서도 사용하는 기능이며, 정비소 포탈 수첩을 닫은 뒤 C/V로 각각 설치·재설치하고 F로 왕복한다. 모든 플레이 데이터는 **치트 모드 → 플레이어·재화·전투 → 게임 초기화 → 확인하고 적용**으로 초기화하고 타이틀로 돌아간다. ESC 메뉴에는 초기화 버튼이 없으며 음량·단축키 설정은 유지한다. 전투 리셋은 F5 키가 아니라 치트 모드의 **전투 상태 초기화**로 하며 Editor 또는 치트 모드를 포함한 빌드에서만 쓴다. 2챕터 보스전이 시작된 뒤에는 씬을 다시 만들되 같은 런의 장비·체력·가방을 이어 받는다.

## 1챕터 랜덤 스테이지 실행

Unity **6000.6.5f1**에서 [고정 리소스 배치](../assets/README.md)를 완료하고 `Assets/MeadowDuskV3/MapVer2/Scenes/Chapter1Procedural.unity`를 열어 Play한다. `Tools > Deviant > Chapter1 > Open Random Stage`로도 연다. 팀 스케치 바닥·발판의 47개 이미지도 같은 배치 계약에 포함한다.

씬을 직접 열어 Play해도 하나의 런으로 시작한다. 플레이 중 **치트 모드 → 이동·진행 → 새 배치로 시작**을 선택하면 새 시드의 새 런으로 배치한다. **플레이어·재화·전투 → 전투 상태 초기화**는 설정 장비와 현재 맵 배치를 유지한다. M으로 전체 지도를 확인하며, 탐색한 방과 인접 길목만 공개한다. 이 공간은 방 12종 중 10종과 길목 5종을 사용하는 테스트 스테이지이며 정식 제품의 챕터 규모를 확정하지 않는다.

적은 팀의 **가시뿌리·먹빗자루·배수관 포수·우물 도르래 수문장** 콘텐츠를 사용한다. 원래 일반 몬스터 위치는 새 일반 3종으로 대응하고, 엘리트 공간에는 수문장을 배치한다. 종별 돌진·쓸기·탄환·갈고리 공격은 [마을 몬스터 시험용 정의](../development/presentation/visuals/stage1-monster-motions.md)를 따른다. 기존 6종의 그림만 교체하는 방식이 아니다. 주 경로 끝 보스방에는 시계탑 집행자를 둔다. 일반 랜덤 스테이지 보스방도 고정형 `ClockExecutionerEncounter`의 시계탑 집행자를 사용한다. 방에 들어서면 입장 연출 뒤 전투가 시작되고, HP 3,500에서 시작해 누적 피해 500(HP 3,000)에서 광폭화 포효 연출, HP 700 이하에서 광폭화 대비 1.2배 속도·공격 후 회복 및 다음 패턴 대기 제거, 처치 연출이 이어진다. `Chapter1BossEncounter`는 이 보스를 받아 처치 후 출구와 1챕터 클리어를 연결하며, 보스 보상·런 기록도 기존 경로를 그대로 쓴다. 보스 더미는 더 이상 생성하지 않는다. `Tools > Deviant > Chapter1 > Play Boss Test`로 바로 실행하거나 `Open Boss Test`로 여는 전용 시험방은 몬스터 없이 보스방 입구 앞에서 시작하고 체력·보정 수치·재시작 버튼·판정 표시를 보여 준다. 에디터 또는 치트 모드를 포함한 빌드에서 랜덤 스테이지 플레이 중 **치트 모드 → 이동·진행 → 현재 런 보스방으로 이동**을 누르면 현재 런·시드·장비·체력·적 상태를 유지한 채 보스방 안의 왼쪽 바닥으로 즉시 이동한다. 이동 속도와 진행 중 행동은 정리하고 카메라는 보스방으로 즉시 맞춘다. 방 진입 후 기존 입장 연출과 전투가 이어진다. 치트 모드에서는 일시정지·입력 차단 상태를 유지한 채 이동하며, 포탈 동작·사망·런 종료 중에는 거부한다. 일반 배포 빌드의 메뉴 포함 여부는 별도 빌드 옵션으로 선택한다. 임시 분리 이미지 구현은 새 스프라이트 모션 제작이나 전체 플레이 검증 완료를 뜻하지 않는다. 최신 공격 규칙·시간·아트 제작 범위는 [고정형 보스 제작 명세](../development/presentation/visuals/clock-executioner-sprites.md)를 따른다. 확정 291프레임은 `resources/authoring/workbench/source/MonsterReference/approved`와 Unity 적용 사본을 대조한다.

현재 씬은 기존 119장과 추가 작업본 20장을 합친 마을 이미지 139장을 공통 배치 계약으로 선택한다. 119장만 있으면 필수 지형이 빠진다. `VillagePresentation`, `VillageArtTransition`, `VillagePixelViewport`를 활성화하며 초기 화면은 스케치 모드다. 기존 충돌 구조 위에 팀 지형·건물·원경을 표시한다. F6은 외형 모드 전환, F9는 팀 원본의 좌표별 컬러/스케치 배치 전환이다. [마을·이동·포탈 이미지 안내](../assets/world/approved-traversal-and-village.md)를 따른다.

랜덤 씬의 방 기반 대기 정책은 팀 몬스터와 돌진·원거리 시제품 몬스터에도 적용한다. 플레이어가 있는 방과 그 방에서 통로로 이어진 방만 깨어 있다. 다른 방에 있는 미감지·미피격 대기 상태의 적은 무거운 AI·지형 검사를 쉬고, 분신이 있으면 쉬지 않는다. 플레이어가 통로에 있으면 그 통로가 잇는 두 방을 깨운다. 순간이동처럼 한 tick 안에 플레이어가 옮겨지면 즉시 다시 판정한다. 플레이어나 적이 어느 방 안에도 없으면 이전 거리 기준을 따른다. 이때는 플레이어에서 가로 64유닛 또는 세로 24유닛보다 먼 적이 쉰다. 처치·추격·복귀·피격 중인 적은 기존 조건을 따른다. 스케치 전용 화면에서는 투명한 컬러 지형·발판 렌더링을 끄며, 컬러 전용에서는 스케치 지형 렌더링을 끈다. 혼합·좌표별 전환 모드는 양쪽을 유지한다. 표시 최적화는 충돌·방 배치·무기 수치를 변경하지 않는다.

랜덤 스테이지의 새 런은 마을 출발이든 Editor에서 씬을 직접 연 경우든 시작방에 도면을 띄우지 않고 맨손으로 시작한다([런 시작 장비](../design/run/run-structure.md#1챕터-플레이-빌드-기준)). 시험 장비는 치트 모드의 장비 항목으로 바꾼다. 독립 전투 시험장의 검/폭탄 시작 장비와는 별개다.

주 경로 중단의 **정비소**(시작방 뒤 전투방 3~4개) 방 안에서만 가방의 잉크를 빈 슬롯에 장착할 수 있다. 장착한 잉크는 런이 끝날 때까지 해제·교체·이동할 수 없다. 방에 들어가면 화면 위쪽에 정비소 안내가 표시되고, 밖에서는 가방 확인만 가능하다. 정비소 방 안에서 **F**를 누르면 전투를 멈추고 정비소 화면을 연다(다시 F 또는 닫기로 닫는다). 시설마다 팔레트 2개(100G부터 구매마다 50G 증가, 산 상품은 판매 완료), 잉크 탭의 잉크 판매대(시설마다 등급 3~4 색상 잉크 2~3개, 등급 3 420G·등급 4 600G 고정, 산 상품은 판매 완료. 가방이 가득 차면 결제하지 않음, 구현 진행 중), 캐릭터 강화(60G부터 30G 증가)·팔레트 슬롯 강화(50G부터 25G 증가), 무기별 무기·스킬 스탬프 적용(빈 칸 첫 적용은 무료, 교체는 20G이고 기존 스탬프는 사라짐)을 이용한다. 가격 증가는 같은 런 동안 유지된다. 스탬프 탭의 버튼은 팔레트·잉크 관리의 보관함을 그 무기·스탬프 종류로 열며, 거기서 스탬프를 골라 적용한다. 무기 스탬프는 그 무기의 도면 종류와 같아야 하고 무기 형태(예: 망치 → 방패)를, 스킬 스탬프는 특수 공격의 범위·이동·후속타 변형을 바꾼다. 같은 효과의 스탬프는 다시 적용할 수 없다.

적을 처치하면 골드가 바닥에 떨어지고 닿으면 들어온다. 일반 적은 골드(6~10G)만, 엘리트(우물 도르래 수문장)는 200~280G와 색상 잉크·스탬프 1개를, 보스는 600~720G와 스탬프 1개를 떨어뜨리고 보스 뒤 제단에서 색상 잉크를 고른다. 가방 잉크(형태·특수 공격 잉크)는 떨어지지 않는다. 팔레트는 도면을 장착할 때 무기마다 하나씩 함께 장착되며 드롭·구매하지 않는다. 스탬프는 색상 잉크와 같은 보관함에 들어가며, 무기 스탬프는 시작방에서 고른 도면 종류(검·둔기·원거리)의 다른 형태로만 나온다. 수치는 1차 시험값이다.

상하 직결과 통로 블록은 각 층에 일방향 발판이 있어 2단 점프로 오르고 아래+Space로 한 층씩 내려간다. 벽타기 통로(위·아래만 열린 통로 블록)는 점프한 뒤 벽에서 **↑를 누르고 있을 때만 붙어서 기어오르고, 놓으면 바로 떨어진다.** ↑ 없이 닿기만 해서는 붙거나 미끄러지지 않으며 정지 매달림이나 별도 잡기 키도 없다. **벽 차기는 ↑를 유지하면서 Space를 새로 눌렀을 때만** 실행하고, 일반 점프 횟수를 쓰지 않는다. ↑ 없는 Space는 일반 점프다. 예약 입력과 벽 이탈 직후의 유예도 ↑ 조건을 우회하지 않으며, ↑를 놓으면 예약을 취소한다. 맞은편 벽에 닿았을 때도 ↑가 있으면 바로 오르고 없으면 붙지 않는다. 일반 점프로 상승하며 벽·턱을 지날 때는 ↑가 없으면 상승 운동을 끊지 않는다. 벽 스태미나는 오르기 시간으로 벽마다 1초이며, 소진하면 낙하하고 다른 벽이나 착지로 회복한다. 자세한 수치는 [전투 규칙](../design/combat/rules.md)의 벽타기·벽점프 항목을 따른다. 상하 통로의 폭은 6칸이고 방 사이 직결은 문 사이 6칸이다([방·통로 공통 규격](../design/world/room-corridor-standard.md)). S는 무기 2 기본공격이며 Q/W는 무기 1/2 스킬이다.

1·2챕터 방 원형의 지형·발판·몬스터는 `data/map/block_rooms.json`에서 수정하고 `node tools/map/export_block_rooms.cjs`로 Unity에 반영한다([블록 맵](../development/gameplay/world/block-map.md)).

## 들판 몬스터 이펙트·배치 테스트

`Assets/MeadowDuskV3/Scenes/Chapter1MeadowCombat.unity`는 들쥐의 찌르기, 두더지의 바닥 충격, 멧돼지의 뒷발 흙먼지·실제 프레임 잔상을 사용한다. 새 이펙트는 기존 공격 시계를 관찰하며 피해·공격 모션·돌진 거리를 변경하지 않는다.

- Play 중 **F4 → 종 선택 → 클릭 배치 시작 → 바닥 위 클릭**으로 몬스터를 추가한다. 들쥐·두더지·멧돼지 외에 허수아비·짚단·두레박도 선택할 수 있다. 배치 장소는 몸 전체를 지지하는 평평한 바닥이어야 한다.
- **선택한 몬스터만 · 플레이어 앞에 배치**는 유효한 배치를 확인한 뒤 기존 테스트 몬스터를 교체한다. 새 몬스터는 AI 정지 상태다. **F1 → 적 AI 시작**으로 공격을 확인한다.
- F5는 현재 배치된 적을 각자의 배치 위치에 되살리고 이펙트를 초기화한다. F4의 모두 지우기는 테스트 적만 제거한다. 플레이 중 추가·삭제는 씬 파일에 저장되지 않는다.
- 편집 모드에서 `Tools > Deviant > Meadow Dusk > Select Monster Placement Settings`를 선택한다. Inspector의 **Use Custom Placements**를 켜고 **Placements**에 종과 발 위치(Unity 월드 좌표)를 지정한다. Scene 뷰 위치 핸들로 이동하고 씬을 저장한다. 빈 목록은 적 없이 시작하며, 옵션을 끄면 기본 맵 배치를 사용한다. 목록 변경은 다음 Play부터 적용한다.

## 타격감 기능 플레이 빌드

`Tools > deviant > Presentation > Build Hit Feedback Linux Playtest` 또는 같은 메뉴의 Windows Playtest를 사용한다. Unity **6000.6.5f1**에서만 만들며, `HitFeedbackPlaytestBuilder`가 승인 이미지·시간 원본과 로컬 VFX/분할 바인딩을 확인한다. CLI의 `-hitFeedbackOutput <폴더>`로 산출물 위치를 지정할 수 있다.

이 빌드는 현재 게임과 같은 `Chapter1Title` → `Chapter1Procedural` 두 씬을 사용한다. 타이틀에서 새 게임을 시작해 도면을 고르고 실제 몬스터를 타격한다. 이전 숲·들판 씬 원문은 회귀 검사에만 사용하며 Assets에 다시 생성하지 않는다. [마을 전체 이미지](../assets/world/approved-traversal-and-village.md)도 빌드 전에 복원한다.

A/S 슬롯별 기본 공격·Q/W 슬롯별 스킬·X 무기 순서 교환·Space 점프·Shift 대시를 사용한다. 장비 편집은 **치트 모드 → 장비·잉크**를 사용한다. **F1**의 명중·화면 효과 설정은 **명중 VFX·명중 흰 점멸·시체 물리 파편·명중 카메라 반응·명중 화면 왜곡·플레이어 사망 슬로우**를 각각 켜고 끈다. 같은 패널에서 명중 VFX 크기도 막대로 바꿔 볼 수 있다. 기본은 모두 켜짐이며 전투 리셋은 선택을 유지한다. VFX를 꺼도 왜곡과 카메라는 독립적으로 사용할 수 있다. 끈 효과는 즉시 정리하고 다시 켜도 이전 타격·죽음을 재생하지 않는다. **F6/F7/F8**의 기존 피격·검/채찍 궤적·처치 비교, 강도, 선택적 히트스톱도 유지한다. 몬스터 명중 그림은 도트 타격과 종이 화풍 프리팹(평소 무작위, 치명타는 큰 둥근 고리)이며 바꾸는 키는 없다. **F1 → 명중 VFX 외곽선 설정**에서 `#RRGGBB` 색상 코드(기본 짙은 회색 `#1A1A1A`)를 적용한다. 안티앨리어싱은 사용하지 않는다. 현재 효과에도 즉시 반영하며 F5는 설정을 유지한다. **외곽선 기본값 복원**은 표현 원본값으로 돌아간다. 종이 화풍에서 사용하는 출력 설정이며 새 씬에서는 기본값으로 시작한다. **F12**는 마을 몬스터가 공격 전에 준비 자세를 유지하는 시간을 +0~+0.6초로 바꿔 비교한다(개발 빌드). 동시 왜곡 파동은 최대 4개이고 슬로우는 플레이어 사망에만 발동한다. 큰 카메라 킥의 강타 목록은 아직 미정이다. 실행 파일과 동반 `_Data`·Player 지원 파일을 한 폴더에 유지한다.

빌드 전용 검사는 실행 파일에 `--verify-feedback-build <보고서 폴더>`를 전달한다. 지정된 경우에만 자동 타격·왜곡 요청·그래픽 장치가 있는 경우 실제 왜곡 패스·실제 죽음 후 파편·플레이어 사망 슬로우와 시간 복구를 검사하고 종료한다. 일반 실행에서는 이 자동 검사를 만들거나 입력을 주입하지 않는다. 실행 확인은 전체 게임 플레이/밸런스 검증과 구분한다.

## 시작하기

1. [에셋 복원 안내](../assets/README.md)에 따라 `에셋 업데이트.bat`으로 현재 공유 이미지를 적용한다. 기본 숲·R16 이미지도 이 목록에 포함되며, 제작 ZIP의 옛 숲 실행 빌드는 R16 빌드로 사용하지 않는다.
2. Unity Hub에서 `unity`를 프로젝트 지정 버전 **6000.6.5f1**로 연다. 패키지 가져오기와 컴파일을 완료한다.
3. `Assets/Deviant/Combat/Scenes/CombatV2Arena.unity`를 열고 Play를 누른다. 지형·캐릭터·적·카메라는 실행 시 생성되므로 편집 모드에 루트만 보일 수 있다.
4. 시작 장비는 **검 / 폭탄**이다. A/S·Q/W로 두 무기의 기본·스킬을 직접 요청한다. F1 또는 우측 상단 버튼에서 슬롯1/2별10형태, 미장착/범위/이동/후속타, 능력치5칸을 선택한다.
5. 적 AI는 기본 정지다. 장비 변경은 **AI 정지·현재 동작 종료 상태**에서 가능하다. `적 AI 시작`으로 전투하고 F2로 판정을 표시한다. HP와 두 무기 쿨타임은 패널을 닫아도 표시한다.

## 수동 실행에서 볼 것

지형·캐릭터·HUD가 표시되고 이동·점프·대시·공격·교체가 동작하는지 확인한다. 실제 HP 변화, 무기 이름, F1 장비 패널, F2 판정, ESC 정지·복귀를 확인하고 재생 중 첫 예외가 없는지 본다. 들쥐 씬은 G로 AI를 시작·정지하고 벽·감지 차폐·피격·복귀 범위를 별도로 확인한다.

마을 화면은 960×540 내부 해상도를 창 중앙에 맞춰 표시한다. F2 판정 박스·투사체 범위·적 체력바·도면 및 시설 안내도 같은 화면 배치 좌표를 사용하며, 창 크기를 바꾸면 함께 정렬된다. F4 몬스터 배치는 화면 여백을 제외한 게임 영역에서만 가능하다.


이미지 누락 상태에서 Play가 켜진 것만으로 정상 실행을 완료 처리하지 않는다. 수동 확인은 자동 테스트 전체 통과를 뜻하지 않으며, 시험장 리셋은 제품 저장·보상·전체 런 검증이 아니다.

## 수동 체크포인트

땅·발판 위에서 대기하거나 걸을 때 **C**로 1번 포탈, **V**로 2번 포탈을 설치하고, 둘을 세운 뒤 가까이에서 **F**로 반대편에 건너간다. 공격·대시·점프·벽타기·피격 중에는 사용할 수 없으며, 적이 주변에 있는 것은 제한하지 않는다. C/V를 다시 누르면 해당 번호의 포탈만 현재 위치에 재설치한다. 설치 2초·진입 0.64초 동안 맞으면 취소되고, 반대편 이동이 확정된 뒤 출현 0.8초 동안은 무적이다. 조작은 각 연출 완료 후 돌아온다. 반복 귀환에 비용·쿨타임은 없으며 체력이나 적은 리셋하지 않는다. 사망·전투 상태 초기화·새 런·새 맵에서는 포탈이 사라진다. 확정된 그리기·맨손 걷기·점프와 분리된 포탈 효과를 사용한다. 이동용 참고 영상의 좌표는 실제 캐릭터 이동에 적용하지 않는다.

F1 패널의 **이동속도 (유닛/초)**에 숫자를 입력하고 **이동속도 적용 · 전투 리셋**을 누르면 현재 플레이의 이동속도를 변경한다. 기본값은 7.5유닛/초이며 대시·점프 설정은 유지한다. 적용 시 F5와 같은 전투 리셋이 발생하며, 플레이를 종료하고 다시 실행하면 기본값으로 돌아온다.

벽타기는 연결된 수직 벽면의 높이가 캐릭터 충돌 높이(현재 2유닛)를 초과할 때만 가능하다. 높이 이하의 낮은 벽은 붙잡기·벽점프 예약 대상에서 제외하며, 일반 점프로 넘어간다. 세로로 이어진 같은 벽면의 지형 조각은 합산한다.

하강은 `↓+Space`다. `S`는 무기 2 기본공격이라 하강에 쓰지 않으며, 단축키 화면에서도 아래 방향과 겹쳐 지정할 수 없다.
