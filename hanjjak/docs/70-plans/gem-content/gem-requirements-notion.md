# 1. 기능

## 1.1 기능 개요

보석 콘텐츠는 메인 스테이지 3-1부터 열리는 계정 성장 시스템이다. 플레이어는 일일 보석 던전에서 보석함을 획득하고, 보석함 개봉과 합성을 통해 보석을 성장시킨다. 획득한 보석은 메인 스테이지와 보스 유형별 프리셋에 장착해 공격력, 최대 HP, 방어 관통, 치명타 확률과 공격속도를 강화할 수 있다.

보석은 거래할 수 있지만 보석함은 계정에 귀속된다. 장착·잠금·거래 등록 상태는 합성과 판매 가능 여부에 영향을 준다.

## 1.2 기능 요약

| 기능 | 요약 |
| --- | --- |
| 콘텐츠 해금 | 메인 스테이지 3-1 해금 시 보석 콘텐츠, 프리셋 4개와 보석 던전을 함께 연다. |
| 프리셋 | 메인 스테이지·생존형·폭주형·장갑형별 6슬롯 프리셋을 제공한다. |
| 장착 | 옵션 종류와 관계없이 모든 슬롯에 장착할 수 있고 같은 보석을 여러 프리셋에 등록할 수 있다. |
| 전투 반영 | 메인 전투에는 메인 프리셋, 보석 던전에는 그날 보스와 일치하는 프리셋을 적용한다. |
| 보석 레벨 | 보석은 1~7레벨로 구성한다. |
| 합성 | 같은 레벨 보석 3개를 소비해 다음 레벨 보석 1개를 만든다. |
| 보석함 | 보석함 한 개를 열면 1~3레벨 보석 한 개를 지급한다. |
| 잠금 | 특수 옵션 보석은 자동 잠금하며 사용자가 직접 잠금 또는 잠금 해제할 수 있다. |
| 거래 | 보석은 거래할 수 있고 보석함은 거래할 수 없다. |
| 인벤토리 | 일반 아이템과 보석이 고정 200슬롯 계정 인벤토리를 공유한다. |
| 입장권 | 최초 3장, 서버 실제 경과시간 8시간마다 1장, 최대 3장을 제공한다. |
| 일일 보스 | 생존형 → 폭주형 → 장갑형을 KST 기준 3일 주기로 순환한다. |
| 단계 진행 | 보스별 1~10단계를 독립적으로 진행한다. |
| 최초 클리어 | 보스·단계별 최초 클리어 보상은 한 번만 지급한다. |
| 소탕 | 오늘 보스의 최고 클리어 단계만 1회·지정 횟수·전체 소탕할 수 있다. |
| 안정성 | 소비·추첨·지급·진행 변경을 원자적으로 처리하고 동일 요청의 중복 적용을 막는다. |

## 1.3 핵심 사용자 흐름

```text
메인 스테이지 3-1 해금
→ 보석 콘텐츠·프리셋 4개·보석 던전 활성화
→ 오늘의 보스와 입장권 확인
→ 보스 프리셋 편집
→ 신규 단계 도전 또는 최고 클리어 단계 소탕
→ 보석함 획득
→ 보석함 개봉
→ 보석 확인·잠금·프리셋 장착
→ 같은 레벨 보석 수동 또는 일괄 합성
→ 메인 스테이지와 보석 던전에 보석 효과 적용
→ 필요하면 모든 프리셋과 잠금을 직접 해제한 뒤 거래소에 판매 등록
```

## 1.4 플레이어 가치

- 일일 던전과 입장권 충전으로 반복 가능한 성장 목표를 제공한다.
- 보스 유형별 프리셋으로 생존, 공격 성능과 방어 관통을 선택적으로 강화할 수 있다.
- 낮은 레벨 보석도 합성해 상위 보석으로 전환할 수 있다.
- 특수 옵션 자동 잠금으로 희귀 보석의 실수 합성을 방지한다.
- 원하는 옵션이 아닌 보석은 거래소를 통해 다른 성장 자원으로 전환할 수 있다.

# 2. 요구사항

## 2.1 범위

### 2.1.1 포함 범위

- 보석 콘텐츠 해금과 초기 상태
- 보석 보유·장착·교체·해제·잠금
- 프리셋 4개와 전투 스탯 반영
- 보석함 개봉과 보석 지급
- 수동·일괄 합성
- 입장권 충전·보유·소비
- 일일 보스 순환과 단계 진행
- 최초 클리어와 소탕 보상
- 보석 거래와 보석함 거래 제한
- 고정 200슬롯 계정 인벤토리 연계
- 원자성·멱등성·오류 처리
- 클라이언트와 서버 사이의 필요 API 목록

### 2.1.2 제외 범위

- 보석 던전 보스의 절대 HP·공격력·방어력·패턴 시간
- 보석을 포함한 메인 스테이지 3-1~4-10 적 수치
- 장기 성장 분포 시뮬레이션
- 실제 UI 배치와 접근성 상세안
- 운영 배포·모니터링·어드민 도구
- API 요청·응답 DTO, HTTP 상태와 오류 코드 상세 계약

| 용어 | 설명 |

| 특수 옵션 | 같은 종류에서는 가장 높은 값 하나만 적용하는 옵션 |
| 입장권 | 보석 던전 성공 보상 또는 소탕 보상을 받을 때 소비하는 자원 |

| 멱등 요청 | 같은 요청을 재전송해도 소비나 지급이 중복되지 않는 요청 |

## 2.4 보석 보유·프리셋·잠금

| ID | 요구사항 | 검증 기준 |
| --- | --- | --- |
| GEM-SLOT-001 | 메인 스테이지·생존형·폭주형·장갑형별로 독립된 6슬롯 프리셋을 둔다. | 네 프리셋과 각 6개 슬롯을 조회할 수 있다. |

| GEM-SLOT-003 | 같은 보석 인스턴스를 여러 프리셋에 등록할 수 있다. | 복수 프리셋에 등록해도 보석 수량은 복제되지 않는다. |
| GEM-SLOT-004 | 메인 전투에는 메인 프리셋, 보석 던전에는 오늘 보스와 일치하는 프리셋을 적용한다. | 해당 콘텐츠 프리셋의 보석만 전투 스탯에 반영된다. |
| GEM-SLOT-005 | 장착 교체는 소유권·잠금·거래 상태를 확인한 뒤 원자적으로 처리한다. | 실패하면 기존 프리셋과 보유 상태가 유지된다. |
| GEM-SLOT-006 | 장착 해제는 해당 프리셋의 참조만 제거한다. | 한 프리셋에서 해제해도 다른 프리셋 등록은 유지된다. |
| GEM-SLOT-007 | 어느 프리셋에든 등록된 보석은 모든 프리셋에서 해제하기 전까지 합성·거래 등록할 수 없다. | 하나의 프리셋에라도 남아 있으면 요청이 실패한다. |
| GEM-SLOT-008 | 메인 프리셋은 언제든 변경할 수 있다. 진행 중 변경하면 현재 전투를 종료하고 현재 스테이지 일반 몬스터 0/20부터 초기 상태로 다시 시작한다. | 일반·보스 전투 중 변경 모두 재시작하며 이미 받은 보상은 유지한다. |
| GEM-SLOT-009 | 오늘 보스 프리셋은 도전 시작 전까지 변경할 수 있고, 도전 종료 전까지 변경할 수 없다. | 도전 중 변경 요청은 실패하며 시작 시점 구성을 적용한다. |
| GEM-SLOT-010 | 거래 등록 중이 아닌 소유 보석을 개별 잠금·해제할 수 있다. | 타 계정 또는 거래 등록 중 보석의 잠금 변경은 실패한다. |
| GEM-SLOT-011 | 잠긴 보석은 장착할 수 있지만 합성·거래 등록할 수 없다. | 잠긴 보석의 장착은 성공하고 소비·판매 요청은 실패한다. |
| GEM-SLOT-012 | 고정 공격력·고정 최대 HP 보석은 미잠금, 특수 옵션 보석은 잠금 상태로 지급한다. | 모든 획득 경로에서 옵션 계열별 초기 잠금 상태가 일치한다. |
| GEM-SLOT-013 | 자동 잠금된 특수 옵션 보석도 사용자가 직접 잠금 해제할 수 있다. | 해제 후 미장착·미판매 상태이면 합성·거래 등록할 수 있다. |

## 2.6 보석함 개봉

| ID | 요구사항 | 검증 기준 |
| --- | --- | --- |
| GEM-BOX-001 | 보석함은 거래할 수 없는 계정 귀속 자원이다. | 거래 등록 요청이 실패한다. |
| GEM-BOX-002 | 1개, 보유 수량 이내의 지정 수량 또는 전체 개봉을 지원한다. | 0개·초과 수량은 상태 변경 없이 실패한다. |
| GEM-BOX-003 | 선택한 보석함 전체 소비와 결과 보석 전체 지급을 원자적으로 처리한다. | 일부 소비·일부 지급·중복 지급이 발생하지 않는다. |
| GEM-BOX-004 | 여러 개를 열면 보석함마다 레벨과 옵션을 독립 추첨하고 결과 목록을 한 번에 반환한다. | 요청 수량과 결과 수량이 같고 각 결과를 재현할 수 있다. |
| GEM-BOX-005 | 결과 레벨과 옵션 풀은 적용 중인 콘텐츠 버전을 따른다. | 고정 seed의 결과가 콘텐츠 데이터와 일치한다. |

## 2.15 오류 처리

다음 요청은 상태 변경 없이 실패해야 한다.

- 해금 전 장착·합성·던전·소탕 요청
- 보유하지 않은 보석 또는 타 계정 보석 사용
- 장착·잠금·거래 등록 중 보석의 합성·판매
- 거래 등록 중 보석의 잠금 변경
- 입장권이 부족한 성공 보상 확정 또는 소탕
- 알 수 없거나 누락된 콘텐츠 버전 사용
- 진행 중 던전의 해당 보스 프리셋 변경
- 보석함 개봉·합성에 필요한 슬롯 부족
- 보석함 스택 지급 권리와 예약할 빈 슬롯이 모두 없는 상태의 던전 시작

실패 응답은 클라이언트가 재시도 가능 여부를 구분할 수 있는 원인 코드를 포함해야 한다.

## 2.16 인수 기준

1. 해금 전에는 보석 UI와 던전에 접근할 수 없다.
2. 3-1 해금 시 프리셋 4개와 던전이 열리고 입장권 3장이 한 번만 지급된다.
3. 오늘 보스 1단계를 정상 성장 무보석 빌드로 클리어할 수 있다.
4. 성공 시 입장권, 보상, 보스 진행과 최초 보상 상태가 함께 확정된다.
5. 보석함 1개·지정 수량·전체 개봉이 선택 수량만 처리한다.
6. 같은 레벨 보석 수동·일괄 합성이 입력 전체 소비와 결과 전체 지급으로 완료된다.
7. 메인 프리셋 변경 시 현재 스테이지 일반 몬스터 0/20부터 초기 상태로 재시작한다.
8. 던전 도전 중 보스 프리셋을 변경할 수 없다.
9. 자정 전에 시작한 도전은 시작 스냅샷으로 종료하고 다음 요청부터 새 날짜를 적용한다.
10. 최고 클리어 단계만 1회·지정 횟수·전체 소탕할 수 있다.
11. 실패·중단·앱 종료·연결 끊김은 입장권과 보상을 바꾸지 않는다.
12. 보석은 거래할 수 있고 보석함은 거래할 수 없다.
13. 같은 요청을 재시도해도 소비와 지급이 중복되지 않는다.
14. 기존 보석함 스택이 도전 중 0개가 되어도 성공 보상 슬롯이 유지된다.
