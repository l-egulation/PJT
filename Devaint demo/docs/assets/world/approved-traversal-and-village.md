# 마을·벽 이동·점프·포탈 이미지

[분야 개요](README.md)

현재 `Chapter1Procedural`의 마을 이미지 139장과 벽 접촉·벽차기·무기별 점프·포탈 290프레임은 모두 [공통 리소스 배치](../README.md)에 포함한다. 별도 입력 파일을 선택하거나 아트 가져오기 도구로 게임 시간표를 다시 생성하지 않는다.

```sh
python3 tools/assets/update_assets.py --check
python3 tools/assets/update_assets.py
```

마을 배경은 기존 119장과 추가 작업본 20장을 함께 사용한다. 119장만 배치하면 필수 밝은 지형이 빠진다. 픽셀·투명 캔버스·접촉선·Unity GUID는 유지한다. 배포와 최종 미술 승인은 별개다.

벽 이동과 포탈은 원본 이미지 또는 JSON 내장 PNG를 그대로 사용한다. 무기별 점프 프레임 중 검·채찍 외 11종은 점프 높이 변화가 그림에 그려져 있어 물리 점프와 겹쳐 끊겨 보였다. PNG는 그대로 두고 메인의 `.meta` 피벗을 프레임별로 그 높이만큼 올려 발을 검과 같은 선에 고정한다(`python tools/combat/pin_jump_feet.py`, 검사 `--check`). 공중 프레임에서 발을 약 3px 접는 검 자세는 유지한다. 시작 마을의 맨손·오프닝 인간 몸체도 같은 도구로 점프·낙하 그림에 들어 있는 높이 이동을 제거하며 자연스러운 발 접힘 0~3px만 남긴다. 착지 시간은 유지하고 웅크림→일어서기(`fall-land/F06`, `F09`, `F12`)를 모두 연결한 뒤 대기로 돌아간다. 몸체 프레임과 시간표의 원본은 `data/story/hero_bodies.json`, Unity 생성본은 `HubBodies.json`이다. 13종 무기 점프, 설치 몸체·생성 효과·소멸 B 효과와 맨손 걷기·점프를 분리한다. 게임 이동량·피격 취소·무적·귀환 정책·단계 시간은 기존 `data/combat/`와 [런 규칙](../../design/run/run-structure.md)이 소유한다.

Unity **6000.6.5f1**에서 현재 씬의 이미지 로딩·좌우 방향·벽 이동·포탈 상태 전환을 확인한다. `Chapter1ApprovedArtTests`, `Chapter1ManualCheckpointTests`, `Chapter1WallTraversalTests`의 게임 검증과 원본 파일 검사를 구분한다.

새 잉크·인간 벽타기 그림은 `data/assets/wall_climb_visuals.json`과 Unity의 `ApprovedTraversal/ClimbV4.json`에 연결한다. 손을 빠르게 붙이는 시작 부분 뒤 등반 부분을 반복하고, 벽차기는 기존 그림을 사용한다. 등반 그림의 오른쪽 손 접촉선은 원본 캔버스의 x=276px(`contactX`)다. 각 프레임의 승인 피벗·PPU로 이 선을 기존 충돌 몸체의 벽 쪽 가장자리에 맞추며, 물리 몸체나 이동 수치는 바꾸지 않는다. 인간 벽차기의 가져오기 설정은 main의 승인 메타(29.5 PPU)를 유지한다. 자동 생성된 100 PPU·중앙 피벗 메타로 대체하면 벽차기 순간 몸체가 작아지고 위치가 어긋난다.

벽타기 시작·반복 그림은 표시 배율 `bodyScale=1.08`로 기본 몸체와 크기를 맞춘다. 벽 끝 마무리도 `ledgeEndScale=1.08`로 같은 배율을 유지한다. 벽 그림 82장은 프레임별 PPU 로 머리 크기가 이미 같아서(머리카락 높이 0.557 유닛, 대기 0.56~0.59), 일어선 그림의 짧은 키에 맞춰 키우면 마지막에 몸이 커졌다가 대기로 돌아갈 때 줄어든다. 발을 기준으로 확대하고 손 접촉선 계산에 표시 배율을 반영한다. 지면에 닿은 마무리는 발을 물리 지면에 내려놓고, 벽차기·일반 점프로 전환하면 전용 표시 배율을 해제한다. 원본 PNG와 승인 PPU·피벗·충돌 크기·점프 수치는 유지한다.

벽 끝 올라서기의 표시 상태는 재생 시간이 끝났다는 이유만으로 해제하지 않는다. 물리 모터가 실제 윗면으로 이동을 확정하거나 피격 등으로 중단할 때까지 벽 모서리에 붙인 마지막 자세를 유지한다. 올라가는 동안과 완료 직후 첫 표시에서는 일반 이동 보간을 적용하지 않고 위치 이력을 현재 몸 위치로 맞춰, 윗면의 일반 자세가 직전 벽 아래 위치로 되돌아 보이지 않게 한다. 다음 표시부터 일반 보간을 재개한다.
