반복·회전 설정

간격을 짧게 하면 소리가 겹칩니다. 회전음은 반복 소스에 좌우 이동과 주기적인 음량 변화를 줍니다. 끝 피치 변화는 첫 반복부터 마지막 반복까지 적용됩니다.

피치와 소리 속도는 따로 조절됩니다. 짧은 구간을 크게 늘리면 떨림이 생길 수 있으니 모션과 함께 들어보세요.
사용 방법 · 저장과 미리보기 범위

① 왼쪽에서 무기·공격 선택 → ② 아래 파형에서 구간 선택 → ③ ‘타격마다 배치’ 또는 ‘선택 구간 배치’ → ④ 오른쪽에서 각 소리의 피치·속도·음량 조절 → ⑤ 재생하며 확인합니다.

회전음은 ‘회전음 프리셋’으로 시작해 간격·유지 시간·좌우 회전·음량 물결을 조절하세요. 모션을 바꾸지 않고 음향을 시험합니다. 프리셋은 제작 시작점이며 확정 음향이 아닙니다.

오디오·승인 프레임·게임 기본 시간표를 HTML에 내장했습니다. 인터넷 없이 동작합니다. 각 공격의 작업은 자동 저장되고 JSON으로 주고받을 수 있습니다. ‘작업 HTML 저장’은 현재 설정까지 담은 사본을 만듭니다. WAV는 48kHz 스테레오 PCM16이며 청취 볼륨은 파일에 적용하지 않습니다. 출력이 넘치는 경우 미리듣기와 WAV에 같은 자동 감쇠를 적용합니다.

기본공격은 최단 연계 기준입니다. 특수공격은 현재 게임이 재사용하는 본체 모션을 같은 접촉·종료 시간에 맞춰 표시합니다. 비행·착탄·게임 이동·히트스톱·전용 특수 이펙트·임시 시험장 슬라이더는 재현하지 않습니다. 회전 이펙트를 새로 확정하지 않습니다. 실제 게임의 오디오 사건 연결·믹싱과는 별도 제작 도구입니다.
