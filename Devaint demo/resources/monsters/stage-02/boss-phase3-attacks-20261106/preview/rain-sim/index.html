화살비 · 실제 연출과 함께 보기

사용자 확정: A-x2 (앞부분 2배속). 게임용 결과는 runtime/rain-a-x2. Unity 적용 전입니다.

몸 동작 A·B를 게임의 화살비 시간표와 같은 시계로 재생합니다. 0초 시작 쪽 경고 → 0.5초부터 12발이 1.5/11초 간격으로 전장 위에서 0.25초 동안 떨어져 바닥에 박힘 → 2.45초부터 같은 순서로 폭 2.5·높이 15유닛 기둥 폭발(마지막 3.95초).

에셋 합성 미리보기입니다. 화살과 폭발 기둥은 확정 VFX 시트(p3-arrow-flight, p3-pillar) 그대로이고 32px=1유닛, 전장 30유닛=화면 960px입니다. 시작 쪽 경고는 게임의 절차 생성 빛을 비슷하게 그린 것입니다. 보스 위치는 예시이며 Unity 화면이 아닙니다.
