# 덧베기 이펙트 시험판

빨강 잉크 `ink2_red_01` 덧베기(몬스터 적중 시 원공격 피해 20%의 추가타 1회)가 들어갈 때 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다.

[표식 격발](../표식격발/README.md)과 같은 잉크 농도장 방식의 [pixelfx](https://github.com/patch-gg/pixelfx)(MIT) 이펙트다. 튀김 없이 몸보다 긴 얇은 일직선(약 94px) 하나만 쓴다. 덩어리를 더하지 않고 화소마다 선까지의 거리를 재서 칠해, 가운데 흰 심에서 빨강, 반투명 번짐으로 매끄럽게 이어지고 양끝은 바늘처럼 길게 빠진다. 위쪽 가장자리는 날카롭고, 아래쪽은 결이 진 채 흐리게 풀린다(빛나는 칼자국 참고 이미지 방향). 종이색 배경에서는 더하는 빛이 보이지 않아 번짐을 반투명 색으로 칠한다. 접촉 장에 60% 그어져 있고 다음 장에 끝까지 그어진 뒤, 그은 방향대로 꼬리부터 지워진다. 0.24초.

- `follow-cut.js`: 이펙트. 옵션 `palette`, `dir`(1이면 오른쪽으로 맞음), `tilt`(칼자국 기울기 rad, 기본 -0.45 = 맞은 쪽으로 올려 긋기), 번짐 픽셀은 반투명이라 시트 PNG 알파가 0~1 사이 값을 갖는다.
- `export.mjs`: 각도가 조금씩 다른 세 판을 뽑는다. 결과는 Git 제외 `outputs/pixelfx/follow-cut/follow-cut_red_v<1~3>.png/json`.

```sh
node 전투테스트/덧베기/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- 한 장 160×120, 25fps, 7장(0.24초, 마지막 장은 빈 장). 피벗 (80, 64) = 맞은 몬스터의 몸통 가운데. PPU32 게임 화소 1:1.
- 0장이 추가타 접촉 장이다. 원타격 뒤 언제 추가타가 들어가는지는 데이터에 없다(미정). 미리보기는 0.1초 뒤로 가정했다.
- 피격 멈춤은 걸지 않는 것을 전제로 했다(검 1·2타처럼 이어지는 작은 타격).
- 오른쪽으로 맞는 판만 뽑는다. 왼쪽으로 맞으면 시트를 좌우 반전한다. 연달아 맞을 때 v1~v3을 돌려 쓰면 같은 각도가 반복되지 않는다.

## 확인한 범위

1스테이지 실제 게임 캡처(가시뿌리를 때리기 전·맞는 순간·맞은 뒤) 위에서 기본 공격 세 번에 각각 0.1초 뒤 덧베기를 겹쳐 렌더링으로만 봤다. Unity 실행·다른 몬스터·추가타 연쇄는 확인하지 않았다.
