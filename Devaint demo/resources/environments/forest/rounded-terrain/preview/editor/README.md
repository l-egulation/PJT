# 1챕터 숲 맵 편집기

`맵 편집기.html`을 다운로드한 뒤 브라우저로 엽니다. 필요한 이미지 9장과 코드가 들어 있는 단일 HTML이라 이미지 복원·Drive·서버·설치가 필요 없습니다. 이 내부 설계 도구의 휴대성을 위해 사용할 이미지 사본을 HTML에 포함하며 별도 PNG나 ZIP은 Git에 추가하지 않습니다.

사용자는 [안내사항.txt](안내사항.txt)를 읽고 시작합니다. 지형과 배치는 **전체 맵 JSON 저장**으로 저장하며, 팀원에게 **HTML과 JSON을 함께** 전달합니다. HTML 파일 자체가 저장 버튼으로 변경되지는 않습니다. 자동 저장은 현재 브라우저에만 남습니다.

## 편집 범위

- 지형: 32px 격자 칠하기·지우기·사각형 채우기/지우기, 1·3·5·9칸 붓.
- 새 지형 타일 자동 연결: 노출 상단은 두꺼운 잎층의 잔디+흙, 옆면·밑면은 흙, 내부는 새 그림과 같은 무늬 없는 짙은 흑갈색입니다. 잔디는 착지선 아래로 겹겹이 내려와 둥근 끝을 감싸며, 돌·뿌리 질감은 가장자리에서 내부로 갈수록 사라집니다.
- 볼록·오목 모서리를 픽셀 단위로 둥글게 연결하고, 한 칸 폭의 천장 끝은 얕은 둥근 끝으로 표시합니다. 지형을 편집하면 주변 연결도 함께 갱신됩니다.
- 고체 발판은 두꺼운 흙층, 통과형은 나무살·뿌리 전용 이미지로 표시합니다. 두 종류 모두 원본 픽셀 크기로 양끝과 중간을 조립합니다.
- 부분 스케치는 새 상단 잎에 종이색 필터를 적용하며 흙 내부와 지형 점유 상태는 유지합니다.
- 발판·보스·상점·몬스터·트램펄린 등 별도 배치 영역 이동·크기 변경·추가·삭제.
- 지형과 배치를 묶은 되돌리기·다시 실행·JSON 저장/불러오기·자동 저장.
- 기존 배치 전용 JSON을 불러오면 현재 지형을 유지하고 배치만 불러오기.

24개 연결 공간의 지형 설계 도구입니다. 보상·잠금 규칙이나 실제 점프·전투를 구현하지 않습니다. 캐릭터는 기존 PNG와 대기 모션 타이밍을 사용한 크기 비교용입니다. JSON이 실제 Unity 씬에 자동 반영되지 않습니다.

## 파일 구성과 재생성

`index.html`은 개발용 템플릿, `editor/`는 UI·지형·배치 편집 소스, `data/`는 기준 맵·추천 배치·타일 연결 규칙입니다. 일반 사용자는 단일 `맵 편집기.html`만 열면 됩니다.

`editor/tile-art.js`는 현재 지형 점유와 5×5 이웃을 읽어 새 256×256 지형 시트 및 512×64 발판 두 장을 조립합니다. 바깥 모서리 64×96px와 안쪽 모서리 128×128px는 잎·뿌리·돌이 연결된 별도 그림이며, 여러 32px 셀에 걸쳐 원본 크기로 표시합니다. 안쪽 모서리의 진입부는 직선 그림과 겹쳐 연결합니다. 내부는 지형 그림과 같은 짙은 흑갈색인 `#241f1d` 단색이고, 뿌리는 가늘어지는 끝과 투명 여백을 통해 내부로 이어집니다. 위가 덮인 천장은 흙 그림을 사용합니다. 한 칸 계단은 큰 안쪽 패치를 생략하며, 더 높은 계단에서도 윗잔디를 안쪽 패치로 덮지 않습니다. 흙 질감은 안쪽으로 갈수록 대표 흙색으로 정리합니다. 모서리 반경은 14px이며, 위쪽에만 연결된 한 칸 끝은 높이 24px·반경 16px로 표시합니다. 이것은 그림의 윤곽 처리이며 편집·JSON의 점유 단위는 32px 사각 격자입니다. Unity 콜라이더를 생성하거나 바꾸지 않습니다.

기존 지형 ID는 복원·편집 모델에 남아 있지만 화면은 새 타일로 그립니다. 재질·32px 좌표·JSON 형식은 유지합니다. 기준 지형 ID는 `A-24-relief-v2-20261021`이며 이전 지형과 자동 저장 키를 분리합니다. 이전 지형 편집본은 전용 버튼으로 내려받아 함께 보관한 이전 지형용 편집기에서 엽니다. 상단 풀 9px와 통과형 풀 11px는 착지선 위 장식이며, 발판 아래 64px 그림 때문에 저장된 배치 높이를 바꾸지 않습니다. 지면과 발판은 차분한 이끼색 잔디와 짙은 흑갈색 흙 세트입니다. 모서리 투명 외곽은 실제 노출 벽에만 적용하며, 아래 착지면 속 흙에는 구멍을 만들지 않습니다. 잎도 실제 경계에서 28~40px 안쪽 구간에서는 흙색으로 정리해 짧은 계단 아래에 긴 꼬리가 남지 않습니다. 배경은 큰 줄기·잎 덩어리·수풀을 굵은 도트로 단순화한 2장입니다. 480×270 원본을 3배로 표시하고, 가로 이동 비율은 0.16과 0.52입니다. 청록·청회색·회갈색을 섞어 잔디와 어울리는 어두운 숲 안쪽을 표현합니다. 아트 출처와 해시는 `data/tile-art.json`에 있습니다.

Python 3.9+로 저장소 루트에서 재생성합니다. 외부 패키지는 필요 없습니다. 기본값은 기존 단일 HTML에서 승인 이미지 묶음을 읽고, 변경한 템플릿·JS·맵 데이터를 삽입합니다.

```sh
python tools/chapter1-map-editor/tools/package.py
```

이미지를 모두 교체할 때는 `--assets`에 PNG 9장이 있는 폴더를 지정합니다. `--tile-assets`는 `ground.png`, `solid-platform.png`, `drop-through.png` 3개가 있는 폴더에서 타일만 바꾸고 배경·캐릭터 6장을 유지합니다. `--out`으로 별도 HTML 출력 위치를 지정할 수 있습니다.

```sh
python tools/chapter1-map-editor/tools/package.py --tile-assets /path/to/sprites
```

공유 ZIP은 필요할 때 Git 제외 출력 폴더에 생성합니다.

```sh
python tools/chapter1-map-editor/tools/package.py --zip outputs/chapter1-map-editor/1챕터_맵편집기_공유.zip
```

ZIP에는 현재 단일 HTML·이전 지형용 호환 HTML·안내 TXT·이 안내가 들어 있습니다. 압축을 풀고 HTML을 엽니다.

## 검사

Node.js 18+로 저장소 루트에서 실행합니다. 외부 모듈을 설치하지 않습니다.

```sh
node tools/chapter1-map-editor/tools/test_terrain.cjs
node tools/chapter1-map-editor/tools/test_tile_art.cjs
node tools/chapter1-map-editor/tools/test_ui.cjs
node tools/chapter1-map-editor/tools/test_ui.cjs --source
```

지형 연결·복원·512가지 이웃 배치·JSON 검증과 단일 HTML 및 소스의 편집 이벤트를 검사합니다. 아트 검사는 단색 내부, 모서리 그림의 셀 경계 연속성, 볼록·오목 모서리, 천장 끝, 대각선 편집 후 캐시 갱신, 최소·최대 발판 폭, 착지선과 내장 이미지 규격을 확인합니다. UI 검사는 Node DOM 모의 환경이며 실제 브라우저 렌더·Unity 플레이 검사를 대신하지 않습니다. 브라우저에서는 단일 HTML을 열어 입구의 흙 벽·통과형 발판, 계단형 천장, 지형 칠하기·되돌리기를 확인합니다. 테스트 산출물은 Git 제외 `checks/` 또는 `outputs/`에 둡니다.

## 지형 구성

편집 원본은 `data/relief-layout.json`입니다. 공간마다 지면·천장 윤곽을 따로 정의하며, 연결 길에도 개별 지면 프로필을 둡니다. 높은 흙둔덕·깊은 분지·돌출된 절벽을 짧고 엇갈린 발판으로 오르내립니다. 전투 후보 8곳에는 8~15칸의 연속 지면을 남깁니다. 중간보스·최종보스 영역은 넓은 지면을 유지합니다. 후보 표시가 적 수·전투 규칙·보상을 확정하지 않습니다.

`node tools/chapter1-map-editor/tools/build_relief.cjs`로 기준 지형·배치를 만들고 `package.py`로 단일 HTML을 갱신합니다. 높이는 원래 발판과 동일한 32px 격자입니다. `test_relief.cjs`는 발판 여유 공간·발 디딤 위치·전투 지면·공간 연결과 간이 점프 궤적의 왕복 경로를 검사합니다. 이 궤적은 최대 상승 5.5칸을 사용하는 설계용 근사치이며 실제 Unity 이동·전투 검증이 아닙니다.

먼 숲은 밝고 대비가 낮은 청회색, 가까운 줄기는 짙은 회갈색·이끼색입니다. `repeatUnmirrored: true`인 레이어는 좌우반전하지 않고 그대로 반복합니다. 원경 PNG는 양끝의 같은 행 색을 연결하고 근경은 좌우에 24px 투명 여백을 둡니다. 배경 반복 방식은 HTML과 Unity에 함께 적용하며, 24공간 지형은 HTML 편집용 데이터입니다.
