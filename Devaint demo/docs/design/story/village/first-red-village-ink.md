# 첫 붉은 마을 잉크 — 확정 구성

[분야 개요](README.md)

주인공은 말을 못 한다. 첫 붉은 잉크 장면에는 주인공 대사나 끄덕임을 넣지 않는다.

## 보스방

시계탑 집행자 처치 → 작은 붉은 병 착지(0.7초) → 가까이서 F로 즉시 줍기 → 출구로 2챕터 진행, 런이 끝나 마을로 돌아오면 아래 마을 컷씬(2026-11-13). 줍는 순간 병과 F 표시가 사라지고 손·주머니 부근에 붉은 빛이 켜진다. 빛은 몸과 방향 전환을 따라가며, 마을에서도 병을 꺼내기 전까지 은은하게 남는다. 물음표·대사·컷씬·시뮬레이션 정지·조작 잠금은 없다. 물리 드롭은 기본 32 PPU에서 높이 36px이며 첫 클리어 전에만 나온다. 출구는 첫 병을 챙긴 뒤 사용할 수 있고, 줍기에 사용한 같은 프레임의 F로 출구까지 열리지는 않는다. 마을 진행도는 기존 출구 정산 시 확정한다.

## 마을 컷씬과 전체 대사

장인이 초당 2.4유닛으로 천천히 등장 → 멈춤 → `!` → 초당 7.2유닛으로 주인공에게 빠르게 접근.

> 어, 또 보네!

> 잘 다녀왔어?

> 어! 너 주머니에… 그거!

> 붉은 잉크잖아!

> 너… 시계탑 집행자를 쓰러뜨렸구나!

> 그 잉크라면 마을에 색을 돌려줄 수 있겠어.

> 이 우물은 마을 곳곳의 물길과 이어져 있거든.

> 여기에 조금 흘려보내면, 색도 마을로 퍼져 나갈 거야.

> 마침 잘됐다. 한 번 써볼까?

*주인공이 우물 쪽으로 돌아서 조금 걷고 멈춘다. 작은 병이 머리 위에 0.55초 동안 페이드인된다. 주머니의 빛은 병을 꺼내며 잦아든다. 병이 우물 앞까지 움직여 뚜껑을 열고, 병 입구를 고정한 채 기울어진다. 잉크가 수직 일자로 우물에 떨어지고 색이 번진다.*

> 봐… 색이 돌아오고 있어!

> 이런 풍경, 정말 오랜만이네.

> 다섯 색을 모두 되찾으면 마을도 예전 모습으로 돌아올 거야.

> 나머지 잉크도 찾아줄 수 있을까?

*잠깐 기다린 뒤 주인공이 장인 쪽으로 돌아본다. 말이나 끄덕임 없이 잠시 눈을 마주친 다음 장인의 감사 대사가 이어진다.*

> 고마워. 네 덕분에 희망이 생겼네.

> 돌아온 색 덕분에 공방에서 팔레트 작업도 할 수 있겠어.

> 잠깐 공방으로 가 볼까?

*함께 장인의 공방으로 걸어간다. 같은 작업대의 팔레트 기능이 열린다.*

> 이제 여기서 마법안료로 팔레트의 칸을 넓혀 줄 수 있어.

> 보급이든 팔레트든, 필요한 일은 이 작업대에서 골라 줘.

> 안료가 모이면 들러. 다음 여행에 맞춰 손봐 줄게.

> 난 다시 정비소에 가 봐야겠네.

> 조심해서 다녀와. 또 보자!

*장인의 몸 전체가 화면 오른쪽 밖으로 나갈 때까지 기다린다. 화면 안에서 갑자기 지우거나 정해진 시간에 제거하지 않는다. 퇴장 뒤 잠깐 마을을 보여주고 컷씬을 끝낸다.*

## 컷씬 뒤 UI

1. 0.4초 쉬고 `마을 잉크 획득` 화면을 0.55초에 걸쳐 페이드인한다. 닫힌 붉은 병, 검은 그라데이션 위 `1 / 5`, 독립된 굵은 방울 틀과 첫 붉은 방울을 보여준다. 병의 기준 영역은 220×220으로 줄이고, 비율 유지 이미지의 피벗을 가운데로 바꿔 제목·숫자·방울과 같은 중앙축에 맞춘다. 여기서는 병을 다시 열거나 붓지 않는다. F 확인.
2. 획득 화면을 F로 닫으면 조작을 돌려준다. 예전의 침식자·마을 잉크 두 페이지 수첩과 기록 농가의 스토리 4(발견한 기록)는 쓰지 않는다(사용자 결정 2026-11-13). F의 연속 입력은 0.65초 확인 간격으로 막는다.

## 기록 농가의 스토리 재생

해금·잠금 미리보기·페이지 재생·완독 저장 조건은 [기록 농가의 스토리 목록](../../world/village/starting-village.md#기록-농가의-스토리-목록)을 따른다. 이 마을 잉크 자동 안내의 진행·확인 키는 기록 농가의 다시 보기와 별개다.

## 첫 런 설명과 중복 방지

첫 런 뒤 마법안료·보급 설명은 장인의 통합 공방을 안내하도록 연결한다. 보급소는 첫 런 정산 뒤 사용할 수 있으므로 “지금은 못 쓴다”는 말을 넣지 않는다. 첫 붉은 잉크 방문에서는 같은 공방에 추가된 팔레트 확장 기능을 설명한다. 첫 런에 바로 집행자를 쓰러뜨려 마법안료·보급소 설명을 못 본 경우에는 `village_visits.json`의 `firstRunSupplyLesson`을 사용한다. 첫 클리어 전용 인사·잉크 설명·색 복원 감상은 `firstRunDialogue`로 바꾼다. 다른 잉크를 부탁하고 주인공이 돌아선 뒤 「고마워. 그럼 다음에 나갈 준비는 내가 좀 도와줄게」로 이어서 마법안료 소개 → 우물에서 다시 깨어남과 안료 보존 → 통합 공방에서 보급 기능 → 팔레트 기능 안내 → 정비소에서 다시 만날 것을 예고하는 작별 인사를 진행한다. 우물에 붓는 동작과 주인공의 침묵은 공통 연출을 유지한다. 첫 런 대본을 뒤에 붙이지 않으며, 이미 안료 설명이나 보급소 안내를 본 프로필에는 이 대화를 반복하지 않는다.

## 상태와 스킵

- `village-red-ink-discovery`: 붉은 병 수집 기록(기존 저장 ID 유지, 발견 컷씬은 없음).
- `village-ink-return-k`: 월드 병의 잉크가 우물에 닿았음. 5.2초 연출 중 2.6초에 색 번짐 시작.
- `artisan-visit-k`: 장인 방문 완료.
- `village-ink-reward-k`: 컷씬 뒤 획득 화면 확인 완료.
- `village-executioner-note`: 예전 침식자 수첩 확인 기록. 지금은 읽지도 쓰지도 않는다.

정상 재진입에서는 확인하지 않은 획득 화면만 이어서 표시한다. 컷씬에서 Esc를 길게 눌러 건너뛰면 색·시설 해금·안내 확인을 함께 정산하고 조작을 푼다. 장면 종료나 GUI 폐기 시 월드 병과 안내 잠금도 해제한다. 실 저장 데이터의 챕터/잉크 개수 의미는 바꾸지 않는다.

연출 분리는 1~5색 모두 공유한다. 자세한 장인 대사는 첫 붉은 잉크에서만 자동으로 나온다. 실제 보스방 물리 드롭은 현재 구현된 1·2챕터에 연결한다. 3~5챕터 보스는 아직 없으므로 해당 색의 귀환은 미리보기에서 확인한다.

2챕터부터는 잉크를 가지고 귀환해도 자동으로 붓지 않는다. 우물 F로 다음 미사용 잉크 하나를 꺼내 붓고, 색 복원 뒤 획득 화면을 확인한다. 장인의 기존 시설 안내는 그 뒤에 진행한다. 붓지 않은 잉크가 없으면 우물에는 F 키캡과 상호작용이 없다. 마을 색은 보유량이 아닌 사용 완료 기록으로 결정한다.

## 확인 방법

`tools/preview_red_ink_discovery.cmd`: 보스 처치 후 F 줍기부터. `tools/preview_village_ink.cmd`: 마을 귀환부터. 둘 다 메모리 프로필을 써 실제 저장 슬롯을 덮어쓰지 않는다. Unity 6000.6.5f1 사용.

새 삽화는 기본 image_gen 도구로 생성했다. 원본 PNG와 Unity 적용본은 동일한 바이트를 유지한다. 현재 두 페이지 원본: `resources/ui/village-ink-return-20261107/source/generated/eroders-notebook.png`, `well-ink-notebook.png`. 전체 프롬프트와 원본 경로는 같은 그룹의 `source/notebook-pages-20261108.json`에 보존한다. `tools/preview_village_ink_storybook.cmd`로 기록 농가 이야기책을 바로 열 수 있다.

## 상호작용 위치의 새 소식

확인하지 않은 새 기록이 있으면 기록 농가에, 아직 사용하지 않은 마을 잉크가 있으면 우물에 작은 금빛 `!`를 표시한다. 농가는 해금된 이야기를 마지막 페이지까지 확인하면, 우물은 잉크가 실제로 사용되어 더 이상 남은 병이 없으면 표시를 지운다. 여러 병을 가지고 있다면 다음 병이 남아 있는 동안 우물 표시는 유지한다. 첫 출발 전에도 기록 표시가 보이며, 컷씬·획득/수첩 화면·열린 책·일시정지 중에는 월드 표시를 숨긴다. 읽은 단계와 사용한 잉크는 기존 프로필 기록을 따르므로 재접속해도 확인한 소식이 다시 뜨지 않는다.

미리보기의 「첫 런 보스 클리어 · 안료 설명까지」는 마법안료 설명을 아직 안 본 첫 클리어를 재현한다. 「새 소식 ! · 농가와 우물」은 새 귀환 기록과 금색 병이 남은 상태, 「확인 / 잉크 사용 후 · ! 없음」은 두 내용을 확인·사용한 상태다. 모두 메모리 프로필이며 실제 저장 슬롯을 바꾸지 않는다.

다섯 번째 잉크를 사용한 뒤에는 마을의 색 복원을 확인하고 「앞으로는 여기 공방에 있을게. 필요하면 찾아와」로 장인의 마을 정착을 알린다. 염색공방은 첫 잉크에서 이미 개방되므로 다시 문을 연다는 대사는 사용하지 않는다.
