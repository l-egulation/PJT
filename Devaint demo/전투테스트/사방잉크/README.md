# 처치 폭발(사방 잉크) 이펙트

빨강 잉크 `ink3_red_05` 처치 폭발(몬스터 처치 시 처치한 자리 반경 6 안의 다른 몬스터에게 기준 피해 100%)가 터질 때 쓰는 시트다. 같은 모양의 보라 판은 독폭탄(`ink3_purple_09`)이 독이 터진 몬스터에게 펑 터지는 데 쓴다. 제품 아트 확정본이 아니며 Unity 시험판(`Chapter1InkPartFx`)에 연결했다.

쓰러진 몬스터 몸통에서 흰 심이 번쩍이며 잉크 덩어리가 부풀고, 고리가 0.24초 만에 피해 반경 끝까지 퍼지며 끊어진다. 굵은 방울들이 사방으로 날아가며 살짝 떨어지고, 바닥에 닿은 방울은 납작한 얼룩으로 남았다가 사라진다. 이전에 빌려 쓰던 파열 가시(발밑에서 가시가 솟음)를 대신한다.

- `export.py`: numpy·PIL 로 두 판(빨강·보라)을 그린다. 고정 시드라 다시 뽑아도 같은 바이트가 나온다. 결과는 Git 제외 `outputs/pixelfx/ink-splash/`.

```sh
python 전투테스트/사방잉크/export.py --preview
```

## 시트 규격

- 판마다 실제 반경 크기로 그린다. 빨강은 피해 반경 6(192px), 보라(독폭탄)는 반경 3.2(102.4px)이며 Unity 에서 키우거나 줄이지 않는다(PPU32 게임 화소 1:1). 반경은 `meta.pixelfx.fieldRadius`(px)·`radiusUnits`에 적는다.
- 빨강: 한 장 470×275, 15장(0.6초). 보라: 한 장 264×172, 13장(0.52초). 25fps, 4열. 피벗은 몬스터 몸통 가운데, 바닥은 피벗 아래 28px(`meta.pixelfx.floor`).
- 반경 2(64px)를 기준 모양으로 두고, 넓을수록 방울·잔점 수와 굵기를 늘리고 퍼지는 시간을 조금 늘린다.
- 팔레트는 표식 격발의 red·purple 과 같은 다섯 색이며 반투명 없이 칠한다.
- 결과 시트는 리소스 저장소 `effects/ink-parts/runtime/ink-splash/`에 등록하고 메인 배치 계약으로 `unity/Assets/ForestCombatV2/Resources/InkPartFx/`에 둔다.

## 확인한 범위

어두운 바탕·반경 원·바닥선을 깐 미리보기로만 모양을 봤다. Unity 훈련장 테스트에서 시트가 쓰러진(독이 터진) 몬스터 자리에 뜨는지 확인했고, 실제 플레이 화면·다른 몬스터 크기·보스는 확인하지 않았다.
