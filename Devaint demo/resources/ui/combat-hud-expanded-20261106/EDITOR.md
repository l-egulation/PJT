# UI 배치 편집기

`preview/편집기_열기.cmd`를 실행하면 브라우저 편집기가 열립니다. Python이 필요하며, 로컬 컴퓨터의 127.0.0.1에서만 실행됩니다. 기존 `preview/index.html`을 직접 열어도 이동·크기 편집은 가능하지만, PNG 저장은 실행 파일로 연 편집기에서 사용하세요.

## 배치 수정

- 에셋을 클릭하고 드래그해 이동합니다. 모서리·변의 손잡이를 끌면 크기가 바뀝니다.
- 오른쪽 X·Y·너비·높이로 정확한 픽셀 값을 입력합니다. 기준 화면은 1670 × 942입니다.
- 오른쪽 목록의 **체력 / 미니맵 / 무기 1 UI / 무기 2 UI / 출발 팔레트** 제목을 누르면 묶음 전체를 이동·확대할 수 있습니다.
- Shift 클릭은 여러 에셋 선택, Alt 클릭은 겹친 에셋 순환 선택입니다. 방향키는 1px, Shift + 방향키는 10px 이동입니다.
- 가로·세로 비율 유지, 8px 맞춤, 화면 확대, 격자를 사용할 수 있습니다.
- 텍스트 내용·크기·색, 그림 회전·불투명도, 숨김·잠금·앞뒤 순서를 편집할 수 있습니다. 숨기거나 잠근 요소도 오른쪽 목록에서 선택할 수 있습니다.
- 에셋 추가에서 공용 PNG를 더 넣거나 텍스트를 추가할 수 있습니다. 복제는 Ctrl+D입니다.
- Ctrl+Z로 되돌리고 Ctrl+Shift+Z 또는 Ctrl+Y로 다시 실행합니다. 기본 배치 버튼도 되돌릴 수 있습니다.

## 상태와 배경

위쪽 **무기·팔레트·체력 조건 바꾸기**를 열면 10종 무기, 발사기 4종을 포함한 스킬, 잉크, 3~5칸, 쿨타임·차징 상태를 바꿀 수 있습니다. 배치는 그림 파일명이 아닌 화면의 에셋 위치 ID에 연결되므로 무기나 색상을 바꿔도 편집값이 유지됩니다. 현재 보이지 않는 상태의 편집값도 파일에 보존합니다.

**게임 화면 넣기**로 PNG/JPG/WebP 스크린샷을 배경에 넣어 어울리는지 비교할 수 있습니다. 배경 파일은 현재 탭에서만 유지하며 JSON에는 포함하지 않습니다.

## 저장과 전달

배치는 이 브라우저에 자동 저장됩니다. 같은 주소로 다시 열면 복원됩니다. 브라우저 데이터 삭제·다른 브라우저·다른 포트에는 이어지지 않으므로 **배치 JSON 저장**으로 파일도 보관하세요. 저장한 JSON은 배치 불러오기로 다시 편집할 수 있습니다.

JSON에는 에셋별 변경값, 묶음 변경값, 추가한 에셋, 미리보기 상태, 최종 위치 목록이 들어갑니다. 이 파일을 다음 구현 작업의 배치 입력으로 사용할 수 있습니다. JSON 저장 자체가 Unity 프리팹이나 게임 코드에 반영되는 것은 아닙니다.

PNG 저장은 선택 테두리·손잡이·격자를 제외하고 1670 × 942로 출력합니다. 투명 PNG 또는 배경 포함 PNG를 선택할 수 있습니다. 개별 PNG 원본 파일은 편집기로 변경되지 않습니다.

발사기는 스킬 목록에서 차징 후 발사·레이저·샷건·유탄포를 선택합니다. 큰 무기 아이콘과 출발 카드가 스킬 외형에 맞춰 바뀝니다. 이전에 저장한 레이저·샷건·유탄발사기 무기는 불러올 때 발사기와 해당 스킬로 변환됩니다.

[사용자 배치 열기](preview/index.html?layout=matched-weapons)는 보존된 사용자 배치에 무기 2의 레이아웃을 맞춘 파일을 불러옵니다. 불러온 뒤에도 계속 편집·저장할 수 있습니다.
