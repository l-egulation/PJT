# 1차 배포 인수 기준

인수 흐름의 정본은 [A-04 작업 문서](../../wiki/06-delivery/tasks/A-release-scope/a-04-define-release-acceptance-scenario.md)다.

## 인수 시나리오 골격

계정 생성 → 로그인 → 주력 재료 선택 → 1-1 시작 → 단일 브라우저 탭에서 메인 전투·펫 UI 확인 → 챕터 화면에서 현재 전투·진행 목표·잠금 확인 → 스테이지 화면에서 상태·주요 보상·`피해 N%`·최근 실패 확인과 입장·1~9 반복 설정 → 1-5 최초 클리어·치장·보석 해금 → 초기 뽑기권으로 픽업 뽑기·도감 등록 확인 → 초기 입장권으로 현재 시간 슬롯 보석 던전·보석함 개봉·합성 확인 → 중복 치장 승급·세트 효과 확인 → 관리 UI에서 자동 진행·획득 확인 → 잠긴 챕터·스테이지 직접 접근 거부 확인 → 성장·장비·아이템·스킬·보석 확인 → 브라우저 종료·재진입 후 서버 스테이지·반복 대상과 로컬 모드 복원 → 4-10 클리어 → 거래소 등록·구매·정산까지의 흐름을 MVP 인수 경로로 사용한다.

각 단계의 세부 조건과 증거 링크는 A-04와 관련 B–K 작업을 함께 확인한다. 이 문서는 흐름만 보여 주며 수치와 상태를 복사하지 않는다.

보석 흐름은 [보석 SSOT](../../30-domain/gems/ssot.md)의 정식 v2 기준과 [보석 콘텐츠 계획](../gem-content/requirements.md)의 남은 장기 분포·메인 적 수치 검증을 구분해 A-04 인수 흐름과 관련 실행 작업에 연결한다. 기존 A-04 원문의 3-10 종료점은 최신 MVP 범위인 4-10으로 재검증해야 하며, 증거가 추가되기 전에는 완료로 판정하지 않는다.

치장 세부 인수 시나리오는 [치장 뽑기 시스템 요구사항 명세서](../cosmetic-gacha/requirements.md)의 검증 기준을 따른다. [MVP 치장 뽑기 콘텐츠 v1](../../60-content/cosmetics/mvp-v1.md)은 승인됐지만 PostgreSQL 통합·웹 브라우저 사용자 흐름과 남은 요구사항은 [K-21 작업](../../wiki/06-delivery/tasks/K-client-ux/k-21-cosmetics-vertical-slice.md)의 부분 검증 상태이므로 치장 인수를 완료로 판정하지 않는다.
