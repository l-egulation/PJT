# 1Stage 채택 미술 참조

현재 제작 기준은 [2차 채택 시안 5장과 B 경계](phase2-selected/selection.json), [마을 미술 기준](../../docs/assets/world/village/stage1-village-art-direction.md)이다. `approved-transition.png`와 `approved-sketch.png`는 기본 화풍을 보존한 1차 정지 시안이다. 시안은 게임용 타일셋이나 Unity 렌더가 아니며 `color-reference.png`는 기존 컬러 기준이다.

2차 기준은 별도 `stage1-village-phase2-selected.zip`과 [복원 목록](../../docs/assets/manifests/stage1-village-phase2-selected.json)으로 복원한다. 새 게임용 짝은 `stage1-village-phase2-working-images.zip`이며 현재 적용 검토 중이다. 1차 승인 패키지를 덮어쓰거나 공유 완료로 표시하지 않는다.

PNG는 저장소 이미지 제외 정책에 따라 별도 전달한다. 이 폴더의 `approved-art-direction.zip`을 저장소 루트에 풀면 기준 이미지·프롬프트를 복원할 수 있다. 복원 파일의 해시는 [manifest](../../docs/assets/manifests/stage1-village-art-direction.json)와 대조한다. 같은 이름의 수정본이 있으면 먼저 따로 보존한다.
