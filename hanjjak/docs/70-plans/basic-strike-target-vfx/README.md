기본 `strike1` 모션과 함께 재생되는 몬스터 중심 피격 이펙트 시안을 보존한다. 2026-09-13 사용자 선택으로 A안 `백금 교대베기`를 확정했으며, 전투 판정과 피해 수치는 이 문서가 정의하지 않는다.

- 전투 사건·공격 주기 정본: [전투 SSOT](../../30-domain/combat/ssot.md)
- 메인 전투 화면 표현 정본: [클라이언트 UX SSOT](../../30-domain/player/ux/ssot.md)
- 액티브 전투 VFX 확정 콘텐츠: [MVP 스킬 표시 콘텐츠 v1](../../60-content/abilities/mvp-v1.md)

## 시안 범위

- 선택 상태: A안 `백금 교대베기` 확정
- `strike1` 4프레임을 프레임당 100ms로 재생한다.
- 이펙트 시작점은 타격 프레임인 3프레임 진입 시점(200ms)으로 시각화한다.
- 이펙트는 몬스터의 보이는 영역 중앙에 배치하고, 영역 크기에 비례해 축소·확대한다.
- 소형 일반 몬스터부터 대형 보스까지 서로 다른 크기의 실제 프로젝트 스프라이트 5종을 비교 대상으로 사용한다.
- A안은 우상향·좌상향 단일 사선을 타격마다 교대하며, 이펙트 때문에 몬스터 자체를 흔들지 않는다.
- 비교 화면 아래의 4초 검산 패널은 사용자가 제안한 피격 예약 메커니즘을 시각화한다. 실제 전투 규칙 반영 전까지는 후보 검증 자료다.

B~E안은 비교 이력으로만 보존한다. A안의 실제 게임 클라이언트 연결과 런타임 검증은 후속 구현 작업에서 수행한다.
