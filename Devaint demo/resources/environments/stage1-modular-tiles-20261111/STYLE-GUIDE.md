# 채택한 밝은 스테이지 제작 기준

이 문서와 [style-contract.json](style-contract.json), 채택 PNG가 다음 버전 제작의 기준이다. 다른 배색·챕터·스케치화를 만들어도 월드 치수, 접합, 충돌 구분과 배경의 명암 위계를 유지한다. 승인일은 2026-11-11이며, 미술 채택과 Unity 적용은 별개다.

새 배색·챕터는 **새 에셋 ID와 새 디렉터리**에서 제작한다. 이 채택본의 PNG와 계약을 덮어쓰지 않는다. 새 버전은 검토 대기 상태로 시작하고, 현재 package.cjs의 채택 상태를 자동으로 물려받지 않는다.

## 발판·벽 규격

| 대상 | 고정 기준 |
|---|---|
| 월드 / 타일 | 1u=32px, 32×32px PNG, PPU 32, scale 1 |
| 기본 돌 / 반장석 | 32×16 / 16×16px. 줄눈 포함 크기 |
| 한 단 | 높이 16px. 가로 돌을 세워 벽돌로 쓰지 않음 |
| 한 칸 기둥 / 막힌 선반 | 높이/폭 한 칸 안에 두 단. 띠 중첩 없음 |
| 지형 외곽 | 안쪽 16px 띠. 윗면·아래면·좌우면 각각 조명 처리 |
| 줄눈 | 경계 시작 1px 소유. 접합 위치 고정, 질감만 변주 |
| 모서리 | 32px 셀 안에서 완성. 이웃 칸 침범 없음 |
| one-way | 목재+철 끝캡. 판 8px+하부 디테일 최대 4px, 아래 알파 0 |
| one-way 충돌 | 기존 4px 두께와 접촉선 유지. 그림과 물리 구분 |
| 길이 | N장의 타일로 N×32px. 끝마개도 첫/마지막 셀 안에 포함 |
| 선택 규칙 | 8방향 이웃 256→47형. 질감 4종. single/벽 부착 포함 목재 11종 |

밝고 가장 뚜렷한 흰 하이라이트는 걸을 수 있는 윗면에 둔다. 아래면에는 같은 흰 선을 반복하지 않는다. 막힌 땅은 불투명 석재, 아래에서 통과하는 발판은 얇은 목재로 구분한다. 모서리·천장·한 칸 기둥 때문에 돌의 높이나 폭을 늘이거나 끝 돌을 잘라 맞추지 않는다.

최종 합성한 점유 격자를 기준으로 타일을 선택한다. 방의 여러 사각형에 각각 테두리를 두르면 내부 접합면에 선이 생기므로 동일한 연결표를 사용한다. 임의 회전으로 광원 방향을 바꾸지 않는다. 경사면 등 직교 격자 밖의 충돌은 별도 규격이 필요하다.

## 배경 구성과 거리감

1. **원경:** 하늘·산·마을. 윤곽선 없이 큰 형태, 약한 명암. 검토용 카메라 이동비 0.2.
2. **배경 건축:** 벽·창·기둥·아치. 개구부는 진짜 투명 알파. 월드 위치 고정이며 지형과 함께 이동.
3. **플레이 지형:** 기존 32px 타일, 또렷한 외곽과 착지선.
4. **캐릭터/상호작용 물체:** 지형과 같은 플레이 공간. 캐릭터는 현재 시안에서 크기 참조 레이어.

근경 건축과 원경 풍경을 한 PNG로 합치지 않는다. 각 방 출력은 같은 크기의 네 PNG를 원점 정렬한다. 화면을 가리는 별도 최근경은 추가하지 않는다. 합성 preview만 열람용 완성 이미지다.

낮은 곳은 벽과 작은 창을, 넓은 홀은 열린 회랑을, 수직방은 아래부터 위까지 이어지는 기둥을 사용한다. 모든 구간에 같은 창을 도장처럼 반복하지 않는다. 중간 바닥이 없는 샤프트에 층별 아치나 수평 발판 같은 띠를 새로 그리지 않는다. 아치와 기둥을 가로/세로로 각각 늘이지 않고 비율을 유지해 배치한다.

현재 배경 소스는 넓은 홀 1774×887px, 높은 아트리움 1182×1330px, 공통 원경 1448×1086px다. 실제 PNG 헤더가 기준이다. 수직 건축 소스는 상단 30px를 크롭한 뒤 균일 확대/크롭한다. 방별 결과는 48×24u=1536×768px 또는 32×36u=1024×1152px다. 이는 채택한 두 배경 소스와 방 합성의 규격이며, 배경 전체 모듈 제작 완료를 뜻하지 않는다.

## 밝기·채도·선명도 기준

전체 화면에 흰 안개나 흐림 필터를 씌워 배경을 연하게 만들지 않는다. 형태는 깨끗하게 유지하면서 **배경의 명암 폭과 세부 대비**를 낮춘다. 배경에는 검은 외곽선과 발판 같은 흰 윗선을 두지 않는다. 원경은 형태를 더 크게 단순화하고, 가까운 플레이 지형을 가장 또렷하게 둔다.

현재 채택 PNG를 측정한 참고 수치다. 명도는 sRGB 가중합 0.2126R+0.7152G+0.0722B(0–255), 채도는 HSV S(%). 알파 240 이상 픽셀을 사용한다.

| 기준 | 명도 P5 / 중앙값 / P95 | 채도 중앙값 |
|---|---|---|
| 걸을 수 있는 석재 면 | 80.49 / 166.74 / 245.97 | 45.41% |
| 넓은 건축 배경 | 176.38 / 205.38 / 212.45 | 18.41% |
| 높은 건축 배경 | 163.08 / 199.73 / 209.65 | 18.92% |
| 원경 전체 | 179.06 / 207.89 / 216.80 | 29.25% |

건축의 P95−P5 명암 폭은 발판의 약 22~28%다. 원경은 하늘을 포함하므로 전체 채도 중앙값이 건축보다 높다. 채도 숫자를 거리별로 기계적으로 정렬하기보다, 외곽선 유무·명암 폭·형태 복잡도를 함께 유지한다.

다른 밝은 배색을 만들 때 참고할 작업 범위는 건축 명암 폭 30~50/255, 채도 중앙값 16~22%다. 이 범위는 비교용 가이드이며 게임 엔진 제한이 아니다. 어두운 버전이나 스케치는 절대 밝기값을 복사하지 말고 지형이 배경보다 또렷한 관계를 유지하며 기준 PNG와 비교한다.

## 다음 버전 확인 순서

재질 원본만 바꾸고 치수·접촉선·연결표를 유지한다. 같은 타일로 ㄴ/ㄷ자, 한 칸 기둥, 벽 부착 선반, 독립 석재·목재, 계단과 수직방을 먼저 조립한다. 원본 1배와 정수 2배에서 비교하고, 접합 확대본을 따로 만든다.

배경은 원경·건축을 각각 생성하고, 창/아치의 알파 투명과 레이어 원점 정렬을 확인한다. 실제 방의 발판/문/계단 위치를 바꾸어 그림에 맞추지 않는다. 마지막으로 전체 합성에서 지형의 대비와 캐릭터 발의 착지선을 비교한다. 생성 프롬프트만으로 같은 결과를 보장할 수 없으므로, 채택 PNG와 이 규격을 함께 사용한다.
