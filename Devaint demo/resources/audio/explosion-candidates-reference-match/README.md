# 참고 영상에 맞춘 폭발음 후보

2026-11-16 사용자가 다른 2D 픽셀 게임의 폭발 장면 녹화를 보내며 "내가 원한 소리는 이런 느낌"이라고 했다. 이 폴더의 후보는 그 소리를 측정해 고른 것이다. 사용자가 고를 때까지 게임에는 적용하지 않는다.

참고 녹화 파일 자체는 다른 게임의 소리이므로 이 저장소에 넣지 않았다. 비교 화면의 「참고 파일 불러오기」를 쓰면 브라우저 안에서만 열어 A/B할 수 있다. 가장 큰 1.6초 구간을 후보와 같은 RMS로 맞춰 재생한다.

## 참고 소리의 특징 (측정)

- 앞에 아주 짧은 밝은 딸깍이 있고, 이어서 몸통이 약 125 ms에 걸쳐 부풀어 오른다. 날카롭게 때리지 않는다.
- 에너지가 거의 500 Hz 아래에 모여 있다. 0.5~6 kHz는 약 13 dB 낮고, 6 kHz 위는 거의 없다. 실제 폭탄의 파편·지글거림이 없는 어둡고 둥근 「퍼엉」이다.
- 감쇠가 부드럽다. 피크 대비 -20 dB가 0.4초, -30 dB가 0.75초, -40 dB가 약 1.05초다.
- 화면에서는 밝은 섬광 뒤 연기가 퍼진다.

이전 후보와 비교하면 다음과 같다.

| 소리 | 참고와의 거리 |
|---|---|
| 지금 게임 소리 (B3 물풍선) | 16.3 |
| 이전 「연기 펑」 | 16.6 |
| 이번 후보 | 6.1~9.9 |

거리는 아래 「고르는 방법」의 기준이며, 낮을수록 가깝다.

## 고르는 방법과 처리

- 구매팩의 폭발 계열 원음을 참고 소리와의 거리로 줄 세웠다. 대상은 실제 폭발, 레트로, 마법, SF, 화염 등이다.
- 거리는 두 값을 합친 것이다. 하나는 시작부터 1.2초 동안의 레벨 곡선 차이이고, 다른 하나는 9개 대역 에너지 분포 차이에 0.6을 곱한 값이다.
- 원음 그대로와, 1.5 kHz·3 kHz·800 Hz 저역 통과를 적용한 경우를 모두 비교했다.
- 계열마다 가장 가까운 것을 골랐다.
- 처리 규칙은 다음과 같다.
  - 원래 속도를 유지하고 꼬리를 자르지 않는다. 녹음이 스스로 -54 dB까지 줄어들 때까지 둔다.
  - 30 Hz 아래 울림을 걷어낸다.
  - 참고 소리의 어두움에 맞춰야 할 때만 12 dB/oct 저역 통과를 쓴다.
  - 크기는 그 자리의 지금 소리와 같게 맞췄다(K-가중 400 ms 최대값).
  - 유탄은 지금과 같은 3연쇄다.

| 번호 | 이름 | 원음 | 저역 통과 | 처리 후 거리 |
|---|---|---|---|---|
| 1 | 어두운 신스 펑 | `sci-fi_weapon_blaster_laser_boom_zap_02` | 1.5 kHz | 6.1 |
| 2 | 부드러운 신스 붐 | `sci-fi_weapon_blaster_laser_boom_03` | 3 kHz | 9.9 |
| 3 | 얼음 마법 폭발 | `ice_blast_projectile_spell_02` | 3 kHz | 7.7 |
| 4 | 덩굴 마법 폭발 | `nature_spell_vines_blast_impact3` | 없음 | 8.2 |
| 5 | 작은 실제 폭발 · 어둡게 | `explosion_small_02` | 3 kHz | 8.4 |
| 6 | 둥근 에너지 폭발 | `energy_blast_small_02` | 없음 | 9.3 |

## 한계

- 거리 값은 파형과 스펙트럼으로 잰 숫자이고, 청감상 비슷하다는 뜻은 아니다. 제작자는 소리를 직접 듣지 못했다.
- 1·2번은 SF 무기 소리라서 앞에 레이저 결이 조금 남을 수 있다.
- 참고 녹화는 화면 녹화 음성(AAC)이라 원래 게임 소리보다 고역이 조금 줄었을 수 있다.
