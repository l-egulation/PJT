잉크눈·멧돼지 픽셀 편집기

1. index.html을 Chrome 또는 Edge로 열어주세요. 설치나 서버 실행 없이 사용할 수 있습니다.
2. 몬스터·동작과 프레임을 선택하세요. 멧돼지 돌진은 160×128, 다른 동작은 128×128입니다.
3. 칠하기(P), 지우기(E), 스포이드(I), 채우기(F)를 사용할 수 있습니다.
   우클릭 또는 Alt+클릭으로 현재 픽셀 색을 가져옵니다.
4. 같은 색 교체(Ctrl+K): 기존 색과 바꿀 색을 선택합니다.
   현재 프레임 / 현재 동작 12프레임 / 같은 몬스터의 모든 동작 범위에서 정확히 일치하는 색만 교체합니다.
5. 되돌리기(Ctrl+Z), 다시 실행(Ctrl+Y). 여러 프레임 색 교체도 한 번에 되돌릴 수 있습니다.
6. 수정 작업은 이 브라우저에 자동 저장됩니다. 다른 브라우저·컴퓨터에서 이어 하려면 작업 JSON을 저장하고 불러오세요.
7. 현재 PNG, 동작 4×3 시트 PNG, 전체 에셋 ZIP으로 내보낼 수 있습니다.
   전체 ZIP에는 개별 PNG 48장, 동작별 시트, GIF, 정보.json, Unity 설정과 편집 작업 JSON이 포함됩니다.
8. Chrome/Edge에서 '몬스터 폴더 연결'을 누르고 아트/몬스터 폴더를 선택하세요.
   '폴더에 수정본 저장'을 누르면 기존 4_픽셀128 안의 에셋과 전체 ZIP이 갱신됩니다.
   Unity에 복사해 둔 파일은 다시 복사하거나 임포트해야 합니다.

마우스로 원본 파일에 바로 쓰지는 않습니다. 폴더 저장 버튼을 누르거나 ZIP을 내보내야 게임 파일에 반영됩니다.
폴더 저장 중에는 편집을 잠시 멈추세요. 작업 JSON도 함께 저장해 두면 복원할 수 있습니다.

에셋 PNG 자체를 다른 세션에서 바꾼 뒤 편집기의 시작 데이터를 갱신하려면 build_data.py를 Python(Pillow 필요)으로 실행하세요.
기존 프레임 크기, 피벗, PPU, 모션 재생 시간은 내보내기에서도 유지됩니다.
사용자 색을 추가할 수 있으며 알파는 투명(0) 또는 불투명(255)만 사용합니다.
GIF 내보내기는 불투명 색 최대 255개를 지원합니다.
