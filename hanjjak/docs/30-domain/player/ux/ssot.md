## 책임

브라우저에서 제공되는 웹 게임의 펫 UI, 관리 UI, 저피로 상호작용과 화면 정보 구조를 소유한다. 도메인 규칙과 서버 정합성은 소유하지 않는다.

## 화면 구조

- 투명하고 항상 위에 둘 수 있는 작은 펫 창
- 성장·장비·스킬·보석·주력 재료·거래소·일일 보석 던전과 치장 뽑기·도감·성급 성장을 확인하는 확장 관리 창. 치장 메뉴는 1-5 최초 클리어 후 서버 해금 상태일 때 제공한다.
- 확장 관리 창의 상단 내비게이션에는 `콘텐츠` 버튼을 제공한다. 버튼을 누르면 던전·레이드 등 플레이 콘텐츠 진입 목록이 열리며, 이후 콘텐츠가 추가되어도 같은 목록을 확장할 수 있어야 한다. 보석 탭은 보석함·보유 보석·프리셋 관리를 담당하고, 일일 보석 던전의 입장·보스 선택·전투·소탕은 `콘텐츠` 목록의 던전 항목에서 진입한다.
- 두 창은 하나의 상태 엔진과 하나의 전투 타이머를 공유한다.
- 관리 창을 닫거나 펫을 숨겨도 게임 상태와 방치 진행이 끊기지 않는다.
- 메인 전투 UI와 관리 UI는 MVP에서 하나의 브라우저 문서와 하나의 상태 엔진·전투 타이머를 공유한다.
- Picture-in-Picture는 지원 브라우저에서만 선택 기능으로 제공하고, 미지원·권한 거부·사용자 취소 시 단일 탭 UI로 대체한다. 메인 전투 화면의 진입 조작은 우측 상단 관리 내비게이션과 획득 패널 사이에 관리 내비게이션과 같은 셸의 소형 아이콘 버튼으로 배치한다. 버튼의 짧은 상태 표시는 `한켠`·`여는 중`·`재시도`·`복귀`를 사용하고 전체 동작명은 접근성 이름과 툴팁으로 제공한다.
- Picture-in-Picture 창의 기본 화면은 별도 배경판과 상시 정보 문구 없이 투명 배경의 현재 착용 외형 캐릭터만 표시한다. 캐릭터는 전투 중 공격 모션을 반복하고, 캐릭터를 선택하면 바로 위에 닉네임·전투 상태·스테이지·HP·레벨·경험치·쌀·최근 진행을 담은 정보창을 겹쳐 연다. 같은 캐릭터를 다시 선택하거나 정보창 닫기 또는 `Esc`로 접으며, 정보창이 캐릭터를 화면 밖으로 밀어내지 않게 작은 창 높이에 맞춰 함께 축소한다.
- 별도 탭·팝업은 MVP 기준 구현이 아니다. 백그라운드 탭은 진행하고 discard는 중단 기준으로 처리한다.
- 같은 탭의 새로고침은 기존 게임 세션을 heartbeat로 재검증해 이어 쓰며 오프라인 복귀로 표시하지 않는다. 오프라인 보상 팝업은 서버가 확정한 실제 오프라인 경과시간과 보상 적용시간을 함께 표시한다. 각 시간은 서버가 준 초를 내림한 뒤 1분 미만은 `N초`, 1시간 미만은 `N분 N초`, 1시간 이상은 `N시간 N분 N초`로 표시하며, 초가 0일 때만 분·시간 표현에서 초를 생략한다.

## 캐릭터·치장·도감 정보 구조

### 캐릭터 창 — 2026-09-04 사용자 합의

- 메인 화면 하단 성장 메뉴의 캐릭터 버튼은 같은 브라우저 문서 위에 캐릭터 창 하나를 연다. 창 안에서 능력치·치장·도감 탭을 전환하고, 열 때마다 능력치 탭으로 시작한다. 탐색과 닫기는 메인 전투를 중단하지 않는다.
- 능력치 탭의 표시 순서는 합계, 기본, 추가 스탯이다. 기본은 초기 능력치·레벨 성장·장비와 강화의 기여이며, 추가는 보석·패시브 스킬·치장 세트 등 나머지 상시 효과다. 일시적인 전투 버프는 제외한다. 표시 분류는 전투 계산 순서를 변경하지 않는다.
- 각 능력치에 마우스를 올리거나 키보드 포커스를 두면 서버가 제공한 출처별 기여 내역을 표시한다. 고정 수치·퍼센트·퍼센트포인트를 구분하고 합계나 기여도를 클라이언트에서 재계산하지 않는다.
- 치장 탭은 캐릭터 미리보기·현재 착용 부위와 부위별 보유 목록을 배치한다. 목록 선택은 임시 미리보기만 변경하고 착용 버튼으로 서버에 적용한다. 해제 동작과 별도 뽑기 진입 버튼을 제공한다.
- 도감 탭은 왼쪽 세트 목록, 오른쪽 선택 세트의 구성 치장·성급·수량과 성급별 세트 효과를 배치한다. 치장별 성급 올리기 버튼은 아래 등록 UX를 따르며 세트 성급은 서버가 자동 파생한다. 별도 세트 승급 버튼은 제공하지 않는다.
- 배경·서체·색상·장식은 이번 결정에서 확정하지 않는다. 사용자 참고 이미지는 도감 정보 배치의 참고이며 이미지의 이름·숫자·성급을 콘텐츠 정책으로 사용하지 않는다.
- 풀스택 설계 제안은 [캐릭터 창 설계](../../../70-plans/character-window/design.md)에서 검토한다.

- 확장 관리 창의 캐릭터 화면은 현재 캐릭터 상태를, 치장 화면은 보유 치장·미등록 중복 재고·착용 상태를, 도감 화면은 등록 수량·성급·세트 완성 기록과 세트 효과를 각각 서버 확정 상태로 표시한다. 화면은 성급·효과·진척을 로컬 계산하지 않는다.
- 치장 상세와 착용 선택에는 실제 외형 미리보기를 제공하지만, 미리보기는 커밋되지 않은 임시 표현이다. 미리보기만으로 보유·등록·착용·효과 상태를 변경하지 않는다.
- 외형 착용은 `HEAD`, `TOP`, `BOTTOM`, `GLOVES`, `SHOES`, `CAPE` 정확히 6부위 슬롯으로 제공한다. 각 슬롯은 비울 수 있고, 착용은 외형만 바꾸며 전투 능력치를 변경하지 않는다.
- 이 캐릭터 창의 도감에서는 치장별 `성급 올리기`가 기존 `다음 성급까지 등록` 명령을 실행한다. 서버가 필요한 사용 가능 중복 수량을 충족한다고 판정할 때 활성화하고, 다음 한 단계까지 필요한 수량만 등록한다. 미획득·수량 부족·최대 성급은 비활성 사유를 표시한다. `1개 등록` 명령은 도메인에 유지하되 이 창에는 별도 버튼을 두지 않는다. 화면에는 서버가 확정한 등록 수량·현재/다음 성급·미등록/예약/사용 가능 중복 재고만 표시한다.
- 도감은 단계·보상·전투 효과를 제공하지 않고 등록 현황과 세트 이동을 표시한다. 세트 효과는 성급별 누적 총값으로 표시한다. 보유 효과 변경은 다음 메인 전투 사이클 시작부터 반영 예정임을 표시하며, 현재 진행 중인 사이클의 효과·스냅샷을 소급 변경하지 않는다.

## 메인 전투 화면 정보

- 좌측 상단은 캐릭터 닉네임과 현재 보유 쌀을 표시한다. 쌀은 합산 총자산이 아니라 유일한 기본 통화의 보유 수량이다.
- 중앙 하단은 레벨, 현재/최대 HP, 현재/필요 EXP와 EXP 비율을 조회 전용으로 표시한다.
- 레벨업 시 짧은 연출과 공격력·최대 HP 상승량을 표시한다.
- 플레이어 사망 시 HP 0과 1초 부활 카운트를 표시한 뒤 복귀 결과를 반영한다.
- 상단 스테이지 패널은 현재 스테이지, 적 이름과 일반 몬스터 처치 수를 표시한다. 일반 구간은 `현재 처치 수 / 20`과 단일 진행 바로 표현하고, 보스전에는 같은 패널에 보스 이름과 남은 제한시간을 표시한다.
- 전투 장면은 적 등장 뒤 캐릭터와 적이 서로 접근해 무기가 닿는 거리에서 공격 연출을 시작한다. 접근 재생 시간은 서버 전투 판정과 결과를 바꾸지 않는다. 일반 몬스터는 원본 전투 스프라이트 기준 절반 크기로 표시하고 보스는 원본 크기를 유지한다. 일반 몬스터가 처치되면 다음 일반 몬스터로 즉시 교체하며, 보스 등장 직전을 제외하고 공격 공백을 만들지 않는다.
- 캐릭터와 현재 적의 머리 위에는 각각 현재/최대 HP 바를 표시한다. 플레이어 공격·공격 스킬·지속 피해가 실제 적중한 사건의 피해 숫자는 대상 몬스터 위에 표시하고, 적중 피해가 없는 행동에는 표시하지 않는다.
- 플레이어 기본공격이 실제 적중하면 대상 몬스터의 보이는 영역 중앙에서 몬스터 크기에 비례한 `백금 교대베기` 이펙트를 재생한다. 우상향과 좌상향 단일 사선을 타격마다 번갈아 표시하며, 별도 피격 모션을 가리지 않도록 이펙트 자체는 몬스터 위치를 흔들지 않는다. 비교·타이밍 근거는 [기본공격 대상 피격 VFX 시안](../../../70-plans/basic-strike-target-vfx/README.md)에 보존한다.
- 실패 시 원인과 재시작 결과를 알리고, 직전 실패 분석에 실패 구간·진행 수·전투 시간·남은 HP·권장 성장 방향을 표시한다. 전체 메뉴와 메인 HUD의 전투 기록은 서버 기록 중 스테이지 승리·패배 결과만 최신순으로 표시하고 스테이지 입장·전투 복귀 사건은 노출하지 않는다. 승리는 스테이지·승리 여부·클리어 시각·입장 시각·소요 시간·사이클 회복 직전 남은 HP를, 패배는 스테이지·패배 여부·패배 시각·입장 시각·소요 시간·실패 원인·플레이어 남은 HP·처치 몬스터 수·마지막 상대의 남은 HP를 표시한다. 모든 승패 기록은 해당 전투에서 획득한 경험치·강화 재료 합계·쌀 수량과 실제 지급된 아이템의 표시명·수량을 함께 표시한다. 승패 카드에는 결과 설명 문장과 공격력·최대 HP·방어 관통 스펙을 표시하지 않는다.
- 전투 영역 자체는 직접 조작하지 않는다. 공격·이동·대상 선택·스킬 사용 버튼은 두지 않는다. 방치 모드 전환은 상단 스테이지 패널의 `자동 진행`·`스테이지 반복` 이미지 토글로 제공하고, 현재 모드를 반복 설명하는 별도 `AUTO` 상태 표시는 두지 않는다.
- 자동 진행과 스테이지 반복의 규칙, 전환 시점과 실패 복귀는 [스테이지 SSOT](../../world/ssot.md)를 표시할 뿐 UI에서 재계산하지 않는다.

## 획득 패널

- 우측 획득 패널은 스테이지에 입장한 시점부터 해당 체류 세션에서 확정된 쌀·아이템 획득량을 누적 표시한다. 자동 진행·수동 선택으로 다른 스테이지에 입장하면 새 체류 세션으로 초기화한다.
- 같은 스테이지에서 사망·재도전하면 누적을 유지한다. 선택 화면을 거쳐 입장을 다시 확정하면 같은 스테이지여도 새 체류 세션으로 초기화하고, 앱 재실행도 새 체류 세션으로 시작한다.
- 쌀은 지급 확정 즉시 좌측 보유량, 전투 영역 `+수량` 연출과 획득 패널 누적량에 함께 반영한다.
- 패널은 접기·펼치기만 제공하고 메인 전투 화면에 들어올 때마다 펼침 상태로 시작한다.
- 획득한 스킬북은 내부 품목 ID가 아니라 스킬명과 등급을 포함한 아이템 카탈로그 표시명으로 노출한다.

## 광장 채팅

- 광장 채팅은 메인 전투 화면 왼쪽 하단 기준선에 맞춘 축소형 접이식 종이 패널로 표시한다. 펼친 패널의 높이는 사용자가 상단 손잡이를 드래그해 조절하고, 최대 높이는 좌측 전투 기록 버튼 아래까지만 허용한다. 높이와 종이 배경 불투명도는 브라우저에 보존해 다시 열어도 유지한다.
- 메시지 행은 별도 캐릭터 아바타와 개별 박스 없이 `닉네임`, 본문, 시각 순서로 표시하되, 인접 메시지를 식별할 수 있는 세로 간격과 옅은 구분선을 둔다. 시각은 오전·오후 문구 없이 `19:00` 같은 24시간제로 표시한다. 닉네임은 본문보다 작은 보조 크기로 표시하고 닉네임과 본문이 가로 공간을 넘으면 말줄임표 대신 줄바꿈한다.
- 별도 전문 아이콘은 두지 않고 주력 재료에 따라 닉네임 색상을 감자 황금갈색 `#E4AD56`, 고구마 적보라색 `#982A59`, 옥수수 선명한 노란색 `#F0C712`로 구분하며 닉네임은 본문과 구분되는 크기로 표시한다. 세 색상은 2026-09-12 사용자 제공 이미지에서 추출한 글자 내부 대표색을 사용하고, 특정 재료에만 그림자를 추가하지 않는다. 나라 선택 화면의 `감자`, `고구마`, `옥수수` 이름에도 같은 색상 기준을 사용한다. 색상만으로 전문 정보를 잃지 않도록 닉네임의 접근성 이름에는 전문 표시명을 함께 제공한다. 다른 사용자의 닉네임을 우클릭하면 신고와 차단을 노출하며, 자신의 닉네임에는 메뉴를 열지 않는다.
- 차단 목록 진입은 패널 상단에서 펼침 상태가 드러나는 `차단 관리` 버튼으로 제공하고, 펼친 목록에서 차단 해제를 수행한다.
- 메시지는 오래된 항목부터 위에 쌓이고 최신 항목이 아래에 보이도록 배치한다. 표시 영역을 넘으면 오래된 항목이 위로 밀리며 사용자가 세로 스크롤로 다시 확인할 수 있다. 새 메시지(자신이 전송한 메시지 포함)가 등록될 때는 사용자가 이미 목록 최하단을 보고 있는 경우에만 목록을 맨 아래로 이동하며, 위쪽 메시지를 읽는 중이면 현재 스크롤 위치를 유지한다.
- 입력창은 종이 장식의 안쪽 안전 영역에 한 줄 높이로 제공하고 전송 버튼과 높이를 맞추며, 240자 제한의 현재 입력 길이를 표시한다. 입력 너비를 넘긴 텍스트는 한 줄 내부에서 왼쪽 내용이 가려지고 현재 입력 위치가 오른쪽에 유지된다. 전송 동작은 코랄색 종이비행기 버튼과 Enter 키로 제공한다. 이용 안내는 정보 버튼을 통해 패널 내부에 겹쳐 표시하되 입력창 위치를 밀지 않으며, 헤더의 슬라이더로 종이 배경 불투명도를 조절한다.
- 패널·전송 버튼의 장식 이미지는 텍스트와 서버 데이터를 포함하지 않는 재사용 에셋으로 분리하고, 실제 닉네임·본문·시각은 HTML로 조합한다. 메시지 행 장식 이미지는 사용하지 않는다.
- 광장 채팅 전용 래스터 에셋은 `apps/web/src/features/chat/assets-cozy-pixel`에서 관리한다.

## 내비게이션

- 하단 성장 내비게이션은 캐릭터·장비·아이템·스킬·보석 다섯 항목을 표시한다. 보석 항목은 1-5 최초 클리어 전에는 해금 조건을 표시하고 이동을 막으며, 서버가 보석 콘텐츠 해금을 반환한 뒤 관리 화면으로 이동한다. 치장 뽑기·도감·성급 성장도 1-5 최초 클리어 후 서버 해금 상태에 따라 전체 메뉴와 관련 성장 진입점에서 제공한다.
- 메인 전투 화면에서 장비·아이템·스킬·거래소를 선택하면 전투 화면과 상태 엔진을 유지한 채 그 위에 해당 종이 창을 모달로 연다. 모달 뒤의 스테이지는 제거하지 않고 낮은 명도의 딤과 흐림으로 구분하며, 우측 상단 닫기·바깥 영역 선택·Esc로 닫으면 같은 스테이지 화면으로 돌아간다.
- 관리 화면의 성공·오류 등 일시적 결과 안내가 기존 콘텐츠의 높이·위치·크기를 바꾸는 경우에는 원래 레이아웃을 유지한 채 그 위에 확인 버튼이 있는 모달로 표시한다. 짧은 수치 상승 토스트처럼 레이아웃에 참여하지 않는 오버레이 피드백은 예외로 한다.
- 랭킹 화면은 좌상단 프로필, 우상단 관리 내비게이션, 하단 성장 내비게이션을 전투 화면과 동일한 공통 HUD 컴포넌트로 표시한다. 전투 화면의 상단 관리 내비게이션은 `치장 뽑기·콘텐츠·거래소·랭킹·메시지·설정` 여섯 항목을 같은 줄에 표시하고, 다른 관리 화면에서는 맨 앞에 메인 전투로 돌아가는 `전투`를 추가한다. 메시지는 알림과 사용자 메시지를 한 진입점에서 제공한다. 서버 기능이 연결되기 전까지 `준비 중` 상태로 이동을 막으며, 레드닷·숫자 배지는 아이콘 에셋에 포함하지 않고 서버 상태에 따라 동적으로 겹쳐 표시한다. 모든 화면의 `설정`은 같은 마이페이지 설정 모달을 연다. 공통 시각 언어는 밝은 아이보리 종이, 햇빛 받은 황금빛 목재, 짙은 초콜릿색 글자, 코랄 강조, 시안 경험치와 초록 보조 상태를 사용한다. 상단 항목과 화면 한켠 버튼은 반투명한 짙은 갈색 사각 셸, 밝은 단색 선 아이콘, 짧은 한글 이름을 사용한다. 웹의 한글 제목·본문·버튼·입력·HUD 수치는 사용자 제공 원본 `긱블 말랑이체 2` 웹폰트를 공용 UI 서체로 사용하고, 폰트 로드 실패 시 `Malgun Gothic`과 시스템 sans-serif 순서로 대체한다. 전체 관리 화면에서는 구형 전체 상단 탭을 중복 표시하지 않고 브라우저 문서 높이를 뷰포트에 고정하며, 긴 본문만 HUD 사이의 콘텐츠 영역에서 스크롤한다.
- 랭킹 화면은 별도 카드나 관리 콘텐츠 구역 안에 넣지 않고 시상식 배경이 브라우저 뷰포트 전체를 채우는 하나의 전용 페이지로 구성하며, 좌상단 프로필·우상단 관리 내비게이션·하단 성장 내비게이션은 그 장면 위에 오버레이한다. 상단 중앙에는 트로피 장식과 `전체·감자·고구마·옥수수` 탭을 두고, 탭을 바꾸면 왼쪽 `2·1·3` 단상의 상위 세 캐릭터와 오른쪽 전투력 순위표를 같은 범위로 함께 갱신한다. 단상 캐릭터는 단상 아트와 같은 비율 좌표계에 고정해 화면 배율이 달라도 발 위치가 단상 위에 유지되며, 전투의 `rest` 자세와 해당 계정의 장착 치장 상태, 닉네임·레벨·전투력을 함께 표시한다. 오른쪽 순위표 행에는 작은 캐릭터 썸네일을 반복하지 않고 순위·닉네임과 레벨/전문·전투력을 분리한다. 행 구분은 한 줄만 사용하고, 현재 사용자 강조 배경은 패널 테두리 안에서 잘리게 한다. 순위표 하단 고정 영역에는 상위 10위 포함 여부와 관계없이 현재 사용자의 순위·닉네임·레벨·전문·전투력을 항상 표시한다.
- 마이페이지는 별도 관리 화면으로 전환하지 않고 현재 화면 위에 모달로 연다. 닫으면 열기 전 화면과 탐색 상태로 돌아가며 메인 전투와 상태 엔진을 중단하지 않는다.
- 마이페이지는 캐릭터 요약 패널과 주력 재료·현재 레벨·경험치·쌀의 중복 표시를 두지 않는다. 하나의 종이 모달을 좌측 책갈피 내비게이션과 우측 콘텐츠로 나누고 별도 구분선은 두지 않으며, 좌측에는 `내 정보`, `소셜`, `설정`을 세로로 배치한다. 책갈피 색은 위에서부터 빨강·파랑·빨강으로 고정하고 선택 상태는 색 교체가 아닌 위치와 명도로 구분한다. `내 정보`의 오른쪽 콘텐츠에는 계정 정보, 캐릭터 상태, 비밀번호 변경을 한 흐름으로 배치하고 닉네임은 별도 변경 섹션을 만들지 않고 계정 정보의 닉네임 행에서 연필 버튼으로 인라인 수정한다. 계정 ID와 캐릭터 ID는 계정 정보 우측의 `식별 정보` 펼침 영역에서 확인한다. 시각 언어는 밝은 크림색 픽셀 종이, 짙은 갈색 외곽선, 코랄 포인트, 둥글고 굵은 글자와 아늑한 캐주얼 게임 UI를 사용하며, 종이 본문 위에 별도의 전체 사각 배경판을 겹치지 않는다. 1024×768 이상의 기준 화면에서는 기본 정보와 편집 영역을 모달 내부 스크롤 없이 노출하고, 그보다 좁은 화면에서만 단일 세로 스크롤을 허용한다. 새 마이페이지 전용 래스터 에셋은 `apps/web/src/features/profile/assets-cozy-pixel-v2`에서만 관리하고 이전 인증·재료 선택·프로필 에셋 및 구형 마이페이지 에셋 폴더를 참조하지 않는다.
- 캐릭터 창은 왼쪽 캐릭터·레벨·경험치와 오른쪽 기본·상세 능력치 배치를 유지하고 밝은 크림색 픽셀 종이, 짙은 갈색 외곽선, 코랄 강조, 둥근 능력치 행과 픽셀 아이콘을 사용한다. 캐릭터 창 전용 래스터 에셋은 `apps/web/src/features/character/assets-cozy-pixel`에서만 관리하고 이전 인증·재료 선택·캐릭터 에셋 이미지를 참조하지 않는다.
- 상단 관리 내비게이션의 `콘텐츠` 버튼은 현재 화면을 이동하거나 레이아웃 크기를 바꾸지 않고 배경만 딤·흐림 처리한 선택창을 겹쳐 연다. 선택창은 던전과 레이드를 같은 크기의 좌우 카드로 표시하며 우측 상단 닫기·바깥 영역 선택·`Esc`로 닫는다. 메시지·거래소·설정은 각각의 진입점을 유지한다.
- 설정 항목의 세부 범위는 별도 기획에서 정한다.
- 관리 화면과 스테이지 선택 화면을 탐색하는 동안 메인 전투는 계속된다. 스테이지 입장 또는 던전 전투 입장을 확정한 시점의 중단·복귀는 [전투 SSOT](../../combat/ssot.md)를 따른다.

## 거래소

- 거래소는 품목 분류·세부 필터로 탐색한 뒤 거래할 한 품목을 선택한다. 열 때마다 `간편 거래`로 시작하고 같은 품목·필터를 유지한 채 화면 안에서 `호가 기반 거래`로 전환한다. 구매·판매 방향은 주요 버튼으로 두고, 보조 보기인 호가 기반 거래 전환은 그보다 작은 체크박스로 구분한다. 창을 닫으면 보기 상태를 초기화한다.
- 품목 탐색은 강화재료의 계열→등급, 스킬북의 스킬→등급, 보석의 옵션→레벨·실제 수치로 묶고 그룹을 접거나 펼친다. 그룹과 분류를 탐색하거나 검색어를 입력하는 것만으로 주문 대상을 바꾸지 않으며 개별 품목을 직접 선택할 때 바꾼다. 전체 품목 검색은 분류에 제한되지 않고 이름·등급·레벨·수치의 검색어를 함께 적용하며, 결과가 없어도 기존 선택과 주문 입력을 유지한다. 선택 품목 요약에서 해당 분류·그룹으로 돌아갈 수 있다. 목록의 반복 시세는 선택 품목 상세에서 확인하며 보석은 같은 표시명이라도 실제 옵션 수치로 구분한다.
- 간편 구매는 다른 사용자의 현재 최저 매도호가를 수정 가능한 최대 단가로 채운 IOC, 간편 즉시 판매는 다른 사용자의 현재 최고 매수호가를 수정 가능한 최소 단가로 채운 IOC다. 내 판매 중 매물도 시장 가격대와 내 물량으로 표시하지만 구매 후보에서 제외하며, 다른 사용자 매물만 구매한다. 간편 판매는 즉시 판매와 지정가 판매 등록을 함께 제공한다.
- 간편 거래는 품목·가격대별 물량을 보고 구매 수량과 허용 최대 단가를 정하는 기존 경험을 기준으로 한다. 강화 재료 구매의 빠른 수량은 10·100·500개이며 클릭할 때마다 현재 수량에 더한다. 수량 입력 오른쪽에는 x 초기화 버튼을 제공한다. 최대 단가 입력을 제거하거나 최저 가격대 물량만 거래하도록 제한하지 않는다. 가격대별 물량을 차트 해석 없이 파악할 수 있어야 하며 개별 판매 매물 목록이라는 형식을 강제하지 않는다. 호가창은 같은 거래를 포함하면서 양방향 시장 정보와 확장 주문 조건을 다루는 경험으로 구분한다. 기능 중복을 없애기 위해 간편 거래의 기존 가격·수량 제어를 축소하지 않는다.
- 간편 화면의 중심 정보는 가격대별 물량이며 최고 매수호가·최저 매도호가·최근 체결가는 보조 정보로 구분한다. 사용 가능 쌀과 현재 판매 가능한 인벤토리 수량만 주문 입력 잔액으로 표시하며 escrow와 거래소 외부 보관량을 합쳐 사용 가능한 것처럼 보이지 않는다.
- 간편 구매는 판매 가격대별 물량과 해당 가격 이하 누적 타인 물량을 숫자로 표시하고, 입력한 최대 단가 안의 가격대와 요청 수량이 걸치는 물량을 구분한다. 즉시 판매는 구매 가격대를 높은 가격부터 읽고 최소 단가 이상 누적 물량을 사용한다. 판매 등록은 경쟁 판매 물량을 참고 정보로 표시하며 이를 즉시 판매 가능한 수요로 부르지 않는다. 내 물량은 별도 표시하고 시장 물량과 자산·공간 제약이 있는 개인 견적을 구분한다.
- 가격대 선택은 허용 단가 또는 판매 가격만 채우고 수량·방향·주문 유형을 바꾸거나 거래를 실행하지 않는다. 가격대는 더 보기로 이어 읽으며 부분 조회 누적을 전체 시장 물량으로 단정하지 않는다. 시세 갱신은 사용자가 입력한 단가를 덮어쓰지 않는다.
- 간편 구매는 구매 수량·개당 최대 허용 가격을, 간편 판매는 판매 수량과 판매 등록/바로 판매 목적에 맞는 가격 입력을 제공한다. 고급 매수·매도·즉시/지정가 제어는 호가창에 둔다. 같은 목적의 모드 전환은 품목·방향·수량·가격을 보존하며, 고급 대기 매수를 간편 구매로 자동 변경하지 않고 계속 작성 또는 명시적 즉시 구매 변경을 선택하게 한다.
- 거래 내용 확인은 최신 서버 견적을 다시 읽고 입력 수량·단가 한도·예상 금액과 최대 지출을 구분한다. 확인 중 입력을 고정하고 돌아가서 수정할 수 있으며, 최종 실행은 같은 확인의 멱등 키를 사용한다. 미체결 종료 수량은 최초 수량과 실제 체결 수량의 차이로 표시하고 서버 종료 잔량 0을 전량 거래로 해석하지 않는다.
- 호가 차트는 하나의 가격 x축과 공통 누적 수량 y축을 사용한다. 매수는 해당 가격 이상 주문의 누적량을 빨간 계단형 선·영역으로, 매도는 해당 가격 이하 주문의 누적량을 파란 계단형 선·영역으로 표시한다. 선·채움·선택점·눈금은 같은 좌표계를 사용하며 채움은 수량 0 기준선까지 이어진다. 양쪽 최우선 호가의 중간가격을 중심으로 좌우 동일 가격 범위를 표시하고, 음수 가격축을 피하려고 범위를 조정하면 그 사실을 표시한다. 한쪽 주문이 없으면 중간가격을 만들지 않고 조회된 가격 범위를 사용하며, 양쪽 모두 없으면 수량축과 격자를 유지한 빈 차트를 표시한다.
- 호가 차트는 방향별 최대 20개 가격대를 조회하고 실제 표시 가격대 수와 조회 한도를 함께 표시한다. 한도에 도달한 방향은 마지막 조회 가격 바깥으로 선·채움을 연장하지 않으며 조회 밖 주문이 더 있을 수 있음을 안내한다. 부분 조회 누적량을 전체 시장 물량으로 단정하거나 양쪽 수량축을 따로 늘려 물량 비율을 왜곡하지 않는다.
- 호가 차트는 선 중심으로 표시하고 현재 탐색·키보드 초점의 호가와 내 주문만 점으로 강조한다. 포인터는 차트 영역의 가로 가격 위치에서 같은 방향의 가까운 호가를 탐색하며 잔량·누적 수량·내 주문 수량을 고정 상세 영역에 표시한다. 탐색·초점만으로 주문 입력을 바꾸지 않고 클릭·터치·키보드 선택 시 해당 호가의 주문 가격만 입력한다. 스프레드 중앙·조회 범위 밖·주문 확인 중에는 포인터 가격 입력을 하지 않는다. 수량축의 큰 수는 축약할 수 있지만 상세 수량은 정확한 값으로 표시한다.
- 가격 추이는 기본 15분봉·최근 12시간으로 조회를 시작한다. 체결이 없으면 1일, 다시 없으면 2일로 자동 확장해 선택 기간을 함께 바꾼다. 2일에도 체결이 없으면 기간 축과 격자를 가진 빈 차트를 유지하고 체결 없음 상태를 차트 안에 표시한다. 차트 영역 높이는 데스크톱·모바일 모두 420px로 둔다.
- 가격 추이의 종가 연결선은 차트 축·보조 글자와 같은 저채도 잉크색을 사용해 캔들의 상승·하락 색과 구분한다. 연결선은 각 봉의 종가를 잇는 보조 표시이며 이동평균선으로 표현하지 않는다.

- 모든 주문은 제출 전에 방향·품목·수량·가격 상한 또는 하한, 예상 즉시 체결 수량·가격 범위·가중평균 단가, 최대 지출 또는 예상 판매금액·수수료·순정산액과 대기할 잔량을 확인한다.
- IOC가 일부만 체결되면 실제 수량·가격 범위·가중평균 단가·총액과 미체결 수량을 표시하고 종료한다. 미체결분을 자동 예약하거나 재제출하지 않는다.
- 내 주문은 활성·부분 체결·전체 체결·취소·만료와 체결분·미체결 잔량을 구분한다. 가격 변경·수량 증가가 우선순위와 만료를 초기화하고 수량 감소는 유지한다는 결과를 수정 확인에 표시한다.
- 물품 수령함은 구매 체결·판매 취소 반환·판매 만료 반환을 한곳에서 출처별로 구분하고 개별·전체 수령을 제공한다. 전체 수령이 일부만 성공하면 수령한 건과 공간 부족으로 남은 건을 구분한다. 판매 정산함은 IOC와 지정가 체결의 받을 쌀을 같은 흐름으로 관리한다.
- 호가창·내 주문·수령함·정산함은 3초 polling과 수동 새로고침으로 갱신한다. 낮은 revision 응답은 폐기하고 revision 간격·cursor 오류는 선택 품목 주문장·내 주문과 개인 요약을 다시 읽으며 복구 중 주문 폼을 비활성화한다. 표시 값이 예약된 가격·수량이 아니며 주문 제출 시 서버가 최신 상태를 다시 판정함을 주문 확인에 반영한다.
- 세부 설계 근거와 검증 질문은 [거래소 호가창 계획](../../../70-plans/market-order-book/README.md)을 따른다.

## 챕터·스테이지 선택

- 챕터 화면은 [MVP 범위](../../../70-plans/mvp-release/requirements.md)의 네 챕터를 한 월드맵에 표시한다. MVP에는 챕터 페이지 전환이나 지도 스크롤을 요구하지 않는다.
- 각 챕터는 번호·이름·스테이지 범위와 서버가 반환한 잠금·진행률·완료 상태를 표시한다. 진행률은 [스테이지 SSOT](../../world/ssot.md)의 최초 클리어 기준을 사용한다.
- 현재 전투 챕터와 진행 목표 챕터를 서로 다른 표식과 접근성 이름으로 구분한다. 두 상태는 같은 카드에 동시에 표시될 수 있다.
- 완료 챕터는 완료 배지와 100%를 함께 표시한다.
- 잠긴 챕터는 잠금 상태를 표시하고 선택 시 필요한 이전 챕터 마지막 스테이지를 안내한다. 클라이언트 비활성화만 신뢰하지 않고 서버의 접근 거부 결과를 같은 안내로 처리한다.
- 해금된 챕터 선택은 해당 스테이지 목록으로 이동할 뿐 현재 전투를 중단하거나 현재 스테이지·방치모드를 바꾸지 않는다.
- 스테이지 목록은 번호·이름과 클리어·현재 전투·잠금·반복 대상 상태를 표시한다. 상태는 색상뿐 아니라 아이콘·텍스트·접근성 이름으로 구분한다.
- 잠긴 스테이지도 선택할 수 있고 이름·주요 보상·`피해 N%`를 포함한 전체 상세를 공개한다. 입장과 반복 설정은 비활성화하며 서버 거부 결과도 같은 잠금 안내로 처리한다.
- 선택 상세는 주요 보상, `피해 N%`, 해당 스테이지의 최근 실패 1건을 표시한다. 실패 기록이 없으면 `실패 기록 없음`을 표시한다. 권장 레벨·권장 스펙·내 스펙·성장벽은 표시하지 않는다.
- 해금 스테이지의 입장을 확정하면 즉시 전투를 전환한다. 반복 대상 설정은 1~9에서만 제공하고, 서버가 반복 대상을 수락한 뒤 웹 상태 엔진의 현재 적용 상태와 다음 사이클 적용 예정 상태를 구분한다.
- 조회·입장·반복 설정 중에는 같은 요청의 중복 전송을 막는다. 인증 만료·서버 오류·콘텐츠 버전 불일치 시 캐시로 권한 상태를 추정하지 않고 공통 오류와 재시도 동작을 제공한다.
- 키보드와 포인터에서 같은 의미와 동작을 제공한다. 세부 화면 계약은 [스테이지 화면 계획](../../../70-plans/stage-screen/README.md)을 따른다.

## 알림

- 캐릭터 메뉴에는 레드닷을 표시하지 않는다.
- 장비는 제작·강화 가능한 항목이 새로 생길 때 레드닷을 표시한다. 장비 화면 진입 시 끄며, 확인 당시 가능했던 항목이 계속 가능하다는 이유로 다시 켜지 않고 이전에 불가능했던 새 제작·강화 항목이 가능해질 때 다시 켠다.
- 아이템은 [아이템 SSOT](../../items/ssot.md)의 제작 특수 아이템, 보석 또는 스킬북을 새로 획득할 때 레드닷을 표시한다. 감자·고구마·옥수수는 제외하며 아이템 화면 진입 시 끈다.
- 스킬은 요구 스킬북·쌀·조건을 충족해 이전에 불가능했던 새 강화가 가능해질 때 레드닷을 표시하고 스킬 화면 진입 시 끈다.
- 보석은 이전에 불가능했던 새 합성 조합이 가능해질 때 레드닷을 표시하고 보석 화면 진입 시 끈다. 신규 보석 획득 자체는 아이템 레드닷으로 알린다.
- 장비·아이템·스킬·보석은 존재 여부만 보이는 단순 레드닷을 사용한다.
- 우편은 미수령 첨부가 있는 우편 수를 숫자 배지로 표시한다. 거래 정산·관리자 보상·공지사항을 포함한 모든 우편은 첨부를 가지며, 수령 전에는 만료되지 않는다. 개별 수령과 모두 수령을 제공한다.

## 던전·레이드

- 현재 웹은 서버 레이드 상태가 연결된 경우에만 바로가기를 노출한다. 서버가 콘텐츠 비가용을 반환하면 `준비 중`, 해금 전이면 서버 `unlockStageId` 조건을, 해금 후에는 레이드 메인 화면을 제공한다. 전체 서버·브라우저 흐름 검증 상태는 [L-04 작업](../../../wiki/06-delivery/tasks/L-raid/l-04-raid-api-web-vertical-slice.md)에서 관리한다.
- `콘텐츠` 선택창의 던전 카드는 1-5 최초 클리어 전에는 해금 조건을 표시하고 클릭 이동을 제공하지 않으며, 서버가 보석 콘텐츠 해금을 반환한 뒤 던전 화면으로 이동한다. 레이드는 같은 선택창에서 계속 `준비 중` 잠금 상태로 표시한다.
- 메인 화면에는 보석 던전의 입장 가능 여부와 오늘 보상 수령 여부만 요약한다. 보스와 단계 선택은 던전 화면에서 수행한다.
- 던전 화면 탐색 중에는 메인 전투를 계속하며, 실제 던전 입장을 확정할 때만 단일 전투 타이머를 던전으로 전환한다.

## 인벤토리와 제외 기능

- MVP 인벤토리는 [아이템 SSOT](../../items/ssot.md)의 고정 200슬롯을 따르며 보석 획득·합성·보석함 개봉·던전 보상 전에 필요 슬롯을 검사한다.
- 빠른 전투, 빠른 전투 보상, 관련 버튼·잠금·향후 기능 예고를 제공하지 않는다.

## 화면 비율·크기

관리 UI는 16:9와 16:10을 지원하되 브라우저 뷰포트에 맞춰 반응형으로 배치한다. 트레이, 자동 시작, 항상 위, 클릭 통과, 데스크톱 창 위치 복원은 MVP에서 제공하지 않는다.

- 브라우저 환경 설정은 소리·볼륨·절전·프레임 제한 등 웹에서 지원 가능한 항목만 로컬 저장한다.
- 절전 모드는 자동전투를 끄는 기능이 아니다. 백그라운드 탭의 렌더링 부담을 낮추되 메인 전투·성장·보상은 [계정·저장 SSOT](../ssot.md)의 서버 기준 진행 정책을 따른다.
- 설정 화면의 로그아웃은 별도 설정 API를 만들지 않고 기존 인증 로그아웃 명령을 사용한다.
- 여러 기기에서 동일하게 유지해야 하는 계정 단위 알림이나 사용자 선호가 확정될 때만 서버 사용자 설정 조회·변경 API와 저장소를 둔다.
- 프레임 제한 허용 목록과 절전 모드의 구체적인 렌더링 정책은 후속 구현 계약에서 정한다. 탭 절전·discard의 진행 정책은 이 문서와 [계정·저장 SSOT](../ssot.md)에 따른다.

## UX 원칙
- 최초 로그인 후 주력 재료를 선택하지 않은 사용자는 선택 화면을 먼저 보고, 선택 완료 전에는 메인 화면과 게임 진행으로 진입하지 않는다.
- 로그인 화면에서 비밀번호 찾기로 이동할 수 있다. 등록 이메일 제출 후 계정 존재 여부를 구분하지 않는 안내를 표시하고, 이메일의 재설정 링크에서는 새 비밀번호와 확인값을 입력한 뒤 로그인 화면으로 돌아간다.
- 로그인 화면은 설정이 완료된 Google·Kakao·Naver·SSAFY GitLab 공급자만 각각 독립적으로 표시한다. 소셜 신규 사용자는 공급자 인증 뒤 별도 닉네임 확정 화면을 거치며, 기존 계정의 마이페이지에서는 공급자 연결·해제와 마지막 로그인 수단 보호 상태를 확인할 수 있다.

- 반복 클릭·수동 회복·수리와 기본 스테이지 입장권 같은 피로 요소를 메인 자동전투 루프에서 제거한다. 별도 보석 던전 입장권은 현재 수량과 충전 시각을 한 화면에서 관리한다.
- 자동 진행 상태, 현재 스테이지, 보상, 실패 이유는 짧고 명확하게 표시한다.
- 보석 관리 화면은 장착 슬롯, 합성 결과, 적용 중인 특수 옵션과 중복으로 비활성화된 옵션을 구분한다.
- 보석 던전 화면은 오늘의 보스, 보스별 독립 진행도, 입장권 수와 다음 충전 시각, 다음 도전 단계, 소탕 가능 단계와 예상 보상을 표시한다.
- 최초 클리어와 소탕 명령은 보상·입장권 결과를 서버 응답으로 표시하며 UI가 수량이나 성공 여부를 최종 계산하지 않는다.
- 관리 기능은 선택적 개입으로 제공하고, 전투 결과를 UI가 계산하지 않는다.
- 스킬 관리 화면은 `스킬 성장`과 `장착·우선순위`를 별도 탭으로 제공한다.
- 스킬 성장 탭은 역할, 등급·단계, 현재·다음 효과, 기본·보정·최종 성공률, 실패 보정, 책·쌀의 보유량과 요구량을 표시한다.
- 해금·승급·강화 결과는 같은 상세 패널에 성공 여부, 소비량, 새 등급·단계와 실패 보정을 즉시 반영한다.
- 재료 부족, 조건 미충족과 최대 단계에서는 실행 버튼을 비활성화하고 이유를 표시한다.
- 스킬북이 부족하면 해당 품목이 검색된 거래소 결과로 이동할 수 있다. 쌀 부족에는 거래소 구매 유도를 제공하지 않는다.
- 인벤토리의 스킬북은 공용 책 실루엣 위에 연결된 스킬의 확정 아이콘을 배지로 표시해 여섯 스킬을 시각적으로 구분한다. 목록과 상세에서는 카탈로그 표시명에 포함된 등급 접두사를 이름에서 분리하고, 상세 상단을 `스킬북`과 등급 배지로 표시한 뒤 고유 비법서 이름을 별도 제목으로 표시한다. 품목 ID와 카탈로그 표시명 자체는 변경하지 않는다.
- 장비의 다음 강화 재료가 부족하면 부족한 재료 행마다 거래소 구매 동작을 제공한다. 사용자는 한 번에 재료 하나만 선택하고, 본인 매물을 포함한 현재 거래소 최저 매물 단가와 본인 매물을 제외한 현재 구매 가능 최저 단가를 구분해 확인한 뒤 개당 허용 최대 단가를 입력해 구매를 명시적으로 확인한다.
- 장비 화면은 왼쪽의 기본 나무검을 든 젓가락 캐릭터 주위에 6개 장비 부위 선택 카드를 배치하고, 선택한 장비의 현재 상태와 다음 강화·승급 결과를 오른쪽에서 직접 비교한다. 그 아래 필요 재료는 현재 성장 비용에 포함된 아이템 재료만 세로 목록으로 표시하며, 쌀은 하단 실행 영역에서 `현재 보유량 / 필요량`으로 분리해 표시한다. 재료 각 행에는 사용자용 재료명·등급·보유량/필요량과 부족 여부 또는 충족 상태를 함께 표시하고, 부족 재료의 거래소 진입은 공용 거래소 아이콘을 담은 정사각형 버튼으로 제공한다. 기본 재료 구성은 지원 해상도의 한 화면에 표시하고, 항목이 가용 영역을 넘을 때는 재료 목록만 휠·터치·세로 드래그로 탐색할 수 있게 한다.
- 장비 제작·강화·승급 성공 시 같은 상세 패널의 서버 확정 상태만 갱신하고 별도 성공 화면이나 상단 성공 안내 행은 추가하지 않는다. 서버가 다시 계산한 종합전투력의 양의 증가량이 확인되면 중앙에 작은 `전투력 +N ↑` 태그 하나만 2.2초 동안 페이드인·아웃한다. 태그는 입력을 막지 않으며 오류·결과 불확실 안내는 명령 복구를 위해 유지한다.
- 구매가 일부만 체결되어 선택 재료 또는 다른 강화 비용의 부족량이 남으면 강화 버튼을 계속 비활성화한다. 모든 강화 비용을 충족해도 구매 결과만 반영하며, 사용자가 새 상태를 확인하고 기존 강화 확인을 별도로 완료하기 전에는 강화 명령을 전송하지 않는다.
- 장착·우선순위 탭은 액티브 4슬롯의 장착, 해제, 순서 변경과 저장을 제공하고 패시브 상시 적용 상태를 구분해 표시한다.
- 치장 뽑기·도감·성장은 [치장 SSOT](../../cosmetics/ssot.md)와 [치장 뽑기 요구사항](../../../70-plans/cosmetic-gacha/requirements.md)의 서버 확정 상태를 표시한다.
- 치장 화면은 현재 쌀·티켓, 1회·10회 예상 티켓 우선 결제, 등급·개별 확률을 보여준다. 최신 표시 상태로 결제할 수 없으면 명령을 비활성화하되 최종 권한은 서버에 둔다.
- 서버가 확정한 순서의 결과, 신규·중복, 도감 진척, 세트 변경, 소비 재화와 잔액을 표시한다. 명령 중 반복 클릭은 막지만 동시성 보장으로 간주하지 않는다.
- 서버 성공 후에만 결과 애니메이션을 재생하며, 건너뛰기·닫기는 이미 커밋된 결과를 취소하지 않는다. 등록 확인은 서버가 산정한 `1개 등록` 또는 `다음 성급까지 등록` 필요 수량과 선택 상자 수령 가능량 오류를 표시한다.
- UI는 확률·결과·세트 효과·도감 등록을 로컬 계산하지 않는다.
- 입력 간섭·접근성·해상도·CPU·배터리 영향을 검증한다.

프레임·컴포넌트·문구의 정본은 추후 디자인 계약과 localization으로 분리한다. 현재 화면 목록은 [K 작업 색인](../../../wiki/06-delivery/tasks/K-client-ux/_index.md)만 참조한다.
