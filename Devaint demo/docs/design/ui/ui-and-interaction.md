# UI·입력·상호작용

[분야 개요](README.md)

## 목적과 기준

플레이어가 현재 상태와 가능한 행동을 이해하도록 한다. 제품 요구와 현재 UI의 연결 범위를 구분한다. 입력·정지 구현은 [HUD](../../development/presentation/ui/hud.md), 대화는 [NPC·직선 대화](../../development/presentation/narrative/narrative-dialogue.md), 목표 구조는 [표현·대화·GUI 설계](../../development/architecture/presentation-narrative-ui.md)가 기준이다.

인벤토리는 [승인된 HTML 시안](../../../resources/ui/craft-ux-html-20261116/preview/index.html)의 배치와 조작 흐름을 Unity의 실제 런 무기·잉크 모델에 연결한다. [팀원용 HTML 가이드](../../../resources/ui/craft-ux-html-20261116/preview/team-guide.html)의 화면은 시안 캡처다. Unity의 무기·잉크·팔레트 그림은 기존 승인 에셋을 사용하며, HTML의 팔레트 도형을 게임 그림으로 복사하지 않는다.

## 확정된 전달 원칙

- 화면 문구에는 중간점(·, ㆍ, ・)을 쓰지 않는다. 서로 다른 정보는 슬래시 또는 줄바꿈, 나열은 쉼표로 구분한다. 피그마의 중간점 표기보다 이 원칙을 우선하며 데이터 ID나 능력치 문자열의 내부 구분자는 변경하지 않는다.
- 화면 설정 유지 확인, 무기 이름 변경, 로딩 실패는 피그마의 키캡 색상과 버튼 문구, 간격, 공통 프레임을 따른다. 화면 설정의 자동 복귀는 기존 15초를 유지하고 실행 중인 해상도를 표시한다. 무기 이름의 길이 검사와 한글 조합 처리, 로딩 재시도와 진행 보존은 유지한다.
- 공통 프레임은 채택한 A의 한 줄 테두리와 1번 직각 모서리를 사용한다. 네 모서리를 깎거나 둥글리지 않고 끝까지 채우며, 원본 내부 질감은 유지하고 외곽선은 별도 픽셀 격자로 그린다. 960 기준 작은 창은 1px, 면적이 320×320px 이상인 큰 창은 2px 테두리를 화면 배율에 맞는 정수 화소 두께로 표시하고, 고해상도 원본의 흐린 외곽선이나 바깥 흔적은 사용하지 않는다.
- 이 공통 프레임을 사용하는 이름 변경창과 첫 런 튜토리얼의 조작·스케치·잉크·팔레트·활성화·내구도 안내는 동일한 픽셀 프레임 생성 경로를 사용한다. 기존 튜토리얼 프리팹도 열 때 이전 프레임을 숨기고 새 프레임으로 전환한다. UI 미리보기의 1920 좌표계는 기준 배율 2를 지정해 게임의 960 좌표계와 같은 테두리 비율을 유지한다.
- 상점을 여는 입력은 구매로 이어지지 않는다. F 또는 패드 확인 버튼을 놓은 뒤 다시 눌러야 선택한 상품을 구매한다.
- 비호환 잉크는 비활성 상태·이유·재활성 조건을 설명한다. 색만으로 구분하지 않는다.
- 보상·인벤토리·공통 메뉴의 키캡은 마지막 사용 장치에 맞춰 표시하고, 열린 화면에서도 장치를 바꾸면 갱신한다. 키보드의 고정 메뉴 F/Esc와 패드의 확인/취소 버튼을 구분한다. 구체적인 장치별 배치는 [다중 입력 장치](../../development/presentation/ui/input-devices.md)의 기본 조작을 따른다.
- 인벤토리의 장비·잉크는 아이콘과 표시명의 가로 중심을 맞추며, 아이콘과 표시명 사이의 여백을 포함한 전체 항목 영역을 클릭해 선택할 수 있다.
- 인벤토리의 상위 탭은 가방·장비다. 내용의 위에서 ↑로 상위 탭에 접근하고 ←/→로 이동, ↓/F로 내용에 돌아간다. Q/E와 A/D 탭 단축키 및 표시는 사용하지 않는다. 탭 문구의 위치·글씨 크기는 고정한다. 마지막 탭과 Esc 닫기 사이에는 충분한 간격과 세로 구분선을 둔다. 선택한 행동은 노란색(`#D9CB84`)이며 붓칠 배경이나 밑줄 강조는 사용하지 않는다. 일반 화면 하단에는 키보드 기준 방향키 선택, F 실행, Esc 돌아가기, W/S 설명 스크롤을 공통 크기로 표시하고, 패드 사용 시 스틱/십자키, 확인, 취소, 오른쪽 스틱 안내로 전환한다.
- 가방 분류는 스케치·잉크다. 분류의 ←/→는 분류만 이동하며 ↓/F로 목록에 들어가야 첫 항목을 선택한다. 스케치 목록은 미확정·확정 무기를 함께 표시한다. 미확정 아이콘은 흑백, 확정 아이콘은 원래 색상이며 비선택 무기를 흐리게 하지 않는다. 선택한 이름과 상태를 노란색으로 표시한다. 미확정 F는 해당 무기 제작, 확정 F는 장착 자리 선택으로 이동한다. 잉크의 F는 첫 미확정 스케치를 선택하며 없으면 이유를 표시한다.
- 잉크 목록은 선택 항목만 고유 색상, 나머지는 흑백으로 표시한다. 상세의 잉크 제목과 적용한 잉크 제목은 고유 색상이다. 목록 횟수는 `남은 횟수/총 횟수`, 상세는 `남은 횟수 n회 / 총 횟수 n회`다. 남은 횟수는 다른 미확정 무기에 예약된 적용까지 제외한 부여 가능 횟수이며, 총 횟수는 런에서 해당 잉크를 획득하며 받은 누적 횟수다. 확정 때만 실제 사용 횟수를 소모한다.
- 제작은 왼쪽 팔레트·현재 적용한 잉크, 오른쪽 보유 잉크다. ←/→로 칸을 고른 뒤 F로 오른쪽 3열 잉크 목록에 진입한다. 진입 전 오른쪽은 흐리고 상세·적용 버튼을 숨긴다. 방향키로 잉크를 고르고 F로 선택한 칸에 적용하면 팔레트로 돌아온다. Esc는 적용 없이 돌아온다. R은 선택한 칸의 잉크를 비운다. ↓는 제작하기·돌아가기 행동으로 이동하고 ←/→·F로 실행, ↑로 팔레트에 복귀한다. 행동 선택 중 위 편집 정보를 흐리게 하며 좌우 행동 구분선과 버튼 높이를 맞춘다.
- 제작하기는 팔레트·묶은 잉크 요약을 담은 확인창을 연다. 버튼 순서는 제작 확정·계속 편집이며 기본 선택은 제작 확정이다. ←/→·F로 선택하며 계속 편집에 별도 Esc 키캡을 붙이지 않는다. 확정 시 횟수 소모·잉크 변경과 빈 칸 추가 불가 안내는 아래 구분선 밑에서 버튼과 같은 줄에 작게 표시한다. 모델의 색상 일치 강화, 전체 미확정 무기의 예약, 빈 칸 고정 규칙은 유지한다.
- 제작 완료는 상단 공통 탭과 하단 공통 조작 안내를 숨긴다. 제작 완료 알림 아래 새 무기의 이름·아이콘·내구도·팔레트 카드를 중앙에 표시하고, 현재 무기 1/2 카드는 아래 양옆에 둔다. 처음에는 교체 대상을 선택하지 않으며 F를 표시하지 않는다. ←/→로 대상을 고르면 새 무기 카드가 해당 슬롯과 같은 X축으로 부드럽게 이동한다. 두 카드 사이에는 새 무기에서 기존 슬롯으로 내려가는 화살표를 반복 이동시키고 그 옆에 F 장착/교체를 표시한다. 방향 전환 때 현재 위치에서 이어서 이동하며 실제 장착은 F를 눌렀을 때만 바뀐다. ↓로 행동을 선택하지 않는다. F 장착하기/교체하기, C 보관하기는 즉시 처리 후 전투로 복귀하며 별도 결과 확인 화면을 추가하지 않는다. 교체된 기존 무기는 가방에 보관한다. 빈 무기 칸의 이름은 맨손이다.
- 장비 위는 실제 장착 중인 두 무기, 아래는 확정했지만 장착하지 않은 보관 무기만 표시한다. 위 카드는 아이콘 왼쪽, 이름·내구도 오른쪽이며 중앙의 X와 ↔로 자리 교환을 표시한다. 선택하지 않은 장비는 흐리게 한다. 오른쪽 상세는 이름 옆 N 이름 변경, 기본 공격·스킬 이름/설명·팔레트·묶은 적용 효과이며 아래 구분선 밑에 F 장착하기/교체하기를 두며 무기 해제 버튼과 R 해제 입력은 제공하지 않는다. 내구도 숫자는 항상 막대 옆이다. 스킬 이름 앞에 이동/범위/후속타 등의 분류를 붙이지 않는다.
- 장비에서 위 칸을 먼저 고른 뒤 F → 보관 무기 선택 → F는 기억한 칸에 즉시 장착한다. 아래 보관 무기를 먼저 고른 뒤 F는 장착 자리 선택 → ←/→·F 순서다. 같은 칸에 이미 장착한 무기는 장착 중으로 비활성화하고, 반대 칸의 장착 무기를 옮길 때는 실제 자리 교환 규칙을 따른다. Esc는 선택 단계만 취소한다. 공격의 실제 몬스터 명중 후 5초 전투 상태에서는 장착·해제·교체·자리 교환을 막고, 인벤토리 정지 중에는 이 시간도 정지한다. 이름 변경은 1~20자와 한글 조합 보호를 유지한다. ↓로 저장/취소 행동을 선택한 뒤 F로 실행하고, Esc는 즉시 취소한다. Enter와 숫자패드 Enter는 저장하지 않는다. 입력 칸의 F는 글자 입력으로 유지하며 두 행동에는 동일한 높이의 테두리 키캡(F 저장 / Esc 취소)을 표시한다.
- 표시 UI가 피해·보상·소유권을 직접 확정하지 않는다. 실제 상태를 공급받고 사용자 의도를 전달한다.
- 단축키 설정의 기본값 복원은 피그마의 확인창을 먼저 연다. F·Esc·취소는 키 설정을 유지하고 같은 설정 화면으로 돌아가며, G·복원만 기존 키보드 기본값 복원을 실행한다. 확인 중에는 뒤 목록의 입력과 키 재지정을 막고, 확인창을 닫는 입력이 뒤 화면까지 닫지 않도록 한다.
- 화면 설정에서 창 모드·해상도에 미적용 변경이 있을 때 다른 설정 분류를 선택하면 피그마의 미적용 설정 확인창을 연다. F·Esc·계속 설정은 임시 변경값을 유지하며 화면 설정에 남는다. G·변경 취소는 마지막 적용값으로 임시 값을 되돌리고 요청한 분류로 이동한다. 이 선택은 화면 설정을 실제로 적용하지 않는다. 변경이 없거나 화면 유지 확인을 마친 경우에는 확인창 없이 분류를 이동한다.
- UI를 닫으면 해당 UI가 요청한 입력 제한·정지만 반환한다. 다른 UI나 대화의 제한을 임의로 해제하지 않는다.
- 실제 1·2챕터 전체 지도는 M 또는 Esc로 닫는다. 열려 있는 동안 자신의 제어 범위로 전투·상호작용 입력과 시뮬레이션을 정지하며, 비활성화·씬 종료 때도 자기 범위만 반환한다. 이번 런에서 발견한 방과 연결 통로를 표시하며 미탐험 연결은 방향 물음표만 표시한다. 전체 지도와 미니맵의 지형 테두리는 실제 고체 벽·바닥에만 그린다. 미탐험 영역과 맞닿아 있어도 실제로 뚫린 통로 입구는 상하좌우 모두 테두리를 끊으며, 이 표시를 위해 미탐험 방의 내부·종류·내용을 공개하지 않는다. 탐험 상태를 별도 영구 저장하지 않는다. 화면 배치·범례·완료 표시는 [화면별 요구](screens.md)의 피그마 지도 기준을 따른다.
- 인벤토리와 일시정지 메뉴는 동시에 열 수 없다. 한쪽이 열려 있으면 다른 쪽의 열기 요청을 무시한다. 인벤토리의 Esc는 현재 선택 단계의 취소·뒤로가기 또는 닫기로만 소비하며, 같은 입력으로 일시정지 메뉴를 열지 않는다.
- HUD의 ESC는 열린 일반 대화상자를 먼저 닫고, 그 외에는 일시정지를 전환한다. 이것을 아직 없는 전체 화면 라우터의 정책으로 확대하지 않는다.
- 대화에서 오래된 표시 토큰·중복 클릭이 다음 줄을 건너뛰지 않게 한다. 대화 완료가 자동 보상·퀘스트 완료를 뜻하지 않는다.
- 채택 전투 HUD는 큰 무기 원 옆에 기본공격·스킬의 실제 키캡을 표시한다. 전체 조작 설명 두 줄은 일반 배포에서 숨기고, Editor/Development Build에서 조작 안내 단축키(기본 H) 또는 일시정지 메뉴로 켠다. 보스 출구의 상황 안내는 유지한다. 이동은 오프닝에서 안내하므로 1챕터 벽타기 안내는 표시하지 않는다. 정비소 도착·방 진입 시 상단 안내는 표시하지 않고, 이용 가능한 NPC 가까이에서만 머리 위에 상호작용 키(F)를 표시한다. 정비소 UI·대화·일시정지 중에는 키를 숨긴다. 두 챕터의 정비소 NPC는 플레이어와 같은 잉크 외곽선을 사용한다. 배치와 연결 범위는 [채택 전투 HUD·출발 팔레트](../../development/presentation/ui/combat-hud-approved.md)를 따른다.


## 키보드 기본값과 향후 변경 설정

A/S는 무기 1/2의 기본공격, Q/W은 무기 1/2의 스킬, Space는 점프다. 공격은 누를 때마다 한 번 요청하며 키를 누르고 있어도 자동으로 반복하지 않는다. 차징 스킬은 해당 슬롯 키의 유지·해제로 충전하며, 미사일 수동 폭발은 새 스킬 키 입력을 요구한다. 월드 상호작용(정비소·보스 출구·보스 입장/2페이즈 연출 건너뛰기)은 F, 1번/2번 포탈 설치·재설치는 C/V이고, 두 포탈 사이 왕복은 포탈 가까이에서 F, 전투 리셋은 F5다. 가방이 열린 동안의 E 장착은 가방 화면 전용 키다. 사용자가 키를 바꿀 수 있도록 물리 입력 매핑을 행동 요청과 분리하며, 실제 설정 화면·중복 처리·저장·초기화 UI는 후속 작업이다.

## 여러 입력 장치 지원

기본 배치는 키보드·마우스와 DualSense·Xbox·일반 Gamepad를 같은 이동·슬롯별 공격·점프·상호작용·UI 액션에 연결한다. 패드는 스틱/십자키 이동, South 점프, East 대시, West/North 기본 1/2, 좌/우 trigger 스킬 1/2, 오른쪽 shoulder 상호작용, 왼쪽 shoulder 가방, Start 일시정지, Select 지도를 사용한다. 열린 화면의 East는 취소로 한 번 소비하고 게임 진행 중에는 대시로 처리한다. 타이틀·마을 오프닝/대화·시설·챕터 1/2·제품 공통 GUI가 이 입력을 사용한다. 누름·유지·해제와 기존 전투 규칙은 장치가 바뀌어도 유지한다. HUD·월드 키캡과 시스템 안내·포탈 설명 대사·가방·지도·정비소의 조작 문구는 실제 바인딩과 마지막 사용 장치에 맞춰 표시한다. 키보드 키를 바꾸거나 열린 튜토리얼 중 패드로 전환해도 같은 액션의 현재 키·버튼을 표시하며, 시범과 진행 상태를 다시 시작하지 않는다. 공통 전투는 실제 행동 시작·확정 명중·피격의 이벤트 진동을 제공하고, 네이티브 DualSense의 L2/R2는 슬롯별 스킬 준비·시작·차지 상태에 따라 저항과 짧은 진동을 적용한다. 패드 전용 그림·패드 재설정 화면·LED·파형 기반 HD 햅틱과 실물 촉감 조정은 후속 범위다. 전체 배치와 구현 경계는 [다중 입력 장치 구조](../../development/presentation/ui/input-devices.md)를 따른다.

사용자 결정(2026-11-16): 창 하단 조작 안내는 인벤토리의 크기로 통일한다. 960×540 기준 글씨 10, 키캡 높이 18.7을 공통 테마 값으로 사용한다. 가방·제작·장비, 마을 기록창, 보상·증강·상점, 설정·일시정지·결과, 지도, 튜토리얼·노트 하단 안내에 적용한다. 2배 좌표로 만드는 지도도 화면에 표시되는 크기는 같다. 월드 상호작용 키, 설명 안의 시범 키와 주요 행동 버튼은 각 역할의 크기를 유지한다.

사용자 결정(2026-11-13): 글자로 쓰는 키 안내는 모든 화면에서 `[키] 동작` 한 형식(`[F] 닫기`, `[Space] 확인`, `[Esc] 건너뛰기`)으로 쓰고, 키캡 그림이 있는 안내는 키캡 다음에 동작을 둔다. 키 이름은 바꾼 키 설정을 따르며 짧은 이름을 쓴다. 방향키는 ←↑→↓, 왼쪽·오른쪽 Shift·Ctrl·Alt는 `Shift`·`Ctrl`·`Alt`, Escape는 `Esc`, 마우스는 `좌클릭`처럼 쓰고 `Left Shift` 같은 엔진 이름은 쓰지 않는다(`LocalInput.KeyboardKeyName`). 단축키 설정 화면만 두 칸을 구분하려고 `좌 Shift`·`우 Shift`·`Num Enter`를 쓴다.

키보드 이동의 기본값은 ←/→, 벽 오르기는 ↑, 아래 방향과 발판 내려가기는 ↓를 쓴다. 시작 마을과 챕터의 일시정지 메뉴에서 **단축키**를 열어 각 키를 변경할 수 있다. 변경 즉시 저장하고 **기본값 복원**으로 되돌릴 수 있다.

## 미정과 확인 대상

타이틀·결과 화면의 추가 배치 검토, 다른 제품 화면 전체의 포커스 복귀, 제품 NPC 상호작용 거리·전투 중 허용 여부는 후속 범위다. 현재 제품 공통 GUI의 키보드·패드 탐색·확인·취소 연결과 구분한다. 공격 키의 현 문서 차이는 [충돌 목록](../../overview/open-questions.md)을 따른다.

## 구현·화면 검증

해상도별 배치·텍스트 잘림·게이지 0/최대값, 클릭 시 전투 입력 차단, 중첩 UI의 닫기 순서, 비활성화·재바인딩 시 제어 반환, 정지 중 입력의 재개 직후 실행 방지를 확인한다. 프리팹 구조 검사와 실제 이미지가 있는 화면 검증을 따로 기록한다.

타이틀은 중앙 종이재 경계의 왼쪽에 밝은 세계와 오른쪽을 보는 인간, 오른쪽에 스케치 세계와 왼쪽을 보는 잉크를 두고 로고·메뉴를 중앙 정렬한다. 양쪽 주인공은 대기 모션을 유지한다. 시작하기·설정·종료는 공용 꾹꾹체로 표시하고, 포인터·키보드·패드 선택에 따라 노란 붓펜을 해당 행으로 옮긴다. 풍경은 창 전체를 채우고, 로고·메뉴는 1600×900 안전 영역을 균일 배율로 확대·축소한다. 캐릭터와 구름은 원본 비율을 유지한다.

**시작하기**를 누르면 반반 구도를 바꾸지 않고 비배율 시간 1.2초 동안 페이드아웃하고, 검은 화면 한 프레임 뒤 시작 마을로 한 번 이동한다. 세부 시간과 움직임 규칙은 [화면별 타이틀 명세](screens.md)를 따른다. 연출 중 중복 입력은 받지 않으며 화면 흔들림·섬광·글리치 효과음은 쓰지 않는다. **설정**은 인게임과 같은 화면·소리·조작 탭과 화면 변경 15초 확인창, 단축키 변경을 사용한다. Esc·패드 취소로 닫고 설정 행에 포커스를 돌려준다. 조작 탭은 별도 화면 없이 스크롤 키 목록을 표시한다. **종료**는 게임을 닫는다(Editor에서는 Play 모드를 끝낸다). 타이틀의 소제목은 표시하지 않는다. 2챕터 준비 중 안내는 기존 반환 메뉴를 유지한다.


화면별 정보와 조작은 [화면 명세](screens.md)를 따른다.

## 메뉴 선택과 보상 수령

기존 화면 배치는 유지한다. 설정은 왼쪽 세로 탭에서 ↑/↓로 즉시 분류를 바꾸고 →로 오른쪽 본문에 진입한다. 본문 위/왼쪽 경계에서 활성 탭으로 돌아갈 수 있으며 음량 슬라이더의 ←/→는 값 조절을 유지한다. 공방의 기존 가로 탭은 ←/→로 즉시 전환하고 ↓로 내용에 진입한다. 탭에 머무는 동안 본문은 흐리게 표시하고 진입하면 선명하게 표시한다. 설정 본문의 포커스 행 제목은 같은 포인트 노랑으로 표시한다. 설정의 미적용 화면 변경 확인과 15초 화면 복구 확인은 유지한다.

일반 메뉴·탭의 포커스는 인벤토리와 같은 노란 글씨(#D9CB84)로 표시하며 선택용 붓칠을 사용하지 않는다. 타이틀의 별도 연출 자산은 유지한다. 보상·증강은 선택한 이름을 노랗게 표시하고 아이콘 확대를 작게 하며 선택 카드 아래에 [F] 선택하기를 표시한다. 보상 선택은 실제 지급 후 추가 영수증/가방 넣기 확인 없이 닫는다. 다음 보상이 대기 중이면 해당 보상을 이어서 표시한다. 상점 구매도 추가 영수증 없이 구매 결과를 진열 상태에 반영한다.
