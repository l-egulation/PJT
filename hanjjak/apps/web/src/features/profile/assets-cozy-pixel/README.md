# Cozy Pixel profile assets

이 폴더는 밝고 포근한 픽셀 UI 버전의 마이페이지 전용 래스터 에셋 경계다.

- `paper-texture-cozy.png`: 사용자 제공 시안의 밝은 픽셀 종이 표면을 기준으로 새로 생성한 배경
- `sprout-icon-32.png`: 섹션 표식용 투명 픽셀 새싹 아이콘
- `character-rest-192.png`: 사용자 제공 기본 rest 프레임을 투명 192×192 캔버스로 변환한 캐릭터

마이페이지의 이미지 참조는 이 폴더 안에서만 추가한다. 이전 인증·재료 선택·프로필 에셋 폴더의 이미지를 재사용하지 않는다.
