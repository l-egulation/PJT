# 2스테이지 보스 동작 확정본 v8

로즈·블루(1·2페이즈 공격, 기절, 컷씬)와 흑화 블루(3페이즈 공격, 이동, 기절, 처치, 등장 변신) 26동작 692장. Unity 연결 전이다.

## 규격

- `runtime/<id>/frames/NN.png`: 384x256 RGBA, 발 기준점 (192, 232). 바닥은 y 231(발 밑 줄). `NN` 은 Aether 시트의 원래 칸 번호다.
- `runtime/<id>/sheet.png`: Unity 용 시트. `frames` 순서대로 8열 격자(왼쪽 위부터), 칸 384x256(최대 3072x1280).
- `runtime/<id>/motion.json`: `sequence`(재생할 칸 순서, 같은 칸 반복 있음)와 `durationsMs`. R1 만 반복.
- 크기: 로즈 키 120px, 블루 139px, 흑화 블루 179px(기본 자세와 같은 배율). 색은 기본 자세 마스터 팔레트 안(로즈 9·블루 11·흑화 8색).
- `motions.json`: 전체 목록과 쓰임(게임 패턴·컷씬 시간).

## 만든 과정

1. Aether 6x6 시트 생성(입력·프롬프트·원본 시트는 `boss-phase1-attacks-20261107`, `boss-phase2-attacks-20261107`, `boss-cutscene-motions-20261107`, `boss-phase3-redesign-20261107` 의 `source/`).
2. 칸 고르기·입 지우기 후 동작별 zip, 배경 제거·팔레트·384x256 변환은 별도 작업(보정본 v5→v8, 부위색 정리).
3. 이 그룹에서 더한 보정
   - R8(쓰러진 채 겨눔): v8 이 몸 상자 높이 맞춤 때문에 0.83배로 커져 있어, 발 기준점 둘레 0.725배 다수색 축소로 0.6배(다른 로즈와 같은 크기)로 맞췄다.
   - 발 보정: 조준 사격·R2·R3(+6px), 하늘 일제 사격(+6~7), 잉크 던지기(+4), 잉크 터뜨리기(+2~3), R8(+1) 은 기본 자세 칸만 바닥에 있고 나머지가 떠 있었다. 칸마다 바닥에 닿게 세로로만 옮겼다(`motion.json` 의 `footShiftPx`). 떠오르기·B2·변신·공중 3연사·R4 깡충 뛰기는 원래 뜨는 동작이라 두었다.
   - 그림에 남은 투사체 지움: 하늘 일제 사격 09~15, 잉크 던지기 06~08(날아가는 구슬), 조준 사격 07, 공중 3연사 11·22·32·33. 게임이 화살·잉크 공을 이펙트로 따로 그리기 때문(`projectilePixelsRemoved`). 블루가 손에 띄워 두는 구슬과 R4 놀람 효과선은 남겼다.
