# 이동 속도 증가 이펙트 시험판

노랑 잉크 이동 속도 파츠 4종(가벼운 발끝·교대 질주·파열 가속·승전 보폭)이 플레이어에게 이동 속도 증가를 걸 때 함께 쓰는 이펙트 후보다. 발동 조건만 다르고 결과는 같은 지속 버프(가벼운 발끝 3초, 교대 질주 1.5초, 파열 가속 3초, 승전 보폭 4초)라 한 벌을 같이 쓴다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다.

[덧베기](../덧베기/README.md)와 같은 빛나는 선 방식의 [pixelfx](https://github.com/patch-gg/pixelfx)(MIT) 이펙트다. 화소마다 선분까지의 거리를 재서 흰 심 → 노랑 → 반투명 번짐으로 칠한다. 종이 배경에서 띄도록 줄기 몸은 진한 노랑이고 흰색은 가운데에만 있다.

- `speed-burst.js`: 버프가 걸리는 순간(0.28초). 몸 뒤로 긴 빛줄기 넷이 한 장 만에 뻗었다가 바로 몸 쪽으로 빨려 들고, 발밑에 가로 섬광이 스친다.
- `speed-trail.js`: 버프가 유지되는 동안 반복(0.64초). 발에서 얼굴 높이(발 위 56px)까지 줄기 열 개가 각각 0.32초 동안 몸 뒤에서 약 48px 밀려나며, 꼬리가 머리를 따라잡아 짧아지고 흐리게 사라진다. 옵션 `lanes`(개수, 기본 10)·`len`(길이 배율, 1.4)·`top`(가장 높은 줄기, -56)·`width`(굵기, 1.5)로 조절한다. 두건 위로 넘어가면 어색해서 얼굴 높이까지만 둔다. `glowLine`을 덧베기와 공유할 수 있게 내보낸다.
- `speed-end.js`: 버프가 끝날 때(0.36초). 반복이 주기 0으로 돌아온 장에서 넘겨받아, 이미 흐르던 줄기만 끝까지 흘려 보내고 새 줄기는 만들지 않는다.
- `export.mjs`: 세 시트를 Git 제외 `outputs/pixelfx/speed/`에 `speed-burst_yellow`, `speed-trail_yellow`, `speed-end_yellow`로 뽑는다.

```sh
node 전투테스트/이동속도/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- `speed-burst` 128×72, 8장(마지막은 빈 장), `speed-trail` 176×96, 16장 반복, `speed-end` 176×96, 10장(마지막은 빈 장). 25fps, PPU32 게임 화소 1:1.
- 피벗은 플레이어 발 가운데(바닥). 오른쪽을 보는 판만 뽑았고 줄기는 왼쪽(뒤)으로 흐른다. 캔버스가 뒤쪽으로만 넓으니 왼쪽을 보면 반드시 시트를 좌우 반전한다(이펙트 안에서 뒤집으면 줄기가 잘린다).
- 미리보기에서는 발동 0.12초 뒤부터 유지 반복을 겹쳐 시작했다. 버프가 끝나면 반복이 12장 주기를 다 돈 장에서 `speed-end`로 넘긴다(최대 0.64초 늦게 끝나 보인다).
- 노랑 팔레트는 임시값이다. 기획에는 같은 버프의 갱신·중첩 표시가 정해져 있지 않다.

## 확인한 범위

1스테이지 실제 게임 캡처의 플레이어(왼쪽을 봄) 위에서 발동 → 유지 반복을 렌더링으로만 봤다. 플레이어가 실제로 달리는 동작·Unity 실행은 확인하지 않았다.
