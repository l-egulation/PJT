# 단검·망치 승인 공격 아트

2026-10-27 사용자 수정본이다. 단검은 1~4타 14장, 망치는 현재 등록된 1~2타 10장이다. 망치 F10은 사용자 수정 F01과 픽셀·PNG가 동일하다. 다른 사용자 프레임과 편집기의 프레임별 시간은 그대로 보존한다.

`manifest.json`은 공유 ZIP 안의 `attack/` 파일 해시·규격·순서·편집 시간과 기존 Unity Resource 대응 경로를 정의한다. PNG·이미지 내장 편집 JSON·GIF는 공유 드라이브 ZIP으로 배포한다.

ZIP의 `attack/dagger/editor.json`, `attack/hammer/editor.json`은 공통 픽셀 편집기에서 불러올 수 있다. PNG는 Point 필터·무압축으로 사용하고 기존 프레임별 피벗을 유지한다.

Unity에는 아직 반영하지 않았다. 연결 시 기존 Resource 경로의 이미지와 해당 모션의 매체 바인딩을 함께 확인하고 `.meta` GUID를 유지한다. 편집 JSON의 `ms`는 아트 검토 시간이며, 이것만으로 `data/combat/`의 타격 시점·판정·공격 간격을 변경하지 않는다. 원본 가져오기 스크립트를 다시 실행할 때 예전 아트가 덮어쓰지 않도록 입력 원본도 함께 갱신해야 한다.

공유 ZIP: 단검망치_공격_대시_확정_20261027.zip (`01_승인에셋`).

# 대시 연출 승인 시안

숙인 자세를 실제 이동 종료까지 유지하고, 멈춘 뒤 100ms 동안 두 복귀 자세를 재생한다. 기본검 원본 대시 5장의 픽셀은 변경하지 않았다. 잔상은 실제로 지나간 위치의 당시 Sprite를 고정해 남긴다.

`presentation-recipe.json`이 승인한 비교 시안의 재현 설정이다. 이동 200ms, 시안 이동 거리 144 원본 픽셀(22.5 Unity units/s, PPU32)이다. 프레임 종료 시각은 대시 시작 기준 20/90/200/245/300ms다. 잔상은 0~180ms에 20ms 간격으로 생성하고 180ms 동안 소멸한다. 색은 #2b546a, 최대 불투명도는 0.52, 감쇠는 `0.52 * (1 - age / 180)^1.15`다. 원래 Sprite 알파를 곱하며 본체 뒤에 그린다. 미리보기 배경은 흰색이다.

아직 Unity 런타임과 13종 전체에 연결하지 않았다. 숫자는 기본검 승인 시안의 표현 설정이며 현재 `data/combat/locomotion/player.json`을 바꾸는 근거가 아니다. 실제 연동 시 이동/무적/입력 취소·충돌은 기존 실행기가 소유하고 표현 계층에서만 자세·잔상을 관리한다. 이동 종료 후 복귀 중에도 공격·점프·낙하·달리기로 전환할 수 있어야 하며, 벽 충돌·취소·사망·장면 전환 때 잔상을 정리해야 한다. 공중 대시의 종료에는 지상 대기 복귀를 강제로 재생하지 않는다.

공유 ZIP의 `dash/`에 원본 5장·설정·흰 배경 전후 비교 GIF와 0.4배속 GIF가 있다. 필터는 Point, 피벗은 각 기존 Unity Sprite 값을 사용한다.
