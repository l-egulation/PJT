# Cozy Pixel character assets

이 폴더는 밝고 포근한 픽셀 UI 버전의 캐릭터 창 전용 래스터 에셋 경계다.

- `paper-texture-character.png`: 새 캐릭터 패널 전용 밝은 픽셀 종이 표면
- `character-rest-192.png`: 이전 시안의 192×192 캐릭터 원본. 현재 능력치 탭은 전투와 외형을 통일하기 위해 챕터 1 공용 `hero/rest_01.png`를 사용한다.
- `sprout-icon-32.png`: 프로필 v2와 같은 잎사귀 형태를 사용하는 제목 표식
- `heart-icon-bold-96.png`, `sword-icon-bold-96.png`, `target-icon-bold-96.png`, `boots-icon-bold-96.png`: 40px 표시에서도 형태가 또렷한 굵은 코코아색 외곽선의 능력치 표식
- `modal-paper-frame-9slice.png`: 밝은 종이 모달 외곽
- `modal-paper-decorated-v2.png`: 찢어진 외곽 바깥을 실제 투명 처리하고 가장자리에 옅은 잎·새싹 장식을 더한 전체 모달 종이
- `modal-paper-smooth-v3.png`: 자글거리는 입자를 줄이고 넓고 고른 아이보리 면을 확보한 1672×941 전체 모달 종이. 바깥은 실제 알파 투명이다.
- `character-backdrop-coarse.png`, `character-floor-shadow.png`: 큰 픽셀 덩어리로 다시 만든 왼쪽 캐릭터 무대와 바닥 그림자
- `section-check-icon-32.png`, `accent-rays-coral.png`, `close-icon-32.png`: 섹션·강조·닫기 표식
- `accent-rays-yellow.png`: 핵심 수치 강조 표식
- `progress-track-9slice.png`, `progress-fill-cyan-9slice.png`: 경험치 막대
- `Jua-Regular.ttf`, `OFL-Jua.txt`: 캐릭터 모달 전용 둥근 한글 글꼴과 라이선스

캐릭터 창 전용 장식 이미지는 이 폴더에서 관리한다. 캐릭터 본체는 전투 동작과 장비 외형을 일치시키기 위해 `apps/web/public/assets/chapters/chapter-01-sushi/hero`의 공용 프레임을 참조한다.

## 제작 출처

- `paper-texture-character.png`는 2026-09-09 사용자 제공 최종 캐릭터 UI 시안을 스타일 기준으로 삼아 내장 이미지 생성 모드로 만든 뒤 512×512 반복 표면으로 정리했다.
- 생성 요청: `밝은 크림색 종이, 미세한 2–4px 입자와 섬유가 있는 아늑한 2D 픽셀 게임 UI 반복 텍스처. 테두리·아이콘·글자·오브젝트·얼룩·그림자·중세 장식 없이 균일한 정면 표면.`
- `modal-paper-decorated-v2.png`는 2026-09-09 내장 이미지 생성 모드로 새로 만든 전체 패널 에셋이다. 사용자 제공 기준 시안의 밝은 크림 종이와 2–3px의 얇고 얕은 찢어진 픽셀 외곽을 따르고, 중앙과 상단은 정보 배치를 위해 비우며 아래 양끝에 작은 저대비 새싹·담쟁이 장식만 남겼다. 후속 배경 추출에서 종이 바깥 체크무늬를 실제 알파 0 투명 영역으로 교체했다.
- 생성 요청: `밝은 크림색 16:9 픽셀 종이 패널, 얕은 찢김과 2–3px 코코아색 선만 남긴 가벼운 외곽, 아래 모서리의 작은 세이지 새싹·담쟁이 장식, 중앙은 깨끗한 정보 여백, 글자·버튼·배경 장면·외부 그림자 없음, 종이 바깥은 실제 알파 투명.`
- `modal-paper-smooth-v3.png`는 2026-09-13 사용자 제공 스킬·치장 화면을 함께 참고해 내장 이미지 생성 모드로 제작했다. 기존 종이의 고주파 입자와 얼룩은 피하고 두 번째 시안처럼 거의 평평한 크림 면, 얇은 갈색 찢김 테두리, 아래 양끝의 작은 저채도 새싹만 남겼다. 최초 생성본은 체크무늬가 실제 픽셀로 들어가 폐기하고 배경 추출을 다시 수행해 `Format32bppArgb`, 네 모서리 알파 0을 확인했다.
- 현재 능력치 탭은 사용자 제공 `기본나무검.zip`의 합성 완료 `rest_01` 프레임을 사용한다. 전투의 `rest`, `run2`, `strike1`, `thrust1`, `death1`과 같은 기본 나무검 외형을 공유하며, 가져온 20프레임의 정보는 `basic-wooden-sword-manifest.json`에 보존한다.
- 모달 프레임·캐릭터 무대·그림자·섹션 표식은 같은 저장소의 최신 `profile/assets-cozy-pixel-v2` 제작물 중 최종 캐릭터 시안과 일치하는 항목만 복사해 캐릭터 전용 경계 안에서 사용한다.
- `character-backdrop-coarse.png`는 기존 캐릭터 무대와 사용자 제공 기준 시안을 이미지 생성 편집 모드에 함께 입력해 제작했다. 요청에는 `3:4 크림색 안뜰 구성을 유지하고, 중앙은 비우며, 6–10px 크기의 픽셀 덩어리와 계단형 가장자리로 배너·담쟁이·화분·나무 상자를 낮은 대비로 다시 그린다`는 조건을 사용했다.
- 192×192 캐릭터 원본은 확대 보간 없이 표시한다. 모달은 뷰포트의 약 72%×76%, 왼쪽 열은 약 30%, 캐릭터 표시 폭은 192–268 CSS px 범위로 제한해 기준 시안의 상대 크기를 유지한다.
- 제목·탭·섹션·주요 수치는 로컬 `Jua` 글꼴을 사용하고, 작은 설명은 가독성을 위해 시스템 산세리프를 사용한다.
- 능력치 아이콘은 내장 이미지 생성 모드에서 `하트·검·명중 표적·가죽 신발을 2×2 투명 스프라이트로 만들고, 16비트 픽셀 덩어리와 4–6px의 둥글고 짙은 코코아색 외곽선, 따뜻한 하이라이트를 적용하며 40 CSS px에서 읽히게 한다`는 요청으로 제작한 뒤 각 96×96 투명 PNG로 분리했다.
