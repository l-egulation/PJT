# 보호막 이펙트 시험판

초록 잉크 교대 방벽(무기 전환 시 보호막 12, 4초 유지)이 플레이어에게 보호막을 걸 때 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다. 지금 게임의 임시 표시(반투명 민트색 캡슐)를 대신할 후보다.

캐릭터를 덮는 완만한 반원 돔이다. 딱딱한 테두리와 바닥 고리 없이, 속은 옅게 채우고 가장자리로 갈수록 진해지다가 바깥으로 부드럽게 번져 사라진다. 테 자리에는 흐린 빛 띠가 번지고, 막 위로 옅은 물결 결이 흐르며, 별이 깜빡이고 빛 띠가 아래에서 위로 훑는다. 왼쪽 위에 유리 광택이 있다. 종이 배경에서는 더하는 빛이 보이지 않아 전부 반투명 색으로 칠한다.

- `shield.js`: 유지 반복(0.96초). `dome()`을 생길 때·깨질 때와 함께 쓴다. 옵션 `rx`·`ry`(돔 반지름, 60·70), `power`(2면 반원, 클수록 위가 납작), `fill`·`edge`·`rim`(속·가장자리·빛 띠 세기), `pattern`(`waves`면 물결 결).
- `shield-up.js`: 생길 때(0.28초). 크기 변화 없이 돔이 슥 페이드인한다(솟거나 출렁이면 푸딩처럼 보여 뺐다).
- `shield-break.js`: 깨질 때(0.36초). 보호막이 다 닳거나 4초가 끝나면 쓴다. 한 번 번쩍이고 살짝 부풀며 잡음 구멍이 번져 부서지듯 사라진다. 유지 반복의 어느 장에서든 넘겨받아도 된다.
- `export.mjs`: 세 시트를 Git 제외 `outputs/pixelfx/shield/`에 `shield-up_green`, `shield_green`, `shield-break_green`으로 뽑는다.

```sh
node 전투테스트/보호막/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- 세 판 모두 152×96, 25fps, 피벗 (76, 86) = 플레이어 발 가운데. 좌우 대칭이라 반전하지 않아도 된다. PPU32 게임 화소 1:1.
- 돔이 폭 약 120px라 바로 앞에 붙은 몬스터도 막 안에 들어와 보인다. 보호막은 플레이어만 지키므로 필요하면 `rx`를 줄인다.
- 초록 팔레트는 임시값이다. 보호막 수치가 남은 양에 따라 진하기를 바꿀지는 미정이다.

## 확인한 범위

1스테이지 실제 게임 캡처의 플레이어 위에서 생길 때 → 4초 유지 → 깨질 때를 렌더링으로만 봤다. 시안 A(빛 타원)·B(도는 고리)·C(빛 기둥)와 돔 시안 다섯 개를 비교해 사용자가 반원·속 진하게·물결 결(시안 4)을 골랐다. Unity·플레이어가 움직일 때는 확인하지 않았다.
