# Gems Content

보석 옵션·합성·입장권·일일 보스 진행 규칙은 [보석 SSOT](../../30-domain/gems/ssot.md)가 소유한다.

- 승인 설계: [보석 성장·던전 콘텐츠 설계](../../70-plans/gem-content/design.md)
- 요구사항 명세: [보석 콘텐츠 요구사항 명세서](../../70-plans/gem-content/implementation-requirements.md)
- 수치·표시명 초안: [MVP 보석·던전 수치 v1](./mvp-v1.md)
- 가속 베타 운영 프로파일: [보석 던전 가속 베타 프로파일](./beta-accelerated.md)

수치 초안은 옵션·보상·기준 빌드와 보석·일일 보스 표시명을 제공한다. 던전 보스 절대 수치와 보석 포함 3-1~4-10 적 수치는 사건 시뮬레이션 후 별도 콘텐츠 버전으로 승격한다.

가속 베타 프로파일은 베타 기간의 순환 주기·입장권·보스 수치만 소유하며 정식 서비스 기준을 대체하지 않는다.
