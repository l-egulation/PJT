# G-04 장비 제작·재료 차감

이 문서는 기능을 찾기 위한 경로 문서다. 정책, 수치, 상태, 완료 여부를 정의하지 않는다.

- 규칙·수치·상태의 정본: [장비·제작·강화 SSOT](../ssot.md)
- 실행 상태·완료 기준·증거: [G-04 작업 문서](../../../../wiki/06-delivery/tasks/G-equipment-crafting/g-04-equipment-crafting-material-consumption.md)

기능 요구가 바뀌면 먼저 정본 문서의 책임 범위를 확인하고, 필요한 결정은 [결정 로그](../../../../80-decisions/README.md)에 남긴다.
