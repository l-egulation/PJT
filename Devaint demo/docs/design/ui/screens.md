타이틀은 같은 픽셀 벌판·타일 바닥·먼 산을 중앙의 종이재 경계로 반 나눈다. 왼쪽은 밝은 세계와 오른쪽을 보는 인간, 오른쪽은 스케치 세계와 왼쪽을 보는 잉크 주인공이다. 양쪽 캐릭터는 원본 비율과 48프레임·3.6초 대기 모션을 유지하고, 잉크 캐릭터에는 한 픽셀 테두리를 더한다. 밝은 쪽 구름·잔디·다섯 꽃은 움직이며 스케치 쪽 풍경은 멈춘다. 나뭇잎과 종이재, 중앙 경계의 작은 종이재 조각은 계속 흩날린다. 로고·메뉴는 화면 중앙에 정렬한다.

시작하기·설정·종료는 main 공용 `MemomentKkukkukk` 글씨체와 눈 색의 노란 붓펜 선택 표시를 사용한다. 포인터와 방향키·패드, Tab/Shift+Tab 이동과 Enter/Space 선택을 지원한다. 설정은 공유 설정창을 열고 닫으면 기존 선택으로 돌아온다.

시작하기를 확정하면 기존 도장 확인음(`sfx_ui_confirm`)을 즉시 한 번 재생하고 메뉴의 재입력을 막고, **반반 구도와 양쪽 캐릭터를 그대로 유지한 채 즉시 1.2초 동안 검게 페이드아웃한다.** 추가 스케치화·전선 이동·스케치 유지 대기는 없다. 검은 화면을 한 프레임 표시한 뒤 마을 진입을 한 번 실행한다. 페이드 종료·마을 진입 시에는 확인음을 다시 재생하지 않는다. 전체 음량과 타이틀 효과음 설정을 따른다. 화면 흔들림·섬광·글리치 효과음은 쓰지 않는다. 화면 아무 곳을 누르는 입력으로는 시작하지 않는다.

1·2스테이지의 전체 지도·미니맵은 발견한 보스방에 빨간 해골을 표시하고, 해당 보스를 처치하면 해골을 숨긴다. 2스테이지는 기계장치 파괴나 페이즈 전환 중에는 유지하며 최종 페이즈 처치 후에 숨긴다. 보스가 다시 살아 있는 새 전투에서는 발견 상태에 따라 다시 표시한다. 살아 있는 일반 적의 빨간 위치 점과 상점·포탈 등 다른 표시는 보스 처치로 지우지 않는다.

포탈 표시는 설치 완료된 위치를 읽는다. C 재설치는 1번 포탈 위치만, V 재설치는 2번 포탈 위치만 갱신하며 이전 위치 표시는 남기지 않는다. 설치가 취소되면 기존 위치를 유지하고 포탈이 없는 슬롯은 표시하지 않는다. 초기화·사망·새 맵에서 포탈이 지워지면 지도 아이콘도 숨긴다. 지형 위에는 포탈 이름을 쓰지 않고 번호 아이콘만 표시한다. 미니맵에서는 HUD 프레임 좌표 28×28(960×540 게임 화면에서 약 13×13화소), 전체 지도에서는 게임 화면 기준 25×25화소로 표시한다. 이름 설명은 오른쪽 범례에 남긴다.

진행 중인 런의 일시정지 메뉴에서 ‘마을로’를 선택하면 ‘이번 도전을 마칠까요?’ 확인창을 연다. 기본 선택은 ‘취소’이며, 취소 또는 Esc는 전투를 멈춘 채 같은 일시정지 메뉴와 ‘마을로’ 포커스로 돌아간다. ‘포기하고 마을로’를 선택한 경우에만 기존 마을 귀환을 실행한다. 확인창에서는 뒤 메뉴를 가리고 입력을 막는다. 결과 화면의 ‘마을로’와 마을의 타이틀 복귀에는 이 런 포기 확인창을 사용하지 않는다.

## 시작 마을과 영구 해금 화면

마을 일시정지 메뉴의 ‘타이틀로’는 ‘타이틀로 돌아갈까요?’ 확인창을 연다. 피그마의 제목·설명·취소/타이틀로 선택·키캡 안내 배치를 따른다. 기본 선택은 취소이며, 취소 또는 Esc는 마을의 일시정지와 타이틀로 포커스를 유지한다. 타이틀로를 확정했을 때만 기존 타이틀 이동을 실행한다.

목표의 마을 로비·건물별 작업대·출발 준비·기록 열람은 [시작 마을](../world/village/starting-village.md)을 따른다. 해금 화면은 보유 마법안료, 선행 조건, 가격, 효과, 적용 시점과 완료/조건 부족/가격 미정 상태를 표시한다. 비용이 미정이면 거래만 제한하고 마을 이동·이야기·기본 출발을 막지 않는다. 시작 골드 지급은 [영구 성장 명세](../progression/roguelite-progression.md)의 거래와 지급 영수증을 사용한다. 이 화면들은 현재 빌드에 연결되지 않았다.

## 스테이지 보상과 무기 관리

[보상과 상점](../run/rewards.md)의 세 후보를 띄우고 전투를 멈춘다. 선택 중에도 인벤토리를 열 수 있고 닫으면 같은 후보로 돌아간다.

채택한 화면은 증강 창과 같은 공용 배경 가림막 위에 같은 너비의 세 후보를 가로로 놓고, 선택된 후보의 이름을 공통 포인트 노랑(#D9CB84)으로 표시하고 아이콘과 글자를 밝게 표시한다. 후보 번호와 별도 밑줄은 사용하지 않는다. [현재 구현·이미지 등록](../../development/presentation/ui/reward-choice.md)을 따른다.

후보의 배치는 보상 창을 기준으로 증강 창의 아이콘·이름·정보·선택 버튼 위치를 맞춘다. 배경 가림막의 밝기와 불투명도는 증강 창을 기준으로 맞춘다.

무기·잉크 보상 선택 중 가방 키(기본 Tab)로 비교용 가방을 열면 가방의 가림막만 표시하고 보상창의 가림막은 겹치지 않는다. 가방을 닫으면 같은 후보와 선택 위치로 돌아가며 보상 선택이 끝날 때까지 전투 정지는 유지한다. 보상창 하단의 선택·획득·가방 확인·설명 스크롤 안내는 키캡과 문구를 같은 높이의 한 줄로 맞추고, 실제 글자 폭에 여유를 둬 줄바꿈과 마지막 글자 잘림을 방지한다.

무기에는 형태·스킬·슬롯을, 잉크에는 색·발동 조건·기본/강화 효과를 표시한다. [무기 관리](../equipment/weapons/rules.md)와 [잉크 적용](../equipment/ink-application.md)을 따른다.

마을 시설 이름은 꼬리 없는 낮은 종이 말풍선 안에 현재 공통 UI 글씨체의 검은 글자로 표시한다. 기존의 검은 장식 이름표는 사용하지 않는다. 기록 목록의 배경은 장인의 공방과 같은 반투명 가림막을 사용하며, 선택 테두리·채움·재생 버튼은 캐릭터 초상화에서 추출한 눈색(#FEC403)을 사용한다. 공방 해금 항목은 선택한 이름을 공통 포인트 노랑(#D9CB84)으로 표시하며 선택용 붓칠 배경을 사용하지 않는다.

보상 후보는 방향키 또는 마우스로 선택하고 F로 현재 카드를 바로 획득한다. 선택한 이름을 노랗게 표시하고 작은 아이콘 확대로 구분한다. 카드 전체의 금색 테두리나 이름 뒤 붓칠은 사용하지 않는다. 선택 카드 아래에는 [F] 선택하기를 표시하며, 가방 비교는 기존 가방 단축키로 유지한다.

보상 카드에서는 무기 이름과 스킬 영역 사이를 구분선으로 나누고, 스킬 구분명·스킬 이름·설명 본문을 서로 다른 크기와 간격으로 표시한다. 스킬 이름은 본문보다 크고 굵게 표시하며, 긴 내용은 기존 설명 스크롤로 확인한다.

조작 설정은 설정창의 오른쪽 스크롤 목록에서 키를 직접 변경한다. 이동·전투·탐험 아래에 최신 메뉴·지도 키도 유지하며, 별도 편집 화면으로 넘어가지 않는다. 입력 중 Esc는 키 변경만 취소하고 설정창을 유지한다. 기본 키 복원은 G 또는 복원 버튼으로 확인창을 연다. 런 중 보상 게이지를 채웠을 때 중앙 상단의 보상 획득 문구는 표시하지 않는다.

### 잉크 묶음 설명

- 캐릭터 버프칸에 마우스를 올리면 소속 무기 번호·잉크 이름·장착 칸 수(강화 칸 수 포함), 발동 조건과 **중첩·강화 계산 후 효과량·지속시간·쿨타임**을 표시한다. 다른 무기의 같은 잉크와, 효과 그림이 같아도 발동 조건이 다른 잉크는 합치지 않는다.
- 설명은 발동 조건·최종 효과량·지속시간·쿨타임으로 간결하게 표시한다. 보라는 공격에 효과를 부여하는 시간과 적의 상태 지속시간을 구분하고, 즉시 회복·방어막 등에는 불필요한 지속시간 문구를 붙이지 않는다. 보스 예외, 갱신 방식, 상한·하한 처리 같은 내부 동작 설명은 표시하지 않는다.
- 인벤토리의 장착 장비·보관 장비 및 제작 결과의 적용 효과는 HUD와 같은 묶음·최종 설명을 사용하며, 기존 스타일대로 발동 조건은 하늘색(`#ACD4E0`), 효과명·계산된 수치는 연두색(`#B4D38D`)으로 강조한다. 슬롯 배치 그림과 부여 전 단일 잉크 설명은 개별 슬롯·잉크를 유지한다.
- 표시는 전투의 발동·시계를 변경하지 않는다. 회복·방어막 상한이나 스킬 대기 하한으로 일부 장착본만 발동했다면 아이콘은 가장 긴 남은 시간을 표시하고 툴팁에 준비된 칸 수를 추가한다. 전부 준비되면 밝게 표시한다. 마우스 이탈·HUD 숨김·가방/상점 열기 시 툴팁을 숨기며 화면 경계 안에 배치한다.

## 공통 메뉴 표시

일시정지는 제목과 메뉴 글씨를 화면 중앙에 정렬하고, 선택한 메뉴의 오른쪽에 F 키캡을 표시한다. 하단 이동/선택 안내와 기존 Esc 복귀 입력은 유지하며 상단 오른쪽의 중복 Esc·계속하기 표시와 빠른 음량 조절 카드는 숨긴다. 음량은 설정 → 소리에서 조절하며 일시정지에는 내구도 표시 전환을 두지 않는다. 소리 설정의 전체 음량과 배경 음악은 10% 단위 슬라이더이며 조절 즉시 기기별로 저장한다. 타이틀 효과음 행은 기존 저장 설정을 읽고 저장하며 시작 확인음을 전체 음량과 별개로 켜고 끈다. 스케치화 연출에는 글리치 효과음을 추가하지 않는다.

제작 완료 설명은 무기 요약·내구도 다음 기본 공격, 스킬, 팔레트, 적용 효과 순서로 표시한다. 일반 사망 결과는 ‘사망’ 제목, 가운데 두 기록 열, 유효한 이동/실행 키 안내를 사용한다. 결과 화면에서 Esc로 닫을 수 없는 동작은 유지한다. 공방 제목의 이름과 단계는 슬래시로 구분하며 중간점을 사용하지 않는다.

장인 머리 위 표시와 월드 상품 카드의 상호작용 키는 일시정지의 공용 키캡을 재사용한다. 얇은 회백색 테두리와 같은 색 글자, 살짝 둥근 모서리를 유지하고 월드의 밝은 배경에서도 읽히도록 반투명한 어두운 바탕을 받친다. HUD 버튼 프레임을 키캡으로 사용하지 않는다. 상호작용 키를 바꾸면 현재 바인딩을 표시한다. 한 글자 키캡은 정사각형으로, 긴 키 이름은 실제 글자 너비와 여백에 맞추며 옆 설명도 맞춰 배치한다. 일시정지의 선택 F는 글씨 바로 오른쪽에 붙이고 내구도 표시 전환은 두지 않는다. 사망 결과의 선택 F와 일시정지 F는 동시에 표시하지 않는다. 슬라이더 손잡이는 이동 영역에 세로로 늘어나지 않도록 고정된 높이를 유지한다.

가방·제작·장비·설정·공방·기록·지도·보상·일시정지의 전체 화면 가림막은 증강 창과 같은 색상·불투명도를 사용한다. 작은 확인창의 카드 바탕과 아이템 선택 강조는 별도로 유지한다.

인벤토리 행동 표시는 실행 가능 여부와 포커스를 구분한다. 제작하기처럼 항상 실행 가능한 주요 행동과 C 보관은 노란색을 유지한다. 포커스를 옮겨 실행하는 선택 행동은 평소 회색, 현재 포커스에서 노란색으로 표시한다. 실행 불가능한 버튼은 흐리게 표시하고 입력을 막는다. F 표시는 기존 키보드 포커스 흐름을 따른다. 마을 안료는 전투의 안료 아이콘을 32 크기로, 수량을 22 크기의 밝은 글자와 어두운 외곽선으로 표시한다. 별도 네모 배경은 두지 않고 메뉴 가림막보다 앞에 그린다. 공방에서 안료가 부족해도 가격을 숨기지 않으며 필요 수량·보유 수량·부족 수량을 빨간색으로 표시하고 구매는 막는다.
