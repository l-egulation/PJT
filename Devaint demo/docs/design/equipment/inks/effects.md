# 잉크 효과

[상위 규칙](rules.md) · [잉크 개요](README.md)

모든 잉크는 [기본 수치와 강화 수치](rules.md#기본-수치와-강화-수치)를 정의한다. 아래 효과·버프의 개별 값을 정할 때 두 적용 상태를 구분한다. 강화는 같은 성능에 필요한 슬롯을 절약한다. 빨강·보라의 중복 계산은 아래 환산량 E를 쓰며, 그 밖의 잉크는 기존 기본·강화 수치와 공통 쿨타임을 유지한다. 잉크별 강화 대상 효과 파라미터도 명시한다. 슬롯의 강화색과 잉크 색이 일치하면 강화 수치를 적용한다. 기본 39종의 수치는 아래 규칙과 [수치표](balance-proposal.md)의 플레이 테스트 시작값을 따른다.

## 효과별 기여 상한

**회복·방어막 생성을 제외한 잉크는 같은 효과에 최대 실제 6칸만 기여한다.** 강화 잉크도 1칸으로 세며 강화 수치와 중복 환산량 E(일반 1·강화 1.5)는 유지한다. 일반 4칸·강화 2칸의 E=7을 6으로 자르지 않는다. 발동 조건이나 잉크 이름이 달라도 같은 효과면 함께 계산하며 기본 공격 피해·기본 공속·이동속도 등 서로 다른 효과는 각각 계산한다. 영구 성장·증강 등 잉크 외 보정은 이 개수에 포함하지 않는다. 구조화 원본은 `inks.effectStacking`이다.

플레이어에게 남는 빨강 피해·공속과 노랑 이동속도는 두 장착 무기뿐 아니라 보관·파괴된 원본의 만료 전 효과까지 합쳐 제한한다. 각 효과량이 높은 순, 동률이면 최근 발동 처리 순으로 최대 6칸을 선택한다. 같은 사건의 장착본은 기존 슬롯 처리 순서를 유지한다. 초과 효과는 기여하지 않지만 원래 만료 시각과 쿨타임은 그대로 진행한다. 선택된 효과가 만료되면 아직 유효한 초과 효과를 재선택하며 시간을 새로 시작하거나 다른 원본의 시간을 갱신하지 않는다. 같은 장착본 재발동은 기존 효과를 갱신할 뿐 기여 개수를 늘리지 않는다. 버프의 활성 시간·강화 표시도 현재 선택된 장착본을 기준으로 한다.

파랑의 스킬 피해·쿨타임 감소는 기존 원본 무기·해당 스킬 범위를 유지하고 보라의 부여 버프는 원본 무기 범위를 유지한다. 이 범위에는 최대 6칸이 있으므로 다른 무기의 잉크를 끌어와 합산하지 않는다. 적에게 부여한 기절·속박의 비합산과 슬로우의 최강 효과 선택도 유지하며 서로 다른 원본의 상태를 6개분 수치로 더하지 않는다. 원본 무기 6칸·강화 최대 2칸의 기존 제한을 바꾸지 않는다.

회복과 일반·대쉬 방어막 생성에는 이 기여 개수 제한이나 무기 사이의 공유 쿨타임을 추가하지 않는다. 기존 회복량·생성량·장착본별 쿨타임·체력 최대값·방어막 보유 상한과 감소 규칙을 유지한다. 나머지 효과도 기존 이동속도 +40%·빨강 공속 +60%·기본 공속 버프 배속 2.0·상태 시간 3초·슬로우 90%·스킬 최소 대기시간 등 수치 제한을 그대로 적용한다.

## 효과 부여 잉크

| 색상 | 부여하는 효과 |
|---|---|
| 노랑 | 이동속도 증가 |
| 초록 | 방어막 생성, 체력 회복 |
| 보라 | 상태이상: 기절, 속박, 슬로우 |

[발동 조건](triggers.md#효과-부여-잉크)과 각 효과를 연결해 모든 유효 조합의 잉크를 정의한다([필수 조합](rules.md#효과-잉크-조합-전체-범위)). 상태이상→상태이상 조합은 금지한다. 방어막 생성과 체력 회복은 독립된 효과 축으로 각각 모든 트리거와 조합한다. 스위칭 상태이상은 해당 공격에 맞은 적에게, 대쉬 상태이상은 이동 중 경로 판정이 닿는 즉시 각 적에게 대쉬당 한 번 부여한다. 경로에 판정을 남기지 않고, 이미 부여한 상태는 대쉬 종료·중단 후에도 원래 수명대로 유지한다. 효과 대상·수명·중첩·갱신·수치는 아래 규칙을 따르며 잉크 레벨은 없다. 기본 공격력 버프는 아래 빨간 잉크, 쿨타임 감소·스킬 피해량 증가는 파란 잉크의 역할이다.

노랑·초록·파랑은 공격 실행당 장착본별 최대 1회 발동한다. 빨강은 매 유효 기본 적중마다 시간을 갱신하며, 보라의 공격 기반 잉크는 활성 중 매 적중마다 상태를 부여한다. 대쉬 보라는 경로 접촉에만 상태를 부여한다. 한 번의 상태 부여가 여러 대상을 포함할 수 있다. 스위칭의 공격 이력 조건과 대쉬의 경로 대상 판정은 [발동 조건](triggers.md#스위칭과-대쉬의-대상)을 따른다.

회복량과 방어막 생성량은 **최대 체력과 무관한 고정 수치**로 정의한다. 잉크별 기본·강화 값을 별도로 정한다. 방어막 보유 상한과 초당 감소량은 기존대로 최대 체력에 비례하며 생성량에 이 비례식을 적용하지 않는다.

### 이동속도 증가와 방어막 중첩

서로 다른 노란 잉크와 동일 잉크 중복본의 이동속도 증가율은 장착본별로 합산하고 각 효과의 지속시간은 독립적으로 관리한다. 효과가 끝나면 해당 증가량만 제거한다. 잉크로 얻는 합산 증가율의 상한은 **+40%**를 플레이 테스트 시작값으로 사용한다. 모든 원본의 유효 효과 중 기여 상한으로 선택한 최대 6칸을 합친 뒤 수치 상한을 적용한다. 영구 이동속도 강화는 이 상한에 포함하지 않고 별도로 더한다([이동 규칙](../../combat/rules.md)). 노랑 잉크 5종의 장착본당 증가율은 **기본 +10%·강화 +15%**다. 기본 공격·스킬 공격·스위칭·상태이상 조건은 **3초 유지·6초 내부 쿨타임**, 대쉬 조건은 **4초 유지·8초 내부 쿨타임**을 플레이 테스트 시작값으로 사용한다. 기본·강화의 지속시간과 쿨타임은 같고 쿨타임은 효과 발동부터 진행한다. 같은 장착본이 재발동하면 증가량을 중첩하지 않고 지속시간만 해당 효과의 원래 값으로 갱신한다. 다른 무기로 교대해도 이미 얻은 이동속도 증가 효과는 유지하고 남은 시간은 계속 흐른다.

방어막은 남은 양에 새 방어막량을 더하되 **최대 체력의 20%를 보유 상한**으로 두고 시간이 지나면 서서히 감소한다. 일반 방어막 4종(기본 공격·스킬 공격·스위칭·상태이상 조건)의 장착본당 생성량은 **기본 7·강화 10**, 내부 쿨타임은 기본·강화 모두 **6초**다. 발동 순간 생성량을 즉시 더하고, 다음 유효 발동까지 기다리는 보충 주기로 운용한다. 중복 장착본은 준비 상태라면 함께 발동하며 자동으로 발동 시점을 나누지 않는다. 수치는 플레이 테스트 시작값이다. 기본 공격·스킬 공격 조건 방어막은 몬스터의 실제 체력을 줄인 뒤 생성한다. 처치 타격도 인정하며 빗나감·피해 0·무적/방어로 체력이 줄지 않은 타격·플레이어·미끼 타격은 발동과 쿨타임을 소비하지 않는다. 스위칭 조건 방어막은 적중 시 생성하고, 상태이상 조건은 부여 성공 시 생성한다.

**대쉬 방어막은 예외로 적중 없이 대쉬 시작 즉시 생성하며 다른 방어막보다 더 빨리 사라진다.** 장착본당 생성량은 **기본 7·강화 10**, 내부 쿨타임은 기본·강화 모두 **8초**를 플레이 테스트 시작값으로 사용한다. 실제 생성량이 양수일 때만 해당 장착본의 쿨타임을 사용한다. 대쉬 도중의 무적이 끝난 직후, 위험 구간에 진입한 캐릭터를 잠시 보호하는 역할이다. 대쉬 중 보호를 추가하는 것이 목적은 아니다.

일반 방어막은 마지막 직접 적중 후 **10초**가 지나면 감소한다. 재적중하면 감소를 멈추고 10초 유예시간을 갱신한다. 두 무기의 기본·스킬 직접 적중을 모두 인정하며 발사체·설치물의 직접 적중도 포함한다. 이 갱신은 방어막 신규 생성 여부와 독립이며, 신규 생성은 해당 잉크의 조건과 내부 쿨타임을 충족해야 한다.

대쉬 방어막은 대쉬 중과 **대쉬 종료 후 3초 동안 시간 감소 없이 유지**하고, 이후 빠르게 감소한다. 일반 방어막의 재적중 유예 갱신을 대쉬 방어막에 적용하지 않는다.

유예가 끝난 일반·대쉬 방어막은 최대 체력에 비례한 초당 고정량으로 감소한다. 일반 방어막은 **최대 체력의 5%/초**, 대쉬 방어막은 **최대 체력의 20%/초**만큼 감소한다. 현재 남은 방어막에 대한 비율이 아니다. 추가 생성·피격·유예 갱신 없이 한 종류만 상한까지 보유한 경우, 유예 종료 후 일반은 4초, 대쉬는 단일 생성분 기준 1초에 소진된다.

일반·대쉬 방어막은 양과 감소 시간을 분리 관리하며, 피격 시 **대쉬 방어막부터 소모**한다. 대쉬 방어막 생성분이 여러 개면 **유예 종료 시각이 빠른 분량부터** 소모하고, 대쉬 방어막을 모두 소모한 뒤 일반 방어막을 사용한다. 두 양의 합계에 최대 체력의 20% 상한을 적용한다. 새 방어막은 합계 상한의 빈 공간만 채우고 초과분은 버리며 기존 방어막을 교체하지 않는다. 대쉬 방어막은 생성분마다 시간을 독립적으로 관리한다. 각 생성분은 자신을 만든 대쉬 종료 후 3초부터 **각각 최대 체력의 20%/초**로 감소한다. 감소량을 생성분 사이에 나누지 않으며 동시에 감소하는 생성분이 많으면 총 감소 속도도 커진다. 아직 유예 중인 생성분은 감소하지 않고, 소진된 생성분의 감소량을 다른 생성분으로 넘기지 않는다. 이후 대쉬가 이전 생성분의 시간을 갱신하지 않는다. 신규 생성에는 내부 쿨타임을 적용한다. 상한 20%·일반 유예시간 10초·일반 5%/초 및 대쉬 20%/초 감소량은 플레이 테스트의 시작값으로 사용한다. 런 종료 시 처리는 미정이다. 무기 소멸 시에도 이미 얻은 방어막은 기존 감소 규칙대로 유지한다.

### 내부 쿨타임

**기절·속박·슬로우를 포함한 모든 효과 부여 잉크에 내부 쿨타임을 적용한다.** 효과와 쿨타임은 무기별로 독립이며 같은 잉크를 두 무기에 적용해도 두 무기의 쿨타임을 공유하지 않는다. 방어막·회복이 플레이어 자원에 미치는 결과까지 별도의 HP로 분리하는 것은 아니다.

회복은 비전투 중에도 조건과 내부 쿨타임에 따라 사용할 수 있다. 회복 잉크의 내부 쿨타임은 기본 공격·스킬 공격·스위칭·상태이상 조건은 **6초**, 대쉬 조건은 **8초**를 플레이 테스트 시작값으로 사용한다. 기본·강화는 같은 쿨타임이며 무기·장착본별로 독립 관리한다. 실제 회복량이 양수일 때만 쿨타임을 시작한다. 회복 잉크 5종의 장착본당 회복량은 **기본 1·강화 2**의 고정 체력 수치를 플레이 테스트 시작값으로 사용한다. 대쉬 회복은 시작 시 회복하지 않고 대쉬 경로 판정이 살아 있는 적에게 닿을 때 장착본별 대쉬당 최대 한 번 회복한다. 경로 판정 범위는 대쉬 상태이상과 같으며, 적을 만나지 못하면 회복과 쿨타임 소모가 없다. 중복 장착본은 각각 회복하며 최대 체력을 넘는 회복량은 버린다. 기본 공격·스킬 공격 조건의 회복은 방어막과 같이 몬스터의 실제 체력을 줄인 뒤 적용하며 처치 타격도 인정한다. 빗나감·피해 0·무적/방어로 체력이 줄지 않은 타격·플레이어·미끼 타격은 회복과 쿨타임을 소비하지 않는다. 기본 공격·스킬 공격 조건의 이동속도와 스위칭 조건의 이동속도·회복은 공격 실행 시 빗나가도 적용하고 실행 전 취소에는 발동하지 않는다. 방어막 생성 시점은 위 방어막 규칙이 우선한다. 대쉬 방어막은 적 없이도 생성할 수 있지만 빠르게 사라진다. 반복 입력·다단 적중으로 내부 쿨타임 중 연속 발동하지 않는다.

노랑·초록의 대쉬 잉크는 다른 트리거보다 긴 내부 쿨타임을 쓴다. 회복·방어막은 실제 증가량이 양수일 때만 발동 기회와 쿨타임을 사용한다. 같은 무기의 여러 장착본은 슬롯 순서로 자원 여유를 다시 계산한다. 증가량 0인 장착본은 원래 트리거로 재시도할 수 있다.

보라의 쿨타임은 아래 무기 버프가 끝난 순간부터 계산한다. 두 무기·서로 다른 잉크는 독립 상태를 유지한다. 보라의 활성 시간과 재사용 시간은 교대·보관·파괴 중에도 전투 시계로 진행하며 초기화하지 않는다. 다른 효과의 장착본 쿨타임은 장착 중 진행하고 가방 보관 중 정지한다. 일시정지는 모든 전투 시간을 멈춘다. 이미 부여한 자기 버프·적 상태와 이미 생성된 독립 공격은 원본 수명을 유지한다.

캐릭터 체력 막대 아래 [버프칸](../../ui/screens.md)은 보라 활성 중에는 남은 부여 버프 시간을, 종료 후에는 재사용 시간을 표시한다. 보스의 기절·속박 전용 재부여 제한은 없다.

## 빨강·파랑의 공통 상태 조건

공격 대상 몬스터가 **기절 상태일 때·속박 상태일 때·슬로우 상태일 때**를 조건으로 사용한다. 이는 상태이상을 새로 부여하는 사건이 아니라 공격 대상의 현재 상태를 확인하는 조건이다. 현재 기본 목록은 잉크마다 한 상태 조건을 가지며, 복합 조건 예외형은 미정이다. 빨강·파랑 모두 같은 공격의 상태이상 부여 후 조건을 확인하므로 그 공격으로 새로 부여한 상태이상으로도 즉시 발동할 수 있다.

**비용 소모와 페널티는 없다.** 체력·방어막·이동속도를 차감하지 않고 몬스터의 상태이상 남은 시간도 소비하지 않는다. 조건이 맞지 않으면 발동 조건이 성립하지 않을 뿐 플레이어에게 기절·슬로우 등 반동을 주지 않는다.

### 원본 무기의 상태이상 부여 버프

기절·속박·슬로우는 원본 무기에 일정 시간 유지되는 부여 버프다. 기본 공격·스킬·스위칭 조건은 첫 유효 적중에서, 대쉬 조건은 대쉬 시작에 활성화한다. 발동 첫 타격부터 상태를 부여하고 빨강·파랑 조건을 확인한 뒤 피해를 계산한다. 기본 공격·스킬·스위칭 조건은 활성 중 원본 무기의 기본·스킬 공격에 맞는 모든 적에게 매 타격마다 부여한다. 다단 재적중도 상태 시간을 갱신한다. 무기 버프 자체는 재적중·조건 재충족으로 갱신하거나 연장하지 않는다.

대쉬는 활성 시간 중 대쉬 경로 범위의 대상별 1회만 부여한다. 대쉬 중이나 종료 후의 기본·스킬 적중에는 대쉬 잉크의 상태이상을 부여하지 않는다. 진행 중인 대쉬·발사된 투사체는 원본 무기 파괴 후에도 원래 잉크 구성과 시간을 사용한다. 새 무기의 효과를 빌리거나 파괴를 이유로 시간·발동 이력을 초기화하지 않는다. 생성 전 후속 공격은 기존 취소 규칙을 따른다.

**중첩 환산량 E = 같은 원본 무기의 동일 잉크 일반본 수 + 1.5 × 색 일치 강화본 수.** 강화 두 개는 일반 세 개와 같다. 실제 소비는 슬롯당 1회이며 강화색·최대 2칸 규칙을 유지한다.

| 효과 | 계산 | 제한 |
|---|---|---|
| 기절·속박 대상 시간 | min(E, 3)초 | 3초 상한 |
| 기절·속박 무기 버프 | E=1.5(강화 1개)는 2.5초, 그 외 T + (E−1) × (6−T) / 3초 | 일반 4개 6초, 이후 동일 증가폭 |
| 기절·속박 재사용 | max(1, 4−E)초 | 종료 후 시작 |
| 슬로우 대상 시간 | min(E, 3)초 | 3초 상한 |
| 슬로우 무기 버프 | T + (min(E,2)−1) × (6−T)초 | 6초 상한 |
| 슬로우 재사용 | max(1, 5−2E)초 | 종료 후 시작 |
| 슬로우 감속률 | E≤2: 40E%, E>2: min(90, 80+10(E−2))% | 90% 상한 |

T는 **1.7초를 첫 시험값**으로 둔다. 기절·속박 강화본 1개의 부여 버프는 **2.5초**이며, 표시와 실제 동작에 같은 값을 사용한다. 대상 상태 시간과 중복 장착의 나머지 계산은 유지한다. 망치 기본 1→2→1타의 첫 적중부터 세 번째 적중까지 원본 시간표상 1.55초이므로, 첫 적중을 포함한 3타 목표에 여유를 둔다. 공격속도·입력 간격·실제 거리에서의 체감은 플레이 검증 대상이다.

적 상태 시간은 남은 시간에 더하지 않는다. 기절·속박은 기존 남은 시간과 새 부여시간 중 긴 쪽을 유지하고, 슬로우는 원본 무기·동일 잉크별 시간을 새 전체 시간으로 갱신한다. 서로 다른 슬로우의 감속률은 합산하지 않으며 가장 강한 유효 효과만 적용한다. 일반 적의 이동과 공격 준비·타격·후딜을 함께 감속하되 재사용 대기시간과 발사된/새 투사체의 비행 속도는 변경하지 않는다. 이미 진행한 공격과 타격 기록은 유지한다.

보스는 세 상태의 시간·아이콘·이펙트와 빨강·파랑 조건을 유지하지만 패턴 중단·이동 잠금·이동 및 공격 동작 감속을 적용하지 않는다. 보스 전용 기절·속박 재부여 제한은 없다. 일반 적은 투자량에 따라 연속 제어할 수 있으며 별도 해제·면역 공백을 추가하지 않는다.

## 공격 부여: 빨간 잉크

기본 공격 적중과 대상 상태 조건을 만족할 때 플레이어에게 모든 무기·맨손의 기본 공격 피해 증가를 부여한다. 스킬 피해에는 적용하지 않는다. 내부 쿨타임은 없으며 다단 공격도 조건을 만족하는 매 적중마다 해당 원본 무기·동일 잉크의 버프를 전체 시간으로 갱신한다. 남은 시간이나 재발동 횟수만큼 피해량을 누적하지 않는다.

증가율은 일반 +30%·강화 +45%를 첫 시험값으로 사용한다. 동일 무기·동일 잉크의 버프 시간은 **R × E**, R은 **0.75초를 첫 시험값**으로 둔다. 검 기본 1타 적중 후 남은 동작과 다른 검의 1·2타 적중까지 약 0.33·0.66초인 원본 시간표를 기준으로 교대 후 1~2타를 목표로 한다. 실제 전투 체감 및 적 처치 타수에 맞춘 공격 증가율 조정은 별도다.

다른 잉크·다른 무기에서 얻은 버프는 각각 수명을 관리하며 효과별 기여 상한으로 선택한 증가율만 합산한다. 교대·보관·파괴 후에도 이미 얻은 버프는 계속 흐르고 모든 무기 기본 공격에 적용한다. 광역 타격은 모든 대상의 상태 부여·조건 확인을 먼저 끝내 같은 타격의 피해가 처리 순서에 따라 달라지지 않도록 한다. 이미 끝난 타격 피해를 소급 변경하지 않는다.

### 피해 증가율 합성

빨강은 기본 공격 피해, 파랑은 스킬 피해라는 **같은 피해 범위에 해당하는 기존 증가율과 잉크 증가율을 모두 합산**한다. 영구 성장·장비·잉크라는 이유로 증가율 묶음끼리 곱하지 않는다. 기준 피해 100에 기존 증가율 +20%, 해당 공격의 잉크 증가율 +20%라면 피해는 `100 × (1 + 0.2 + 0.2) = 140`이다. 기본 공격 증가율을 스킬 피해에 섞거나 반대로 적용하지 않는다. 런타임 이행 시 기존 보정 항목의 적용 범위를 대조하며 고정 수치 보정이나 다른 피해 계산 단계까지 임의로 증가율로 환산하지 않는다.

### 동시 발동 순서

빨강·파랑 모두 **효과 부여 → 대상 상태 확인 → 해당 색의 효과 발동 → 발동 타격의 피해 계산** 순서로 처리한다. 기본 공격으로 상태이상을 부여하면 빨강이, 스킬 공격으로 부여하면 파랑이 같은 공격에서 즉시 발동할 수 있다. 빨강의 기본 공격 피해 증가와 파랑의 스킬 피해 증가는 모두 **발동시킨 타격부터 적용**한다. 빨강은 [광역 타격 처리](triggers.md#공격-부여-잉크)에 따라 같은 타격의 조건을 먼저 조사해 발동 타격 전체를 강화한다. 파랑의 피해 증가는 발동시킨 스킬 사용 1회의 남은 타격까지 유지하며 다음 스킬 사용으로 이어지지 않는다. 파란 피해 증가는 각 타격의 피해 계산 시 대상이 해당 잉크의 상태 조건을 만족할 때만 적용하며, 대상별로 조건을 확인한다. 이미 계산한 피해는 소급 변경하지 않는다. 상태는 조건 확인 후에도 소비하지 않는다. 공격 기반 보라 잉크는 해당 공격의 모든 적중 대상에게 각각 한 번 부여하며, 늦게 처음 맞은 적은 포함하고 동일 대상 반복 적중으로는 갱신하지 않는다. 상태이상 부여 트리거의 연쇄 단계는 미정이다. 발동 횟수는 공격당 잉크별 최대 1회다.

### 기본 공격 공속 버프

기절·속박·슬로우 조건별로 기본 공격 공속 증가 잉크를 제공한다. 일반 +20%·빨강 강화 +30%이며 기존 피해 증가 +30%·+45%와 별개로 합산한다. 같은 타격으로 상태를 부여해도 발동한다. 피해 증가는 발동 타격부터 적용하지만 공속은 다음 기본 공격 시작부터 적용하고 진행 중 공격의 시간표를 바꾸지 않는다.

같은 원본 무기·동일 잉크의 중복 환산량 E에 대해 `min(3, 1.5×E)초` 유지한다. 일반 1개는 1.5초, 강화 1개는 2.25초다. 조건을 만족하는 매 기본 적중에 전체 시간으로 갱신하고 재발동으로 수치를 추가 누적하지 않는다. 모든 원본의 활성 공속 중 기여 상한으로 선택한 최대 6칸을 합산해 빨강 공속은 최대 +60%다. 무기 교체·가방 이동·파괴 이후에도 시작된 버프와 남은 시간을 유지하며 사망·전투 리셋은 정리한다.

런의 증강·은신 종료 공속도 같은 버프 축에 합산하고 기본 공격의 버프 배속은 최대 2.0으로 제한한다. 무기 자체 기준 속도와 분리한다. 스킬 동작·쿨타임·충전·투사체 비행·독립 설치물 주기는 가속하지 않는다. 본체·공격 이펙트는 시작 때 확정한 동작 배속을 쓰지만 효과음 원본은 배속하지 않는다. 휘두름음은 공격 시작에 원본 속도·피치로 재생하고 별도 타격음은 실제 적중에 연결한다. 기본 공격 공속의 상승으로 소리 발생 간격은 짧아질 수 있으며 새로운 소리를 합성하지 않는다.

공속 버프도 기존 빨간 불꽃 표시를 공유하며 버프칸은 기본 공속 아이콘과 실제 남은 시간·최종 수치를 표시한다. 원본 그림·공격 범위·타수는 유지한다.

## 스킬 강화: 파란 잉크

**스킬 공격 적중 시 맞힌 몬스터의 상태 조건**을 확인한다. 빗나가거나 적중 대상이 없으면 발동하지 않는다. 기본 공격으로 발동하지 않는다. 비용·페널티 없이 다음 두 효과 유형을 제공한다.

| 효과 유형 | 역할 | 남은 구체화 |
|---|---|---|
| 쿨타임 감소 | 조건을 충족한 공격의 원본 무기에서 현재 진행 중인 같은 스킬의 대기를 줄인다. 감소량은 **스킬의 전체 기본 쿨타임 × 감소율**로 계산하며 남은 시간에 감소율을 곱하지 않는다. 장착본당 감소율은 **기본 15%·강화 20%**를 플레이 테스트 시작값으로 사용한다. 같은 스킬의 감소량은 적중 시점에 따라 달라지지 않는다. 서로 다른 잉크가 함께 발동하면 기본 쿨타임 기준 감소율을 합산한다. | 충전 수를 보유하는 스킬의 적용 방식 |
| 스킬 피해량 증가 | 장착본당 **기본 +20%·강화 +30%**를 플레이 테스트 시작값으로 사용한다. 조건을 만족하면 **1타 피해 계산 전에 강화해 1타부터** 적용하며, 발동 후 같은 스킬 사용의 남은 타격에도 대상별 상태 조건에 따라 적용한다. 다음 스킬 사용으로 이어지지 않는다. | 위 피해 증가율 합성 규칙 참조 |

**파랑 피해 강화의 1타 처리:** 준비된 피해 강화 잉크는 `1타의 상태이상 부여 → 대상 상태 조건 확인 → 피해 강화 적용 → 1타 피해 계산` 순서로 처리한다. 1타 피해를 먼저 준 뒤 강화하지 않는다. 같은 1타로 상태이상을 부여해도 조건을 즉시 만족하므로 1타부터 강화된다. 예를 들어 `슬로우 포화`(슬로우 조건 스킬 피해 강화)의 기본본이 준비된 상태에서 기준 피해 100인 1타로 슬로우를 부여하면 그 1타 피해부터 120이 된다(다른 보정 없음). 1타에서 조건을 만족하지 못하면 해당 타격은 강화되지 않으며, 후속 타격에서 처음 조건을 만족하면 기존 발동 규칙에 따라 그 타격의 피해 계산 전에 강화한다. 후속 타격도 대상별 상태 조건을 다시 확인하며 이전 피해를 소급 변경하지 않는다.

예를 들어 전체 기본 쿨타임이 10초이고 4초가 남았을 때 기본 잉크(15%)가 발동하면, 10초의 15%인 1.5초를 차감해 2.5초가 남는다. 강화 잉크(20%)는 같은 기준으로 2초를 차감한다. 최소 대기시간과 남은 시간에 따른 실제 감소량 제한은 유지한다.

이전 사용에서 남은 투사체·설치물이 조건을 만족해 적중하면 **현재 진행 중인 같은 원본 무기·같은 스킬의 대기**를 줄일 수 있다. 다음 사용의 대기가 이미 시작된 경우에도 적용하며 다른 무기나 다른 스킬로 넘기지 않는다. 진행 중인 대기가 없으면 실효 감소량은 0이며 내부 쿨타임·발동 기회를 사용하지 않는다. 감소는 조건을 만족한 적중 시 즉시 정산하고, 최소 대기시간은 감소 대상인 현재 사용의 쿨타임 시작부터 계산한다. 충전 수를 보유하는 스킬의 충전 회복 처리는 미정이다.

쿨타임 감소에는 **기본 쿨타임의 20%에 해당하는 최소 총 대기시간**을 플레이 테스트 시작값으로 둔다. 스킬 쿨타임 시작부터 재사용까지의 시간이며, 잉크 발동 때마다 대기를 새로 시작하지 않는다. 이미 최소 시간이 지났다면 감소로 즉시 준비될 수 있다. 남은 쿨타임이나 이 하한 때문에 사용하지 못한 감소량은 버리며 다음 사용으로 이월하거나 저장하지 않는다. 기본 쿨타임이 10초인 스킬은 쿨타임 시작 후 최소 2초가 지나야 재사용할 수 있다.

파란 피해 증가 잉크는 서로 다른 잉크와 동일 잉크 중복 장착본 모두 **스킬 피해 증가율을 장착본별 합산**한다. 파란 쿨타임 감소율도 동일 잉크 중복본까지 합산한다. 여러 쿨타임 감소 장착본이 동시에 조건을 충족하면 **도면 슬롯 순서대로** 적용하며, 각 장착본 처리 후 남은 스킬 쿨타임과 최소 총 대기시간을 다시 확인한다. 실제 감소량이 양수인 장착본만 내부 쿨타임과 공격당 발동 기회를 사용하며 감소량이 0인 장착본은 둘 다 보존한다. 감소율 합산과 하한에 따른 최종 감소량은 유지하고 실제 기여분을 장착본별로 순서대로 정산한다. 같은 장착본의 재발동으로 합산 항목을 추가하지 않는다. 빨강의 기본 공격 피해 증가율과 파랑의 스킬 피해 증가율에는 **증가율 자체의 별도 수치 상한을 두지 않는다.** 효과별 최대 실제 6칸 기여와 각 잉크의 발동 조건으로 제한하며 두 색의 증가율은 서로 다른 공격 범위에 적용하므로 서로 합치지 않는다. 기존 상태이상 비중첩·방어막 상한·쿨타임 하한은 유지한다.

파랑 6종의 내부 쿨타임은 쿨타임 감소형·피해 증가형과 기본·강화 모두 **4초**를 플레이 테스트 시작값으로 사용한다. 스킬 재사용 대기시간과 별개이며 장착본별로 실제 잉크 발동 시 시작하고, 비활성 무기에서도 계속 진행한다. 빗나가거나 상태 조건이 맞지 않으면 시작하지 않는다. 스킬 쿨타임 감소량이 실제로 양수일 때만 해당 잉크의 발동으로 처리하고, 0이면 내부 쿨타임과 공격당 발동 기회를 보존한다. 재시도에는 원래 적중·상태 조건을 다시 요구하며 초과분은 이월하지 않는다. 두 효과의 한 잉크 내 구성·파랑 효과끼리의 동시 처리 순서는 미정이다. 빨강의 버프 기간·갱신 규칙을 파랑에 자동 적용하지 않는다.

모든 잉크는 런 도감의 부여 횟수 소비·동일 종류 재획득 허용, 무기별 효과·쿨타임 독립과 기본/강화 수치 쌍 규칙을 따른다. 현재 정의한 유형은 노말이며 Unity 일반 런의 새 장비 경로에 연결한다. 전체 런의 밸런스·플레이 가독성 검증은 별도 범위다.

## 화면 표시

잉크 효과는 사용자가 고른 픽셀 FX(2026-11-12)로 표시한다. 그림 원본과 게임용 시트는 `resources/effects/ink-buffs`, 기절의 별 고리는 기존 `resources/effects/ink-status`가 소유한다. 표시는 전투 상태를 바꾸지 않으며 전투 시간에 맞춰 재생한다.

| 효과 | 표시 | 언제 |
|---|---|---|
| 이동속도 증가 | 몸 뒤로 흐르는 노란 바람 줄과 뒤꿈치 `>>` | 유지 중. 남은 0.5초는 깜박인다 |
| 방어막 | 몸을 감싼 초록 잉크 거품막. 생길 때 밖에서 조여 들고, 피해를 막으면 하얗게 번쩍이며 금이 간다. 감소 중에는 점선 | 일반 방어막이 남아 있는 동안 |
| 대쉬 방어막 | 진행 방향 앞쪽의 민트 초승달. 감소가 시작되면 조각나 뒤로 흩어진다 | 대쉬 방어막이 남아 있는 동안 |
| 체력 회복 | 밝은 초록 큰 십자와 회복량(+3·+5), 몸 초록 번쩍임 | 실제 회복량이 있을 때 한 번 |
| 기본 공격력 증가(빨강) | 어깨·머리의 빨간 불꽃과 양옆 위 화살표 | 유지 중. 남은 0.5초는 깜박인다 |
| 스킬 쿨타임 감소(파랑) | 머리 위 파란 시계가 거꾸로 돌다 깨지고 감소율(-15%·-20%) | 실제 감소량이 있을 때 한 번 |
| 스킬 피해 증가(파랑) | 어깨·머리의 파란 불꽃과 양옆 위 화살표 | 발동부터 1.2초 |
| 기절 | 머리 위 금빛 별 고리 | 기절 중 |
| 속박 | 몸을 감싼 보라 밧줄 세 줄. 앞·뒤 시트를 몸 중심에 나눠 표시하며, 몸 너비 2unit 이상은 큰 크기를 쓴다 | 속박 시작부터 종료까지 |
| 슬로우 | 머리 위를 기어가는 보라 달팽이와 옅은 보라 몸 색 | 슬로우 중 |

강화본은 회복량·감소율 숫자와 입자 수가 다른 강화 행을 쓴다. 스킬 피해 증가 표시 1.2초는 "같은 스킬 사용의 남은 타격" 동안을 대신하는 화면 표시 시간이며 피해 규칙을 바꾸지 않는다. 상태 조건으로 강화된 타격 자체를 따로 표시하지 않는다.
