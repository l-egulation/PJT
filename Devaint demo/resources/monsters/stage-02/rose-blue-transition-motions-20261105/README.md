# Rose·Blue 승인 전환 모션

- 로즈: B안 8프레임, 쓰러짐 동작 440ms. 시작 자세 100%, 두 번째 97%, 이후 94%. 공통 발밑 기준 (192,232).
- 블루: 낙하·착지 원본 13~20, 회복 21~36을 80ms로 유지. 회복의 구체 잔여물·외곽 픽셀 정리.
- 블루 무릎 꿇은 들썩임: 별도 승인 자세 390×264 캔버스. 강제 크기 통일하지 않음.
- source는 제공 원본·생성 원본·참조·요청문을 보존합니다. runtime은 검토 승인 출력이며 Unity에 연결된 상태를 뜻하지 않습니다.
- preview/rose-first-absorption/index.html: 로즈 선행 사망 → 블루 낙하·회복 → 임시 말풍선 대화 → 흡수 → 기존 포효·강화형의 합성 검토본. 흡수·대사는 미확정이며 전투 규칙을 변경하지 않습니다. lineup.html은 같은 배율 비교입니다.
- 로컬 웹 서버로 이 디렉터리를 열어 미리보기를 확인합니다. 예: python -m http.server 8152 --directory preview/rose-first-absorption
- 생성 방식: 로즈 정적 쓰러짐 키는 내장 imagegen, 쓰러짐·블루 착지 원본은 사용자 제공 Aether 출력. 픽셀·배경·색·타이밍 보정은 로컬 편집.
