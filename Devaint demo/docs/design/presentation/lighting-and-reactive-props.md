# 조명·명암·반응형 소품

[분야 개요](README.md)

이 문서는 조명과 반응형 소품의 제품 방향·확정 범위다. [아트·연출 기준](art-and-presentation.md), [전투 규칙](../combat/rules.md)을 함께 따른다. 소프트웨어 구조는 [기술 설계](../../development/presentation/visuals/lighting-and-reactive-props.md), 랜턴·창문·횃불의 제작 계약은 [에셋 규격](../../assets/presentation/lighting-props.md)이 소유한다.

**설계 방향과 범위는 확정했으며, 조명·노말·동적 그림자의 전체 연결은 합성 진단 에셋을 쓰는 공통 전투 실험장 범위다. 2챕터 S/F01에는 분리 랜턴·횃불의 소수 배치와 몸·지원 근접 반응을 시험한다. 실제 아트 전체의 노말·그림자·전체 모션·본 게임 통합은 미완료다.** 지원 범위·실행과 검증 방법은 기술 설계와 [소수 배치 계약](../../assets/presentation/lighting-props.md#2챕터-소수-배치-시험)을 따른다. 기존 장식용 불빛이나 URP 설정의 존재를 이 기능 전체의 완료로 해석하지 않는다.

## 1. 확정 방향

| 항목 | 적용 기준 |
|---|---|
| 활용 | 실내 창문, 천장 랜턴, 벽 횃불과 석양 등 맵 분위기 연출 |
| 표면 명암 | 캐릭터·몬스터에 노말맵을 적용하고 기존 잉크·스케치 화풍을 유지하는 완만한 픽셀 명암 |
| 명암 단계 | 초기에는 부드러운 변화를 유지하며 2~3단 셀 명암으로 강제 양자화하지 않음 |
| 투영 그림자 | 지형뿐 아니라 캐릭터·몬스터까지 초기 지원 범위에 포함 |
| 랜턴 반응 | 몸·공격에 반응하지만 캐릭터의 통행을 막거나 캐릭터를 밀지 않는 단방향 반응 |
| 전투와의 관계 | 조명·그림자 출력이 피해·공격 시각·쿨타임·이동 판정을 바꾸지 않음 |

캐릭터·몬스터 그림자는 후순위 선택 기능으로 취급하지 않는다. 다만 첫 기술 실험의 대표 각 1종과 전체 콘텐츠 적용 완료는 구분한다.

## 2. 빛과 그림자의 구분

| 표현 | 담당하는 결과 | 자동으로 제공하지 않는 결과 |
|---|---|---|
| 노말맵 표면 명암 | 광원 방향에 따른 얼굴·옷·몸 표면의 밝고 어두운 면 | 바닥으로 드리우는 그림자, 코·옷 주름의 실제 자기 차폐 |
| 투영 그림자 | 벽·구조물·소품·캐릭터·몬스터가 다른 빛을 차폐하는 실루엣 | 높이와 깊이를 해석하는 정확한 3D 바닥·벽 투영 |
| 발광 | 불꽃·전구·밝은 창문 자체의 밝기 | 주변 물체를 실제로 비추는 조명 |
| 빛줄기 | 창문이나 랜턴에서 보이는 빛의 경로·먼지 | 공격 판정·이동 충돌·새 게임 규칙 |

기본 투영 그림자는 2D 평면 차폐다. 석양의 평행 태양광, 긴 바닥 그림자, 벽을 꺾어 타는 그림자는 별도 표현·기술 검토 대상이며 초기 구현이 이를 자동 제공한다고 약속하지 않는다. 접지 그림자를 추가할 경우에도 별도 표현으로 구분한다.

## 3. 시각 기준

- 노말은 큰 형태 중심으로 완만하게 사용한다. 기존 그림의 고정 명암과 동적 명암이 중첩되어 검게 뭉개지거나 선·빗금·무늬가 요철처럼 솟지 않아야 한다.
- 모션·반전·광원 이동에서 명암과 그림자가 튀거나 표면이 끓어 보이지 않아야 한다.
- 투영 그림자의 경계는 반그림자로 완만하게 전환한다. 광원 밝기도 바깥으로 부드럽게 감쇠시키되, 화면 전체 블러나 컬러 텍스처 필터 변경으로 캐릭터 실루엣·픽셀·외곽선을 흐리지 않는다. 그림자 중심의 차폐와 전투 판독성은 유지한다.
- 플레이어의 기존 1텍셀 잉크 외곽선을 유지한다. 피격 점멸·색 바램·알파와 조명 합성도 함께 검증한다. 컬러 구간 외곽선의 별도 전환 미정 사항을 이 기능에서 임의 확정하지 않는다.
- 공격 예고·필수 판독 표현·UI는 어두운 구간에서도 읽혀야 한다. 전체 공용 머티리얼을 일괄 Lit로 바꾸지 않는다.
- 마을의 따뜻한 종이·흑연선과 지하수로의 저채도 재질 차이를 보존한다. 석양은 전체 화면의 주황색 덮개만으로 처리하지 않는다.

## 4. 조명의 활용

### 창문

실내에서 외부 빛이 들어오는 창문과 실외에서 보는 밝은 창문은 조명 방향·영향 범위를 구분한다. 창문 자체 발광, 주변을 비추는 조명, 선택적인 빛줄기를 분리한다. 창문이 있다는 이유로 실내 진입·창문 개폐 같은 상호작용 규칙을 추가하지 않는다.

실내 유입광은 창문 중앙의 원형 광원이 아니라 개구부 면적을 지정 방향으로 펼친 영역이다. 사각형 또는 여러 열린 다각형을 조합한 개구부에서 방향 각도·도달 거리·경계 감쇠를 조절하고, 명시한 실내 수신 범위 안으로 제한한다. 십자 프레임은 열린 유리 영역 사이의 빈 공간으로 제외하고 곡선은 다각형으로 근사한다. 여러 창문은 같은 수신체에 독립적으로 더하며 한 창문의 소등이 다른 창문을 지우지 않는다. 각도는 창문 앵커의 XY 좌표에서 0°=오른쪽, +90°=위, -90°=아래다. 창문 영역·표면 노말 명암·그림자·빛줄기는 같은 평행 유입 방향을 사용한다. 창문 중앙이나 출구 한 점을 기준으로 그림자가 부채꼴로 벌어지거나, 수신체 위치에 따라 입사 방향이 바뀌어서는 안 된다. 실제 표면 조명과 빛줄기 표시는 독립적이며 빛줄기만 꺼도 조명은 남는다. 이 2D 평행 투영을 물리적 면적광의 다중 각도 적분·3D 산란·곡면 창이나 창살 두께의 정밀 투과까지 구현한 것으로 보지 않는다.

### 랜턴·횃불

광원은 불꽃·전구 소켓에 부착한다. 깜빡임과 소품 운동은 독립 설정이다. 랜턴이 흔들리면 본체·광원 위치·빛줄기와 주변 캐릭터의 명암·그림자가 일관되게 움직인다. 원형 광원은 회전만으로 비추는 모양이 달라지지 않으므로 소켓 위치 변화와 광원 형상을 구분한다.

천장 랜턴은 고정 앵커 아래의 감쇠 진자로 시작하고, 벽 횃불은 고정형으로 시작한다. 모든 조명에 흔들림을 강제하지 않는다.

랜턴 연결부는 일자 막대 대신 사슬·줄 두 외형을 지원한다. 사슬은 정면/측면 고리가 번갈아 이어지고 줄은 연속된 곡선으로 표시한다. 충격·흔들림에 따른 작은 표현 지연으로 중간 부분이 휘어 보여도 천장 부착점과 랜턴 연결 소켓은 정확히 유지한다. 연결부의 외형·굽힘은 기존 진자·광원 소켓·몸/공격 판정을 바꾸지 않으며, 고리별 강체·관절 물리를 추가하는 기능은 아니다.

### 석양·구역·시퀀스

환경광, 따뜻한 주광, 상대적으로 차가운 음영, 배경·안개·색보정을 프로필로 조절한다. 기본 환경·현재 구역·연출 요청의 합성으로 전환하며, 구역 경계에서 반복 점멸하지 않아야 한다. 시퀀스의 정상 종료·취소·스킵은 각 콘텐츠가 선언한 상태와 수명 계약을 따른다.

현재 공통 실험장은 사각 구역 안쪽 거리 기반 환경광 블렌드와 바깥 이탈 여유를 두는 히스테리시스를 지원한다. 경계 왕복은 같은 소유 요청을 유지하고 상위 진단 연출을 해제하면 현재 구역으로 돌아간다. 실제 제품 맵의 구역·시퀀스, 방향성 태양·배경·안개 전체 연출을 통합한 상태는 아니다.

스케치/컬러와 점등/소등은 별도 축이다. 기록 삭제나 색 복구가 자동으로 불을 끄고 켜는 규칙은 정하지 않는다.

## 5. 랜턴의 접촉 규칙

- 몸 접촉은 실제 몸 이동을 기준으로 한다. 무기·스카프·이펙트·빛 번짐을 몸 크기로 사용하지 않는다.
- 단순 겹침만으로 매 프레임 충격을 가하지 않는다. 빠른 이동·대시의 접촉 누락도 검사한다.
- 2챕터 소수 배치 시험은 플레이어 몸의 새 접촉과 수락한 지원 근접 타격에 접촉 면의 짧은 흰 테두리 섬광을 표시한다. 몸 접촉 유지·같은 타격의 반복 표본·적 접촉은 중복 표시하지 않으며 밝기는 국소 표현으로 한정한다.
- 공격은 실제 활성 구간·판정 형상과 벽 차폐를 사용한다. 같은 타격의 여러 프레임·콜라이더 접촉은 중복 충격으로 처리하지 않는다.
- 반응 강도는 HP 피해량과 분리한다. 피해량 강화가 자동으로 과도한 진폭을 만들지 않는다.
- 소품 접촉만으로 전투 적중 보상·잉크 효과·콤보 성공을 발생시키거나 투사체를 소모·차단하고 관통 횟수를 줄이지 않는다.
- 소품은 가짜 몬스터나 HP 0짜리 전투 액터로 등록하지 않는다.
- 근접·투사체·폭발·지속 공격은 지원 종류와 반복 충격 정책을 명시한다. 대표 근접 실험 통과를 모든 공격 지원 완료로 간주하지 않는다.

## 6. 초기 제외·미정 범위

초기 범위에서 랜턴의 양방향 물리 충돌, 고리별 다중 체인 물리, 파손·낙하·화재 피해, 색유리 투과·굴절은 제외한다. 조명 기반 은신·AI 시야·추가 피해·보상 규칙도 추가하지 않는다.

광원 수·겹침 상한, 그림자 해상도, 대상 PC 성능 예산, 빛의 색·범위·깜빡임·진자 수치, 공격별 충격값, 최종 소품 크기와 무기·스카프의 차폐 포함 여부는 실측·제작 바인딩으로 확정할 항목이다. 약 20×36px 랜턴은 첫 미술 검토 기준이지 승인된 최종 규격이 아니다.

성능 부족 시 형상 단순화·영향 범위·그림자 해상도부터 조정한다. 캐릭터·몬스터 그림자를 지원 범위에서 제거해야 한다면 별도 범위 결정이 필요하다.
