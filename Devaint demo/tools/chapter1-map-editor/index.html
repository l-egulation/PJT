가로세로

둘러보기 모드에서는 아래 화면을 드래그해 이동할 수 있어. 지형을 지워도 별도 배치한 발판은 남으므로 배치 편집 모드에서 선택해 삭제해줘. 나무·뿌리 발판은 통과 바닥, 흙층이 있는 발판은 고체 발판이야. 트램펄린은 기능 배치 표시이며, 이 페이지에서 캐릭터를 조작하는 물리 시뮬레이션은 제공하지 않아.

선택한 배치

지도 또는 아래 목록에서 영역을 골라줘.

편집 내용은 이 브라우저에 자동 보관돼. 다른 PC로 옮기거나 확실히 남길 때는 JSON 파일로 저장해. Ctrl+Z / Ctrl+Y / Ctrl+S도 사용할 수 있어.
