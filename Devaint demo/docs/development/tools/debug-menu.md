# 공통 치트 모드 명세

[분야 개요](README.md)

치트 모드 메뉴의 구현 계약이다. 화면·문서·빌드 요청은 **치트 모드**로 통일하며, `DEVIANT_DEBUG_MENU`와 `DebugGameMenu` 등 기존 코드 식별자·검사 인자는 호환성을 위해 유지한다. 게임 조작 연결은 `ForestCombatV2/Runtime/DebugGameMenu.cs`, 새 런 장비 편집은 `DebugGameMenu.Sketch.cs`, 공유 행 배치·렌더링은 `DebugGameMenu.Layout.cs`, 빌드 포함 설정은 `Editor/DebugMenuBuildOption.cs`가 담당한다. 실행 검증 범위는 아래와 구분한다.

## 접근과 입력

- 빌드 옵션으로 치트 모드 포함 여부를 선택한다. `Tools > deviant > 치트 모드 > 플레이어 빌드에 치트 모드 포함`에서 현재 빌드 대상의 `DEVIANT_DEBUG_MENU` 심볼을 전환한다. 에디터에서는 사용할 수 있고 플레이어 빌드는 Development 여부와 관계없이 이 옵션으로 포함한다. 일반 빌드에도 포함할 수 있다. 포함하지 않은 빌드에서는 메뉴와 조작을 사용할 수 없다. Windows에서 메뉴와 스크립트 디버깅을 함께 켜려면 [Windows 개발 빌드](../delivery/build-and-distribution.md#windows-x64-바이너리)의 `GameBuilder.BuildWindowsDebug`를 사용한다.
- 기존 게임 입력과 충돌하지 않는 전용 키와 게임패드 버튼 조합으로 열고 닫는다. 키보드는 Ctrl+백틱, 게임패드는 왼쪽 스틱 버튼(L3)을 누른 상태에서 오른쪽 스틱 버튼(R3)을 눌러 전환한다. 방향키·왼쪽 스틱·십자키로 탐색/값 변경, Enter/A로 실행, Backspace/B로 뒤로 간다. 화면 상단의 뒤로·닫기 버튼으로도 조작하며 Esc는 선택 목록·확인창·세부 메뉴에서 한 단계 뒤로 가고, 메인 분류 화면에서만 치트 모드를 닫는다. 상단 닫기 버튼과 열기 단축키는 어디서든 전체 닫기다.
- 키보드와 게임패드만으로 분류 이동, 선택, 값 변경, 적용, 뒤로 가기와 닫기를 지원하고 마우스도 지원한다. 선택 상태와 입력 안내를 표시한다.
- 메뉴를 열면 게임을 일시정지하고 닫으면 기존 정지 상태를 복원한다. 메뉴 입력이 게임 조작에 전달되지 않게 한다.
- 씬이나 상태에 따라 사용할 수 없는 기능은 이유와 함께 비활성화한다. 실행 결과와 실패 이유를 표시한다.
- 기존 F5, F9, F10, Alt 기믹 단축키와 마을 G 정상 이동는 제거하고 해당 기능을 메뉴로 통합한다. 그 밖의 기존 개발 단축키와 UI도 조사해 통합 대상을 정한다.

- 메뉴 패널은 화면 중앙에서 너비·높이를 각각 약 70.7%로 하여 전체 화면 면적의 절반을 차지한다. 메뉴는 1280×720 기준 본문 20·제목 26·버튼 최소 높이 52·버튼 간격 6로 표시하고 화면 크기에 비례해 확대/축소한다. 분류·이름 선택 목록·짧은 실행 항목은 2열로 배치하고, 슬롯 탭은 라벨 옆에 놓는다. 재화는 현재 수량·목표 수량·적용을 한 줄에, 해금은 현재/목표 단계·저장을 한 줄에 묶는다. 장비의 선택 컨트롤에 이미 표시한 현재 값은 별도 설명 행으로 중복하지 않는다. 효과 설명과 실패 이유는 줄바꿈해 표시하고, 긴 실행 결과는 높이가 제한된 스크롤 영역에서 전부 확인한다. 방향키·패드의 상하 입력은 분류·선택 목록의 같은 열로 이동하고 세부 설정에서는 읽기 순서로 모든 조작을 순회한다. 좌우 입력은 값/탭 변경 또는 같은 줄의 버튼 간 이동이다. 긴 항목은 줄바꿈에 맞춰 높이를 늘리고, 키보드·게임패드 선택 항목이 스크롤 영역에 보이도록 맞춘다.

## 분류와 기능

### 이동·진행

스테이지 이동 그룹에서 마을·1챕터·2챕터로 이동한다. 2챕터처럼 `ForestCombatWorld`가 없는 씬에도 이 그룹을 표시한다. 실행 전 현재 런의 진행·장비·체력을 이어가지 않는다는 확인창을 띄우며 취소하면 현재 씬과 런을 유지한다. 1·2챕터는 새 테스트 런으로 시작하고 2챕터는 보스 처치·클리어 조건을 요구하지 않는다. 마을 귀환은 기존 마을 진입을 사용한다. 스테이지 이동으로 보스 처치·챕터 클리어·영구 해금 기록을 추가하지 않는다. 씬 전환·사망·포탈 동작 중에는 거부하며, 성공 시 치트 모드를 닫고 정지·입력 차단을 반환한다. 같은 챕터를 선택해도 새 테스트 런으로 다시 시작한다. 기존 보스방·구간 이동의 현재 런 보존과 구분한다.

마을의 하늘길(점프맵) 정상 이동을 마을 · 하늘길 그룹에서 제공한다. 기존 G 입력은 제거하며, 이동은 기존 연습 판 처리와 도착 연출을 유지하고 최고 기록에 포함하지 않는다. 메뉴를 닫으면 도착 연출이 이어진다. 마을 밖에서는 비활성 이유를 표시한다.

현재 런의 보스방 이동, 봉인 석판·잠긴 상자·열쇠 보유 적 이동, 지원하는 구간 이동, 새 배치로 시작을 제공한다. 보스방 이동은 현재 런·시드·장비·체력·적 상태를 유지한다. 치트 모드의 보스방 이동은 치트 모드 및 다른 화면의 정지·입력 차단을 해제하지 않고 위치 변경 명령만 수행한다. 사망·포탈 동작·런 종료는 계속 거부한다. 이전 맵 선택기의 직접 호출은 기존 정지 차단 규칙을 유지한다. 전용 버튼과 구간 이동은 현재 월드의 방 이동 경로를 사용하며 이전 맵 선택기 컴포넌트나 별도 바닥 레이캐스트 유무에 의존하지 않는다. 전용 버튼은 방의 입구 높이를 기준으로 왼쪽 바닥에 배치하고 카메라·입구 벽을 즉시 맞춘다. 거부 시 런 종료·사망·포탈 등의 이유를 표시한다. 새 배치 시작 전 확인한다. 이동 가능 조건은 기존 게임 상태와 대상 존재 여부를 따른다.

### 플레이어·재화·전투

**게임 초기화**는 별도 확인창에서 적용하면 모든 플레이 데이터(영구 프로필의 재화·해금·스토리·튜토리얼·클리어·하늘길 기록과 현재 런의 장비·가방·진행)를 초기화하고 타이틀로 돌아간다. 복구 백업도 새 프로필로 교체하여 이전 진행이 복원되지 않게 한다. 취소·뒤로·닫기는 데이터를 변경하지 않으며 저장 실패 시 기존 프로필·런·씬을 유지하고 실패 이유를 표시한다. 음량·단축키 등 기기 설정은 유지한다. ESC 메뉴에서는 제공하지 않으며 치트 모드를 제외한 빌드에서는 사용할 수 없다.

기존 F5의 장비 유지 전투 초기화를 제공한다. 골드와 로그라이트 재화는 종류별 현재 수량을 표시하고 허용 범위의 목표 수량을 지정해 적용한다. 런 한정 값과 저장되는 값을 구분해 표시한다. 로그라이트 재화 변경은 실제 저장에 반영하며 적용 전 확인한다. 새 체력·쿨타임 개별 조작은 이번 범위에 포함하지 않는다.

현재 런의 **보상 +1**은 「플레이어·재화·전투 → 보상 · 현재 런」에서 제공한다. 누를 때마다 받아 둔 보상을 1개 더하고 현재 개수와 결과를 표시한다. 치트 모드를 닫거나 보상 화면을 자동으로 열지 않는다. 처치 기록·현재 게이지·게이지 필요량을 바꾸지 않으며, 이후 보상을 열고 선택할 때는 기존 회차·무기 보장·보상 단계 규칙을 따른다. 이미 열린 보상의 후보와 선택 순서도 유지한다. 런 보상 상태가 없는 씬과 사망 상태에서는 이유를 표시하고 실행을 거부한다. 현재 런에만 적용하며 영구 저장을 바꾸지 않는다.

### 장비·잉크

일반 런은 `WeaponGrowth.Sketch`의 실제 장착 상태를 편집한다. 무기 1·2 탭에서 형태와 스킬을 선택하면 런 소유 장비와 실제 전투 장비를 함께 갱신하며, 다음 장비 동기화·치트 모드 종료·전투 초기화 뒤에도 선택을 유지한다. 빈칸에 무기를 선택하면 확정된 치트 모드 무기와 무색 3칸 팔레트를 생성한다. 기존 무기의 형태·스킬 변경은 무기 ID·내구도·팔레트·장착 잉크를 유지한다. 맨손을 선택하면 해당 칸을 비우고 기존 무기는 가방에 남긴다.

잉크 선택 목록은 현재 런 카탈로그의 39종과 없음이다. 보유·도감 등록 여부와 관계없이 치트 모드에서 적용하며 도감의 등록 상태와 골드를 변경하지 않는다. 팔레트는 3~5칸과 각 칸의 무색·5색을 지정한다. 색이 일치하면 해당 잉크의 강화 값, 다르면 기본 값을 사용하며 효과 설명과 현재 적용 구분·재발동 대기시간을 표시한다. 같은 잉크의 색만 바꿀 때는 장착본과 남은 쿨타임을 유지하고, 다른 잉크로 바꾸거나 비울 때 해당 칸의 쿨타임을 0으로 만든다. 줄어들 칸에 잉크가 있으면 먼저 비우도록 안내한다. 일반 런에는 구형 +0~+5 강화 단계·스탬프·파츠 시험 세트를 표시하지 않는다.

치트 모드 편집은 일반 장착 대기·확정 후 편집 금지의 예외이며, 기존 장착 대기시간 자체는 소비하거나 초기화하지 않는다. 일반 인벤토리의 확정·도감·장착 대기 규칙은 그대로 적용한다. 치트 모드 변경은 현재 런에만 유지하고 새 런에서 초기화한다. 공격 도중 메뉴를 연 경우 편집 시 현재 공격을 취소하고 입력 상태를 정리한다. 사망·대시·포탈 중에는 적용을 거부하고 이유를 표시한다.

`Sketch`를 사용하지 않는 훈련장·구형 구성에서는 기존 무기·스킬·스탬프 기록, 팔레트 색상과 잉크 파츠·강화 단계, F9 시험 세트를 편집한다. 이 경로의 세부 규칙은 아래 구형 팔레트 편집 안내를 따른다.

### 로그라이트 해금

마을에서 해금하거나 강화할 수 있는 항목을 실제 데이터의 카테고리별로 표시한다. 각 항목의 현재 해금 상태·강화 단계·효과와 변경할 값을 보여 주고 해금/미해금 또는 허용 범위의 단계를 지정한다. 변경은 실제 저장에 반영하며 적용 전 확인한다. 치트 모드의 해금 적용은 선행 해금·클리어·조각·재화·가격 확정 조건을 무시한다. 적용 후 충족하지 않은 조건들을 나열하고 임의 설정 완료를 안내한다. 재화는 차감하지 않는다. 저장 프로필의 `debugUnlockOverrides`에 예외 항목을 명시하여 재실행 시에도 유지하되, 클리어 이력을 만들거나 다른 해금을 임의로 구매하지 않는다. 일반 구매와 일반 프로필의 조건 검증은 그대로 적용한다. 장착 파츠의 해금 취소 충돌은 계속 표시한다.

### 몬스터

현재 씬에서 실제로 사용하는 몬스터 카탈로그를 이름 목록으로 표시하고 선택한다. 예전 시험 씬의 고정 종류 번호를 현재 스테이지에 사용하지 않는다. 배치 모드에서는 마우스로 커서를 옮기거나 방향키·왼쪽 스틱·십자키로 이동하고, 마우스 왼쪽 클릭·Enter·패드 A로 선택한 위치 아래의 평평한 바닥에 생성한다. 메뉴 상단 버튼이나 게임 화면 밖의 클릭은 배치하지 않는다. 배치 모드를 여는 입력은 생성 입력으로 중복 처리하지 않는다.

치트 모드의 일시정지와 게임 입력 차단을 유지한 상태에서도 배치할 수 있다. 성공 시 몬스터 이름과 완료 안내를, 실패 시 바닥 부재·몸 전체 지지 부족·지원하지 않는 종류 등의 이유를 표시한다. 새 몬스터는 AI 정지 상태로 생성하며 메뉴에서 AI 시작·정지를 조작한다. 배치 모드를 유지해 반복 생성할 수 있고 Esc/B로 종류 설정으로 돌아간다. 제거 명령은 해당 치트 모드로 생성한 시험 몬스터만 제거한다. 씬별 지원 범위와 배치 가능 조건을 표시한다.

### 표시·진단

기존 판정 표시, 체력바, 전투 진단 정보와 구간 표시 등 씬에서 지원하는 표시 기능을 개별적으로 조작한다.

### 전용 시험장

보스 시험방의 체력 단계 적용과 전투 재시작 등 전용 씬의 기능을 제공한다. 해당 시험장이 아니면 사용 불가 이유를 표시한다.

## 구현과 검증

기존 기능·씬별 조건·입력 충돌과 재화·해금 데이터 및 저장 규칙을 조사한 뒤 공통 메뉴에 연결한다. 키보드·게임패드 탐색과 커서 배치, 입력 차단과 정지 상태 복원, 씬별 사용 조건, 런 상태와 저장 변경, 빌드 옵션 포함·제외를 Unity 6000.6.5f1에서 검증한다. 문서의 목표는 구현 또는 검증 완료를 뜻하지 않는다.

현재 검증은 Unity 6000.6.5f1의 프로필 저장 회귀 검사, 메뉴 제어 범위 검사, 현재 씬 카탈로그 기반 몬스터 배치 검사로 수행한다. 새 런 장비 검사는 실제 1챕터의 치트 모드 이름 목록으로 무기·스킬·색상·잉크를 적용하고, 무기 ID·내구도·장착본과 골드·도감 상태 보존, 39종 선택·기본/강화 전환, 칸 수 변경·잘못된 입력 거부, 치트 모드 종료·전투 초기화 후 장비 유지와 실제 공격 시작을 확인한다. 일반 인벤토리의 확정 후 편집 금지도 별도로 검사한다. 몬스터 검사는 Input System의 가상 마우스·키보드·패드 입력으로 이동·클릭·Enter/A 생성, 상단 메뉴·화면 밖 클릭 차단, 배치 실패 안내와 치트 모드 생성 몬스터만 제거하는 동작을 확인한다. 실제 게임패드 하드웨어와 플랫폼별 플레이어 빌드 검증은 자동 검사 결과와 구분한다.

스테이지 이동 회귀는 `Deviant.Run.Tests.RunFlowTests`의 새 테스트 런 초기화·클리어 조건 유지 검사와 `Deviant.Chapter2.Tests.Chapter2Tests.DebugStageButtonsCancelThenTravelBetweenChaptersAndVillage`로 확인한다. 후자는 실제 1챕터에서 이동 취소 뒤 런 보존, 2챕터 직접 진입, 2챕터 치트 모드의 1챕터 이동, 마을 이동과 치트 모드 정지 반환을 검사한다. Unity 6000.6.5f1의 격리 프로젝트에서 EditMode로 실행하며 화면 가독성·실물 패드 검증과 구분한다.

## 치트 모드 빌드 요청

“치트 모드로 빌드해줘”는 일반 빌드의 `BuildOptions.None`을 유지하고 `extraScriptingDefines`에 `DEVIANT_DEBUG_MENU`만 추가하라는 뜻이다. Development Build·Script Debugging·프로파일러 연결은 켜지 않는다. 플랫폼별 진입점은 `GameBuilder.BuildLinuxCheatMode`, `GameBuilder.BuildWindowsCheatMode`, `GameBuilder.BuildWebCheatMode`이며 Editor 메뉴는 `Tools > deviant > Game > Build <플랫폼> With Cheat Mode`다. 별도의 스크립트 디버깅 요청에만 `BuildWindowsDebug`를 사용한다.

`DEVIANT_CHEAT_BUILD_OUTPUT`으로 출력 디렉터리를 지정한다. 기본 경로는 `outputs/builds/linux-cheat`, `outputs/builds/windows-cheat`, `outputs/builds/web-cheat`다. 기존 `DEVIANT_DEBUG_BUILD_OUTPUT`은 새 변수가 없을 때만 호환용으로 읽고, 기존 Linux 배치 호출 `BuildLinuxDebug`는 `BuildLinuxCheatMode`에 위임한다. 전역 define은 변경하지 않는다.

## Linux 빌드와 실행

현재 프로젝트의 전체 진입 경로를 포함하고 치트 모드를 켠 일반 Linux 빌드는 `Tools > deviant > Game > Build Linux With Cheat Mode` 또는 Unity 배치 모드의 `-executeMethod Deviant.Game.Editor.GameBuilder.BuildLinuxCheatMode`로 만든다. Development Build는 사용하지 않고 해당 빌드에만 `DEVIANT_DEBUG_MENU`를 추가한다. 출력은 Git 제외 `outputs/builds/linux-cheat/`이며 `DEVIANT_CHEAT_BUILD_OUTPUT` 환경 변수로 변경할 수 있다. 실행 파일은 `deviant.x86_64`이고 같은 폴더의 데이터·플레이어 라이브러리와 함께 사용한다.

일반 Linux 빌드의 보스방 버튼 경로는 실행 파일에 `-batchmode -nographics -debugMenuBossSmoke <로컬 JSON 결과 경로>`를 지정해 검사할 수 있다. 이 명시적인 검사 실행에서만 시험용 소유자가 타이틀에서 1챕터로 진입하고, 이전 맵 선택기를 제거한 상태로 치트 모드의 보스방 이동 명령을 실행한다. 도착 위치와 런·시드·장비·체력·적 상태를 확인하고 결과를 기록한 뒤 종료한다. 평소 실행에서는 동작하지 않는다.

일반 Linux 빌드에 `-debugMenuLayoutSmoke <로컬 JSON 결과 경로>`를 지정하면 그래픽 출력을 사용하는 명시적 UI 검사로 실행한다. 현재 스테이지에서 분류·장비·이름 목록·잉크 설명·재화·해금·이동·몬스터 화면을 순회하여 결과 파일 옆의 `dense-captures/`에 화면을 저장하고 종료한다. 이 검사는 `-nographics` 없이 실행하며 실제 재화·해금 저장 명령은 실행하지 않는다.

## 구형 팔레트 편집

이 절은 `Sketch`를 사용하지 않는 훈련장·구형 구성의 편집 규칙이다. 일반 런의 39종 잉크 편집은 위 장비·잉크 항목을 따른다.

장비 편집 대상은 무기 탭, 팔레트 칸 탭, 잉크 칸 탭으로 직접 선택한다. 좌우 입력으로 탭을 바꾸고 Tab/Shift+Tab 또는 패드 LB/RB로 무기 탭을 전환한다. 형태·스킬·색상·잉크 파츠는 번호 증감 대신 이름 목록에서 선택하고 즉시 반영한다. 선택 목록의 Esc는 변경하지 않고 상위 설정으로 돌아간다. 팔레트는 기존 칸의 색상을 개별 변경할 수 있고 다른 칸·팔레트 ID·강화·파츠 ID·골드·일반 색 변경 횟수를 유지한다. 장착 파츠와 호환되지 않는 색 변경은 거부한다. 무색은 기존 규칙대로 첫 칸에서만 선택한다. 팔레트 칸 수는 탭을 고르는 즉시 변경하며, 유지되는 칸의 색상·파츠·강화·ID와 팔레트 ID를 보존한다. 줄어드는 칸에 파츠나 강화가 남아 있으면 변경을 거부하고 먼저 비우도록 안내한다.

팔레트 칸별 색상은 목록에서 고르는 즉시 적용하며 별도의 적용 버튼을 두지 않는다. 호환되지 않는 장착 파츠가 있으면 원래 색상·파츠를 보존하고 실패 이유를 표시한다. 색상 파츠 선택 화면에는 편집 원본의 효과 설명과 선택한 강화 단계의 수치(`StatsAt`)를 일반 텍스트로 표시한다. 강화 단계는 장착 칸 기준 +0~+5이며, 파츠 선택이나 단계 변경 즉시 반영한다. 단계만 바꿀 때는 장착 파츠 ID를 유지한다. 다른 칸·파츠·골드와 일반 강화 비용은 변경하지 않는다.

장비·스킬·팔레트·파츠·강화 단계·시험 세트는 선택 즉시 반영하며 별도의 적용 버튼을 두지 않는다. 칸 수를 늘릴 때 새 칸은 마지막 칸의 색상으로 생성한다.
