# 마을 기하·게임 배치 도구

메인은 마을의 논리 기하·게임 배치 JSON과 Unity 어댑터를 소유한다. `generate_layout.py`와 `generate_presentation.py`는 명시한 `outputs/`에 검토용 기하·배치를 만들며 이미지나 현재 씬을 자동 교체하지 않는다. 이동·충돌·탄도 검증과 미술 승인을 구분한다.

현재 게임 이미지는 [고정 리소스 배치](../../docs/assets/README.md)로 준비한다. 정상 컬러·스케치·지형·점프대의 원본 바이트·전체 투명 캔버스·접촉선·GUID를 유지한다. 선택한 세트 외 이미지를 자동으로 추가하지 않는다.

이미지 등록·지형/발판 제작 알고리즘과 기준점 JSON은 `resources/authoring/workbench/source/tools/stage1_village_experiment/`에 원본 입력으로 보존한다. 이 원본 코드는 소비자 실행기가 아니며 메인에서 직접 실행하는 배치/복원 절차로 사용하지 않는다. 지원되는 공통 리소스 검증·출력은 `resources/tools/`가 담당한다. 새 아트 제작은 해당 원본 입력과 승인 상태를 먼저 확인한 뒤 분리된 검토 출력으로 진행한다.

실제 1Stage 마을·스케치 원본이나 씬을 수정하는 작업은 루트 `AGENTS.md`의 전용 작업 폴더·브랜치 기준을 유지한다. 이번 리소스 경로는 그 제한을 우회하거나 미채택 그림을 자동 승인하는 경로가 아니다.
