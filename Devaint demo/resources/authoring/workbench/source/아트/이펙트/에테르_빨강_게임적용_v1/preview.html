에테르 빨강 이펙트 · 실제 게임 적용

TwilightInkHUDTest 씬의 실제 Unity Play Mode 촬영. 에테르 시트를 투명 PNG로 정리하고 실제 타격에 연결했습니다.

기본 크기: 표식 8×12px / 폭발 40px

타격마다 별도 표식 생성 → 마지막 프레임 유지 → 세 표식 완성 → 모여서 폭발. 피격의 빨간 실루엣과 구분되도록 폭발의 밝은 빨강을 조금 밝게 조절했습니다.

빨강의 역할: 표식 누적·폭발. 현재 적용은 시각 효과 시안이며, 추가 폭발 피해 수치는 변경하지 않았습니다.
