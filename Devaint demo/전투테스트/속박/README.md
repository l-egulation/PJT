# 속박 이펙트 시험판

보라 잉크 파열 족쇄(표식 격발 시 1초 속박)가 몬스터를 묶을 때 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다. 지금 게임의 임시 표시(발밑 링 + 사슬)를 대신할 후보다.

발 둘레 바닥에 보라 빛이 먼저 번지고, 그 자리에서 빛 말뚝 다섯이 바깥 것부터 비스듬히 땅을 뚫고 솟아 안쪽으로 조여 발을 붙잡는다. 0.05초 만에 촥 박히고 그대로 멈춘다. 1초가 끝날 무렵 다시 땅속으로 빠져 사라진다. 말뚝은 [`glow-path.js`](glow-path.js)로 경로 전체까지의 거리를 재서 흰 심 → 보라 → 반투명 번짐으로 칠한다.

- `root.js`: 이펙트(1초). 옵션 `count`(말뚝 수, 5), `order`(`out` 바깥→안 / `in` / `all` 한꺼번에 / `rand`), `rise`(솟는 시간, 0.05), `over`(넘침, 0), `shake`(박힌 뒤 떨림, 0), `len`·`lenVar`, `width`, `spread`(바깥 기울기), `bend`(안쪽으로 휨).
- `glow-path.js`: 빛나는 꺾은선. 선분마다 따로 그리면 이음매가 두 번 칠해져 진해지므로 경로 전체를 한 번에 잰다.
- `export.mjs`: Git 제외 `outputs/pixelfx/root/root_purple.png/json`을 뽑는다.

```sh
node 전투테스트/속박/export.mjs --pixelfx <pixelfx>
```

## 시트 규격

- 104×80, 25fps, 26장(마지막은 빈 장). 피벗 (52, 70) = 몬스터 발 가운데(바닥). 좌우 대칭이라 반전하지 않아도 된다. PPU32 게임 화소 1:1.
- 가시뿌리(발 폭 약 57px) 기준으로 말뚝을 ±26px에 세웠다. 큰 몬스터는 크기를 키워야 한다.
- 보라 팔레트는 임시값이다. 둔화(무거운 발목)는 아직 만들지 않았다.

## 확인한 범위

1스테이지 실제 게임 캡처의 가시뿌리 발밑에서 렌더링으로만 봤다. 시안 셋(빛 덩굴·빛 말뚝·조여드는 고리)에서 말뚝을 고르고, 위에서 내리꽂기 → 땅에서 솟기로 바꾼 뒤 솟는 방식 여섯 가지를 비교해 바깥→안 차례를 골랐다. 넘침과 떨림은 「또잉 하는 푸딩 느낌」이라 뺐다. Unity·다른 몬스터는 확인하지 않았다.
