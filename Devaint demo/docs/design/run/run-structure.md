# 런·챕터·성장 구조

[분야 개요](README.md)

[사용자 확정 사항](../../overview/overview.md)에 따른 현행 기준이다. 과거 런 구조·성장·경제의 폐기된 수치를 승계하지 않는다. 장르는 **2D 액션 로그라이트**, 세계관은 **잉크 컨셉**이다.

## 런 규모

| 항목 | 확정 목표 |
| --- | --- |
| 전체 런 | 3챕터 |
| 전체 플레이 시간 | 45~60분 |
| 일반 전투 맵 | 챕터당 8개 |

시간은 플레이 시간 목표다. 챕터별 시간 배분·구간별 전투 시간·적 수·보스 배치·보상량 등 과거 문서의 다른 수치는 이번에 재확정하지 않았다.

## 공간과 진행

- 한 챕터 안에서는 방 없이 자유롭게 이동한다.
- 챕터 내부의 이동을 적 전멸 후 방 출구가 열리는 방식으로 제한하지 않는다. 챕터 내부의 이전 위치로 돌아가는 이동을 일괄 금지하지 않는다.
- 이전 챕터로 돌아갈 수 없다.
- 챕터와 챕터는 물리적으로 연결되어 있지 않다. 1챕터 보스 처치 후 보상 선택과 출구 철창 상호작용을 거쳐 페이드로 2챕터에 진입하며 같은 런의 장비·체력·가방·경제·성장 상태를 유지한다. 1챕터 출구는 처음 깨는 런이어도 늘 2챕터로 이어지고, 런은 사망하거나 지금 빌드의 마지막 챕터(2챕터)를 깼을 때만 끝나 마을로 돌아간다(사용자 결정 2026-11-13, 아래 [클리어 이후](run-structure.md#1챕터-플레이-빌드-기준)).
- 기존 1챕터 고정 시험 맵은 연결된 24공간 중 일반 전투 8구역에 각각 10마리 이상을 배치한다. 정비소·상점은 일반 적을 배치하지 않는 별도 공간이다.
- 1챕터 랜덤 스테이지는 [방·통로 공통 규격](../world/room-corridor-standard.md)의 블록 격자 전투방 원형 12종 중 8종을 매 판 중복 없이 뽑고, [스테이지 기믹](../world/stage-gimmicks.md)의 봉인 도전방 1곳과 잠긴 상자방 1곳을 함께 시드로 조립한다. 각 전투방에는 몬스터를 18마리, S1-05 원형에는 15마리 두어 한 판의 일반 몬스터가 최소 140마리가 되게 한다. 적을 모두 처치하지 않아도 통과하거나 되돌아갈 수 있다.
- 새 런은 맨손으로 시작한다. 두 장착 칸과 입력은 [무기 구성](../equipment/weapons/rules.md)을 따른다.
- 1챕터는 **왼쪽 시작방에서 오른쪽 끝 보스방으로 가는 가로 진행**이다(사용자 결정 2026-11-05). 주 경로의 방은 앞 방의 오른쪽 출입구에 직결로 붙고, 높이 차는 방을 블록 단위로 위아래로 엇갈려 놓아 방 안 지형으로 처리한다. **정비소는 주 경로에 1곳만** 두며 **시작방 뒤 전투방 3개 또는 4개를 지난 자리**(시드로 선택)다. 어떤 갈래도 정비소를 건너뛰지 않는다(사용자 결정 2026-11-03). 위·아래 우회 갈래 각 1개는 전투방 1개를 거쳐 주 경로 방 하나를 건너뛰고 다시 합류하며 보스방에는 합류하지 않는다. **봉인 도전방은 정비소 뒤 주 경로 자리 1곳**(우회 갈래가 건너뛰는 자리 제외)이고, **잠긴 상자방은 정비소에서 또는 그 뒤에서 갈라지는 우회 갈래**다(사용자 결정 2026-11-05). 그래서 주 경로 전투방은 6개, 우회 갈래 전투방은 1개다. 엘리트 갈래는 주 경로 5~8번째 방에서 위나 아래로 전투방 1개와 엘리트방을 잇는 막다른 갈래다. 최종 보스방은 주 경로의 마지막이다. 지도에는 방문한 공간과 그에 인접한 통로만 공개한다. 랜덤 스테이지의 8개 전투 공간과 기믹 방 2개는 기존 고정 시험 맵의 8구역과 별개이며, 나머지 챕터의 규모를 새로 확정하지 않는다.
- 전투방 12종(쌍공터·뿌리 협곡·긴 나무다리·세 단 언덕·낮은 뿌리 터널·순환 마당·계단 탑·넓은 분지·ㄷ자 회랑·ㄹ자 회랑·두물길 둑·三자 누각)은 3×2 블록(안쪽 42×20칸)과 2×3 블록(안쪽 26×32칸)이다. 시작방은 2×2, 1챕터 정비소는 3×2(안쪽 38×20, 사용자 요청 2026-11-06), 2챕터 정비소는 3×1(안쪽 42×8, 정비공 오른편 진열 벽감 자리, 사용자 요청 2026-11-14), 엘리트방은 1·2챕터 모두 2×2(안쪽 26×20, 사용자 요청 2026-11-06), 보스방은 안쪽 30칸 폭이다. 원형별 지형·발판·몬스터는 `data/map/block_rooms.json`이 소유한다.
- 1챕터 시작방은 모든 시드가 같은 배치를 쓴다(사용자 결정 2026-11-13). 플레이어는 바닥에서 8칸 위 발판에서 시작하고, 튜토리얼 팻말도 같은 발판 위에 선다. 바닥에는 먹빗자루 4마리를 두며, 추격 점프 높이(6칸)로는 시작 발판에 오르지 못한다. 네 마리의 보상 게이지는 합계 16이다. 첫 보상 필요량을 15로 바꾸는 규칙은 아직 정하지 않았고 현재 필요량은 [런 보상](rewards.md)을 따른다. 출구는 오른쪽 하나다.
- 흙 지형과 나무 발판 사이에는 최소 1칸 간격을 두거나 벽에 붙인다. 나무 발판은 하향 통과가 가능하고 아래 전투층 또는 지면에 안전하게 착지한다. 여러 층을 구성하는 방의 하층은 몬스터가 배치된 실제 전투면이다.
- 방 사이 연결은 직결(문 사이 6칸, 사용자 요청 2026-11-06으로 4칸에서 늘림)을 기본으로 하고, 한 블록이 비면 통로 블록 하나(수평 16칸, 굴곡, T자)를 쓴다. 상하 연결은 각 층에 하향 통과 발판을 두어 아래+Space 한 번에 한 층씩 내려가며, 오를 때는 2단 점프로 닿는 간격(4칸+3칸)이다. **벽타기 통로**(벽 한 면 8칸)는 1챕터에서 갈래에만 0~1개 둔다(사용자 결정 2026-11-05).
- 랜덤 스테이지는 맵 전체를 흙으로 채운 뒤 방과 통로 블록이 자기 셀만 판다. 쓰지 않는 출입구는 파지 않으므로 테두리 실벽으로 닫히고 그 출입구 전용 발판도 두지 않는다. 연결 그래프에 없는 우회는 생기지 않는다. 보이는 지면 위에는 낙사 판정을 두지 않으며, 낙사 복귀는 실제 월드 바깥으로 이탈했을 때만 적용한다.
- 전투 공간에서 적을 모두 잡기로 한 플레이어는 진입 지점에서 다음 길목까지 순방향으로 한 번 이동하며 모든 적을 만날 수 있어야 한다. 층을 나눌 때는 전투면과 층 전환 구간을 순서대로 연결하고 이미 지나온 전투면으로 되돌아가야 하는 적 배치를 피한다. 몬스터의 비전투 순찰도 해당 교전 구간을 벗어나 이미 지난 구간에 남지 않도록 제한한다. 적을 무시하고 지나가는 경로도 유지한다.
- 1챕터는 위 랜덤 스테이지 방식을 1차로 채택한다. 이후 고정 제작 맵 등으로 바뀔 수 있으며, 랜덤 스테이지의 전투방 8개·기믹 방 2개와 챕터당 일반 전투 맵 8개 목표의 관계는 미정이다. 어느 방식이든 위 자유 이동·챕터 경계 규칙을 따른다. 기술 경계는 [목표 아키텍처의 맵 공급 설계](../../development/architecture/gameplay-architecture.md#고정-맵과-절차-생성-맵의-공통-경계)를 따른다.

## 1챕터 플레이 빌드 기준

현재 빌드의 진입·스토리 구현과 새 장비 설계의 목표를 구분한다. 마을은 통합 공방·이정표와 맨손 출발로 연결되었고, 스케치 무기·런 도감·무기별 잉크 부여는 별도 이행 대상이다. 2·3챕터와 최종 제품의 전체 런 규칙을 확정하지 않는다.

| 항목 | 기준 |
| --- | --- |
| 진입 | 타이틀 → [시작 마을](../world/village/starting-village.md) → 해금·이야기 확인 → 이정표에서 맨손 출발 → 1챕터. 타이틀의 「시작하기」는 마을로 가며 마을 출발은 이정표 F로 시작한다. |
| 초반 이야기 | 새 프로필은 [플레이형 오프닝](../story/opening/opening-playable.md)(이동 튜토리얼, 지워짐, 조력자, 마을 기능)을 거쳐 첫 출발을 한다. 현재 첫 런에서는 [첫 런 수첩](../story/tutorials/first-run-guide.md#첫-런-수첩)과 첫 런 잉크 안내가 이어진다. 무기·잉크 튜토리얼은 새 도면·도감·무기 잉크 적용 규칙으로 재설계한다. |
| 런 시작 장비 | 마을에서는 도면 선택 없이 맨손으로 출발하며 시작방의 도면 제안·선택 잠금도 표시하지 않는다. 현재 런에서는 A로 [맨손 전용 2타 기본 공격](../equipment/weapons/rules.md#맨손-기본-공격)을 사용하며 별도 특수 공격은 없다. 승인 초기 규격의 최종 밸런스는 플레이 테스트 대상이다. 마을 없이 Editor에서 1챕터 씬을 직접 열어도 시작방에 도면을 띄우지 않고 맨손으로 시작한다. |
| 목표 장비 성장 | 무기별 팔레트 확정과 도감 잉크 반복 사용. [장비 기획](../equipment/rules.md) |
| 현재 개발용 팔레트 | 개발용으로 시작 무기 둘을 쥐여 주는 경로(디버그 도구)에서는 그 무기의 팔레트(기본 3칸, 칸 색 랜덤)를 함께 장착한다. 팔레트 칸 수·무색 칸의 영구 해금은 제거한다. 마을에서는 맨손으로 출발하고, 출발 추가 보상 해금이 있으면 일반 처치 보상과 별개로 무기 3택1 보상을 한 번 받는다. 획득 무기는 가방에서 확정·장착한다. 팔레트는 드롭·구매·재제작하지 않는다. |
| 맵 | 랜덤 스테이지. 정비소는 중단 주 경로의 1곳(시작방 뒤 전투방 3~4개)이고 엘리트 공간을 유지한다. 정비소 뒤 주 경로에 봉인 도전방, 정비소 뒤 우회 갈래에 잠긴 상자방을 둔다. 고정 시험 맵의 상점·정비소 자리는 모두 정비소로 사용한다. |
| 몬스터 | 마을 일반 3종, 엘리트 우물 도르래 수문장, 보스 시계탑 집행자. [몬스터](../enemies/chapter1/monsters.md)를 따른다. |
| 클리어 | 최종 보스방에서 보스를 처치한 뒤 출구와 상호작용하면 1챕터를 클리어한다. 보스 처치 전에는 출구를 사용할 수 없다. |
| 클리어 이후 | 보스 출구는 철창 열림 연출과 페이드 후 현재 장비·런 성장 상태·인벤토리·체력·골드를 유지해 **다음 챕터로 바로 이어진다**. 처음 깬 챕터든 이미 깬 챕터든 같다. 런은 사망하거나 마지막 챕터를 깨야 끝나 결과 화면 뒤 마을로 돌아간다. 지금 빌드는 3챕터가 없어 2챕터를 깨면 마을로 돌아간다(사용자 결정 2026-11-13, 2026-11-04의 「처음 깬 챕터는 마을로」를 대신함). 각 챕터의 보스를 **처음** 처치하면 [마을 팔레트 조각](../progression/village-palette-pieces.md)을 하나 기록하고(챕터마다 하나, 총 5개 = 5챕터) 마을에 돌아왔을 때 조각 수만큼 마을 색이 돌아오며 마을 장인이 통합 공방에서 새로 열린 기능을 소개한다. 1챕터 보스는 언제나 보스 골드·스탬프와 잉크 제단을 준다. 2챕터는 런이 끝나는 챕터라 제단과 보스 골드·스탬프가 없다. |
| 장비 구성 | 무기·잉크를 무제한 보관하고 가방에서 무기를 확정한 뒤 장착한다. |
| 보상 획득 | 일반 누적 처치 보상과 보스 무기 선택을 별도로 제공한다. [보상과 상점](rewards.md) |
| 사망 | 체력 0 → 기존 붉은 피격 테두리·HUD 반응을 유지하면서 0.28초 카메라 충격 → 기존 죽는 모션 완료 → 0.1초 여운 → 화면 전체가 실제 시간 1.8초 동안 서서히 검어짐 → 완전 암전 0.25초 → 기존 사망 결과 화면 → 「마을로」. 1·2챕터에 공통 적용하며 사망 모션은 기존 시뮬레이션 시계와 사망 슬로우를 따른다. 암전·카메라 충격은 피드백 실제 시간을 따르고 일시정지 중에는 진행하지 않는다. 새로운 화면 정지·줌·캐릭터 밀림은 추가하지 않는다. 결과 화면 전까지 월드는 계속 진행하며 결과 전환 때 기존 방식으로 정지한다. 다음 런은 마을에서 다시 출발한다. |
| 결과 화면 | 현재 데모의 2챕터는 보스를 처치하고 출구 열림이 끝나 런 정산이 완료되면 기존 클리어 결과 대신 데모 완료 창을 표시한다. 「데모 클리어」「플레이해 주셔서 감사합니다.」「정식 출시도 기대해 주세요!」와 플레이 시간·처치 수·마법안료를 보여 준다. 공격·보상·포탈 안내와 같은 어두운 픽셀 창과 Galmuri11을 사용한다. 「마을로」는 기존 마을 귀환, 「타이틀로」는 실제 타이틀 씬으로 이동한다. 버튼 클릭·키보드·패드 포커스 선택을 지원하며 출구에 사용한 입력으로 즉시 넘어가지 않도록 0.35초 유예한다. 다시 여는 버튼은 두지 않고 클리어 때마다 표시한다. 1챕터 및 사망 결과는 기존대로 유지한다. 클리어·사망 여부, 플레이 시간, 처치 수, 탐험한 구역 수, 사망이면 보스 남은 체력, 이번 런의 마법안료와 마을 팔레트 조각 수를 표시한다(플레이 테스트 2026-11-04). 2챕터 클리어도 사망처럼 화면이 검게 덮인 뒤 결과가 나타난다. 출구가 열린 순간부터 플레이어는 움직이지 않고, 사망과 같은 1.8초 암전과 0.25초 검은 화면 뒤 결과가 뜬다. 카메라 충격과 죽는 모션은 없다. 결과 화면에는 일시정지 메뉴의 내구도 표시 설정 버튼을 띄우지 않는다(QA 2026-11-13). |

보스의 패턴·수치, 출구의 위치·연출, 결과 화면과 준비 중 화면의 배치는 미정이다. 현재 구현은 출구를 보스 처치 전에는 숨기고, 처치 후 전용 출구 아치(열림 8장 뒤 `exit-open`, 승인 대기)로 보여 준다. 그 위에 상호작용 키 F 키캡이 1초 주기·4픽셀로 위아래로 움직인다(사용자 요청 2026-10-31). 정비소 기능과 보상 수치는 [성장·경제](progression-and-economy.md)를 따른다.

## 수동 체크포인트(포탈)

- 포탈은 Editor·개발 빌드뿐 아니라 일반(Player) 빌드에서도 쓰는 정식 기능이다. **C**로 현재 발 위치에 포탈1을, **V**로 포탈2를 설치한다. 이미 있는 포탈의 키를 다시 누르면 그 포탈을 지금 자리로 옮긴다. 두 포탈이 모두 서 있으면 한쪽 포탈 안(포탈 중심에서 좌우 1unit)에서 **F**를 눌러 반대쪽 포탈로 건너가고, 몇 번이든 오갈 수 있다(사용자 결정 2026-11-07, 이전에는 C 설치·V 귀환 한 방향). 서 있는 포탈 위에는 F 키캡이 뜬다. 같은 칸의 상자·정비소·출구가 F를 먼저 받는다. 런에서는 1챕터 정비소 장인의 짧은 포탈 소개 뒤, 설치·재설치·왕복과 지도 번호를 설명하는 수첩을 닫으면 C·V와 포탈의 F가 켜진다(`portal-taught` 기록). 그 전에는 눌러도 아무 일도 없다. 이 잠금 전에 장인을 만난 기록은 다음 런부터 켜진다. 런이 없는 시험 씬(훈련장·보스 시험)은 잠그지 않는다. 설치 2초(사용자 결정 2026-11-08: 1초는 주인공 모션과 포탈 그림이 너무 빨랐다. 2026-11-06~07에는 1초, 그 전 하루는 2초, 원래는 5.12초. 설치 중 대시로 취소할 수 있다), 들어가기 0.64초, 나오기 0.8초다(나오기는 점프 그림 16장이 보이게 2026-11-08 원래 0.8초로 되돌렸다). 포탈이 하나뿐일 때 F는 건너가지 않는다. 두 포탈은 가로 2.5unit 안에 함께 세울 수 없다. 땅·일방향 발판 위에서 대기·걷기 중에만 포탈 키를 사용할 수 있다. 주변 적의 감지·전투 여부는 제한하지 않는다. 점프·벽타기·공격·대시·피격 이동잠금·기절 중 요청은 거절하며 이후로 예약하지 않는다.
- 포탈은 C·V 하나씩, 둘까지 유지한다. 미니맵과 전체 지도는 포탈마다 번호 1/2와 서로 다른 색을 쓰며, 지형 위에는 미니맵 22×22px, 전체 지도 시안 기준 50×50px(960 무대에서 25×25)의 번호 아이콘만 표시하고 「1번 포탈」「2번 포탈」 이름은 오른쪽 범례에 둔다. 옮겨 세우는 모션이 완료되면 지도에서 해당 번호의 위치만 갱신하고 그 포탈만 새 자리로 바꾸고 옛 자리는 녹아 사라지는 그림을 한 번 보여 준다. 완료 전에 피격되면 기존 포탈은 유지한다. 몸 전체가 지지되는 바닥과 도착 신체 공간을 설치·건너가기 확정 시 검사한다. 건너갈 때는 먼저 들어가는 포탈 자리로 발을 맞춘 뒤 들어간다. 도착 위치가 막히거나 바닥이 사라지면 현재 위치에서 취소한다.
- 설치·진입·출현 중 이동·공격·다른 상호작용을 잠근다. 설치·진입 중 실제 피격되면 취소하고 피해·경직은 정상 적용한다. 설치 중 대시(사용자 요청 2026-11-06)나 점프(사용자 요청 2026-11-16)를 누르면 설치를 취소하고 그 대시·점프가 그대로 나간다. 취소된 재설치는 기존 위치를 유지한다. 진입·출현 중 대시·점프는 취소하지 않는다. 반대쪽 포탈로 이동을 확정한 시점부터 출현 완료까지 무적이다. 모션 완료 후 조작을 돌려준다.
- 건너가기는 지형·방 경계를 지나 반대쪽 포탈로 이동하며 체력·장비·무기 쿨타임·적 상태를 초기화하지 않는다. 포탈은 유지하며 비용·사용 횟수·쿨타임 제한은 없다. 사망·개발용 전투 상태 초기화·새 런·새 맵에서는 삭제한다. 자동 부활 지점으로 사용하지 않는다.
- 원본 클립 길이(그리기 5.12초·걷기 진입 1.28초·출현 및 착지 0.80초)를 현재 동작 시간(설치 2초·진입 0.64초·출현 0.8초)에 맞춰 재생하며 `data/combat/manual_checkpoint.json`을 편집한다. 그리기 46장과 맨손 걷기·점프, 별도의 포탈 생성·소멸 효과를 조합한다. 두 포탈은 건너간 뒤에도 그대로 있고, 소멸 그림은 포탈을 옮겨 세울 때 옛 자리에만 쓴다. 캐릭터 그림을 늘이거나 줄이지 않으며 참고 영상의 위치 이동은 실제 이동·충돌에 적용하지 않는다. 전투 시계를 사용하므로 일시정지 중 진행하지 않는다.

## 성장과 경제

장비 보상의 기준은 [무기·잉크](../equipment/rules.md), 재고·경제는 [성장·경제](progression-and-economy.md)를 따른다. 챕터 귀환과 마을 채색 보상은 장비 보상과 구분한다. 보스 잉크 제단·색상 보정·스탬프 보상을 새 선택 보상에 자동 적용하지 않는다.

### 잉크 충전소 — 회복 밸런스 시험값

- 현재 1·2챕터마다 잉크 충전소 **1곳을 보장**한다. 주 경로 일반 전투방 목록의 중반~후반(목록의 약 1/3~80%)에서 방과 위치를 런 시드로 무작위 선택한다. 해당 구간에 안전한 자리가 없으면 다른 주 경로 전투방을 확인한다. 시작방·정비소·상자방·봉인방·엘리트·보스방에는 두지 않는다.
- 단단하고 평평한 바닥, 좌우 지지면과 머리 위 공간을 실제 지형으로 검사한다. 출입구에서 떨어뜨리고, 낭떠러지·일방향 발판·벽 속에는 배치하지 않는다.
- **챕터당 최대 2회, 한 번에 현재 최대 체력의 25%**를 회복한다. 가격은 **첫 번째 100G, 두 번째 150G(합계 250G)**다. 기본 최대 체력 100이면 25씩, 챕터당 합계 최대 50이다. 최대 체력 강화도 비례 반영하며 소수 체력을 유지한다. 체력이 가득 차 있으면 횟수·골드를 소모하지 않고, 초과 회복분은 버린다. 회복량 0·사망·골드 부족 시에는 사용할 수 없다.
- 충전소 외곽에서 1.8유닛 안의 지상에서 상호작용 키(기본 F)를 **전투 시간 1초 동안 계속 눌러야** 회복한다. 기존 F 상호작용 키캡의 테두리가 위쪽 중앙부터 시계 방향으로 차오르며 키를 떼거나 멀어짐·피격(보호막 흡수 포함)·공격·대시·포탈·일시정지·입력 차단이면 취소한다. 여러 번 짧게 누른 시간은 누적하지 않는다. 완료 순간에만 골드와 횟수를 한 번 차감하고 회복한다. 계속 누르고 있어도 두 번째 회복은 시작되지 않으며 다시 눌러야 한다. 공격·대시·포탈 동작·피격 이동잠금·기절 중에는 시작할 수 없다. 사용 간격은 **전투 시간 1초**다. 자동 사용·무적·적 시간 정지는 없으며 전투 중에는 계속 피격될 수 있다.
- 재방문·포탈 이동·지도 열기·화면 숨김은 충전 횟수나 가격을 초기화하지 않는다. 다음 챕터는 첫 가격과 별도의 2회를 받는다. 새 런·새 씬과 치트 모드의 개발용 전투 상태 초기화만 새 횟수·가격을 만든다(사용한 골드를 환불하지 않는다). 허수아비 훈련에는 설치하지 않는다.
- 가까이 가면 구조물 위에 구조물 상단에서 약 2px 떨어진 위치에 압축한 세 줄로 표시한다: `F 길게`(재지정한 상호작용 키 반영), 동전 아이콘과 현재 가격 숫자, `N회 남음 · 최대 체력 25% 회복`. 전체 안내 배경은 없으며 F는 기존 상호작용 키캡 이미지를 22×24px로 작게 표시한다. 현재 가격 숫자는 같은 픽셀 폰트의 획을 1px 보강해 굵게 표시한다. 글씨는 기존 UI의 갈무리11, 12px로 통일하고 1챕터는 검정, 2챕터는 흰색이다. 누르는 동안 키캡 테두리만 차오르고 놓거나 취소되면 즉시 초기화한다. 각 줄은 구조물의 같은 중심축에 맞추며 키캡·길게 문구와 동전·가격은 실제 내용 너비로 가운데 정렬하고 줄 사이에 6px 여백을 둔다. 두 번째 가격은 150이다. 골드 부족·체력 가득 참·소진은 추가 상태 줄로 안내한다. 실제 회복량은 충전소 안내에서 분리해 캐릭터 머리 위에 `+25 HP`처럼 표시한다. 캐릭터를 따라 살짝 위로 떠오르며 전투 시간 1초 안에 사라지고, 최대 체력에 막혔으면 실제 회복량만 표시한다. 멀어지거나 일시정지·상호작용 입력 차단 중에는 안내를 숨긴다. 발견한 방의 충전소는 미니맵·전체 지도에 초록 십자로 표시하고, 소진하면 지도 표시를 끄고 구조물을 어둡게 표시한다. 실제 체력이 회복된 완료 순간에만 기존 초록 몸 회복 연출과 화면 외곽빛을 재생한다. 외곽빛은 게임 화면 영역에 맞는 UI로 표시하며 전투 시간 0.15초 동안 켜지고 0.75초 동안 사라진다. 키를 놓거나 취소됐을 때는 재생하지 않는다.
- 이 수치는 생존 여유를 더하기 위한 **1차 플레이 시험값**이다. 방 섬멸·상자·잉크 회복을 유지한 채 기본 체력 기준 챕터당 추가 피격 약 5~6회(일반 적 8~10 피해)의 여유를 준다. 실제 난이도 적합성은 플레이로 조정한다. 수치 원본은 `data/combat/stage_recovery.json`이다.

1챕터는 새 지형과 같은 2×2 도트 픽셀 주유기형 구조물(둥근 등 간판·하트 계량창·주유건과 호스, 96×112px)이고, 2챕터는 중앙 탱크와 굵은 U자 배관 구조물을 사용한다. 중앙 하트창은 검은 잉크를 담는다. 1챕터 그림은 PPU32·점 필터·무압축으로 원본 도트를 그대로 표시하고 선은 1점 굵기다. 높이는 각각 3.5·3.3유닛이며 안전 바닥 검사는 각 구조물의 전체 폭(3.0·3.8유닛)과 높이를 반영한다. 2챕터 고해상도 원본은 무압축·Trilinear·밉맵으로 축소 표시한다.

### 전투방 섬멸 회복

일반 전투방과 엘리트방의 배치된 적을 모두 섬멸하면 플레이어 체력을 10, 보스방의 적을 모두 섬멸하면 30 회복한다. 회복은 최대 체력을 넘지 않고 사망한 플레이어를 부활시키지 않는다. 각 방은 한 번만 지급하며 빈 방·재방문에는 지급하지 않는다. 적이 다른 방으로 이동해도 최초 배치된 방의 섬멸 판정에 포함한다. 허수아비 훈련장에는 적용하지 않는다. 개발용 전투 리셋·새 맵에서는 섬멸 기록을 초기화한다. 수치 원본은 `data/combat/chapter1_economy.json`의 `roomClearHealth`다. 실제로 체력이 회복되면 회복 파츠와 같은 초록 회복 이펙트(`heal_green`)를 플레이어 몸에 띄우고, 화면 외곽선에 초록 테두리가 0.15초 동안 켜진 뒤 0.75초 동안 사라진다. 최대 체력이라 회복량이 없으면 연출하지 않는다. 연출은 전투 시계를 따라 일시정지 중 진행하지 않는다.

### 전투방 클리어 장비 보상과 성장

[스테이지 처치 보상](rewards.md)은 필수 경로와 선택방의 처치를 합산한다. 방 클리어 회복·골드·마법안료 지급은 별도다.

런 잉크는 획득마다 기본 10회가 더해지고 무기 슬롯마다 1회를 예약·확정 소비한다. 같은 런에서 재획득할 수 있다. 적용한 효과 구성은 무기에 고정되며 누적 가한 피해로 내구도를 소모한다. 공급량과 내구도는 스테이지 전체 몬스터 수·필요 피해량을 함께 보고 정한다. 새 성장 구현과 검증은 미완료다.

## 사망과 귀환

체력 0에 따른 런 종료·결과 화면·새 런의 전투 규칙은 [공통 전투 명세](../combat/rules.md)를 따른다. 반복 사망 후 귀환의 서사, 세계 시간, 맵 재구성·적과 보스 재등장의 관계는 재기획한다.

초반 조력자의 희생과 주인공의 첫 잉크 몸 각성은 [초반 이야기](../story/opening/opening.md)로 유지한다. 이 첫 각성이 이후 반복 귀환 방식까지 확정하지는 않는다.
