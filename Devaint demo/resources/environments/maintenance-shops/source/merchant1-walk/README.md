# 1스테이지 정비소 상인 — 채택 걷기 전달본

사용자가 채택한 최종본은 pixel-clean-v4입니다. 다른 시안과 섞지 말고 이 폴더의 frames/walk-01.png~walk-20.png를 사용하세요.

- 20장, 원본 시트 28~47번 순서, 루프 24fps (한 주기 약 0.833초)
- 셀 128×144px, RGBA 투명 배경, 0/255 알파
- 공통 피벗: 좌상단 기준 (64,136), Unity 좌하단 정규화 (0.5,0.05555556)
- 시트 merchant1-walk-20f.png: 1280×288px, 10열×2행, 각 셀128×144px, 왼쪽→오른쪽/위→아래
- Point / 압축 없음 / Mipmap 끔. 현 프로젝트 기준 PPU32 참고.
- 캐릭터 높이 약120px. 프레임마다 잘라서 크기·발 위치를 개별 보정하면 현재 동작이 달라집니다.
- 승인 대기 NPC 이미지의 실제 RGB만 사용. 별도 공식 팔레트 문서는 확인되지 않았습니다.
- 눈은 승인 대기 이미지의 노란색. 흰 외곽 잔여물, 앞치마 뒤쪽 띠, 1~3프레임 왼쪽 밝은 선 보정 완료.
- 기존 대기 NPC/상점 에셋은 덮어쓰지 않았습니다. 이 걷기는 아직 Unity 적용·Git 등록·커밋하지 않은 로컬 전달본입니다.

preview/index.html을 브라우저에서 열면 수정 전후를 확인할 수 있습니다. 실제 적용에는 frames/ 또는 스프라이트 시트를 쓰세요. preview의 이미지는 검토용입니다.
animation.json에 프레임 SHA256, 순서, 피벗, 원본 위치와 가져오기 참고값을 기록했습니다.
