# 덜 위협적인 폭발음 후보

2026-11-16 사용자 피드백에 따라 다시 고른 후보다. 피드백 내용은 다음과 같다.

- 실제 폭탄 녹음은 3D 실사 게임처럼 위협적이고 리얼하다.
- 이 게임은 2D 픽셀 횡스크롤이다.
- 원하는 것은 소리를 끊거나 빠르게 재생하는 것이 아니다. 덜 위협적인 느낌이다.

그래서 이번에는 가공으로 바꾸지 않고 원음 계열 자체를 바꿨다. 사용자가 고를 때까지 게임에는 적용하지 않는다.

## 원음 계열

| 계열 | 원음 | 느낌 |
|---|---|---|
| 연기 펑 | `Magic_Spells/vanish_spell_flash_potion_*` | 만화 폭탄이 연기를 내며 퐁 하고 사라지는 마법 효과음 |
| 둥근 마법 펑 | `Magic_Spells/energy_blast_small_*`, `energy_blast_large_*` | 파편 소리 없이 둥글게 퍼지는 에너지 폭발 |
| 픽셀 폭발 | `Retro_Classic/Explosion/retro_explosion_*` | 고전 8비트 게임의 노이즈 폭발 |
| 반짝 팝 | `Magic_Spells/magic_pop_open_*` | 반짝이며 터지는 가장 귀여운 소리. 반짝임 꼬리가 길다. |

실제 폭탄 녹음(`explosion_*`)과 신스 SF 폭발(`sci-fi_explosion_*`)은 여전히 무겁고 리얼해서 제외했다.

## 처리

첫 후보 모음(`explosion-candidates`)과 같은 규칙을 따른다.

- 원래 속도로 쓰고 꼬리를 자르지 않는다.
- 30 Hz 아래 들리지 않는 울림만 걷어낸다.
- 녹음이 스스로 -54 dB까지 줄어든 지점에서 끝낸다.
- 크기는 그 자리의 지금 소리와 같게 맞췄다(K-가중 400 ms 최대값).
- 유탄은 지금과 같은 3연쇄로 만들었다. 시각은 0, 0.13, 0.27초이고 배율은 0.7, 0.55, 0.85다.

예외로, `retro_explosion_general_09`와 `retro_explosion_short_02`는 녹음 파일 자체가 소리가 다 줄어들기 전에 끝난다. 이 두 개만 녹음 끝 80 ms를 페이드했다.

| 자리 | 후보 |
|---|---|
| 기본 폭발 | 1 연기 펑 · 2 둥근 마법 펑 · 3 픽셀 폭발 · 4 픽셀 폭발(긴 꼬리) · 5 반짝 팝 |
| 큰 폭발 | 1 큰 마법 펑 · 2 둥근 마법 펑(큰) · 3 픽셀 큰 폭발 · 4 픽셀 깊은 폭발 · 5 긴 연기 펑 |
| 유탄 3연쇄 | 1 연기 펑 · 2 마법 펑 · 3 픽셀 펑 · 4 픽셀 짧은 펑 · 5 반짝 팝 |

## 비교 화면과 재생성

비교 화면 `preview/index.html`의 기능은 이전 화면과 같다. 지금 소리와 A/B, 3개 겹침, 실제 공격·스킬 소리 뒤에 붙여 듣기, 음량 조절, 별표, 메모, 선택 파일 저장을 할 수 있다.

원음 해시와 수치는 `source/recipes.json`에 있다. 메인 루트에서 `python -X utf8 resources/tools/build_explosion_stylized.py`로 다시 만든다.
