## 현재 운영 기준

### 차기 리밸런싱 범위

2026-09-10~11 사용자 합의로 장기 목표를 챕터 1~10, 총 100스테이지로 확장한다. `progression-rebalance-v1`의 절대 수치·구현 범위는 1~4장·1~79레벨이며, 아래 목록과 제외 항목은 기존 배포 버전 범위다. 차기 설계 승인만으로 구현 완료를 의미하지 않는다.

장비·성장벽·보상 정본은 [리밸런싱 진입점](../progression-rebalance/README.md)에서 연결한다. 5~10장·80레벨 이후, 전설·신화 장비, 4-10 신규 보상과 레이드 보상은 후속 범위다. 보석·치장 규칙은 해당 도메인 SSOT를 유지하고 이번 리밸런싱에서 치장 밸런스를 변경하지 않는다. 차기 레이드는 5-1 도달에 해금하고 추가 콘텐츠는 7-1 도달에 해금하는 일정만 유지한다. 실행 범위와 상태는 [A-05](../../wiki/06-delivery/tasks/A-release-scope/a-05-progression-rebalance.md)를 따른다.



현재 배포 작업의 기준은 A-01의 완료 기준과 A-02~A-04의 인수 흐름이다.

- 챕터 1–4
- 총 40스테이지
- 단일 브라우저 탭의 펫 UI·관리 UI와 선택적 Picture-in-Picture 표시
- 한짝 1종
- 자동 이동·조우·전투·보스·실패 복귀
- 경험치·레벨·쌀·기본 성장
- 6부위 장비와 감자·고구마·옥수수 주력 재료 선택
- 액티브 4슬롯, 스킬 6종과 스킬별·등급별 스킬북 성장
- 1-5에서 해금되는 메인 스테이지와 보스별 6슬롯 프리셋 4개, 1~7레벨 3:1 합성과 1시간 슬롯 보석 보스 던전
- 서버 실제 경과시간 1시간마다 충전되는 입장권, 최대 5장과 보스별 독립 1~10단계 진행
- 1-5 최초 클리어로 해금되는 전설 세트별 상시 치장 픽업, 공용 뽑기권·쌀 결제, 치장 도감·1~5성 성장과 세트 효과
- 메인 전투 화면의 자동 진행·스테이지 반복, 체류 획득 요약, 성장 알림, 우편·거래소·보석 던전 진입
- 네 챕터의 잠금·최초 클리어 진행률·완료·현재 전투·진행 목표를 확인하고 해금 챕터의 스테이지 목록으로 이동하는 챕터 화면
- 스테이지 목록의 클리어·현재·잠금·반복 상태, 주요 보상·`피해 N%`·최근 실패 확인, 해금 스테이지 입장과 1~9 반복 설정을 제공하는 스테이지 화면
- 거래 가능한 자원의 등록·구매·취소·정산 흐름
- 계정 생성부터 4-10 클리어와 거래까지 재현 가능한 인수 시나리오

- 공개 종합전투력·전문별 랭킹 화면과 조회 API를 추가한다. 랭킹은 감자·고구마·옥수수 전문별 TOP과 내 전문 순위를 제공하며, 시즌·보상·실시간 스트리밍·Kafka 집계는 포함하지 않는다.

세부 포함·제외 기능은 [A-02](../../wiki/06-delivery/tasks/A-release-scope/a-02-define-mvp-inclusions-exclusions.md), 인수 기준은 [A-04](../../wiki/06-delivery/tasks/A-release-scope/a-04-define-release-acceptance-scenario.md)가 소유한다.

## MVP에서 하지 않는 일

- 챕터 5 이후 실제 스테이지와 전설 스킬북 최초 배치
- 궁극기
- 계정·거래 권한을 로컬 파일만으로 확정
- 시장 병목을 Kafka 도입만으로 해결
- UI가 도메인 규칙을 직접 소유
- 보석 던전 정식 v2의 검증된 절대 보스 수치와 별개로 남은 장기 공급 분포·보석 포함 메인 적 수치를 검증 없이 임의 상수로 구현
