QUICK GUIDE

길을 만들고, 직접 고쳐보세요.

1. 전체 동선

방을 선택하고 드래그하면 16×12u 블록 단위로 이동합니다. 방을 두 번 누르거나 ‘방 내부 편집’을 누르세요.

2. 발판 편집

발판을 드래그해 이동하고 모서리의 손잡이로 크기를 조절합니다. ‘발판’이나 ‘고체’를 선택하고 빈 공간에 드래그하면 추가합니다.

3. 연결과 시설

전체 동선에서 ‘연결’ 도구로 방 두 개를 누릅니다. 오른쪽에서 출입구 방향·슬롯을 고칩니다. 시설은 종류를 고른 뒤 방 안을 누르세요.

4. 저장과 테스트

수정 내용은 브라우저에 자동 저장됩니다. JSON으로 따로 보관하고 불러올 수 있습니다. ‘이동 테스트’는 발판을 걷고 점프하는 간이 확인용입니다.
