기본 잉크가 화면에 보여야 하는 효과를 효과 종류별로 묶었다. 사용자가 고른 후보는 테두리로 표시하고 맨 아래 목록에 ✓확정으로 남긴다(중독은 게임에서 빼기로 해 제외, 강화 타격 표시는 넣지 않음). 각 카드는 발동 → 유지 → 종료를 명세의 시작 수치(지속시간·강화 수치)대로 반복한다. 1배 32px = 1u, 게임 캐릭터·몬스터 대기 동작과 같은 척도로 그렸다. 카드를 눌러 효과별로 고르면 맨 아래에 선택 목록이 모인다. 방어막은 피격 소모·감소를 짧게 줄여 보여 준다.
