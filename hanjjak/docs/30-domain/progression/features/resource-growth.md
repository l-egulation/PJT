# 쌀·기본 성장 소비

이 문서는 기능을 찾기 위한 경로 문서다. 정책, 수치, 상태, 완료 여부를 정의하지 않는다.

- 규칙·수치·상태의 정본: [성장 SSOT](../ssot.md)
- 실행 상태·완료 기준·증거: [B-09 작업 문서](../../../wiki/06-delivery/tasks/B-account-storage/b-09-battle-progression-reward-loop.md)

아이템·장비·거래 자산의 세부 정의는 이 문서에 복사하지 않고 각 도메인 SSOT를 참조한다. 필요한 결정은 [결정 로그](../../../80-decisions/README.md)에 남긴다.
