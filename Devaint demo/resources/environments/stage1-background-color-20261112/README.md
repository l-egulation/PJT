# 1스테이지 마을·튜토리얼 · 색 있는 판

사용자가 준 컬러 디자인 5종(구름·새·가까운 마을·먼 마을·산, `source/inputs/` 원본 그대로)을 스케치 배경 레이어와 같은 크기·도트 격자에 맞춘 판이다. 바깥 윤곽은 스케치와 같고 안쪽 구성은 사용자 디자인을 따른다(사용자 선택).

- 가까운 마을 666×334(2×2 도트), 먼 마을 444×222, 산 888×444. 그림마다 자기 색 몇 가지로 정리했다.
- 구름 6장: 3×2 묶음을 칸마다 잘라 스케치 구름과 같은 자리·폭으로 맞췄다.
- 새 6무리 × 날갯짓 3장(위·수평·아래, 0-1-2-1 순서): 원본 새는 게임 크기에서 사라질 만큼 작아, 스케치 새 무리 자리에 사용자 새 색 #6A7E89로 그렸다.
- 하늘색 #BCD6E6(출발 마을 하늘과 같은 계열).

`source/color5.py`가 다시 뽑고, `preview/`에 하늘 두 가지 비교·움직임 GIF·스케치 대비가 있다.

## 마을·튜토리얼 적용 (2026-11-12)

전투가 아니라 마을·튜토리얼 길에서 쓴다(사용자 결정). 마을은 조각마다 색 있는 그림과 색 빠진 그림을 짝으로 그리고 오프닝에서 색을 지운다. 색 빠진 쪽은 전투 스테이지와 같은 그림(잔디 타일 stage1-pixel-lawn-wood-32, 크림 배경 stage1-background-cream-20261112)이고, 색 있는 쪽이 이 세트다.

- 산·먼 마을·가까운 마을: 원본 디자인의 지붕·나무 가장자리에 남아 있던 흰 테두리 점을 지웠다(스케치가 비쳐 보였다). 가장자리 점은 투명, 안쪽 점은 이웃 색(`color5.drop_halo`).
- 산·먼 마을·가까운 마을을 2×2 도트로 다시 그렸다(픽셀 규칙 영상 기준, 사용자 디자인의 구성을 따라). 집은 3/4 시점(빛 받는 앞면과 그늘진 박공 면), 지붕 사선은 모두 1:1, 창문은 2×3 한 쌍, 종탑은 같은 기둥 둘과 1:1 박공·십자가. 나무·덤불은 둥근 원을 합친 덩어리에 왼쪽 위 밝은 테두리 3점·오른쪽 아래 그늘 2점. 사이프러스 끝은 1:2. 산은 두 능선을 다듬고 경사마다 계단 길이가 가장 가파른 곳까지 줄었다가 다시 늘게 맞췄다. `source/near_redraw.py`·`far_redraw.py`·`mountain_redraw.py`(공통 `village_px.py`), 묶어 뽑기 `make_bands_clean.py`.
- `runtime/sketch/`: 같은 그림을 크림색으로 바꾼 색 빠진 판. 색마다 같은 밝기의 크림 회색(r, r-5, r-16, 크림 세트와 같은 범위)이라 두 판이 점 하나까지 겹친다. 마을의 색 빠진 배경은 이것을 쓴다(크림 세트 원본은 그대로 둔다).
- `runtime/village/ground/`: 바닥 타일 47모양×4종의 컬러판. 2챕터처럼 속을 비운다. 드러난 면을 따라 흙 테두리(잔디 아래 그늘, 겉흙, 잔뿌리, 왼쪽 밝은 면·오른쪽과 아랫면 그늘)만 두고 안쪽은 짙은 흙빛(#583E30). 칸 안에서 끝나 이음매가 이어진다. 나무 발판 5조각, 데이지, 박힌 돌 3종(어둡게).
- `runtime/village/background/{color,sketch}/`: 먼 마을·산(정리본·그 크림판)을 맨 아래 줄 그대로 3유닛(96px) 더 내린 판. 전투에서는 띠의 맨 아래 줄을 바닥까지 늘이는데 마을은 일반 그림이라 그 연장을 그림에 넣었다(가까운 마을 틈 사이로 하늘이 비치지 않게).
- `runtime/village/sky/`: 하늘(#BCD6E6, 색 빠진 쪽 #FCF7EE), 구름 띠 1600×170(구름 6장 배치, 색 빠진 쪽은 크림 구름 같은 자리), 새 날갯짓 3칸 96×32(색 빠진 쪽은 크림 새 색).
- `source/make_village_colour.py`가 `tilecolour.py`·`tiledetail.py`(속 비우기 `hollow`)로 다시 뽑는다. `preview/village-ground-options.png`는 음영 판 대 속 비우기 판, `preview/bands-mirror-seams.png`는 좌우반전 이음매, `preview/unity-*.png`는 Unity 캡처(마을, 튜토리얼 길, 전투).

## 전투 스테이지 (2026-11-12)

전투는 색 빠진 세계라 `runtime/sketch/`의 배경 세 장을 쓴다(마을의 색 빠진 판과 같은 그림). 띠는 좌우반전으로 이어지므로 양 끝 이음매 구역에는 대칭 건물 반쪽만 두고, 맨 아래는 덤불 줄과 그늘색 세 줄로 끝나 전투가 맨 아래 줄을 바닥까지 늘여도 잘린 선이 생기지 않는다. 구름과 새는 색 빠진 세계에서 움직이지 않는다.
