# 무리 전투와 무기 스펙 테스트

[분야 개요](README.md)

기존 공통 씬과 최신 들판 씬 `Assets/MeadowDuskV3/Scenes/Chapter1MeadowCombat.unity`에 연결하는 테스트 도구다. 정식 챕터 적 배치와 출시 밸런스를 확정하지 않는다. 현재 일반 테스트 적을 사용하며 6종 AI 구현 완료를 뜻하지 않는다.

실행 이미지는 Unity를 닫고 [고정 리소스 배치](../../assets/README.md)로 준비한다. 코드·씬·설정·`.meta`는 메인 Git의 것을 유지한다. Unity **6000.6.5f1**을 사용한다.

```powershell
python tools/assets/update_assets.py --check
python tools/assets/update_assets.py
```

이미지 배치는 에디터 시작이나 무리 모드 활성화를 하지 않는다. 기존 Editor의 전투 시험 도구로 명시적으로 모드를 켠다. 무리 배치는 지면 직사각형이 몸 전체를 지지하는 위치에만 생성하므로 실제 마릿수를 확인한다. 이미지 누락이나 지정 에디터 미설치 상태를 실행 완료로 취급하지 않는다.

승인 이미지 동기화가 완료되면 망치·방패·대검도 선택할 수 있다. 이미지가 누락된 임시 환경에서는 해당 장비를 선택 보류로 표시하며 다른 무기 이미지로 대체하지 않는다. 이 선택 보류 처리는 독립 아트 검증의 통과를 뜻하지 않는다.

기본 배치는 일반 적5마리씩4무리, 무리 중심 간32칸이다. 무리 내부 기본 간격은3.2칸이고 첫 중심은 플레이어 시작점 앞18칸이다. 보스 더미를 제외한다. 편집 원본은 `data/combat/playtest_environment.json`이고 `python tools/combat/export_unity_catalog.py`로 Unity 리소스를 생성한다.

Play 후 **F1 또는 테스트 설정 버튼**을 누르면 전투와 시간이 멈춘다. 왼쪽에서 무리당 마릿수·무리 수·중심 간격을 바꾸고 다시 배치한다. 현재 시작 지형의 스트리밍 범위 안에서1~8마리,1~4무리,20~40칸을 지원하며 무리 사이 빈 간격12칸 이상을 유지한다. 지면이 없는 후보 지점은 생성하지 않으므로 실제 배치 수를 화면에서 확인한다.

오른쪽에서 슬롯1/2, 무기, 특수공격을 고른다. 해당 슬롯의 다음 값을 입력한 후 **스펙 적용**을 누른다.

| 값 | 의미 |
|---|---|
| 기본 공격력 배율 | 원본 기본 피해와 강화 잉크 적용값에 곱함. 예:10피해 무기에2를 입력하면 강화 없음 기준20피해 |
| 특수 공격력 배율 | 특수의 모든 피해 구성에 곱함 |
| 추가 기본 공격속도 배율 | 무기별 시험 공속에 추가로 곱함.1은 시험 기본값,2는 시험 기본 모션 시간의 절반 |
| 특수 쿨타임 초 | -1은 원본과 강화 쿨감 사용.0 이상은 테스트용 최종 재충전 간격 지정. 내부 최소 간격은0.001초 |

기본 피해·특수 피해 배율은0~1000, 추가 공속 배율은0.05~20, 지정 쿨타임은0~3600초를 받는다. 이 범위는 도구의 입력 안전 범위이며 밸런스 승인 범위가 아니다. 특수 공격속도·사거리·피격 박스는 원본을 유지한다. 슬롯별 입력값은 무기/특수 변경과 F5 리셋에 유지되며 Play를 종료하면 초기화된다. 슬롯 입력값은 원본 데이터나 팀원의 설정에 저장하지 않는다.

무기별 기본공격 시험 공속은 배치 원본의 `basicSpeedTrials`에 둔다. 테스트 설정창이 연결된 환경 또는 `ForestCombatWorld.enablePlaytestBasicSpeeds`를 켠 씬에서 적용하며, 무기를 바꾸면 해당 형태의 시험 공속으로 전환된다. 현재 본 게임 1챕터 `Chapter1Procedural.unity`는 공속 옵션을 켜고, 2챕터는 `Chapter2World` 초기화에서 같은 설정을 적용한다. 따라서 1·2챕터 모두 근접 무기별 공속과 마지막 타 추가 후딜을 동일하게 사용하며, 맵 몬스터 배치와 장비 UI는 기존 구성을 따른다. 슬롯의 추가 배율과 공속 잉크는 별도로 곱한다. **슬롯 배율·쿨타임 초기화**는 추가 배율을1로 되돌리며 무기별 시험 공속은 유지한다. 테스트 설정창에서는 무기별 시험 공속과 최종 공속을 표시한다.

| 무기 | 원본 대비 시험 공속 | 시험 연계 주기 | 이론 DPS | 1분 환산 피해 |
|---|---:|---:|---:|---:|
| 검 | 1 | 0.7초 | 약37.1429 | 약2228.57 |
| 대검 | 0.8 | 1.375초 | 약46.5455 | 약2792.73 |
| 망치 | 1 | 0.96초 | 46.875 | 2812.5 |
| 채찍 | 1.4 | 약0.85714초 | 약36.1667 | 2170 |

망치 1타는 시험 공속 1에서 선딜(판정 시작) 0.21초, 판정 지속 0.1초, 판정 종료 후 회복 0.06초로 전체 0.37초다. 수치 원본 `melee_weapon_design.json`의 1타 impact=0.21·duration=0.37을 사용하며, 2타는 선딜0.29초·판정0.1초·후딜0.2초로 전체0.59초다.

대검은 시험 공속0.8에서 1타 선딜0.2초·판정0.125초·후딜0.0625초(전체0.3875초), 2타 선딜0.125초·판정0.125초·후딜0.1125초(전체0.3625초), 3타 선딜0.3초·판정0.125초·후딜0.2초(전체0.625초)다. 시간 원본은 `melee_weapon_design.json`이며 대검의 원본 시간에 시험 공속0.8을 나누어 적용한다. 망치·대검의 `lastHitExtraRecoverySeconds`는0으로 추가 회복을 붙이지 않는다. 마지막 타 후딜도 원본 동작의 일부이므로 추가 공속 배율과 잉크에 따라 함께 단축된다.

이 표는 강화 잉크·슬롯 추가 배율 없이 단일 대상 전타 적중 시 `연계 피해 ÷ (원본 연계 모션 합 ÷ 시험 공속 + 마지막 타 추가 후딜) × 60`으로 환산한다. 정확히60초 내 실제 적중 수를 세는 실측과 구분한다. 기본 피해는 승인된 원본 값(검 13/13, 대검 16/18/30, 망치 17/28, 채찍 14/17)을 사용하며, 이 설정창에서 바꾼 슬롯 배율은 해당 원본이나 특수 모션에 기록하지 않는다. 다른 형태의 시험 공속은1이며 추가 후딜은0이다. Play 재진입 시 슬롯 입력은 초기화되고 이 시험 기본값을 다시 적용한다.

설정을 닫으면 전투가 재개된다. HUD 일시정지 등 다른 주체의 정지가 남아 있으면 도구를 닫아도 그 정지는 유지한다. 입력 중 공격·이동 키가 게임으로 전달되지 않는다. A/S 무기 1/2 기본공격, Q/W 무기 1/2 스킬, F5 리셋을 사용한다.
