# 마을 잉크

[분야 개요](README.md)

## 범위와 상태

사용자 결정(2026-11-02, 2026-11-07 UI·명칭 갱신). 시작 마을의 색과 영구 해금을 **챕터를 하나씩 처음 깰 때마다 단계적으로** 되찾는 규칙이다. 한 챕터를 처음 깨면 마을로 돌아와 다시 1챕터부터 도는 반복 구조(사용자가 예로 든 「세피리아」 방식)를 따른다. 기획 확정 상태이며 Unity에는 조각 수·작업대 열림·이름표·장인 방문·마을 색 얼룩·챕터별 런 끝내기까지 적용했다(아래 「구현 상태」). 대사·연출은 로컬 HTML 시험판(저장소 밖 `04_테스트/오프닝 테스트`)에서 검토했고, 아래 내용이 그 기준이다.

영구 해금의 항목·가격은 [로그라이트 영구 성장](roguelite-progression.md), 마을 시설·배치는 [시작 마을](../world/village/starting-village.md), 1챕터 클리어 뒤의 런 흐름은 [런 구조](../run/run-structure.md#1챕터-플레이-빌드-기준), 마을 장인의 인물 설정은 [정비소 첫 만남](../story/tutorials/maintenance-introductions.md)을 따른다.

## 잉크와 런 흐름

- **챕터마다 조각 하나**(사용자 결정 2026-11-04): 어떤 챕터의 보스를 **처음** 처치하고 출구로 나가면 **마을 잉크** 하나를 얻는다. 런은 그 출구에서 끝나지 않고 다음 챕터로 이어지며, 마을의 채색은 런이 끝나 돌아왔을 때 보여 준다(2026-11-13). 1챕터 첫 클리어가 첫 조각, 2챕터 첫 클리어가 두 번째 조각, … 5챕터 첫 클리어가 다섯 번째 조각이다. 조각은 모두 **5개**이고 영구 프로필에 「가장 멀리 깬 챕터」로 기록한다. 이미 깬 챕터를 다시 깨도 조각은 없다. 지금 기획은 3챕터까지지만 5챕터까지 늘릴 것을 전제로 한다.
- **런은 늘 1챕터부터**: 보스 출구는 처음 깬 챕터든 이미 깬 챕터든 같은 런 상태(장비·런 성장 상태·인벤토리·체력·골드)를 유지한 채 **다음 챕터로** 이어진다. 런은 사망하거나 마지막 챕터를 깨야 끝나 마을 우물 앞으로 돌아간다. 지금 빌드의 마지막 챕터는 2챕터다(사용자 결정 2026-11-13, 2026-11-04의 「처음 깬 챕터는 런을 끝낸다」를 대신함).
- 다섯 번째 잉크(5챕터 첫 클리어 보상)를 우물에서 사용하면 마을 색이 모두 돌아온다. 획득 화면 확인 뒤 마지막 장인 장면이 이어진다. 마지막으로 만든 챕터를 다시 깨면 이어질 챕터가 없으므로 런 클리어로 끝난다(지금 빌드는 2챕터가 마지막이라 2챕터 클리어는 늘 마을로 돌아간다).
- 사망은 지금처럼 정산 후 마을로 돌아가며 조각을 주지 않는다.
- 각 챕터의 난이도는 조각 수와 관계없이 같다(사용자 결정 2026-11-03).

## 잉크마다 열리는 것

영구 해금은 장인의 공방 한 화면에서 다룬다. 개편한 묶음 해금·공용 리롤·능력치·생존·경제 지원은 [영구 성장](roguelite-progression.md)을 따른다. 팔레트 칸 수·무색 칸·구형 가방·개별 잉크 해금은 제거한다. 기능별 열림 기준과 항목·가격·선행·챕터 조건은 [`roguelite_progression.json`](../../../data/combat/roguelite_progression.json)의 현재 `unlocks`와 `buildings`를 그대로 따른다([새 구조 이행 범위](roguelite-progression.md#구현-범위와-이행)). 공방 작업대는 처음부터 확인할 수 있고, 아직 사용할 수 없는 기능은 화면 안에서 잠겨 있다.

| 조각 | 새로 열리는 것 |
|---|---|
| 0 | 우물·기록 농가·장인의 공방·이정표. 공방의 보급 기능은 첫 런 정산 뒤 열린다 |
| 1 | 통합 공방의 팔레트 작업 기능 |
| 2 | 통합 공방의 회수 기능 |
| 3 | 새 시설 없이 잉크 획득과 마을 색 복원 연출 |
| 4 | 팔레트 5칸 항목 |
| 5 | 마을 색 전부 회복, 장인이 통합 공방에 상주 |

## 마을 색

- 처음 방문한 마을은 전부 스케치다. 첫 잉크는 장인 설명 중 사용하고, 이후 잉크는 귀환 뒤 우물 F로 사용하면 우물에서부터 색이 번진다. 잉크 1은 우물 둘레와 마을 곳곳에 군데군데, 2~4는 점점 많고 넓게, 5는 마을 전체다.
- 번지는 영역은 월드 좌표에 고정한 얼룩 모양이다. 가장자리는 네모 디더 대신 종이 결 잡음을 섞은 부드러운 번짐(40px)이며, 잡음·칸도 월드 좌표에 붙여 카메라가 움직여도 얼룩 모양이 바뀌지 않는다(사용자 2026-11-02 「움직일 때마다 바뀐다」). 새로 얻은 조각의 얼룩만 약 2.4초 동안 번지고, 이미 얻은 조각의 영역은 처음부터 칠해져 있다.
- 색은 프로필의 사용 완료 기록 `village-ink-return-k`로 계산한다. 보유량만 늘어서는 색이 추가되지 않는다. 기존 저장의 완료된 장인 방문은 사용 완료로 호환하며, 기록 초기화는 마을을 다시 전부 스케치로 되돌린다.
- 해금 구매·보스 첫 클리어·출발은 건물을 칠하지 않는다. 색은 조각으로만 돌아온다([마을 채색과 해금](../world/village/starting-village.md#마을-채색과-해금), 사용자 결정 2026-11-04).
- 통합 공방 건물과 작업대는 첫 잉크의 얼룩 안에 배치한다. 후속 잉크는 기존 얼룩을 더해 마을의 색을 넓히며 별도 회수공방 건물을 새로 칠하지 않는다.

## 마을 장인의 방문

1챕터 정비소에서 만난 **마을 장인**(채택 1상인, `merchant_village`)이 첫 잉크 귀환에서 사용법을 설명한다. 후속 시설 방문은 우물 F 사용과 획득 확인 뒤에 이어진다. 장인의 마을 가게는 통합 공방이며 회차마다 장면이 다르다.

공통 규칙:
- 결과 화면 뒤 잉크 로딩(「마을로」)이 끝나 밝아지면 우물 앞이다. 컷씬은 위아래 검은 띠로 조작을 잠근다. 첫 붉은 잉크는 장인이 먼저 용도와 우물의 물길을 설명한다. 주인공은 우물을 바라보고 작은 병이 그 앞에서 기울어 잉크를 수직으로 흘려보낸다. 장인의 공방 소개·작별까지 끝난 뒤 닫힌 큰 병과 개수·다섯 방울의 획득 화면이 페이드인된다. F로 확인하면 첫 회차만 집행자의 마을 파괴 삽화와 공통 설명을 담은 작은 수첩이 이어진다. 설치나 끼우기 조작은 없다.
- 작업대로 갈 때는 **순간이동하지 않고** 장인·주인공이 걸어간다(초속 4.6, 보통 컷씬 걷기 3.2보다 조금 빠르게. 장인 걷기 그림도 그만큼 빨리 돈다). 카메라는 앞질러 가서 기다리지 않고 걷는 주인공을 따라가다가, 둘 다 도착하면 작업대를 가운데에 둔다.
- 카메라 따라가기 빠르기는 평소 8, 컷씬·초점이 있을 때 2.5이며 그 사이를 약 1초에 걸쳐 바꾼다. 초점이 바뀔 때 목표 자리도 한 번 더 부드럽게 옮겨, 대화 시작·끝과 검은 띠가 씌워질 때 화면이 확 움직이지 않게 한다.
- 작업대가 열릴 때: 자물쇠가 떨리며 금이 가고(0.28초) → 깨져 조각이 흩어지고 조건 글씨가 사라지며 반짝임 → 이름이 흐린 색에서 검정으로 진해지며 살짝 커졌다 돌아온다(0.38~0.85초). 그다음 설명한다.
- 말풍선 규격과 글자 소리는 정비소 구현(`MaintenanceBubbleView`, 상인별 합성 글자 효과음)과 같고 화자 이름표는 「마을 장인」이다. 장인은 서 있을 때 정비소와 같은 호흡 모션, 걸을 때 채택한 걷기 20장(24fps 기준)을 쓴다. 발은 바닥 바로 위에 둔다.
- 컷씬이 끝난 직후 0.3초는 F를 받지 않는다(대사를 넘긴 F로 옆 작업대 판이 열리지 않게).
- Esc를 길게 누르면 장면을 건너뛰고 그 조각까지의 열림·색 상태만 반영한다.

| 회차 | 열림 | 장면 |
|---|---|---|
| 1 | 통합 공방의 팔레트 기능 | 오른쪽에서 걸어와 붉은 잉크를 알아보고 우물 사용법을 설명 → 잉크 연출과 색 복원 → 함께 통합 공방으로 걸어가 자물쇠가 깨짐 → 설명 → 몸 전체가 화면 밖으로 걸어 나간 뒤 획득 UI와 수첩 안내 |
| 2 | 통합 공방의 회수 기능 | 같은 작업대에서 회수 기능이 추가되었음을 안내한 뒤 떠난다. 별도 건물 수리나 이동 과제는 없다 |
| 4 | 팔레트 5칸 | 우물 F 사용과 색 복원 → 획득 화면 확인 → 장인이 네 번째 잉크를 반긴다 → 함께 통합 공방으로 걸어가 반짝임 → 설명 → 공방을 한번 돌아보고 떠난다 |
| 5 | 색 전부 | 우물 F 사용으로 마을 전체에 색 → 획득 화면 확인 → 장인이 우물 앞에서 하늘을 올려다보며 첫마디 → 남은 대사 → 통합 공방으로 걸어가 반짝이고 그 자리에 남는다 |

### 대사

첫 붉은 잉크는 보스방에서 F로 즉시 줍는다. 줍기의 물음표·대사·조작 정지는 없다(2026-11-08 변경). 전체 구성과 대사는 [첫 붉은 마을 잉크](../story/village/first-red-village-ink.md), 실제 마을 대본은 `data/story/village_visits.json`을 따른다.

| 회차 | 대사 |
|---|---|
| 1 | 「어! 너 주머니에… 그거!」 「붉은 잉크잖아!」 「너… 시계탑 집행자를 쓰러뜨렸구나!」 → 우물의 물길과 잉크 사용 → 색 복원과 감사 → 공방 소개 → 「모아 둔 안료가 있으면 한번 써봐. 다음 여행에 도움이 될 거야.」 「난 다시 정비소로 가 봐야겠네.」 「조심해서 다녀와. 또 보자!」 |
| 2 | 「두 번째 잉크도 되찾았네.」 → 「공방에 회수 작업도 준비해 뒀어.」 → 내구도가 소진된 무기의 골드 회수 안내 → 필요한 준비는 같은 작업대에서 선택 |
| 4 | 「네 번째 잉크까지 돌아왔네. 마을의 색도 한결 선명해졌어.」 / 「공방에서 해금할 수 있는 준비도 다시 살펴봐.」 / 「마지막 하나만 더. 기다릴게!」 |
| 5 | 「…다 모았구나.」 → 「마을이 원래 색을 되찾았어.」 「이제 나도 밖에서만 장사할 필요는 없겠네.」 「앞으로는 여기 공방에 있을게. 필요하면 찾아와.」 「고마워. 정말 수고 많았어.」 |

효과 대사는 잉크 묶음 연구와 무기 파괴 회수를 안내한다. 실제 선택 가능한 항목과 가격은 공방 화면의 현재 카탈로그를 따른다.

## 작업대 이름표

- 상호작용 대상은 기록 농가·우물·장인의 공방·출발 이정표 네 곳이다. 기존 종이 이름표 화풍과 F 키캡을 사용한다. 공방 전체는 열려 있고 각 기능의 잠금은 화면 안에 표시한다.
- 통합 공방은 처음부터 F로 확인할 수 있다. 기능별 잠금과 「N챕터 클리어 필요」 등 조건은 공방 화면의 항목에 표시하며, 별도 닫힌 시설 카드를 만들지 않는다.
- 가까이 가면 카드 위에 F 키캡을 띄운다.
- 캐릭터(주인공·장인·주민 등 NPC)는 언제나 이름표와 F 키캡보다 앞에 그리고, 말풍선은 이름표보다 위에 그린다(사용자 2026-11-03).
- 화면 글자에는 가운뎃점(·)을 쓰지 않고 쉼표·빗금·괄호·쌍점을 쓴다.

## 미정

- 다섯 번째 조각의 추가 기능.
- 세 번째 조각에 새로 열리는 것과 장인 방문 장면(회수공방이 2번째 조각으로 옮겨 비었다, 2026-11-05).
- (정함, 2026-11-04) 해금 구매는 건물을 칠하지 않는다. 마을 색은 조각으로만 돌아온다.
- 새 해금 트리에 맞춘 작업대 설명 대사, 2~5회차 대사 확정.

## 구현 상태

- **조각 수**: 프로필의 「가장 멀리 깬 챕터」 `chaptersCleared`를 `palettePieces`(5)에서 끊어 센다(`ProgressionService.PalettePieces`). 1챕터 보스 출구(`RecordChapterOneClear`)와 클리어 정산(`SettleRun(…, chapter)`, 1챕터 귀환은 1, 2챕터 클리어는 2)이 올린다. `chaptersCleared`가 없던(0으로 읽히는) 예전 프로필만 읽을 때 1챕터 클리어가 있으면 1, 런 클리어가 있으면 2로 옮긴다. 값이 있는 프로필은 그대로 쓴다(첫 1챕터 귀환도 런 클리어로 세므로, 다시 읽을 때 2챕터 조각이 생기면 안 된다). 1챕터 클리어 횟수 `chapter1Clears`는 기록 표시용으로만 남는다. 기록 초기화는 조각도 0으로 되돌린다.
- **작업대 열림**: 공방은 처음부터 목록을 확인할 수 있다. 보급은 첫 런 정산 뒤, 잉크 연구 작업대의 열림 연출·채색은 마을 잉크 1개부터다. 공방 항목은 작업대 열림과 별개로 첫 런 정산 뒤 [해금 트리](roguelite-progression.md#해금-트리)의 선행 조건으로 열리며 마을 잉크 개수를 요구하지 않는다. 개별 항목은 현재 `roguelite_progression.json`의 조건을 따른다. 제거된 팔레트 5칸의 조각 4개 조건과 구형 잉크 파괴 보상은 사용하지 않는다.
- **이름표**: 역 이름은 [`starting_hub.json`](../../../data/assets/starting_hub.json)의 `stations[].label`. `TemporaryGameGui.StationCards`가 작업대 그림 위 23px에 종이 카드를 그리고, F 키캡은 카드 위로 올렸다. 카드가 있는 동안 아래쪽 F 이름 안내는 띄우지 않는다(같은 이름이 겹친다). 오프닝 ①~③에서는 숨긴다. 1챕터로 처음 출발하기 전(프로필 `RunsStarted` 0, 오프닝 ④ 포함)에도 카드와 아래쪽 F 이름 안내를 모두 띄우지 않고 F 키캡만 남긴다(사용자 플레이 테스트 2026-11-03). 카드는 GUI 위층이 아니라 월드 공간 캔버스(월드 1유닛 = 32px, 마을 카메라와 같은 배율)에 있어 화면 크기와 관계없이 제 작업대 위에 붙는다. 정렬 순서는 `StartingVillageWorld.MarkerOrder`(-11)다. 작업대·건물·소품(-12 이하)보다 앞이고, 캐릭터(오프닝 주민 -10, 장인 9, 주인공 10)보다 뒤다. F 키캡도 같은 순서다(예전에는 20이라 주인공을 덮었다). 말풍선·책 화면의 어두운 막은 GUI 위층에 있어 카드보다 위다.
- **자물쇠 파괴**: 0.28초 떨림·금 → 0.3초에 깨져 조각이 흩어지고 조건 글씨가 사라짐 → 0.38~0.85초 이름이 진해지며 1.14배까지 커졌다 돌아옴 → 1.2초 동안 작업대 둘레에 노란 반짝임 18개(HTML 시험판 수치). 장인의 기능 소개 순간 같은 통합 공방 카드에 재생하고 프로필에 `station-opened-<역>`으로 기록한다(본 이야기 목록에 함께 저장되지만 기록 농가의 이야기 칸에는 보이지 않는다). 보급 기능은 첫 런 뒤 장인 안내에서 소개한다.
- **장인 방문**: 대본은 [`data/story/village_visits.json`](../../../data/story/village_visits.json)(파트 k = k번째 조각의 방문)이고 `tools/assets/build_hub_bindings.py`가 `Hub/Resources/HubVisits.json`으로 복사한다. 오프닝과 같은 비트 실행기·말풍선·배너로 돈다(`TemporaryGameGui.Visits`). 첫 붉은 잉크는 마을 도착 시 장인 방문을 재생한다. 2~5번째 잉크는 우물 F로 다음 미사용 잉크 하나를 붓고, 색 복원과 획득 화면 확인을 마친 뒤 해당 시설 방문을 재생한다. 여러 미사용 잉크도 순서대로 처리하며 완료 방문은 `artisan-visit-k`로 기록한다. 3번째는 시설 대사가 없다. `unlockStation`은 기존 기능의 안정 ID와 확인 기록을 유지하고, 같은 공방 카드에 해금 연출을 재생한다. 공방 전체를 닫지는 않는다. 첫 런 뒤 장인의 마법안료·보급소 안내를 아직 못 봤다면 첫 붉은 잉크 방문의 작별 전에 합친다. 첫 런이 사망으로 끝났다면 별도 방문으로 한 번 보여 준다([플레이형 오프닝 ⑤-1](../story/opening/opening-playable.md#⑤-1-첫-런-뒤-장인--마법안료와-보급소-한-번만)).
  - 장인(`StartingVillageWorld.Artisan`): 서 있을 때 정비소 채택 그림(`MaintenanceShops/npc1`)의 윗몸만 1.1초 주기로 숨 쉬고, 걸을 때 채택 걷기 20장(초속 4.6, 그림도 그만큼 빨리)을 쓴다. 짐 정리·망치질(박자마다 「쿵」, 멀수록 작고 가까우면 화면이 살짝 흔들림)·하늘 보기 자세가 있다. 다섯 번째 방문 뒤에는 마을에 올 때마다 통합 공방 앞(x 32.2)에 서 있다.
  - 함께 걷기(`pan`): 주인공은 작업대 1.9 왼쪽, 장인은 지정한 오른쪽 자리로 걸어가고 카메라는 주인공을 따라가다 둘 다 도착하면 작업대에 머문다. 걷는 동안만 조작 잠금을 풀어 둔다(전투 입력 차단이 걷기 입력까지 지우기 때문이며, 걷기 중에는 키를 받지 않는다).
  - 카메라: 방문 동안 가로 따라가기 세기가 12.5에서 3.5로 약 1초에 걸쳐 바뀌고(`ForestCombatWorld.CameraFollowOmega`), 초점(`FixedCameraCenter`)도 한 번 더 부드럽게 옮긴다.
  - 조작이 잠긴 동안 위아래 검은 띠(오프닝과 같은 [장면 띠](../story/opening/opening-playable.md#장면-띠)). 장인은 전체 스프라이트가 화면 밖으로 나갈 때까지 걸어서 떠난다. Esc를 길게 누르면 장면을 건너뛰고 그 방문의 끝 상태(열림, 2회차는 회수 기능이 열림, 5회차는 공방 앞)만 남긴다.
  - 마을 잉크: `VillageInkPourView`는 캐릭터 앞의 작은 월드 병으로 뚜껑 분리와 우물로 흐르는 잉크를 보여준다(5.2초, 2.6초에 색 번짐). `VillageInkRevealView`의 닫힌 병 획득 화면은 첫 색에서 장인 방문 뒤, 2~5색에서는 우물 사용 뒤 시설 방문 전에 F로 확인한다. 스킵은 색·해금·안내를 함께 정산하며 별도 팔레트를 설치하지 않는다.
- **마을 색 얼룩**: 얼룩 자리·반지름은 [`starting_hub.json`](../../../data/assets/starting_hub.json)의 `layoutProposal.colourBlots`(통합 공방·작업대를 덮는 조각 1 얼룩과 기존 마을 얼룩. 조각 1 열·2 열여섯·3 열일곱·4 스물하나·5 하나). `StartingVillageWorld.ColourBlots`가 마을의 모든 그림 조각(하늘·원경·건물·소품·작업대·땅) 위에 컬러 쌍둥이를 하나씩 두고, 조각이 스케치로 그려지는 동안 `Resources/VillageBlotColour.shader`가 얼룩 안쪽에서만 쌍둥이를 보인다. 마스크는 월드 4px 칸·고정 종이 결 잡음(32칸 반복)에 붙고, 가장자리는 40px에 걸쳐 흐려진다. 얼룩은 실제 사용 완료한 잉크 수만큼 보이고, 우물에 잉크가 닿으면 해당 얼룩을 2.4초 동안 번지게 한다(이전 조각은 처음부터 칠해져 있다). 지워짐·미리보기·오프닝의 전부 컬러/스케치 상태에서는 보이지 않는다. 땅 기둥은 줄끼리 겹쳐서 기둥마다 한 정렬 묶음으로 그린다(스케치 줄 다음에 컬러 줄).
- **런 끝내기**: `ProgressionService.ChapterClearEndsRun(chapter)`는 `chapter >= LastChapter`(지금 2)일 때만 참이다. 1챕터 보스 출구(`Chapter1BossEncounter`)는 늘 2챕터로 이어지고, 첫 1챕터 클리어는 2챕터로 넘어가는 순간 `RecordChapterOneClear`로 첫 조각을 저장한다. 2챕터는 보스를 깨면 결과 뒤 마을로 돌아가며 첫 클리어면 두 번째 조각을 준다. 마을에 돌아오면 우물 옆(x 18)에서 시작하고 첫 색은 장인 설명으로, 이후 색은 우물 F로 사용한다. 3챕터가 생기면 `LastChapter`를 올린다.
- **장인 말풍선**: 마을의 모든 화자와 같은 정비소 `MaintenanceBubbleView` 말풍선이다(굵은 Galmuri11, 184px 줄바꿈, 계단 픽셀 테두리, 이름표 「마을 장인」, [플레이형 오프닝의 말풍선 규격](../story/opening/opening-playable.md#말풍선-이야기)). 장인만 글자 소리가 있다(`TemporaryGameGui.ArtisanBubble`). 장인이 선 자리가 스케치면 어두운 바탕이고 컬러면 밝은 바탕이다. 초당 30자로 쓰이고, 글자 소리는 정비소 1상인과 같은 합성음(`MaintenanceRoomPresentation.SynthesizeVoice`, `MaintenanceDialogue.json`의 첫 음높이, 저역 1450Hz)이다. 두 글자마다 한 번 울리고 빈칸·문장부호는 건너뛰며, 최소 간격은 0.055초다.
- **에셋 연결**: 원본 보존 및 Unity 적용·미리보기 방법은 [마을 잉크 UI 연결](../../assets/world/village/village-ink-integration.md)을 따른다. 저장 필드와 기존 조건 ID의 `palette` 명칭은 호환을 위해 유지한다.

### 첫 붉은 잉크 발견

첫 1챕터 집행자 처치 뒤 붉은 병은 F로 즉시 챙기며 별도 줍기 연출 없이 움직일 수 있다. 마을에서는 장인이 천천히 등장해 멈추고 느낌표 뒤 빠르게 접근한다. 우물의 물길과 색을 짧게 설명하고 월드의 작은 병이 잉크를 흘려보낸다. 이후 통합 공방의 팔레트 기능 소개와 작별을 마치고 획득 UI가 나온다. 아직 못 본 첫 런 보급소 안내는 같은 방문에 합친다. 자세한 대사와 순서는 [첫 붉은 마을 잉크](../story/village/first-red-village-ink.md)를 따른다.

## 우물에서 잉크 사용

1챕터의 장인 설명은 자동으로 진행한다. 2챕터부터는 보스를 쓰러뜨리고 잉크를 F로 챙긴 뒤 우물에서 F를 누르면 다음 미사용 색 하나를 붓는다. 색 복원 → 마을 잉크 획득 화면 확인 순서이며, 미확인 화면은 재입장해도 이어진다. 미사용 잉크가 없으면 우물에는 F 키캡과 상호작용이 없다. 시설 개방 조건은 챕터 클리어를 유지하지만 회수 기능은 기존 잉크 2개 조건을 유지하고 통합 공방에서 소개한다. 별도 문 수리 장면은 없다.
