# Items Content

아이템·장비·드롭 콘텐츠의 모델 경로다. 아이템과 장비 규칙은 [Items Domain](../../30-domain/items/ssot.md)과 [Equipment Domain](../../30-domain/items/equipment/ssot.md)이 소유한다.

- 표시 콘텐츠: [MVP 아이템·장비 표시 콘텐츠 v1](./mvp-v1.md)
- 주력 재료 드롭 수치 초안: [MVP 주력 재료 드롭표 v1](./material-drops-mvp-v1.md)

재료 드롭표는 최초 구현·시뮬레이션용 `working` 데이터다. 검증을 통과한 버전만 `applied`로 승격한다. 표시명은 `mvp-v1.md`의 승인된 콘텐츠를 사용한다.
