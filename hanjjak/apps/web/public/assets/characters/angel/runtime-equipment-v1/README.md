# 천사 장비 런타임 아틀라스 v1

사용자 최종 TIFF 5개에서 6개 장비 슬롯을 독립 선택할 수 있게 내보낸 엔진 중립 패키지다.
각 셀은 928×672 고정 캔버스이며 자동 크롭·스케일·보간을 사용하지 않는다.

- 장비 슬롯: `cape`, `clothing`, `shoe`, `weapon`, `glove`, `hat`
- 무기 변형: 깃털검, 천사링 지팡이, 빛의 창
- 기술 레이어: `base-body`, `base-feet-front`, `base-arms`, `base-hands`
- 아틀라스: 4열(프레임) × 5행(모션), 3712×3360
- 모션 시트: 4열 × 1행, 3712×672

게임은 `angel-equipment-manifest.json`의 `drawOrderByFrame` 순서대로 기술 레이어와 선택된 슬롯을 그린다.
다른 세트도 같은 프레임 키와 슬롯 계약으로 내보내면 세트와 무관하게 부위별 혼용할 수 있다.
현재 run1은 보류 상태라 포함하지 않았고, 실제 엔진 로더 연결은 별도 구현이 필요하다.
