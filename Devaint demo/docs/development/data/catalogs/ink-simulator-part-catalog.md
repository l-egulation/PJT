# 색상 잉크 파츠 50종 설계 초안

[카탈로그 개요](README.md)

> 적용 범위: 현재 코드·생성기·시험 도구의 구현 자료이며 제품 성장 기획이 아니다. 새 기준은 [무기 도면·런 잉크 도감](../../../design/equipment/rules.md)이다. 아래 고정 파츠·등급·팔레트 수치를 새 잉크 레벨·보상에 승계하지 않는다.

색상별 10종의 후보 중 20종을 MVP 우선 콘텐츠로 채택했다. 개별 효과 수치·세부 제약은 검토 초안이며 제품 구현 완료를 뜻하지 않는다.

편집 원본: [ink_simulator_parts_proposal.json](../../../../data/combat/ink_simulator_parts_proposal.json). 현재 제품 기준은 [잉크 구성 규칙](../../../design/equipment/inks/rules.md#효과-부여와-공격-부여)를 따른다.

이 문서는 `node tools/ink-combination-lab/generate-simulator.cjs`로 생성한다. 직접 작성할 내용은 [잉크별 설계 작성지](../../../design/equipment/inks/combination-worksheet.md)를 사용한다.

## 공통 기준

- 파츠는 트리거 + 효과로 구성한다. 빨강=공격, 노랑=이동 속도, 초록=생명·보호막·회복, 파랑=범위·쿨타임, 보라=CC 부여.
- 초기 트리거는 몬스터 적중 시 / 스위칭 시 / 표식을 터트릴 시 / 몬스터 처치 시다.
- 제품 장착 기준: 무기에 팔레트를 먼저 장착하고 지정 색상 칸에만 잉크를 넣는다. 기본 효과는 장착 무기 자신에게만 적용하며, 다른 무기 강화는 개별 파츠에 명시한 예외다. 자유 50종 모드는 비교용으로 유지하며, 별도 MVP 정비소 모드의 20종에는 팔레트·색상·귀속·강화를 적용한다.
- 스위칭은 A의 관련 효과 모두 발동 → B로 전환 → B 자동 공격 순서다. 스위칭 파츠의 발동 원본은 A이며 적용 대상은 개별 설명을 따른다.
- MVP 표식은 원타격 적중당 1개를 쌓고 추가타는 부여하지 않는다. 최대 5개·8초 유지하며 무기 전환 후 적중하면 쌓인 표식을 전량 소비한다. 소비한 표식 수에 비례한 기본 격발 피해를 주고 각 격발 잉크 효과는 격발당 1회 발동한다. MVP 기본 격발 피해는 격발 무기의 기본 콤보 타격 피해 평균 × 소비 표식 수 × 0.15를 시험 기준으로 한다. 이 피해는 추가타로서 잉크의 적중·처치 트리거를 발동하고 새 표식은 부여하지 않는다. 원타격으로 표식을 추가할 때 해당 몬스터의 전체 표식 유지시간을 8초로 갱신한다. 격발 타격은 기존 표식을 먼저 격발한 뒤 새 무기의 표식 1개를 남긴다.
- 추가타도 적중·처치 트리거를 발동한다. 추가타·격발·처치의 연쇄 제한은 미정이다. 지속 피해는 없다. 지연 단발 공격은 시간이 지난 뒤 한 번 공격한다.
- 모든 숫자·퍼센트·시간·거리·누적 한도는 제안값이다. 내부 쿨타임·중복 유형·동일 효과 중첩·CC 저항과 보스 적용은 미정이다. 미정을 쿨타임 0 또는 무제한 발동으로 해석하지 않는다.
- 색상별 적중 3·스위칭 3·격발 2·처치 2종 배분은 이번 초안의 다양성을 위한 제안이며 필수 콘텐츠 배분 규칙이 아니다.
- 범위 피해 공격은 빨강, 사거리·반경을 늘리는 효과는 파랑으로 제안한다. 복합 효과의 최종 색상 판단은 검토가 필요하다.

## MVP 우선 채택 20종

색상별 4종이며 각 색상에서 적중·스위칭·격발·처치 1종씩 채택한다. 콘텐츠 종류와 트리거의 선정이며, 아래 수치·지속시간·제약은 검토 초안이다. 나머지 30종은 후속 후보로 보존한다.

| 색상 | 파츠 | 트리거 | 효과 초안 |
|---|---|---|---|
| 빨강 | 덧칠 | 몬스터 적중 시 | 원공격 피해의 20%인 추가타 1회를 가한다. |
| 빨강 | 건네는 진한 먹 | 스위칭 시 | A에서 효과를 부여해 B무기의 다음 공격 피해를 30% 높인다. 공격 시작 시 1회 소비한다. |
| 빨강 | 터지는 먹물 | 표식을 터트릴 시 | 격발 대상에게 발동 무기 기본 공격 기준 피해 60%인 추가타 1회를 가한다. |
| 빨강 | 진해진 먹 | 몬스터 처치 시 | 장착 무기의 다음 공격 피해를 25% 높인다. 공격 시작 시 소비하며 반복 처치는 수치를 더하지 않고 갱신한다. |
| 노랑 | 가벼운 발끝 | 몬스터 적중 시 | 이동 속도가 3초간 12% 증가한다. 재발동 시 지속시간만 갱신한다. |
| 노랑 | 바꿔 쥐고 내달리기 | 스위칭 시 | A에서 부여한 이동 속도 35% 증가를 B 전환 후 1.5초간 유지한다. |
| 노랑 | 터뜨리고 달리기 | 표식을 터트릴 시 | 표식 격발 후 이동 속도가 3초간 30% 증가한다. |
| 노랑 | 가벼워진 걸음 | 몬스터 처치 시 | 몬스터 처치 후 이동 속도가 4초간 22% 증가한다. 재처치 시 갱신한다. |
| 초록 | 빨아들이는 먹 | 몬스터 적중 시 | 해당 적중이 몬스터 체력에 실제로 준 피해의 5%만큼 체력을 회복한다. |
| 초록 | 덧댄 종이 한 장 | 스위칭 시 | A에서 보호막 12를 부여하며 B 전환 후 4초간 유지한다. 같은 파츠의 재발동은 갱신한다. |
| 초록 | 터진 자리의 생기 | 표식을 터트릴 시 | 표식 격발 시 체력을 8 회복한다. |
| 초록 | 한숨 돌리기 | 몬스터 처치 시 | 몬스터 처치 시 최대 체력의 5%를 회복한다. |
| 파랑 | 빨리 마르는 붓 | 몬스터 적중 시 | 현재 진행 중인 스킬 쿨타임을 0.3초 줄인다. 남은 시간 아래로만 줄이며 다음 사용에 저장하지 않는다. |
| 파랑 | 길게 건네는 획 | 스위칭 시 | A에서 효과를 부여해 B 다음 공격의 사거리를 40% 늘린다. 공격 시작 시 소비한다. |
| 파랑 | 크게 번지는 먹 | 표식을 터트릴 시 | 격발 후 4초간 장착 무기의 공격 반경이 35% 증가한다. 피해·직선 사거리는 바꾸지 않는다. |
| 파랑 | 말끔히 헹군 붓 | 몬스터 처치 시 | 진행 중인 스킬 쿨타임을 0.8초 줄인다. 남은 쿨타임을 초과해 저장하지 않는다. |
| 보라 | 끈적한 먹 | 몬스터 적중 시 | 이동 속도를 2초간 20% 낮춘다. |
| 보라 | 끌어당기는 획 | 스위칭 시 | A에서 주변 몬스터를 A의 전환 전 위치 쪽으로 최대 1unit 끌어당긴 후 B로 전환한다. |
| 보라 | 발을 붙이는 먹 | 표식을 터트릴 시 | 1초간 속박해 이동을 제한한다. |
| 보라 | 빨아들이는 얼룩 | 몬스터 처치 시 | 처치 지점 쪽으로 주변 몬스터를 최대 1unit 끌어당긴다. |

표식 부여·누적·소비, 내부 쿨타임·중첩·연쇄, CC 저항·보스 적용은 미정이다. MVP 정비소·드롭·Unity 연결 범위와 실행 검증은 개발 문서를 따른다.

## 빨강 — 공격 10종

### 덧칠 — `ink2_red_01`

색상: 빨강 · 트리거: **몬스터 적중 시**

**1. 운용 목표**

- 목표: 한 대의 적중을 후속 공격으로 연결한다.
- 활용 상황: 단일 몬스터를 계속 공격할 때
- 선택 이유: 한 대의 적중을 후속 공격으로 연결한다. 단일 몬스터를 계속 공격할 때에 선택할 후보다.
- 연계 의도: 추가타의 적중 트리거와 연결

**2. 발동 조건**

- 트리거: 몬스터 적중 시
- 발동 원본: 적중·처치·격발 이벤트의 무기. 파생 공격 귀속 세부 판정은 미정

**3. 보상 효과**

- 적용 대상: 적중한 몬스터
- 무기 귀속: 장착 무기 자신
- 효과 초안: 원공격 피해의 20%인 추가타 1회를 가한다.

**4. 대가·제약**

- 대가 초안: 별도 재화·체력 소모는 제안하지 않는다. 발동 준비와 아래 운용상 약점을 대가 후보로 둔다.
- 운용상 약점·제한: 추가타가 다시 추가타를 만드는 연쇄 한도는 미정이다.
- 내부 쿨타임·중복 유형: 미정

**추가로 정할 내용**

- 수치·지속시간·내부 쿨타임 확정
- 동일 파츠 중복과 동일 효과 중첩 판정

### 떠나며 긋기 — `ink2_red_05`

색상: 빨강 · 트리거: **스위칭 시**

**1. 운용 목표**

- 목표: 근접 압박을 남기면서 무기를 교대한다.

- 대가 초안: 별도 재화·체력 소모는 제안하지 않는다. 발동 준비와 아래 운용상 약점을 대가 후보로 둔다.
- 운용상 약점·제한: 이미 발사된 공격에는 소급 적용하지 않는다. 조준 행동의 상세 범위는 미정이다.
- 내부 쿨타임·중복 유형: 미정

**추가로 정할 내용**

- 수치·지속시간·내부 쿨타임 확정
- 동일 파츠 중복과 동일 효과 중첩 판정
- 제어 저항·보스 적용·반복 CC 제한

## 구현 범위

50종 파츠의 구조화 수치 `effect.params`를 [독립 브라우저 시뮬레이터](../../tools/ink-simulator.md)에 연결했다. 피해·회복·보호막·이동 속도·범위·쿨타임·CC와 4종 트리거를 간이 모델로 계산한다. `ink_simulator_proposal.json`의 표식·연쇄·중첩·CC 설정은 미정 규칙의 실험값이며 제품 규칙을 확정하지 않는다. 이 50종을 Unity 전투로 내보내지 않는다. 기존 Unity 잉크 데이터와 실행 코드는 변경하지 않는다.

표식 기본 피해 계수·처리 순서·연쇄 제한, 공통 효과 중첩, 스위칭 취소, CC 저항·보스 적용, 미지원 무기 범위 해석, 실제 수치는 제품 설계로는 미정이다. 브라우저 간이 무기·판정·AI는 Unity 전투·드롭·저장·경제를 재현하지 않는다. 엔진·브라우저 검사는 제품 밸런스·재미나 Unity 동작 검증을 대신하지 않는다.
