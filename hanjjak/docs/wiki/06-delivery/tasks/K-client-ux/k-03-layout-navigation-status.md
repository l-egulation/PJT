# K-03 공통 레이아웃·내비게이션·상단 정보 구현

> 작업 상태와 완료 증거의 SSOT. 도메인 규칙은 [클라이언트 UX](../../../../30-domain/player/ux/ssot.md)를 따른다.

## 완료 기준

투명 펫 창과 확장 관리 창을 이동할 수 있고 레벨·쌀·알림 등 공통 정보가 단일 상태 엔진 기준으로 일관되게 표시된다.

## 선행 작업

K-01, K-02

## 비고

공통 내비게이션에 마이페이지와 설정 진입점을 추가했고, 로그인 세션 기준으로 닉네임·이메일·계정 ID·캐릭터 ID·레벨·경험치·쌀을 조회 표시한다. 마이페이지는 현재 관리 화면 위에 뜨는 모달이며 중복된 캐릭터 요약 없이 계정 정보·캐릭터 상태·비밀번호 변경을 한 열로 제공하고 닉네임은 계정 정보 행에서 인라인 수정한다. 닉네임을 수정하면 서버 상태와 인증 세션 캐시가 갱신되어 재로그인 후에도 유지된다. 현재 관리 화면을 탭 세션에 보존해 전투 기록·거래소·아이템·장비·스킬·보석·던전·랭킹에서 브라우저를 새로고침해도 같은 화면으로 복귀한다. 마이페이지·설정 모달과 일시적인 치장 뽑기 화면은 복원 대상으로 저장하지 않는다. 투명 펫 창 이동, 확장 관리 창 이동, 알림 표시는 아직 남아 있다.

2026-09-08 상단 내비게이션에 `컨텐츠` 버튼과 확장 목록을 추가했다. 던전 항목은 보석 던전 전용 경로로 이동하고, 레이드는 준비 중 잠금 상태로 표시한다. 보석 탭은 보석함·보유 보석·메인 프리셋 관리만 남겨 플레이 콘텐츠 진입 책임과 분리했다. 투명 펫 창 이동, 확장 관리 창 이동, 공통 알림 표시는 아직 남아 있다.
