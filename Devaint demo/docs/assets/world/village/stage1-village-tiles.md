# 1Stage 마을 타일·발판

[분야 개요](README.md)

컬러·스케치 바닥과 발판의 기존 47개 이미지는 [공통 리소스 배치](../../README.md) 계약으로 준비한다. 별도의 다운로드·ZIP 복원 경로는 사용하지 않는다.

원본은 `resources/environments/village/`의 세트와 이관 색인에 보존한다. 메인의 `unity/Assets/MeadowDuskV3/MapVer2/Art/` 및 해당 `.meta`가 Unity 배치·GUID를 소유한다. 원본 파일명·32px 격자·투명 캔버스·피벗을 유지한다.

마을 전체 139장과 32px 타일 묶음은 서로 다른 배치 대상이므로 한쪽만 복원해 다른 쪽을 대신하지 않는다. 아트의 채택 상태·스케치 표현·슈퍼점프 배치는 [마을 미술 기준](stage1-village-art-direction.md)을 따른다. 충돌·이동 규칙을 이미지 배치에서 변경하지 않는다.
