# 1스테이지 몬스터 모션 적용

[분야 개요](README.md)

## 술통 포격수·맷돌 돌진체

두 신규 일반 몬스터는 `data/combat/chapter1_new_monsters.json`의 준비·비행·피해 시각을 사용한다. `export_chapter1_new_monsters.py`는 게임 수치를, `export_chapter1_new_monster_art.py`는 승인 리소스의 클립 참조와 메인 소유 배치 계약·신규 Unity 메타데이터를 운반한다. 이미지 배치는 `tools/assets/update_assets.py`를 사용한다. 부풀기·굴림 원본과 박자는 보존하며, 술통의 상부 잉크 줄기만 별도 투사체와 중복되지 않게 파생본에서 제거한다.

`Tools > deviant > Stage 1 Monsters > Import Approved Barrel And Millstone`는 Point·PPU32·무압축·mipmap 없음·Full Rect·클립별 발 피벗과 해시·팔레트·본체 불투명 알파를 검증한다. 사용자 승인 예외인 흰 충격파·증기·붉은 폭탄 표시만 원래 부드러운 알파를 유지한다. 붉은 전조는 기존 6색 본체 팔레트와 별도다. 모든 시각은 `arena.Now`를 사용한다.

맷돌은 2초 준비 중 처음 1.8초에 0~3px의 수평 떨림이 강해지고 마지막 0.2초에는 정지한다. 돌진 시 굴림 8장/320ms, 흰 충격파는 0.2초에 걸쳐 커지며 발 아래를 셰이더로 가린다. 걸을 때도 같은 굴림 8장을 쓴다. 걸은 거리만큼 돌진 때와 같은 비율로 돌아가서(돌진 속도로 320ms 거리마다 한 바퀴) 느리게 걸으면 느리게 구르고, 멈추면 마지막 장에 머문다. 전조가 시작되면 대기 그림으로 돌아간다(플레이 확인 2026-11-06). 별도 바닥 그림자는 없다. 술통은 발사 때 고정한 착탄 박스와 같은 2×2유닛 폭탄 표시를 사용하고, 별도 잉크탄의 상승·화면 밖 대기·낙하는 피해를 주지 않는다. 착탄만 기존 accepted-hit 경로로 한 번 피해를 준다. 다른 스테이지가 재사용하는 일반 프로토타입 표현은 이 두 ID의 아트로 대체하지 않는다.

`Chapter1NewMonsterArtTests`와 `Chapter1PrototypeEnemyTests`는 원본 크기·발사 후 위치 고정·착탄 단일 피해·전조 마지막 정지·굴림/충격파·공격 취소·리셋을 검사한다. 실행 결과와 실제 씬 캡처는 별도로 확인한다.

`Play Approved Barrel And Millstone` 메뉴는 현재 타이틀을 열며 사용자가 마을에서 장비를 고르고 표지판으로 출발한 뒤 시작방에 두 몬스터를 시험 배치한다. 정식 게임의 마을·정비·출발 단계를 건너뛰지 않는다. CLI의 `Chapter1ApprovedMonsterGameFlowVerification.Run`은 실제 화면의 버튼·상호작용을 사용해 같은 경로와 출발 장비의 유지·시작방 도면 생략을 검사하고 현재 GUI 캔버스까지 촬영한다. 검증용 프로필은 메모리에만 두고 플레이어 저장 프로필을 수정하지 않는다. 기존 직접 씬 검증은 개별 전투 회귀용이며 정식 진입 흐름 검증을 대신하지 않는다.

## 원본과 범위

마을의 네 몬스터 픽셀은 외부 리소스의 승인 `normal-outline-free-v3_elite-outline-free-v4` 프레임을 사용한다. [공통 리소스 배치](../../../assets/README.md)가 선택 버전·바이트·해시를 검사하고 기존 Unity 목적지로 운반한다. 이전 편집 JSON을 현재 승인 PNG 위로 다시 내보내지 않는다. Unity `.meta` GUID·시간표·보스 2프레임과 승인 상태를 보존하며 원본 패키지·출처 매핑도 `resources`에서 관리한다.

현재 픽셀·프레임 순서·시간은 `resources/authoring/workbench/source/MonsterReference/approved/manifest.json`과 승인 프레임을 따른다. 네 몬스터의 이전 편집 JSON은 위 ZIP 적용 전 자료이며 현재 픽셀 원본으로 다시 내보내지 않는다. 가시뿌리·먹빗자루·배수관 포수·우물 도르래 수문장은 기본·대기·이동·공격·피격·죽음이 있다. 양주먹 시계탑 보스의 기존 기본·피격은 이전 이동형 보존 자료로 유지한다. 새 천장 사슬 고정형의 대기·등장·공격·복귀·죽음은 [고정형 보스 모션 제작 명세](clock-executioner-sprites.md)를 따르며, 걷기·일반 이동·기본 공격은 제작하지 않는다. 전용 시험방의 분리 이미지·도형 구현을 새 모션 제작 완료로 취급하지 않는다.

Unity 적용 사본은 `Assets/Deviant/Stage1Monsters`다. 모션 확인 씬은 표현 전용이고, `Game/`은 팀 마을 게임 `Chapter1Procedural`에 선택적으로 붙이는 실제 전투 연결이다. 다른 숲·들판 씬은 기존 콘텐츠를 유지한다. 피격 1장의 편집 길이 120ms는 게임 피격 경직 수치가 아니다.

## 사용

현재 보스 후속 모션 제작 계획은 `resources/authoring/workbench/source/MonsterReference/aether-prompts/boss-action-plan.json`이다. 걷기 대신 잉크 잠행→다른 지점에서 솟구치기를 사용하고, 솟구치기 순간 주변 잉크 피해를 한 번 주는 방향이다. 기존 낙하시침·양손 지면 파쇄에 가슴을 위로 펴고 머리를 뒤로 젖힌 자세를 유지하는 잉크 포효를 추가한다. 포효 생성에서는 깊은 웅크림·처지는 회복을 빼고 큰 상체 펴기를 중심으로 한다. 다섯 동작의 에테르 입력을 준비했으며, 사용자가 제공한 솟구치기·낙하시침·양손 지면 파쇄는 각 36장/3초로 추출해 `resources/authoring/workbench/source/MonsterReference/local-assets/boss-frame-extract-v1/`에서 12·18·24장 후보와 비교한다. 이들은 미확정 추출본으로 픽셀·6색·크기 보정 전이다. 잠행·잉크 포효의 추출본과 보스 판정·FX·밸런스·Unity 적용은 아직 없다. 대기·죽음 제작은 이번 범위에서 제외한다. 보스 피격은 별도 자세 전환 없이 흰 점멸·파편·타격음만 사용하는 방향이며 보존된 피격 에셋과 다른 몬스터는 변경하지 않는다.

Unity 6000.6.5f1에서 `Tools > deviant > Stage 1 Monsters > Play Motion Showcase`를 실행한다. 씬은 `Assets/Deviant/Stage1Monsters/Scenes/Stage1MonsterMotions.unity`다. 플레이어 크기 참고 이미지와 몬스터 5종을 같은 PPU로 배치한다.

자동 반복은 대기 → 이동 → 공격 → 피격 → 죽음 순서다. 상단 버튼으로 각 상태를 고정하고 Pause/Resume, Flip을 확인할 수 있다. 보스에 없는 모션을 요청하면 재생하지 않는다.

`Prefabs/`에는 종별 `Stage1MonsterPlayer`가 있다. `Play("idle")`, `Play("walk")`, `Play("attack")`, `Play("hit", true)`, `Play("death")`로 표현 상태를 지정한다. `true`는 다른 상태를 지시할 때까지 마지막 자세를 유지한다. 전투 어댑터에서 피격 경직 종료에 맞춰 idle/walk를 선택해야 한다. 공격은 기본적으로 idle로 돌아가고 죽음은 끝난 뒤 렌더러를 숨긴다. 새 상태를 재생하면 다시 표시한다. 사망 시 GameObject 삭제나 보상 생성은 하지 않는다.

`Animations/`에는 동일 프레임 시간의 `.anim`과 종별 `.controller`도 제공한다. 기본 프리팹은 원본의 밀리초 시간 배열을 읽는 플레이어를 사용한다. Animator를 직접 연결할 때는 같은 SpriteRenderer를 동시에 두 재생기가 쓰지 않도록 한다.

## 픽셀과 원점

모든 몬스터는 PPU32·Point·무압축·mipmap 없음·Full Rect다. 생성·보간 프레임, 추가 색·반투명·Transform 크기 변형을 넣지 않는다. 일반 모션의 발 피벗은 (64,8), 보스는 (128,16)이다. 엘리트 죽음은 192×160의 (96,16), 사거리 2배 공격은 448×180의 (286,15)다. 기본형 뒤 지지발 x110과 공격 뒤 지지발 x332가 같은 월드 위치에 놓인다. 모션마다 프레임을 중심 정렬하거나 실루엣 높이로 재확대하지 않는다.

## 재생성·검증

일반 게임 이미지는 `python tools/assets/update_assets.py`로 배치한다. 제작 재생성이 필요한 경우에만 `python resources/tools/export_stage1_monster_motions.py --destination outputs/art-review/monsters`로 새 검토 디렉터리에 출력한다. 원본 manifest·프레임·박자를 검토한 뒤 필요한 Unity 연결을 명시적으로 갱신하며 기존 스프라이트·애니메이션·프리팹 GUID를 유지한다. 리소스 원본 커밋을 먼저 push하고 메인의 배치 계약·gitlink·필요한 연결을 함께 갱신한다.

`Validate Imported Motions`는 실제 Unity Sprite 임포트 설정·팔레트·알파, `.anim` 중간 시점의 프레임, 루프 시간, 피격 복귀·죽음 숨김·방향 반전 및 Transform 불변을 검사한다. 출력은 Git 제외 `outputs/stage1-monsters/`다. 기존 게임의 피해·충돌·AI·밸런스 검증은 포함하지 않는다.

## 마을 게임 적용

이 몬스터 브랜치는 `experiment/stage1-village-reference`의 팀 랜덤 마을을 병합해 사용한다. `Tools > deviant > Stage 1 Monsters > Play Village Game`으로 실행한다. `Apply To Village Game`은 기존 `Chapter1Procedural` 씬의 월드에 콘텐츠만 연결하며 지형·발판·카메라·플레이어를 재생성하지 않는다. 씬을 교체하기 전에 저장하지 않은 씬 변경의 저장 여부를 확인하며, 취소하면 기존 씬을 유지하고 플레이에도 진입하지 않는다.

기존 들쥐/멧돼지 배치는 가시뿌리, 두더지/허수아비/짚단 배치는 먹빗자루, 두레박 배치는 배수관 포수로 교체한다. 원래 배치의 위치·구역·배회 시드를 유지한다. 기존 엘리트 랜드마크의 바닥에 우물 도르래 한 마리를 놓는다. 마을 콘텐츠의 배치와 수동 생성 API는 네 종만 허용한다. 보스방의 시계탑 집행자는 `ForestCombatV2.Chapter1BossEncounter`가 따로 생성하며, 이 콘텐츠는 `IChapter1BossArt`로 승인된 기본·피격 프레임만 제공한다. 보스 기본·피격 그림은 모션 확인용 카탈로그에 남아 있다.

`Stage1VillageMonsterPresentation`은 실제 전투 시계로 대기·이동·공격·피격·죽음을 선택한다. 걷기는 원본 느린 박자, 공격은 원본 시간, 피격은 실제 경직 종료까지 한 자세를 유지한다. 방향은 원본 왼쪽 기준으로 오른쪽을 볼 때만 반전한다. 죽음은 승인 모션을 끝까지 재생한 후 숨긴다.

| 종 | 시험용 공격 |
|---|---|
| 가시뿌리 | 0.85초 예고(승인 0.65초 + 3번 준비 자세 0.2초 유지) 후 0.2초 동안 3유닛 돌진(속도 15), 양팔 베기 창에서 한 번 피해 |
| 먹빗자루 | 0.90초 예고(승인 0.70초 + 4번 준비 자세 0.2초 유지) 후 전방 낮고 넓은 박스로 한 번 쓸기 |
| 배수관 포수 | 몸통이 꿀렁이며 압력을 모으고(#1~#13) 포신이 떨린 뒤(#14~#17), 그림의 발사 프레임 #18과 같은 1.25초에 기존 지형 충돌 탄환 한 발, 잉크색 사용. 준비 자세 유지는 쓰지 않는다 |

전조 길이는 사용자 결정(2026-10-30)이다. 가시뿌리·먹빗자루는 준비 자세 유지 +0.2초, 배수관 포수는 발사 시점을 승인 그림의 발사 프레임에 맞췄다(1.02초 → 1.25초, 피해 구간 0.13초 유지). 유지 방식은 [데이터 파이프라인](../../data/data-pipeline.md)을 따른다.

전조 동안에는 떨림과 번쩍임을 함께 보여 준다(사용자 결정 2026-10-30).
- 전조 구간: 종별 `windupCueFrame`(가시뿌리 3번, 먹빗자루 4번, 배수관 포수 14번 포신 떨림)이 시작될 때부터 피해 판정이 시작될 때까지다.
- 떨림: 0.06초마다 몸을 한쪽으로 1픽셀 옮겼다 돌아오고, 구간의 마지막 40%에서는 좌우로 1픽셀씩 흔든다.
- 번쩍임: 피해 직전 0.1초 동안 몸 전체를 한 가지 색(기본 흰색 #F2EFE9)으로 덮는다.
- 붉어짐: 근접 공격(`tintKinds`, 가시뿌리 돌진·먹빗자루 쓸기)은 공격을 시작한 순간부터 번쩍임 직전까지 몸 위에 빨간색(#D62C20)을 덮고, 불투명도를 0에서 `tintMax`(0.55)까지 시간의 제곱으로 올린다. 그 뒤 흰 번쩍임으로 바뀐다. 배수관 포수(원거리)는 붉어지지 않는다. 맷돌 돌진체도 2초 전조 동안 점점 세지는 떨림과 함께 같은 색으로 붉어진다(`data/combat/chapter1_new_monsters.json`의 `windupTint`·`windupTintMax`, 전조 전체에 걸쳐 시간의 제곱, 굴러가기 시작하면 꺼짐).
- 두 효과 모두 그림의 표시 위치와 덧그림만 바꾼다. 몬스터 위치, 판정, 승인 그림 픽셀은 바꾸지 않는다.
- 엘리트·보스에는 쓰지 않는다. 구현은 `Stage1VillageWindupCue`, 공통 수치는 데이터의 `windupCue`다. 비교 화면은 Git 제외 `outputs/q4-windup/`에 있다.
| 우물 도르래 | HP 3000. 근접이면 후반 할퀴기만 즉시 시작(0.64~0.81초 피해). 그 밖에는 갈고리 연계 1.5배속: 0.567초 투척 → 1.067초까지 회수 → 1.493~1.607초 할퀴기. 사거리 4.7유닛 유지 |

`FieldMouseEnemy.SpeciesAttackStarting`에서 엘리트가 실행별 공격 종류를 선택한다. 할퀴기 판정과 지형 차폐로 근접 여부를 판단하며 근접 공격이 잠행보다 우선한다. 엘리트 정의는 개체별로 복사해 준비·실행·회복 시간을 설정하고 공유 카탈로그는 수정하지 않는다. `Stage1VillageMonsterAttack.MotionAge`를 본체·피해·갈고리·먼지 FX가 함께 사용한다. 갈고리 연계는 전체 1.5배속(끌어오기 속도 포함), 직접 할퀴기는 승인 시간축 1.60초부터 원속도로 재생한다. 원본 아트·클립·공격 간격 3.8초와 잠행 시간은 바꾸지 않는다. 근접 공격은 포획 없이 피해를 주지만 회피·벽 차폐·공격 취소·단일 적중 규칙을 유지한다.

### 공격 이펙트와 엘리트 잉크 잠행

공격 이펙트의 기존 기준본은 `resources/authoring/workbench/source/MonsterReference/approved-effects/manifest.json`, 선택한 픽셀 보정·베기 버전은 `approved-polish-v1/manifest.json`이다. 이전 원본은 보존한다. `resources/tools/export_stage1_fx_polish.py --destination <새 검토 디렉터리>`가 선택한 미디어와 두 import 설명을 내보내며, Unity 미디어 배치는 메인의 배치 계약으로 수행한다. 엘리트 전체 몸체의 밝은 외곽 픽셀을 승인 6색으로 낮추고, 가시뿌리 공격에 박혀 있던 이전 띠와 엘리트 공격의 이전 할퀴기 띠를 선택 사본에서 분리했다.

가시뿌리 베기는 실제 준비 유지 후 0.85초에 시작한다. 짧은 이동 잔상은 시각 효과이며 판정이 없다. 엘리트 직접 할퀴기와 갈고리 후 할퀴기는 동일한 `elite-claw-sweep`을 공유한다. 승인 모션 시각 2.18초에 잔광이 시작하고 피해 창은 2.24~2.41초를 유지한다. 직접 할퀴기는 모션 시각 1.60초부터 원속도로, 갈고리 연계는 전체 1.5배속으로 같은 클립을 재생한다. 가시뿌리·엘리트 베기의 밝은 중심은 실제 공격 박스에 맞추고, 바깥 잔광은 알파 80 이하로 제한하며 피해 범위를 늘리지 않는다. 빗자루 먼지와 프레임별 균일 페이드는 유지한다. 베기의 부드러운 잔광에는 연속 알파를 허용하고 RGB는 최대 3색을 유지한다.

배수관 포수의 발사 위치는 발 기준 전방 1.375·위 1.25유닛이다. 코드 전조는 포구 내부에서 시작해 포신 떨림을 따라가고 발사 시 사라진다. 탄 몸통 16×12 네이티브 픽셀과 판정 0.5×0.375유닛을 함께 사용하며, 지형 스윕과 대상 검사 모두 같은 인스턴스 크기를 읽는다. 전조 두께도 같은 높이를 읽는다. 기존 다른 종의 탄은 0.25×0.25유닛을 유지한다.

엘리트는 근접 할퀴기를 우선하며, 근접 조건 밖에서 첫 공격 이후 쿨타임과 안전 지면 조건이 맞으면 잠행 패턴을 선택한다. 0~0.55초 기존 몸체가 잉크 수면 아래로 잠김(잔여 웅덩이·파문이 잦아듦) → 1초 잠행 → 1.55초에 대상 발밑의 유효한 지면을 고정하고 0.55초 예고 → 2.10~2.28초 한 번 분출 피해 → 기존 공격 종료까지 복귀한다. 잠행 중 몸·피격 콜라이더와 노출을 해제하며 출현·취소·죽음·리셋 시 복원한다. 예고 뒤 대상을 추적하지 않는다. `Stage1BurrowInk`가 전투 시계로 기포를 점점 거세게 그리며, 웅덩이의 가로 폭은 `DamageBounds.size.x`와 같다. 출현 때 같은 몸체가 0.18초에 빠르게 솟고 작은 잉크 방울만 튄다. 기포·파문·방울에는 별도 피해 판정이 없다. 출현 지점은 바닥 전체 지지·몸 공간·구덩이·6유닛 이동 한계·기존 활동 범위를 검사하며, 불가능하면 출발 지점으로 예고하거나 취소한다. 피해는 기존 accepted-hit 경로를 사용한다. 잠행 쿨타임 8초와 분출 2.8125×3유닛 박스는 플레이테스트용이며 최종 밸런스가 아니다. 보스는 생성하지 않는다.

이미지 배치와 게임 콘텐츠 생성을 구분한다. 제작 변환은 `resources/tools/export_stage1_monster_effects.py --destination <새 검토 디렉터리>`, 실제 이미지는 공통 배치, 시험용 게임 정의는 `tools/combat/export_stage1_village_monsters.py`가 담당한다. 필요 시 `Import Attack Effects And Apply To Village`로 명시적으로 연결한다. 전투 시계 정지·공격 취소·방향 반전·고정 예고·회피·단일 피해·리셋은 `Stage1MonsterEffectTests`에서 검사한다. 에셋 생성·Unity 임포트·전투 테스트 결과를 각각 기록한다.

사용자가 우선 대략적인 판정을 요청한 **플레이테스트용 수치**다. 원본은 `data/combat/stage1_village_monsters.json`이며 `python tools/combat/export_stage1_village_monsters.py`로 적용 JSON을 재생성한다. 체력·피해·감지·경직의 출발값은 기존 승인 종별 데이터에서 가져오고, 몸통 박스·공격 시점·돌진·갈고리 거리는 임시 값으로 분리했다. 일반 3종은 난이도 조정으로 가로 감지 거리를 공통값 10유닛의 1.3배인 13유닛으로 덮어쓰며 세로 감지 4유닛은 유지한다. 먹빗자루 쓸기 박스는 뒤쪽 끝(-0.15)을 유지한 채 폭을 4.4유닛(앞쪽 끝 4.25)으로 늘렸다. 공격 시작 거리는 2.55유닛이다(처음 2.6·1.5에서 두 차례 늘림, 사용자 요청). 가시뿌리는 돌진 거리를 3유닛으로 늘렸다. 피해 창 0.2초는 그대로라 속도를 15로 올렸고, 공격 시작 거리도 4.5유닛으로 늘렸다. 가시뿌리 베기의 밝은 중심은 공격 박스 안에 두고, 바깥 잔광·잔상에는 피해 판정을 추가하지 않는다. 엘리트 수문장은 공통 감지값을 따른다. 피격 취소·사망·명령 실행 ID·피해 수신·탄환 지형 충돌은 기존 전투 경로를 사용한다. 갈고리 연계 실패 시 할퀴기 그림은 이어져도 피해를 주지 않는다. 직접 근접 할퀴기는 포획 없이 판정한다. 공격 FX와 잠행은 위 승인 이펙트 경로를 따른다.

`Stage1VillageMonsterInstaller.PlayAndVerify`와 `-stage1VillageCaptureRoot <폴더>`를 명시하면 실제 씬에서 네 종·보스 제외·모션 연결, 좌우 베기·탄환 피해·갈고리 성공/실패·공격 취소·리셋을 검사하고 게임 화면을 저장한다. 이 실행은 일회성 검사이며 일반 플레이에는 개입하지 않는다. 시제품 판정 확인은 최종 밸런스·모든 시드의 동선·전체 무기 조합 검증을 뜻하지 않는다.

화면 조작 없는 전투 회귀 검사는 Unity Test Runner의 EditMode `Deviant.Stage1Monsters.Game.Tests.Stage1VillageMonsterTests`로 수행한다. 실제 마을 씬에 진입한 뒤 기존 전투 시뮬레이션을 진행하며 네 종/보스 제외, 지형 보존, 좌우 베기, 탄환 적중, 갈고리 성공/실패, 실제 피격 취소와 피격 자세, 죽음 종료, 리셋을 검사한다. `outputs/stage1-monsters/village/logic-validation.json`과 Test Runner 결과를 출력한다. 이 검사는 실제 창의 시각 검토와 구분한다.

## 마을 피격·마지막 타격 연출

마을의 `Stage1VillageMonsterPresentation`도 실제 유효 피격 횟수를 관찰해 기존 `Chapter1HitFeedback`의 65ms 흰 점멸, 월드 좌표 파편 18개와 짧은 타격음을 재생한다. 흰색은 현재 프레임의 알파를 사용하는 별도 오버레이이며 승인 PNG의 6색·모양·발 피벗을 바꾸지 않는다. 파편의 시작점은 투명 캔버스나 긴 갈고리가 아닌 고정 몸통 박스 안에 둔다.

죽이는 타격도 동일한 짧은 흰 점멸·파편을 유지하면서 승인 죽음 프레임을 시작한다. 물리 시체 파편은 죽음 모션 완료를 기다리지 않고 치명타 프레임에 생성하며, 점멸 0.08초 뒤 몸을 숨긴다. 파편 생성이 불가능하면 죽음 모션을 그대로 보여 준다. 죽음 전체 속도는 일반 몹 1.6초, 엘리트 1.79초의 원본을 유지한다. 피격 경직·공격 판정·체력·넉백은 전투 시스템이 계속 소유한다. 실드로 피해가 흡수된 유효 피격도 연출하고, 죽은 대상에 거절된 공격에는 재생하지 않는다. 전투 일시정지 때 파편·소리도 멈추며 리셋·비활성화·파괴 때 정리한다. 표현을 다시 켜거나 같은 시각을 다시 그려도 과거 피격을 반복하지 않는다.

`AcceptedHitsAndFinishingBlowsKeepExistingFlashParticlesAndCleanup`은 실제 마을 네 종의 좌우 방향에서 일반 피격·재피격·실드·치명타 점멸과 파편, 정지/복귀·비활성화·죽음 종료·리셋을 검사한다. 원본 그림·죽음 프레임 시간과 기존 들판 피격 연출은 유지한다.

손맛 비교 효과가 켜진 테스트 실행에서는 `CombatFeelFeedback`이 몹 중앙의 큰 흰 섬광과 흰 파편을 담당한다. 기존 `Chapter1HitFeedback`은 소리를 유지하고 시각 효과를 중복 재생하지 않는다. 비교 효과를 끄면 기존 점멸과 파편 경로를 사용한다. 기본 타격 멈춤은 꺼져 있으며 F8로 켜서 비교할 수 있다.

### 일반 몹의 외곽선 없는 표현

가시뿌리·먹빗자루·배수관 포수의 기준 원본은 기본·대기·걷기·공격·피격·죽음 전체에 `normal-outline-free-motions-v3`를 적용한다. 가까운 기존 명암색으로 검은 외곽 테두리를 대체하고 내부 디테일과 실제 잉크 덩어리는 유지한다. 기존 6색, 알파 0/255, 캔버스·피벗·동작 시간은 그대로다. 배수관의 분리된 공격 FX는 보존한다.

`resources/authoring/workbench/source/MonsterReference/aether-prompts/apply-normal-outline-free.py --apply`는 로컬 원본 보관본을 기준으로 PNG·시트·편집 JSON을 재생성한다. 이후 `validate-approved.cjs --refresh`, `editor/build-projects.cjs`, `build-approved-gallery.cjs`를 실행한다. 일반 몹 v3와 엘리트 v4의 최신 보정본은 Unity 적용 사본에도 내보내고 6000.6.5f1의 ImportAndValidate로 검증한다.

외곽선 없는 v3 보정에서는 재질색 사이에 홀로 남은 작은 검은 경계를 정리한다. 먹빗자루는 새로 채우는 경계에 중간 명암까지만 사용해 가는 팔·손끝이 밝게 지워져 보이지 않게 한다. 내부 원래 명암과 알파는 유지한다. 직전 v2 비교본은 `local-assets/99_archive/before-normal-outline-free-motions-v3/`에 보관한다.

엘리트도 `elite-outline-free-motions-v1`로 기본·대기·걷기·공격·피격·죽음 114장에 같은 방향을 적용했다. 기존 6색·실루엣·피벗·사거리·박자를 보존하며 죽음의 분리 FX는 변경하지 않는다. `apply-elite-outline-free.py`로 재생성한다. 현재 기준은 후속 재질색·외곽 튐 보정을 포함한 v4이며 Unity 적용 사본과 동기화한다.

엘리트 후속 보정은 `elite-outline-free-motions-v2`: 외곽 2픽셀 이내의 색 면을 정돈하고 본체의 1~3픽셀 구멍·작은 오목 틈만 채운다. 기존 불투명 픽셀 삭제와 깊은 내부 디테일 변경은 금지한다. 사슬 같은 얇은 구조는 주변 면적 조건으로 빈틈 채움에서 제외하며 죽음 프레임 알파와 분리 FX는 보존한다. v1 비교본은 `local-assets/99_archive/before-elite-outline-free-motions-v2/`에 보관한다.

엘리트 외곽선 없는 v3는 몸에서 내려오는 잉크 가장자리에 번진 밝은 재질색을 원래 잉크색으로 보정한다. 원본에서 검은 잉크가 우세한 외곽의 새 중간·밝은 색만 되돌리고 원래 금속 하이라이트와 내부 명암은 유지한다. v2 대비 알파·크기·피벗·타이밍·죽음 FX는 동일하며, v2 비교본은 `local-assets/99_archive/before-elite-outline-free-motions-v3/`에 보관한다.

엘리트 v4는 v3의 재질색을 기준으로 앞뒤 프레임에서 일치하는 경계만 비교해 순간적인 외곽 1픽셀 돌출·오목 틈·밝은 색 튐을 보정한다. 내부 디테일·분리 FX·발 접지·프레임 수·박자는 유지한다. 기본/피격은 변화 없고 죽음은 본체 경계색만 수정한다. 적용 도구는 `aether-prompts/smooth-elite-temporal-rim.py`, v3 원본은 `local-assets/99_archive/before-elite-outline-free-motions-v4/`에 보존한다.

Unity의 현재 일반 몹 3종은 외곽선 없는 v3, 우물 도르래는 잉크 재질색과 프레임 외곽 1픽셀 튐을 보정한 v4다. 기존 Art 경로·GUID·클립 시간·PPU32·피벗을 유지해 마을의 기존 카탈로그 연결로 사용한다. 보스 생성 제외 정책은 유지한다.
