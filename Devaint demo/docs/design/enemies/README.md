# 몬스터

[상위 문서](../README.md)

먼저 전투 공통 판정과 콘텐츠 역할을 확인하고 챕터별 적 목록에서 개별 적으로 내려간다. 일반·엘리트·보스 전용 예외는 해당 명세에서 명시하며 다른 적에 확대 적용하지 않는다.

## 스테이지별 배치 규모

랜덤 스테이지 한 판에 처음 놓이는 몬스터 수와 체력이다. `node tools/map/monster_stats.cjs 200`의 성공한 배치 기준이며 방 원형이나 체력 원본을 바꾸면 다시 산정한다. 마리수는 최소 / 평균 / 최대다. 각 종의 체력 원본은 챕터별 몬스터 명세를 따른다.

| 1챕터 | 체력 | 마리수 | | 2챕터 | 체력 | 마리수 |
|---|---:|---|---|---|---:|---|
| 가시뿌리 | 46 | 53 / 57.2 / 61 | | 먹침필경사 | 54 | 46 / 47.5 / 49 |
| 먹빗자루 | 44 | 41 / 43.3 / 46 | | 등짐분사수 | 54 | 29 / 30.0 / 31 |
| 배수관 포수 | 46 | 29 / 31.5 / 34 | | 신호투척수 | 54 | 28 / 28.9 / 30 |
| 술통 포격수 | 46 | 8 / 10.6 / 12 | | 늘어진 수의 | 54 | 9 / 9.0 / 9 |
| 맷돌 돌진체 | 78 | 2 / 3.3 / 5 | | 쐐기보행기 | 90 | 3 / 4.5 / 7 |
| **일반 합계** | | **145 / 145.8 / 148** | | **일반 합계** | | **120 / 120.0 / 120** |
| 일반 체력 합 | | 6,644 / 6,728.8 / 6,882 | | 일반 체력 합 | | 6,588 / 6,643.4 / 6,732 |
| 우물 도르래 수문장(엘리트) | 234 | 1 | | A3 엘리트 | 270 | 1 |
| 시계탑 집행자(보스) | 1,800 | 1 | | Rose·Blue(보스) | 아래 | 1 |

- 스테이지마다 일반 몬스터를 최소 140마리 배치한다. [처치 보상](../run/rewards.md#스테이지에서-얻는-무기와-잉크)의 보상 게이지 6칸(600)에 여유를 두기 위한 하한이다. 1스테이지 일반 몬스터를 모두 잡으면 게이지가 약 696 찬다.
- 1챕터 전투방 원형은 18마리(S1-05만 출입구·바닥 규칙상 15마리)이고 한 판에 8개를 쓴다. 봉인 도전을 하면 30마리가 더 떨어지며, 그 판 일반 전투방에 놓인 종류 중 무작위라 체력 기댓값은 1,560이다.
- 2챕터 전투방 원형은 12마리이고 한 판에 10개를 쓴다(전투방 2곳 자리를 봉인 도전방·잠긴 상자방이 쓴다, 사용자 결정 2026-11-13). 그래서 처음 배치는 120마리로 위의 하한 140보다 적다. 봉인 도전을 하면 30마리가 더 떨어진다. 하한을 지킬 방법(방당 마릿수·하한 조정)은 미정이며, 위 표는 현재 10방의 배치를 따른다.
- Rose·Blue는 장치 15,000 → Rose 12,000·Blue 12,000(어느 한쪽을 쓰러뜨리면 전환, 12,000~24,000) → 합쳐진 Blue 20,000이라 보스 전체 47,000~59,000이다(2026-11-16 사용자 결정).
- 열쇠 운반자는 기존 일반 몹 1마리라 따로 세지 않는다. 보스 패턴의 화살·구체(HP 100)는 제외한다.
