# 에셋 작업 안내

[분야 개요](README.md)

새 에셋을 만들 때 이 폴더를 복사하고 에셋 이름으로 바꾼다. 필요한 하위 폴더만 사용한다.

## 에셋 정보

- 이름:
- 분류: 캐릭터 / 몬스터 / 배경 / UI / 이펙트 / 사운드 / 스토리연출
- 현재 상태: 참고 / 작업중 / 부분확정 / 전체확정
- 현재 미리보기 경로:
- 게임 적용용 확정 파일 경로:
- 편집 가능한 원본 경로:

## 폴더 사용법

| 폴더 | 넣는 자료 |
| --- | --- |
| 01_참고자료 | 레퍼런스와 컨셉 |
| 02_제작원본 | 편집 원본, 생성 원본, 리터치 데이터, 제작 코드 |
| 03_작업중 | 검토 중인 결과 |
| 04_확정본 | 승인된 게임 적용용 파일과 설정 |
| 05_미리보기 | 재생 화면, 비교 이미지, GIF |
| 99_이전시안 | 이전 결과와 수정 전 백업 |
