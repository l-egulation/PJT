# 무기 사운드 작업실

확정 검 단발의 일부를 잘라 다른 무기 모션과 비교하는 오프라인 HTML 편집기다. 외부 서버·CDN·모델 호출 없이 동작한다. 생성 HTML과 승인 그림 원본은 제작 작업 공간에서 관리한다.

## 사용

1. 생성된 `weapon-sfx-studio.html`을 브라우저로 연다.
2. 무기와 기본공격 한 타·전체 연계·특수공격을 선택한다.
3. 아래 파형에서 10ms 이상의 구간을 선택하고 타격마다 배치하거나 현재 시점에 추가한다.
4. 이벤트마다 피크 시점·피치·음량·속도·소스 범위를 편집한다. 블록을 드래그해 시점을 옮긴다.
5. 수리검·회전공격은 회전음 프리셋을 추가하고 간격·유지 시간·좌우 회전·음량 물결을 조절한다. 기존 단발과 겹치지 않으려면 이벤트 목록에서 기존 소리를 지운다.
6. JSON으로 설정을 저장·불러오거나 현재 설정을 담은 HTML 사본을 저장한다. 현재 공격의 소리를 48kHz 스테레오 PCM16 WAV로 내보낸다.

청취 볼륨은 WAV에 적용하지 않는다. 믹스가 0.94 피크를 넘으면 미리듣기와 내보내기에 같은 감쇠를 적용한다. 시작보다 앞에 놓인 소리 부분은 0ms에서 잘린다. 타임라인은 마지막 소리의 꼬리까지 포함한다. 자동 저장은 브라우저·주소별 저장소이므로 공유·백업에는 JSON/작업 HTML을 사용한다.

## 입력과 재생 범위

- 소스 선택: [basic-sword-selection.json](../../../data/audio/basic-sword-selection.json)의 Minifantasy 검 3 단발.
- 승인 11종·표창/폭탄 원본 ZIP: [에셋 복원](../../../docs/assets/README.md).
- 프레임·피벗: 승인 원본 패키지. 11종 본체는 매니페스트 SHA256과 대조한다. 표창의 정해진 픽셀 보정도 기존 가져오기와 동일하게 적용한다.
- 모션·기본 시간표: `AnimationCatalog`, `HeavyWeaponCatalog`, `MeleeCatalog`와 명시 모션 바인딩. 시험장 임시 슬라이더는 포함하지 않는다.
- 특수공격은 현재 연결된 공용 본체 모션을 표시한다. 전용 특수 이펙트·실제 이동·투사체 비행·착탄·히트스톱은 재현하지 않는다. 표창·폭탄 투사체는 승인된 회전 그림을 위치 고정 참고로 표시한다.
- 피치 조절은 리샘플링, 독립 속도 조절은 WSOLA를 사용한다. 짧은 소스·극단적 변경에는 입자감이 생길 수 있으므로 최종 청취 판단이 필요하다.
- 회전음은 같은 소스의 겹친 반복과 equal-power 좌우 이동, 주기적 음량 변화다. 별도 합성 음원을 추가하지 않는다.

현재 빌더는 고정 시간 모션을 대상으로 한다. FrameTime 바인딩을 발견하면 빌드를 중단한다. 편집 파일은 검토 후보이며 Unity WAV·승인 목록·전투 수치를 자동 수정하지 않는다. 검 선택 확정과 Unity 전달본 교체·게임 사건 연결은 별도다.

## 만들기

Python 3와 Pillow가 필요하다. 원본 ZIP을 압축 해제할 필요는 없다.

```powershell
python tools/audio/weapon_sfx_studio/build.py `
  --package "<무기11종_확정_20261021.zip>" `
  --thrown-package "<approved-thrown-20261023.zip>" `
  --sound "<sfx_weapon_base_sword_swing_07_v01.wav>" `
  --output "<weapon-sfx-studio.html>"

node tools/audio/weapon_sfx_studio/test_dsp.cjs
```

일반적인 편집은 생성 HTML에서 한다. 제작 도구의 코드 수정은 `app.js`, 음원 처리 수정은 `dsp.js`, UI 수정은 `studio.html`에 적용한 뒤 다시 빌드한다. 생성된 그림 내장 HTML·실행 로그·검증 산출물은 Git에 추가하지 않는다.
