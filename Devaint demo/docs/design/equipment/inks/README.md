# 잉크·런 도감

[상위 문서](../README.md)

잉크는 유틸리티를 제공하는 노랑·초록·보라, 기본 공격과 대상 몬스터 상태 조건으로 발동해 무기와 관계없이 플레이어의 기본 공격 피해 또는 공속만 높이는 빨강, 스킬 공격으로 발동해 대상 몬스터의 상태 조건에 따라 쿨타임을 줄이거나 스킬 피해만 높이는 파랑으로 역할을 나눈다. 유틸리티와 상태 조건부 강화 사이의 채용 균형을 목표로 하며 색별 규칙에서 개별 조합으로 내려간다. 효과 잉크는 트리거×효과의 모든 유효 조합을 정의하며 상태이상→상태이상만 제외한다. 현재 기본 목록은 효과 부여 27개·빨강 6개·파랑 6개로 총 39개다. 이름은 조건·효과를 드러내는 기능형으로 작성한다. 기본 39종의 수치는 수치표의 플레이 테스트 시작값을 사용하며 개별 이름·설명은 [39종 표시 문구](names-and-descriptions.md)를 따른다. Unity 런 도감·보상·상점에 표시 문구를 연결했다. 아이콘은 잉크 자체의 색에 맞는 기본 5색 아이콘을 사용하며, 색별 매핑은 구조화 원본의 `inks.presentation.iconsByColor`를 따른다. 개별 효과별 전용 그림의 채택은 후속 범위다.
