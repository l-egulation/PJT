공사장, 항만, 재난 현장처럼 소음이 심한 곳에서는 무전이나 음성이 잘 전달되지 않음. 작업자가 표준 수신호를 보내면 카메라가 이를 인식해서 운전자나 장비 조작자의 화면에 크게 표시한다.
> 정지
	천천히 이동
	상승
	하강
	위험
	신호자 시야 이탈
단순 수신호 인식 후
- 신호가 일정 시간 보이지 않으면 작업 중단 경고
- 두 사람이 서로 다른 신호를 보내면 충돌 경고
- 작업자가 위험구역에 들어가면 별도 표시
- 조작자가 확인 버튼을 눌러야 신호 완료
- 작업 종료 후 미확인 신호 기록
수신호 학습 앱과 인식 연구는 이미 있다. [크레인 수신호 학습 앱](https://play.google.com/store/apps/details?id=com.simcoachgames.signaling), [동적 수신호 인식 연구](https://www.iaarc.org/publications/fulltext/013_Dynamic_Hand-Signal_Recognition_and_Prediction_Framework_for_Crane_Operations_Using_Deep_Learning.pdf)
