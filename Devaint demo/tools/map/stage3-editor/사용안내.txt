DEVIANT — 3챕터 맵 설계실

시작
  ‘3챕터_맵편집기.html’을 Chrome 또는 Edge에서 여세요.
  HTML 한 파일만 옮겨도 사용할 수 있습니다. 설치나 서버, 인터넷 연결이 필요하지 않습니다.
  index.html은 같은 폴더의 editor.css, map-core.js, editor.js를 사용하는 개발용 진입점입니다.

기본 설계
  수로 출구 → 덮인 정원 회랑 → 외곽 경비실 → 성벽 계단실 → 경비 휴게실
  → 복층 경비 회랑 → 안쪽 운반 계단 → 기록 운반 통로 → 기록 반입장 관문
  선택 갈래: 휴게실 → 위층 경비탑 → 복층 회랑 / 경비탑 → 경비대장 대기실
  선택 갈래: 운반 계단 → 작업동 보관실 → 기록 운반 통로
  일반 전투방 8개와 시작·정비소·엘리트·보스방 각 1개, 총 12방입니다.
  전투와 보상 종류·개수는 위치 후보이며 확정된 밸런스가 아닙니다.

편집
  전체 동선에서 방을 드래그해 16×12u 블록 단위로 이동합니다.
  방을 두 번 누르거나 오른쪽 ‘이 방 내부 편집’을 눌러 발판을 편집합니다.
  발판을 드래그하면 1u씩 이동합니다. 선택한 발판의 양끝 손잡이로 너비를 바꿉니다.
  고체 지형은 네 모서리 손잡이로 크기를 바꿉니다. 오른쪽에서 좌표와 크기를 직접 입력할 수도 있습니다.
  ‘발판’ 또는 ‘고체’를 누르고 빈 공간에서 드래그하면 새 배치를 만듭니다.
  ‘적’은 위치 후보를, ‘시설’은 선택한 시설 종류를 클릭한 발 위치에 추가합니다.
  ‘연결’ 도구로 방 두 개를 누릅니다. 연결 선을 누르면 오른쪽에서 출입구 방향과 슬롯을 수정할 수 있습니다.
  슬롯은 위 또는 왼쪽부터 0으로 셉니다. L/R은 12u 행마다, T/B는 16u 열마다 있습니다.
  출입구와 연결용 발판은 자동 생성됩니다. 직접 바꾸려면 연결 슬롯 또는 방 위치를 수정하세요.
  출입구가 어긋나거나 통로 1블록으로 연결할 수 없으면 점선 경고를 표시하고 해당 벽은 닫습니다.

단축키
  V 선택 / P 발판 / G 고체 / E 적 / F 시설 / C 방 연결
  방향키: 선택한 배치 1u 이동. Shift를 누르면 4u 이동.
  전체 보기에서 방 이동은 방향키당 가로 16u / 세로 12u입니다.
  Ctrl+D 복제 / Delete 삭제 / Ctrl+Z 실행 취소 / Ctrl+Shift+Z 다시 실행
  휠 확대·축소 / Space+드래그 또는 오른쪽·가운데 버튼 드래그로 화면 이동 / Home 맞춤
  Ctrl+S JSON 저장 / Esc 선택 해제 또는 이동 테스트 종료

저장과 복원
  수정 사항은 이 브라우저의 로컬 저장소에 자동 저장합니다. 저장할 수 없는 환경은 화면에 표시합니다.
  자동 저장은 HTML 원본을 덮어쓰지 않습니다. 중요한 수정은 반드시 ‘JSON 저장’으로 보관하세요.
  ‘불러오기’로 저장한 JSON을 다시 엽니다. 이 편집기의 버전 1 JSON만 지원합니다.
  불러오기·기본 초안 복원·방 삭제도 실행 취소할 수 있습니다.
  ‘기본맵.json’은 기본 12방 설계의 보존본입니다.
  ‘지도 PNG 저장’은 현재 전체 배치를 그림으로 저장합니다.

이동 테스트
  선택한 방 또는 선택한 발판에서 시작합니다. 선택하지 않았다면 시작방에서 시작합니다.
  A/D 또는 좌우 방향키로 이동 / Space 2단 점프 / 아래+Space 발판 내려가기 / R 시작 위치.
  창을 벗어나거나 Esc를 누르면 편집으로 돌아갑니다.
  1u=32px, 몸 0.9375×2u, 속도 7.5u/s, 점프 초속 20u/s를 사용합니다.
  사각형 몸체의 간이 물리입니다. 적·전투·벽타기·대시·입력 보정은 재현하지 않습니다.
  이 페이지의 검사와 테스트는 Unity의 실제 이동·카메라·전투 검증을 대신하지 않습니다.

좌표
  월드와 방 내부 모두 왼쪽 위가 원점이며, Y는 아래로 증가합니다.
  발판·고체의 X/Y는 왼쪽 위, 적·시설·시작·출구의 X/Y는 왼쪽 발 위치입니다.
  오른쪽 배치 확인은 연결 정렬·방/지형 겹침·지지면·적 출입구 근접을 검사합니다.
  점프 경로의 완주 가능성을 자동 증명하지 않습니다.

개발 파일
  map-core.js: 설계 데이터, 충돌 지형, 연결 검사, JSON 검증, 실행 취소 이력.
  editor.js: 화면, 편집 조작, 파일 저장·복원, 간이 이동 테스트.
  editor.css: 편집기 스타일.
  node build.cjs: 수정한 개발 파일을 단일 HTML과 기본맵 JSON에 반영합니다.

이 폴더는 HTML 검토·편집용입니다. Unity 프로젝트·씬·원본 이미지에는 적용하지 않았습니다.
