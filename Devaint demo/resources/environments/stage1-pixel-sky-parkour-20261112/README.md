# 하늘길 파쿠르 구조물 · 2×2 도트 픽셀판

우물 마을 위 하늘길(수직 파쿠르)의 발판·장치와 꼭대기 종탑·기록판을 1스테이지 픽셀 지형(stage1-pixel-lawn-wood-32)과 같은 격자로 다시 그린 세트다. 32px = 1유닛(PPU 32), 기본 도트 2×2px, 선은 1점 굵기. 색은 지형 6색에 중간 톤 셋(#ece7de #b7b3ab #8a8882)을 더한 회색 단계이고, 의미 있는 색(화살 장치의 경고 주황, 종·첨탑 공·책갈피 금색)만 남긴다.

이전 세트 `environments/village/sky-parkour-props-20261105`와 같은 파일 이름이라 Unity `Hub/sky/props/`의 같은 자리를 바꾼다. 하늘길 벽은 그림이 아니라 전투 잔디 타일 아틀라스(`Stage1Combat/terrain-atlas`)로 그린다.

## 제작과 확인

테두리는 화면 1px 단위로 다듬는다(`source/fillsmooth.py`, numpy·opencv). 2×2 도트 그림의 점은 하나도 지우지 않고, 바깥 실루엣을 논리 격자의 점 가운데로 곧게 편 다각형으로 따서 원래 테두리 바로 바깥 1px 안의 빈 홈만 채운 뒤, 바깥 먹선을 새 테두리에서 2px 띠로 고르게 다시 칠한다. 직선은 같은 마디, 곡선은 마디가 차례로 늘거나 주는 픽셀 선 규칙을 따르며, 안쪽 선(종·아치·문·눈)은 건드리지 않는다. `runtime/`은 아래 스크립트의 출력에 이 단계를 거친 결과다.

`source/`의 스크립트가 격자에 직접 그린다(`px.py`의 lint로 뭉침·꺾임 검사). `s_sky.py`는 발판·장치, `s_tower.py`는 종탑, `s_board.py`는 기록판이다. 뜬 돌·무너지는 돌은 바위 사이를 1점 회색 선으로 나누고 바위 안은 옅은 두 단계 명암만 쓴다(스케치 느낌 유지). 종탑·기록판은 밝은 정면과 그늘진 옆면으로 입체를 낸다. `preview/unity-before-after.png`는 Unity 6000.6.5f1 마을 장면에서 하늘길 여섯 구간을 지금/새 그림으로 같은 자리에서 찍은 비교다.
