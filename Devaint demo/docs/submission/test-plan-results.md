## 1. 테스트 방식

| 방식 | 확인 항목 |
|---|---|
| 자동 테스트 | 전투 규칙, 장비·보상·구매, 저장, UI 조작, 수집 API |
| 실제 씬 검사 | 타이틀·마을·챕터 이동과 화면별 입력 |
| 수동 화면 검토 | 시안 일치, 배치·잘림·가독성, 사용자 승인 |
| 수동 플레이 | 이동·전투·상점·보스·귀환, 난이도와 조작감 |
| 설계 검토 | 무기·잉크 공급, 보상 방식, 메뉴·상점 이용 흐름 |

결과는 통과·확인·실패·미실행으로 표기하고 검증 시점의 커밋을 함께 기록한다.

## 2. 테스트 환경

| 항목 | 환경 |
|---|---|
| 게임 | Unity 6000.6.5f1, 원본 패키지·프로젝트 설정 |
| 실행 흐름 | 타이틀 → 시작 마을 → 1챕터 → 2챕터 → 마을 |
| 화면 | 1280×720, 1920×1080 |
| 입력 | 키보드·마우스·게임패드 |
| 서버·스크립트 검사 | Linux amd64, Go 1.27.3, Python·Node.js |
| 시험 데이터 | 메모리 프로필·임시 DB·합성 플레이 기록 |
