# Combat Events

전투 시스템이 생산하는 이벤트의 계약은 [Event System SSOT](../event-system/ssot.md)가 소유한다. 전투 상태와 결과의 규칙은 [Combat Domain SSOT](../../30-domain/combat/ssot.md)를 참조한다.

현재 후보 이벤트와 payload의 확정 여부는 이벤트 SSOT와 [J 작업](../../wiki/06-delivery/tasks/J-delivery-operations/_index.md)을 함께 확인한다.
