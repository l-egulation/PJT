현재 적용된 네 종류

이미지는 현재 Unity에서 사용하는 실제 PNG입니다. 도감의 중첩 이미지는 원본 발 피벗과 런타임 판정 수식으로 재구성했으며, 플레이 화면 캡처는 아닙니다. 청색은 공격을 받는 몸통, 적색은 데미지를 주는 영역, 황토색은 갈고리 포획입니다. 방향 전환 시 X 오프셋도 함께 반전됩니다.

SHARED RULES

네 종류에 공통으로 적용되는 규칙

감지와 추적

  • 최초 감지는 좌우 10u, 발 높이 차이 4u 이내. 원형 반경이 아니라 축별 조건입니다. 감지 주기는 0.1초, 경로 갱신은 0.25초입니다.
  • 대상의 중심·상단·하단 중 하나라도 보여야 합니다. 시야 검사에서는 발판도 차폐물에 포함합니다.
  • 추적 중 가로 10u를 벗어났다고 즉시 해제하지는 않습니다. 시야 상실 시 마지막 확인 위치로 이동하고, 1.5초 탐색 대기 후 복귀합니다.
  • 스폰 위치에서 가로 16u 이상 벗어나면 복귀합니다. 재교전은 본체가 스폰 기준 16u 안쪽, 대상이 스폰 기준 14u 이내이고 경로 또는 공격 조건을 충족해야 합니다.
  • 유효한 분신을 감지하면 다음 타깃 판단에 영향을 줍니다. 이미 시작한 공격 중에는 타깃을 바꾸거나 방향을 다시 조준하지 않습니다.
  • 안전한 지지면을 따라 수평 이동합니다. 절벽·벽에 막히면 멈추며, 복잡한 점프·벽타기·다층 우회 AI가 구현된 것은 아닙니다.

평상시 배회 · 성능 정책

피격 · 충돌 · 사망

  • 몸통 물리 박스와 별도의 트리거 피격 박스를 사용하되 현재 크기·중심은 동일합니다. 몸통은 지형과 충돌하며 캐릭터끼리는 통과합니다. 단순 접촉 데미지는 없습니다.
  • 몬스터의 피격 영역은 프레임마다 팔다리를 따라 바뀌지 않는 고정 AABB입니다. 긴 무기·갈고리·투명 캔버스 전체를 피격 영역으로 취급하지 않습니다.
  • 유효 피격은 진행 중 공격을 취소하고 최소 0.3초 경직을 적용합니다. 공통 기본 공격 반응도 경직 0.3초이며 중첩 합산하지 않습니다.
  • 플레이어 기본 공격의 별도 밀치기 지정이 없으면 0.25u를 0.1초 동안 밀칩니다. 특수 공격의 밀치기·속박·기절은 해당 무기 설정을 따릅니다.
  • 수문장도 현재 구현에서는 isBoss=false입니다. 엘리트라는 이름만으로 경직·넉백 면역이 부여되지 않습니다.
  • 별도 종별 방어력·속성 저항·슈퍼아머 수치는 네 종 정의에 없습니다. 표시 공격력은 플레이어 무적·방어 등의 수신 처리를 하기 전 기본 피해입니다.
  • 사망 즉시 공격을 취소합니다. 인벤토리 바인딩의 사망 처리 시 몸통·피격 콜라이더를 비활성화하며, 사망 모션 길이는 종별 표에 표시합니다.
  • 현재 기본 인벤토리 바인딩에서 네 종 모두 FieldMouseEnemy이므로, 별도 InkDropSource가 없으면 field_mouse 드롭 테이블을 사용합니다. 이 기본 테이블은 힘의 잉크 1개이며, 종별 사망 모션 시간이 지난 뒤 생성됩니다. 종별 고유 전리품 표는 연결되어 있지 않습니다.

이 도감은 현재 마을 랜덤 테스트 씬 Chapter1Procedural.unity 기준입니다. 이전 숲·들판 씬의 구형 몬스터와 구분해야 합니다. 맵 시드에 따라 배치 수는 달라질 수 있으며 여기의 수치는 개체 기본값입니다. AI를 정지한 테스트 상태에서는 배회·추격·공격이 실행되지 않습니다.

SOURCE OF TRUTH

수치와 이미지의 기준 원본

현재 작업본의 데이터와 코드로 생성한 스냅샷입니다. Unity 카탈로그가 기준 데이터의 내보내기 결과와 같은지, 모든 수록 프레임이 원본 SHA-256과 같은지 생성 시 검사합니다. 파일 하나에 이미지와 코드를 모두 포함하므로 HTML만 전달해도 오프라인에서 열립니다.

다시 생성하는 방법

저장소 루트에서 Python + Pillow로 tools/monster-reference/build.py를 실행합니다. 출력은 outputs/monster-reference/index.html과 개별 판정 PNG입니다. 게임 수치는 이 HTML에서 수정하지 않고 기준 데이터에서 편집 후 내보내기·재생성을 진행합니다.

실제 PNG + 판정 수식 시각화 · 1u = 원본 32픽셀 · 좌표 원점은 몬스터 발 위치 · 상호작용 화면은 지형·타깃 충돌이 없는 독립 공격 1회 예시입니다. 실전에서는 지형 차폐·경직·피격 취소·타깃 무적 등에 따라 결과가 달라집니다.
