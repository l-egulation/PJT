# 맵과 챕터 기획

[분야 개요](README.md)

## 목적과 기준

한 챕터를 이동·전투·탐험이 연결된 공간으로 이해하기 위한 문서다. 규모와 이동 정책은 [런 구조](../run/run-structure.md), 충돌·낙사·카메라 요구는 [전투 명세](../combat/rules.md)가 기준이다.

## 확정 사항

- 전체 3챕터, 목표 플레이 시간 45~60분, 챕터당 일반 전투 맵 8개다.
- 챕터 안은 방 없이 자유 이동한다. 일반 전투 맵은 콘텐츠 규모의 단위이며 독립 방·전멸 잠금 출구를 뜻하지 않는다.
- 챕터끼리는 물리적으로 이어지지 않으며 이전 챕터로 돌아갈 수 없다.
- 고정 제작 맵과 절차 생성 맵을 수용할 기술 경계를 둔다. 1챕터는 랜덤 스테이지를 1차 채택했으며 이후 바뀔 수 있다. 2·3챕터의 공급 방식은 미정이다.
- 지형 충돌 몸, 피해 수신 영역, 공격 판정을 구분한다. 고체와 일방향 발판은 역할에 맞는 이동·차폐 규칙을 적용한다.

## 1챕터 보스방 배경

승인한 시계탑 길목·보스방은 [제작 원본](../../../resources/README.md)을 사용한다. 마을의 따뜻한 크림색과 얇은 스케치 선을 유지하며, 최대 6유닛 높이의 길목에서 낡은 회벽이 점차 마을 원경을 가린다. 안쪽에서는 기둥·도르레·회전 톱니가 보스방을 예고한다.

`Chapter1BossBackdrop`이 17유닛 연결 구간과 30유닛 보스방에 후면 장식을 배치한다. 연결부 장식의 가로 배치 위치는 실제 통로 폭에 맞춘다. 보스방의 톱니는 천천히 회전하고 작은 잔해가 떠다닌다. 배경은 캐릭터·보스·기존 지형 뒤에 그리며 충돌체를 추가하지 않는다. 바닥 타일과 기존 전투·카메라 규칙은 각 원본을 따른다. 배치 및 색상은 승인본의 `unity-layout.json`, 사용 텍스처는 Unity `Resources/ClockBossEnvironment`에서 관리한다.

## 미정 사항

2·3챕터의 지형과 테마 구성, 일반 전투 맵 8개 목표와 1챕터 전투방 10개의 관계, 보스 패턴, 1챕터 출구의 위치·연출, 2챕터 전환 방식, 2·3챕터 공급 방식이 남아 있다. 벽 점프 해금과 맵 끝 시각 여백도 후속 설계다.

## 작업 전달 항목

맵을 넘길 때는 대상 챕터·모듈 ID, 시작·이동·상호작용 앵커, 고체·일방향 발판·위험 구간, 요구 이동 능력, 사용 에셋 버전, 현재 검증 범위를 함께 명시한다. 몬스터가 못 가는 지형을 플레이어도 못 가는 지형으로 오해하지 않는다. 공급·연결도 검증과 실제 이동·화면 검증은 별도로 수행한다.
