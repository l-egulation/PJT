# 보석 콘텐츠 수치화 계획

## 목적

[보석 SSOT](../../30-domain/gems/ssot.md)의 확정 규칙과 [승인 설계](./design.md)를 구현 가능한 콘텐츠 버전으로 옮기는 작업을 관리한다. 현재 정식 던전 v2 수치와 보존된 이전 버전은 [보석 콘텐츠 v1](../../60-content/gems/mvp-v1.md)이 소유한다.

## 확정된 입력

- 1-5 해금, 메인 스테이지·생존형·폭주형·장갑형별 6슬롯 프리셋 4개와 콘텐츠 일치 프리셋 적용
- 메인 프리셋은 언제든 변경 가능하며 진행 중 변경 시 현재 스테이지 0/20 재시작, 보석 던전 프리셋은 도전 시작 후 종료까지 변경 금지
- 1~7레벨, 같은 레벨 3:1 합성, 수동 선택·옵션별 소비 수량 지정 안전 일괄 합성과 결과 옵션 재추첨
- 1~5·6·7레벨별 옵션 풀과 확률
- 보석별 수동 잠금·해제, 특수 옵션 보석 자동 잠금, 잠금 보석의 프리셋 사용 허용과 합성·거래 등록 금지
- 고정 옵션 합산과 종류별 특수 옵션 최고값 하나 적용
- 보석함 귀속, 보석 거래 가능, 1·2·3레벨 `85:10:5` 결과 확률과 1개·지정 수량·전체 일괄 개봉
- 보석 판매 등록 전 모든 프리셋 직접 해제·잠금 직접 해제, 등록 시 자동 해제 없음
- MVP 계정 공용 인벤토리 고정 200슬롯·확장 없음, 보석 인스턴스당 1슬롯, 보석함 중첩 1슬롯과 소비·지급 전 필요 슬롯 검사
- 보석 던전 시작 전 기존 보석함 스택 슬롯 지급 권리 또는 빈 슬롯의 보상 수용량 예약, 미보상 종료 시 예약 해제
- 서버 실제 경과시간 1시간당 입장권 1장, 최대 5장과 초기 3장
- 성공·소탕 보상 수령 시 차감, 실패·사용자 중단·앱 종료·연결 끊김 미차감·미보상과 도전 종료 시 프리셋 잠금 해제
- 도전 시작 시 시간 슬롯·보스·단계·프리셋·콘텐츠 버전·보상표 스냅샷 확정, 다음 정각 이후에도 해당 도전 완료 후 새 시간 슬롯 전환
- 보스별 독립 1~10단계 진행, 입장권이 남아 있는 동안 같은 시간 슬롯의 신규 단계 연속 도전, 최초 클리어와 최고 클리어 단계 전용 1회·지정 횟수·전체 일괄 소탕 보상
- 정식 v2 단계별 목표 진행 `1-5, 1-7, 1-10, 2-1, 2-4, 2-7, 2-10, 3-1, 3-4, 3-7`
- 세 보스의 1단계는 1-5 목표 성장 빌드가 무보석으로 클리어 가능하되 확정 클리어는 아닌 기준
- 3-1~4-10 보석 포함 적 수치 재산출 방향

## 남은 콘텐츠 산출

1. 정식 v2 생존형·폭주형·장갑형 1~10단계의 적용 HP·공격력·방어력·제한시간·강타 값이 현재 시뮬레이터에서 계속 재현되는지 검증한다.
2. 입장권 공급, 최초 클리어, 소탕, 보석함 RNG, 3:1 합성과 거래를 포함한 P10·P50·P90 보석 성장 분포를 계산한다.
3. 보석 기대 공급을 기준 빌드에 넣어 3-1~4-10 일반 몬스터와 보스를 별도 콘텐츠 버전으로 다시 산출한다.
4. 보석 포함 버전에서도 공격력·최대 HP·방어 관통 성장벽의 실패 원인이 유지되는지 검증한다.
5. 치명타·공격속도 seed별 전투 결과와 장시간 타이머 드리프트를 검증한다.

## 검증 순서

1. 보석 없이 [MVP 적 수치 v1](../../60-content/enemies/mvp-v1.md)의 회귀 기준을 보존한다.
2. 보석 옵션 확률·값·합산·상한을 단위 검증한다.
3. 입장권 충전·차감과 최초 클리어·소탕 보상의 멱등성을 검증한다.
4. 세 보스의 단계별 실패 원인이 목표 성장축과 일치하는지 검증한다.
5. 보석 공급과 거래를 포함한 장기 분포를 검증한다.
6. 3-1~4-10 보석 포함 적 수치가 일반 통과율과 성장벽을 보존하는지 확인한다.

## 출시 판단

보석 시스템 규칙과 정식 던전 v2 절대 수치는 `applied`다. 옵션·보상·기준 빌드의 버전별 이력은 [보석 콘텐츠 v1](../../60-content/gems/mvp-v1.md)이 소유한다. 장기 공급 분포와 보석 포함 메인 적 수치는 검증이 남아 있으므로 해당 범위만 `working`을 유지한다.
