채찍 스킬 몸 모션 — 에테르 입력 (2026-11-06)

모든 스킬이 같은 그림을 시작·끝에 쓴다.
기본 입력: whip-holding-6144x3072-white.png (시작·끝 모두)
업로드 크기 제한이 있을 때만 whip-holding-4096x2048-white.png 쌍으로 바꾼다. 두 규격을 시작·끝에 섞지 않는다.
투명본은 보존·다른 도구 입력용이다. 에테르에는 흰 배경본을 쓴다.
파일 원본을 업로드한다. 대화의 축소 미리보기를 캡처해 쓰지 않는다.
입력 그림은 확정 채찍 대기 F006(256x104, PPU32)을 24배(작은 판 16배) 최근접 확대한 것이다. 다시 칠하거나 색을 더하지 않았다.
위쪽 576px(작은 판 384px)은 머리 위로 휘두를 자리를 비운 것이다.

스킬마다 영어 프롬프트 파일 하나를 통째로 붙여 넣는다. 한 번에 한 스킬씩 뽑는다.
채찍 줄은 몸 그림의 일부다(검은 가는 줄). 이펙트(가시·매듭 빛·속박 표시)는 나중에 따로 만든다. 그래서 프롬프트는 이펙트 없는 몸+채찍만 요청한다.

| 파일 | 스킬 | 게임 시간(바꾸지 않음) | 꼭 보여야 하는 실루엣 |
|---|---|---|---|
| 01-whirl-wrap | 휘감기 (미장착) | 타격 0.25초 / 끝 0.60초 / 쿨 5초 | 먼 끝에 둥글게 감긴 고리, 손에서 고리까지 팽팽한 줄, 뒤로 버티는 몸 |
| 02-thorn-net | 가시 그물 (범위) | 타격 0.35초 / 끝 0.80초 / 쿨 8초 | 머리 위 둥근 회전, 높은 곳에서 먼 바닥까지 긴 대각선 채찍 |
| 03-knot-approach | 매듭 접근 (이동) | 타격 0.15초 / 끝 0.50초 / 쿨 7초 | 가슴 높이로 곧게 뻗은 가장 긴 수평 채찍, 앞으로 숙인 몸 |
| 03b-knot-pull-travel | 매듭 접근 끌려가기 | 다시 D 를 누르면 적 앞까지 날아가는 동안(속도 50) | 두 손으로 팽팽한 줄을 잡고 공중에서 앞으로 끌려가는 자세(제자리 반복) |
| 04-knot-tighten | 매듭 조이기 (후속타) | 타격 0.25초 / 끝 0.60초 / 조임 피해 0.85초 / 쿨 8초 | 먼 고리, 두 손으로 뒤로 세게 당기는 자세 |

생성 단계에서는 실루엣이 온전히 나오는 것을 우선한다. 클립 길이는 상관없다.
결과를 받은 뒤 프레임을 고르고 위 게임 시간에 맞춰 늘리고 줄인다. 최종 장 수는 결과를 보고 정한다.
받은 결과는 그대로 보존하고(리소스 저장소 source), 게임 크기 픽셀 적용본은 따로 만든다.

판정·피해·속박·쿨타임은 바꾸지 않는다(docs/design/systems/combat/melee.md 채찍 절).
지금 게임은 네 스킬 모두 기본 공격 1타 모션을 임시로 쓴다.
