정밀 조립 v2 — 전달 안내

이번 결과는 예상 이미지의 실제 프레임·아이콘을 분리하고, 글자와 숫자를 별도 레이어로 다시 조립한 결과입니다.
새 전체 화면을 AI로 생성하지 않았습니다.
v1에서 별도로 생성한 22개 파츠는 사용하지 않습니다. 이 폴더의 v2 파츠 30개가 새 기준입니다.

확인한 내용
- 모든 스프라이트 배치 크기 = PNG 원본 크기. 개별 이미지의 가로/세로를 늘리지 않았습니다.
- 원본에 있던 일시정지와 ESC 버튼은 크기가 다른 각각의 파츠입니다.
- 장착 병 테두리, 빨강 잉크 2개, 파랑 잉크 1개를 분리했습니다.
- 깃털펜, 구분선, 물방울은 원본 비율을 유지합니다.
- HP/EXP 수치와 레벨, 화폐 수량은 별도 글자로 배치합니다.
- 실제 게임 캡처 위에 파츠를 조립했습니다. Unity Game View에서 새로 촬영한 화면은 아닙니다.

원본과 남은 차이
- 글자는 미리보기용 Arial/맑은 고딕으로 다시 렌더링했으므로 생성 이미지의 글자와 완전히 같지는 않습니다.
- 프레임 안쪽의 기존 글자·그림을 제거한 빈 바탕은 원본에 맞춘 단색으로 복원했습니다.
- 외곽 투명도는 원본의 배경색을 제거하여 만들었습니다. 최종 엔진 임포트 후 밝은 배경·어두운 배경에서 가장자리를 확인하세요.
- 원본 예상 이미지의 EXP 40/100과 파란 채움 길이는 수학적으로 일치하지 않습니다. 이번에는 요청한 외형 비교를 위해 원본 길이를 유지했습니다. 실제 연동 시 current/max로 계산하세요.

Unity 배치 방법
1. UnityReady/Assets/Deviant/UI를 프로젝트 Assets에 복사합니다.
2. Canvas Scaler를 Scale With Screen Size / Reference Resolution 1672 x 941로 설정합니다.
3. 모든 PNG의 PPU는 100, Image는 Simple, Preserve Aspect를 사용합니다.
4. RectTransform의 앵커·피벗을 왼쪽 위 (0,1)에 맞춥니다.
5. layout.json 순서대로 파츠를 만들고 anchoredPosition=(x,-y), sizeDelta=(w,h)를 지정합니다.
6. Canvas 전체에 동일 배율이 적용되도록 합니다. 파츠마다 서로 다른 가로/세로 배율로 맞추지 않습니다.
7. 아이콘 내부 글자를 추가하지 말고 text 레코드를 TMP로 구현합니다. 한글 지원 TMP 폰트가 필요합니다.
8. 원래 기준에서 더 작게 만들려면 전체 HUD 그룹에 동일한 배율을 적용합니다. 아이콘만 세로로 압축하지 않습니다.

게이지와 잉크
- hp_fill / exp_fill은 현재 길이의 시안용 파츠입니다. 폭을 바꾸려면 끝부분 형태를 보존하는 9-slice 또는 마스크 기반 게이지를 따로 구성하세요. Image 전체 가로 Stretch는 피하세요.
- active_bottle_shell은 빈 병 테두리이며 ink_insert_*를 별도로 안에 배치합니다.
- 다른 색상과 다양한 장착량은 별도 게임 데이터로 연결합니다.
- 이 단계는 확정 외형을 다시 맞추는 파츠 전달이며, Unity 씬 수정·프리팹 생성·실시간 게임 상태 연결은 포함하지 않았습니다.
