# 전체 콘텐츠 퀘스트·튜토리얼 맵

## 1. 결론

한짝의 온보딩은 하나의 긴 강제 튜토리얼이 아니라 다음 세 장치가 함께 작동해야 한다.

1. **마을 복구 의뢰**
   - 챕터와 스테이지를 진행할 이유를 만드는 메인 여정이다.
2. **한짝 성장 수첩**
   - 장비·스킬·보석·치장·거래소를 처음 제대로 사용하는 일회성 성장 퀘스트다.
3. **상황 가이드**
   - 기능이 열리거나 플레이어가 막힌 순간에만 1~3단계로 조작을 알려준다.

1-5의 보석·던전·치장 개방은 세 장치 가운데 `성장 수첩 추가 + 기능 개방 안내 + 선택한 기능의 상황 가이드`가 동시에 예약되는 사례다. 온보딩 전체의 시작점은 아니다.

## 2. 퀘스트와 튜토리얼을 나누는 기준

| 장치 | 사용 목적 | 완료 근거 | 보상 원칙 |
| --- | --- | --- | --- |
| 퀘스트 | 플레이할 이유와 다음 목표 제시 | 서버가 확정한 게임 상태 변화 | 별도 정책이 확정되기 전에는 기존 보상과 완료 도장만 사용 |
| 튜토리얼 | 화면 조작과 규칙 이해 | 화면 방문·대상 조작·확인 | 보상 없음 |
| 안내 | 새 기능·결과·위험 고지 | 사용자가 내용을 확인 | 보상 없음 |
| 도움말 | 실패·정체 해소 | 사용자가 선택적으로 열람 | 보상 없음 |

다음 원칙을 모든 콘텐츠에 공통 적용한다.

- 퀘스트 완료를 버튼 클릭으로 판정하지 않는다. 실제 제작·클리어·획득·장착처럼 서버가 확정한 결과를 사용한다.
- 튜토리얼 완료는 기능 해금·재화 지급·전투 결과를 만들지 않는다.
- 아직 수행할 수 없는 행동은 목표로 주지 않는다.
- 사용자가 먼저 행동했다면 과거 상태를 대조해 자동 완료한다.
- 첫 설명 이후에는 반복 팝업 대신 기존 레드닷·배지·빈 상태 안내를 사용한다.
- 모든 콘텐츠를 퀘스트로 만들지 않는다. 설정·랭킹·채팅처럼 선택적인 기능은 첫 방문 가이드만 제공한다.

## 3. 플레이어 여정 구조

### 3.1 최초 진입: 세 가지만 이해시키기

최초 진입에서 이해해야 할 것은 다음 세 가지다.

1. 한짝은 자동으로 이동하고 전투한다.
2. 전투로 성장 자원을 얻는다.
3. 지금 할 만한 일은 의뢰서에서 확인한다.

주력 재료 선택은 게임 진입 전 필수 선택이므로 퀘스트로 위장하지 않는다. 선택이 되돌릴 수 없고 드롭에 영향을 준다는 점을 선택 화면에서 명확히 알린다.

첫 메인 화면에서는 공격 버튼을 찾게 만들지 않는다. 현재 스테이지·전투 진행·획득 패널을 한 번씩 짧게 강조하고 `첫 전투 결과 확인`을 최초 의뢰로 둔다.

### 3.2 첫 성장 경험: 상태가 준비될 때 시작

아이템·장비·스킬을 특정 스테이지 번호에 강제로 연결하지 않는다.

- 제작 가능한 재료가 모이면 장비 의뢰를 제안한다.
- 첫 스킬북을 실제로 얻으면 스킬 의뢰를 제안한다.
- 첫 실패가 발생하면 실패 원인과 맞는 성장 기능을 연결한다.
- 기능을 먼저 사용한 플레이어는 해당 입문 의뢰를 자동 완료한다.

### 3.3 기능 개방: 한 번에 설명하지 않고 갈라서 배우기

여러 기능이 동시에 열려도 한 화면에서 개방 사실만 묶어 보여준다. 이후 플레이어가 고른 기능의 성장 수첩만 활성화한다.

예를 들어 1-5 최초 클리어 뒤에는 보석·던전·치장 개방을 한 번에 알리고 다음 중 하나를 먼저 선택하게 한다.

- 보석 던전 둘러보기
- 치장 둘러보기
- 나중에 보기

선택하지 않은 기능은 `NEW` 상태만 유지하고 첫 방문 시 가이드를 시작한다.

### 3.4 장기 진행: 챕터는 이야기, 시스템은 숙련

메인 의뢰는 각 챕터의 가게를 되찾는 이야기 목표를 제공한다. 성장 수첩은 플레이어가 새 등급·새 재료 세대·새 기능을 실제로 만날 때만 추가된다.

챕터의 성장벽 보스는 내부 유형을 화면에 직접 노출하지 않는다. 실패 결과를 사용자 언어로 바꾸어 적절한 성장 기능으로 연결한다.

| 내부 전투 상황 | 사용자 안내 | 연결할 성장 기능 |
| --- | --- | --- |
| 제한 시간 안에 피해 부족 | `조금만 더 빠르게 몰아붙이면 이길 수 있어요.` | 무기·장갑, 공격 액티브, 공격 계열 보석 |
| 예약 강타를 견디지 못함 | `강한 한 방을 버틸 준비가 필요해요.` | 갑옷·투구, 최대 HP 계열 보석 |
| 높은 방어력에 피해가 낮음 | `단단한 상대에게 공격이 잘 들어가지 않아요.` | 망토·신발, 방어 관통 계열 보석 |
| 일반 사망·보스 실패 | 최근 전투 기록의 실제 원인 요약 | 현재 수행 가능한 성장 행동 하나 |

이 안내는 해당 보스를 처음 보는 순간이 아니라 실제로 실패했을 때만 제안한다.

## 4. 전체 콘텐츠 매핑

### 4.1 계정·첫 진입·메인 전투

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 회원가입·로그인 | 퀘스트로 만들지 않음 | 입력 오류, 소셜 신규 사용자의 닉네임 확정, 비밀번호 재설정 흐름만 단계별 안내 | 사용자가 해당 인증 흐름 선택 | 인증 성공 후 종료 |
| 주력 재료 선택 | 퀘스트로 만들지 않음 | 영구 선택과 드롭 영향 고지, 세 선택지 비교 | 최초 로그인 후 미선택 상태 | 선택 완료 후 재노출 없음 |
| 자동 이동·전투 | `첫 전투 결과 확인` | 현재 적·내 HP·스테이지 진행·자동 전투임을 비차단 강조 | 첫 메인 화면 진입 | 첫 전투 결과 확인 후 완료 |
| 전투 보상·획득 패널 | `방금 얻은 전리품 확인` | 쌀·아이템 누적 위치와 스테이지 이동 시 체류 누적이 바뀜을 첫 1회 설명 | 첫 확정 보상 발생 | 이후 패널 자체와 레드닷 사용 |
| 레벨·경험치 | `첫 성장 확인` | 첫 레벨업 때 공격력·최대 HP 증가와 경험치 바를 연결 | 첫 레벨업 확정 | 이후 레벨업 연출만 사용 |
| 캐릭터 능력치 | 성장 수첩의 선택 목표 | 합계·기본·추가 스탯과 출처 상세을 첫 방문에 설명 | 캐릭터 창 첫 방문 또는 성장 원인 확인 필요 | 다시 보기는 도움말에서 제공 |

### 4.2 챕터·스테이지·전투 결과

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 챕터 진행 | `점령된 가게 되찾기` 메인 의뢰 | 현재 전투 챕터와 진행 목표 챕터의 차이를 첫 방문에 설명 | 첫 스테이지 클리어 후 또는 챕터 화면 첫 방문 | 챕터별 새 메인 의뢰만 갱신 |
| 스테이지 선택 | 선택 목표로 두지 않고 메인 의뢰의 바로 가기로 사용 | 클리어·현재·잠금·반복 상태와 상세 정보 확인법 안내 | 스테이지 화면 첫 방문 | 상태 범례 도움말로 전환 |
| 자동 진행·스테이지 반복 | 첫 파밍 필요 시 `원하는 장소에서 재료 모으기` | 전환은 다음 사이클에 적용됨을 확인 문구로 안내 | 첫 실패 후 파밍 필요 또는 사용자가 토글 선택 | 첫 사용 뒤 반복 팝업 없음 |
| 일반 스테이지 클리어 | 메인 의뢰 진행량으로만 반영 | 짧은 완료 도장과 다음 목표 | 서버 클리어 확정 | 같은 스테이지 재클리어에는 의뢰 연출 없음 |
| 챕터 최종 보스 | `가게의 주방 되찾기` 같은 챕터 결산 의뢰 | 단독 보스전임을 짧게 안내하고 결과 후 다음 챕터 개방 표시 | 챕터 마지막 스테이지 진입·클리어 | 챕터당 한 번 |
| 전투 실패·최근 기록 | 퀘스트 실패로 처리하지 않음 | 실패 원인·남은 HP·진행 수를 보여주고 가능한 성장 행동 하나 추천 | 서버 실패 기록 확정 | 같은 원인 연속 노출은 요약 카드로 축소 |

메인 의뢰의 실제 이름과 가게별 사건은 Story의 현재 미해결 사항이 확정된 뒤 콘텐츠 데이터로 작성한다. 이 계획의 이름은 경험 제안이며 서사 정본이 아니다.

### 4.3 아이템·인벤토리

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 강화 재료 | 첫 제작·강화 의뢰의 재료로 자연스럽게 사용 | 주력·비주력 재료와 세대 표시는 아이템 상세에서 설명 | 제작 가능한 행동이 생김 | 일반 재료 획득마다 안내하지 않음 |
| 스킬북 | `새 비법 익히기` 성장 의뢰 | 책과 연결 스킬, 등급, 사용처 강조 | 첫 스킬북 실제 획득 | 스킬별 첫 획득 이후 레드닷 사용 |
| 보석·보석함 | 보석 성장 수첩에 연결 | 보석함과 결과 보석의 차이, 공간 필요, 잠금 상태 설명 | 해당 아이템 첫 획득 | 각 종류 첫 1회 |
| 치장 선택 상자 | `원하는 전설 치장 고르기` 선택 의뢰 | 세트 선택 후 부위 선택의 2단계를 소비 전에 안내 | 실제 사용 가능한 상자 보유 | 상자 첫 사용 뒤 도움말로 전환 |
| 인벤토리 용량 | 퀘스트로 만들지 않음 | 사용량과 공간 부족으로 건너뛴 지급을 즉시 경고 | 여유 슬롯 부족 또는 지급 건너뜀 발생 | 상태가 해소될 때까지 고정 경고 하나 |

아이템 상세를 여는 것 자체보다 실제 성장 행동으로 이어지는지를 우선한다. 일반 재료를 얻을 때마다 퀘스트를 추가하면 방치 흐름을 방해하므로 금지한다.

### 4.4 장비

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 최초 제작 | `첫 장비 마련하기` | 6부위가 각각 하나의 영구 성장 상태이며 별도 장착이 필요 없음을 설명 | 한 부위 이상 실제 제작 가능 | 첫 제작 뒤 나머지는 목록 목표로 축소 |
| 강화 | `장비 한 번 강화하기` | 현재/다음 수치, 재료·쌀, 확정 적용을 실행 전에 설명 | 제작 장비와 강화 비용 보유 | 첫 강화 뒤 서버 결과 태그만 사용 |
| 부족 재료 구매 | `부족한 재료 구해오기` | 재료 하나 선택, 허용 단가, 부분 체결 가능성을 확인 단계에서 설명 | 강화 재료 부족 + 구매 가능한 시장 품목 | 첫 구매 뒤 거래소 공통 확인 사용 |
| 등급 승급 | 챕터 결산 뒤 조건이 모두 갖춰졌을 때 성장 의뢰 추가 | 챕터 클리어와 장비 성장 조건을 함께 보여줌 | 실제 승급 가능 상태 | 등급별 첫 승급 때만 강조 |
| 전투 반영 | 별도 퀘스트 없음 | 서버가 반환한 전투력 증가 태그와 다음 사이클 반영 안내 | 제작·강화·승급 성공 | 기존 결과 표현 유지 |

장비 성공마다 전체 화면 축하를 추가하지 않는다. 현재 UX 기준의 작은 전투력 증가 피드백을 유지한다.

| 액티브 장착 | `새 기술을 전투에 넣기` | 4슬롯, 위에서부터 자동 사용 우선순위를 직접 한 번 구성 | 첫 액티브 해금 | 첫 저장 후 자유 편집 |
| 패시브 | 퀘스트로 만들지 않음 | 해금 즉시 항상 적용되고 슬롯을 쓰지 않음을 결과에서 안내 | 첫 패시브 해금 | 첫 패시브 한 번만 |
| 강화 | `비법 다듬기` 선택 의뢰 | 성공률·비용·실패 보정과 실패 시 소비를 확인 전에 강조 | 첫 강화 가능 상태 | 첫 시도 뒤 일반 결과 UI 사용 |
| 승급 | 등급 조건 충족 시 성장 의뢰 | 현재/다음 효과와 확정 승급 조건 안내 | 실제 승급 가능 상태 | 등급별 첫 승급 한 번 |
| 자동 전투 연출 | 퀘스트 없음 | 새 액티브가 전투에서 처음 발동할 때 이름표를 짧게 표시 | 장착 후 첫 실제 발동 | 스킬별 첫 발동 이후 생략 |

스킬북은 스테이지별 드롭 풀에 순차 추가되지만 획득이 확률이므로 스테이지 도달을 튜토리얼 트리거로 사용하지 않는다. 실제 획득과 사용 가능 상태를 기준으로 한다.

### 4.6 보석·프리셋

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 보석 콘텐츠 개방 | `새로운 성장법 살펴보기` | 개방 사실과 보석 탭·던전 진입 위치만 알림 | 서버 해금 상태 최초 확인 | 개방 안내 한 번 |
| 보석함 개봉 | `첫 보석 꺼내기` | 보석함 소비, 결과 보석, 인벤토리 공간을 실행 전에 설명 | 보석함 실제 보유 | 첫 개봉 뒤 일괄 개봉 도움말만 유지 |
| 보석 장착 | `보석을 전투에 연결하기` | 슬롯에 배치하는 것과 프리셋을 전투 유형에 연결하는 것을 분리해 안내 | 장착 가능한 보석 보유 | 첫 연결 후 완료 |
| 프리셋 관리 | `전투에 맞는 보석판 만들기` | 같은 보석의 복수 프리셋 사용, 전투 유형별 연결, 메인 연결 변경의 전투 재시작 영향 안내 | 둘 이상의 전투 유형 또는 프리셋 편집 진입 | 위험 확인 문구만 유지 |
| 수동 합성 | `같은 보석을 모아 합성하기` | 사용할 수 없는 장착·잠금·판매 보석을 구분 | 실제 합성 가능한 조합 보유 | 첫 합성 뒤 일반 확인 사용 |
| 일괄 합성 | 선택형 숙련 의뢰 | 목표 레벨·옵션 필터·예상 횟수·보존 대상을 실행 전에 설명 | 안전 대상과 실행 가능 조합 보유 | 첫 사용 뒤 도움말로 전환 |
| 잠금·거래 준비 | 퀘스트로 만들지 않음 | 특수 옵션 자동 잠금, 판매 전 해제 조건을 해당 실패 시점에 안내 | 잠금 변경 또는 판매 시도 | 오류 원인별 한 번 |

보석 입문을 개방 직후 한 번에 끝내지 않는다. `던전 클리어 → 보석함 획득 → 개봉 → 장착 → 합성 가능해짐`의 실제 자원 흐름에 따라 수첩이 순서대로 열린다.

### 4.7 보석 던전

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 던전 첫 방문 | `오늘의 보스 확인하기` | 현재 열린 보스, 입장권, 다음 단계, 예상 보상 위치 안내 | 던전 해금 후 첫 방문 | 첫 방문 뒤 요약 HUD 사용 |
| 첫 신규 단계 도전 | `첫 보석 던전 도전` | 보스 유형의 승리 조건과 적용 프리셋을 시작 전에 확인 | 입장권·공간·도전 가능 상태 | 보스 유형별 첫 도전 한 번 |
| 첫 클리어 | `보석함 받아오기` | 서버 확정 보상과 다음 단계 개방 표시 | 던전 성공 확정 | 단계마다 팝업 없이 최고 단계 갱신 |
| 첫 실패·중단 | 퀘스트 실패로 처리하지 않음 | 소비·보상 결과와 추천 성장 방향을 실제 서버 결과로 안내 | 실패·중단 확정 | 같은 원인은 축약 안내 |
| 소탕 | `전에 이긴 보스를 빠르게 정리하기` 선택 의뢰 | 대상 단계·횟수·소비·예상 보상 확인 | 소탕 가능한 최고 단계와 입장권 보유 | 첫 소탕 뒤 일반 확인 사용 |
| 보스 순환 | 퀘스트로 만들지 않음 | 현재 보스와 변경 시각을 상시 표시 | 던전 화면·메인 요약 | 별도 팝업 없음 |

세 보스의 서로 다른 승리 조건은 각 유형의 첫 도전에서만 가르친다. 사용자가 이미 해당 유형을 클리어했다면 해당 안내는 완료 처리한다.

### 4.8 치장·뽑기·도감

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 치장 콘텐츠 개방 | `한짝의 새 모습 살펴보기` | 개방과 최초 지급 재화, 치장 진입 위치 안내 | 서버 해금 상태 최초 확인 | 개방 안내 한 번 |
| 첫 뽑기 | `첫 치장 만나기` | 티켓 우선 결제, 쌀 사용 가능성, 공개 확률과 결과 확정 시점을 실행 전에 안내 | 실행 가능한 지급 재화 보유 | 첫 실행 뒤 공통 확인 사용 |
| 첫 치장 획득 | `새 옷 입어보기` | 최초 획득은 등록·외형 해금, 미리보기와 실제 착용의 차이 안내 | 등록 치장 첫 보유 | 첫 착용 뒤 자유 편집 |

| 도감 | `새로 완성된 기록 확인하기` | 등록 수량·성급·세트 이동과 미보유 필터를 첫 방문에 안내 | 첫 치장 보유 또는 도감 첫 방문 | 다시 보기는 도움말 |
| 세트 완성 | `의상 한 벌 완성하기` 장기 성장 의뢰 | 세트 성급과 보유 효과, 착용 여부와 효과가 별개임을 완료 시 안내 | 실제 세트 완성 또는 성급 상승 | 세트별 첫 완성·성급 상승 때만 |
| 마일스톤 선택 상자 | `원하는 전설 치장 고르기` | 수령과 사용을 분리하고 세트→부위 선택을 소비 전에 설명 | 실제 수령 가능 또는 상자 보유 | 첫 수령·첫 사용 각각 한 번 |

무료로 지급된 재화가 있더라도 자동 뽑기를 실행하지 않는다. 사용자가 확률과 소비 재화를 확인한 뒤 직접 실행해야 한다.

### 4.9 거래소·우편

| 콘텐츠 | 퀘스트로 푸는 방식 | 튜토리얼·안내 방식 | 시작 조건 | 반복 노출 방지 |
| --- | --- | --- | --- | --- |
| 품목 탐색 | 독립 퀘스트보다 부족 재료 해결 의뢰에서 진입 | 카테고리·검색·가격대별 물량과 내 물량 구분 안내 | 거래소 첫 방문 또는 부족 재료 바로 가기 | 첫 방문 뒤 도움말 |
| 즉시 구매 | `부족한 재료 사오기` | 수량·최대 단가·예상 체결과 부분 체결을 확인 | 실제 구매 목적과 사용 가능 쌀 존재 | 첫 구매 뒤 확인 화면 유지 |

| 주문 수정·취소 | 퀘스트 없음 | 우선순위·예약 자산 변화가 있는 경우 확인에서 설명 | 해당 행동 선택 | 확인 문구만 유지 |

| 일반 우편 | 퀘스트로 만들지 않음 | 개별·전체 수령과 첨부 상태만 첫 사용 안내 | 첫 첨부 우편 도착 | 이후 숫자 배지 사용 |

랭킹에는 현재 시즌·보상 규칙이 없으므로 경쟁 퀘스트나 순위 달성 보상을 만들지 않는다.

## 5. 메인 의뢰 구성 후보

메인 의뢰는 기능 체크리스트가 아니라 세계관의 `가게 복구`를 전면에 둔다.

```text
마을 복구 의뢰
├─ 현재 가게 조사
├─ 일반 몬스터 구역 돌파
├─ 가게 안쪽 진입
├─ 최종 보스 처치
└─ 다음 가게 개방
```

- 실제 스테이지 클리어와 챕터 해금 상태로 진행한다.
- 장비·스킬 메뉴 방문 같은 UI 행동을 메인 의뢰에 섞지 않는다.
- 성장 행동은 별도의 성장 수첩에서 선택적으로 안내한다.
- 가게별 퀘스트 이름·대사·사건은 Story의 미해결 서사가 확정된 뒤 작성한다.

챕터 중간의 성장벽은 메인 의뢰를 실패시키는 것이 아니라 `정비 제안`을 여는 트리거다. 플레이어가 별도 성장 없이 통과하면 제안을 보여주지 않는다.

한짝 성장 수첩

│  └─ 캐릭터 능력치 확인

│  └─ 첫 승급

│  ├─ 첫 해금
│  ├─ 첫 액티브 장착
│  └─ 첫 강화
├─ 보석
│  ├─ 던전 첫 클리어
│  ├─ 보석함 첫 개봉

목록은 처음부터 전부 보이지 않는다. 기능이 열리고 완료 가능한 상태가 되었을 때 한 항목씩 추가한다.

## 7. 튜토리얼 표현 방식

### 7.1 네 가지 공통 컴포넌트

1. **의뢰서 카드**
   - 현재 목표 하나와 바로 가기만 표시한다.
2. **대상 강조**
   - 화면을 완전히 잠그지 않고 대상 한 곳에 외곽선과 화살표를 준다.
3. **소비 전 확인 설명**
   - 확률·재화·거래·합성처럼 되돌리기 어려운 행동을 실행 직전에 설명한다.
4. **결과 도장**
   - 서버 성공 뒤 짧게 완료를 알리고 다음 행동이 있을 때만 연결한다.

### 7.2 방해 강도

| 강도 | 사용 시점 | 예시 |
| --- | --- | --- |
| 전체 화면 | 첫 진입의 핵심 전환, 여러 기능 동시 개방 | 주력 재료 선택 완료, 1-5 개방 묶음 |
| 반차단 강조 | 첫 핵심 조작, 소비 전 필수 확인 | 첫 스킬 장착, 첫 뽑기 결제 확인 |
| 비차단 카드 | 다음 목표·성장 제안 | 의뢰서, 실패 후 정비 제안 |
| 인라인 안내 | 반복 사용·오류·빈 상태 | 재료 부족, 공간 부족, 잠금 보석 |

전체 화면 연출은 전투 중이 아니라 결과 연출이 끝난 안전한 시점에만 예약한다.

## 8. 이벤트·상태 설계 후보

퀘스트와 가이드 정의는 분리한다.

```text
QuestDefinition
├─ questId
├─ category: MAIN | GROWTH | DISCOVERY
├─ eligibilityCondition
├─ completionCondition
├─ destination
├─ copyKey
└─ rewardPolicy

GuideDefinition
├─ guideId
├─ featureKey
├─ triggerCondition
├─ safePresentationPoint
├─ steps
├─ dismissPolicy
└─ replayPolicy
```

상태 후보:

```text
QuestProgress
├─ status: LOCKED | AVAILABLE | ACTIVE | COMPLETED
├─ currentValue
└─ completedAt

GuideProgress
├─ status: NOT_SEEN | ACTIVE | COMPLETED | DISMISSED
├─ currentStepId
├─ lastPresentedAt
└─ version
```

진행 재구성에 필요한 사건 후보:

- 스테이지·챕터 최초 클리어
- 기능 해금
- 레벨업
- 아이템·스킬북·보석함·치장 획득
- 장비 제작·강화·승급
- 스킬 해금·장착 저장·강화·승급
- 던전 입장·클리어·실패·소탕
- 보석함 개봉·장착·프리셋 연결·합성
- 치장 뽑기·착용·등록·세트 완성
- 거래 주문·체결·수령·정산
- 오프라인 보상 청구

실제 이벤트 명칭과 저장 책임은 Quest SSOT와 Event System 설계 시 확정한다. 현재 문서에는 퀘스트 도메인 정본이 없으므로 이 목록은 구현 계약이 아니다.

## 9. 복귀·건너뛰기·상태 보정

- 계정 단위로 완료한 가이드는 다른 기기에서 반복하지 않는 안을 권장한다.
- 화면 강조 위치, 접힌 카드와 같은 표현 상태만 로컬에 둘 수 있다.
- 플레이어가 가이드보다 먼저 기능을 사용하면 서버 상태를 읽어 자동 완료한다.
- 버전 업데이트로 단계가 추가되어도 기존 완료 사용자를 처음부터 되돌리지 않는다.
- 전체 온보딩 건너뛰기와 새 기능 개방 안내 끄기는 분리한다.
- 다시 보기는 안내만 재생하며 보상·해금·구매·뽑기를 자동 실행하지 않는다.
- 대상 UI가 사라지거나 이름이 바뀌면 화면을 잠그지 않고 설명 카드로 대체한다.

## 10. 하지 않는 것

- 모든 메뉴를 차례대로 누르게 하는 최초 진입 강제 투어
- 매일 접속·반복 클릭을 요구하는 일일 퀘스트
- 아직 잠긴 기능의 사용법 선행 설명
- 시장 물량에 따라 실패할 수 있는 거래를 필수 메인 퀘스트로 지정
- 뽑기·합성·구매·등록의 자동 실행
- 실패하지 않은 플레이어에게 성장벽 공략법 선행 노출
- 설정·채팅·PIP 사용을 성장 보상 조건으로 지정
- 퀘스트 완료를 콘텐츠 해금의 권한으로 사용

## 11. 현재 범위에서 제외할 콘텐츠

다음 항목은 현재 기준에서 실제 튜토리얼·퀘스트를 만들지 않는다.

- 레이드: 준비 중 잠금만 표시하며 실제 입장·전투·보상은 미래 범위다.
- 아레나: 현재 책임 SSOT와 MVP 범위가 없다.
- 길드·친구·파티: Social SSOT가 없다.
- 빠른 전투: MVP 시스템과 UI에서 명시적으로 제외됐다.
- 챕터 5 이후와 전설 스킬북 획득 경로: 미래 범위이거나 미확정이다.
- 랭킹 시즌·보상: 현재 MVP 랭킹 범위가 아니다.
- 도감 단계·도감 단계 보상: 치장 SSOT에서 제공하지 않는다.

잠긴 메뉴가 존재하더라도 `곧 공개` 정도의 상태만 표시하고 사용법·보상·일정을 추정하지 않는다.

## 12. 권장 도입 순서

### 1차: 핵심 길찾기

- 첫 메인 전투
- 획득 패널
- 첫 실패와 성장 연결
- 장비 첫 제작·강화
- 스킬 첫 해금·장착

### 2차: 1-5 개방 묶음

- 보석·던전·치장 개방 안내
- 던전 → 보석함 → 장착 → 합성의 자원 흐름
- 뽑기 → 착용 → 중복 등록 → 세트의 상태 흐름

### 3차: 경제·복귀

- 부족 재료 거래소 구매
- 판매·수령·정산
- 오프라인 보상·우편

### 4차: 보조 기능

- 랭킹 첫 방문
- 채팅 안전 안내
- Picture-in-Picture와 설정 도움말

## 13. 검증 지표

- 최초 메인 화면 진입 후 첫 전투 결과 확인율
- 첫 성장 행동까지 걸린 시간
- 기능별 가이드 노출 대비 실제 핵심 행동 완료율
- 가이드 건너뛰기·접기·반복 노출 비율
- 실패 도움말 이후 재도전·성장 행동·클리어 비율
- 1-5 개방 뒤 보석 던전·보석·치장 첫 방문 퍼널
- 거래소 첫 진입부터 구매·판매·수령·정산까지의 이탈 지점
- 튜토리얼 오버레이 직후 세션 이탈률

지표는 `튜토리얼을 많이 봤는가`가 아니라 `필요한 순간에 실제 행동으로 이어졌는가`를 판단해야 한다.

## 14. 현재 문서 충돌과 미결정 사항

### 현재 확인된 충돌

- [MVP 범위](../mvp-release/requirements.md)의 보석 프리셋·입장권 요약 수치 일부가 최신 [보석 SSOT](../../30-domain/gems/ssot.md)와 [결정 로그](../../80-decisions/README.md)의 확정 기준보다 오래됐다.
- 이 계획은 해당 수치를 재정의하지 않으며 최신 보석 SSOT와 결정 로그를 기준으로 한다.

### 온보딩 도입 전에 결정할 것

1. 퀘스트 완료 보상을 별도로 지급할지
2. 메인 의뢰를 어느 시점까지 유지할지
3. 성장 수첩을 필수 또는 선택으로 둘지
4. 퀘스트·가이드 진행 상태의 서버 저장 모델
5. 기능 개방 안내를 표시할 화면별 안전 시점
6. 가게별 메인 의뢰 이름·대사·사건
7. 광장 채팅의 도메인 규칙과 안전 정책 정본
