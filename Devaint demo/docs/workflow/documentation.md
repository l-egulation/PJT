# 문서 계층과 소유권

[협업 기준](README.md)

## 공통 규칙에서 콘텐츠로

분야의 README는 목적·적용 범위·읽는 순서와 하위 문서를 안내한다. 긴 공통 규칙은 rules.md로 분리한다. 하위 문서는 상위 규칙을 참조하고 자신이 소유한 차이·조건·구체값만 정의한다. 예외는 적용 대상을 명시하며 다른 콘텐츠의 기본값으로 확대하지 않는다.

개별 적·보스·장면처럼 여러 상세 문서가 필요한 콘텐츠는 자체 폴더와 README를 둔다. 짧은 항목은 목록·표의 행으로 유지한다. 잉크의 발동 조건과 효과처럼 독립된 축은 각각 정의하고 조합에서 참조한다. 파일 수를 늘리기 위해 모든 항목을 동일한 깊이로 분할하지 않는다.

## 규칙의 소유권

- 런은 보상 지급 조건·진행·종료를 소유하고 장비는 획득한 도면·잉크의 성질을 소유한다.
- 맵은 배치·연결을, 몬스터는 행동·패턴을 소유한다.
- UI는 정보 표현·입력·화면 상태를, 게임 시스템은 보상·피해·소유권을 소유한다.
- 스토리는 장면의 의미·조건을, 구현은 실행 모듈과 연결 방법을 소유한다.
- 기획은 의도한 규칙, 개발은 현재 구현·연결·제한, 에셋 문서는 제작·배치 계약을 소유한다.

같은 규칙의 기준 문서는 하나다. 상위 문서의 요약에 세부 수치를 복제하지 않는다. 콘텐츠 목록은 상세 명세로 연결하는 색인으로 사용한다. 편집 원본이 data/에 있으면 생성 카탈로그만 직접 고치지 않는다.

## 문서 추가와 이동

새 문서는 가장 가까운 소유 분야에 배치하고 상위 README에 연결한다. 관련 기획·구현·에셋 문서는 서로 참조하되 동일 규칙을 복사하지 않는다. 확정·미정·현재 구현·검증 범위를 본문에 명시하고 상태 변화만으로 경로를 바꾸지 않는다.

경로를 바꾸면 내부 상대 링크·다른 문서의 링크·AGENTS.md·데이터의 문서 경로·생성기의 출력과 Markdown 템플릿·검사 fixture를 함께 갱신한다. 생성물을 다시 검사하고 문서 탐색이 루트에서 상세까지 이어지는지 확인한다. 검증 로그·작업 보고서·과거 안내 보관함은 새로 만들지 않는다.

## 계층·링크 검사

저장소 루트에서 `python3 tools/docs/check_links.py`를 실행한다. 문서 대상·제목 앵커·루트에서의 도달 가능성을 검사한다. 현재 탐색 대상에서 기존 `docs/verification/`의 일회성 출력물은 제외한다. 복원하지 않은 미디어 링크는 별도로 보고하며, 미디어까지 모두 복원한 환경에서는 `--strict-media`로 누락을 실패 처리한다. 생성 문서는 해당 생성기의 검사도 함께 실행한다.
