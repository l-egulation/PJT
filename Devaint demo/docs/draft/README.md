# 검토 중인 초안

[문서 입구](../README.md)

이 경로는 확정 전 기획 제안을 검토하는 곳이다. 초안은 현행 규칙의 기준 원본을 대체하지 않으며 구현·플레이 검증 완료를 뜻하지 않는다. 확정한 내용은 해당 규칙의 소유 문서와 구조화 데이터에 반영하고 중복 규칙을 남기지 않는다. 작업·변경 이력과 검증 보고서는 보관하지 않는다.

| 초안 | 범위 |
|---|---|
| [첫 런 경험 순서](first-run-experience.md) | 기본 전투에서 잉크 중복·조건 조합·두 무기 활용·다음 런의 선택으로 이어지는 경험 설계 |
| [잉크 조합과 전투 흐름의 문제점](ink-combat-balance-problems.md) | 초반 조합 접근성, 중복 투자 체감, 쿨타임 공백과 적 유입, 빌드 다양성 및 연관 밸런스의 검토 과제 |
