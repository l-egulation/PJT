# 승인 에셋

이 세션에서 채택한 에셋만 보존한 폴더다.

- sprites: 마을 건물3종과 정면 소품9종의 컬러/스케치, 총24개. 원화 크롭이며 실제 표시 배율은 bindings.json을 따른다.
- sources: 승인된 건물 및 소품 생성 원본4장.
- background: 상점가, 종탑/구름, 하늘, 나무 원본4장. 상태별 영역과 불투명·색 보정·채도·정렬·패럴랙스는 rendering-and-flow.js를 따른다.
- boss: 승인된 석조 보상 제단 준비/소진, 출구 닫힘/열림, 석조안 시트와 실제 Unity 배치 캡처. 철제 대안은 제외했다.
- layout-units.json: 사용자 확정 배치. 32PPU, 밑면 중앙, 맵 왼쪽 바닥 원점, 맵 폭84유닛.

현재 최종 표시는 output/previews/village-walk-20261101/index.html에서 확인한다. build.py로 재생성 가능하며 승인본만 참조한다. 원화 그대로의 PNG와 최종 HTML 렌더 보정은 구분된다. Unity 본게임 적용은 아직 하지 않았다. 종탑/구름과 하늘은 합쳐진 원화 시트에서 독립 영역으로 렌더한다. 최종 레이어를 Unity로 옮길 때도 같은 보정이 필요하다.

manifest.json에 승인 파일의 해시를 기록했다. 이전 후보·임시 출력·대안 비교 메뉴는 제거했다.
