# 콘텐츠 비용 정책

[분야 개요](README.md)

동작과 획득 규칙은 [무기·잉크](../equipment/rules.md), [성장·경제](../run/progression-and-economy.md)를 따른다. 비용 미정은 무료 확정을 뜻하지 않는다.

## 장비 비용

일반·보스 보상은 [스테이지 처치 보상과 상점](../run/rewards.md)을 따른다. 도면 확정과 빈칸 잉크 부여는 무료다. 무기·잉크 구매에는 골드를 쓰며 1·2스테이지 진열·가격의 1차 시험값은 [상점](../run/rewards.md#스테이지에서-얻는-무기와-잉크)을 따른다. 3스테이지 가격은 미정이다.

## 별도 경제와 구현 데이터

마법안료와 영구 강화는 [영구 성장](roguelite-progression.md)을 따른다. 기존 정비소의 캐릭터 강화 비용과 팔레트 조정 비용은 구형 런타임·도구의 값이다. 기존 수치 입력과 생성 절차는 [데이터 파이프라인](../../development/data/data-pipeline.md)에 기록한다.
