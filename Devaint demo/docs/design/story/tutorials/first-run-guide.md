# 첫 런 안내

[분야 개요](README.md)

이동·점프·대시와 마을의 첫 각성·회귀는 [플레이형 오프닝](../opening/opening-playable.md)을 따른다. 무기·성장 안내의 기준은 [무기 도면·런 잉크 도감](../../equipment/rules.md)이다.

## 표시 시점과 화면

| 시점 | 안내 |
|---|---|
| 첫 런 전투 시작 전 | 맨손 대기 → 공격 그림과 A 공격. F로 닫는다. |
| 첫 일반 보상 선택 화면을 열 때, 선택 전 | 아래 5페이지를 하나의 중앙 창으로 보여 준다. 좌우 방향키 또는 버튼으로 이동하고, 어느 페이지에서든 F 또는 닫기 버튼으로 전체 창을 닫는다. 닫으면 보상 선택 화면으로 복귀한다. |
| 이후 잉크·스케치 획득 | 획득별 설명창을 추가로 띄우지 않는다. |
| 무기 장착 | 별도 조작 안내창 없이 전투 HUD의 무기·공격·스킬 키 표시를 사용한다. |

첫 일반 보상은 단독 사용 가능한 효과 잉크를 고른 뒤 도면을 골라 둘 다 획득한다. 세부 지급 규칙은 [런 보상](../../run/rewards.md)을 따른다. 보상 조건과 무작위 등장 문구는 보상 화면이 소유한다. 스케치와 잉크를 설명하면서 실제 보상을 자동 선택하거나 인벤토리를 자동으로 열지 않는다.

## 첫 보상 안내 5페이지

| 페이지 | 본문 | 작은 붉은 주석 |
|---|---|---|
| 1 스케치 | 활성화 후 무기로 사용 가능 | * {교체 키} 키로 {A} 칸과 {S} 칸의 무기를 서로 교체(바꾼 키 설정을 따름, 2026-11-13) |
| 2 잉크 | 잉크 장착으로 무기에 효과 부여 / 같은 무기의 여러 칸과 다른 무기에 중복 장착 가능 | * 잉크는 획득당 10회, 칸마다 1회 사용 · 같은 잉크 재획득 가능 |
| 3 팔레트 | 모든 색 잉크 장착 가능 / 슬롯과 같은 색 장착 시 효과 강화 | 없음 |
| 4 활성화 | 활성화 후 팔레트 구성 변경 불가 | * 빈 슬롯에도 추가 장착 불가 |
| 5 내구도 | 가한 피해에 따라 내구도 소모 / 내구도 소진 시 무기 소멸 | * 획득한 잉크는 유지 |

활성화하면 빈 슬롯을 포함해 구성 전체가 고정된다. 이후 추가·교체·해제·이동을 허용한다는 안내는 사용하지 않는다. 실제 장비 동작의 이행은 장비 담당 구현에서 처리한다.

## 확정 미술과 UI 부품

중앙 창의 구성과 문구는 사용자 확정 디자인을 따른다. 그림은 새 픽셀 에셋으로 구성하고, 맨손 공격 그림은 크림색 후드·검은 얼굴·금색 눈·청록색 목도리의 주인공을 유지한다. 설명 본문은 작은 크기의 명사형이며, 핵심 단어는 볼드와 옅은 스케치 붓터치로 강조한다. 주석은 본문보다 작은 붉은 글씨와 별표를 사용한다. 실제 게임 배경은 캡처에 굽지 않고 뒤에서 표시한다.

새 그림의 생성 원본과 내보내기 규격은 리소스 `ui/first-run-tutorial-pixel/source/`, 적용 픽셀 에셋은 같은 그룹의 `runtime/`에 둔다. 생성 원본은 큰 해상도의 시안이며, 적용본은 고정 팔레트·최근접 보간으로 변환한 16×16·32×32·64×64 등의 명시적 저해상도 PNG다. 작은 프레임은 원본 픽셀 격자에서 직접 작성한다. 시안 화면을 잘라서 창 내용으로 사용하지 않는다. 문구·페이지 번호·키 표시는 실제 텍스트, 그림·프레임·버튼은 분리된 UI다. Point 필터·압축 없음·밉맵 없음과 정수 배율을 사용한다. 좌우 버튼은 첫·마지막 페이지에서 각각 비활성화한다. 새 픽셀 적용본은 미술 검토 전 초안이며 기존 디자인 승인과 별도로 확인한다.

검·검 스케치·소멸한 검은 생성 시안의 축소본을 사용하지 않는다. 32×32 원본 격자에서 제한된 6색과 일정한 45도 계단으로 직접 작성한 공통 실루엣을 사용한다. 재편집 가능한 원본 픽셀은 `source/sword-pixels.json`, 작성기는 `resources/tools/tutorial_sword_pixels.py`다. 강조 단어에는 정적 픽셀 폰트의 실제 Bold 파일을 사용하며, 일반 파일에 런타임 볼드 스타일을 덮어쓰지 않는다.

망치는 32×32 격자에서 머리와 자루의 중심축을 맞춰 직접 작성한다. 굽은 화살표는 32×24 격자에서 5픽셀 굵기의 직선·일정한 45도 연결부·수평 화살촉으로 작성한다. 두 그림의 원본 픽셀은 `source/hammer-arrow-pixels.json`, 작성기는 `resources/tools/tutorial_tool_pixels.py`다.

캐릭터 대기·공격의 최종 편집 원본은 `source/hero-user-edit.json`이다. 사용자가 편집기에서 수정 완료한 픽셀을 우선하며, 내보내기는 재채색·리사이즈 없이 해당 RGBA를 그대로 적용한다. 독립 HTML 편집기는 `authoring/hero-pixel-editor.html`이며 `resources/tools/build_tutorial_hero_editor.py`로 현재 PNG를 담아 갱신한다.

## 재사용 UI와 연결 범위

재사용 컴포넌트는 [FirstRunTutorialWindow](../../../../unity/Assets/Deviant/Tutorial/Runtime/FirstRunTutorialWindow.cs)다. 프리팹은 `unity/Assets/Deviant/Tutorial/Prefabs/FirstRunTutorialWindow.prefab`, 독립 검토 씬은 `unity/Assets/Deviant/Tutorial/Preview/FirstRunTutorialPreview.unity`다. Unity 메뉴 `Tools/Deviant/Tutorial/Build approved tutorial`로 생성한다.

호출자는 플레이어의 `LocalInput`과 `IControlRequests`, 닫기 콜백을 전달해 `ShowAttack` 또는 `ShowRewards`를 호출한다. 창이 연 입력을 즉시 닫기로 처리하지 않으며, 닫을 때는 이 창이 획득한 입력 제한·일시정지만 해제한다. 기존 보상 화면의 정지 상태는 유지한다. 실제 키 설정에 맞는 상호작용 키를 읽고 기본값 F에서 닫는다.

보상 선택 화면·최초 노출 기록·보상 지급과의 호출 연결은 스케치 전투 바인딩이 소유한다. 보상 종류와 처치 기준은 보상 시스템이 소유한다. 스케치 전투에서는 예전 전용 잉크 몬스터·수첩 안내를 활성화하지 않는다. 검토 씬은 실제 프로필·지갑·보상을 변경하지 않는다. 기존 `FirstRunNotebookView`와 이 재사용 UI는 별개이며, 이전 장비 흐름용 코드로만 남아 있다. 스케치 전투에서는 새 자동 안내만 사용한다.

## 조작 튜토리얼 다시보기

런 시작 방에 「조작 튜토리얼」과 「시스템 튜토리얼」 팻말을 나란히 두고 F로 각각 연다. 두 팻말은 같은 시작 지형 위에서 4.5칸 이상 간격을 두어 이름이 겹치지 않게 한다. 조작 팻말은 조작 안내를 따로 연다. 달리기·점프·더블 점프·대시·대시로 피하기·벽타기·벽차기의 녹화 시범 7페이지만 표시한다. 공격·보상·장비 안내는 각 표시 시점에 별도로 열며 조작 안내에 합치지 않는다. 창 외형과 하단 버튼은 같은 UI를 재사용한다.

공격·보상·조작 안내 제목은 붓터치 하이라이트 없이 창 왼쪽 상단에 표시한다. 보상 안내의 제목 영역은 왼쪽 160px로 제한해 중앙의 팔레트 물방울 그림과 겹치지 않게 한다. 본문의 핵심 단어 강조는 유지한다. 조작 시범의 바닥과 벽은 실제 게임의 잔디·흙 타일을 사용한다. 녹화 시범의 키 점등과 스태미나 표시는 계속 재생한다.

마지막 벽타기·벽차기 두 페이지는 앞 페이지와 같은 32px/unit 배율로 캐릭터를 표시한다. 전체 동작을 한 화면에 넣기 위한 자동 축소는 사용하지 않는다. 캐릭터의 발 위치를 시범 영역의 가로 중앙과 기본 바닥선 위 12px에 고정하고, 녹화된 위치와 벽 접촉 보정을 따라 벽·바닥이 반대 방향으로 이동한다. 앞의 다섯 페이지와 오프닝의 작은 조작 카드는 기존 구도를 유지한다.

좌우 키 또는 버튼으로 페이지를 이동하며 처음·마지막 페이지에서 이동을 제한한다. 첫 페이지의 왼쪽 화살표와 마지막 페이지의 오른쪽 화살표는 숨긴다. 범위를 벗어난 이동이나 같은 페이지 선택은 무시하며 현재 녹화 시범을 처음부터 다시 재생하지 않는다. F·닫기 버튼 또는 Esc로 닫으면 이 창의 일시정지만 해제한다. 본문은 기본 12픽셀 글꼴을 사용하고 정수 배율로 표시한다.


## 첫 런 자동 노출 연결

새 프로필의 첫 정식 런에서 스케치 전투 바인딩을 생성한 직후 공격 안내를 열고 첫 전투 입력과 시뮬레이션을 잠근다. 실제 보상 제안이 열린 뒤 선택 입력을 처리하기 전에 보상 안내 5페이지를 연다. 보상 안내를 닫아도 보상 선택 화면의 제안 순서·내용과 일시정지는 유지한다.

프로필의 기존 seenStories 저장소에 first-run-attack-v1과 first-run-reward-v1을 각각 기록한다. 안내가 성공적으로 열린 시점에 기록하며 페이지 이동이나 닫기로 추가 기록을 만들지 않는다. 같은 첫 런의 씬 재진입·프로필 재로드에도 재노출하지 않는다. 첫 런이 끝났거나 정식 런을 두 번 이상 시작한 프로필, 훈련과 직접 에디터 실행에는 자동 안내를 띄우지 않는다. 첫 런에 보상을 열지 못하고 사망했어도 다음 런에 보상 안내를 이월하지 않는다.

시스템 팻말은 첫 런의 공격·보상·무기·잉크 설명 6페이지를 순서대로 다시 보여 준다. 조작 팻말과 동일한 프레임·방향키 페이지 이동·F/Esc 닫기를 사용하며, 다시보기는 보상을 지급하거나 튜토리얼 완료 기록을 바꾸지 않는다. 두 팻말 다시보기는 이 두 기록을 읽거나 변경하지 않는다. 스케치 전투에서는 예전 무기·팔레트 수첩을 함께 열지 않는다.
