# 편집기 작업 규칙

- 공통 편집 HTML 하나를 고정하고 작업 대상 데이터만 교체한다. 새 작업은 `set_project.py` 또는 JSON 불러오기를 사용하며 `index.html`을 버전별로 복제하지 않는다.
- 배경 4종(진회색/회색/흰색/체크무늬), 확대·격자·이전 프레임 겹치기·취소/다시 실행·JSON/PNG 내보내기의 기능과 위치를 유지한다.
- 사용자 수정 픽셀·배치·메타데이터와 브라우저 저장소를 임의로 변경하거나 삭제하지 않는다.
- UI 자체 변경을 요청받은 경우에만 공통 HTML/JS/CSS를 수정한다. 리소스 배치 경로 이관을 UI 변경 권한으로 해석하지 않는다.
