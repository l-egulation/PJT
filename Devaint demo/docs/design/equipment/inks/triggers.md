# 잉크 발동 조건

[상위 규칙](rules.md) · [잉크 개요](README.md)

## 효과 부여 잉크

각 트리거는 [여섯 효과](effects.md#효과-부여-잉크) 모두와 조합한다. 상태이상 트리거는 기절·속박·슬로우 부여만 제외하며, 그 밖의 조합은 선택적으로 생략하지 않는다.

| 조건 | 의미 | 남은 구체화 |
|---|---|---|
| 기본 공격 | 이동속도는 공격 실행 시, 회복·방어막은 몬스터의 실제 체력을 줄인 뒤 발동. 실행 전 취소는 제외 | 실행 사건의 구현상 경계 |
| 스킬 공격 | 이동속도는 공격 실행 시, 회복·방어막은 몬스터의 실제 체력을 줄인 뒤 발동. 실행 전 취소는 제외 | 실행 사건의 구현상 경계 |
| 스위칭 | 직전 공격이 다른 무기였을 때 현재 공격 실행 시 자기 효과 발동, 적중 불필요. 교체 후 들어온 무기의 잉크 사용 | 없음 |
| 대쉬 | 이동속도·방어막은 시작 시 한 번. 회복은 경로 적 접촉 시 장착본별 한 번, 상태이상은 경로의 적들에게 적용 | 없음 |
| 상태이상 | 몬스터에게 상태이상을 성공적으로 부여·재부여할 때 효과 부여. 시간·강도 증가 불필요, 부여 실패는 제외 | 연쇄 처리 단계 |

상태이상 부여 트리거는 **기절·속박·슬로우를 부여한 원본 무기의 잉크만** 반응한다. 비활성 원본 무기의 지연 투사체·설치물이 부여해도 원본 장착본을 사용하며 현재 사용 무기나 다른 무기의 잉크로 발동을 넘기지 않는다. 성공한 재부여는 인정하지만 환경이나 다른 공급원의 부여·플레이어가 상태이상에 걸리는 사건은 포함하지 않는다.

상태이상 조건으로 기절·속박·슬로우 등 상태이상을 다시 부여하는 조합은 금지한다. 다른 조건의 적중·처치를 자동 필수로 해석하지 않는다. 자기 효과의 일반 실행 시점보다 [방어막 예외 규칙](effects.md#이동속도-증가와-방어막-중첩)이 우선하며, 대쉬 방어막은 시작 즉시 생성 후 다른 방어막보다 빠르게 사라진다. 정확한 대상과 지속시간은 [효과](effects.md)와 [작성지](combination-worksheet.md)에서 구체화한다.

### 스위칭과 대쉬의 대상

스위칭은 무기 교체 입력 자체가 아니라 **직전 공격과 다른 무기로 공격하는 조건**이다. 효과는 교체 후 들어온 무기의 잉크에서 발동한다. 스위칭 상태이상은 해당 공격에 맞은 적에게 부여하며 주변 적에게 자동 부여하지 않는다. 이동속도·회복은 조건을 만족한 공격 실행 시 적용하고 빗나가도 발동한다. 방어막은 해당 공격의 적중 시 생성한다. 실행 전 취소에는 발동하지 않는다. 런의 첫 공격은 직전 공격이 없으므로 스위칭으로 인정하지 않는다. 공격이 실제 실행되면 빗나가도 해당 무기를 직전 공격 무기로 기록한다. 현재 공격의 스위칭 여부는 기록 갱신 전에 판정한다. 실행 전에 취소하면 기존 직전 공격 무기 기록을 유지한다. 직전 공격은 슬롯이나 무기 종류가 아니라 **무기 개체의 고유 식별**로 기록하며 해당 무기가 소멸하거나 가방으로 이동해도 기록을 유지한다. A가 공격 후 파괴되었어도 다음 B의 공격은 스위칭 조건을 만족한다.

대쉬의 이동속도·방어막은 **시작 시 한 번**, 회복은 **대쉬 경로 판정이 적에게 닿을 때 장착본별 대쉬당 최대 한 번** 발동한다. 발동 대상은 **대쉬 시작 시 현재 사용 중인 무기**에 장착한 준비된 대쉬 잉크이며 다른 무기의 잉크를 함께 발동하지 않는다. 직전 공격 무기가 아니라 시작 시 현재 무기를 기준으로 한다. 이동속도·방어막은 대쉬 시작 시 적용한다. 회복은 상태이상과 같은 경로 판정으로 살아 있는 적과 접촉해야 하며, 적을 만나지 못하면 회복과 회복 쿨타임 소모가 없다. 실제 회복량이 양수일 때만 회복 쿨타임을 시작한다. 기절·속박·슬로우는 **대쉬 경로에 있는 적들**에게 부여한다. 다음 공격에 효과를 예약하지 않으며 공격 적중을 요구하지 않는다. 노랑·초록 대쉬 잉크는 다른 트리거보다 긴 내부 쿨타임을 쓰며 보라는 공통 중복 계산을 따른다. 확정 수치는 [효과 규칙](effects.md)과 [수치표](balance-proposal.md)를 따른다.

대쉬 이동 중 경로 판정이 적에게 닿는 즉시 상태이상을 부여한다. 대쉬 1회당 잉크별로 각 적에게 한 번만 부여하며 같은 적과 재접촉하거나 오래 겹쳐도 재부여하지 않는다. 지나간 경로에 판정을 남기지 않는다. 대쉬가 중단되면 이후 접촉 판정은 중단하지만 이미 부여한 상태이상은 각 지속시간대로 유지한다. 상태이상 부여 범위는 **캐릭터의 피격 범위를 좌우·위아래로 각각 0.25unit 확장한 영역**이 대쉬 경로를 따라 지나가는 범위로 정한다. 플레이 테스트 시작값이며 플레이어의 피격 범위 자체를 변경하지 않는다. 대쉬 도중 원본 무기가 교체되거나 소멸해도 **대쉬 이동과 시작 시 발동한 원본 잉크의 경로 효과를 종료까지 유지**한다. 무기 교체·소멸 자체로 남은 이동·무적을 중단하지 않는다. 새 무기의 잉크를 추가 발동하지 않으며 원본 잉크의 쿨타임과 대상별 적용 기록을 유지한다. 별도 사유로 대쉬 자체가 중단되면 기존 중단 규칙을 따른다. 대쉬 보라는 시작 시 부여 버프를 활성화한다. 적에게 닿지 못해도 활성 시간은 흐르며 버프가 끝나면 재사용 시간이 시작된다. 활성 중 대쉬 경로의 대상별 한 번만 부여하며, 기본·스킬 적중에는 대쉬 잉크의 상태이상을 적용하지 않는다.

### 공격당 발동 횟수

노랑·초록·파랑은 공격 실행당 장착본별 최대 1회 발동한다. 빨강은 조건을 만족하는 매 기본 적중마다 버프 시간을 갱신하며, 보라의 기본 공격·스킬·스위칭 조건은 원본 무기의 부여 버프 활성 중 매 기본·스킬 적중마다 적 상태를 갱신한다. 보라의 같은 무기·동일 잉크는 중복 환산량으로 하나의 활성 시간과 재사용 시간을 사용한다. 대상 수는 효과량의 추가 중첩을 만들지 않는다. 대쉬 경로는 기존 대상별 1회 판정을 유지한다.

기본 공격·스킬 공격 조건의 효과 잉크는 **공격이 실제 실행될 때** 발동한다. 이동속도는 빗나가거나 적이 없어도 적용하며, 실행 전 취소에는 발동하지 않는다. 기본 공격·스킬 공격의 회복·방어막은 몬스터에게 실제 체력 피해가 발생한 뒤 발동하며 처치 타격도 인정한다. 피해 0·무적/방어로 체력이 줄지 않은 타격·플레이어·미끼 타격은 발동과 쿨타임을 소비하지 않는다. 적에게 부여하는 상태이상은 실제 적중 대상을 필요로 한다. 스위칭의 이동속도·회복도 조건을 만족한 공격 실행 시 적중 없이 적용한다. 스위칭의 방어막은 적중 시 생성한다. 상태이상 트리거의 자기 효과는 몬스터에게 상태이상을 실제 부여해야 한다. 빨강·파랑의 조건은 아래 별도 규칙을 따른다.

## 공격 부여 잉크

빨강은 **기본 공격(일반 공격)으로 피해를 넣을 때**, 공격 대상 몬스터의 기절·속박·슬로우 상태 조건을 함께 확인한다. 스킬 공격으로 발동하지 않는다. 내부 쿨타임은 없으며 매 적중에 공격과 상태 조건을 다시 확인한다.

효과 부여 → 대상 상태 확인 → 기본 공격 피해·공속 버프 → 발동 타격의 피해 계산 순서를 따른다. 비용·상태 시간 소모·부족분 반동은 없다. 같은 기본 공격으로 부여한 상태이상도 즉시 조건을 충족한다. 광역 타격은 같은 타격의 모든 대상에게 상태이상을 먼저 적용하고 조건을 조사한 뒤, 조건을 만족한 대상이 하나라도 있으면 준비된 해당 빨강 버프를 발동해 **그 타격의 모든 대상부터 강화**한다. 적 처리 순서에 따라 피해가 달라지지 않는다. 다단 공격의 이전 타격에 이미 계산한 피해는 소급 변경하지 않는다.

## 스킬 강화 잉크

파랑은 **스킬 공격 적중 시** 맞힌 몬스터의 기절·속박·슬로우 상태 조건을 함께 확인해 쿨타임 감소 또는 스킬 피해량 증가를 제공한다. 기본 공격으로 발동하지 않으며 비용·페널티가 없다.

빗나가거나 적중 대상이 없으면 발동하지 않는다. 효과 부여 → 대상 상태 확인 → 파랑 효과 발동 → 발동 타격의 피해 계산 순서로 처리하므로 같은 스킬 공격으로 부여한 상태이상도 즉시 조건을 충족한다. **1타도 상태이상 부여와 조건 확인, 피해 강화 적용을 먼저 끝낸 뒤 피해를 계산**하므로 같은 1타로 부여한 상태이상으로 그 1타부터 강화할 수 있다. 파란 피해 증가는 피해 계산 시 각 대상이 해당 잉크의 상태 조건을 만족할 때만 적용한다. 한 대상에서 발동했다고 조건이 없는 다른 대상에게 피해 보너스를 주지 않는다. 이미 계산한 피해는 소급 변경하지 않는다. 내부 쿨타임은 [효과 규칙](effects.md)을 따른다. 스킬 공격을 사용하는 기존 효과 잉크 조합은 유지한다.

공통 상태 조건과 효과는 [색별 효과](effects.md#빨강파랑의-공통-상태-조건)를 따른다. 효과 잉크의 '몬스터에게 상태이상을 부여할 때' 사건과 빨강·파랑의 '공격 대상이 해당 상태일 때' 조건을 구분한다.

공격 조건 보라 잉크는 첫 유효 적중에 부여 버프를 활성화하며 버프 종료 후 재사용 쿨타임을 시작한다. 회복·방어막은 실제 증가량이 있을 때만 쿨타임을 사용한다. 이는 공격 실행·적중·대쉬 등 각 효과의 발동 사건을 바꾸지 않는다([내부 쿨타임](effects.md#내부-쿨타임)).
