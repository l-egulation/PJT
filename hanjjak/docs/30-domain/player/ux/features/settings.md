# 설정 화면

이 문서는 설정 화면을 찾기 위한 경로 문서다. 정책, 수치, 상태, 완료 여부를 정의하지 않는다.

- 화면·상호작용 정본: [클라이언트 UX SSOT](../ssot.md)
- 계정·인증·로컬 실행 상태 정본: [계정·저장 SSOT](../../ssot.md)
- 데이터 저장 경계: [데이터 권한과 저장 경계](../../../../50-architecture/persistence.md)
- 결정 상태: [결정 로그](../../../../80-decisions/README.md)
- 관련 실행 문서: [K-01](../../../../wiki/06-delivery/tasks/K-client-ux/k-01-screen-flow-information-architecture.md), [K-04](../../../../wiki/06-delivery/tasks/K-client-ux/k-04-auth-first-entry-ui.md), [K-15](../../../../wiki/06-delivery/tasks/K-client-ux/k-15-loading-empty-error-feedback.md), [K-18](../../../../wiki/06-delivery/tasks/K-client-ux/k-18-pet-management-tray-windows.md), [K-20](../../../../wiki/06-delivery/tasks/K-client-ux/k-20-low-fatigue-idle-ux-validation.md), [K-23](../../../../wiki/06-delivery/tasks/K-client-ux/k-23-browser-settings-ui.md)
