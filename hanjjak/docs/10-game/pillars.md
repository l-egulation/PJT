# Game Pillars

한짝의 최상위 설계 원칙이다. 각 도메인과 시스템은 이 원칙을 만족하는지 확인한다.

## 저피로 자동성

이동, 전투, 보스 도전과 재도전은 자동으로 이어지고, 플레이어의 반복 클릭을 기본 전제로 삼지 않는다.

## 지속되는 존재감

펫은 브라우저에서 쉽게 다시 확인할 수 있는 지속적 존재감을 제공하며, 화면 표시 상태와 게임 상태를 분리한다. 백그라운드 탭은 진행을 유지하고, discard·브라우저 종료·기기 절전·네트워크 단절은 중단 처리한다.

## 선택의 가치

장비·스킬·전문·거래소의 선택은 성장 효율을 바꾸지만 반복 조작을 강제하지 않는다.

## 권한의 분리

로컬 성장·실행 체크포인트의 편의성과 서버 스테이지 진행·거래 자산의 최종 권한을 분리한다. 저장·권한 경계는 [Runtime Architecture](../50-architecture/README.md)와 관련 도메인 SSOT를 따른다.

## 단계적 확장

초기에는 단일 배포 단위로 시작하고, 병목과 계약이 확인된 경우에만 런타임 경계를 확장한다.
