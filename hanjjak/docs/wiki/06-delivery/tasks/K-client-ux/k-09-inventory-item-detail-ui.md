# K-09 인벤토리·아이템 상세 UI 구현

> 작업 상태와 완료 증거의 SSOT. 도메인 규칙은 [클라이언트 UX](../../../../30-domain/player/ux/ssot.md)를 따른다.

## 완료 기준

고정 200슬롯 인벤토리에서 아이템 분류, 정렬, 수량, 획득처, 거래 가능 여부와 사용처를 확인하고 제작 특수 아이템·보석·스킬북 신규 획득 알림을 아이템 화면 진입으로 확인 처리할 수 있다.

## 선행 작업

F-04, F-06, K-02

## 비고

200슬롯 용량, 분류·정렬·페이지 탐색, 총·예약·사용 가능 수량, 획득처·사용처·거래 가능 여부와 반응형 상세 화면을 구현했다. 전투 스테이지 위 모달로 연결해 닫기·바깥 영역·Esc 복귀를 제공한다. 제작 특수 아이템·보석·스킬북 신규 획득 알림의 확인 처리 상태는 별도 서버 계약이 없어 남아 있다.

## 증거 링크

- `apps/web/src/features/inventory/InventoryScreen.tsx`
- `apps/web/src/features/inventory/api.ts`
- `apps/web/src/main.tsx`
- `apps/web/src/navigationState.ts`
- `apps/web/src/styles.css`
- 검증: `pnpm --filter @hanjjak/web typecheck`, `pnpm --filter @hanjjak/web build` 성공
- 2026-09-11 배포 통합 검증: 인벤토리 전용 코지 픽셀 화면과 전투 위 모달 진입을 최신 `origin/main`에 결합했다. 웹 전체 50개 파일·296개 테스트, typecheck, production build가 통과했고 1280×720 실제 미리보기에서 종이 프레임·분류 탭·정렬·닫기 조작이 전투 화면 밖으로 잘리지 않는 것을 확인했다.
- 2026-09-11 등급별 재료 이미지 보정: `POTATO_M1`~`POTATO_M5`, `SWEET_POTATO_M1`~`SWEET_POTATO_M5`, `CORN_M1`~`CORN_M5`가 거래소·장비 화면과 같은 F·D·C·B·A 전용 이미지를 사용하도록 인벤토리 아이콘 매핑을 보정했다. API가 구형 공통 아이콘을 내려주더라도 등급별 런타임 에셋을 우선하며 `InventoryScreen.test.tsx`로 15종 이미지 분리, 세 재료군의 F~A 표시 등급 매핑, 비재료 아이콘 보존을 검증했다.
- 2026-09-11 보유 수량 합계 표시 보정: 목록은 999개 단위로 분리된 슬롯 수량을 유지하고, 오른쪽 아이템 상세의 `보유 수량`은 아이템 상세 API가 반환하는 전체 합계로 표시한다. `InventoryScreen.quantity.test.tsx`에서 999개·999개·662개 슬롯이 각각 유지되면서 상세에는 2,660개가 표시되는 회귀 시나리오를 검증했다.
- 2026-09-11 재료 등급 표시 보정: 인벤토리 목록과 상세가 재료 아이템 ID의 M1~M5를 F·D·C·B·A 등급으로 변환해 표시하도록 보정했다. 목록에는 등급별 색상 배지를, 상세에는 `<등급> 강화 재료` 문구를 제공하며 `InventoryScreen.test.tsx`에서 전 등급 매핑과 비재료 제외를 검증했다.
- 2026-09-11 인벤토리 헤더 정렬 보정: `가방 공간` 표시를 제목과 화면 중앙 사이가 아니라 닫기 버튼 바로 왼쪽의 우측 끝 영역에 배치했다.
- 2026-09-11 재료 설명·한 화면 배치 보정: 재료 상세 설명을 표시명 반복과 `~입니다` 종결 없이 `장비 제작과 강화에 사용하는 {세대}세대 재료`로 통일했다. 높이가 짧은 데스크톱 화면에서는 제목·도구 모음·아이템 카드·상세 영역의 세로 여백과 이미지를 함께 조정해 1280×720에서도 12칸 목록과 상세 정보를 스크롤 없이 확인할 수 있도록 했으며, 데스크톱 모달 전체를 26px 아래로 내려 상하 여백의 시각 균형을 보정했다. 상세 하단의 보유 수량·재료 설명·획득처·사용처 글자 크기도 키워 노트북 해상도에서 정보 가독성을 높였다.
- 2026-09-11 전투 HUD 인벤토리 미리보기 복구: `battle-hud-preview.html?route=inventory`가 실제 인벤토리 API 기동 여부에 의존하지 않도록 F~A등급 15종의 정적 재료 데이터 소스를 연결했다. 미리보기에서는 분류·정렬·페이지 이동·상세 조회를 로컬 데이터로 수행하며 `/api/v1/inventory` 요청을 보내지 않는 회귀 테스트를 추가했다.
- 2026-09-11 인벤토리 상단 여백·바로 판매 동선 보정: 장식 종이의 상단 테두리와 제목·가방 공간이 겹쳐 보이지 않도록 내부 콘텐츠를 아래로 이동했다. 거래 가능한 아이템 상세의 보유 수량 옆에는 `바로 판매` 버튼을 추가했으며, 선택한 아이템 ID를 유지한 채 거래소 판매 탭으로 이동하도록 연결했다. `InventoryMarketShortcut.test.tsx`에서 선택 아이템 전달과 기존 판매 입력값 보존을 검증했다.
- 2026-09-11 운영 뷰포트 정합성 보정: 로컬 `1440×900` 프리셋과 달리 실제 브라우저 콘텐츠 영역이 `1201×731`인 환경에서 모달의 `translateY(26px)`가 하단을 10px 넘기는 현상을 실측했다. 모달을 뷰포트 안에서 고정 높이로 중앙 정렬하고 종이 내부를 3행 그리드로 수축시켜, 낮은 16:9·16:10 화면에서도 외곽 프레임과 상세 하단이 함께 보이도록 보정했다. 수정 후 같은 화면에서 모달 상·하단이 각각 `16px`, 상세 영역의 `scrollHeight`와 `clientHeight`가 모두 `522px`임을 확인했다. `InventoryScreen.layout.test.ts` 포함 웹 53개 파일·309개 테스트, typecheck, production build가 통과했다.
- 2026-09-11 관리 모달 좌우 여백 통일: 인벤토리 모달 폭을 장비 모달과 같은 `min(1320px, 100vw - 16px)`로 맞췄다. `1440×730`에서는 좌우 60px, `1280×720`에서는 좌우 8px을 확보해 장비·인벤토리 전환 시 외곽 프레임 폭이 바뀌지 않도록 했다.
- 2026-09-11 장비·인벤토리 릴리스 검증: 최신 `origin/main` 위에 두 관리 화면의 확정 변경만 결합한 뒤 웹 전체 57개 파일·329개 테스트, TypeScript typecheck, production build를 통과했다. 외부 API가 없는 단위 테스트에서 발생하는 `localhost:3000` 연결 거부 로그는 테스트 실패로 처리되지 않았고 전체 회귀 결과는 성공이다.
- 2026-09-11 스킬북 식별·상세 제목 보정: `skillbook:<skillId>:<grade>`에서 스킬과 등급을 분리해 공용 책 이미지 위에 해당 스킬의 확정 아이콘 배지를 표시한다. 여섯 스킬의 목록·상세 아이콘이 서로 구분되며, 상세는 장비와 같은 정보 위계로 `스킬북` 제목과 등급 배지를 먼저 표시하고 카탈로그명의 등급 접두사를 뺀 고유 비법서 이름을 별도 제목으로 표시한다. 품목 ID와 서버 카탈로그명은 유지했다. `InventoryScreen.quantity.test.tsx`에서 여섯 배지의 고유성과 `스킬북·노말·잘게 더 잘게! 비법서` 분리 렌더링을 검증했고, 전체 웹 Vitest 59개 파일·336개 테스트, TypeScript typecheck와 production build가 통과했다.
- 2026-09-11 스킬북 시각 검수 경로: 전투 HUD 인벤토리 미리보기에 MVP 6개 스킬의 노말 스킬북 fixture를 추가했다. API 서버나 보유 계정 없이 `battle-hud-preview.html?route=inventory`에서 공용 책·스킬별 아이콘 배지·분리된 상세 제목을 한 화면에서 비교할 수 있으며, 미리보기 회귀 테스트에서 6개 배지 렌더링과 운영 인벤토리 API 미호출을 확인한다.
- 2026-09-12 보석함 직접 개봉: 인벤토리의 보석함 상세에서 `1개 열기`와 `사용 가능 수량 모두 열기`를 제공하고 기존 원자적 개봉 API에 연결했다. 성공 시 보석·인벤토리 캐시를 함께 갱신하고 획득 개수를 표시한다. 범용 보석 아이콘 대신 보석이 든 나무 상자 전용 투명 픽셀 에셋 `apps/web/src/features/inventory/assets-gem-box-chest.png`를 적용했으며 `InventoryScreen.quantity.test.tsx`로 아이콘과 1개 개봉 요청을 검증했다. 웹 전체 61개 파일·350개 테스트, TypeScript typecheck와 production build를 통과했다.
