# 벽차기 1차 확정 아트

무기를 숨기는 맨손 벽 접촉 모션의 1차 확정본이다. Unity 상태 전환·이동 물리·무기 재표시 시점은 아직 연결하지 않았다. 미리보기의 이동 궤적은 검토용이다.

- `source/wall-editor.json`: 공통 픽셀 편집기에서 불러올 32장 원본. 8~23장은 10장 몸체에 각 장 목도리를 유지한다.
- `wall_frames/F01.png`~`F32.png`: 128×128 투명 PNG. 원본 픽셀 비율을 유지하고 Point 필터를 사용한다.
- `source/jump-master-editor.json`, `jump_master/`: 사용자 수정 1~7장 점프 몸체 마스터.
- `weapon_jump_review/`: 13종 무기에 마스터를 적용한 검토 JSON. 기존 낙하·착지와 무기는 보존했다. Unity 반영 전 검토 자료다.
- `preview/`: 벽차기 연결, 점프 수정 전후, 13종 점프 비교.
- `manifest.json`: 프레임 순서·시간·파일 SHA-256.

점프 마스터와 무기별 검토 자료는 벽차기와 함께 전달한다. 벽차기에는 무기를 합성하지 않는다. 재생 시간은 편집 JSON의 `ms`를 따른다.
