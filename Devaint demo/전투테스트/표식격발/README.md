# 표식 쌓임·격발 이펙트 시험판

무기 A 적중마다 머리 위에 쌓이는 표식 방울과, 무기 전환 뒤 적중으로 그 표식을 터트릴 때(격발) 쓰는 이펙트 후보다. 제품 아트 확정본이 아니며 Unity에 연결하지 않았다.

[pixelfx](https://github.com/patch-gg/pixelfx)(MIT)의 이펙트 형식으로 쓴 코드다. 원·막대 같은 도형 대신 움직이는 잉크 덩어리의 농도를 더해 문턱 위만 칠하고, 잡음으로 좌표를 비틀어 장마다 윤곽이 일렁이게 한다. 격발은 흰 몸에 먹 테두리를 쓴 기본 판과, 「표식을 터트릴 시」 파츠 색 다섯 판(테두리 없음)을 뽑는다. 표식 방울은 기본 판만 뽑는다.

- `mark-drop-land.js` · `mark-drop-idle.js` · `mark-drop-expire.js`: 표식 방울 하나의 세 동작. 쌓일 때(위에서 떨어져 눌렸다 튀어 자리 잡음), 떠 있는 동안(반복, 꼭지가 흔들리며 들썩임), 만료(마르듯 쪼그라들어 부스러기로 사라짐).
- `mark-burst.js`: 격발. 옵션 `palette`(어두운 → 밝은 6단), `marks`(1~5), `dir`(1이면 오른쪽으로 맞아 오른쪽으로 더 튄다), `rim`(먹 테두리), `mix`·`mixMode`(여러 색 섞기). 머리 위 방울은 `mark-drop-idle`과 같은 모양·자리에서 몸통으로 빨려 든다.
- `export.mjs`: 방울 세 동작 기본 판 3장, 격발(표식 1~5개) 기본·빨강·노랑·초록·파랑·보라 30장, 여러 색 섞임 130장을 뽑는다(약 3분).

## 시트 뽑기

pixelfx 체크아웃이 필요하다. 설치 단계는 없고 Node 18 이상만 쓴다.

```sh
git clone https://github.com/patch-gg/pixelfx <pixelfx>
node 전투테스트/표식격발/export.mjs --pixelfx <pixelfx>
```

결과는 Git 제외 폴더 `outputs/pixelfx/mark-burst/`에 `mark-drop-<동작>_base.png/json`, `mark-burst_<base|색>_m<표식 수>.png/json`으로 생긴다. 이 저장소는 PNG를 추적하지 않는다. 게임에 쓸 그림은 `resources/` 서브모듈 절차로 등록한다.

## 시트 규격

표식 방울:

- `mark-drop-land`(24×40, 9장, 마지막 장은 비어 있음 → `idle`로 넘긴다), `mark-drop-idle`(24×28, 30장, 반복 1.2초), `mark-drop-expire`(24×36, 12장). 모두 25fps, 피벗은 방울 몸 가운데.
- 방울 하나만 그린다. n개일 때 i번째 방울은 몸통 가운데(격발 피벗)에서 x `(i - (n-1)/2) × 8`, y `-42`(위쪽) 자리에 둔다. 값은 JSON `meta.pixelfx.slot`에 있다. 개수가 늘면 기존 방울을 새 자리로 0.1초 동안 옮겨 보였다.
- 여러 방울이 함께 떠 있을 때 `idle` 시작 장을 서로 다르게 두어 같이 들썩이지 않게 한다.
- y `-42`는 가시뿌리(머리 끝이 몸통 가운데에서 약 32px 위) 기준이다. 키가 다른 몬스터는 머리 위 기준점으로 바꿔야 한다.

격발:

- 한 장 200×170, 25fps, 26장. 피벗은 `meta.pixelfx.pivot`(100, 108) = 맞은 몬스터의 몸통 가운데. 바닥은 피벗 아래 28px.
- 화소 1:1 = PPU32 게임 화소. 가시뿌리(128px 칸, 몸 약 57×60) 기준으로 맞췄다.
- 0~4장은 머리 위 표식 방울이 몸통으로 빨려 드는 구간이다. `meta.pixelfx.impactFrame`(5)이 접촉 장이다.
- 피격 멈춤은 `holdFrame`(6)에 건다. 이 장은 일부러 작은 불꽃이다. 크게 터진 장에서 멈추면 박제처럼 보인다.
- 오른쪽으로 맞는 판만 뽑는다. 왼쪽으로 맞으면 시트를 좌우 반전한다.
- 흰 몸에 먹 테두리(#1A1A1A)로, 기존 흰 피격 효과와 맞춘다. 먹색 몬스터 몸 위에서도 보인다.
- `base`는 파츠 없이 터질 때 쓴다. 「표식을 터트릴 시」 파츠(빨강 파열 가시·노랑 파열 가속·초록 파열의 생기·파랑 파열의 여백·보라 파열 족쇄)를 끼우고 터트리면 그 파츠 색 판으로 바꿔 쓴다. 격발 자체가 그 파츠의 발동이라는 걸 색으로 보여 주려는 것이다(사용자 결정). 파츠 이펙트(가시·이속·회복·말뚝)는 그 위에 따로 나오고, 이펙트가 없는 파열의 여백은 파랑 격발이 유일한 표시다.
- 색 판은 테두리 없이 몸 색으로 채운다(옵션 `rim: false`). 팔레트는 각 파츠 이펙트와 같은 임시값이다.
- 여러 색 「표식을 터트릴 시」 파츠를 함께 끼우면 한 격발에 색을 섞는다. 튀어 나가는 덩어리마다 색을 하나씩 돌려 주고, 화소는 가장 진하게 더해 준 덩어리의 색을 따른다(옵션 `mix`: 팔레트 목록, `mixMode: "blob"`). 부채꼴로 나누기(`sector`)·겹치는 곳 섞기(`blend`)도 비교했고 사용자가 덩어리마다 색을 골랐다. 색 조합 26가지(둘~다섯 색, 빨강→보라 순서) × 표식 1~5개 = 130장을 `mark-burst_<색-색…>_m<표식 수>`로 뽑는다.
- 표식은 색과 관계없이 쌓이므로 방울은 기본 판 하나다.

## 확인한 범위

1스테이지 실제 게임 캡처(가시뿌리를 때리기 전·맞는 순간·맞은 뒤) 위에서 표식 다섯 개 쌓임 → 격발 → 두 개 쌓임 → 만료를 이어 붙여 렌더링으로 봤다(만료는 8초 대신 1초로 당김). 마을 스케치 배경 위 가시뿌리 한 마리에 게임 피격 반응(`hit_feedback.json`의 흰 점멸·강타 멈춤 0.075초, hit 그림 0.12초, 3px 밀림, 화면 파동, 몸 젖힘 0.2rad)을 흉내 내어 렌더링으로만 봤다. Unity 실행·다른 몬스터·보스 크기는 확인하지 않았다. pixelfx 검사에서 한 장 5.5ms가 걸려, 게임에서 코드로 직접 돌리기보다 시트로 쓰는 것을 전제로 한다.
