# 잉크 설계 작성지

[잉크 개요](README.md) · [공통 규칙](rules.md)

효과 잉크의 27개 유효 조합과 빨강·파랑의 색별 역할을 구분해 작성한다. 빈 수치를 기존 파츠에서 자동 승계하지 않는다.

| 항목 | 정의할 내용 |
|---|---|
| 정체성 | ID·색상·역할·플레이어 설명 |
| 레어도 | 노말·레어·에픽. 현재 유형은 노말이며 기본/강화와 독립 |
| 기본/강화 | 모든 잉크에 두 수치 필수. 변경 파라미터·강화 조건은 별도 결정 |
| 트리거 | 효과 잉크의 다섯 조건, 빨강 기본 공격 피해, 파랑 스킬 공격 적중(맞힌 몬스터의 상태 조건 확인) |
| 상태 조건 | 빨강·파랑은 공격 대상 몬스터의 기절·속박·슬로우. 같은 공격의 상태 부여 후 확인하여 즉시 발동 가능. 기본 목록은 조건 하나씩, 복합 조건 예외형 미정 |
| 비용·페널티 | 없음. 자원·상태 시간 차감과 플레이어 반동 없음 |
| 빨강 효과 | 발동 타격부터 플레이어에게 버프를 부여해 무기와 관계없이 기본 공격 피해만 증가. 교대·가방 보관·원본 무기 소멸 후에도 남은 시간 유지. 기본/강화 증가율·기간·쿨타임은 [효과 규칙](effects.md#빨강파랑의-공통-상태-조건) 참조 |
| 파랑 효과 | 원본 무기에서 현재 진행 중인 같은 스킬의 기본 쿨타임에 비례해 남은 대기 감소(이전 사용의 지연 적중도 가능) 또는 조건 충족 시 1타 피해 계산 전에 강화해 1타부터 피해 증가(같은 1타로 부여한 상태도 인정), 이후 같은 스킬 사용의 남은 타격까지 적용. 각 대상의 상태 조건을 피해 계산 시 확인. 수치는 [효과 규칙](effects.md#스킬-강화-파란-잉크) 참조, 기존 동일 피해 범위의 증가율과 합산 |
| 발동 단위 | 노랑·초록·파랑은 공격 실행당 장착본별 최대 1회. 빨강은 매 유효 적중에 갱신, 보라는 활성 중 원본 무기의 매 적중마다 부여. 중복 환산·활성 시간은 [효과 규칙](effects.md) 참조 |
| 스위칭·대쉬 | 직전 공격이 다른 무기이면 들어온 무기의 잉크 사용, 이속·회복은 공격 실행 시, 방어막은 적중 시 발동. 대쉬 자기 효과는 시작 시, 상태이상은 대쉬 경로의 적들에게 부여. 노랑·초록의 대쉬 쿨타임은 같은 효과의 기본/스킬 조건보다 길게; 보라는 공통 부여 버프 규칙 적용 |
| 효과 수명 | 대상·중첩·갱신·비활성 무기 시간·무기 소멸 |
| 쿨타임 | 무기별 독립. 빨강은 쿨타임 없음, 보라는 활성 종료 후 재사용 대기. 파랑은 실제 유효 발동 시 시작. 확정 수치는 [효과 규칙](effects.md) 참조 |
| 적용·도감 | 획득당 기본 10회·슬롯당 1회 소비·재획득 허용. 팔레트 슬롯마다 하나씩 동일 잉크 중복 허용. 슬롯 구성·확정 후 빈칸 포함 전체 편집 금지는 [무기 적용](../ink-application.md), 중복본 처리는 [효과 규칙](effects.md) 참조 |
| 내구도 | 실제 누적 피해·초과 피해·소진 타격 |
| 검증 | 실제 발동률·상태 유지율·클리어 시간·유틸리티·생성 문서와 런타임 경계 |
