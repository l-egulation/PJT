# 인벤토리·정비소 아이템 그림

[분야 개요](README.md)

`resources/ui/inventory-symbols-20261106`은 확정 v2 문양과 물방울 잉크·D 손잡이 도장 바탕의 제작 원본을 보존한다. 생성된 개별 투명 PNG는 `runtime/items/`, ID·해시·크기는 `runtime/items.json`, 요청문은 `source/production-prompts.json`이다. 검토 보드를 잘라 런타임 에셋으로 사용하지 않는다.

초록 잉크는 초록 방울·먹색 문양·초록색 음각으로 통일한다. `ink3_green_01`, `ink3_green_04`, `ink3_green_06`, `ink3_green_10`에는 종이색 원판이나 밝은 채움·선이 들어가지 않는다. 수정 전·중간 제작본과 최종 생성 원본·요청문은 [초록 아이콘 편집 기록](../../../../resources/ui/inventory-symbols-20261106/source/green-palette-review-20261108/generation-edits.json)에 보존하며, 게임은 같은 파일명의 최종 `runtime/items/` 그림을 사용한다. Sprite 이름·GUID·가져오기 설정과 장착 동작은 유지한다.

아이템 64개는 색상 잉크 54종, 형태 스탬프 7종, 공통 스킬 스탬프 3종이다. 추가 빈 바탕은 잉크 5색·형태·스킬의 7개다. 스탬프 이름·호환성·획득 규칙은 바꾸지 않는다. 기본 도면과 발사기 스킬 외형은 별도 스탬프 아이템으로 추가하지 않는다. 등급·강화 수치·개수·선택 테두리는 그림에 포함하지 않고 기존 UI의 별도 요소로 둔다.

`python tools/assets/prepare_inventory_icons.py`는 메인 소유의 가져오기 설정과 배치 계약을 준비한다. `python tools/assets/update_assets.py --asset ui.inventory-symbols-20261106 --local-preview`는 선택한 로컬 제작본을 바이트 그대로 Unity의 `Resources/ApprovedItemIcons`에 배치한다. 원본 PNG를 재인코딩하지 않으며 importer는 최대 512·Bilinear·압축 없음·밉맵 없음·투명 알파를 사용한다.

공통 `TemporaryGameGui.ItemIcons.cs`가 ID별 Sprite를 캐시한다. 인벤토리의 보관·장착·상세 보기와 정비소의 색상 잉크·스탬프 보관 목록·상세 보기에 같은 그림을 표시한다. 색상 잉크는 실제 파츠 ID로 연결하고, 형태 스탬프는 `FormId`, 스킬 스탬프는 범위·이동·후속타의 실제 슬롯으로 연결한다. 기존 인벤토리의 `form.*`, `special.range`, `special.move`, `special.follow` 아이템도 같은 스탬프 그림을 사용한다. 장착하지 않은 기본 도면 표시와 비어 있는 팔레트 칸의 안내, 등급·강화 배지는 기존 UI 역할을 유지한다. 획득·장착·교체 규칙은 바꾸지 않는다.

정비소 보관 목록의 스탬프 칸에는 이름을 넣지 않고 아이콘만 가운데 표시한다. 클릭한 아이템의 이름·효과·적용 조건은 목록 아래의 상세 영역에서 확인한다.

정비소의 `장비 관리` 화면은 왼쪽 위에 현재 형태·스킬 스탬프, 아래에 선택 무기의 팔레트·슬롯 강화를 배치한다. 오른쪽은 보관함과 선택한 아이템이다. 왼쪽의 형태·스킬 칸을 클릭하면 해당 스탬프 보관 필터를 연다. 팔레트 칸에는 번호를 표시하고, 중복된 팔레트 미리보기는 두지 않는다.

왼쪽 스탬프 카드는 170×84, 내부 도장 그림은 68×68로 표시한다. 팔레트의 물방울은 최대 76×76이며, 4·5칸에서도 옆 칸과 겹치지 않도록 실제 칸 너비에서 좌우 여백을 뺀 크기로 제한한다. 칸 번호·강화 배지는 모서리에 유지한다.

왼쪽 도장 바탕에는 현재 무기 형태와 실제 선택된 스킬의 문양을 검은색으로 겹쳐 표시한다. 기본 상태에도 검·강베기 등의 문양을 표시하고, 형태·스킬 스탬프 적용 후에는 실제 런타임 장비 상태에서 다시 읽는다. 아직 적용하지 않은 보관 아이템의 문양과 장착 중 문양을 혼동하지 않는다.

스탬프를 선택하면 `현재 → 변경 후`에 전투 HUD와 같은 무기·스킬 아이콘을 나란히 표시한다. 비교 영역에는 사각 테두리를 두지 않고 지름 72의 원형 바탕과 64×64 아이콘을 사용한다. 실제 FormId와 스킬 ID로 HUD 바인딩을 찾아 발사기 변형에도 연결한다. 선택한 아이템의 이름은 상세 영역 제목에 둔다. 일반적인 작동 원리를 문장으로 반복하지 않고 종류를 짧게 표기한다. 변경 비용은 하나의 실행 버튼에 `무료` 또는 골드 아이콘과 실제 가격으로 표시한다. 호환 불가·골드 부족·기존 스탬프 소멸은 짧은 상태 문구로 남긴다. 잉크 전용 색 변경·판매·파괴 버튼은 스탬프 보기에서 숨긴다.

색상이 지정된 빈 팔레트 칸에는 같은 색의 `backing-ink-*` 물방울 그림을 불투명도 40%로 연하게 표시한다. `빈 칸` 글자는 넣지 않고 문양 유무와 진하기로 장착 상태를 구분한다. 무색 칸의 자유색 안내는 유지한다. 인벤토리의 빈 색상 칸에도 같은 바탕과 진하기를 사용한다. 변경 미리보기의 `현재 / 변경 후` 글씨는 각 아이콘 아래에 표시한다.

원본 PNG와 Unity 배치 PNG의 바이트는 같다. 가져오기 최대 크기는 512이므로 Unity 내부 텍스처는 원본과 다른 크기일 수 있다. 압축은 사용하지 않는다. 화면에서 수십 픽셀로 축소하는 과정과 캡처 자체의 해상도도 윤곽에 영향을 준다. 검토용 원본은 1920×1080 캡처도 제공하며, 960×540 이미지를 확대해 가져오기 손상을 단정하지 않는다.

보관 잉크를 선택했을 때만 장착·판매·파괴를 표시하고, 색 변경은 선택한 점유 칸과 잉크의 색이 다르며 변경 횟수가 남았을 때 표시한다. 칸 미선택 상태의 주 버튼은 `장착할 칸 선택`, 장착 가능한 칸이 선택되면 `N번 칸 장착/교체`로 대상을 드러낸다. 원래의 칸 선택 후 장착·잉크 선택 후 칸 선택 흐름, 강화·비용·잉크 반환 규칙은 유지한다.

정비소 첫 팔레트 화면의 무기 초상도 전투 HUD의 현재 무기 그림을 사용한다. 형태·스킬 변경 시 초상을 갱신하며 발사기 스킬 외형도 따른다. 보관 목록은 선택 테두리가 스크롤 마스크에 잘리지 않도록 사방에 여백을 둔다.

첫 팔레트 화면에서는 무기 원 바깥의 사각 초상 프레임을 표시하지 않는다. 옆 물방울은 최대 너비 54로 키우고, 4·5칸에서도 카드 안에 들어오도록 실제 너비에 맞춰 제한한다.

장착 대상 문구는 `N번 칸 장착`처럼 한 줄로 표시한다. 정비소의 보유 골드·강화 가격·판매·색 변경·스탬프 교체 비용에는 `G`를 붙이지 않고 전투 HUD의 골드 아이콘과 숫자를 함께 표시한다. 무료 적용은 `무료`로 표시한다.

정비소 스탬프 탭은 그 화면에서 직접 교체하는 양쪽 펼침 구성이다. 오른쪽에는 보유 스탬프 아이콘과 전체·형태·스킬 필터, 선택한 스탬프의 이름·종류를 둔다. 왼쪽에는 두 무기 각각의 현재 형태·스킬 문양과 이름, 선택 가능한 네 대상 칸을 둔다. 스탬프 선택은 현재 무기의 해당 종류 칸을 선택하고, 대상 칸 선택은 해당 종류의 보유 목록을 연다. 왼쪽 하단에는 현재/변경 후 아이콘과 실제 적용 버튼을 표시하며 다른 장비 관리 화면으로 이동하지 않는다. 첫 적용 무료·종류별 교체 비용·현재 스탬프 소멸·도면 호환·골드 부족 판정은 기존 정비 서비스에서 읽고, 적용 후 보유 목록과 현재 장착 문양을 즉시 갱신한다. 보유 목록은 스크롤되며 선택 테두리의 여백을 유지한다.

색상 잉크의 상세 제목 옆에는 기존 1~4등급 그림 배지를 표시한다. 본문 첫 줄에는 선택된 슬롯 레벨의 실제 값을 `현재 비율 40%`, `현재 수치 15`처럼 굵게 표시하고 효과 설명을 잇는다. 숫자 등급과 `이 칸 +N 적용`을 문장으로 반복하지 않는다. 인벤토리도 같은 표시를 사용한다. 색상 불일치 안내 문구는 표시하지 않으며, 호환 검사와 칸 선택·색 변경·장착 제한은 유지한다.

Unity 6000.6.5f1 메뉴 `Tools > deviant > Item Icons > Validate Applied Sprites`는 71개 Sprite의 로드와 가져오기 설정을 확인한다. 아트 미세 차이와 실제 UI 내 배치의 미술 검토는 별도로 수행한다.
