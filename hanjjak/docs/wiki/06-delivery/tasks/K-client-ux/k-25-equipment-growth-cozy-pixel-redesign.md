# K-25 장비 성장 cozy-pixel UI 개편

> 작업 상태와 완료 증거의 SSOT. 강화·승급 규칙은 [장비 SSOT](../../../../30-domain/items/equipment/ssot.md), 거래 규칙은 [거래소 SSOT](../../../../30-domain/economy/ssot.md), 화면 원칙은 [클라이언트 UX SSOT](../../../../30-domain/player/ux/ssot.md)를 따른다.

## 완료 기준

- 캐릭터 창과 같은 cozy-pixel 종이 화면에서 왼쪽 젓가락 캐릭터 주위에 6개 장비 선택 카드를 배치하고, 선택 장비의 현재 상태와 다음 성장 결과, 필요 재료와 실행 가능 상태를 오른쪽 상세 영역에 표시한다.
- 진행 바 없이 `+N강` 형식을 사용하고, 현재 성장 비용의 아이템 재료를 세로 목록으로 나눠 사용자용 이름·등급·보유량/필요량과 부족 여부 또는 충족 상태를 표시한다. 쌀은 강화 버튼 왼쪽에 현재 보유량/필요량으로 표시한다.
- 승급 가능 상태와 승급 결과는 장비 SSOT의 등급·강화 전이를 그대로 표현한다.
- 상단에는 젓가락 마스코트와 닫기 동선을 표시하고 장비·재료·쌀골드·거래소 에셋을 확정 화풍으로 통일한다.
- 부족 재료 구매 모달은 본인 매물을 제외한 실제 구매 가능 최저 단가를 `현재 최저가`로 표시한다.
- 1440px 기준과 지원 해상도에서 잘림, 겹침, 가로 오버플로 없이 동작하고 강화·승급·거래소 구매 회귀 테스트를 통과한다.
