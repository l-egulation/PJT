확장 광역기 · 실제 연출과 함께 보기

사용자 확정: B4 (주먹 사이 장 추가). 게임용 결과는 runtime/fan-final. Unity 적용 전입니다.

몸 동작 A·B를 게임 광역기 시간표와 같은 시계로 재생합니다. 0초 중앙 순간이동·회오리 시작 → 0.5~2.5초 광역 확장(회오리를 도는 화살 60개) → 2.5초부터 0.1초 간격으로 머리 위 화살 6개 생성 → 3.0 / 3.5·3.6 / 4.1·4.2·4.3초에 플레이어를 향해 발사.

에셋 합성 미리보기입니다. 회오리 앞뒤 시트와 화살은 확정 VFX 시트(aoe-whirl-back/front, p3-arrow-flight) 그대로이고, 회오리를 도는 화살 60개는 게임 코드의 계산식을 그대로 옮겼습니다. 32px=1유닛, 보스는 1배 크기로 중앙에 둡니다. 광역 전조 빛은 얇은 보라 바닥 선으로 비슷하게 그렸습니다. Unity 화면이 아닙니다.
