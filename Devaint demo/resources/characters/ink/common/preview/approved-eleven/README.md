# 잉크 · 무기 11종 확정본

2026-10-21 사용자 승인 기준입니다.

- `index.html`: 11종 전체 모션, 단발/연속 공격, 타격별 확인, 이펙트 재생.
- `원거리4종_직접발사.html`: 원거리 직접 발사. 레이저는 버튼을 누르는 동안 지속됩니다.
- `무기별/`: 각 무기의 원래 크기 PNG, 동작별 시트, 프레임 순서·시간·피벗을 기록한 `animation.json`.
- `이펙트_스프라이트/`: 기본포 A, 레이저 B, 샷건 A, 유탄 비대칭 B. 근접 7종 이펙트는 해당 무기 폴더에 있습니다.
- `편집자료/`: 사용자 최종 공격 편집 원본. 최종 전체 모션의 기준은 `무기별/`입니다.
- `viewer-data.json`, `effects-data.json`: 확정 모션·이펙트 원본 데이터. 미채택 시안은 포함하지 않았습니다.
- `확정목록.json`, `검증결과.json`, `정리기록.json`: 승인 기준, 무결성 검증, 삭제 내역.

HTML은 이 폴더 안의 파일만 사용합니다. 무기별 PNG는 크기를 재조정하지 않았으며 시트의 셀 크기·피벗은 각 animation.json을 따라야 합니다. 대기, 걷기, 달리기, 점프, 대시, 공격, 죽음의 픽셀과 프레임 시간은 승인본 그대로입니다. 모든 이펙트는 검정 계열이고 레이저만 승인한 흰 중심·청색 발광을 사용합니다.

최종 구성: 무기 11종 / 원래 크기 프레임 602장 / 동작별 시트 88장. 기존 모션·이펙트 시안과 중복 배포본 등 69개 항목, 파일 16,652개(약 489MiB)를 실제 삭제했습니다. 수리검·폭탄 진행 자료, 02_에셋 제작 원본, 게임 저장소와 다른 작업 자료는 보존했습니다.
