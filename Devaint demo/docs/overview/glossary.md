# 공통 용어

[분야 개요](README.md)

팀원이 같은 단어를 같은 범위로 사용하기 위한 안내다. 수치·예외는 연결된 원본을 따른다.

| 용어 | 이 프로젝트에서의 의미 | 혼동하지 않을 것 |
|---|---|---|
| 런 | 시작부터 종료까지의 한 게임 진행 | 개발용 F5 리셋과 실제 새 런·정산 |
| 챕터 | 자유 이동 공간을 이루는 큰 진행 단위 | 물리적으로 연결된 층·독립 방 |
| 일반 전투 맵 | 챕터당 8개라는 콘텐츠 규모 단위 | 적 전멸 잠금 방 8개 |
| 무기 종류 | 검·둔기·원거리·미정 1종 | 각 종류의 형태 수는 동일하게 확정되지 않음 |
| 형태 | 검·채찍·방패 등 기본·특수 동작의 구성 | 별도 장착 무기 슬롯 수 |
| 맨손 | 빈 장착 칸에서 쓰는 기본 공격 | 별도 스킬 없음 |
| 스케치 무기(도면) | 무기 종류·스킬 하나·팔레트가 정해진 런 장비 | 최초 확정 후 사용 |
| 색상 잉크 | 유틸리티 효과 부여, 몬스터 상태 조건부 기본 공격 강화(빨강)·스킬 강화(파랑). 잉크 레벨 없음 | 효과와 쿨타임은 무기별 독립 |
| 런 잉크 도감 | 런마다 종류별 부여 횟수를 관리. 획득당 기본 10회 합산·재획득 허용 | 영구 수집 도감 아님 |
| 무기 잉크 적용 | 보유 횟수 안에서 무기 슬롯마다 잉크 부여 | 슬롯당 1회 예약 후 확정 소비. 동일 잉크 중복 부여 가능 |
| 무기 확정 | 가방에서 현재 팔레트 구성을 확정해 사용 가능하게 함 | 골드 비용 없음, 빈 팔레트도 가능 |
| 내구도 | 도면 무기의 누적 가한 피해량으로 소모하며 소진 시 무기 소멸 | 공격 횟수·피격량 기준 아님 |
| 일반 처치 보상 | 보상 게이지가 한 칸 찰 때마다 받아 두고, 열 때 무기·잉크 후보 3개 중 하나 획득 | 보스·이벤트 방 보상은 별도 |
| 보상 게이지 | 처치한 몬스터의 크기(체력 등급)만큼 차는 막대. 한 칸이 차면 일반 처치 보상 1개를 받아 둔다 | 엘리트는 한 칸 |
| 이벤트 방 | 고유 목표(구출·생존·상자 선택·수집 등)를 완료하면 즉시 보상을 고르는 방 | 받아 둘 수 없음 |
| 몸 / 피격 / 공격 | 지형 충돌 / 피해 수신 / 적중 탐색의 별도 역할 | 스프라이트 전체 투명 캔버스 |
| 발 피벗 | 배치·판정의 발 기준 원점 | 플레이어·몬스터가 반드시 같은 픽셀인 것은 아님 |
| 독립 효과 | 발동 후 교체·취소와 별도 수명을 갖는 투사체·잔상 등 | 직접 다단 판정의 남은 타격 |
| 공통 씬 | `Assets/Deviant/Game/Scenes/deviant.unity` | 전체 제품 루프 완성 |
| 시험장 | `CombatV2Arena`의 격리 전투 시험 공간 | 정식 챕터 |
| 파일럿 | 특정 대상·지형·행동의 제한된 적용 | 모든 종·지형·제품 기능 완료 |
| fixture | 계약 검사를 위해 구성한 격리 테스트 데이터 | 실제 제품 맵·NPC 콘텐츠 |
| 기준 원본 | 직접 편집하고 다른 결과물이 따라야 하는 명세·데이터 | 생성 문서·카탈로그 |
| 제작 확정 / 적용 / 검증 | 콘텐츠 승인 / 게임 연결 / 실제 확인 | 서로 대신할 수 있는 완료 표시가 아님 |

규칙은 [게임 개요](overview.md), [런 구조](../design/run/run-structure.md), [무기·잉크](../design/equipment/rules.md), [전투 명세](../design/combat/rules.md), [개발 구조](../development/architecture/architecture.md)를 따른다.
