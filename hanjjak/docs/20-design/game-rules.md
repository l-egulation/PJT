# Game Rules

게임 규칙을 찾기 위한 상위 경로다. 규칙·수치·상태 전이는 다음 도메인 SSOT가 단독으로 소유한다.

- 플레이어·저장: [Player](../30-domain/player/ssot.md)
- 캐릭터·전문: [Character](../30-domain/character/ssot.md)
- 전투: [Combat](../30-domain/combat/ssot.md)
- 월드·스테이지: [World](../30-domain/world/ssot.md)
- 아이템·장비: [Items](../30-domain/items/ssot.md)
- 성장: [Progression](../30-domain/progression/ssot.md)
- 경제·거래: [Economy](../30-domain/economy/ssot.md)

출시 범위와 실행 순서는 [MVP Plan](../70-plans/mvp-release/requirements.md)과 A–K 작업 문서에서 확인한다.
